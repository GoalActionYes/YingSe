# 映色：参考图驱动调色基线

**2026-09-27更新：V0.2风格滤镜版。** 八种风格为黑金、赛博朋克、青橙、复古胶片、日系清新、冷峻电影、暖阳、黑白电影。点击缩略图直接应用100%风格；滤镜强度与基础调整独立。详情见 `风格滤镜更新说明.md`。

这是为2026年9月28日进度会议准备的第一版可运行原型。当前实现是**统计基线与固定LUT视频管线**，未训练神经网络，未实现语义肤色保护。原计划书未被修改。

## 在这台电脑上启动

**发给组员体验（Windows 10/11 x64）：使用 `dist/映色-V0.2.2-Windows64-小组体验.zip`，不要发项目根目录的单个EXE。** 便携包已包含Python、NumPy、Pillow和FFmpeg；组员完整解压后双击包内映色.exe，不需要Codex、Python安装或PowerShell 7。使用说明与反馈模板在包内。程序仍需现代浏览器；有Edge时打开独立应用窗口。已完成本机换目录解压验收，其他电脑兼容性需组员首轮确认。

**桌面演示入口：双击 `映色.exe`。** 自动启动本机服务并打开独立的 Edge 应用窗口。此版是本机启动封装，仍依赖现有 Python 与 Edge，不能单独复制 EXE 到其他电脑。操作及会议流程见 `桌面版使用与现场演示.md`。

双击项目根目录的 `启动演示.cmd`，浏览器会打开 http://127.0.0.1:8765 。也可在已经运行的服务上直接访问这个地址。

服务只监听本机。图片和视频不会上传到云端，载入素材存于 `prototype/data/`，导出结果存于 `prototype/outputs/`。本地页面启动后可离线演示。

## 最稳妥的演示顺序（2分钟）

1. 载入图片，点击“黑金”“赛博朋克”“青橙”等风格缩略图，检查各自的色调变化。内置参考图为程序生成的青橙合成色卡。
2. 将“滤镜强度”设为0、50、100，展示原图与完整风格的连续变化；再独立调整曝光、对比度、饱和度、色温。
3. 点击“下载 .cube LUT”。它只保存全局颜色映射，不包含肤色Mask。
4. 点击“示例视频”，再点击“导出调色视频 MP4”。完成后播放结果、查看“实验参数JSON”。
5. 说明还需要用真实拍摄素材评估风格效果和肤色。不要把合成素材演示作为真实影视质量证明。

若现场浏览器或服务出现问题，直接打开已导出的 `prototype/outputs/verified-video-v2/graded.mp4`，并展示 `prototype/outputs/style-check/styles-portrait.jpg`。历史V0.1视频与记录也保留在原位置。

## 已实现

- 参考图、目标图片或短视频载入；视频抽取首帧用于推荐和预览。
- 8个风格滤镜加恒等映射；默认单选直接应用，混合配比放入高级设置。原色不参与界面中的风格配比。
- 滤镜强度0—100%，曝光−3～+3 EV，对比度、饱和度、色温−100～+100；基础调整均以0为中性。
- 根据目标素材与参考图的RGB均值和标准差，搜索预设混合权重。
- 33³ LUT生成、三线性插值预览、标准 `.cube` 导出。
- FFmpeg视频处理、H.264 MP4输出、可选第一音轨AAC转码、进度显示与取消。
- 导出每次实验的权重、强度、耗时与方法边界。

## 当前限制

- 自动推荐需要目标图（视频首帧）和参考图；它是全局统计拟合，不是计划书中的ResNet18。
- 管线验证使用合成色卡和6秒24fps的960×540视频。V0.2另用项目中现有的人像和蓝色灯光照片进行目视对比；尚未开展系统主观评价、风景测试或真实视频质量研究。
- 没有语义分割、肤色保护、Mask时间平滑、神经网络训练和跨平台桌面打包。
- 首版输入应是常规SDR素材。没有完成ICC、HDR、Log及专业色彩管理。图片预览最长边1280；图片输出也是预览分辨率。
- 视频按原分辨率处理，奇数尺寸补齐为偶数；仅保留第一条视频流和第一条音频流。字幕、其他音轨不在此版交付范围。
- 已输出 `.cube` 并与FFmpeg交叉检查；没有实际操作达芬奇导入验收。
- 导出取消后可能保留未完成文件，页面不会把它标成成功；仅使用显示“导出完成”的结果。
- 为保证现场可用，服务重启后需要重新选择自有素材；内置素材无需重新载入。

## 环境与复现

目前启动脚本使用本机Codex附带的Python运行时。**复制给其他人不能假设直接运行**：需要Python 3.12或相近版本，安装以下依赖，再执行 `python prototype/server.py`。

```powershell
python -m pip install -r requirements.txt
python prototype/verify.py
python prototype/verify_styles.py
python prototype/server.py
```

本项目使用的依赖：NumPy、Pillow；imageio-ffmpeg 0.6.0在本机的 `.deps/` 中提供FFmpeg。未修改系统Python或安装GPU驱动。

## 技术依据

- FFmpeg `lut3d` 和混合滤镜文档：https://ffmpeg.org/ffmpeg-filters.html
- FFmpeg音视频流选择：https://ffmpeg.org/ffmpeg.html#Stream-selection
- 后续神经模型研究参考：https://arxiv.org/abs/2009.14468

这版工程基线是后续比较对象。之后加入神经模型时，应保持LUT渲染和输出管线不变，独立比较权重推荐质量。
