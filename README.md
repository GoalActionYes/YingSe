# 映色参考图调色原型

输入参考图与目标图片或视频，生成颜色映射并导出。现有源码、实验和研发记录从2026年11月5日开始统一使用Git管理。

## 选择版本

- `reference_color_app/`：参考调色稳定源码，核心按剪映逆向证据独立实现，非完整原生引擎。
- `experimental/skin-protection-20261019/`：默认关闭的肤色保护实验，支持图片和30fps保护视频。
- `experimental/content-balance-20261105/`：统计贡献平衡研究。7项测试通过，但更换采样种子出现漂移增大的反例，未接入App。
- `prototype/`：早期八种预设风格与权重搜索方案。

完整版本标签、切换方法及上传状态见[版本索引](VERSIONS.md)。研发复盘与当前策略见[持续日志](讨论/11-研发日志与调整策略/持续研发日志.md)。

## 源码与完整体验包的区别

Git仅保存已筛选的源码、测试与文档。运行时、离线模型、大文件、私人素材、项目数据库和浏览器配置不入库。原电脑完整体验ZIP仍在讨论/06、09目录；它们不随源码克隆分发。依赖准备见requirements.txt及实验版dependencies-lock.json；模型来源见实验版THIRD-PARTY-NOTICES。未随库提供的原生验证资料及媒体夹具会影响部分证据测试，不能将源码快照误称为完整可独立验收的发行包。

## 基本开发

Python需NumPy、Pillow、FFmpeg；源码服务可通过 `python -m reference_color_app.server --port 0` 启动，仅监听本机。精确支持范围见[使用说明](docs/reference-color-usage.md)。实验模块另有README，不承诺全局HDR或原生10位等价处理。

未来工作先走研究与对照，稳定后再进入产品接入；任何新增方法都须检查全画面协调性，不能只看局部误差。
