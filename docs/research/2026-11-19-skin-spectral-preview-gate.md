# 打码预览上的自动定位保住了已知光源的脸颊修正

用三张作者打码的完整 D65 预览运行固定的 MediaPipe 皮肤定位器。它只读 JPEG，按 `face_skin` 概率 ≥0.70 选像素。之后在六组已归档光谱试验里，把定位结果投到原登记的脸颊片上，只有入选像素保留旧肤色修正，其余回到同一个矩阵输出。登记的脸颊范围与光源信息用于离线图板和评分，未传给定位器。[事前协议](../../experimental/adaptive-reference-20261113/skin-spectral-preview-gate-protocol.md) · [原光谱出图](2026-11-19-skin-spectral-donors.md)

| 拍摄组 | 两侧脸颊核心自动覆盖 | 低值背景入选／像素数 | 两个方向的脸颊中位误差范围 |
| --- | ---: | ---: | ---: |
| 235 | 100%／100% | 0／61,617 | 0.33–0.33 |
| 253 | 100%／100% | 1／79,507 | 0.33–1.00 |
| 282 | 100%／100% | 0／92,717 | 0.33–0.33 |

六组使用自动定位回退的图板成片都与原修正逐像素一致，保住了先前的已知光源结果。脸颊 90 分位误差最高 1.33，六组达到该阶段的定位及成片门槛。背景统计仅覆盖预览上 RGB 三通道均 ≤3 的像素。拼接灰块没有参与定位，保持原来的矩阵输出。评估在 D65 打码预览上只检测一次，两种光谱方向复用同一定位。全脸、暖灯下重检测、白墙和衣物误报、普通参考如何判断光源及有意调色仍待验证。这轮保留现有软件模型。

两遍生成的四个掩膜准备文件和七个评估文件逐件同哈希。报告 SHA256 `b8c2b2a9018f8f7a5d93c46e071149c13a7dd4facc309331b69b6475d6a3ba92`。另按原坐标独立复算六块脸颊的采样覆盖及背景计数，检查六张落盘图中修正区域和矩阵控制。数据使用作者管控的打码 RGB 预览，存档研究图板只包含已登记的光谱脸颊片和色块。[作者资料与 CC BY 4.0](https://doi.org/10.6084/m9.figshare.c.7163569)

本机复现使用 `probe_skin_spectral_preview_gate.py`。用已有皮肤保护便携 Python 和 [DAST 脚本调用方式](2026-11-19-dast-exposure-response.md)执行 `prepare <hyperspectral-faces-input> <掩膜输出>`，再用视觉研究 Python 将仓库根和 `.tools/DeepWB-audit/vendor` 加入 `PYTHONPATH`，执行 `evaluate <hyperspectral-faces-input> <掩膜输出> <skin-spectral-donors> <skin-spectra-input> <新输出>`。全部目录位于本机研究输出根。未上传媒体、掩膜、权重或运行环境。
