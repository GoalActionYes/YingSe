# 颜色簇一致变换诊断

本轮独立实现并验证颜色簇配准候选。它在已知变换、颜色面积变化的受控素材上有效，在真实开发图上仍不可靠，因此不接入软件，不替代完整自适应协调目标。

## 方法和范围

对RGB每通道16档量化，取非空箱真实均值；超过256簇时用固定最远点采样。两组颜色点做双向最近邻匹配，保留误差最低80%的匹配池，以Cauchy权重和单位变换正则拟合4×3仿射矩阵。迭代最多20次，线性部分奇异值限制0.5–2，偏置限制±0.2。全部参数在本轮自然图推断前固定，不逐例调节或挑选结果。

方法借鉴[点集配准](https://arxiv.org/abs/0905.2635)的一致变换思想；本实现不是该论文的CPD算法，也不是[颜色同态论文](https://homepages.inf.ed.ac.uk/rbf/PAPERS/hgbmvc16.pdf)的完整复现。最近颜色不一定对应同种材质，ICP也不保证全局最优。输出是全局仿射，尚不具备基于画面上下文的区域协调能力。

先写3项轻量测试并观察缺少模块导致失败，再实现模块，验证乱序调色板恒等、小幅已知偏色恢复、非法输入拒绝。随后运行上一轮8个固定内容占比控制，算法不接收颜色标签或真实对应。已用PST第1–15组全部预测保存并冻结哈希后才读取专家目标；第16–50组未参与。

## 实际结果

四个恒等控制RGB MAE均为0，四个已知暖色仿射控制均为0.125码值。此处不含同图快捷保护，确实通过无标签最近邻拟合得到结果；这只证明所测小幅已知变换可恢复。

| 真实开发结果 | 数值 |
|---|---:|
| 总组数／推断失败 | 15／0 |
| 现有版平均RGB MAE | 17.867 |
| 颜色簇配准平均RGB MAE | 23.404 |
| 改善／退化 | 8／7 |
| 严重退化 | 5 |

阈值沿用0.1码值，严重退化须同时超过基线5码值和25%。平均误差与严重退化均不满足替换依据。查看第1、7组：候选在第1组不能保留所需的深冷色风格，在第7组比旧版少了明显压暗，但参考／专家效果仍未完整恢复。仅查看两组，不称为全部图人工验收。

## 结论与下一步

控制测试与真实照片存在明确差距：多个颜色簇支持一个仿射变换，仍不能证明对应是同材质或同照明。颜色统计均衡、最近邻及一致变换不足以提供可靠语义证据。下一轮不继续根据这15组调节trim比例或正则，而应验证更可靠的跨图对应／风格监督来源；冻结真正有依据的候选后，才使用尚未参与调试的样例。
