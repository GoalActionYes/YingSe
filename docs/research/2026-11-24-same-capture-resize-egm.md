# EGM 审阅同原片缩小参考

独立审阅者在空白会话阅读实验协议、旧工作台、共同细节代码和验证入口，按 EGM 第 5 阶段检查范围与复用。变更只进入同原片候选。普通两图的跨场景自动调色仍用原研究门槛。[验证协议](../../experimental/adaptive-reference-20261113/same-capture-resize-protocol.md)

| 审阅发现 | 处理 |
| --- | --- |
| 比例边界、像素取整和残差叠加未定义，实施方式会改变支持范围。 | 固定缩放比例、取整误差、有符号 RGB 残差、双线性放大及最终取整，保留 800 万像素上限。复用现有 OpenCV 和 Pillow，无新增依赖。 |
| 共同细节门槛可让半幅被改动的图通过。之前的负例只覆盖一个缩放设置。 | 保留已有 0.98 梯度相关门槛，把现有重拍和跨图负例纳入四种缩放设置，新增半幅移位的结构负例。 |
| 对照角色及两种 JPEG 用例的预期容易混淆。 | 缩小图对 13 号，原尺寸和裁切对变更前 15 号。把原尺寸双端重存和新增半尺寸单端压缩分别记录。沿用两位作者原有的区分评分，并记录运行库版本和产物哈希。 |
| 原尺寸的脸颊量值不足以证明缩小参考有同样的问题。 | 在缩小输入的实际导出上核对基线和候选。首个基线回归确实复现旧工作台的漏调。 |

高重叠的结构改动还有其他可能，不能用本轮对照代替广泛的跨场景或结构验证。本轮开发样本均保留原拍摄分组。
