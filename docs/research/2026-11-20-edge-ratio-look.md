# 局部亮暗边缘未能可靠识别可迁移风格

前几轮发现，目标保护区里的背景偏色和有意风格可能沿同一色度方向变化。本轮寻找参考图本身的另一条线索。固定已有全图描述、线性读出、整来源留出和 80% 渲染，对照唯一改动为加入参考局部亮暗边缘的通道相对变化。分别用原图和 JPEG 85 检查识别和成片。两种编码的对照臂均使用同一最长边 256 分析图。[事前协议](../../experimental/adaptive-reference-20261113/edge-ratio-look-protocol.md) · [原同款识别验证](2026-11-19-capture-invariant-look.md)

| 参考编码 | 三态选对，全图统计 → 加边缘 | 关闭态保持原样 | 全部成片联合通过 |
| --- | ---: | ---: | ---: |
| 原图 | 25／72 → 29／72 | 22／24 → 13／24 | 0／24 → 0／24 |
| JPEG 85 | 24／72 → 30／72 | 22／24 → 20／24 | 0／24 → 0／24 |

原图加入边缘后，有 7 张实拍曝光关闭态由保持变为改色。换灯来源的原图和 JPEG 各新增 2 个关闭态误触，中性色最坏的同款换灯差由 0 增至 8.91 RGB8，超过既有 3.00 门槛。两个编码均无整来源通过。正确数上升与关闭态退化同时出现，不能作为画质升级。

停止使用这套固定边缘统计识别风格。该特征在普通图像中可计算，但本实验没有证据证明它能区分有意调色、真实受光和材质。不再根据这些失败样例改置信度。这里仅有两款已知风格及四个已使用来源，未进入开放风格、独立自然度和视频验收。产品版本未变。

## 复现

在已有视觉研究环境，设置 `PYTHONPATH` 指向仓库根目录及已核验 OpenColorIO 2.5.2 依赖目录，`OPENBLAS_NUM_THREADS=2`。执行 `python experimental/adaptive-reference-20261113/probe_edge_ratio_look.py <本机研究输出根目录> <新输出目录>`。合成等比例梯度可恢复比例 1，过弱梯度和通道方向不一致样本被拒绝。两遍各 288 张 PNG 及报告逐件一致，并从保存的决定重新汇总留出状态和画质通过数。报告 SHA256 为 `492447366e5ec095c6e0f28fb866a418f7436197da9bd4ae2ab834ae9135649e`。[本机成片](../../outputs/adaptive-reference-20261113/edge-ratio-look-v1) · [脚本](../../experimental/adaptive-reference-20261113/probe_edge_ratio_look.py)
