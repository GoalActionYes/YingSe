# 在另一张照片上用编辑器核对局部调色

映色已有按位置调色的渲染能力。跨场景时还需分别判断该调哪里，以及该把颜色调向哪里。本轮预先给出位置，只检查从混合光原片估计的固定色度变化，能否近似另一张照片对同一编辑操作的真实响应。[事前协议](../../experimental/adaptive-reference-20261113/playraw-mixed-light-cross-editor-protocol.md) · [固定色度的来源](2026-11-20-playraw-mixed-light-operator.md)

在《Cuckoo》自身的显影历史中接入混合光照片的 RGB 色彩平衡参数。参考手绘蒙版只适用于原照片，因此编辑器以全图覆盖渲染两态，离线只取脸颊和胸口的 80% 强度结果作为对照。重放方法应用同一参考向量，只读取目标关态和事前登记区域。浅色树皮与绿色背景是固定保护区。两张照片来自不同内容，编辑器负责生成对照，作者未为《Cuckoo》制作过此项编辑。

## 导出排查

替换参数后的关态和原封未动的旧关态，均在最初的 180 秒调用中超时。无 XMP 的原片在同一工具中可导出，但它和旧关态全图梯度相关只有 0.9620，低于 0.97。单模块侧车也能导出，但关闭时缺了默认曝光，和无 XMP 默认图最大相差 25 个码值，超出基线规定的 1，故在关态停止该分支。

PowerShell 直接导出的完整历史关态满足几何门槛，未偏移相关为 0.999980，±2 像素中最佳非零偏移为 0.522855。子进程追踪显示旧历史的一项扩散锐化在直接运行时约耗时 43 秒。检查到视觉研究辅助模块会在载入后设置 `OMP_NUM_THREADS=2`，限制传给了编辑器。本轮只在编辑器子进程移除此继承设置，保留 180 秒超时和既有 CLI 参数。共享导出函数增加可选环境参数，原来不传参数的调用仍继承调用进程环境。

原混合光开关和蒙版重新导出通过。高权重区 5,824 个像素，色度变化中位数 24.5，区外 P95 为 0，与旧报告一致。各 TIFF 页与旧输出最大相差 1 RGB8。

投影 1 表示重放在编辑器响应方向上的幅度相等。两处的投影满足 0.75–1.25，但固定向量超过误差门槛。浅色树皮与绿色背景的 P95 为 0，来源是事前固定的空间范围。这个数字不能用于证明自动保护背景。保留固定偏移作为同一张原片的诊断对照，停止将该向量直接用作跨照片修正。即使已知肤色位置，软件仍要根据目标判断应施加的颜色变化。

两轮四处区域的全部读数相同。开态重复导出的最大通道差为 1。关态在最左列第 299 行（从 0 开始）的一个像素上出现了两个超过 1 的通道差，分别为 11 和 2，超出全图复现门槛。该像素在登记区域之外，也在区域配准的计算范围之外。一次独立的命令行关态对照与第二轮在全图最多差 1。保留两轮原结果，判定全图复现性未通过。区域评分另用落盘图与整数亮度权重复算，核对全部数值、区外逐像素保持、ICC 和图像哈希。数值报告 SHA256 为 `030d3a3fabc5d50bff888d415f7095071bb0e364de9501263d5b96b494e06ca7`。

## 复现

在已有视觉环境中设置仓库根目录为 `PYTHONPATH`、`OPENBLAS_NUM_THREADS=2`，用本机临时 ASCII 盘符运行 `python experimental/adaptive-reference-20261113/probe_playraw_mixed_light_cross_editor.py <已有研究输出根目录的绝对路径> <新的结果目录绝对路径>`。脚本核对原片、侧车、编辑器、固定色差和区域身份，保存每次的开关 TIFF、对照 PNG 和数值。原片、成片、运行时和权重保留在本机。本轮为开发诊断，产品版本和独立验收状态未变。[脚本](../../experimental/adaptive-reference-20261113/probe_playraw_mixed_light_cross_editor.py)
