# 稀疏灰球测点尚不足以支撑两场景的密集照明校正

走廊和用餐区分别有 125 与 29 个实测照明点。将图像划为 4×4 网格，每次拿掉一整格的标签，再用四个最近的其余点预测。用同一批训练点的全局均值作对照。第四近邻距离超限时回退到全局均值。留格比逐个留点更少受同一小片区域内相邻采样影响。见[事前协议](../../experimental/adaptive-reference-20261113/drone-illumination-field-protocol.md)及[原片与测点来源](2026-11-18-drone-wall-illuminant.md)。

| 场景 | 有够近邻的点 | 支持点中位误差，全局 → 局部 | 支持点 90 分位，全局 → 局部 | 全部点中位误差，含回退 |
| --- | ---: | ---: | ---: | ---: |
| [走廊](../../outputs/adaptive-reference-20261113/drone-illumination-field/wall_hallway-support.jpg) | 104/125（83.2%） | 1.42° → 1.23° | 3.40° → 5.20° | 1.51° → 1.84° |
| [用餐区](../../outputs/adaptive-reference-20261113/drone-illumination-field/dining_area-support.jpg) | 8/29（27.6%） | 0.69° → 0.82° | 1.09° → 1.26° | 0.41° → 0.45° |

走廊在有支持的点上中位误差改善约 13.8%，绝对改善 0.20°，均低于门槛。90 分位还增加 1.80°。用餐区采样主要沿一道窄带，留出整格后有效支持不足。图中绿点为局部误差较低，红点为持平或更高，白点为缺少近邻。这些对照使用了实测标签作为离线输入，对于普通照片中的光色推断，不能将这些低于 2° 的中位读数当作软件成绩。

两组均未通过，因此本轮没有生成依赖密集测量的校正成片。结束用固定四邻点把这两张照片扩成像素级照明监督。稀疏标签继续作为现有照明估计的可核验对照。后续若用其他来源建立密集监督，需要场景表面分区、足够的实际采样，或同一场景不同灯光下的对齐原片。

两遍的逐点数组、预览和报告分别字节一致。用逐点排序和另一种角度公式独立复算 154 项结果，确认全部支持判断。源标签和预览留本机。见[摘要及校验值](2026-11-19-drone-illumination-field-evidence.json)。

复现时使用既有 NumPy 与 Pillow 环境运行 `probe_drone_illumination_field.py <取件目录> <上轮输出目录> <RawPy 目录> <上轮证据 JSON> <新输出目录>`。
