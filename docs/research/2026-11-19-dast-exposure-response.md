# 参考人像的拍摄曝光变化会传播到另一位人物的肤色

使用已经核实的 DAST 公开样例。固定五个同人同相机组，每组比较两张名义曝光与四档非名义曝光。先定位脸部皮肤并做同组配准，再把各档参考交给固定 13 号，目标始终是另一位参与者的名义曝光照片。强度为 80%，实际生成 30 张成片。推理只读目标和参考 RGB。皮肤区域、配准与档案曝光条件用于离线比较，未将色度仪记录当作照片像素真值。[事前协议](../../experimental/adaptive-reference-20261113/dast-exposure-response-protocol.md) · [公开样例身份](2026-11-19-dast-exposure-intake.md)

25 张参考对都通过配准和测量区域门槛。20 个非名义曝光对对于不同程度的欠曝和过曝均纳入统计。参考时排除暗区、饱和通道及过亮像素后，每对仍有 2,109–47,635 个共同脸部皮肤像素。评分比较解码后的 `log(R/G)`、`log(B/G)` 平均变化向量，与各自名义基准对照。

| 实际比较 | 参考脸部色度变化范数 | 13 号目标脸部色度变化范数 |
| --- | ---: | ---: |
| 名义曝光重复拍摄，5 个对照 | 0.011–0.053 | 0.0002–0.0154 |
| 非名义曝光，20 个对照 | 0.187–0.694 | 0.132–0.418 |

每个非名义曝光对都满足事前的同方向传播条件。输出在参考色度变化方向上的投影为 0.384–1.020，五个分组全部通过诊断门槛。亮度变化另行保留，不按偏色计。五组来自三位参与者，并非五个独立人物样本。[统计与复算摘要](2026-11-19-dast-exposure-response-evidence.json)

这表明，同一人像在不同曝光条件下拍摄就可能产生可迁移的肤色色度差。13 号从参考成片中把部分拍摄变化带到了另一个目标人物。样例含相机、闪光和成像处理差异，JPEG 没有 ICC，以上结果覆盖本组曝光条件下观测到的 RGB 差，不能归因于纯光强变化，也不能当作新的肤色准确度分数。下一步可对同一参考固定亮度或色度分析输入，区分两路贡献，再与现有明确风格开关一起验证，避免把保护肤色做成不迁移风格。当前未形成新候选。

使用已有皮肤保护便携 Python 通过 `runpy` 运行 `probe_dast_exposure_response.py prepare <样例 ZIP> <新准备目录>`，将脚本父目录加入模块搜索路径。再在已有 GPU 研究环境将仓库根目录加入 `PYTHONPATH`，运行 `probe_dast_exposure_response.py render <准备目录> <新输出目录>`。两遍 36 项准备产物、31 项出图产物分别逐字节一致。另从落盘图独立复核 30 项成片哈希、25 项色度和亮度测量及全部门槛。样例、掩膜、参与者记录和图片仅留本机。[复现脚本](../../experimental/adaptive-reference-20261113/probe_dast_exposure_response.py)
