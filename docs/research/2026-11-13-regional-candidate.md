# 区域残差候选：第一轮开发验证

## 本轮产出

独立候选位于 `experimental/adaptive-reference-20261113`，稳定主版未改。候选先使用主版全局映射，再按对应类别的 RGB 均值／标准差估计受限的局部偏移与对比度。偏移最大 24 码值、局部逐通道残差最大 32，增益限制 0.75–1.333。类别概率低于 0.8 不额外处理，至少两个可靠对应类别才允许局部处理。参数为本轮起点，不是验证出的最优值。

复用了既有 MediaPipe selfie 六类模型，校验 SHA256 后读取概率。标签为背景、头发、身体皮肤、面部皮肤、衣服、饰物，只是人物部位识别，不能表述为通用材质、场景、光照或审美理解。没有训练新模型。

模型概率说明类别识别的确信程度，不等于参考与目标材质／调色意图对应可靠。这是候选当前的重要不足。

## 测试与修复

先写测试，观察缺失模块失败后实现。自动探针暴露单个可靠类别仍会额外改色；新增测试确认失败，再增加至少两个对应类别的条件。最终五项测试通过，覆盖同图、零强度、局部调整误差改善、缺失／不确定区域、无效输入和单类别回退。它们不是自然画质测试。

受控左右重复颜色样例，使用已知左右蒙版的计算对照：

| 场景 | 主版 MAE | 已知区域候选 MAE |
| --- | ---: | ---: |
| 同图 | 0.00 | 0.00 |
| 全局提亮 | 0.00 | 0.00 |
| 区域明暗不同 | 24.00 | 5.22 |
| 区域对比度不同 | 14.63 | 4.72 |
| 区域饱和度不同 | 18.78 | 12.00 |
| 区域颜色平衡不同 | 13.99 | 4.32 |

此处人工提供区域，仅检验残差表达能力，不是自动算法成绩。饱和度误差仍较大，RGB 对角增益不能完整表达跨通道的饱和度变化。

## 性能范围

十张最长边不超过 640 的图片，目标与参考区域概率复用。分割中位数 0.093 秒、95 分位 0.109 秒；区域拟合＋应用中位数 0.107 秒、95 分位 0.179 秒。均未计入主版全局分析、解码、显示和编码，不代表整个预览小于 200ms，也不代表 1080p/30fps。

首次运行模型初始化约 8.94 秒，后续两次约 0.73 和 1.50 秒，有明显冷启动差异。需要常驻、预热与真实端到端测量，不能隐去冷启动宣称实时。

## 复现

运行环境：项目已有肤色实验版 runtime（Python 3.12.14，包含 MediaPipe/OpenCV），不新增依赖或模型。主版便携 runtime 可运行纯 NumPy/Pillow 的 regional 单元检查和全局限制探针。

1. 将实验目录加入 Python sys.path，运行 `test_regional.py`。
2. 运行 `probe_global_limit.py`，生成受控基线与已知区域对照。
3. 使用肤色运行时运行 `probe_automatic.py --historical-dataset <上述归档目录>`。
4. 运行 `summarize.py`，生成汇总与完整总览。

输出在 `outputs/adaptive-reference-20261113/global-limit`、`automatic`、`historical-development`。包含输入副本、全部对照、参数和来源哈希，未上传照片或运行时。
