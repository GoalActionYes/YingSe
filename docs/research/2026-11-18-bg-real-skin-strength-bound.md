# 逐图选择保护强度仍无法同时保住肤色和冷调

在原 13 号与旧肤色保护的 RGB8 成片之间插值。每张目标可用已知答案独立选强度，换背景负例与有意冷色正例共用该目标的强度。只比较原有五处实拍皮肤框。本轮暂不计苹果图误触发，以核查即使能避开这类误识别，强度是否足以解决问题。见[事前协议](../../experimental/adaptive-reference-20261113/bg-real-skin-strength-bound-protocol.md)与[旧保护实测](2026-11-18-bg-real-legacy-skin.md)。

| 目标 | 保留冷调时最多过线的皮肤框 | 最优选择的色度差，原 13 号 → 后混合 | 有意冷色方向投影保留 |
| --- | ---: | --- | ---: |
| 785 | 1/1 | 面部 2.60 → 2.19 | 90.75% |
| 9483 | 1/2 | 前额 1.55 → 1.24，手背 1.52 → 1.39 | 91.03% |
| 872，白球服 | 0/2 | 手臂 2.09 → 1.79，脸颊 2.28 → 2.24 | 92.31% |

每个区域须降低至少 15%，任何区域不得加重超过 0.25 码值，冷色方向投影须正向且至少保留基线的 90%。表中在满足后两项的状态中先最大化达标块数，再选区域总差值最低的状态。即使逐张独立选择，最多 2/5 块达到降幅，低于 4/5 门槛。加入识别准确度或无人约束只会增加要求。继续调整这两个输出端点之间的每图固定比例，无法满足这批已知案例的必要条件。

按每通道半码值的取整断点枚举完整 0–1 区间。相邻断点之间，所有被测像素的量化结果保持一致。每个区间取一个代表点，精确处理断点上的取偶数，共检查 367 个点。两遍数值报告一致，另用逐像素有理数计算复核全部 367 点的达标数量。无新推理，结论限于两个现有 RGB8 输出端点后混合，不涵盖融合前的浮点参数或能依据参考内容决定保护程度的模型。见[数值与身份](2026-11-18-bg-real-skin-strength-bound-evidence.json)。

复现可用现有视觉研究环境运行[脚本](../../experimental/adaptive-reference-20261113/audit_bg_real_skin_strength.py)并传入新 JSON 路径。输入取既有本机成片，脚本核对源文件哈希。
