# 参考肤色协调：首轮效果原型

2026年11月5日。阶段：已实现可复现的图片效果与短视频原型，供用户评判，不是已发布的新App或剪映原生算法。

## 本轮方向与固定方法

针对全图统计容易把肤色与背景折中的问题，保留原有全局调色，再对人物皮肤追加有限的参考色度偏移。与原肤色保护不同，这里靠近参考皮肤，不回拉目标原肤色。

只在原图分割与可见面部条件成立时使用皮肤蒙版。比较参考可信皮肤与已调色目标可信皮肤的RGB去亮度均值，取差值一半，最大单通道偏移限制8个8位码值；蒙版羽化混合。靠近色域边界时整体缩小色度向量，保持全局调色的亮度，最终8位取整允许至多半码值亮度误差。没有新增模型，不替换原生恢复公式。

首轮运行前固定0.5拉近量、8码值上限、六张既有图的暖肤色／冷背景控制参考和三对自然参考。没有根据结果选最优参数。控制参考用预测蒙版生成，属于有条件合成验证，不是独立自然风格真值或新留出数据。

## 实证

五项新测试先确认缺模块失败，再实现通过；结合现有28项合计33项通过。覆盖色度靠近参考、背景不变、单通道上限、接近色域边界的亮度保持、恒等与缺区域回退、非法蒙版。

六组控制参考相对实际原管线，可信皮肤逐像素色度MAE分别降低45.2%、35.5%、42.2%、48.5%、48.9%、47.1%。图片蒙版外零权重区域逐像素不变，额外亮度变化最大0.445码值，RGB变化最大7码值。这些数值只评价控制试验，不等同于自然画面美感或普遍更好。

作者查看了全部六组控制图和三对自然参考：肤色变化小，未观察到明显新亮度接缝；没有多人盲评，不能宣称所有自然参考都改善。参考人物的本色和照明仍会被混入风格，原图或参考的错误肤色不会自动纠正，多人采用共同偏移而非身份对应。

## 短视频

3秒640×360片段转30fps，首帧拟合固定色度偏移，每帧复用原有皮肤分割和光流蒙版平滑。90帧编码前均满足蒙版外背景不变、额外亮度变化小于0.501码值。最终H264/AAC视频3秒90帧，合成440Hz音轨存在，完整音视频解码通过；未做听音。

首次合并使用-shortest时，90张处理帧只输出89帧。保留失败解码日志，改为按90/30明确输出时长并对音频补齐后重跑通过；没有降低帧数验收门槛。视频仅一个短场景，不能据此宣称无闪烁、镜头切换、长片或跟踪可靠。探针复用私有时间平滑方法，尚未整理为正式产品接口。

## 交付与限制

本机演示位于讨论/15-参考肤色协调原型：完整图片对照、肤色局部放大、目标与结果视频、参考图和说明。代码在experimental/content-balance-20261105/skin_reference.py及两个check_skin_reference脚本。

这是空间蒙版效果，不能封装进普通全局CUBE。原稳定版、肤色保护版及默认App均未修改，也没有新界面或便携软件发布。图像数据和运行依赖不随Git上传，仅收录代码、小体积证据和日志。

本阶段停止继续叠加功能，向用户提交上述效果与限制，供其评判下一目标。后续若继续，应先扩大自然参考和人物肤色、照明、遮挡覆盖，再考虑图片与视频的可选产品接入。
