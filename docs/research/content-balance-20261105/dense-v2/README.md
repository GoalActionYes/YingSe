# 全像素加权统计研究版

日期：2026年11月5日。状态：研究实现完成，未接入App。

## 问题与改动

v1将像素重新抽样成拼图，再交给原有稀疏提取器；内容占比、抽样误差和稀疏点选择混在一起。补充随机种子1107时，强候选的输出漂移增大10.8%。

v2用全部分析像素直接计算加权亮度直方图、色度均值、协方差和饱和度。采用float64加权总体矩，固定1000万单位的归一化整数直方图质量；复用已审计的亮度区间规则、参数及LUT构建。仍然只生成一套共同映射，人物／背景贡献限制沿用v1，不增加分区渲染。

这改变了统计估计方法、精度和采样范围，不是剪映原生提取的逐值复刻。0档是本研究的全像素统计对照，不是旧App的原始稀疏提取。旧App未改，关闭回退仍保持旧行为。

## 验证

新增5项测试：输入及蒙版联合排列不变、重复像素不改变分布、缺少可靠分区时回退无权重统计、63/57项特征布局有限且输入不变、非法参数拒绝。连同v1的7项，12项针对性测试全部通过。先记录缺模块失败，再实现并运行。

| 试验 | 0.5档相对同估计器0档的漂移下降 |
| --- | ---: |
| 首轮10%、20%、50%、80%、90%占比 | 26.8% |
| 种子1106，20%、50%、80% | 15.7% |
| 种子1107，20%、50%、80% | 52.9% |
| 种子1108，20%、50%、80% | 12.5% |

首轮与补充组使用的占比集合不同，不能混合平均或与v1整体数字直接比较。种子变化改变了有限像素池本身，不是三个独立照片。算法已不依赖内部随机抽样，但不同输入分布仍可能触发不同阈值和参数。

这些指标只衡量不同参考占比下输出的敏感性，不能解释为审美提升百分比。首轮满足拟议20%门槛，但两组补充对照低于20%，自然留出、盲评和视频新方法均未执行。不能宣称完整继续条件通过。

实际不同内容参考图对照已查看，尚未发现足以宣称优于旧版的可靠证据。同图参考仍出现漂移，0、0.25、0.5档平均绝对差约6.17、6.05、6.09；没有解决恒等问题。
