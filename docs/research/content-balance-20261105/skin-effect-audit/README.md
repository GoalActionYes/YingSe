# 扩展验证结论：暂不接入参考肤色协调

2026年11月5日。用户要求扩大测试并验证实际意义。本轮冻结原色度拉近量0.5、RGB偏移上限8和分割阈值，不根据新结果调整效果参数。结论：有条件的数值改善存在，但收益小且不稳定，目前不足以作为默认功能或明确画质创新点。仅本地保留，不上传GitHub，不修改默认App。

## 试验范围与数据独立性

先固定skin_external_protocol.md，下载face_recognition六张图，运行30组全图控制；随后发现人物与场景覆盖不足，再固定Dlib六张图的扩展协议，补30组。第二批发生在第一批结果之后，不伪称全部预先一次性固定。所有原图来源、SHA256、失败记录与结果保留。

obama.jpg经目视和整图ORB几何对应确认，是以前portrait照片的不同裁切，772对特征匹配中713对支持同一几何变换。保留原始60组，但新内容汇总排除该文件的五组，得到11份新摄影内容、55组控制。重复人物、每图五种变换和合照意味着样本非独立，不能换算为真实用户成功率。

五种控制为同图、全图暖色、冷色、去饱和与对比度，不用人物蒙版生成参考。另做10对不同内容的自然参考，保留完整对照，由作者检查，未做多人盲评。未用算法直接优化的肤色均值距离作为自然画质评分。

## 数值结果及意义

全部60组皮肤RGB逐像素MAE：31组下降超过0.1码值，8组上升超过0.1，21组变化不超过0.1。剔除重复内容后的55组：28组改善、7组恶化、20组小变化，中位数改善约0.1202个8位码值。0.1仅为计数阈值，不是人眼可见门槛；RGB误差也不是完整美感指标。

还有5组总体改善的样例，其中某些皮肤连通区域RGB误差反而增加。连通区域可能是脸或手，不等于人物身份。不能只看所有人物的总体均值就认定每个人都受益。

三类反证：

- 冷色参考等样例出现RGB MAE恶化，同时色度MAE下降，说明单看被优化的色度指标会过度乐观。
- 同图参考2008_001322的皮肤RGB MAE从7.861增到8.177，理想同图应保持原图。这项局部改动没有普遍解决基础漂移。
- 基础管线在同图参考2008_007676中，皮肤RGB MAE约32.631、全图约16.302；局部修正后皮肤仍约32.298。基础亮度与对比度误差远大于新功能的典型改善，需要优先处理。

背景零蒙版区域仍逐像素不变，额外RGB加权亮度变化最大0.484码值。它只证明局部约束成立，不证明整体调色好看。作者查看全部12张控制对照和10对自然参考，改善多较细微，不能确认稳定、明显的自然观感收益。

## 视频反证、安全修复与限制

上一原型只在首帧检查可见面部，后续每帧仅做皮肤分割。用原拟合偏移检查无人画面时，旧猫图3229个像素、猫狗图17452个像素仍被额外改色；水果图未触发。单场景解码成功不足以证明视频安全。

新增apply_frame要求明确提供当前帧的布尔人物适用条件；无条件时逐像素回退。视频探针每帧检查，拒绝时清空时间蒙版历史。先写两项测试确认失败，再实现；合计35项测试通过。

修复后的连续单场景3秒90帧，以及人物→猫→人物的3秒90帧都整片音视频解码通过。切换测试30帧猫画面编码前不再受到额外局部修改，人物返回时历史重新开始。仅修改探针与研究辅助函数，未发布App。

补充运动对齐后的校正量变化诊断：160×90分析、有效运动且校正量活跃的像素，未平滑版本的帧均变化中位数约0.02074码值，平滑后约0.01932；最大帧95分位约2.5降至2.0。此量包含运动估计和蒙版误差，没有人眼闪烁阈值，不能宣称无闪烁或长片可靠。音轨为合成440Hz测试声，解码通过而未听音。

## 决定与后续优先级

原六组特定合成控制的35%至49%色度误差下降仍是历史事实，但不能概括本轮扩展结果。暂不将参考肤色协调接入默认App，不把它当作已验证的产品创新点，不继续针对本组调参。

优先调查基础管线的同图参考漂移、亮度与对比度偏差，以及不同画面占比对结果的干扰。皮肤参考均值同时混合人物本色和照明，在没有明确对应和意图时不能自动当作风格真值。旧肤色保护是另一种意图，不能与参考肤色学习混为一项指标比较。
