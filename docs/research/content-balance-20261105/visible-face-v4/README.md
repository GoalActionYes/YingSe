# 人物适用条件 v4

2026年11月5日。范围：修复研究候选在已知非人物图像上的误触发，不改稳定版、肤色保护版或下游调色公式。不宣称剪映使用本方法。

## 根因与选择

旧猫图在分割模型中约10%面积被当成人物，其中主要是衣服类；仅凭总人物面积不足以决定适配。检查原始类别后，旧猫图没有高置信面部区域，六张已观察人物图则存在。

选择保守的可见面部适用条件：face-skin类别、置信度至少0.85，8邻域最大连通区域至少max(16,ceil(分析像素数×0.0001))。否则蒙版归零，由已有composition.extract_pair逐值回退未加权全像素对照。通过时不修改原蒙版，不改变语义权重或颜色映射公式。使用原有离线模型，不新增模型或依赖。

这是同一分割模型上的工程条件，不是独立训练的人物检测器。高置信度不是校准后的真实正确概率。保守回退会牺牲部分覆盖率，背影、遮脸、暗光和极小面部可能不适配；回退仍继续普通调色。

## 固定协议与结果

先写person_gate_protocol.md，再运行六份新增固定素材；未根据新增结果调整阈值。

- 已观察回归：宇航员、正装人像、全身人物、portrait、pose、多人图及旧猫图，共七张。
- 新增验证：OpenCV的lena、messi5、basketball1，以及fruits、MediaPipe的cats_and_dogs和burger，人物与非人物各三张。sources.json保存URL、SHA256和大小；原样保留全部结果。
- 本组合计九张人物通过，四张非人物回退，没有观察到人物拒绝或非人物放行。小样本不能换算为真实场景准确率，也不包含全部肤色、遮挡或物种。
- 九张通过图像的蒙版与旧分割路径逐值相同。
- 四张拒绝图像分别作为目标和参考，八个方向检查的映射层及80%强度RGB输出均与未加权对照逐值一致。这里的对照不是稳定版稀疏提取路径。
- 单元测试25项通过，其中本轮新增七项，覆盖衣服不构成面部、连通性、置信度、尺度、输入不变性与非法输入。
- 首帧接入适用条件后生成固定共同LUT，3秒25fps视频完成75帧整片解码。无音轨，未验长视频、逐帧人物判断或跟踪。

## 后续条件

本轮已处理限定测试中的误触发，不等于人物识别已普遍可靠，更不等于调色画质提升。下一步应检验新的自然风格参考与人物观感，形成匿名对照供同学评议。背影、遮脸、肤色与光照覆盖仍需独立样本，不使用本组继续挑阈值。默认App尚未接入该候选。

## 已准备的自然参考匿名对照

另已生成七组实际调色画面，位于讨论/14-构图适配研究验收/自然参考匿名对照.html。三张新增人物图的六个有向配对，加一组水果参考回退。自然参考不是从目标按已知公式生成；同一照片多次使用，不能当作七组独立数据。

比较全像素未加权对照与适用条件下的构图适配，统一80%强度及预览缩放，以固定随机种子交换A/B位置。操作者对应表保存在natural-pair-key.json，页面不显示方法名称。原始结果保留，case04及case07两组输出逐像素相同，不能删掉或假定新方法总会产生不同效果。

页面允许选择A、B、看不出差别或两者都不理想；导出JSON时未填题明确为null，不自动填成持平或赞同。评议记录生成函数已用Node校验非法选项、重复题号、未填题与完成状态。没有实际人类评分，ratings_collected为0；不包含伪造评议或自动画质结论。导出按钮尚未做人工浏览器操作验收。

make_natural_review.py生成素材和页面源文件，review_scoring.js及test_review_scoring.cjs负责记录校验。匿名页面只展示固定样例，不能替代可导入自己素材的软件。
