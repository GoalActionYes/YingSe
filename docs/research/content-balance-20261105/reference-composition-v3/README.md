# 参考构图适配 v3：阶段验收

2026年11月5日。状态：研究候选通过新增三组受控占比数值门槛，未完成产品验收，不替换默认App。不是剪映同算法已完整恢复的证明。

## 本轮解决的问题

v2同时把目标与参考的人物贡献向50%拉近，会在构图本来接近时额外干预。v3保持目标特征完全不加权，仅适配参考贡献。输入仍是参考图和目标图片或视频分析帧，输出仍使用一套共同颜色映射，避免人物和背景套不同映射导致边缘突兀。

记可信人物在目标中占比为p，在参考中占比为r。候选贡献q取 r+0.5(p-r)，并裁剪到各组相对原占比0.5至2倍的范围。参考人物像素权重q/r，背景权重(1-q)/(1-r)，不确定像素保持1。目标不加权。关闭、占比相同或可靠区域不足时，返回全像素未加权对照。

这里的对照不是稳定版稀疏特征提取。全像素统计、语义权重都是自主研究环节，不能写成已证实的剪映技术手段；下游继续复用已有恢复的特征布局、参数求解和LUT渲染公式。

## 数值问题及修复

新增全身人物测试的80%人物参考，在0档触发 `zero native eigenvector norm`。参考第一组协方差约为10^-32，求解中间矩阵约为10^-34，float32平方下溢。根因是对恒定颜色直接加权求均值后，减均值留下舍入残差，虚构了非零方差。

先增加恒定色零协方差测试并确认失败，再改用相对一个观测颜色的差值计算矩；保持原有参考均值限幅分支。没有修改恢复的矩阵求解公式，也没有加噪声或把异常偷偷替换为另一算法。修复前的报告和数值诊断保留，修复后按同一协议重跑，没有调整权重参数。统计版本为 `dense-weighted-packet-v3-stable-moments`，不宣称原生逐字节一致。

## 执行结果

- 代码测试18项通过：原12项、新增5项构图适配约束、1项恒定色回归。
- 三张新增自然图像构造20%、50%、80%人物占比；每组内部重复完全相同的像素分布。占比漂移分别减少47.1%、66.0%、55.4%。门槛为各组至少20%，在运行前固定于 `holdout_v3_protocol.md`。
- 三组同内容控制参考的误差变化分别约-0.0036、+0.0011、+0.0001个8位码值，低于预定0.2增量限制。但整体绝对误差仍约16.58、12.88、23.62，不能解释为精确还原已知风格。
- 旧像素池重复对照仍只有5.4%、23.7%、31.3%的漂移改善。其中第一组不满足20%目标。旧协议会随配额改变区域内抽样，本轮严格重复调色板；两类结果不可合并，只报告新结果会造成误导。
- 已有三张照片同内容控制中，多人图误差仍从10.69升至10.80。不同内容的三对参考已生成，并由作者查看；没有足够证据判定普遍更好看。
- 新方法完成3秒640×360、25fps固定共同映射视频输出，整片75帧解码通过，无音轨。没有验证本分支音频、长视频、镜头切换、HDR或高位深端到端处理。
- 猫图被现有分割模型报告约10%“人物”，候选仍会触发。这是必须保留的失败边界：可靠区域面积条件不能等同于可靠的人物存在检测。

## 下一步与停止条件

本轮支持继续研究，但不支持立即发布默认增强。先用未参与这些测试的自然风格参考做匿名对照，验证画面统一和人物观感；再验证人物存在判断及非人物回退。不能靠同一批素材继续调参，不能把受控漂移减少称作画质提高，更不能把这项自主改进称作剪映已恢复原算法。

稳定版和肤色保护版继续可用。20份已有稳定交付文件哈希保持原样，详见本目录核验记录。研究候选的界面接入、独立分发、多人主观验收尚未完成。
