# 优先拟合目标常见颜色，白球服仍然迁移不足

上一轮用已知调色变换生成均匀色样，在不换模型的情况下补足了白球服的风格变化。本轮改用真实照片的参考原图和调色成片，只让与目标原图颜色相近的参考样本获得更高的拟合权重。两款风格、两种参考背景、三次色表、80% 的渲染强度和留出区域均沿用前轮。全一权重逐项复现了旧系数，16 张对照成片逐像素匹配归档。[事前协议](../../experimental/adaptive-reference-20261113/paired-target-weighting-protocol.md) · [前轮颜色覆盖诊断](2026-11-20-paired-operator-support.md)

| 留出区域 | 换款投影，旧 → 加权 | 响应误差，旧 → 加权（RGB8） |
| --- | ---: | ---: |
| 白球服，C1 背景 | 0.537 → 0.616 | 1.598 → 1.386 |
| 白球服，F1 背景 | 0.606 → 0.690 | 1.546 → 1.369 |
| 手臂险区，F1 背景 | 0.657 → 0.786 | 0.941 → 0.706 |
| 浅墙，C1 背景 | 0.866 → 0.820 | 0.503 → 0.631 |
| 投影幕中性区，F1 背景 | 0.951 → 1.479 | 1.111 → 1.427 |

投影以 1 为预期幅度。白球服两项均低于 0.75，投影幕超过 1.25，同时误差增加超过预设的 0.25 RGB8。其余符合条件的区域未触发退化限制。白球服的 83 个留出像素在两张参考中均有同一粗颜色箱的拟合样本，仍然没有恢复到合格幅度。投影幕 F1 的 57 个留出像素只有 10 个所在的箱在参考中出现。粗颜色分箱只能记录邻近样本是否存在，无法确认邻近得足够精细，也无法解释全部误差。小于 8 个像素或风格信号不足的区域保留缺测。[本机白球服对照](../../outputs/adaptive-reference-20261113/paired-target-weighting-v1/872-1268/comparison.png) · [本机投影幕对照](../../outputs/adaptive-reference-20261113/paired-target-weighting-v1/8021-8690/comparison.png)

这轮收尾固定参考配对的加权路线。以后若取得颜色覆盖更完整的同款编辑配对，可以检验覆盖增量是否转化成白衣和投影幕的实际改善。普通使用只有调色后的参考图，怎样推断其风格依旧是另一项待验证的问题。实验只用已经消费的四组开发素材，稳定 1.3 和 13 号仍用于体验和课程演示。

## 复现

在仓库根目录，使用本机视觉环境，设置 `PYTHONPATH` 为仓库根目录、`OPENBLAS_NUM_THREADS=4`，执行 `python experimental/adaptive-reference-20261113/probe_paired_target_weighting.py <新的输出目录>`。输入沿用归档并逐项校验哈希。两次运行的 16 张成片、四张图板及一份报告逐件一致。从保存的 PNG 另算白球服和投影幕的最重要三项，结果与报告一致。报告 SHA256 为 `9732eec9146a1a8fb2ae9da950df098cb69fa688c3e9e6423a25f489a6f4ce7a`。[复现脚本](../../experimental/adaptive-reference-20261113/probe_paired_target_weighting.py)
