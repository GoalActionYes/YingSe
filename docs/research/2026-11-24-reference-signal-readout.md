# 参考特征可保留部分配对顺序，单张分类仍不足

上一轮局部条件训练压低了灯光误传，但也压低有意局部提亮。这里检查不同表示中的信号。固定两个采集来源的 18 个已匹配方向、35 张参考成片及每场景的既有目标。冻结 13 号和上轮每折权重，分别读参考 RGB 图块、直方图、投影图块与两个空间网格。测试来源的场景从读出拟合的目标和参考两侧排除。测试候选网格的头也冻结自相同排除规则的训练折。[事前协议](../../experimental/adaptive-reference-20261113/reference-signal-readout-protocol.md) · [上轮原尺寸成片](2026-11-24-positional-lightness.md)

固定的线性岭读出同时评估两种问题。配对优先率看同一方向内有意编辑是否排在实拍换光前。单张平衡准确率看每张图能否凭训练后固定的分数正负判断，分别计算两类正确率再取平均。每折两项都须至少三分之二。重复参考不在分类项中反复加权，排序仍保留所有事前固定方向。

| 单参考表示 | MIT 成对胜出／平衡准确率 | WildRelight 成对胜出／平衡准确率 |
| --- | ---: | ---: |
| 4×4 RGB | 10／12 · 53.33% | 6／6 · 50.00% |
| 13 号直方图 | 5／12 · 46.67% | 4／6 · 50.00% |
| 13 号投影图块 | 8／12 · 61.67% | 6／6 · 58.33% |
| 13 号对普通目标生成的网格 | 8／12 · 41.67% | 4／6 · 50.00% |
| 局部实验头对普通目标生成的网格 | 7／12 · 50.00% | 3／6 · 50.00% |

4×4 RGB 的两个测试集都能排对大部分组内顺序，但阈值在户外将六张不同的真实换光和四张不同的有意编辑都判为真实换光。在留出的室内，局部候选网格将六张不同的真实换光与十张不同的手工提亮都判为手工提亮。冻结投影图块的准确率高于局部候选网格，仍未过门槛。即使在线下给同机位的原参考，按冻结规则看单位特征增量，最高平衡准确率也只有 54.17%。两种输入均无过线的表示。[逐方向分数、平局和误判](2026-11-24-reference-signal-readout-evidence.json)

这说明组内可排序线索不能直接充当产品的单参考开关。至少在当前数据上，上一轮实际候选保留的信息不足以用这个线性读出可靠区分两种变化。停止把该分数接成全局开关。已有无位置特征和训练失败记录继续保留。后续若采用新的参考条件，须说明它增加了什么可验证的输入信息，再重新以成片衡量肤色、浅色表面和原有风格。离线使用原参考未经两输入产品验证。此处只有两个采集来源，未检验其他非线性读出，也不能推导所有参考都无法判断。[两输入固有歧义的受控证据](2026-11-17-style-task-ambiguity.md)
