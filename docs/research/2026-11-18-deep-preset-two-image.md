# Deep Preset 两图筛查：局部偏色减轻，风格响应不足

Deep Preset 在训练中用 Lightroom 预设参数监督，同时能从目标与已调色参考两张图生成结果。固定作者发布的带正样本配对损失权重，采用其图像前向，不用只在预测预设时使用的线性头。在已有 13 号、80% 强度与同一对照下试验。见[作者论文](https://openaccess.thecvf.com/content/WACV2021/papers/Ho_Deep_Preset_Blending_and_Retouching_Photos_With_Color_Style_Transfer_WACV_2021_paper.pdf)、[固定源码](https://github.com/minhmanho/deep_preset/tree/04eb47352e2f4cd643d466c7c6835f17d9513c92)及[事前协议](../../experimental/adaptive-reference-20261113/deep-preset-two-image-protocol.md)。

公开权重原文件大小 1,071,225,835 字节，其中约 47.5 MB 是图像前向所需。按固定前缀解析旧格式，读取六段合计 47,482,012 字节；验证 194 个张量的长度、有限值和图像分支键。未获取线性预设头，无须把整个 1 GB 权重下载到本机。作者代码与权重仅用作课程研究。五个作者源码的 Git blob、所取区间和本机权重摘要见[证据](2026-11-18-deep-preset-two-image-evidence.json)。

| 六组背景换色对照 | 实际结果 | 既有门槛 |
| --- | ---: | ---: |
| 人物减干扰且保留整体色偏响应 | 2/8 | 至少 6/8 |
| 近中性色平均干扰 | 降低 4.53% | 至少降低 15% |
| 近中性色最差单项干扰变化 | 增加 4.63 码值 | 至多增加 1 码值 |
| 对比度与去饱和响应 | 1/12 | 12/12 |

最差单项为 8021–8690 的品红背景，近中性色输出变化从 4.12 增到 8.75 码值。六组未干预参考的实际输出均通过旧 256 输入结构筛查，全图相关为 0.990–0.997。它只能筛出该尺寸的显著几何变化，尚不能保证细节在任意分辨率不变。

| PSBench 105 目标 | 整图误差，原图／13 号／Deep Preset | 近中性色误差，原图／13 号／Deep Preset |
| --- | ---: | ---: |
| 台阶人像 | 9.39／15.46／11.51 | 7.60／16.77／10.21 |
| 铁塔 | 11.39／15.03／11.27 | 11.93／15.91／12.47 |

台阶青偏减轻，但裙子仍偏紫。铁塔整体接近原图，作者成片中的暖色建筑与青绿天空没有充分迁移，整图响应投影仅 0.114。两例均未过事前门槛。原尺寸 704×1080 输出按 16 倍数下沿补 8 像素，推理后裁回原尺寸。两个运行的 44 张输出与结果 JSON 哈希一致，落盘结果复算 402 项，包括整图响应、人物和近中性色误差。使用原图的比较基准仍保留。

结束这个固定外部模型配置。未用它替换软件，也未使用独立保留素材。此次发现是实际两图输入下，预设监督模型能减轻一部分跨场景偏色，其输出可能更接近原图且无法稳定保住风格幅度。未来候选需要同时改善两项，完整自然度、肤色、视频和候选回退标准保持。

复现时在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path`。按协议先取得发布文件的前 1,048,576 字节，运行 `experimental/adaptive-reference-20261113/prepare_deep_preset_image_weights.py <元数据文件> <新资产目录> [--proxy <本机代理>]`，再运行 `experimental/adaptive-reference-20261113/probe_deep_preset_two_image.py <资产目录> <新输出目录>`。本机输出为 `outputs/adaptive-reference-20261113/deep-preset-two-image-v1`，含 `psbench-comparison.jpg`。图片、权重和发布源码副本不进入本项目 Git。
