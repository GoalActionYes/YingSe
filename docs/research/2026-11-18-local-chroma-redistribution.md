# 白球服与部分背景可借重新分配现有冷色同时改善

用冻结的 13 号局部开关输出做离线对照。把落在人物及邻近过渡区的部分冷色分量按原羽化权重移到背景，不增加量化前的全图冷色总量。白球服和另一组通过既定局部及整图控制，另两组的背景冷色仍明显不足。见[运行前协议](../../experimental/adaptive-reference-20261113/local-chroma-redistribution-protocol.md)和[原局部开关对照](2026-11-18-local-edit-toggle.md)。

| 配对 | 背景方向投影，13 号 → 重分配 | 人物近中性色误差，13 号 → 重分配 | 13 号全图冷色分量相对预定局部冷色 |
| --- | ---: | ---: | ---: |
| 785–3553 | 0.415 → 0.474 | 2.300 → 1.019 | 47.1% |
| 9483–19432 | 0.380 → 0.440 | 2.252 → 0.945 | 44.5% |
| 872–1268，白球服 | 0.709 → 1.006 | 5.465 → 0.758 | 103.1% |
| 8021–8690 | 0.464 → 0.761 | 2.930 → 0.737 | 76.8% |

误差单位为 RGB8 码值。白球服案例的背景增量误差由 2.445 降至 1.866。前两组的冷色分量仅约为预定结果的一半，重分配后仍达不到背景 0.75 投影门槛。四组人物与人物近中性色保持门槛均通过。本轮整图冷色臂复用原 13 号输出，仍有 4/6 通过。两组无人图相同输入继续产生逐像素相同的结果。

此对照使用人工蒙版、已知局部开关身份及关闭版输出取得实际冷色增量，目标调色答案只用于评分。算法在浮点上保持原亮度和全图冷色分量，量化和裁切可能改变总量。四组量化后亮度变化 MAE 为 0.112–0.170 码值，裁切比例最高 0.17%。图中白球服冷偏明显减弱，背景保留冷色。程序化目标和真实自然评价分别验收。

两遍各约 1.34 秒，覆盖本机小图读取、重分配、写盘和离线评分。六份 PNG 逐张字节一致，另按独立邻域权重与求和公式逐像素复现，复核 40 项区域误差及方向。全图冷色分量比为离线描述，未用于拟合或改变门槛。见[逐组数值](2026-11-18-local-chroma-redistribution-evidence.json)。

在当前对照中，空间分配与冷色响应幅度需要分别验证。下一步如果从参考成片取得可辨别的局部信号，先检验它能否区分同一冷色施加于背景或全图，再用自动区域验证能否重现收益。没有推出新的自动两图候选。

复现时在现有研究环境中运行 `python experimental/adaptive-reference-20261113/probe_local_chroma_redistribution.py <新输出目录>`。输入为原局部开关实验的冻结文件，本机对照和全部结果位于 `outputs/adaptive-reference-20261113/local-chroma-redistribution-v1`。
