# 颜色插值扩大了覆盖，交界处出现色块

在同一组台阶人像和铁塔上，用对侧调色前后图的编辑差建固定 RGB 网格。只在两个场景都有足够邻近颜色的位置插值，其他像素保留原图。仍使用 32×32 留块、80% 强度和同一份 13 号基线。见 [运行前协议](../../experimental/adaptive-reference-20261113/psbench-action-rgb-interpolation-protocol.md)及[精确颜色对照](2026-11-18-psbench-action-rgb-transfer.md)。

| 目标 | 近中性色插值支持率 | 整图误差，原图／13 号／插值 | 近中性色误差，原图／13 号／插值 |
| --- | ---: | ---: | ---: |
| 台阶人像 | 89.01% | 9.39／15.46／7.00 | 7.60／16.77／4.27 |
| 铁塔 | 95.61% | 11.39／15.03／5.98 | 11.93／15.91／6.10 |

误差为相对作者结果的 RGB8 码值，整图和完整近中性色均计入无支持位置。只看上轮没覆盖、本轮新增覆盖的近中性色，人像误差从保留原图的 7.94 降到 4.17，铁塔从 13.05 降到 6.37，响应投影均为正。两个方向达到本轮预设的覆盖和误差门槛。按整张图计算，仍有 50.83% 和 28.23% 像素缺少插值支持，保持原色。

查看四列图时，人像的白台阶相对 13 号少了大片青色，裙子的紫色仍明显。铁塔天空出现不规则青蓝色块。为定位该问题，追加检查原图的水平和垂直相邻像素，限任一通道差至多 3 码值。测量每对相邻像素的调色位移差，取三通道最大绝对差后算第 95 百分位。人像和铁塔在支持状态相异的边上分别达到 20、25 码值，作者结果为 5、4。双方都有支持时，两张图的插值结果均为 1 码值。该检查在看到色块后追加，仅用于定位突变。见 [完整数值与哈希](2026-11-18-psbench-action-rgb-interpolation-evidence.json)。

这组实图表明，部分中性色偏移可以用全局颜色变换减少，同时说明缺色时直接切回原图会形成可见色块。插值额外读取了参考原图，且明显退化仍存在。保留此输出为开发诊断，暂不接入软件。若要把此证据用于自动两图候选，仍需验证能否从正常输入估计可靠的颜色变化，并同时处理低置信颜色和连续性。此前底图估计失败的固定方案不重跑。见 [底图估计对照](2026-11-18-inretouch-inferred-original.md)。

两次运行的八张 PNG 和原始结果 JSON 哈希一致。落盘后独立复算 96 项指标，检查范围边界、无支持位置与原图逐像素一致。四列对照留本机 `outputs/adaptive-reference-20261113/psbench-shared-local-v1/action-interpolation-v1/comparison.jpg`。输入和图片未上传。
