# 已有作者配对未提供足够的近中性色空间监督

检查固定换参考开发集的 24 张目标，各有两份作者结果。在同一个原尺寸 RGB8 目标中，比较具有相同输入 RGB 的像素是否需要不同的颜色变化。用同一个 RGB 表、按真实象限分开的 RGB 表及打散象限的查表作为离线对照。打散保持每个 RGB 在各象限的样本数一致。评分读取作者结果，仅用于判断数据能提供的监督。见 [运行前协议](../../experimental/adaptive-reference-20261113/tst-reference-spatial-signal-protocol.md)和 [固定开发组](2026-11-18-tst-reference-equivalence-split.md)。

- **近中性色原尺寸。** 两种作者效果的 RGB 差，20/24 组用任意精确 RGB 查表可零误差表达，其他四组的平均绝对误差下界最高仅 0.004364 码值。近中性色像素中有重复 RGB 的比例为 36.65%–99.41%。0/24 达到预设空间信号门槛。
- **整图复核。** 19/24 组的两份作者结果各自与统一 RGB 查表相容。在其他组观察到同一 RGB 有不同输出，最大单通道跨度 131，不能归纳为每张图的所有变化都能由全图映射表达。跨度是极值，不等于整图平均误差或可验证的局部编辑意图。
- **缩图对照。** 256×256 双线性缩图的近中性色下界均值升到 0.203，最大 0.894 码值。这与缩放将不同原像素混合为相同 RGB 后产生差异相容。两份作者结果均通过既有结构检查的目标有 20 组。该粗对齐检查不能排除细微几何差异。

复核从 72 份本机副本重新核对内容哈希，用另一路分组和中位数实现复算原尺寸近中性色下界，并逐像素核对整图相同 RGB 的最大输出跨度。初步显示将 0.004364 四舍五入为 0.00，独立核验区分了实际为零的 20 组和小幅非零的四组。这里的任意精确 RGB 表对每个出现的颜色逐项查询，表达上限高于有限网格的普通 CUBE，结果不代表固定网格或两图算法已经能复现。见 [逐组数值](2026-11-18-tst-reference-spatial-signal-evidence.json)。

保留这批素材作为换参考行为开发对照。若要针对肤色、墙面等区域学习，应另用能核对局部编辑意图的实图监督。现有软件保持，未训练或读取独立评估。复现时从仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path`，运行 `python experimental/adaptive-reference-20261113/probe_tst_reference_spatial_signal.py <新结果 JSON 路径>`。
