# 同画面参考匹配：有条件的颜色变换学习

2026年11月5日。阶段改进已接入基础版与肤色实验版，默认自动判断，不增加操作控件。适用对象为构图对齐、近似全局线性颜色变换的参考；不是任意两张不同内容图片的风格理解。

## 技术选择

原统计路径会因细小像素变化出现明显漂移。全面自基线差分又导致对比度回归，因此此轮采用有条件的另一条路径：先检查宽高比与空间梯度相关性，只对有足够色彩和结构证据的画面拟合RGB仿射变换。

拟合使用8×8棋盘空间分块，一半像素训练，一半留出。参考通道已饱和的训练像素排除。要求源颜色矩阵条件数不超过200，空间梯度相关至少0.95，留出MAE不超过1.5码值、95分位不超过4码值，所有小块最大平均误差不超过6码值，并限制增益与偏移范围。条件不满足即保留原路径，不降低阈值凑通过。

RGB仿射回归是标准方法，不宣称算法原创、独有或剪映使用同一方法。本项目新增的是带适用条件、留出验证和明确回退的自主实现。映射转换为两层64阶LUT，第一层为80%变换、第二层100%，兼容现有预览、强度与视频/CUBE导出。精确同图恒等策略优先保留。

诊断保留原特征与参数，并明确parameters_describe_raw_recovered_path、output_policy及aligned_reference系数；不能把这些原参数解释为新拟合LUT的生成参数。算法指纹增加新模块，缓存随代码变化失效。

## 试验与结果

12张此前已用于测试的图片，每张8种输入，共96组：恒等、加1码值、暖色、冷色、去饱和、对比度、JPEG质量92和半尺寸参考。不伪称这12张是独立新留出。基线为上一发布56f9938的“精确同图恒等、其他保留恢复路径”；评估脚本显式重建该基线，避免接入后再用新管线自我比较。

已知全图变换在100%强度下，整图RGB MAE中位数：

- 近似同图：11.40降到约0.001；暖色：11.52降到0.032；冷色：8.89降到0.038。
- 去饱和：5.33降到0.024；对比度：6.28降到0.201。上述每类12组全部接受，无MAE恶化超过0.1码值的样例。
- 恒等保持0误差；JPEG质量92接受10/12，中位数11.78降到1.73；半尺寸接受4/12，中位数11.07降到9.74。后两类覆盖不完整，不能宣传为全面支持压缩或缩放。
- 132对不同内容原图、132对强制相同尺寸的不同内容图，共264负例均拒绝新路径；另12个局部内容改变样例也拒绝。小数据不能证明通用同场景识别或零误接受概率。
- 阈值固定后新增Dlib 2009_004587照片，近似、暖色、冷色、对比度四组均接受，RGB误差约8.65→0.0006、9.53→0.023、4.40→0.023、3.76→0.072。只有一张新增场景，不扩大为广泛泛化结论。
- 作者查看完整对照，接受的新结果更接近这些已知参考；这是成对真值下的重建效果，不等于任意自然参考的审美提升。

基础版77项、肤色版97项代码测试通过。含同图恒等、近似图不再大幅跳变、未对齐参考逐值保留旧LUT、非同布局与平移拒绝、局部改变拒绝、平坦图拒绝等。

## 视频与发布包

使用视频首帧的已知暖色参考生成固定LUT，全片不逐帧重估。0、1、2秒编码前相对已知暖色变换的RGB MAE约0.060。3秒75帧视频及合成音轨整片解码通过。没有验证长片、镜头切换或复杂非线性风格，不能宣称普遍无闪烁。

## 适用边界

不同人物、不同机位、裁切、复杂曲线、局部调色或无法确认对应的参考，通常拒绝新路径并保留原统计算法。拒绝时仍可能有原来的亮度和对比度偏差。这次没有修复不同内容之间的一般风格迁移，不宣称完整复刻剪映。
