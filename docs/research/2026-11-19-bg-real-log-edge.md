# 相邻像素亮度比保留了编辑信号，也受参考背景影响

以近似同色的相邻像素为样本，统计线性亮度对数差的第 75 百分位。合成的等比例线性曝光控制通过。同一方法用于 12 组确定阈值、四组换背景开发素材，以及 30 张实拍曝光负例。每张只用参考成片，分别测无损与 JPEG 95。[运行前协议](../../experimental/adaptive-reference-20261113/bg-real-log-edge-protocol.md)

| 检查项 | 无损 | JPEG 95 |
| --- | ---: | ---: |
| 达到识别阈值的有意对比度参考 | 0/8 | 0/8 |
| 其他编辑误报 | 0/24 | 0/24 |
| 实拍曝光误报 | 0/30 | 0/30 |
| 同时在两个参考背景中，编辑变化都大于换背景变化的案例 | 0/4 | 0/4 |

八张有意增强对比度的参考均得到正向分数变化，JPEG 后仍如此。但白球服对应的参考在 JPEG 条件下，有意对比度使分数增加约 0.026／0.003，只换参考背景的最大差约 0.143。五组实际曝光中，四组的最大分数跨度超过开发对比度产生的最大变化 0.043。真实相机与输出管线的结果由内容、可用区域与拍摄条件共同影响。无误报同时伴随零检出。[全部分数和覆盖](2026-11-19-bg-real-log-edge-evidence.json)

这次证实具体的亮度比变化可以跨 JPEG 保留，但这个量在当前参考里无法从背景和拍摄变化中单独识别编辑。结束固定近似同色像素的亮度比作为单图判据。预设未过，未进入新候选渲染或调整评分阈值。后续若再从参考估计明暗调整，需要足以区分拍摄与编辑的额外可验证线索，例如可核对的编辑前后配对提供监督；产品推理仍保持正常两张输入。[两图组合上界及剩余问题](2026-11-19-bg-real-component-coverage.md)
