# 按目标颜色边缘平滑调色增量，未消除局部偏色

13 号曾在浅墙与肤色上带入参考背景的颜色。若明显偏色主要来自同一表面内不同程度的局部调整，那么让增量沿原图相似像素扩散，应能在保留整图调色的同时改善局部。此次保持原 13 号明暗和量化前的整图色度均值，仅在原图相似像素之间交换已有色度增量。原图和单参考对应的 13 号成片是唯一算法输入，人工范围只评分。[事前协议](../../experimental/adaptive-reference-20261113/target-chroma-diffusion-protocol.md)

| 开发项 | 实际 |
| --- | --- |
| 背景干预 | 0／4 组通过 |
| FACD | 0／7 组通过 |
| Film B | 0／6 组通过 |
| 色卡 | 2／7 区响应通过，整套未通过 |
| 六项肤色 | 0／6 达到改善门槛，其他区域无超过 0.25 RGB8 的退化 |

浅墙在一项对照中由 0.875 降至 0.835 RGB8。后方人物脸颊在另一项由 3.185 降至 3.078 RGB8，仍低于所需改善。72 张候选相对 13 号的整图色度平均绝对改变量最大为 0.601 RGB8。输出亮度最大差为 0.4974，限域和量化后的全图平均色度分量最大变动为 0.095。操作主要是小幅重新分配局部色度，没能从一块已产生共同偏色的表面上移除这种偏色。按协议结束固定邻域平滑，不扩距离或迭代数追分。[结果、局部测量和成片哈希](2026-11-20-target-chroma-diffusion-evidence.json)

合成检查覆盖两种恒等路径、恒定调色增量、跨强色边界衰减和色度守恒。两次完整开发运行报告一致。复现时在原研究环境设置仓库根目录 `PYTHONPATH`，运行 `probe_target_chroma_diffusion.py <新结果目录>`。原 13 号运行入口和软件未改。此次保留的是已用开发场景的失败对照，封存白墙素材没有进入测试，独立画质和视频仍待验收。
