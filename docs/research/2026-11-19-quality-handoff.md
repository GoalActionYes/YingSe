# 映色画质阶段交接

**当前可体验的是稳定 1.3 和 13 号空间调色研究版。跨场景自动偏色修正没有通过升级条件。** 从剪映参考调色功能出发，项目实现了自己的全局调色，然后让不同画面位置可以使用不同调色。现在卡在判断参考里的颜色究竟来自物体、拍摄光照，还是应当迁移的创意风格。课程汇报可以用白球服和实体色卡分别展示这两个阶段。[体验与课程交付](../../00-从这里开始/0-体验与课程交付.md) · [原阶段交接与历史路线](2026-11-18-route-handoff.md)

## 2026-11-20 阶段结论与接续

现有稳定 1.3 和 13 号空间调色研究版仍是课程演示入口。新的 ICC 工程候选已构建并从两份独立解压副本验证。Display P3 和带配置 CMYK 作目标或参考，PNG 与各自正确转换的 sRGB 基准逐像素一致。包内微调、普通 CUBE 和 MP4 已实测，旧版本可回退。工程候选改善的是文件解码偏色，跨场景怎样迁移风格仍未过画质门槛。[便携包、依赖和回退](https://github.com/GoalActionYes/YingSe/blob/1570aaf9fca9c71285577d95d6e247e65743942f/docs/research/2026-11-20-image-icc-portable.md)

| 研究问题 | 已得到的证据 | 阶段决定 |
| --- | --- | --- |
| 目标已有色相能否识别参考串色 | 普通两图中，人物改善 0／8，近中性色平均改善 4.43%，三项有意去饱和退化超线 | 停止固定目标色相权重。[成片](2026-11-20-target-hue-support.md) |
| 整图不减色时，只平滑局部变化能否解决肤色和浅墙 | 72 张候选保持原明暗，既有肤色改善 0／6，开发浅墙一项从 0.875 降至 0.835 RGB8 | 停止固定邻域平滑，后续直接查同一表面的整体偏色。[成片](2026-11-20-target-chroma-diffusion.md) |
| 是否能够把目标统计和局部画面的修正量分别求出再相加 | Film B 的焊工 8／8 个组合存在可测交互。24 个组合有 3 个至少一项方向预测失误，联合通过为零 | 停止借用其他照片的模型输入，后续若改训练，需联合验证空间位置和目标颜色收到的响应。[成片](2026-11-20-film-b-condition-interaction.md) |

**画质研发的继续条件。** 上述成片支持优先找能控制拍摄偏色与编辑偏色的实拍配对。训练或诊断可见应用编辑前后的参考，实际推理必须只见目标和单张参考。较便宜的前置检查是在至少两个拍摄家族分别有同场景换灯、同场景加同向编辑，以及有肤色和明确浅色材料时，观察既有模型对两种变化能否给出不同的实际成片。已有受控人像和白球服继续作为负例和风格回归。若新资料无法给出这两种不同成因的配对，不按文件名猜同款，也不在原反例上提高强度或追加相同规则。已有资料可用于开发验证，未见过的内容按拍摄家族单独留出。

**验收仍待完成。** 本轮重核四套开发对照 132 个可解码 RGB 文件，身份和哈希完整。这批均已用于开发。两个白墙场景已登记并封存，只在新候选通过开发后启用。独立画质、真实人类自然度和新候选的真实运动、遮挡、切镜及完整导出尚未完成。13 号的两段约三秒 640×360 开发视频有 3.08–3.42 秒的完整导出基线，不能代表新候选或更高分辨率的表现。普通全局 CUBE 可复用颜色查表，无法保留空间调色随位置变化的效果。仍无达到完整门槛的画质候选或可审阅的画质升级 PR。[四套开发预检](../../experimental/adaptive-reference-20261113/verify_development_inputs.py) · [白墙封存](2026-11-20-white-wall-reserve.md) · [视频基线](2026-11-20-spatial-video-stage-timing.md)

## 实图证据与停止范围

| 具体问题 | 已确认的结果 | 对后续的约束 |
| --- | --- | --- |
| 能否统一保护浅色区域 | 扑克两块白桌布在三档曝光下减去共同色偏均改善，但最高档浅色衬衫退步，且已经正确的 Film A 成片也受损。[共同色偏对照](2026-11-19-common-chroma-offset.md) | 结束固定减色，验证须包含有意染色。 |
| 用稳定版估计颜色能否补足空间调色 | 保留 13 号明暗、换用稳定版色度，实体色卡两脸颊基础偏色下降，风格响应由 2／7 降到 1／7，白球服换背景偏色加重。[色度拼接](2026-11-19-stable-chroma-hybrid.md) | 结束固定全局／空间拼接。 |
| 能否单靠强度拉回风格 | Film B 参考加深后，扑克和色卡同向但偏弱；焊工在四个非零档位均反向，换另一张参考也仍反向。[五档成片](2026-11-19-arri-film-b-dose.md) · [六个交叉方向](2026-11-19-arri-film-b-crossed.md) | 量化方向和幅度，保留原样例作为负例。 |
| 目标颜色统计是否参与反向 | 固定目标图只换全局直方图，焊工四个外来统计组合中三个转正；反过来可使扑克从正向转为反向。18 个组合均未过原门槛。[统计干预](2026-11-19-film-b-target-histogram-swap.md) | 这条全局统计路径会影响方向。结束固定替换；离线借来的另一张原片不会作为产品输入。 |
| 参考端能否告诉 13 号局部编辑在哪里 | 两组控制中只交换参考里已知编辑的位置，保持 RGB 像素总计数。参考直方图、网格和最终成片逐值相同。[空间位置对照](2026-11-19-reference-layout-collision.md) | 当前参考接口缺少位置线索。后续如有能从普通参考估计区域归属的方法，先同时验证实际换背景和有意调色。 |
| 已有参考外观模型能否补足位置缺口 | 扩展第 4 轮在相同参考对上产生了不同成片，整图位置响应投影约为 0.002／−0.00005，两组都未过门槛。[外观开关对照](2026-11-19-appearance-layout-response.md) | 该检查点已对参考布局敏感，但不能用此信号把编辑放到目标相应位置。保留检查点和反例，后续需要能分辨编辑归属的局部信息。 |
| 真实作者的局部去色会不会连保色区一起改变 | 人像去色不足，鸟照去色响应达到方向和误差要求。两例的保色区变化都超限。[真实成片对照](2026-11-19-psbench-background-desaturation.md) | 用作区域归属的开发反例。两份任务共有去色操作，实际保色范围和额外编辑有差异。 |
| 能否直接把自动识别的物体当保色范围 | 两个方向均触发回退。鸟照约 71% 的保色测量像素被判为背景；人像约 39% 的去色测量像素被判为物体。[分割范围复核](2026-11-19-automatic-selective-chroma.md) | 结束这种固定物体分区。后续验证需显式区分物体轮廓与作者的编辑范围。 |
| 能否从参考剩余颜色直接判断目标保色位置 | 两份参考都能触发，但人像的去色区域反而有更高保色权重，去色差由 6.72 增至 10.45。鸟照对应误差下降，联合仍未通过。[色相对应实图](2026-11-19-selective-hue-support.md) | 停止固定色相对应。后续须同时核查实际编辑范围、场景变化和反例。 |
| 已知参考实际编辑位置后，局部特征能否找到目标对应区域 | 鸟照参考没有足够的保色网格，人像整张回退。反向使鸟照整张去色，保色区变化 6.39，超过 1.5。[实拍跨图对应](2026-11-19-paired-semantic-desaturation.md) | 结束固定描述子网格匹配。进一步验证需要多构图同款编辑，并检查小范围编辑的表示。 |
| 参考相机成像是否会改变同一风格 | 使用同一实体色卡与固定数字风格时，13 号的白桌布响应会由正向变为反向，两脸颊也发生可测变化。[相机交叉对照](2026-11-19-middlebury-camera-film-cross.md) | 参考色的相机成像与后期编辑共同影响结果。接续可分别验证明暗和色度来源，沿用风格、真实主体和近中性色门槛。 |
| 只固定参考明暗能否稳定画质 | 近中性色的换相机 RGB 差八项均至少减半，但出现色度差扩大、风格响应反向。两种固定明暗均未达标。[分通道复算](2026-11-19-middlebury-camera-channel-replay.md) | 结束直接套用另一台相机明暗。后续需分别检查相机色度、风格方向和激活条件。 |
| 校准已有参考成片能否保住风格 | 校准让留出色格更接近；先调色后校准令 8.24% 参考像素限域，两种顺序的整图／近中性色联合均未通过。[顺序对照](2026-11-19-middlebury-camera-calibration-order.md) | 结束把该固定校准直接应用到已调色参考。新路线须区分成像与已施加的创意风格。 |
| 只读一张参考能否从实拍变化监督中认出已知风格 | 差分约束减少曝光组误触，但留出来源仍常整组回退或固定选一款。四来源均未达标。[留出来源与成片](2026-11-19-capture-invariant-look.md) | 结束固定全图特征与线性读出，保留关闭态误触、漏判和错误稳定的反例。 |
| 能否取得同时改变实际灯色和灯强的独立拍摄内容 | 两个新场景各有两灯色、两强度实拍。16 张成片中出现白灯同向、蓝灯两档均反向。[实拍灯色与强度](2026-11-19-chromamill-capture-cross.md) | 作为场景归组的开发素材，能逐项核查灯色、灯强、风格和交互。只覆盖自动拍摄干扰的一部分。 |
| 两图校正能否学会减少蓝灯干扰并保住有意风格 | 四场景训练后，两个未参与拟合的场景换灯差均减半；六张常规参考全部被大幅误改，完整风格仍不达标。[成对监督候选](2026-11-19-pair-supervised-reference-correction.md) | 保留反向修复与严重退化。未验证普通参考的可用性，不能接入软件。 |
| 实测光色模型能否直接校正普通参考 | 作者模型对两个已消费场景的 16 张参考均分对白／蓝灯；直接使用输出或只取色度均未过联合风格、稳定和负例门槛。[光色识别与输出对照](2026-11-19-cti-reference-screen.md) | 结束直接接入作者校正结果。光色估计在其它来源和有意染色下的可靠性仍待核查。 |
| 白／蓝灯预测能否安全触发校正 | 六张常规参考未触发，八张有意加蓝参考全部触发，目标近中性色最坏额外误差 33.41 RGB8。[开关负例](2026-11-19-cti-selective-correction.md) | 结束使用二类白点直接判断是否应校正。保留匹配色偏强度的编辑负例。 |

最新实图仍来自开发诊断。原扩展训练第 4 轮在 64 个已用开发配对上平均 RGB 误差下降 19.28%，有 2 个严重退化，32 组换参考响应里的达标数为 18，低于 20。后续背景换色检查同样未给出升级依据。[冻结候选及失败](2026-11-18-route-handoff.md#最强保留研究候选)

## 接续决策：默认偏色与风格反应都需要处理

| 后续实图检查 | 已确认的结果 | 研发取舍 |

| 只改变参考外观左右方向 | 目标和参考颜色统计完全相同，目标成片仍会变化。两方向平均时，三个较轻换背景案例有改善，最差反例没有改善，四套开发检查均未通过。 | 停止镜像平均。[参考镜像](2026-11-19-reference-mirror-appearance.md) |

## 下一候选的复查入口

已核对四套开发对照的原图、参考、已知效果和基线成片，共 132 个可解码 RGB 文件。其中背景换色与有意编辑 40、FACD 同款换照片与换款 70、Film B 六方向 18、实体色卡 4。数字是文件数，不能作为独立样本数。运行 `verify_development_inputs.py <本机研究输出根目录>` 可复查清单身份、文件哈希及 RGB 解码。评分沿用各自原有协议，不能以该预检代替候选实图评分。公开 Git 只保存核查工具和说明。[开发素材预检脚本](../../experimental/adaptive-reference-20261113/verify_development_inputs.py)

已经用扩展第 4 轮权重跑通四套复查。白球服换背景差下降，焊工两组 Film B 响应转正，FACD 仍有显著近中性色退化，四套均未通过。后续应对照这组保留收益和失败检查，不再先按整图平均数挑候选。[完整开发检查](2026-11-19-frozen-candidate-development-crosscheck.md)

正式独立画质、真实自然评价及新候选的完整视频验收均尚未开展。进入正式验收需要先有通过开发门槛的独立版本，再核对独立素材家族、实际人类评价、视频运动／切镜／遮挡、端到端性能及导出边界。当前没有符合条件的画质 PR。课程版用现有入口，便携 ZIP 哈希已重新核对，外部课堂设备仍待实测。[课堂彩排](../CLASSROOM_REHEARSAL.zh-CN.txt)

## 可选推进方向

1. **当前课程优先。** 继续以稳定 1.3 展示完整操作，用 13 号研究版和白球服实图解释空间调色进展。课堂素材、实拍成片及模型按现有本机交付范围使用。
2. **继续自动画质研发。** 有价值的新素材应能分别检查「风格不变只换拍摄条件」和「拍摄条件不变只开关同一编辑」。优先准备同一人物、机位和曝光下重复拍摄的白光／彩光组，背景应有可测的浅色区域；另外保留从白光原片做出的同方向有意染色。跨人物或场景拟合时按拍摄家族留出；原图、编辑历史、标签和采集条件均只供训练或离线诊断，运行时仍只输入两张普通图。多套公开人像库已核查，暂未找到可直接使用的小样。[拍摄来源与许可缺口](2026-11-19-portrait-light-source-eligibility.md)

新候选先在既有四套开发对照同时验证主体偏色、风格方向、迁移幅度和退化限制，再考虑打开独立保留集。现有课程取舍适用，暂无要求用户评分、提供账号或购买设备。完整画质目标保留。
