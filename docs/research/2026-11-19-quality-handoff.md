# 映色画质阶段交接

**当前可体验的是稳定 1.3 和 13 号空间调色研究版。跨场景自动偏色修正没有通过升级条件。** 从剪映参考调色功能出发，项目实现了自己的全局调色，然后让不同画面位置可以使用不同调色。现在卡在判断参考里的颜色究竟来自物体、拍摄光照，还是应当迁移的创意风格。课程汇报可以用白球服和实体色卡分别展示这两个阶段。[体验与课程交付](../../00-从这里开始/0-体验与课程交付.md) · [原阶段交接与历史路线](2026-11-18-route-handoff.md)

## 实图证据与停止范围

| 具体问题 | 已确认的结果 | 对后续的约束 |
| --- | --- | --- |
| 能否统一保护浅色区域 | 扑克两块白桌布在三档曝光下减去共同色偏均改善，但最高档浅色衬衫退步，且已经正确的 Film A 成片也受损。[共同色偏对照](2026-11-19-common-chroma-offset.md) | 结束固定减色，验证须包含有意染色。 |
| 用稳定版估计颜色能否补足空间调色 | 保留 13 号明暗、换用稳定版色度，实体色卡两脸颊基础偏色下降，风格响应由 2／7 降到 1／7，白球服换背景偏色加重。[色度拼接](2026-11-19-stable-chroma-hybrid.md) | 结束固定全局／空间拼接。 |
| 能否单靠强度拉回风格 | Film B 参考加深后，扑克和色卡同向但偏弱；焊工在四个非零档位均反向，换另一张参考也仍反向。[五档成片](2026-11-19-arri-film-b-dose.md) · [六个交叉方向](2026-11-19-arri-film-b-crossed.md) | 量化方向和幅度，保留原样例作为负例。 |
| 目标颜色统计是否参与反向 | 固定目标图只换全局直方图，焊工四个外来统计组合中三个转正；反过来可使扑克从正向转为反向。18 个组合均未过原门槛。[统计干预](2026-11-19-film-b-target-histogram-swap.md) | 这条全局统计路径会影响方向。结束固定替换；离线借来的另一张原片不会作为产品输入。 |
| 参考端能否告诉 13 号局部编辑在哪里 | 两组控制中只交换参考里已知编辑的位置，保持 RGB 像素总计数。参考直方图、网格和最终成片逐值相同。[空间位置对照](2026-11-19-reference-layout-collision.md) | 当前参考接口缺少位置线索。后续如有能从普通参考估计区域归属的方法，先同时验证实际换背景和有意调色。 |
| 已有参考外观模型能否补足位置缺口 | 扩展第 4 轮在相同参考对上产生了不同成片，整图位置响应投影约为 0.002／−0.00005，两组都未过门槛。[外观开关对照](2026-11-19-appearance-layout-response.md) | 该检查点已对参考布局敏感，但不能用此信号把编辑放到目标相应位置。保留检查点和反例，后续需要能分辨编辑归属的局部信息。 |
| 真实作者的局部去色会不会连保色区一起改变 | 人像去色不足，鸟照去色响应达到方向和误差要求。两例的保色区变化都超限。[真实成片对照](2026-11-19-psbench-background-desaturation.md) | 用作区域归属的开发反例。两份任务共有去色操作，实际保色范围和额外编辑有差异。 |
| 能否直接把自动识别的物体当保色范围 | 两个方向均触发回退。鸟照约 71% 的保色测量像素被判为背景；人像约 39% 的去色测量像素被判为物体。[分割范围复核](2026-11-19-automatic-selective-chroma.md) | 结束这种固定物体分区。后续验证需显式区分物体轮廓与作者的编辑范围。 |
| 能否从参考剩余颜色直接判断目标保色位置 | 两份参考都能触发，但人像的去色区域反而有更高保色权重，去色差由 6.72 增至 10.45。鸟照对应误差下降，联合仍未通过。[色相对应实图](2026-11-19-selective-hue-support.md) | 停止固定色相对应。后续须同时核查实际编辑范围、场景变化和反例。 |
| 参考相机成像是否会改变同一风格 | 使用同一实体色卡与固定数字风格时，13 号的白桌布响应会由正向变为反向，两脸颊也发生可测变化。[相机交叉对照](2026-11-19-middlebury-camera-film-cross.md) | 参考色的相机成像与后期编辑共同影响结果。接续可分别验证明暗和色度来源，沿用风格、真实主体和近中性色门槛。 |
| 只固定参考明暗能否稳定画质 | 近中性色的换相机 RGB 差八项均至少减半，但出现色度差扩大、风格响应反向。两种固定明暗均未达标。[分通道复算](2026-11-19-middlebury-camera-channel-replay.md) | 结束直接套用另一台相机明暗。后续需分别检查相机色度、风格方向和激活条件。 |
| 校准已有参考成片能否保住风格 | 校准让留出色格更接近；先调色后校准令 8.24% 参考像素限域，两种顺序的整图／近中性色联合均未通过。[顺序对照](2026-11-19-middlebury-camera-calibration-order.md) | 结束把该固定校准直接应用到已调色参考。新路线须区分成像与已施加的创意风格。 |

最新实图仍来自开发诊断。原扩展训练第 4 轮在 64 个已用开发配对上平均 RGB 误差下降 19.28%，有 2 个严重退化，32 组换参考响应里的达标数为 18，低于 20。后续背景换色检查同样未给出升级依据。[冻结候选及失败](2026-11-18-route-handoff.md#最强保留研究候选)

## 下一候选的复查入口

已核对四套开发对照的原图、参考、已知效果和基线成片，共 132 个可解码 RGB 文件。其中背景换色与有意编辑 40、FACD 同款换照片与换款 70、Film B 六方向 18、实体色卡 4。数字是文件数，不能作为独立样本数。运行 `verify_development_inputs.py <本机研究输出根目录>` 可复查清单身份、文件哈希及 RGB 解码。评分沿用各自原有协议，不能以该预检代替候选实图评分。公开 Git 只保存核查工具和说明。[开发素材预检脚本](../../experimental/adaptive-reference-20261113/verify_development_inputs.py)

正式独立画质、真实自然评价及新候选的完整视频验收均尚未开展。进入正式验收需要先有通过开发门槛的独立版本，再核对独立素材家族、实际人类评价、视频运动／切镜／遮挡、端到端性能及导出边界。当前没有符合条件的画质 PR。课程版用现有入口，便携 ZIP 哈希已重新核对，外部课堂设备仍待实测。[课堂彩排](../CLASSROOM_REHEARSAL.zh-CN.txt)

## 可选推进方向

1. **当前课程优先。** 继续以稳定 1.3 展示完整操作，用 13 号研究版和白球服实图解释空间调色进展。课堂素材、实拍成片及模型按现有本机交付范围使用。
2. **继续恢复自动画质研发。** 先验证能否取得许可清晰的独立拍摄组，包含可核对的同款编辑前后图，以及只换背景或光照的对照。这些额外证据可用于训练或离线诊断。运行时仍保持两图输入。首个候选必须在四套开发对照同时验证主体偏色、风格方向、迁移幅度和已有退化限制，再考虑打开独立保留集。现有三个 Film B 实拍来源可作检查，覆盖不足以直接训练开放风格模型。

现有课程取舍仍适用。继续研究可以先自主核验公开来源，暂无需要用户评分、提供账号或购买设备的环节。完整画质目标保留。
