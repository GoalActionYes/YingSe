# 去掉网格取样引导中的目标颜色，成片变化不到一个码值

这个对照只改变 13 号在渲染时选择网格深度的输入。模型仍根据目标 RGB、目标和参考直方图预测原网格，颜色变换也仍作用于原 RGB。原生渲染中，取样引导模块临时收到目标亮度的三通道副本。每张图片渲染后解除替换，再核对原 RGB 路径逐像素重现 13 号。见[事前协议](../../experimental/adaptive-reference-20261113/target-guide-chroma-protocol.md)与[上轮空间网格预测对照](2026-11-18-target-spatial-chroma.md)。

| 检查 | 原空间编码只看亮度 | 原取样引导只看亮度 |
| --- | ---: | ---: |
| 候选相对 13 号的平均 RGB 变化，码值 | 4.04 | 0.087 |
| 人物抗背景干扰并保留整图色偏 | 0/8 | 0/8 |
| 近中性色背景干扰 | 降低 0.53% | 增加 0.044% |
| 对比度与去饱和 | 8/12 | 12/12 |
| 局部冷色与人物保护 | 0/4 | 0/4 |
| 整图冷色与无人负例 | 2/6、2/2 | 4/6、2/2 |
| PSBench 台阶／铁塔联合改善 | 0/2 | 0/2 |

取样引导替换确实改变了部分像素选取的深度。归一化深度坐标的最大差为 0.1163，输出的最大单图平均 RGB 差却只有 0.218 码值。白球服的背景品红干预中，近中性色变化为 9.910 → 9.907 码值，局部冷色例的近中性色人物误差也基本相同。两个真实方向的整图误差分别增加约 0.05、0.08 码值。整图响应多数保留，同时原偏色也保留。

两遍各用时 8.59、8.73 秒，62 张输出哈希完全相同。暂停干预后的 62 张 RGB 原路径逐像素重现。同图保持通过，并从已保存 PNG 独立复核 166 项变化量和近中性色记录。见[数值与输出身份](2026-11-18-target-guide-chroma-evidence.json)。

这两轮观察区分了目标颜色的两种用途。在当前冻结模型和场景下，目标颜色影响网格预测的程度更大，仅在渲染取样阶段替换引导没有改善可见偏色。结束冻结模型直接去掉目标颜色的方向。亮度替换是模型的分布外输入，本轮没有验证专门训练的亮度引导。软件画质升级、独立验收和新候选视频仍未通过。

复现时在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path` 与 `$env:OPENBLAS_NUM_THREADS = '2'`，用现有研究 Python 运行 `experimental/adaptive-reference-20261113/probe_target_guide_chroma.py <新输出目录>`。依赖冻结 13 号与原三套开发对照。本机保留完整输出和重复结果。
