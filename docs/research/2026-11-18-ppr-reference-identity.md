# 参考图颜色统计未给出足够的跨照片专家身份信号

当前人物分区监督支路保持停止。本轮转向一个不同问题：官方三专家目标虽然不同，只看已调色参考图的颜色统计，能否跨照片识别其编辑身份？该探测未通过运行前条件，没有扩大数据、搜索参数或训练产品候选，也没有把软件改成三种专家预设。

## 与前轮的区别与输入边界

前轮使用真值及人工人物蒙版诊断空间拟合能力。本轮只读取既有四原照片的12张已调色专家图，不打开原始参考图、目标原图或蒙版，不把XMP参数当输入。专家标签仅用于监督与评分；类别识别成绩不等于参考色彩迁移或自然度。

按[运行前协议](../../experimental/adaptive-reference-20261113/ppr-reference-identity-protocol.md)，主特征为RGB各32箱直方图加均值／标准差，共102维；次要基线仅6维均值／标准差，不依据结果切换主检验。固定ridge=1，按原照片整组留出：每折九图拟合特征标准化与分类器，三图测试，四折各一次。同照片的不同专家版本没有跨折泄漏。

为避免将12个有关联的版本误当独立样本，精确枚举照片组内专家标签置换；首照片固定，其他三照片各6种，共216配置，包含原始标签。运行前主条件为至少9/12正确且精确p≤0.05，只决定是否值得进一步最小参考条件研究，不代替任何产品门槛。

## 结果与全部失败

主特征正确5/12，次要基线3/12。216配置中59个不少于5次正确，精确p=59/216≈0.27315。两项主条件均未达到，不靠次要基线、分箱或lambda搜索挽救。

| --- | ---: |
| 4_2 | 2/3 |
| 7_4 | 1/3 |
| 15_3 | 1/3 |
| 19_1 | 1/3 |

完整逐图预测、类别混淆和全部216置换命中数见[证据摘要](2026-11-18-ppr-reference-identity-evidence.json)。不把41.7%写成画质分数，也不宣称它可靠优于机会水平。p值条件于本固定特征及组内标签可置换的零假设，不是随机分配实验的因果结论；四照片很少，未证明跨人物／全部场景独立。阴性只说明本固定特征及小型探测未提供推进信号，不能证明专家身份或自然风格永远不可学习。

## 复核与决策

生产主流程记录0.250秒，CPU、无GPU／网络／安装。独立复核重新解码12张专家图，用计数分桶替代直方图API、显式均值方差重建全部特征，结果逐值一致；再以原始空间ridge求解替代生产对偶形式，最大得分差2.22e-14，全部预测与216置换命中数一致。没有打开原图或蒙版。两脚本退出0，无活任务。

停止本固定颜色统计探测，不将它更名后换参数继续。已停止的PPR人物分区支路也不恢复；本结果没有给出扩大479项或接入产品的依据。今后若使用该来源，需有实质新的参考信息、监督任务或可信证据，而非仅因已有数据便启动训练。

保留专家像素、源身份、标签对照、工具及阴性结果，供后续路线决策。研究尚未形成下一版实际画质收益；现有稳定1.3、13号研究版与课程体验包保持，原完整目标未完成。

本机目录`outputs/adaptive-reference-20261113/ppr-reference-identity-v1`保存配置、特征和全部结果。Git只保存脚本、协议及数值摘要，照片和完整生成物不上传。复核运行`verify_ppr_reference_identity.py`；生产脚本`probe_ppr_reference_identity.py`拒绝覆盖已有目录，勿删除原记录来重跑追分。
