# 按灰度纹理匹配未能区分有意调色和背景串色

本轮直接在已知开发照片出图。每个目标小块用灰度亮度和纹理找到参考近邻，再用近邻色度约束近中性色能接收多少 13 号色度增量。没有把参考色度本身用于配对。与以往全图重加权相比，这里每个目标位置可以受到不同限制。推理处理只读取目标、参考及 13 号输出。该灰度近邻无法确认两块属于相同材质，也没有输入调色历史。见[事前协议](../../experimental/adaptive-reference-20261113/texture-matched-neutral-support-protocol.md)。

| 检查 | 结果 | 事前门槛 |
| --- | ---: | ---: |
| 人物减干扰并保留整图色调 | 0/8 | ≥6/8 |
| 近中性色平均干扰降低 | 3.49% | ≥15% |
| 对比度和去饱和响应 | 12/12 | 12/12 |
| 局部冷调、人像保持联合 | 0/4 | ≥3/4 |
| 整图冷调及无人负例 | 4/6、2/2 | ≥4/6、2/2 |
| PSBench 105 | 0/2 | ≥1/2、另一方向无明显退化 |
| BG-REAL 背景／冷调交叉 | 0/4 | ≥3/4 |
| FACD 同款／换款联合 | 0/7 | ≥6/7 |

白球服品红干预的近中性色变化仅从 9.91 降到 9.56。该例 55.47% 的目标小块有可用近邻，9.29% 的输出像素受到限幅。换真实背景后，白球服的人物冷调响应差从 2.61 增到 2.68。婚纱 XProII 换同款参考的整图差从 22.94 降到 22.77，两张成片仍差异明显。台阶近中性色误差由 16.77 降到 15.86，原图为 7.60。见[白球服与婚纱对照图](../../outputs/adaptive-reference-20261113/texture-matched-neutral/white-jersey-and-wedding.jpg)及[数值与身份](2026-11-18-texture-matched-neutral-evidence.json)。

结束以这四个灰度纹理读数作为固定色度旁证。它保留了大部分原模型的亮度和有效整图响应，实际串色收益仍不足。该结论只覆盖所用匹配规则。后续需要更能确认相同材质或明确编辑作用的证据，才值得继续约束局部色度。开发成片与阈值均保留，软件候选、独立画质和视频验收仍未完成。

在既有 `vision-advisor-env` 设仓库根目录为 `PYTHONPATH`，运行 `probe_texture_matched_neutral.py <新输出目录>`。两遍各 120 张 PNG 与报告哈希一致，另由成片按整数系数复核全部亮度差，最大为 0.4998 码值。同图用例逐像素保持。复核白球服背景变体与真实背景冷调交互，以及婚纱换同款参考误差。图片留本机。
