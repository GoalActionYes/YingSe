# 已知参考前后的分位变化能让焊工转正，仍恢复不了完整风格

此前把参考的实际 Film B 拆成明暗或色度，在焊工场景仍有反向。这轮在已知同一参考编辑前后两图时，比较每个亮度或色度分位的变化，并将这份变化按值映射到目标原图。对照同一个合成引导的直接结果与交由冻结 13 号的结果，均沿用 80% 强度。目标的作者效果只用于离线评分。参考原片是本诊断额外输入，普通两图推理没有它。[事前协议](../../experimental/adaptive-reference-20261113/film-b-reference-quantile-transfer-protocol.md) · [明暗与色度拆分](2026-11-20-film-b-reference-components.md)

| 目标 ← 参考 | 整图，13 号／直接／再次经 13 号 | 近中性色，13 号／直接／再次经 13 号 |
| --- | ---: | ---: |
| 焊工 ← 扑克 | −0.033／0.695／0.592 | −0.087／0.787／0.665 |
| 焊工 ← 色卡 | −0.325／0.650／0.590 | −0.447／0.735／0.677 |
| 扑克 ← 色卡 | 0.338／0.508／0.230 | 0.206／0.707／0.227 |
| 色卡 ← 焊工 | 0.304／0.501／0.191 | 0.627／0.854／0.166 |

投影 1 表示与作者开关同向且幅度相同。焊工两个方向的整图及近中性色全部转正，但直接臂整图响应误差仍为 5.17–5.36 RGB8，近中性色为 6.40–6.66，均高于 3。再次经 13 号渲染，焊工两方向的误差有所减小，整图与近中性色投影均变弱，仍未联合通过。直接臂与 13 号臂各 0/6，未达到至少四个方向含两个焊工方向的预设条件。六组全部保留。[本机焊工对照](../../outputs/adaptive-reference-20261113/film-b-reference-quantile-transfer-v1/sparks_4592-from-hdr_testimage/comparison.png)

分位改变量保留了可检出的风格方向，但单独处理三个通道也改变了联合颜色关系。色卡合成引导的色域压缩比例为 41.67%–48.34%，焊工不足 1%。焊工在很少限域的情况下也未达标，不能把失败都归因于裁切。停止把这套单轴分位变化直接用作训练目标或自动候选。可保留焊工方向转正的离线证据，未来若加入联合颜色关系，仍须证明普通两张图能得到有效线索。没有更改现有软件或使用独立验收素材。
