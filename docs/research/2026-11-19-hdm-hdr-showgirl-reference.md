# 13 号对同一参考帧编辑有响应，也会压掉原有灯光差异

沿用《Showgirl 2》固定的两帧和区域。两张原片各作目标，两时点的原片与作者成片各作参考，得到八张 13 号 80% 成片。每一行的目标相同，参考内容相同，仅切换参考的编辑状态。对照板的第 4、5 列是实际输出，第 6 列是目标对应的档案成片。同帧对照明确允许用档案目标成片做参考，作为离线诊断。跨时点比较中的档案目标成片及全部人工区域只用于离线测量。[本机成片对照](../../outputs/adaptive-reference-20261113/hdm-showgirl-reference-results-v1/comparison.png) · [事前协议](../../experimental/adaptive-reference-20261113/hdm-hdr-showgirl-reference-protocol.md)

使用同一参考分别渲染两个目标，比较输出是否保留两个时点原有的灯光差异。两区域各有四项比较，合计 **3/8** 通过。结果与参考有关：采用偏暖镜中段落的作者成片，两区都保留了原先的主要差异；采用偏冷直拍段落的作者成片，脸颊变化的方向余弦为 −0.971，白羽毛变化的幅度只剩 0.107 倍。该组测量只用输入和 13 号输出，不依赖作者目标成片。两个原片同时变化的取景、反射路径和姿态仍属于这个对照的限制。[原片换光与区域记录](2026-11-19-hdm-hdr-showgirl-light.md)

| 固定参考 | 脸颊方向余弦／长度比例 | 白羽毛方向余弦／长度比例 |
| --- | ---: | ---: |
| 镜中暖光，原片 | 0.870／0.360 | 0.990／0.743，通过 |
| 镜中暖光，作者成片 | 0.841／1.140，通过 | 0.985／0.738，通过 |
| 直拍冷光，原片 | −0.048／0.153 | 0.994／0.419 |
| 直拍冷光，作者成片 | −0.971／0.899 | 0.516／0.107 |

作者成片的四个目标区域在 SDR 显示转图里均有 100% 像素至少一个通道到端点，四个跨时点参考响应的指标全部低于预设显示支持条件。暖光目标换用冷光作者参考后，脸颊和白羽毛在 SDR 图上离作者目标更远；冷光目标换用暖光作者参考后，两个距离略降，但沿作者方向的变化幅度只达 18% 和 13%。冷光目标白羽毛的作者编辑方向在转换前后余弦为 −0.886，说明显示转换能改变该区域对编辑方向的判断。保留这些数值为显示诊断，结束把两帧作者成片当作共享风格监督的做法。

对候选的直接要求是保留这个案例里真实存在的主体与白面灯光差异，同时继续检验对有意编辑的响应。下一步只在无端点裁切、编辑方向可复核的参考对照上判断迁移准确性。此次保留两张原片及成片作为开发反例，没有接入软件改动。

复现先在 OpenCV 环境运行 `probe_hdm_hdr_showgirl_reference.py prepare <本机档案目录> <ROI JSON> <准备目录>`（启用 OpenEXR），再在 13 号环境运行 `probe_hdm_hdr_showgirl_reference.py render <准备目录> <新输出目录>`。两轮的四张准备图、八张输出图、对照板和两份 JSON 逐文件哈希一致。档案与生成图均留本机。[脚本](../../experimental/adaptive-reference-20261113/probe_hdm_hdr_showgirl_reference.py) · [数值与哈希](2026-11-19-hdm-hdr-showgirl-reference-evidence.json)
