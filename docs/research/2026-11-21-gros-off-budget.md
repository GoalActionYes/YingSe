# 改用原有关闭态预算后，六个真人离线方向通过三个

此前七份冻结成片的逐像素 RGB 混合把关闭态固定为原图。那一试验中，部分脸颊和白幕的可达边界仅适用于关态逐像素保持。原开发评分实际允许关态相对原图及冷暖差各不超过 3 RGB8。本轮沿用原门槛、人物、灯光、样本及七份源成片，核查同类混合在这个范围是否还有可行见证。[上一轮与边界](2026-11-21-gros-rgb-mixture.md) · [事前协议](../../experimental/adaptive-reference-20261113/gros-off-budget-protocol.md)

先用上次的开态减去已知的编辑增量，求最接近的可混合关闭态。对每组两灯统一向原片收缩，留出 RGB8 取整余量。再以新的关态加编辑增量，求最接近的开态。两个像素的混合权重可以不同，同一像素的三个通道共享一组非负权重。每种灯光分别拟合。正确成片和区域范围只用于离线构造及验证。未运行两图自动预测或接入软件。

区域包含整图、双颊和两侧白幕。完整方向为 2／6 → 3／6，先前达标区都保留。关态对原图的最大误差为 2.494 RGB8，关态冷暖最大差 2.102 RGB8，均符合原限额。六个方向来自三位已经使用的开发人物。[数值、哈希和分灯证据](2026-11-21-gros-off-budget-evidence.json)

新增完整通过的 01 ← 02 冷灯整图，风格投影从 0.717 到 0.878，编辑增量误差由 2.90 降到 1.80 RGB8。不过直接比较开态与正确成片，整图误差从 2.90 升至 3.10。同一组冷灯右白幕的最终成片误差也由 3.02 升至 3.21。关态离开原片可以调整开关差，因此原联合通过数增加，仍不足以证明视觉成片更接近正确颜色。02 ← 03 的左脸颊，暖灯投影达到 0.842，冷灯仍只有 0.663。03 ← 02 暖灯左脸颊达到 0.749510，低于原 0.75，保留失败。[新增完整通过组](../../outputs/adaptive-reference-20261113/gros-off-budget-v1/01-from-02-comparison.png) · [左颊失败组](../../outputs/adaptive-reference-20261113/gros-off-budget-v1/02-from-03-comparison.png)

这次给出一组能真实合成的新增见证，也定位了评分和最终成片可以分离的情形。原来关于逐像素关态保持的数学排除仍有效，不能扩展到原评分允许的全部关态。本轮算法没有穷尽全部权重。下一项若使用现有材料推进，应先选可以直接改善最终出片的颜色生成或自动判断，不再依靠改变关闭态提升差分。新的实拍编辑配对仍是已规划训练路线的一项条件，非训练验证可继续使用现有开发资料。稳定 1.3、研究 13 和原完整画质、真实人评与视频门槛继续适用。
