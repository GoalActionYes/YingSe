# 关闭 Filmic RGB 未缩小 RAW 与 sRGB 的暖调响应差异

混合光照片采用同一蒙版时，RAW 与 sRGB 的作者暖调响应仍有差异。作者流程的执行顺序里，Filmic RGB 位于 RGB 色彩平衡之后。本轮关闭实验副本中这一个模块的四条历史记录，避免旧状态生效。除色彩平衡本身的开关外，其他历史和参数保持。以各流程开减关的色度变化比较暖调响应，沿用原蒙版和 80% 强度。此项比较在最终合成量化前计算，因此读数与上一轮对落盘成片的测量略有差别。[事前协议](../../experimental/adaptive-reference-20261113/playraw-filmic-response-protocol.md)

| 区域 | 原 RAW 与 sRGB 的响应差 | 关闭 Filmic 后的响应差 |
| --- | ---: | ---: |
| 满权重 | 2.963 | 3.484 |
| 高权重留出折 0 | 3.338 | 3.558 |
| 高权重留出折 1 | 3.288 | 3.533 |

表中为首轮色度 MAE，单位 RGB8。两折均未达到至少减少 1 RGB8 的要求，差异反而略增。三处评分区中，关闭 Filmic 后新增的近边界像素只在第二折开态出现一处，占 0.034%。未触发增加五个百分点的限制。关态与原 RAW 关态的水平亮度边缘相关约为 0.9745。两次关态和开态分别有 66、146 个像素相差 1 码值，评分结论一致。[本机四态对照](../../outputs/adaptive-reference-20261113/playraw-filmic-response-0/comparison.png) · [两轮数据与哈希](2026-11-21-playraw-filmic-response-evidence.json)

这个结果排除了「在这份作者历史中单独关闭 Filmic 就能缩小差异」的解释。它不能分离工作空间、其他模块或交互的影响。保留对照，结束本项 Filmic 假设。现有两图工作流的画质、自然评价和视频验收尚未达成。后续应优先寻找能在实际两图输入中取得、并可在更多内容上检验的线索。
