# 正面人脸框漏掉三个实拍脸部，同时保留投影幕脸

在已有四张 BG-REAL 原图上，用固定语义肤色模型预测修正权重，并比较增加固定正面人脸框后权重的变化。九个旧登记框只用于离线评分。两种输入都以相同的固定 RGB 偏移出图，显示误触和漏检。见[事前协议](../../experimental/adaptive-reference-20261113/skin-face-gate-protocol.md)。

| 测量项 | 语义肤色 | 语义肤色加人脸框 |
| --- | ---: | ---: |
| 三个直接拍摄脸部通过数 | 3/3 | 0/3 |
| 真实墙面、球服、雪地未触及 | 3/3 | 3/3 |
| 投影幕脸未触及 | 0/1 | 0/1 |

旧语义掩膜在三个脸部框的高权重覆盖率分别为 100%、100%、85.71%。新增约束在这三张图都没有检出人脸框。它唯一检出的是投影幕上的 30×30 脸框，该区域里两个方法都触及全部 110 个登记像素，诊断输出平均变化 6.67 码值。两个直接皮肤的手臂、手背框在新增约束后都失去原有覆盖。这些范围较小，墙面等已登记区域的零变化不代表整张图无误改。见[投影幕反例](../../outputs/adaptive-reference-20261113/skin-face-gate/8021-8690.png)和[白球服与后方人物](../../outputs/adaptive-reference-20261113/skin-face-gate/872-1268.png)。

停止将这套固定正面人脸框用作修正开关。可继续研究拍摄主体归属，例如用物体边界或场景上下文区分真实人物与屏幕人物，并保留这里的远处脸部及投影幕作开发对照。此轮尚没有普通参考图选取正确光源或迁移风格的验证。

两个独立进程生成的四张图与数值报告逐文件一致。用原图和已生成图复算 18 项 RGB 变化。使用既有便携皮肤保护运行环境加载 `probe_skin_face_gate.py <OpenCV 级联 XML> <新输出目录>`。便携解释器需用 `runpy` 并将脚本父目录加入模块搜索路径。初次直接调用时因便携环境限制搜索路径退出，补入路径后两次均成功，无模型或参数改动。见[数值证据](2026-11-19-skin-face-gate-evidence.json)。
