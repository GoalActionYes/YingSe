# 周围明暗未解释同教程调色的剩余区域误差

台阶人像和铁塔来自同一调色教程。离线使用参考原图构建固定 RGB 表后，台阶青偏已有改善，衣服与铁塔天空仍存在误差。本轮检验在颜色相同的像素之间，周围明暗能否解释剩余的编辑差，并能否跨场景迁移。见 [事前协议](../../experimental/adaptive-reference-20261113/psbench-local-contrast-protocol.md)和[固定 RGB 表](2026-11-18-psbench-action-rgb-global-map.md)。

在原尺寸参考前后图的固定棋盘格训练折上，扣除每种精确输入 RGB 内的均值，用半径 16 的高斯邻域亮度与中心亮度之差拟合三个通道的斜率。合成检查恢复已知斜率，只有全局颜色变化时得到零斜率。每份跨场景成片仅用参考侧斜率，叠加至原全图固定表输出。每折整图渲染，目标侧作者裁切只用于该方向落盘后的离线评分。两个方向的裁切共用同一份作者拼图文件。

| 目标和参考拟合折 | 近中性色误差，固定表 → 加邻域 | 整图误差，固定表 → 加邻域 | 最差中性色块增加 |
| --- | ---: | ---: | ---: |
| 台阶人像，第 0 折 | 4.083 → 4.079 | 6.780 → 6.880 | 1.734 |
| 台阶人像，第 1 折 | 4.082 → 4.128 | 6.662 → 6.768 | 2.006 |

| 铁塔，第 1 折 | 6.334 → 6.316 | 5.629 → 5.640 | 0.974 |

单位为 RGB8 码值。四份成片的近中性色误差均未达到预定的 0.50 码值改善，台阶人像第二份的局部退化超过 2.0 上限。整图和相邻平滑像素跳变达到本轮限制。留块同色像素中，同场景斜率的近中性色误差收益至多 0.053 码值。跨场景斜率在台阶两折都使这项误差增大，在铁塔两折只有 0.035–0.040 码值收益。全图衣服和天空的原有差异在比较图中仍可见。

两遍各约 4.1 秒，覆盖图像读取、计算、写盘和离线评分。四张 PNG 字节一致。另按颜色排序分组重算系数、逐像素复现候选，并复核整图与近中性色误差及报告所列最差块。该实验使用额外参考原图和已有开发样例，结束固定配置。它仅限定当前亮度差特征和线性拟合在这个同教程对照上的作用，无法判断作者是否做过其他局部调整。

保留这一对照片作可复现的全局颜色对照。下一批空间素材应能核对明确的局部编辑操作在不同原始内容中的应用，例如同一局部调整开关前后各有一份已导出照片，才能把局部操作与全局调色、JPEG 及个别画面的效果分开。未读取独立保留图，未训练或接入软件。
