# 同一人像色彩平衡换照片后出现不足和过调

《Cuckoo》的作者用 RawTherapee 色彩平衡减少绿色植被反光。本轮复用这项开关，并将相同参数加载到另一张混合光人像的默认显影上。每张照片的开、关状态只变更该区块的 Enabled。两张照片的相机和其余显影条件各自保留。随后以 80% 强度让两张照片的开、关成片互作参考。13 号每次只读取目标原图和其中一张参考。已知目标开态及评分区域用于离线测量。[作者开关的实拍记录](2026-11-20-rawtherapee-portrait-toning.md) · [事前协议](../../experimental/adaptive-reference-20261113/rawtherapee-portrait-cross-protocol.md)

| 混合光人像共同近中性色 | 1.855 | 1.84 | 46.32 |

投影 1 表示沿编辑预期方向的幅度相当。误差单位为 RGB8，响应误差基于红、蓝去亮度分量，关态误差基于 RGB。整图和共同近中性色均满足事前的像素数与编辑信号要求。两方向都没有通过。向《Cuckoo》传递时改色不足，反向则过强。即使只比较开、关成片之差，两个方向的整图及近中性色仍各自未达到投影区间 0.75–1.25。关态误差也超过预设 3 码值。关态指标用于量化受控试验中内容差异带来的变化，实际用户可有意采用未编辑照片的整体色调。

保留这组数据用于区分关闭态偏差与编辑响应。两张原片此前均用于开发。本轮只核对同一个 RawTherapee 操作参数，不能把两份默认／作者显影背景或改色强度当作相同。编辑是全图操作，浅色树皮仅作低饱和材料代理。结果支持后续方法同时检查基底与编辑响应，单凭把同一调色名称贴到两个场景上无法校验真实迁移幅度。[数值及哈希](2026-11-20-rawtherapee-portrait-cross-evidence.json) · [《Cuckoo》成片](../../outputs/adaptive-reference-20261113/rawtherapee-portrait-cross-v1/cuckoo-from-mixed-on.png) · [混合光成片](../../outputs/adaptive-reference-20261113/rawtherapee-portrait-cross-v1/mixed-from-cuckoo-on.png)

## 复现

将仓库根目录加入 `PYTHONPATH`，在现有研究 Python 运行 `experimental/adaptive-reference-20261113/probe_rawtherapee_portrait_cross.py <研究输出根目录> <本机 RawTherapee CLI 路径> <新输出目录>`。脚本核对编辑器、原片、原作者配置、原作者两态成片及模型身份。两遍各四张模型输出、两张用于评分的目标期望图和 JSON 报告逐字节一致。新显影成片依照报告中的规范化 RGB 哈希核对。原片、完整成片和环境保留本机。
