## 已排除的简单推进方式

| 路线 | 实际结论 | 后续限制 |
| --- | --- | --- |
| 近中性亮部锚点、肤色回补 | 前者收益微小，后者仍混合参考人物本色与照明 | 不重跑阈值或强度搜索 |
| 面部／皮肤／衣服类别均值方差对齐 | 早期已经使用细人物类别，150控制中125恶化、21改善 | 不能把重新加入面部类别当成新方法 |
| 人物／背景学习修正头及修正场监督 | 原固定方案收益不足，辅助监督未超过零修正 | 不追加同头、loss或seed |
| DINO局部对应与输出颜色条件 | 两轮均未优于未修正版；后续证明有粗人物类别信号 | 不把失败全归于“没有看见主体”，不重启旧头 |
| 扩展真实配对与多项风格／颜色监督 | 存在平均收益，但完整风格响应和退化门槛仍有失败 | 不靠更多轮数／数据量或重命名损失追分 |
| 多个现成颜色迁移模型 | 有跨案例严重失败；ICTone同源局部有效、跨来源不稳定且不可直接产品集成 | 不用单张好图或模型名称替代验证 |
| 默认单图白平衡先验 | 8方向仅4项同时满足响应与抗干扰 | 不默认接入或继续调参 |
| 空间反射颜色／光照估计及自动背景去色 | 原方案同时6/8；去色后抗干扰8/8但有效响应0/8 | 停止当前两轮修复，不能以少响应冒充自然 |

## 当前能力边界

软件已有空间变换能力，但无法可靠地从两张不同内容图片确定物体本色、光照与应迁移风格。分割和内容对应提供部分对象线索，却尚未形成稳定调色决策。[精确构造](2026-11-17-style-task-ambiguity.md)说明隐藏生成过程不总能由RGB唯一辨认；它不证明自然照片普遍冲突或未来算法不能改善。

目前没有证据支持立即启动下一项具体训练。继续同头调参、轮换先验模型或不断写诊断，不是有依据的软件升级路径。也不能因没有新候选而降低已有标准、重新启用已消费独立集，或将目标标记完成。

2. **继续原画质目标的开放研究。**下一阶段优先寻找与现有三元组、合成规则、区域统计和先验模型实质不同的监督或风格约定，先交付来源、许可、输入可获得性及可证伪的任务设计，再决定训练。当前尚未验证这样的新来源；不能承诺再训练一轮就能成功，也不立即下载大型数据或启动新模型。
