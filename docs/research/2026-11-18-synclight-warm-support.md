# 目标图的暖色分布不足以定位应迁移的灯色

在 13 号 80% 成片上保留原亮度变化，只对色度增量进行空间重分配。权重由目标原图线性 sRGB 的红蓝对数比经高斯平滑后取得。该方法把一张图内相对偏暖的区域视作更可能受到暖灯影响。候选出图使用普通目标和参考工作流，不使用已知受光比例、锚结果或目标答案。见[事前协议](../../experimental/adaptive-reference-20261113/synclight-warm-support-protocol.md)与[实拍成分对照](2026-11-18-synclight-ambient-balance.md)。

| 场景 | 弱受光误差，13 号 → 候选 | 强受光方向投影，13 号 → 候选 | 强受光误差，13 号 → 候选 |
| --- | ---: | ---: | ---: |
| 走廊 scene35 | 1.764 → 2.351 | 0.803 → 0.743 | 1.19 → 2.16 |
| 床头 scene25 | 1.020 → 1.238 | 0.301 → 0.588 | 4.37 → 4.30 |

误差单位为 RGB8 码值。两场都未满足弱区误差 ≤1 和强区投影 0.75–1.25 的联合条件。床头强区响应提高，但近中性色误差从 0.88 增至 1.43，超过 0.25 上限。已有四组换背景检查中，8021 的整幅近中性色变化从 30.74 增至 32.38，超过 1 码值上限。其整图和局部背景冷色方向响应也低于保护要求。同图和两个无人局部保持通过。

按门槛停止此固定重分配。目标图的颜色包含物体颜色与照明，当前统计无法稳定给出受光位置。后续需要能验证实际光照空间分布的额外信息，并同时检查真实风格和背景变化。现场演示软件没有新增画质升级。
