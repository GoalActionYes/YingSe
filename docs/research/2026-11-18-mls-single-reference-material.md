# 单参考加已知材质通过同灯与换灯控制，比较优势未全达标

上一轮用供体的换灯前后实拍测量材质变化。本轮每个输出只用一张目标原图和一张不同场景参考，蓝纸、绿纸对应仍由作者掩膜给定。分别计算相同材质的参考色度减目标色度，再按 80% 强度调色，浮点亮度保持。共同均值对照用同样两张图和同样的范围，在两个区域施加同一个色度变化。目标实际换灯照片只用于成片后的评分。见[事前协议](../../experimental/adaptive-reference-20261113/mls-single-reference-material-protocol.md)及[供体实拍前后重放](2026-11-18-mls-material-response.md)。

色度变化与误差均为线性 RGB 对数通道比 RMS。同材质的同灯变化四项均低于 0.05。四项也都保留了有效换灯响应，方向投影介于 0.663 和 1.012。两个绿纸范围相对共同均值的收益仍低于门槛，联合通过 2/4。13 号的数值来自上轮同一输入与范围，输出覆盖整图；本轮仅改蓝纸和绿纸，表格中的数值只比较指定区域。这一结果限于同一实验室的两个重复场景，尚未验证近中性色整体区域或人像。

两遍报告与 8 张输出哈希一致，同图和掩膜外像素保持通过。另从落盘文件独立复算 16 个区域的像素、误差、投影和同灯变化。见[数据与版本身份](2026-11-18-mls-single-reference-material-evidence.json)。

已知材质在本批能减轻同灯参考串色，同时保留实际换灯的颜色响应。固定相减的组合优势未全达标，结束直接接入。场景和材质标注仍为离线输入，后续有新证据时，才核对普通图像上的自动匹配是否能保持此类收益。课程版、独立评价和视频状态不变。
