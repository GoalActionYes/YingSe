# 同一结果的参考替换仍会明显改变 13 号输出

换一个背景内容不同的参考时，如果作者索引要求同一个目标结果，软件输出也应相对稳定。核对 TST100K 的固定 108,808 条索引和既有 4,096 条训练清单，不根据预设后缀匹配，也不从目标真值拟造参考。只保留没有歧义的作者配对，排除已知同源家族。9,002 份已准备训练资产覆盖 364 个拥有至少两种参考来源的目标／结果组合。153 个目标原图家族同时还有另一明确结果，可检查应当保持和应当改变的两种响应。原索引的图级结果无法指明哪些局部颜色属于调色意图。见 [数据发布](https://huggingface.co/datasets/ToneStyle/TST100K)、[元数据协议](../../experimental/adaptive-reference-20261113/tst-reference-equivalence-protocol.md)。

固定取前八个合格目标家族，每个目标用来自三个不同家族的参考。前两张参考指向同一结果，第三张指向另一个结果。13 号以 256×256 输入和 80% 混合生成 24 张图，输出及哈希在读取作者结果前保存。全部八组的两份作者结果相差至少 1 RGB8 码值。见 [实图协议](../../experimental/adaptive-reference-20261113/tst-reference-equivalence-pilot-protocol.md)。

- 整图同结果参考的换图差在 5/8 组小于两次换不同结果的差异。在余下三组中，同结果参考本身已明显改变输出。
- 要求不同结果的响应投影至少达到作者结果差的 50% 后，仅 2/8 组同时达标，低于预设的 6/8。最大同结果换图差为 28.12 码值，同组其中一次不同结果换图差只有 9.74 码值。近中性色的完整数值随全部案例保留。

独立检查了 24 条作者索引、24 个输出哈希与 16 项分区记录。首次元数据脚本因训练清单哈希漏写一个字符退出，再核对后发现已准备资产的相对路径应从训练清单目录解析。两处修正未改变素材、取样规则和门槛。8 组来自既有训练资产，当前尚未全面复核近重复及区域局部调色意图，未改软件或消耗独立验收集。见 [核验数值](2026-11-18-tst-reference-equivalence-evidence.json)。

这类配对可用于构造参考替换对照。若要训练新方案，应先对指定组核对近重复、风格差和局部处理依据，固定训练与开发组，并沿用独立验收和负例门槛。现有两图模型结果仍只有开发诊断资格。

复现使用既有本机素材和研究环境。在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path`，运行 `python experimental/adaptive-reference-20261113/probe_tst_reference_equivalence.py <新输出目录>`。本机输出在 `outputs/adaptive-reference-20261113/tst100k/reference-equivalence-pilot-v1`，图片、照片路径和私有取样清单不随 Git 发布。
