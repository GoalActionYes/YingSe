# 校准同一批参考颜色的调色差值，白衣和雪地恢复，投影幕仍不足

上一轮用四份已知同款的参考前后图，按八个相近 RGB 重放调色。白球服 C1、雪地 F1、投影幕内的脸 F1 未通过。本轮用同一批参考原图颜色、相同近邻和权重，在这些颜色上直接计算 Film A 和 Film B 的已知变化，替换从参考照片取得的差值。两种方法均以 80% 渲染，目标成片仅用于评分。[事前协议](../../experimental/adaptive-reference-20261113/paired-neighbor-labels-protocol.md) · [上一轮实拍对照](2026-11-20-paired-neighbor-replay.md)

| 留出区域 | 投影，照片差值 → 已知差值 | 响应 MAE，照片差值 → 已知差值（RGB8） | 最近／第八近邻 RGB 距离的中位数 |
| --- | ---: | ---: | ---: |
| 白球服，C1 背景 | 0.688 → 0.819 | 1.173 → 0.851 | 7.07／9.43 |
| 白球服，F1 背景 | 0.800 → 0.840 | 0.855 → 0.775 | 5.83／7.48 |
| 雪地，F1 背景 | 0.736 → 0.990 | 0.714 → 0.074 | 1.41／2.24 |
| 投影幕中的脸，F1 背景 | 0.538 → 0.623 | 1.047 → 0.860 | 13.15／42.37 |

白球服 C1 和雪地 F1 恢复到预定的投影 0.75–1.25、误差 ≤3，误差改善也超过 0.25 RGB8。参考样本颜色没有变化，结果表明样本的调色前后差值影响了这两处。近邻的 RGB 位置仍让两种白衣保留一定误差。本轮没有进一步把原差值的偏差拆解为缩图、渲染链、编码或量化来源。投影幕 F1 仍不通过，且第八近邻距离的中位数为 42.37，远高于另外三项。本轮只表明换差值仍不足，尚未证明补齐颜色一定能修复投影幕。[本机白衣图板](../../outputs/adaptive-reference-20261113/paired-neighbor-labels-v1/872-1268/comparison.png) · [本机投影幕图板](../../outputs/adaptive-reference-20261113/paired-neighbor-labels-v1/8021-8690/comparison.png)

联合门槛仍为未通过。后续若继续以已知配对作对照，应优先补偿投影幕附近缺少的颜色位置并量化实际出图收益。现有观察来自四组已消费开发内容。已知调色变换用于校准诊断，普通两图的自动编辑识别和候选验收仍待验证。

## 复现

原视觉环境加入仓库根目录、OpenColorIO 2.5.2 和 SciPy 1.16.3 到 `PYTHONPATH`，设置 `OPENBLAS_NUM_THREADS=4`。运行 `python experimental/adaptive-reference-20261113/probe_paired_neighbor_labels.py <新的输出目录>`。每遍复现全部 16 张原近邻成片。新存的 16 张成片、四张图板及报告两次逐件一致，独立从落盘图复算 26 项区域评分。距离按相同缩图与 8 像素棋盘训练区拼合四个来源，对去重的调色前 RGB 样本求第一和第八近邻欧氏距离，再在原固定留出区分别取中位数。报告 SHA256 为 `bf0ed1a7dfa801e8d9298e6c5cdc0b18832c44350469f2bbd9c137ed43e5e547`。[脚本](../../experimental/adaptive-reference-20261113/probe_paired_neighbor_labels.py)
