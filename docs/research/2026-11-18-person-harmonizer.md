# 先保留人物原色，再做前景协调，仍未保住整图风格

本轮从正常两张输入开始，先由 13 号迁移风格，再比较两个方案。直接混合用目标原图的人物和 13 号已经调色的环境，第二个方案对同一混合结果运行 Harmonizer 的六项滤镜。两者都使用固定自动人物概率，人工范围只离线评分。Harmonizer 原为合成图前景协调而训练，利用已调色的目标背景估计人物颜色，没有另外判断参考图的局部编辑意图。见[事前协议](../../experimental/adaptive-reference-20261113/person-harmonizer-protocol.md)和[作者代码及论文入口](https://github.com/ZHKKKe/Harmonizer/tree/48ecd70becbff50ccaf576db0e64212dbc494e26)。

| 开发检查 | 直接混入人物原色 | 再运行 Harmonizer | 门槛 |
| --- | ---: | ---: | ---: |
| 减少人物干扰且保留整图色偏 | 0/8 | 0/8 | ≥6/8 |
| 近中性色背景干扰降幅 | 8.35% | 6.13% | ≥15% |
| 对比度与去饱和 | 7/12 | 10/12 | 12/12 |
| 有意局部调色与人物保护 | 0/4 | 0/4 | ≥3/4 |
| 整图冷色 | 2/6 | 2/6 | ≥4/6 |
| PSBench 台阶／铁塔完整筛查 | 0/2 | 0/2 | 至少一向通过 |

白球服的局部冷色案例中，人物近中性色误差从 13 号的 5.47 降到直接混合的 1.42，以及协调模型的 2.83 个 RGB8 码值。两个方案的背景冷色方向投影都约为 0.709，离预设的 0.75 仍有差距。与参考整图均变冷的例子并看，人物恢复原色后，真实全局冷色也减弱。协调模型在这张图中给球服加了暖色，回看完整控制后仍无法作为默认方案。本机对照见诊断输出中的 `white-jersey-comparison.png`。

真实台阶方向，协调模型使整图误差 15.46 → 13.77，近中性色误差 16.77 → 16.25，仍高于原图误差。铁塔无人，两个方案回退到 13 号输出。两张无人开关图和同图恒等检查通过。

两遍用时 14.61、14.27 秒，各 124 张输出哈希、评分和模型参数一致。从输出像素独立复核 92 项近中性色变化与误差。这些耗时含本轮对照和写盘，未测完整视频。见[数值与模型身份](2026-11-18-person-harmonizer-evidence.json)。

结束此固定前景协调配置。它给白球服减轻了部分冷偏色，也牺牲有效全局冷色，且两张实图均未达到门槛。开发软件未接入、未开启独立画质及视频验收。

复现时在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path` 及 `$env:OPENBLAS_NUM_THREADS = '2'`，用研究 Python 运行 `experimental/adaptive-reference-20261113/probe_person_harmonizer.py <新输出目录>`。12 份固定作者源文件、19,215,729 字节的发布权重、Kornia 0.7.0、OpenCV headless 4.11.0.86 和 Packaging 26.3 均留在本机隔离目录。首次导入发现 Kornia 依赖 Packaging，补齐后严格加载权重并完成两遍。研究沿用作者 CC BY-NC-SA 4.0 条款。本机完整输出在 `outputs/adaptive-reference-20261113/person-harmonizer-v1` 和对应重复目录。
