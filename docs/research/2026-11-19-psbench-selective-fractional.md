# 保留参考的小块颜色后，跨图仍不能找准保色范围

原方法只保留占视觉网格过半的参考标注，鸟照小块保色线索被全部过滤。本次改用每格像素比例和按类归一的余弦匹配。普通候选只看一张参考成片，用近灰与有色像素作弱标记；离线对照额外使用参考作者前后图，标出真实去色与保色范围。两者使用同一个匹配、同一个固定 80% 去色和目标原明暗。[事前协议](../../experimental/adaptive-reference-20261113/psbench-selective-fractional-protocol.md)

| 自动结果 | 去色区响应投影 | 去色区响应误差 | 保色区被改变的幅度 |
| --- | ---: | ---: | ---: |
| 人像 145 ← 鸟照 | 0.508 | 6.62 | 17.77 |
| 鸟照 248 ← 人像 | 0.740 | 2.25 | 5.12 |
| 既有门槛 | 0.75–1.25 | ≤3 | ≤1.5 |

误差与幅度为 RGB8 亮度分离后的色度码值；本轮与早期自动候选一样用完整作者成片定义区域和评分。两张参考均触发，但联合 0/2。12 个普通、全灰、同图和原片空操作检查全部逐像素保持。该空操作只表示此分支未应用局部去色，不能代表完整调色版适用于这些照片。

参考使用作者标注时，鸟照保色像素在 50 个格子出现，但加起来只相当于 4.55 个完整格子，低于事前固定的 5，导致人像方向回退。另一方向的人像标注足够，鸟照去色投影达到 0.756，保色区仍平均改变 5.41，证明不只有参考标签获取问题，跨图对应也不够准确。停止这套固定视觉网格匹配；不降低支持门槛或重选温度。
