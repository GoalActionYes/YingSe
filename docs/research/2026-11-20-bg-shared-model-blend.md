# 混合两代成片仍无法补足换款风格

13 号和扩展第 4 轮在一些区域各有收益，因此检验能否用一个比例把两份成片混起来，既稳住肤色和浅色物体，又保留 Film A 到 Film B 的风格变化。本轮直接复用四组已归档的两种参考背景、两款调色和关态。同一目标的六个状态共用一个比例，不同目标允许用不同的比例。比较对象、强度和开发门槛沿用原实验。[事前协议](../../experimental/adaptive-reference-20261113/bg-shared-model-blend-protocol.md) · [原换款对照](2026-11-20-bg-real-two-look-switch.md)

即使每个目标可以离线选择最有利的比例，四组中最多一组仍有通过可能，低于至少三组的要求。换款投影在连续混合时随比例线性变化。上界用两端较大值再加 RGB8 两张图分别取整可能带来的最大误差，因此覆盖区间内任何比例。下表的幅度以 1 为预期完整响应，最低要求为 0.75。

| 开发案例和关键项目 | 任意比例的保守上界 | 各占一半的实际投影 |
| --- | ---: | ---: |
| 雪地，C1 整图 | 0.732 | 0.439 |
| 浅墙场景，F1 整图 | 0.691 | 0.313 |
| 投影幕场景，C1 整图 | 0.423 | 0.155 |
| 白球服，C1／F1 的衣料框 | 0.330／0.478 | 0.046／0.180 |

白球服整图的保守上界仍允许过线。衣料框是附报区域，显示整图分数不能代表白衣效果。浅墙场景的前额在 C1 和 F1 的上界仍为负，意味着各自的风格方向保持反向。各占一半的实际成片，四组均未通过。最坏保护区换背景差为 27.91 RGB8；白球服所在案例为 4.64，高于单组 1.5。保留全部区域、两种背景与两款换背景的测量。[数值和成片哈希](2026-11-20-bg-shared-model-blend-evidence.json) · [本机白球服图板](../../outputs/adaptive-reference-20261113/bg-shared-model-blend-v1/872-1268/comparison.png)

结束为这两代模型训练一个整图混合比例。上界只约束这两个冻结端点在线性 RGB8 成片空间中的逐图共用比例，区域独立选择、网格参数混合、跨参考状态调整和其他模型端点均未验证。要恢复本例缺少的风格幅度，需要从已有端点之外获得有效信号。原工作台继续用于体验与课程，本轮属于开发诊断。

## 复现

在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path` 与 `$env:OPENBLAS_NUM_THREADS = '2'`，用现有研究环境的 Python 运行 `experimental/adaptive-reference-20261113/probe_bg_shared_model_blend.py <研究输出根目录> <新输出目录>`。读取 48 张锁定的模型成片，逐项核对端点评分。两遍各 24 张成片、四张图板和报告逐字节一致。完整实图保留本机。
