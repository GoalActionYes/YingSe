# 用边缘梯度校正偏色，背景干扰反而增大

试验固定在现有两图输入。用目标、调色参考与 13 号已有输出的局部 RGB 梯度估计各自的综合色偏，计算补偿量后微调 13 号的颜色。仅调节通道比例，限域前保持每个像素的线性亮度。算法借鉴 Gray-Edge 的梯度估计思路，未复现论文完整方法，也未把估计值当作物理光源真值。目标效果和人工人物蒙版只用于评分。见[预先固定的协议](../../experimental/adaptive-reference-20261113/gray-edge-correction-protocol.md)及[Gray-Edge 论文](https://staff.science.uva.nl/th.gevers/pub/GeversTIP07.pdf)。

| 开发筛查 | 实际结果 | 门槛 |
| --- | ---: | ---: |
| 减少人物背景干扰且保留整图色偏响应 | 0/8 | 至少 6/8 |
| 近中性色平均背景干扰 | 增加 19.90% | 至少减少 15% |
| 近中性色单项最大干扰增幅 | 3.69 码值 | 至多 1 码值 |
| 对比度与去饱和响应 | 8/12 | 12/12 |

最严重的是 285–1993 的背景品红对照，近中性色干扰从 13.42 增至 17.11 码值。白球服的绿色背景干预后，校正输出中的球服更偏绿，品红方向也依然可见。六组未干预参考对应的校正结果相对 13 号变化为 0.13–3.30 码值。受控输出在校正限域前的最大亮部越界占 1.67% 通道。两组无人场景仍参与近中性色、对比度和饱和度测量，未计入人物分数。

| PSBench 105 目标 | 整图误差，原图／13 号／边缘校正 | 近中性色误差，原图／13 号／边缘校正 |
| --- | ---: | ---: |
| 台阶人像 | 9.39／15.46／17.17 | 7.60／16.77／18.87 |
| 铁塔 | 11.39／15.03／15.03 | 11.93／15.91／15.77 |

台阶人像的白台阶比 13 号更偏青，铁塔近中性色误差略降，整体变化很小。两个方向均未通过。本配置的边缘统计仍受参考背景影响，其综合色偏不足以确定哪些颜色应迁移，不能作为默认校正。未单独量化肤色，未开展独立自然评价或视频验证。结束这套固定的全图边缘补偿，不继续搜索指数、增益或混合强度。使用额外参考原图的[固定表对照](2026-11-18-psbench-action-rgb-global-map.md)仍保留，软件研究版保持原权重。

两个运行的 44 份 PNG 和结果 JSON 哈希一致。同图、平坦图及已知通道增益三个数学检查通过。独立复核首次读取基线文件字段时把清单对象当成路径，转用其中的路径字段后从图片完成 402 项数值检查，包含空区域和零方向量检查。原运行与输出均未改。见[摘要和哈希](2026-11-18-gray-edge-correction-evidence.json)。

复现时在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path`，使用研究 Python 运行 `experimental/adaptive-reference-20261113/probe_gray_edge_correction.py <新输出目录>`。本机产物为 `outputs/adaptive-reference-20261113/gray-edge-correction-v1` 和 `gray-edge-correction-repeat-v1`。两张检查图 `white-jersey-comparison.jpg`、`psbench-comparison.jpg` 仅留本机。
