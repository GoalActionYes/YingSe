# 等权插值没有解决近中性色的风格衰减

保持 13 号预测出的网格及原来的 XY 平滑。原流程用网格节点的权重对相邻颜色变换做插值。本轮先还原各节点的颜色变换，再等权插值，原来每个节点的颜色矩阵、偏移、80% 强度和最终渲染流程均保留。两种方法均只读目标和参考 RGB。数值正控确认不同权重节点的插值会改变，同权重节点的结果一致。[事前协议](../../experimental/adaptive-reference-20261113/grid-uniform-interpolation-protocol.md)

| 开发检查 | 等权插值结果 |
| --- | --- |
| 背景变化及有意编辑 | 0/4。白球服换参考背景后的最差保护区差由 7.680 升至 7.794 RGB8。 |
| FACD | 0/7。最坏额外近中性色误差为 1.612 RGB8。 |
| Film B | 0/6。两种参考下的焊工近中性色响应仍反向。 |
| 实体色卡 | 只有 1/7 通过色度响应检查，基线为 2/7。 |
| 固定参考内容换款 | 0/7。最差额外整图 MAE 为 0.663 RGB8。 |

固定参考的第 20 组，近中性色度投影从 0.654 升到 0.703，仍未达到 0.75，且其他保护问题继续存在。第 16 组同一目标的两个对应参考槽均出现色度响应下降。渲染权重确实影响颜色，但等权替换无法同时满足风格与保色。停止这项固定替换。以后检查其他渲染环节须先有对应问题的证据。[本机第 20 组对照](../../outputs/adaptive-reference-20261113/grid-uniform-interpolation-20-comparison.png) · [本机白球服对照](../../outputs/adaptive-reference-20261113/grid-uniform-interpolation-v1/background/872-1268/comparison.png)
