# 现有真人成片用真实 RGB 混合，六个方向有两个完整通过

上轮从七份已有成片逐像素选完整 RGB 时，六个方向均未通过。把红、绿、蓝分别取值时有三个方向通过。本轮检查普通混合能实现多少。每个像素选一组非负权重，权重和为 1，RGB 三通道共用。关态逐像素保留目标原片，开态用已知效果离线求欧氏距离最近的混合值。对每份成片检查候选颜色组成的顶点、线段、三角形和四面体内部，再取整导出。两档拍摄灯分别求解。推理时只有两张图的产品无法获得这次使用的答案或状态。[事前协议](../../experimental/adaptive-reference-20261113/gros-rgb-mixture-protocol.md) · [上轮端点和逐通道对照](2026-11-21-gros-channel-envelope.md)

计分范围为整图、双颊及双白幕，评分要求同时检查关态原色、风格响应和冷暖换灯稳定。最近 RGB 混合完整通过 **2／6**，保留最近单一 RGB 的全部通过区域。三组逐通道通过中的 03 ← 02 未能以本次最近 RGB 组合重现完整通过。它的必要条件未超线，不能据此排除其他 RGB 混合。必要下界、取整余量和全部成片分别保存。[完整数值与鉴别范围](2026-11-21-gros-rgb-mixture-evidence.json)

目标 02 取人物 03 参考时，RGB 混合的右脸颊冷／暖投影为 0.79／0.77，响应误差 1.26／1.12 RGB8，两档成片相差 0.49。左脸颊却只能得到 0.15／0.26。在关态必须逐像素等于原片时，即使每像素任选非负权重，含取整余量的左脸颊投影上界也只有 0.26／0.37，低于 0.75。01 ← 03 的冷灯右白幕响应误差下界为 5.76 RGB8，风格投影上界为 0.50。这里的证明只限制这七份成片的混合和本轮的关态条件。[双颊本机成片](../../outputs/adaptive-reference-20261113/gros-rgb-mixture-v1/02-from-03-comparison.png)

## 项目进度与取舍

稳定 1.3 已能演示导入、调色、预览、微调、撤销重做和导出。13 号能执行空间调色，保留作研究体验。现在缺的能力有两项。已具有合适颜色时，软件需要仅凭目标与参考识别正确变化。现有成片没有足够颜色变化时，还需要生成正确方向与幅度。本轮在同一批真人的不同区域分别看到这两个情况。由于至少两个方向存在明确的受限区域，不把混合七份结果当作可覆盖全部问题的升级。优先寻找能补足左脸颊或白幕的颜色响应，再验证自动推断，同时检查白球服换背景、真实冷暖灯和有效风格。正式独立画质、人类自然评价、视频稳定和端到端验收属于后续资格，当前没有符合要求的画质 PR。[课程体验入口](../../00-从这里开始/0-体验与课程交付.md) · [已完成与待验](2026-11-19-quality-handoff.md)
