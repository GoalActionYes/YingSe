# 参考颜色覆盖不足解释了分区拟合的主要退化

固定上轮整图、分区两套配对成片；在目标像素处只检查参考同区域的近似 RGB。使用原拟合缩图、内部蒙版和棋盘像素，最近邻距离不超过既有 6 码值即记为覆盖。目标边缘由两套区域表共同参与，因此要求两边都有覆盖。成片重放只在覆盖内取分区结果，其余取冻结整图结果。作者目标只评分。[事前协议](../../experimental/adaptive-reference-20261113/film-b-regional-support-protocol.md) · [原分区配对](2026-11-19-film-b-paired-regions.md)

| 人物区域 | 覆盖比例（两背景） | 覆盖外人物误差：整图 → 分区（RGB8） |
| --- | ---: | ---: |
| 785–3553 | 49.6%／48.7% | 4.33 → 6.11／3.36 → 5.87 |
| 9483–19432 | 2.5%／1.4% | 1.39 → 5.04／2.26 → 4.99 |
| 872–1268（白球服） | 13.1%／12.0% | 1.08 → 4.43／1.63 → 4.39 |
| 8021–8690 | 13.5%／13.5% | 0.97 → 3.02／1.36 → 3.03 |

八个覆盖外人物结果全部变差；覆盖内按像素汇总误差由 1.20 小幅降至 1.16，仍有三个结果变差，不能把邻近颜色当作可靠的改善开关。回退后，白球服人物误差为 1.15／1.64，最差保护区换背景差 1.30，联合通过；整图配对原本也只有该组通过。回退后的四组为 1/4，低于 3/4；最坏保护区新增误差为 0.119，说明能收回大部分分区退化，尚未扩大通过范围。没有在同一批素材上重选半径或改变拟合。

以上是对颜色支持的离线定位，不证明全部退化都由外推造成。区域和参考前后图是额外输入。结果支持优先避免用狭窄的主体颜色覆盖推断一整套风格；对是否需要实际空间编辑仍须用真实局部调色对照。停止本轮覆盖回退作为修复路径；未更换软件或开展独立验收。
