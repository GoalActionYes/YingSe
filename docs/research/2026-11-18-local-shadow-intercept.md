# 局部颜色截距改善了白球服，但未通过跨场景筛查

上轮用已知范围证明，简单空间偏移可以将冷色留在背景。本轮直接输入目标和参考图，用各个小块里颜色随亮度变化的关系，估计与亮度变化无关的附加色偏。自动分割只用于取得人物和背景的样本。候选沿用原空间色度重分配的渲染、幅度上限和强度，换掉近中性色分箱统计。作者效果和人工蒙版只在生成后的评分阶段使用。见[事前协议](../../experimental/adaptive-reference-20261113/local-shadow-intercept-protocol.md)。

合成色块中的纯色度附加项可准确恢复，比例色变化产生零截距差。首次合成测试给定的偏移含有亮度分量，而该分量会通过斜率改变截距。修正测试输入为零亮度偏移后再开始照片评估，候选公式和开发门槛未改。真实照片中的压黑、混合光源和图像曲线仍会干扰估计。

| 开发对照 | 结果 | 事前门槛 |
| --- | --- | --- |
| 人物抗背景干扰与保留整图色偏 | 2/8 | 至少 6/8 |
| 近中性色平均背景干扰 | 增加 2.99% | 至少减少 15% |
| 近中性色最大干扰增幅 | 0.90 个 RGB8 码值 | 至多 1 个码值 |
| 对比度与去饱和响应 | 12/12 | 12/12 |
| 局部背景冷色与人物保护 | 0/4 | 至少 3/4 |
| 整图冷色与无人负例 | 4/6、2/2 | 至少 4/6、2/2 |
| 台阶人像与铁塔 | 0/2 | 至少一向改善，另一向无明显退化 |

白球服局部对照中，人物近中性色的增量误差从 5.47 降到 **2.99** 个 RGB8 码值，背景冷色方向投影从 0.709 增加到 **0.800**。背景过线，人物误差仍超过 1.5 码值。候选在全部 62 张对照中对 29 张实施校正。两张 PSBench 实图都保留了 13 号结果，台阶方向缺少参考人物块，铁塔方向缺少目标人物。对比度、去饱和及无人负例的通过包含回退结果。

两遍各生成 62 张 PNG，分别用时 9.02 秒和 8.53 秒，图片哈希和除用时外的报告一致。另从出图独立复算 92 项区域度量及回退检查。同图检查通过。见[数值及输出身份](2026-11-18-local-shadow-intercept-evidence.json)。

停止这一固定截距方案，不用本批素材另选小块或增益。白球服上的部分收益说明这项统计确实改变了局部颜色分配，两套控制和实图对照仍无法证明它是可靠的参考调色线索。保留稳定版与 13 号，独立评估和新候选视频验证尚未启动。

复现时在项目根目录设置 `$env:PYTHONPATH = (Get-Location).Path` 和 `$env:OPENBLAS_NUM_THREADS = '2'`。用现有研究 Python 运行 `experimental/adaptive-reference-20261113/probe_local_shadow_intercept.py <新输出目录>`。需要原背景干预、局部冷色开关、PSBench 105 及本机固定分割权重。完整输出留在本机 `outputs/adaptive-reference-20261113/local-shadow-intercept-v1` 和对应重复目录。
