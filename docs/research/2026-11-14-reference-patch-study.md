# 参考局部特征集合对照：查询参与学习，但没有额外调色收益

本轮按预设完成两条新训练：16 个参考特征 token 与重复均值 token。候选平均 RGB MAE 为 11.62198，差于匹配控制的 11.56526，也差于外部 C10 的 10.94288；两套完整门槛均未通过。因此没有新独立素材评估或 App 模型升级，当前 13 号与第 6 阶段功能保持不变。

新增分支的查询和 key 确实得到非零梯度，固定所选权重下压成均值也会改变输出。但这些证据只能说明新机制参与计算，不能证明它读懂了风格、人物／背景关系或语义对应。

## 这次检验什么

[上一轮诊断](2026-11-14-blend-capacity-and-attention.md)排除了固定 101 档单占比预测器方向，也确认当前注意力模块只有一个参考条件 token。单 token 结构不等于整个映射恒定，更不是已证明的失败根因。本次直接检验增加参考特征集合是否带来实际收益，不把结构新颖当成结果。

设计按[训练前协议](../../experimental/adaptive-reference-20261113/reference-patch-protocol.md)及[实施计划](../superpowers/plans/2026-11-14-reference-patch-study.md)固定：当前 13 号纯基模型，加一个 65,664 参数的参考注意力残差分支。共享编码器将参考图缩至 64 后提取特征，再平均到 4×4 共 16 个 token；目标特征提供查询。新分支有 8 个头，输出投影为零初始化，残差加到原注意力输出，再送入原融合／网格／guide／采样链。

| 部分 | 匹配均值控制 | 16-token 候选 |
|---|---|---|
| 参考特征 | 4×4 token 取均值，再重复 16 次 | 保留 16 个不同 token |
| 模块与参数 | 相同 | 相同 |
| 完整初始状态 | 相同，新增输出为零 | 与控制逐张量相同 |
| 数据／顺序／更新 | 1024 条真实训练配对，8 轮／2048 更新 | 完全相同 |
| 推断输入 | 目标 RGB＋参考 RGB | 相同，GT 不进入推断 |

这不是几何对齐或语义区域匹配。没有位置编码，交换参考 token 的顺序不影响注意力输出；参考块中的物体本色仍可能干扰。两组虽然参数相同，但有效机制和梯度不同，也不声称 FLOPs 或有效容量完全匹配。

两组都从当前 13 号开始，没有从 C10 或上一轮失败候选续训。新分支初始化 seed20261126，训练 seed20261124；学习率、优化器、RGB L1＋0.1 梯度 L1、batch4、裁剪等均固定。没有配对辅助损失、合成参考或新的分割组件。C10 只作外部较强基准，不冒充同架构匹配控制。

## 初始条件和训练确实可核对

新增 6 项测试先观察到失败再实现通过，覆盖零残差、参数量、输出投影与后续查询／key 梯度、均值控制的查询不变性、token 排列不变性、无效输入及两套门槛必须同时通过。

两条训练开始前，64 例的启用零残差、禁用分支和相反 token 模式，其原始输出、网格及 PNG 均与当前 13 号完全一致。候选完整初始参数与控制一致；外部 C10 的 64 例原生输出及全部 RGB／参考变化／色度指标在每条训练预检中重现。恢复初始参数后才创建优化器，避免把基准权重带入训练。

两组均完成 8 轮／2048 更新，全部目标顺序摘要一致。仅按第 0–8 轮真实开发 RGB MAE 最低选轮，均选择第 7 轮；没有改选第 8 轮或按色度分数选轮。控制先终止，再启动候选。没有安装新工具、读取新的保留照片或更改冻结协议。

全训练期间，新分支查询／key 最大梯度在均值控制中为 0；候选分别为 0.01357／0.02161。两组 value 和输出投影均有非零梯度。此结果符合不同 token 可供查询选择的计算结构，但不是有用颜色对应的证明。

## 实际效果没有超过匹配控制

| 64 张已用真实开发图指标，越低越好 | 当前 13 号 | 外部 C10 | 均值控制 | 16-token 候选 |
|---|---:|---:|---:|---:|
| RGB MAE | 12.41128 | 10.94288 | 11.56526 | 11.62198 |
| 参考 delta MAE | 15.12363 | 13.44712 | 14.68198 | 14.63959 |
| 暗亮部 Cb／Cr 关系变化误差 | 5.79086 | 4.41337 | 5.01049 | 5.11885 |
| 亮度变化误差 | 10.60790 | 9.62846 | 10.78595 | 10.90344 |
| 对比度变化误差 | 4.37828 | 3.79727 | 4.25963 | 4.16637 |
| 饱和度代理变化误差 | 11.85058 | 11.00663 | 11.75720 | 11.92046 |

候选相对当前 RGB 均值改善 6.36%，但匹配控制已经改善 6.82%；候选反而比控制差 0.49%，比 C10 差 6.21%。不能把相对较早模型的平均收益，归功于保留多个参考 token。

资格要求两套完整 `response_development_gate` 同时通过，分别比较匹配均值控制和 C10，没有临时放宽外部基准条件。关键未通过项如下：

| 检查 | 相对均值控制 | 相对外部 C10 | 原要求 |
|---|---:|---:|---:|
| 平均 RGB 改善 | −0.49% | −6.21% | 至少 3% |
| 改善例数 | 21／64 | 21／64 | 至少 36 |
| 严重退化 | 0 | 3 | 至多 2 |
| 参考 delta 改善 | 0.29% | −8.87% | 至少 5% |
| delta 改善组数 | 13／32 | 12／32 | 至少 20 |
| 暗亮部色度关系改善 | −2.16% | −15.99% | 至少 3% |

此外，候选相对当前的参考 delta 改善只有 3.20%（要求至少 5%），亮度与饱和度代理也变差。相对当前严重退化为 2 例，虽未超过上限，不能覆盖其他失败项。均值控制也没有通过完整门槛，不作为备用升级。

## 难例与固定权重诊断

候选相对当前严重退化的条目是 3026／27824；相对 C10 是 59779／9839／26768。检查了固定前两例 22927／88391、上述全部严重退化，以及相对均值控制最大改善／退化 64217／3026、相对 C10 最大改善／退化 88391／26768。没有删掉难例或额外挑选好图。

全部 64 张七格对照在本机 `outputs/adaptive-reference-20261113/tst100k/reference-patch-audit-v1/`。定性检查仍可见：自行车例未达到 GT 的明显蓝青氛围；婚纱例的明暗／色彩迁移不足；鸡蛋餐盘例仍偏棕；街道例虽比均值控制数值改善较大，仍未充分达到 GT 的红青关系。这些是缩略对照观察，不是盲评或误差因果分析。

另对候选所选第 7 轮做两种固定权重变化，仅用于诊断，不再训练或选模型：

| 所选候选权重下的推断方式 | RGB MAE | 参考 delta MAE | 相对原候选平均输出变化 |
|---|---:|---:|---:|
| 保留 16 个 token | 11.62198 | 14.63959 | 0 |
| token 压成均值 | 11.71577 | 14.74399 | 2.18200 码值 |
| 关闭新分支 | 11.83432 | 14.88637 | 3.27667 码值 |

候选确实依赖新分支及不同 token，但这个固定权重下的变化，不等于重新训练的均值控制，也不能替代完整对照的失败结论。未证明它学到了语义或正确风格，而不是参考物体颜色和其他统计。

## 审计、交接与下一步

审计重新核验 2445 个准备文件、两组完整初始状态及 16 份训练后权重、全部目标顺序和选轮。1280 张逐轮 PNG 的 20 份完整评分表，包含 RGB、参考变化及色度统计，均从图片和 GT 重算一致。当前、均值、候选的 192 张所选原生输出及额外 64 张 C10 输出与保存 PNG 完全一致；另外保存 128 张固定权重诊断图。计分函数实际定义源码一并冻结。232 项研究测试通过。审计通过说明记录可复核，不代表画质通过；[公开数值证据](2026-11-14-reference-patch-evidence.json)保留全部所选评分和完整门槛。

代码入口为实验目录中的 `reference_patch.py`、`train_reference_patch.py` 与 `audit_reference_patch.py`；运行记录见[执行日志](../../experimental/adaptive-reference-20261113/reference-patch-ledger.md)。研究仍依赖本机模型／环境／数据，Git 只发布代码、协议和脱敏数字，不包含照片、GT、权重、特征、环境或会话。仍限非商业课程研究。

本配置和预算没有支持多 token 优于均值条件，因此不继续调 token 数、学习率或 seed 追分，也不把上轮的单 token 结构当作已证实的画质根因。后续优先检查风格表示和训练覆盖是否适合真实迁移，再决定新的固定对照；不能仅凭增加注意力机制就假定模型更懂参考图。

新候选仍需完整通过开发门槛，才冻结新的独立照片验证，并检查原尺寸、视频、速度及实际操作。现有可用软件、默认模型和用户输入方式均不变，整体目标仍未完成。
