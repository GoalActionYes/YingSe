# 已知前景材质能阻止背景物体色被误传

沿用 MLS 两场景的自动背景定位及原色度重放。新增离线旁证：在目标和参考中，作者标注对应的蓝纸、绿纸色度变化须同时支持背景色向。旁证只决定是否应用原候选，数值和位置不随旁证改动。保留两类只改参考背景物体色的负例：上轮的暖调，以及与实拍蓝灯同向的新蓝调。两类负例背景线性亮度误差在 0.40%–0.44%，其他像素与参考原图一致。见[事前协议](../../experimental/adaptive-reference-20261113/mls-foreground-corroboration-protocol.md)和[未加旁证的反例](2026-11-18-mls-auto-anchor-replay.md)。

| 参考条件 | 02 目标色度变化 RMS，未核实 → 有旁证 | 03 目标色度变化 RMS，未核实 → 有旁证 |
| --- | ---: | ---: |
| 同灯换场景 | 0.019 → 0 | 0.015 → 0 |
| 同灯，只把参考背景改暖 | 0.146 → 0 | 0.104 → 0 |
| 同灯，只把参考背景改蓝 | 0.084 → 0 | 0.102 → 0 |
| 实拍换灯 | 0.389 → 0.389 | 0.403 → 0.403 |

前六项保持原图，两个实际换灯输出保留原候选，近中性色误差较 13 号仍低 53.25% 和 50.40%。两组均通过预设条件。这里测的是目标已定义的近中性色区域。两个颜色反例为合成干预；同灯标签只固定灯设置，局部位置和反射仍可能不同。所有场景无真人。

两遍报告、八张输出和两张蓝调参考哈希一致。另逐像素确认六张未接受的成片等于目标原图，两张换灯成片等于未加旁证的结果，独立复算 16 次材质支持判定。见[数据与版本身份](2026-11-18-mls-foreground-corroboration-evidence.json)。

这轮表明，在已知对应的材质区域时，背景之外的颜色可作为额外依据。正常不同内容的照片可能缺少可比较的材质，人物与背景也可能有意分别调色。后续需验证自动得到的独立区域能否保留有效信号，并用局部风格与独立拍摄组检查拒绝条件；不能把本轮直接用作普通照片的白色判定。课程版未升级，独立自然评价和新候选视频验证均未开展。
