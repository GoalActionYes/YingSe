# 保留参考原像素仍未补回白球服的风格

已知参考的调色前后图时，旧拟合先分别双线性缩图。用相同数量的原图单点拟合，可以检查混合邻近颜色是否损失了有效的前后对应。本轮沿用四组实拍开发素材、两种背景、两款风格、三次色表及 80% 强度。评分区域和门槛沿用上一轮。[事前协议与尺寸勘误](../../experimental/adaptive-reference-20261113/paired-native-sampling-protocol.md) · [前轮样本加权](2026-11-20-paired-target-weighting.md)

| 留出区域 | 换款投影，缩图 → 原图单点 | 响应 MAE，缩图 → 原图单点（RGB8） |
| --- | ---: | ---: |
| 白球服，C1 背景 | 0.537 → 0.454 | 1.598 → 1.920 |
| 白球服，F1 背景 | 0.606 → 0.602 | 1.546 → 1.602 |
| 前景人物手臂，C1 背景 | 0.762 → 0.694 | 0.882 → 0.941 |
| 雪地场景近中性色，F1 背景 | 0.858 → 0.942 | 1.961 → 2.305 |
| 浅墙，C1 背景 | 0.866 → 0.798 | 0.503 → 0.435 |
| 投影幕中的脸，F1 背景 | 0.951 → 1.038 | 1.111 → 0.924 |

白球服两项都低于预设的 0.75。手臂丢失原通过项，雪地场景近中性色误差增加 0.344，超过 0.25 RGB8 的退化限制。另两处局部误差下降，浅墙 C1 仍在原通过区间。其余符合条件的区域没有新增超线退化，缺测完整保留。[本机白球服图板](../../outputs/adaptive-reference-20261113/paired-native-sampling-v3/872-1268/comparison.png) · [本机雪地图板](../../outputs/adaptive-reference-20261113/paired-native-sampling-v3/785-3553/comparison.png)

这组结果结束保持样本数的原图单点替换。与此前均匀色样的诊断合看，改变实际观察到的颜色范围比改变同一参考的取样方法更值得检验。单点实验未检验使用全部原始像素，也没有新增参考颜色或识别参考风格。现有软件继续用于体验和演示。

## 复现

在仓库根目录使用原视觉环境，将仓库根目录加入 `PYTHONPATH`，设置 `OPENBLAS_NUM_THREADS=4`，运行 `python experimental/adaptive-reference-20261113/probe_paired_native_sampling.py <新的输出目录>`。原缩图拟合与 16 张归档成片逐像素相同。两遍正式运行的 16 张新成片、四张图板和报告逐件同哈希，另从落盘图独立复算 26 项区域评分。旧加权入口复跑 21 件输出也全部保持原哈希。新报告 SHA256 为 `319197162e537b95411e2dd275be81b4ba4ac8ba3410b325274f3b4bc686e29e`。[脚本](../../experimental/adaptive-reference-20261113/probe_paired_native_sampling.py)
