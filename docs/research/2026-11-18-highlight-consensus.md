# 不同材质的亮部共点未能提供足够的校正线索

白球服和台阶青偏在本轮没有改善。固定筛选在 44 个开发对照中均保留 13 号输出，逐图核对的 PNG 哈希与 RGB 像素完全一致。结束该配置的直接接入，保留全部输出。见[运行前协议](../../experimental/adaptive-reference-20261113/highlight-consensus-protocol.md)和[逐图核查](2026-11-18-highlight-consensus-evidence.json)。

## 检验内容

从目标、参考成片和两图生成的 13 号结果中，各自估计多个材质亮部的共用色向。固定实现用每个小块亮暗像素的色度方向拟合直线，寻找不同方向直线支持的交点。三图均有足够证据时，沿用旧边缘实验的校正模型，保持线性亮度并限制色向改动。这里借用了漫反射与镜面反射混合的成像模型。调色后的照片、漫反射材质、物体交界和多光源仍可能破坏假设。见 [Shafer 成像模型](https://onlinelibrary.wiley.com/doi/10.1002/col.5080100409)。

合成图中，四块颜色不同的材质混入同一种亮部色向，精确恢复已知线性归一化色度 `[0.39, 0.34, 0.27]`，四块都支持该估计。移除该亮部成分，仅改变漫反射强度时，算法返回无证据。

## 开发对照

| 项目 | 实际结果 |
| --- | --- |
| 三个输入均有足够证据 | 0/44 |
| 各角色有证据的评估调用数 | 目标 7/44，参考 12/44，基线输出 5/44 |
| 人物抗干扰与有效色调均通过 | 0/8 |
| 近中性色平均背景干扰 | 7.196 → 7.196 个 RGB8 码值 |
| 对比度与去饱和门槛 | 12/12，均来自回退 |
| 台阶人像近中性色误差 | 16.77，原图 7.60 |
| 铁塔近中性色误差 | 15.91，原图 11.93 |

目标在多个参考变体中重复出现，角色覆盖率统计的是评估调用。白球服的三个角色在两个背景换色方向都未满足固定共点条件。两方向 PSBench 反例中的台阶与铁塔也都缺少足够证据。全图对比度、去饱和和剪切情况继承基线。自然素材上校正实际起效时的质量仍未知，因此不据此推断改色会有收益，也不在这批照片上放宽门槛。

两次生成各约 6.7、6.2 秒，包含开发小图读取、计算、评分和写盘。除用时外报告一致，44 张输出在两遍之间及与冻结基线字节一致。没有消费独立保留素材，未开启新候选的软件或视频验收。

共用脚本由参数选择校正函数。用默认旧边缘方法重新运行，其 44 张输出与原报告图像字节一致，除脚本哈希外报告完全相同。

## 复现

在研究环境中运行 `python experimental/adaptive-reference-20261113/probe_highlight_consensus.py <新输出目录>`。需要原有背景对照和 PSBench 105 本机文件。两次输出保留于 `outputs/adaptive-reference-20261113/highlight-consensus-v1` 和 `outputs/adaptive-reference-20261113/highlight-consensus-repeat-v1`。
