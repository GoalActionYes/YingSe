# 参考色度空间加权未减轻跨场景偏色

同一参考图上，空间分布较广的颜色也可能来自草地、雪地或背景物体。本轮检验按色度的空间覆盖加权能否减少这类影响。候选只调整参考图的 Cb／Cr 直方图，空间网格渲染、目标特征、参考亮度和调色强度均使用既有设置。与早期人物分区方案的区别是权重只由参考 RGB 的空间分布确定。见[运行前协议](../../experimental/adaptive-reference-20261113/reference-chroma-spread-protocol.md)。

在已消费的六组素材上，生成 42 张候选输出，另逐像素复现 42 张基线。人物区域的 8 项换色对照中，有 0 项同时达到减轻背景干扰和保留整图色调的条件，要求至少 6 项。近中性区域的平均干扰增加 0.94%，最差单项增加 0.25 码值。对比度与去饱和两个整图对照共 12 项，其中 11 项保留了规定范围内的响应，要求全部通过。原参考输入的候选与基线全图差为 0.128–0.658 码值。

已复核 84 张输出的文件哈希，从保存像素独立复算人物和近中性区域误差、整图控制投影及通过条件。查看六组原参考和绿向干预的并排图时，室内墙面、雪地与球服的背景换色影响仍可见。粉向和其余对照也完整保留。此处的阈值只用于开发筛查，图片为已有素材上的受控干预。见[逐例数值](2026-11-18-reference-chroma-spread-evidence.json)。

停止本固定配方。空间覆盖统计在这一测试中未提供足以改善画面的信号，后续若需讨论相近方法，应先给出独立于颜色覆盖范围的参考线索。这个小规模试验仅涉及一种加权和一个冻结模型。当前没有可交付的画质升级，完整目标仍待完成。
