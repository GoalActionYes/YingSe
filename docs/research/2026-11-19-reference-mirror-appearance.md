# 参考左右翻转会改变成片，平均两个方向仍未通过

目标图和参考颜色统计保持不变，只将参考外观分支收到的图左右翻转。测试冻结扩展第 4 轮在 80% 强度下的成片差，再比较两个方向的像素均值与原扩展版。只对已有整图风格开发素材解释结果；左右位置本身可能是局部编辑的一部分。见[运行前协议](../../experimental/adaptive-reference-20261113/reference-mirror-appearance-protocol.md)。

| 开发套件 | 单张成片左右翻转最大平均差（RGB8） | 原扩展版 → 两方向平均 |
| --- | ---: | --- |
| 背景换色与有意编辑 | 2.54 | 0/4 → 0/4；最差保护区差 26.88 → 26.94 |
| FACD | 1.45 | 0/7 → 0/7；相对 13 号最差近中性色新增误差 14.61 → 14.95 |
| ARRI Film B | 1.22 | 0/6 → 0/6 |
| 实体色卡 | 0.58 | 响应合格区域仍为 2；无编辑态最差色度误差 6.74 → 6.86 |

背景组中，三个较轻案例的最差区域差分别由 10.61 降至 10.24、6.31 降至 5.31、4.57 降至 4.34。最差的一组反而略升。最大逐通道差 8 码值，出现在背景组。因为两臂使用同一参考统计张量，可以把这次成片差定位到外观分支接收的空间布局变化。结论限于本轮翻转和现有开发样本，不能把所有背景误染都归结到方向。

两次运行各保存 72 张成片、18 张对照板和一份报告，共 91 件，哈希逐件相同。另由落盘 PNG 与冻结扩展版重算了 72 份成片差，检查了同图保护。四套均未通过，停止镜像平均方案。没有产品改动，也没有新的独立人体肤色或视频验收。若后续尝试外观分支的新表示，应验证它能区分应迁移的区域风格与构图变化；单纯消除左右方向无升级依据。
