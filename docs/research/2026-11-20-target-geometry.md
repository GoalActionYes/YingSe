# 保留目标宽高比未解决跨场景偏色

原有 13 号可以输出原尺寸成片，但生成空间网格时仍把目标拉到正方形。为区分几何拉伸与颜色判断的问题，本轮只改变目标空间编码及其坐标映射。将目标居中镜像填充到正方形，按原比例编码和渲染，再取回原范围。颜色统计、参考图、权重和 80% 调色强度照旧。[事前协议](../../experimental/adaptive-reference-20261113/target-geometry-protocol.md) · [此前原尺寸结果](2026-11-18-psbench-shared-local.md#原尺寸复查)

| 开发案例 | 原版 → 保持比例 | 结果 |
| --- | --- | --- |
| 竖幅窗边肖像，1080 × 1920 | 近中性色误差 37.45 → 37.83，整图响应投影 0.068 → 0.051 | 近中性色偏差上升，往作者调色方向的响应减弱。 |
| 横幅户外拼图，1440 × 1080 | 近中性色误差 15.63 → 15.40，整图响应投影 −0.363 → −0.352 | 误差下降约 0.23，低于 1.00 门槛，整图响应仍反向。 |
| 混合光照片，1024 × 702 | 肤色局部编辑范围内色度投影 0.012 → 0.010，误差 19.23 → 19.27 | 几乎没有迁移作者的局部编辑。未编辑区及其近中性色的第 95 百分位误差维持约 0.72。 |

照片及作者结果均已用于开发。前两项作者编辑的风格方向相近，未确证为同一预设。最后一项使用同一张照片的镜像参考及已知作者编辑，只用于隔离局部改色响应。近中性色及人工编辑区域分别用于离线测量。色度投影为 1 代表沿指定方向的响应幅度等于预期。[数值与成片哈希](2026-11-20-target-geometry-evidence.json)

三例均未过门槛，停止固定镜像填充。它能改变成片，但没有在这些照片上同时减少偏色和保留风格。本轮只检验这一种目标几何处理，参考分析和其他几何表示不在比较范围。工作台继续使用原版。

固定检查通过。两方向的基线与已登记的 PSBench 成片哈希相同，PlayRaw 两份原版与前次镜像成片哈希相同。传入方图时，两条路径逐像素相同。同图保持检查也满足逐像素相同。首次运行生成成片后，在记录脚本哈希时因字符串路径报错。修正后在两个新目录重跑，八张 PNG 和数值报告逐字节一致。

在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path`，调用现有研究环境的 Python 运行 `experimental/adaptive-reference-20261113/probe_target_geometry.py <新输出目录>`。本机输出为 `outputs/adaptive-reference-20261113/target-geometry-v2` 及 `target-geometry-repeat-v2`。仅脚本、协议、结果汇总和哈希进入 Git。
