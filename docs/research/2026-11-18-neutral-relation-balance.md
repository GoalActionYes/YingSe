# 两图近中性色重分配未通过画质筛查

本轮从正常目标与参考图提取近中性色关系。由自动分割取人物和环境，在相同亮度箱里比较色度，再把 13 号结果的两区域色差向参考关系拉近。以目标人物概率相对其全图均值来分配调整。浮点渲染保持原逐像素亮度和整图平均 RGB。算法未读取局部标签、原始参考照片或人工蒙版。评分使用原开发对照和作者效果。见[事前协议](../../experimental/adaptive-reference-20261113/neutral-relation-balance-protocol.md)。

| 配对 | 人物近中性色增量误差，13 号 → 候选 | 背景方向投影，13 号 → 候选 | 整图冷色投影，候选 |
| --- | ---: | ---: | ---: |
| 785–3553 | 2.300 → 1.688 | 0.415 → 0.474 | 0.526 |
| 9483–19432 | 2.252 → 1.805 | 0.380 → 0.464 | 0.638 |
| 872–1268，白球服 | 5.465 → 5.467 | 0.709 → 0.709 | 0.865 |
| 8021–8690 | 2.930 → 2.930 | 0.464 → 0.464 | 0.783 |

误差单位为 RGB8 码值。前两组有所改善但未过背景和人物门槛，合计 0/4 通过。白球服案例的基础和局部版本均触及蓝通道 −8 码值的校正上限，两版采用相近的校正，局部操作的额外偏色几乎保持原样。因果解释限于这个固定配置。8021 及两组无人照片没有足够的目标人物中性色样本，回退后与当前输出逐像素一致。整图冷色仍是 4/6 通过。同图恒等检查通过。

台阶人像与铁塔的双向写真都回退。人像方向缺少参考人物支持，铁塔方向缺少目标人物支持，两个输出与 13 号相同。人像近中性色误差仍为 16.77，铁塔仍是 15.91，均未达到真实开发对照门槛。这暴露了当前特征的适用范围，包含无人目标或无人物参考的情形无法从此规则获得改善。

首次运行保存了全部图像，结果写盘时因 NumPy 整数无法 JSON 序列化退出。计数显式转换成 Python 整数后，按原门槛重跑两次。之前及之后的 20 张结果哈希逐一一致。两次完整用时 5.05、5.25 秒，含模型加载、分割、调整、写盘和评分。核对回退结果、浮点校正向量、量化后亮度差并独立复算 48 项受控区域数值。见[数值与哈希](2026-11-18-neutral-relation-balance-evidence.json)。

固定两图方案未达标，停止当前配置。白球服的先前离线重分配仍可展示在已知编辑范围时的潜在改善。自动候选仍需建立可靠关系，并涵盖无人、人物／环境不共享中性色及有效全局色调等情况。无软件改动、独立验收或产品 PR。见[已知开关的重分配](2026-11-18-local-chroma-redistribution.md)。

在现有研究环境运行 `python experimental/adaptive-reference-20261113/probe_neutral_relation_balance.py <新输出目录>`。需要固定开关报告、PSBench 105 图及本机分割权重。两遍结果仅位于本机 `outputs/adaptive-reference-20261113/neutral-relation-balance-v2` 与相应重复目录。
