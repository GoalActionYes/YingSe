# 亮度和色度分别混合后，128 张结果仍等于扩展版

在扩展版与 C10 之间分别拟合亮度权重和色度权重。候选通过正常目标、参考和两份成片计算八项统计量来调整权重。常数对照只训练两个固定权重。两套使用相同 64 个目标、256 份已消费训练配对、冻结主干、训练目标及更新预算。拟合使用整图 RGB 与同目标换参考响应监督，开发作者效果在两套 RGB8 成片保存之后才读取。见[运行前协议](../../experimental/adaptive-reference-20261113/adaptive-component-mixture-protocol.md)。

| 方法 | 64 张平均 RGB MAE | 32 组换参考变化 MAE | 换参考相对 C10 改善 |
| --- | ---: | ---: | ---: |
| 扩展训练第 4 块原结果 | 10.018 | 12.592 | 18/32 |
| 亮度／色度常数权重 | 10.018 | 12.592 | 18/32 |
| 亮度／色度参考自适应权重 | 10.018 | 12.592 | 18/32 |

两个可调权重从混入 10% C10 开始，拟合结果均接近只使用扩展版。在开发图上，常数的亮度与色度权重约为 0.525% 和 0.517%。自适应的亮度为 0.482%–0.496%，色度为 0.508%–0.513%。裁切与量化前单通道最大变化分别约 0.188 和 0.180 码值。两套各 64 张成片均逐像素等于原扩展结果。因此相同的均值来自相同的量化结果，原来两例严重退化也继续出现。

训练目标在这批由原主干已用过的配对上倾向扩展端点。两组实现与拟合可复现。证据尚无法区分是训练素材上缺少 C10 的真实互补收益、八项统计量无法找到互补场景，还是固定线性权重与正则的限制。上轮用作者真值选择共同色调和差分的收益仍成立，本轮说明该训练目标和观测信号没有把它带到普通两图输出。未以开发结果重选样例、调整权重初始化或去掉惩罚项。见[离线重组](2026-11-18-paired-grade-components.md)。

两遍用时约 37.27 和 34.02 秒，范围含模型加载、640 次固定前向、CPU 全批拟合、成片写盘与评分。开发两模型的 128 张冻结端点逐像素复现，两候选的 128 张图及训练记录复跑一致。另用独立坐标计算重算输入统计、系数、像素、RGB 和 paired MAE。数值未过原双门槛，没有接入软件、独立评估或视频。见[数值与哈希](2026-11-18-adaptive-component-mixture-evidence.json)。

复现时运行 `python experimental/adaptive-reference-20261113/probe_adaptive_component_mixture.py <新输出目录>`。依赖原训练覆盖审计、已准备图像和冻结模型。本机两遍输出位于 `outputs/adaptive-reference-20261113/adaptive-component-mixture-v1` 和对应重复目录。
