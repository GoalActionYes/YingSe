# 真实参考前后变换：平均收益明显，三个反例仍未过门槛

本轮完成固定64个不同训练目标的额外原图诊断。用参考原图与调色后参考估计同一全局guide变换，再迁移至目标，平均RGB误差12.74628→6.47871（下降49.17%），57/64改善超过0.1。但出现3例严重退化，高于协议上限2，监督来源推进条件失败。**不据此启动预测器训练，不接入软件，不放宽门槛。**

这是扩展训练部分中新增可用前后配对的诊断，不是旧开发64图，也不是独立样本；不能与旧开发均值12.41130横向比较。推断额外获得参考原图，正常产品仍只有目标和参考两张图，不能把49.17%写作产品收益。固定guide来自历史受过训练GT监督的模型，也不是整个系统从未接触GT。

桥接旧69006记录的基线、参考跨块重建、目标迁移三张图，均与旧存档逐像素一致。首次v1检查拒绝基线差异，原因是新入口在GPU归一化而旧入口在CPU归一化；v2恢复旧运算顺序后严格检查通过，未改容差，v1失败产物保留。64项密集设计／原生输出最大差均不超过原协议1码值，不把这一项称逐浮点一致。

## 结论与下一步

较旧75条结果，扩展范围仍支持额外参考原图含有有用的变换信息；但同一参考映射在另一场景直接应用并非可靠监督。按协议暂不训练此来源的预测器，也不恢复旧GT合成参考或残差头。不能将平均收益抹去，也不能忽略三个反例。

下一项应先区分：同一全局RGB函数是否能同时解释参考前后和目标前后，还是当前有限函数／颜色覆盖导致外推失败。可在已使用64条上检查共享RGB的目标冲突与点映射下界，先固定测量规则，不换网络、不调整严重退化门槛。这项诊断仍不能证明理想用户风格，也不使用其结果挑图上线。完整目标保持未达成。
