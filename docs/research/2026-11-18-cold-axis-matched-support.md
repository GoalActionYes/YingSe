# 匹配亮度与正交颜色仍无法可靠估计局部冷调

离线对照证明，已知目标答案时，沿一个冷暖方向就能修复四组受控人像。此次只用目标图与参考成片，在各自的人物和背景区域找亮度与正交颜色相近的分组，用共有分组估计需要补多少冷色。已知未裁切的加性色偏不会改变这两项分组依据，但不同照片的同组像素仍可能来自不同物体。候选对已有的 13 号结果沿同一冷暖方向追加修正，独立保留人物和背景的估计量。见[事前协议](../../experimental/adaptive-reference-20261113/cold-axis-matched-support-protocol.md)与[单轴离线对照](2026-11-18-local-cold-axis-bound.md)。

| 检查 | 结果 |
| --- | --- |
| 只换背景时减轻人物偏色，同时保留整图着色 | 0 / 8 |
| 近中性色背景干扰 | 平均增加 2.08%，最差增加 1.02 个 RGB8 码值 |
| 对比度及去饱和响应 | 9 / 12 |
| 局部背景冷色与人物保护 | 0 / 4 |
| 整图冷色、无人局部空操作 | 6 / 6、2 / 2 |
| 台阶人像和铁塔真实编辑 | 0 / 2，两向均回退到 13 号 |

白球服案例只有两组可比较的人物颜色，低于预设的三组支持要求。候选回退，人物近中性色的局部误差仍是 5.47 个 RGB8 码值。8021–8690 的背景方向投影从 0.464 升到 0.969，但人物近中性色误差从 2.93 增到 4.09。这组反例表明，只看背景是否更接近会漏掉人物退化。两张 PSBench 成片保留 13 号，没有取得实图改善。

两遍运行的报告和 62 张出图哈希一致。同图恒等与合成位移检查通过。另从落盘 PNG 独立复算 148 个背景与局部区域的变化、误差或投影。见[验证摘要](2026-11-18-cold-axis-matched-support-evidence.json)。

按预定门槛结束固定颜色分组的方案。此前按亮度比较近中性色、用局部亮度截距也没有解决两图间材质差异。后续需要可检验的同材质或同编辑操作证据，才值得尝试估计该调哪里和调多少。继续保留课程版、已知范围的正对照和普通输入的反例。当前没有新产品候选，独立自然评价及新候选视频验证尚未开展。

复现时在仓库根目录设置 `PYTHONPATH`，用现有研究环境运行[脚本](../../experimental/adaptive-reference-20261113/probe_cold_axis_matched_support.py)并传入新输出目录。依赖已有背景干预、局部开关、PSBench 105 和固定分割权重。两遍本机输出为 `outputs/adaptive-reference-20261113/cold-axis-matched-support` 及对应重复目录。
