# 自动肤色权重保住胸口响应，并减少实拍环境变色

已知《Cuckoo》原参数蒙版未能有效作用于胸口，取消蒙版又明显改变了树皮和草地。本轮只替换选区。使用现有映色研究中已冻结的旧肤色权重生成器，从关态 RGB8 自动定位皮肤，将已知全量色相输出与关态之差按权重回混。压力对照仅给定位器看全量色相输出，回混仍使用同一关态和同一已知变化。两张定位输入来自同一原片。人工登记框只参与评分。其中衣物框在运行前追加，用来区分皮肤与整个人物。[事前协议](../../experimental/adaptive-reference-20261113/cuckoo-skin-support-protocol.md) · [原蒙版与全量对照](2026-11-20-darktable-cuckoo-mask-coverage.md)

| 区域 | 原作者蒙版 | 全量作用 | 原图定位 | 全量图定位 |
| --- | ---: | ---: | ---: | ---: |
| 胸口 | 0.00 | 4.14 | 4.14 | 4.14 |
| 脸颊 | 0.00 | 4.50 | 4.50 | 4.50 |
| 浅灰树皮 | 0.00 | 2.50 | 0.00 | 0.00 |
| 草地 | 0.00 | 16.00 | 0.00 | 0.00 |
| 衣物 | 0.00 | 2.01 | 0.00 | 0.00 |

数值为原关态到试验图的色度变化中位数，单位为 RGB8 码值。两种定位均通过胸口至少 2、树皮、草地、衣物各不超过 1.5 的门槛。胸口的权重中位数由作者蒙版的 3.14% 提高至 100%。衣物的局部边缘仍有少量触及，两种定位分别有 10／476 和 9／476 个衣物测量像素改动，P95 为 0。脸颊同样被施加了已知编辑，说明皮肤识别能限定到皮肤，但没有表达作者只想调整部分皮肤的意图。[主要定位成片](../../outputs/adaptive-reference-20261113/cuckoo-skin-support-v1/skin_on_original.png) · [颜色变化后定位](../../outputs/adaptive-reference-20261113/cuckoo-skin-support-v1/skin_on_uniform.png)

该结果提供了既有皮肤模型能在这张照片上替代纯色相选区的证据。当前方法借用了同张图经过作者操作后的全量变化；普通参考调色需要另外判断编辑是否应迁移及其方向。下一次进入普通两图开发验证时，须同时保留远处人物、真人与屏幕同框、不需修正和确实要迁移颜色等现有对照。正式自然评价、独立画质及视频均待开展。[既有真人和屏幕反例](2026-11-19-skin-person-context.md)

首次检查因旧权重上界为 `1.0000001` 而退出。允许 `1e-6` 的插值舍入余量并裁至 0–1 后，两遍各九件产物哈希一致，从四张 PNG 和掩膜独立复算 20 组区域读数，零权重像素和无编辑输入逐像素保持。正式报告 SHA256 为 `a66f299951cc11695bc2292281f47b8016a83416ebac01634ee24b1039973f99`。设置仓库根目录为 `PYTHONPATH`，使用既有视觉研究 Python 执行 `probe_cuckoo_skin_support.py <研究输出根目录> <新输出目录> <旧肤色保护运行时的 site-packages>`。媒体和权重留本机。[复现脚本](../../experimental/adaptive-reference-20261113/probe_cuckoo_skin_support.py)
