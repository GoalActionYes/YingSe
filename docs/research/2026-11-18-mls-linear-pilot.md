# MLS 线性原片确认整图响应与材质响应分离

强蓝灯 JPEG 预览缺有效样本后，按[事前协议](../../experimental/adaptive-reference-20261113/mls-linear-pilot-protocol.md)固定场景 02、03、标准灯和最弱蓝灯。仅从官方 ZIP 定向读取目录及 4 张 1157×950 的 16 位 PNG，累计请求 20,081,325 字节。所有照片共同乘线性增益 4，再使用 sRGB 编码曲线。保持相机 RGB 色轴，未进行显示色域校准。增益未造成任何像素截断。两组换灯图的明度梯度相关度为 0.558、0.547，均达到原配准代理门槛。整图共同有效覆盖分别为 99.79% 和 99.0%，整图、近中性色、蓝纸和绿纸共八个范围全部合格。见 [MLS 官方发布](https://github.com/Visillect/mls-dataset)。

| 目标范围 | 同灯换场景色度变化 RMS，02／03 | 换灯换场景方向投影，02／03 | 同场景换灯方向投影，02／03 |
| --- | ---: | ---: | ---: |
| 整图有效区 | 0.091／0.109 | 0.557／0.843 | 0.760／0.647 |
| 近中性色代理 | 0.100／0.164 | 0.265／0.210 | 0.319／0.219 |
| 蓝纸棱柱 | 0.098／0.139 | 0.231／0.265 | 0.317／0.229 |
| 绿纸方块 | 0.077／0.094 | 0.848／0.879 | 1.054／0.692 |

同灯换场景的八个范围均超过 0.05 色度变化门槛。换灯时两种参考关系中的整图和绿纸均通过色度门槛，近中性色和蓝纸均未通过。其中近中性色的实拍换灯 RMS 为 0.438／0.430。原误差并非因真值无变化，整体随灯变化也没有保证每种材质响应足够。测试能观察到同一灯设置下的输出差异，物体位置、局部反射等影响仍可能存在，不能把变化全归因于背景物体颜色。两组实验室场景无真人，仍属于开发诊断。

两遍报告、4 张编码输入和 6 张 13 号输出哈希一致。重算 24 个区域的色度指标与门槛，复核 4 个原始成员 CRC 及两个前置单臂输出。见[数值与身份](2026-11-18-mls-linear-pilot-evidence.json)。本机对照图位于 `outputs/adaptive-reference-20261113/mls-linear-pilot/comparison.jpg`。

这批样本可以用于下一轮有针对性的诊断。先用离线已知材质身份比较跨场景的真实换灯变化是否足够稳定，再决定是否有理由预测材质级响应。如果连已知身份也不能预测，继续靠自动分割匹配这两种纸块无助于解决本问题。课程版未修改，独立自然评价和产品验证仍待开展。

复现先用[下载脚本](../../experimental/adaptive-reference-20261113/fetch_mls_linear_pilot.py)读取固定成员，再在仓库根目录设置 `PYTHONPATH`，用现有研究环境运行[色度基线](../../experimental/adaptive-reference-20261113/probe_mls_linear_pilot.py)，传入原片目录、材质目录和新输出目录。本机原片及成片不随 Git 上传。
