# 新增两位光谱供体后，三位测试人像的六组换光均达标

将 UMINHO-HSFD 的 222 和 226 各 128 个有效脸颊点加入已有 ISSA 样本，固定 CQS 矩阵、八近邻、光源和 80% 强度。253、282 整人继续保留作测试，另整人留出 235。三位测试对象的光谱均未进入校准。关键问题是，补上先前稀疏的颜色范围能否降低原失败侧脸颊误差。见[事前协议](../../experimental/adaptive-reference-20261113/skin-spectral-donors-protocol.md)及[光谱资料](https://doi.org/10.6084/m9.figshare.c.7163569)。

| 人像和方向 | 原校准两侧中位误差 | 加供体后两侧中位误差 | 联合门槛 |
| --- | ---: | ---: | --- |
| 253，D65 → A | 1.67／0.67 | 0.67／0.67 | 通过 |
| 253，A → D65 | 1.67／0.67 | 1.00／0.33 | 通过 |
| 282，两个方向 | 0.33／0.33 | 0.33／0.33 | 通过 |
| 235，两个方向 | 0.33／0.33 | 0.33／0.33 | 通过 |

单位为 RGB8 码值。六组的脸颊 90 分位误差均不高于 1.33，过渡带通过，灰块最大误差为 0.33–0.67，所有非肤色控制与原矩阵逐像素一致。235 原校准已达标，加入供体后测得的中位数和 90 分位数相同。见[原失败例日光转暖光](../../outputs/adaptive-reference-20261113/skin-spectral-donors/253-D65-A.png)、[反向对照](../../outputs/adaptive-reference-20261113/skin-spectral-donors/253-A-D65.png)和[新留出人像](../../outputs/adaptive-reference-20261113/skin-spectral-donors/235-A-D65.png)。

253 原失败侧两方向均有 2,304 个有效核心像素。按上一轮固定的距离阈值，覆盖从 0 分别增加至 351 和 338 个。所有核心像素都使用了至少一个新供体点，改善发生在远多于通过距离阈值的像素上。距离仍只用于覆盖诊断，未参与出图或门槛选择。

本阶段通过的是已知两种标准光源、人工登记脸颊和同设备光谱重建的局部对照。现在有依据验证自动肤色定位，并在普通人像中查真实墙面和衣物是否会误改。普通两图的光源判断、风格迁移以及产品验收仍需独立验证。

两次运行的六张图和数值报告逐字节一致。另用源光谱及落盘 PNG 复核脸颊、过渡带和非肤色像素。在现有视觉研究环境加入本机 SciPy 解码目录，运行 `probe_skin_spectral_donors.py <光谱校准目录> <人像资料目录> <上轮成片目录> <新输出目录>`。见[证据文件](2026-11-19-skin-spectral-donors-evidence.json)。
