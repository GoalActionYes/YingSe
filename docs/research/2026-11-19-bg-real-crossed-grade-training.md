# 交叉训练减少了部分背景变化，也削弱了应保留的编辑

同一参考人物分别使用原背景和替换背景，每种背景都施加相同的无编辑、冷调、暖调与提高对比度操作。参考与目标使用不同人物。用 12 组拟合素材、四组不进入拟合的开发案例，比同样 96 条训练行的两个固定岭回归臂。基线重复原背景，候选用等数原背景和替换背景。两个方法都只从两张 RGB 的分位数预测冷暖与对比度。见[事前协议](../../experimental/adaptive-reference-20261113/bg-real-crossed-grade-training-protocol.md)。

| 开发案例 | 冷调时人物换背景差，基线 → 交叉 | 原背景有意冷调投影，基线 → 交叉 |
| --- | ---: | ---: |
| 785 | 3.83 → 3.67 | 1.00 → 0.83 |
| 9483 | 5.28 → 1.01 | 0.75 → 0.67 |
| 872 白球服 | 1.30 → 0.01 | 0.60 → 0.32 |
| 8021 | 8.90 → 6.10 | 0.94 → 0.85 |

背景差异以 RGB8 码值计。两种训练的四组联合门槛均未通过。白球服在原背景条件下只剩预期冷调方向的约 32%，且 785 换背景的对比度条件下，相对目标的整图误差从 0.58 升到 9.68，超过退化上限 2.00。两项反例说明输出更稳定可能同时压掉有意编辑。见[白球服出图](../../outputs/adaptive-reference-20261113/bg-real-crossed-grade-training/872-1268.png)和[对比度反例](../../outputs/adaptive-reference-20261113/bg-real-crossed-grade-training/785-3553.png)。

结束这一固定分位数岭回归方案。结果只回答这种特征与拟合组合能否利用交叉标签，不外推到其他结构。数据是既有背景替换开发素材，已知编辑由程序施加，保留作反例和后续监督对照。没有形成自然画质、视频或软件升级证据。

两次运行的四个成片图板和报告逐字节一致。用落盘全分辨率图复算 64 个渲染结果的整图误差及编辑投影。使用已有视觉研究环境和仓库根目录 `PYTHONPATH` 运行 `probe_bg_real_crossed_grade_training.py <新输出目录>`。见[全部误差和输出身份](2026-11-19-bg-real-crossed-grade-training-evidence.json)。
