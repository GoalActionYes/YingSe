# 闭合四边形可排除一张显示器人脸，投影幕仍然误触

已有场景分割把投影幕里的人当作人物，外扩所标的屏幕区域也没有圈到脸。这轮使用独立的原图边缘线索。固定亮度边缘检测及对面积、边长和角度的要求，提取闭合凸四边形，在其内部关闭已有肤色修正。两臂均采用同一固定模拟偏色，让误改能直接在成片中比较。评分区域和图像编号不参与几何判断。[事前协议](../../experimental/adaptive-reference-20261113/screen-quadrilateral-protocol.md) · [既有显示类别实验](2026-11-19-screen-face-transfer.md)

| 实拍屏幕脸 | 旧肤色触及 | 加入几何排除 | 通过触及不超过 1% |
| --- | ---: | ---: | --- |
| 8021 投影幕 | 100% | 100% | 否 |
| 479248 电视 | 30.77% | 30.77% | 否 |
| 340894 电脑显示器 | 100% | 0% | 是 |
| 342367 电视 | 100% | 100% | 否 |

触及率统计区域中修正权重大于 0.05 的比例。340894 的显示器有明显完整边缘，几何方法能覆盖其中的脸，补上了语义外缘规则在该图的漏检。语义外缘曾成功排除 479248 的电视脸，几何法在该图找到的四边形没有覆盖脸。8021 与 342367 没提取到满足条件的闭合四边形。六个实拍直接皮肤框的高权重覆盖都保持，浅墙、雪地、白球服无触及。合成遮挡控制未提取到四边形，前景前额仍被保留，这一结果无法证明已有方法在屏幕被真人遮挡时能区分前后关系。[本机电脑显示器三联图](../../outputs/adaptive-reference-20261113/screen-quadrilateral-v1/340894.png) · [本机投影幕三联图](../../outputs/adaptive-reference-20261113/screen-quadrilateral-v1/8021-8690.png)

四个显示脸只通过一个，关闭仅靠当前闭合四边形作排除的路线。即使把语义外缘和四边形合用，8021 和 342367 仍缺有效线索。若以后有可信的遮挡或显示平面信息，先核对它能否补足这两个反例并保住现场人物。屏幕误判属于局部修正的退化检查，解决它仍不足以证明整体参考风格迁移有效。
