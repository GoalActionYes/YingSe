# 补足拟合颜色后，白球服的换款幅度可以恢复

旧配对实验已拿到参考的编辑前后图，白球服仍然迁移不足。这轮固定三次色表、正则化与 80% 强度，比较原配对参考、均匀的 24³ 个 RGB8 色样，以及目标画面的前后对应。后两臂均有已知 Film A 和 Film B。目标拟合臂只用棋盘一半拟合，余下像素评分，其他方法在同一留出范围对照。[事前协议](../../experimental/adaptive-reference-20261113/paired-operator-support-protocol.md) · [原局部反例](2026-11-20-bg-real-paired-two-look.md)

| 白球服场景，83 个白衣留出像素 | 换款投影 | 响应误差 RGB8 |
| --- | ---: | ---: |
| 原配对，C1 | 0.537 | 1.60 |
| 原配对，F1 | 0.606 | 1.55 |
| 均匀 RGB8 色样 | 0.914 | 1.44 |
| 目标半幅拟合 | 0.834 | 1.02 |

两臂均达到白球服预设的投影 0.75–1.25、误差 ≤3。固定三次表示可以表达该局部的风格变化，结果支持保留拟合颜色覆盖及分布作为解释。均匀拟合对白球服场景的整图投影是 0.725，手臂只有 0.504，均不通过。9483 的均匀色样浅墙投影为 0.687，目标拟合为 0.994。前额、手背以及另一组脸部在棋盘留出没有合格像素，保留缺测。投影幕组的共同近中性色在两臂分别是 0.748 与 0.731，仍低于 0.75。[本机白球服图板](../../outputs/adaptive-reference-20261113/paired-operator-support-v2/872-1268/comparison.png)

这项结果为后续配对训练增加了一道可测条件。只看整图拟合误差不足以确认白衣或肤色对应颜色已获得监督覆盖。均匀臂使用了已知颜色变换，目标拟合臂使用目标真值作离线表达诊断，两者均不能提供普通两图成绩。两款原有换背景结论保留，现有软件未改动。

首次输出报告时，NumPy 布尔值不能序列化。改用原生计数后，两个正式运行的 16 张成片、四张图板与报告逐件一致，与未生成报告的首轮成片一致。报告 SHA256 为 `0fa2a23071a46321dbd264b8d67b63ecf26138c3e96b0cc92d9713f969986798`。复现使用已有视觉环境，加入仓库根目录与 OpenColorIO 到 `PYTHONPATH`，设置 `OPENBLAS_NUM_THREADS=4` 后运行脚本。[复现脚本](../../experimental/adaptive-reference-20261113/probe_paired_operator_support.py)
