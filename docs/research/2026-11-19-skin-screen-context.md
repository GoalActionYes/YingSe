# 场景分割识别了部分屏幕，仍将屏幕内的脸判为人物

在上一轮四张原图上，把冻结的 ADE20K 场景分割与已有肤色掩膜相交。仅当首选类别属于四种显示类别且置信度不低于 0.70 时，关闭该像素的肤色修正。三个实拍脸部通过，浅墙、白球服和雪地仍未触及。手背和手臂的已登记覆盖也保留。见[事前协议](../../experimental/adaptive-reference-20261113/skin-screen-context-protocol.md)和[原人脸框结果](2026-11-19-skin-face-gate.md)。

有投影幕的照片中，模型在全图标出 1,179 个高置信显示类别像素，但已登记的 110 个屏幕脸部像素全部首选 `person`。这 110 个像素的四种显示类别后验之和平均为 0.60%。因此逐像素屏蔽对该脸完全无效，诊断偏移的平均 RGB 变化仍为 6.67 码值。模型的屏幕区域和画面人物在分类输出中可以分开，不能通过简单逐像素开关确定它们的包含关系。见[投影幕反例](../../outputs/adaptive-reference-20261113/skin-screen-context/8021-8690.png)。

保留三个实拍脸部和投影幕作后续开发对照，停止这套逐像素规则。下一步可用屏幕外缘或区域连通关系做可证伪的包含测试，再检查真实人物站在屏幕前时能否保住肤色。四张原图上的固定偏移只测定位与外溢，未进入产品，也没有光源或自然画质成绩。

两个独立进程的四张图、四份肤色权重和一份报告共九个文件逐字节一致。用已生成图复算 18 项 RGB8 变化。复现用现有视觉研究解释器运行 `probe_skin_screen_context.py --portable <旧皮肤保护解释器> --output <新输出目录>`。保留在本机的既有两套模型按哈希检查。见[数值证据](2026-11-19-skin-screen-context-evidence.json)。
