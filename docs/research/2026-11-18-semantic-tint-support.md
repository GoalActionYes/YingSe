# 人物和背景同方向，也不足以确认整图调色

上轮只按参考的空间分块判断绿／品红证据，大背景独自就能放宽限制。本轮改为在参考中用自动分割选取明确人物和环境，各自估计同方向色偏上限，再取交集。目标区域、冷暖和亮度约束、13 号 80% 基线及色域处理均沿用。支撑不足时复用上一轮整图参考规则。见[事前协议](../../experimental/adaptive-reference-20261113/semantic-tint-support-protocol.md)与[上一轮对照](2026-11-18-reference-tint-envelope.md)。

| 开发检查 | 固定限制 | 原整图分块 | 人物与背景共同支持 | 原门槛 |
| --- | ---: | ---: | ---: | ---: |
| 人物抗背景干扰并保留整图色偏 | 0/8 | 0/8 | 0/8 | ≥6/8 |
| 人物整图绿／品红投影至少 0.90 | 2/8 | 8/8 | 7/8 | 联合判定的一项 |
| 近中性色背景干扰降幅 | 53.21% | 2.27% | 9.68% | ≥15% |
| 对比度与去饱和 | 11/12 | 11/12 | 11/12 | 12/12 |
| 局部背景冷色与人物保护 | 0/4 | 0/4 | 0/4 | ≥3/4 |
| 整图冷色与无人负例 | 4/6、2/2 | 4/6、2/2 | 4/6、2/2 | ≥4/6、2/2 |
| PSBench 台阶／铁塔 | 0/2 | 0/2 | 0/2 | 至少一向通过 |

白球服例里，只把参考背景改为品红。核对参考人物的 7,761 个标注像素，干预前后完全一致。候选仍把相对目标的品红容许值从未改色参考的 22.125 放宽到 27.5。原整图分块规则放到了 48。相对各自锚点，目标近中性色变化仅从旧方案的 9.91 降至 9.86 个 RGB8 码值，明显偏色保留。这个对照说明，两个区域的颜色同向可以与参考人物本身并未被编辑同时成立。本轮无法仅凭这项检查区分物体本色、分割受干预的影响和真实统一调色。

候选在 62 条对照中的 41 条取得双区域支撑，有 35 张与旧整图分块结果逐像素一致。两遍用时 10.75、10.42 秒，62 张输出哈希、评分和回退一致。另独立复算 46 项区域误差，并核对参考人物像素。台阶人像方向仍回退，铁塔微调仍未过门槛。见[数值与文件身份](2026-11-18-semantic-tint-support-evidence.json)。

两轮固定绿／品红限制均未达到联合要求。结束对该规则的阈值或分位调校。当前结果只支持把「参考区域具有某色」和「该区域有意被调成某色」分开验证，不能据此判断所有分割辅助方法的上限。软件和课程演示入口延续现有版本，未读取独立保留素材。

复现时在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path` 与 `$env:OPENBLAS_NUM_THREADS = '2'`，用现有研究 Python 运行 `experimental/adaptive-reference-20261113/probe_semantic_tint_support.py <新输出目录>`。需已有分割权重、固定开发对照和上一轮报告。图片及完整结果留在本机 `outputs/adaptive-reference-20261113/semantic-tint-support-v1` 与对应重复目录。
