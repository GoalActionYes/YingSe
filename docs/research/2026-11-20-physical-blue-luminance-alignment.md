# 给定实拍亮度后，跨灯强预测仍有色偏

前一轮从一档白灯和蓝灯实拍拟合颜色变化，再预测另一档蓝灯。两组四个方向的 RGB8 误差混合了明暗与颜色。这轮逐像素按实拍亮度缩放已有预测的线性 RGB，三个通道共用同一倍率，保留限域前的通道比例。这样可以检查，即使知道每处实际明暗，模型原来的颜色比例是否足够。采用 Rec.709 线性 RGB 亮度权重作为显示空间测量约定。实拍亮度只用于离线构造，灯强标签与前一轮一致。[事前协议](../../experimental/adaptive-reference-20261113/physical-blue-luminance-alignment-protocol.md) · [原跨灯强成片](2026-11-20-physical-blue-spatial-cross.md)

原实拍门槛为 MAE ≤ 3、P95 ≤ 8，单位为 RGB8 码值。对齐前后的正式评分沿用同一有效像素范围。两种预测对齐后均为 0/4，剔除裁切的归因检查仍为 0/4。空间矩阵的合格像素裁切比例为 0.12%–0.33%，无全黑无比例的合格像素。落盘图重新线性化后，空间矩阵的亮度 MAE 为 0.00041–0.00051，满幅为 1。两种数字增益控制各为 4/4，最大 MAE 0.026，最大 P95 为 0.334。

在这四个方向里，已知的亮度修正可以消除大部分 RGB8 误差，剩余颜色比例误差仍足以让全部实拍预测未过线。现有证据支持停止只补亮度的路线。仍需从带独立照明和材质记录的实拍中查明色度变化来自何处。两组照片无人，此轮不能证明自然肤色或风格迁移有改善。补查的人像来源中，Meyer 等在固定相机设置下拍摄彩色滤片对照，另一套研究报告了 285 位参与者和 15 种照明，但后者明确需申请，前者的论文未给出可核验的小样下载与使用范围。本次未取用这些人像。[Meyer 等论文 §4](https://www5.informatik.uni-erlangen.de/Forschung/Publikationen/2013/Meyer13-CCI.pdf) · [照明采集与数据获取说明](https://www.mdpi.com/2313-433X/10/5/109)
