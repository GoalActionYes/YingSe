# 固定线性条件预测：PETAL未通过，保留H128对照线索

本轮训练封闭式线性预测器，避免将前一MLP失败简单归为迭代训练问题。固定PETAL候选仍未通过完整画质门槛，不接入产品、不搜索正则强度。现有图像编码器H128对照有均值收益，但不是预先指定候选，也未达到原5%要求，不能事后改选成成功版本。

## 方法

只用已审计的1024个训练条件目标。每行输入为单位化目标/参考特征及差值，X与128维Y仅减训练均值，固定λ=0.1·trace(XcXcᵀ)/1024，解岭回归；开发预测截到±3。两种特征分别为原模型图像编码器H128补零到1024，以及冻结PETAL1024。另生成训练标签均值常量作为诊断。所有特征、目标和索引沿用同一数据缓存。

这是新的线性预测器训练，原颜色映射主干冻结。GT条件仅来自训练行，不进入开发预测输入。四组全部64张PNG及参数先保存，再读取开发GT像素评分；历史素材和分数已消费，不能称为盲测或独立泛化验收。基线PNG与历史零轮64图哈希完全一致。[协议](../../experimental/adaptive-reference-20261113/condition-ridge-protocol.md)在求解前固定。

## 完整结果

| 方法 | 开发64图RGB MAE | 32组响应delta MAE |
| --- | ---: | ---: |
| 当前13号基线 | 12.41129 | 15.12367 |
| 训练标签均值常量 | 12.52513 | 14.92466 |
| H128回归对照 | **11.82290** | **14.59613** |
| PETAL回归候选 | 12.49378 | 14.64160 |

PETAL比基线均值更差，30/64改善、3例明显退化；对H128仅27/64改善、7例明显退化。新增参考和响应门槛也失败。相对基线的明显退化为41049、64217、17288，均保留。

H128相对基线均值降低4.7407%，41例改善、23例恶化、2例明显退化；新增参考25/32改善且均值不退步。这是对照的事后描述，仍低于5%预定要求，不能以接近门槛为由放宽，也不能用它替换固定PETAL候选上线。常量对照未带来整体均值收益，不能把任意非零条件都解释为提升。

回归训练标签MSE为H128的0.65740和PETAL的0.72338。两组预测均未触及±3截断，不能把本轮失败归为截断损失。条件标签MSE与风格配对正确率都不能替代实际图像效果；本次结果不支持把PETAL配对优势直接等同于更好的条件预测。

## 验证与限制

独立CPU审查重新求解两个回归模型、正则尺度、训练MSE、64图预测参数及均值常量。数值解存在正常微小浮点差：独立dual最大差约1.46e-12，预测最大差约1.89e-13；保存解的方程残差不超过3.13e-13。这里只声明数值一致，不冒称独立求解逐位相同。

全部256张PNG的哈希与GT误差、128组响应指标、摘要及完整门槛经独立重算一致。源码、教师条件、特征、预测先保存记录、历史基线及主干状态关联一致。独立审查没有GPU重渲染。本轮没有新自然图、人类盲评、原生大图、视频或完整速度验证。

求解时间约H128 0.67秒、PETAL 2.01秒，仅为本次已缓存特征的CPU构造/求解/保存计时，不包含特征提取与完整App流程。不能据此宣称实时。
