# 分块颜色证据无法区分背景品红和有意的整图品红

白球服和其他近中性色在跨场景参考下容易出现绿偏与品红偏。本轮将这方向的变化与暖冷分开，只限制 13 号在目标近中性色上的绿／品红增量。固定方案统一限制在三个码值内，参考方案在多个参考块有同方向证据时放宽。两者保留同样的 80% 调色基线、目标区域软权重和色域处理。暖冷和亮度按协议中的线性分量衡量。没有用人工区域做预测。见[事前协议](../../experimental/adaptive-reference-20261113/reference-tint-envelope-protocol.md)。

| 开发检查 | 固定限制 | 按参考图放宽 | 原门槛 |
| --- | ---: | ---: | ---: |
| 人物抗背景干扰并保留整图色偏 | 0/8 | 0/8 | ≥6/8 |
| 人物保留整图绿／品红响应，投影至少 0.90 | 2/8 | 8/8 | 联合判定的一项 |
| 近中性色背景干扰降幅 | 53.21% | 2.27% | ≥15% |
| 对比度与去饱和 | 11/12 | 11/12 | 12/12 |
| 局部背景冷色与人物保护 | 0/4 | 0/4 | ≥3/4 |
| 整图冷色与无人负例 | 4/6、2/2 | 4/6、2/2 | ≥4/6、2/2 |
| PSBench 台阶／铁塔 | 0/2 | 0/2 | 至少一向通过 |

白球服的纯背景品红干预中，参考方案把正向允许值从固定 3 个码值放到 48。整图品红版则放到 56.5。前一种情况下，目标近中性色相对各自锚点的平均变化由固定方案的 2.45 回到 9.91 RGB8 码值。后一种的有意全图品红也回来了。两张参考内的大面积背景在块统计中都提供了同方向证据，放宽规则未加区分。两排输出可见本机 `white-jersey-tint-comparison.png`。

白球服的有意局部冷色对照中，参考方案的人物近中性色误差为 5.47 码值，基本继承了 13 号。台阶方向候选的整图／近中性色误差为 15.39／16.40，原图的对应误差为 9.39／7.60。两种做法都未达到预设门槛。

两遍用时 13.55、13.44 秒，各 124 张输出哈希一致。从 PNG 独立复核所有暖冷和亮度变化及 84 项近中性色背景度量。量化后最大亮度差为 0.499 码值，R−B 不变。同图和支撑不足合成检查通过。见[数值与文件身份](2026-11-18-reference-tint-envelope-evidence.json)。

停止这套固定限制与分块放宽。强行少迁移确实可以压低测得的干扰，同时牺牲了用户想要的整图色偏。继续改进需要能区分这些同向颜色证据来自哪个区域，以及是否属于统一调色。当前没有新的软件升级，未读取独立保留素材。

复现时设置 `$env:PYTHONPATH = (Get-Location).Path` 与 `$env:OPENBLAS_NUM_THREADS = '2'`，用现有研究 Python 运行 `experimental/adaptive-reference-20261113/probe_reference_tint_envelope.py <新输出目录>`。依赖已有背景干预、局部开关和 PSBench 105 对照。本机保留完整输出及重复结果。
