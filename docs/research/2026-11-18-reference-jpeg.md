# JPEG 转存对跨场景调色的影响

本轮针对雪地、室内白墙、球服等既有开发案例，检查同一张参考图经 JPEG 转存后，当前自适应版的目标画面会改变多少。已知参考背景换色会传到人物及近中性区域，普通图片编码是否也是主要干扰源尚未量化。

沿用背景干预第二轮的全部六组 256×256 输入和 multiref-v1 权重，强度固定 80%，无手动调整。唯一变化是参考编码，分别用 Pillow 13.0.0 的 JPEG 质量 92、4:4:4，以及质量 70、4:2:0。两档代表两种转存条件，质量和色度抽样的影响未单独估计。通过实际 SpatialStore 分析、渲染，先要求六张 PNG 参考的输出逐像素复现旧基线，再跑 12 张 JPEG 参考。没有重新编码目标图，也没有触发同画面对齐旁路。运行前固定六组、两档及比较对象，沿用每区域超过 1 个 RGB 码值的敏感性描述，可与既有背景干预结果比较。

| 参考变化 | 人物区域平均 / 最大变化 | 近中性区域平均 / 最大变化 |
| --- | ---: | ---: |
| JPEG 92，4:4:4 | 0.222 / 0.291 | 0.324 / 0.804 |
| JPEG 70，4:2:0 | 0.639 / 1.008 | 0.645 / 1.244 |
| 已有满背景换色，正反方向汇总 | 3.709 / 8.631 | 7.196 / — |

数值为相对 PNG 参考输出的平均绝对 RGB 差，单位为 8 位码值。人物统计覆盖四组，近中性代理覆盖六组。JPEG 92 两种区域均无超过 1 的案例，JPEG 70 两种区域各一例。全部 12 组输出已在同一面板查看。较强 JPEG 转存出现了可测变化，但在这批素材上幅度低于满背景换色，优先级仍是参考本色与所需调色的区分。两类干预的输入变化量不同，这个描述不能推出等扰动幅度下的因果排名。现有结果也未覆盖原尺寸、反复转存、其他 JPEG 设置或人眼偏好。

本机输出在 `outputs/adaptive-reference-20261113/reference-jpeg-20261118-v1`，含 12 张参考 JPEG、12 张输出、六组对照面板和完整区域数值。复核重新读取文件并计算区域误差，24 个 JPEG／输出 SHA256 一致。复核首轮误用了模型亮度系数，导致近中性掩膜不一致，按原区域定义使用 0.299／0.587／0.114 后全部通过。没有调整任何推理或比较条件。

复现入口为 `reference_jpeg_probe.py`，依赖已保存背景干预 v2 与同一权重，并拒绝覆盖现有输出目录。这个结果降低了优先投入 JPEG 预处理的必要性。跨场景偏色改进及原有画质、视频验收仍待达成。
