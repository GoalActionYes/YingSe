# 从参考统计中剔除背景方向，仍未同时保住风格

白球服在参考背景改变后仍会偏色，有意冷暖和对比度也经常迁移不足。本轮检验能否从两张输入中提取更稳定的调色信息。先用 12 个拟合组的未调色参考差分找出背景变化方向，再约束参数预测，使这些方向无法影响结果。保持图像描述、逐图回归目标、目标输入和 80% 渲染一致。在原有四组开发照片上输出 64 张图，两臂各 32 张。[事前协议](../../experimental/adaptive-reference-20261113/background-subspace-protocol.md) · [白球服本机成片](../../outputs/adaptive-reference-20261113/background-subspace-v1/872-1268/comparison.png)

| 问题 | 对照 → 候选 |
| --- | --- |
| 12 个拟合换背景方向的参数变化均值 | 0.07855 → 小于 10⁻¹⁵ |
| 白球服近中性色，未编辑参考换背景 | 2.00 → 2.33 RGB8 码值 |
| 白球服有意对比度，原背景响应投影 | 0.398 → 0.336 |
| 白球服有意对比度，换背景响应投影 | 0.143 → 0.165 |
| 9483 有意对比度，换背景响应投影 | 0.505 → 0.640 |
| 背景稳定和编辑保留联合通过 | 0/4 → 0/4 |

预期的编辑投影为 1，门槛为 0.75–1.25。候选最严重的整图误差增加 1.39 码值，仍在 2 码值限额内，但联合条件未达标。四组开发里的未编辑换背景向量仍有 23.6%–49.1% 的标准化特征范数，冷暖编辑向量只剩约 31.5%，对比度向量剩 40.8%–54.5%。这里的百分比描述输入特征量，画质由实际成片评分。结合白球服和 9483 的成片，固定的背景方向在新场景会漏掉一部分背景变化，同时也与有意编辑重叠。[逐组数值及成片哈希](2026-11-19-background-subspace-evidence.json)

结束固定背景方向剔除。此结果只适用于既有统计表示和封闭编辑开关，开放照片中的光照与编辑能否由其他图像线索分开，仍待验证。后续要有独立于同一组颜色统计的新信号，优先考虑有原片与成片可核对、跨内容沿用同一处理的对照。保留封存回归素材和现有演示版。[素材要求与阶段交接](2026-11-19-bg-real-crossed-grade-subject.md)

用研究环境将仓库根目录设为 `PYTHONPATH`，运行 `probe_background_subspace.py <新输出目录>`。两遍的 64 张成片、4 张图板和报告逐字节一致。另用拉格朗日乘子求解同一约束，从落盘成片独立复算区域色差、编辑响应和门槛。旧成对监督入口复跑后的报告与上轮逐字节一致。[脚本](../../experimental/adaptive-reference-20261113/probe_background_subspace.py)
