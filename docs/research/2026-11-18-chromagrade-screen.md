# ChromaGrade 固定配置未通过跨场景筛查

ChromaGrade 对近中性色的背景干扰平均增加 29.91%。人物方向有 0/8 同时达到抗干扰和保留整图色调的要求。对比度和去饱和的整图响应通过 1/12。此固定配置停止，未接入映色。见 [运行前协议](../../experimental/adaptive-reference-20261113/chromagrade-screen-protocol.md)及[逐项数值](2026-11-18-chromagrade-screen-evidence.json)。

本轮比较完整的分阶段颜色映射，检验先估计白平衡与明暗、再匹配颜色分布并加近中性色约束，能否改善两轮参考直方图加权未解决的问题。固定上游版本、默认 quality 配置、强度 80% 与四个 CPU 线程。现有基线读取既有输出，候选重新计算 42 张。两个算法的强度定义不同。ChromaGrade 的颜色映射主体是全局 LUT，默认另有细节恢复。代码快照附 MIT 许可证。见 [上游源码](https://github.com/v3devv/ComfyUI-ChromaGrade/tree/9ef7f1cd747f542d4201297ef86d43e79493bad8)。

- 白球服案例 872-1268 的参考背景往品红变化后，近中性色测量区域的差分由 9.910 增至 12.191 码值。绿色方向由 6.365 降至 6.159。
- 最差近中性色方向出现在无人熊毛案例 285-1993。参考背景往绿色变化后，差分由 7.656 增至 15.681 码值，增加 8.025。
- 雪地案例 785-3553 使用未经干预的参考图时，候选把雪面明显压暗并染成黄绿色。候选与现有基线的全图平均 RGB 差为 93.971 码值，已查看目标、参考和两方法结果。此差值反映输出差异，画面没有专家真值。

42 张候选 PNG 与 42 张历史基线均重新核对哈希和解码尺寸。独立从像素重算区域 RGB 平均绝对差、响应投影和筛查结论，结果一致。生成循环约 15.56 秒，包含读取输入、计算、保存和统计，范围仅为此 CPU 小图实验。人物区域包含衣物；近中性色是根据目标 RGB 筛出的代理区域。本轮未消费独立样张，也未验证真实自然度或视频。

此结果否决默认配置直接接入。进一步改善仍需解决应从参考中迁移哪些颜色的问题。单凭本轮差异无法将失败归因于某个内部阶段。保留本机目录 `outputs/adaptive-reference-20261113/chromagrade-screen-v1`。

复现时，在已准备的研究环境中运行 `python experimental/adaptive-reference-20261113/probe_chromagrade.py <固定上游源码目录> --out <新输出目录>`。需要原背景干预报告和图片。脚本校验上游提交、基线报告与输入输出哈希，已有输出目录受保护。
