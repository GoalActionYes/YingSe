# 本机局部调色研究版使用与验证

## 打开与版本

双击项目根目录下`00-从这里开始/12-打开局部调色研究版.cmd`。这是新的独立课程研究入口，保留原深灰色编辑界面和调节布局；旧的`1-打开当前稳定版.cmd`与`11-打开自适应调色实验版.cmd`继续保留。

新入口使用`dev-data/spatial-reference`，不替换稳定版或旧研究工作台的最近工程。当前本机已经准备好模型和环境；首次进入已放入一组研究样例，可替换参考图和目标素材。源代码可以修改，但本机`.tools`环境与研究权重未打包进Git，其他电脑不能只克隆仓库就立即运行此入口。

本版限非商业课程学术研究。基于此前固定第8轮模型，保留32组对照为21改善／10退化／1变化很小，平均RGB MAE降低约19%；仍有2组强风格迁移不足，不保证每张图优于现有版，不是完整剪映算法恢复。

## 实际操作

1. 导入目标图片或视频，再选择参考图，等待分析。
2. 调节克隆强度或关闭克隆查看原色；基础／HSL／曲线微调作用于局部调色之后。
3. 曲线吸管点击画面，读取对应原尺寸位置在当前克隆与基础／HSL处理后的值；吸管采样时不重复叠加曲线。
4. PNG保留原尺寸。MP4逐帧估计局部网格，首版统一30fps，保留首条可用音轨并编码AAC；可补帧或丢帧，H.264／AAC为有损编码，奇数边补齐偶数。
5. 局部空间效果不能完整保存为单个普通CUBE，因此该入口不提供CUBE。需要普通CUBE时使用原稳定版或全局工作台，不把两种效果视作完全等价。

视频选择的是预览帧，导出仍逐帧自适应处理。输出设置和工程可恢复，模型／版本不一致或缓存损坏时应重新分析。更新代码后再次运行入口会核对服务build；仅关闭自己验证过的旧服务，正在导出时拒绝关闭，不按进程名强制结束。

## 接入方式

`spatial_store.py`保存空间网格与模型／源码身份，单独校验网格哈希。兼容既有项目结构所用的identity LUT只是传输占位，未参与实际预览或导出；后端也拒绝伪造的CUBE请求。图片先保留既有精度检查，再处理EXIF及ICC；支持普通8位RGB、RGBA、灰度和调色板图，alpha按旧版RGB转换规则处理，不宣称透明PNG输出。

调色预览缓存两个结果，拖强度时复用满强度画面再混合，避免每次重新估计网络。手动调节使用现有数学；曲线取色调用同一局部渲染路径。PNG与视频任务沿用异步进度、取消、原子发布和独立导出记录；取消只终止当前任务拥有的解码／编码进程，清理具体临时文件。

## 实际HTTP验证

使用单独的`outputs/adaptive-reference-20261113/spatial-workbench/verification-v3/data`启动测试服务，没有操作用户最近工程。真实上传、请求、结果下载完成：

| 检查 | 结果 |
|---|---|
| 1920×1080图片分析 | 约1.18秒，含输入校验与准备 |
| 交互预览6次 | 约0.412／0.348／0.170／0.174／0.187／0.186秒 |
| 强度0／0.5／1 | 零强度字节相同；半强度符合混合公式，容许1码值量化差 |
| 基础亮度、曲线吸管、项目保存恢复 | 真实接口通过 |
| PNG导出 | 1920×1080，与服务端同设置渲染逐像素一致 |
| CUBE伪造请求 | 后端400拒绝 |
| 3秒640×360、25fps视频 | 约4.65秒完成导出及核验，输出30fps、90帧、3秒 |
| 合成音轨视频 | 音轨保留，AAC输出约3.02秒 |
| 运行中的导出取消 | 确认有存活解码进程后取消；无结果或残留partial文件 |
| 导出期间请求关闭服务 | 409拒绝，未中断任务 |
| RGBA／灰度上传后取帧 | 与预期RGB转换一致；另有调色板单元检查 |

首次HTTP验证发现了启动路径导入问题并修复，随后完整流程通过。独立审查另发现普通图片模式兼容问题：先观察回归失败，再修正规范化及ICC处理；不是把错误输入静默当空图。

启动器已实际连续执行三次，复用同一PID及地址，没有重复启动服务；只在独立新目录没有最近工程时导入保留组首个样例（索引88538），不是按最好效果挑选。模型不因该样例更新。

## 边界与未完成项

HTTP验证不等于浏览器视觉验收；本机当前没有可靠浏览器自动化，尚未逐项检查窗口布局、拖动观感、缩放和交互动画。强风格失败、不同自然视频、镜头切换、大幅照明变化、VFR转30fps后的体验及大型素材仍需进一步验证。音轨检查只证明存在和时长，不是音画同步质量或所有音轨格式验收。

研究权重没有发布，也没有独立安装包／CPU后备；本机需要现有CUDA模型环境。完整目标仍在推进，不能因为界面接入或测试通过就宣称已解决所有人物／场景关系。

启动停止命令：使用`.tools/vision-advisor-env/Scripts/python.exe`运行`experimental/adaptive-reference-20261113/launch_spatial_workbench.py --check`或`--stop`。日志在`dev-data/spatial-reference/workbench.log`，会话文件包含本地关闭令牌，请勿作为公开演示材料传播。

验证机器记录见`2026-11-13-spatial-workbench-evidence.json`。原素材、输出视频、运行环境、模型和个人会话记录不入Git。
