# 主图像色彩目标：梯度核查与匹配训练

本轮匹配训练已完成，未获得新增画质收益，停止固定配方，稳定程序不变。前一原参考分布辅助训练未通过，已停止；本轮改动主像素训练目标，不追加旧辅助头。

## 依据与限制

[PREEN论文](https://arxiv.org/abs/2610.36896)使用图像级CIELAB监督，提供误差空间值得检验的线索。本项目没有采用作者网络或权重，不称为PREEN复现。已有YCbCr统计辅助约束与此次主像素目标不同。

颜色转换按照[W3C CSS Color 4](https://www.w3.org/TR/2026/CRD-css-color-4-20261112/)公开定义实现sRGB解码、XYZ、Bradford D50适配及CIELAB；本项目明确固定D50，不假定与论文未明确的细节一致。未复制第三方项目代码。

## 已完成的训练数据核查

固定4096训练清单前128行，不使用开发或独立评价选权重；主干采用expanded-v2 epoch4，没有优化器更新。原模型state前后相同，输入与源文件哈希留存。

RGB MSE与色彩目标的平均梯度余弦0.6429025438，原RGB L1与其平均余弦0.4621351740；有效通道方向平均冲突27.6381%。训练聚合RMS比0.1324448181246545，后续冻结该系数。差异只说明训练方向不同，不证明肤色更自然或实际效果更好。

双精度CPU/GPU固定小数组最大颜色值差5.684e-14、梯度差6.821e-13。模块另验证黑白、灰中性、边界有限梯度、有限差分和同图零损失。结果及128行输入身份见同目录数值证据。

## 停止与下一步边界

停止这套固定色彩主目标，不搜索权重、白点、seed或追加轮次，不接产品、不读取独立评价素材、不要求人工填表。失败不能证明所有CIELAB监督无效，也不能仅凭训练批损失下降认定已经定位泛化根因。

下一项如开展，只对既有训练128行固定重评起点与两组末轮，区分固定训练状态是否也退化；不重新训练、不改变候选身份，不使用该诊断挽救验收。真实跨内容一致性增强已在2026-11-14失败，不换名重启。整体软件改进目标仍未达成。
