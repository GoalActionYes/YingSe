# 去掉原有偏色后，三个方向仍无共同改色力度

用两张已归档人像和两款冻结模型，取同一目标上参考开态与关态的逐像素色度差。离线诊断先令关态等于目标原图，相当于先解决关态偏色，再检查只用一个增益能否恢复有意编辑。预设投影区间仍为 0.75–1.25。连续投影随统一增益线性变化，以下为量化和色域处理前的必要区间。[事前协议](../../experimental/adaptive-reference-20261113/portrait-common-chroma-gain-protocol.md) · [基线成片](2026-11-20-expanded-portrait-cross.md)

| 模型与目标 | 整图允许的力度 | 共同近中性色允许的力度 | 两区交集 |
| --- | ---: | ---: | --- |
| 13 号，《Cuckoo》 | 4.41–7.35 | 2.53–4.22 | 无 |
| 扩展版，《Cuckoo》 | 2.95–4.92 | 1.55–2.59 | 无 |
| 13 号，混合光人像 | 0.56–0.93 | 0.40–0.67 | 0.56–0.67 |
| 扩展版，混合光人像 | 1.03–1.72 | 0.54–0.89 | 无 |

在《Cuckoo》扩展版里，脸颊允许 1.19–1.98，浅树皮允许 2.34–3.90，两处本身也没有共同增益。实际使用整图色度最小二乘得到的 2.394 倍出图，整图投影 0.606、脸颊 1.504、浅树皮 0.762。约 4.92% 像素触发色域压缩。另一个具有连续区间交集的 13 号混合光案例，按事前固定的最小二乘选到 0.347 倍，出图整图和近中性色投影为 0.380／0.592，幅度仍低。分析保留这个数学可行区间。它只约束幅度，未证明采用区间内某个值就能通过全部门槛。[全量数值和成片身份](2026-11-20-portrait-common-chroma-gain-evidence.json)

两方向各两版的真实渲染都未达到联合门槛。结束用这两版的现有编辑增量学习一个全图色度力度。色域处理和取整可改变像素响应，因此连续区间只约束处理前的统一缩放。该诊断读取已配对的参考状态与作者答案，并给予理想关态。它定位不同区域所需力度不一致，尚未验证普通两图能否自动找出各自的调整。[本机《Cuckoo》扩展成片](../../outputs/adaptive-reference-20261113/portrait-common-chroma-gain-v1/cuckoo-expanded.png)

复现时在研究环境将仓库根目录加入 `PYTHONPATH`，运行 `experimental/adaptive-reference-20261113/probe_portrait_common_chroma_gain.py <研究输出根目录> <13 号人像输出目录> <扩展版人像输出目录> <新输出目录>`。两遍四张成片和数值报告逐字节一致，13 号与扩展版的原区域评分复算一致。
