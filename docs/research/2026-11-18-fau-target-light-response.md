# 已知换灯时，目标图的受光信息可以跨内容使用

上一轮把参考的光色按画面坐标搬到目标，换成同灯设置的不同物体时也会偏色。这次固定红蓝换灯操作，用一组杯子的实测照明校准，到另一组检查。候选从目标原图的估计照明色度预测各位置的调整。对照用校准组的平均调整量，整图统一应用。两路沿用 80% 的色度重放。见[事前协议](../../experimental/adaptive-reference-20261113/fau-target-light-response-protocol.md)及[固定坐标结果](2026-11-18-fau-cross-content-light.md)。

| 测试组 | 范围 | 统一调整误差 | 按目标位置调整误差 | 响应投影 | 候选达标 |
| --- | --- | ---: | ---: | ---: | --- |
| bmug | 整图有效区 | 0.2362 | 0.1247 | 0.5733 | 是 |
| bmug | 近中性色代理 | 0.1815 | 0.0861 | 0.7148 | 是 |
| bpmug | 整图有效区 | 0.1768 | 0.1210 | 0.6972 | 是 |
| bpmug | 近中性色代理 | 0.1667 | 0.1039 | 0.5839 | 是 |

误差为相对本组实际换灯 80% 对照的线性 RGB 对数色度差 RMS。候选四项通过。两组近中性色相对统一调整的误差分别下降 52.57% 和 37.70%，均高于固定的 15%。每组只在校准另一方向时使用自己的标签；本组测试出图使用另一组拟合参数、本组原图与原图的冻结照明估计，不使用本组参考、标签或蒙版。两次报告和四张预测图哈希一致，另从落盘图片独立复算八个区域的误差和投影，同图恒等通过。见[数值与身份](2026-11-18-fau-target-light-response-evidence.json)。

目标图估计照明能提供部分“哪里应变红或变蓝”的位置线索。测试与校准共享实验室和同一种已知换灯，本轮不验证陌生机位、普通参考意图、同灯抗干扰、肤色或完整风格。输出保留原亮度。没有产品升级或独立验收成绩。

下一项需要检验参考端能否区分灯光操作相同、物体不同，与灯光操作确有改变。只在取得来自不同物体、明确灯设置的数据后做识别检验。现有两组可作开发桥接，不能作为匹配方案的独立验证，也不能把当前固定操作用于普通参考。

复现时在仓库根目录设置 `PYTHONPATH` 为当前目录，在已有画质研究环境运行[脚本](../../experimental/adaptive-reference-20261113/probe_fau_target_light_response.py)，传入本机 `outputs/adaptive-reference-20261113/fau-two-light-intake-v1` 和新输出目录。档案、增亮图、估计数组沿用之前的哈希记录；本轮不新增素材、环境或模型。
