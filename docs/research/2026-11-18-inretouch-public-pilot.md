# INRetouch 公开同款示例中的两图调色

用两张内容不同、在作者配置中作为同款调色的参考图，分别给两个目标调色。现有 13 号在两张目标上都能借第一张参考缩小与作者调色的差距。换成第二张参考后，两张结果均比保持原图更偏离，固定小样规则未通过。见 [预先协议](../../experimental/adaptive-reference-20261113/inretouch-public-pilot-protocol.md)和[数值证据](2026-11-18-inretouch-public-pilot-evidence.json)。

原照与目标效果来自作者公开仓库的研究示例，固定下载 8 张，合计 1,623,640 字节，逐个验证 Git blob。两组参考分别为红岩景观和人物，两组目标均为不同内容。作者配置将两对参考前后图一起用于同款优化，示例仓库使用 CC BY-NC-SA 4.0 声明。本轮限本机课程研究，媒体及输出不随 Git 发布。未核实这些示例的实际预设参数或局部人像编辑记录。见 [公开示例](https://github.com/omarAlezaby/InRetouch/tree/cbf0db19487222c21d63116c320357764438360d/example_data)和[作者配置](https://github.com/omarAlezaby/InRetouch/blob/cbf0db19487222c21d63116c320357764438360d/options/train/InRetouch_Optimize_Multiple.yml)。

固定用目标原图和一张已调色参考，按 13 号原生空间路径、80% 强度输出。四份预测保存后才读取参考原图和目标调色图。评分将目标调色图按同样的 80% 与原图混合，整图和近中性色均用 RGB8 平均绝对误差。近中性色从目标原图筛选。

| 目标／区域 | 保持原图 | 用参考一 | 用参考二 | 两输出之间的差 |
| --- | ---: | ---: | ---: | ---: |
| a0006 整图 | 13.537 | 12.638 | 14.668 | 8.689 |
| a0006 近中性色 | 11.552 | 10.276 | 12.064 | 5.484 |
| a0007 整图 | 13.997 | 12.764 | 14.431 | 6.356 |
| a0007 近中性色 | 14.086 | 13.010 | 14.686 | 6.453 |

已查看 a0006 的两个输出。用人物作参考时，水面反光和羽毛比用红岩参考时更偏红。两个参考的结果变化均小于作者相对原图的调色幅度，但参考二在两幅目标上都退步，故不通过小样规则。每行指标、八张 JPEG 和四张输出的 SHA256 均已复核。这是公开示例的开发对照，未做近重复独立性认证或人类评价，也未获得可安装的新候选。

两对参考都带原图，下一步可以在离线测量中控制是否提供参考原图，判断未能识别同款是否与缺失的原始颜色信息有关。参考原图只作为额外输入诊断，正式目标仍是两图推理。样本或产品验收范围不扩大。

复现时从仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path`，运行 `python experimental/adaptive-reference-20261113/probe_inretouch_public.py <示例目录> <固定树元数据> <新输出目录>`。本机示例位于 `outputs/adaptive-reference-20261113/inretouch-public-pilot-v1`。
