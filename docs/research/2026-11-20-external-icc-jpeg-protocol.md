# 核对第三方宽色域 JPEG 的普通图片工作流

既有 ICC 候选已在重新编码的测试图上通过，仍缺独立发布的原始 JPEG。选择 WebKit 的三张公开宽色域示例，包括 Italy、Yellow Flower 和 Shoes。样图用于本机兼容性验证，分别代表两个嵌入配置。固定下载字节及嵌入配置，所有原图与衍生图留在本机。[发布页](https://webkit.org/blog-files/color-gamut/)

每张照片分别作目标与参考，另一张输入固定为合成颜色梯度。只改变照片编码臂。候选直接导入原 JPEG，另用 Pillow 对同一 JPEG 解码后分别生成独立转换到 sRGB 的 PNG 和直接保留 RGB 数值的无 ICC PNG。基准不使用发布页的另一个 JPEG，因为该文件可能另有编码或编辑差异。三臂走同一 HTTP 接口完成原图读取、分析、80% 强度预览、明度与 HSL 微调、PNG 导出。

每张 JPEG 原图读数须与对应 sRGB 转换逐像素相同。六组角色中，带 ICC 成片与 sRGB 成片须逐像素相同，去标签控制与 sRGB 成片须至少相差 0.5 RGB8 MAE。每臂预览与对应导出精确相同。两遍使用不同本机数据目录，输出像素与评分须一致。若任一角色不满足门槛，按原结果报告，先判明是候选缺陷还是对照不足。本轮只验证图片输入色域处理，编辑器转换用于参考基准，不做自然度或跨场景模型验收。
