# 固定风险判断器：减少一例严重退化，丢失过多收益

仅用训练集分组OOF记录拟合一个五输入逻辑回归判断器，阈值固定0.5，再对已消费开发64图决定采用HC修正或保留当前13号基线。它避开一例严重退化，但拒绝了12例有益修正，完整门槛失败。**没有接入软件，也不能称为可靠回退功能。**

## 固定训练与数据范围

五项输入保持上一资料阶段的未解释特征能量、条件L2、条件最大幅度、上下文范数比、H128距离。标签为训练OOF修正相对基线改善超过0.1，共512正例。均值/std仅从训练1024条得到，加截距，以平均交叉熵加0.01权重L2正则拟合；32次Newton更新及固定回溯步骤，没有开发选轮或阈值搜索。分类分数不等于已经校准的真实置信概率。[协议](../../experimental/adaptive-reference-20261113/condition-risk-gate-protocol.md)在运行前固定。

开发线索从保存的完整HC模型、输入上下文和预测条件重新计算，不使用开发GT；先保存64例分数、选择和输出，之后读GT像素评分。输出直接复制既有PNG，不重新渲染、不混合强度。这里的回退是保留当前13号已调色基线，不是恢复原始照片。

不对训练OOF记录再做普通CV宣称两阶段整体严格留出，没有独立自然图或人类校准评价。训练主干此前见过本训练集，开发64图此前也已用于研究；本轮只是新固定判断器的开发诊断。

## 结果与损失的收益

| 方法 | 开发64图RGB MAE |
| --- | ---: |
| 当前13号 | 12.41129 |
| 原HC修正 | **11.37217** |
| 加固定判断器 | 11.54558 |

采用修正50例、回退14例；相对基线29例改善、18例恶化、2例明显退化。原HC有41例改善，判断器拒绝其中12例；严重退化3026被避开，27824与41049仍保留。不能只展示严重退化3→2而忽略丢失的收益。

相对当前版改善数量29低于40；相对H128控制的完整门槛也失败。新增参考仅15/32改善，低于17；响应delta均值14.51255，其均值与组数要求均失败。不能以大量回退或降低采用比例来声称目标完成。

## 验证与结论

独立CPU审查重新拟合全部32步、目标值/回溯/权重及训练标准化，核对64图风险线索、分数、选择与PNG哈希、GT误差、32组响应及全部门槛。训练最大logit约1.9233、开发约1.4978，±40保护未触发，未因截断改变实际训练梯度。风险输入最大数值差约4.44e-16，分数约2.50e-15，声明数值一致，不冒称通用确定性。

源码、OOF/候选/数据关联一致。输出选择无需GPU，审查也未运行GPU。没有新的原生尺寸、视频、真实人类评价或产品体验测试。

本次五项线索与固定线性判断器没有实现足够可靠的收益保留；不能据此认定所有可靠性方法无效，也不能针对开发反例继续调阈值。下一方案必须重新提出可检验的信息或模型依据，而不是只把阈值改到这批图更好看。
