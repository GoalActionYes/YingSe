# 多路线未达标后的下一步决策

当前没有可宣称验收通过的新画质候选。稳定1.3和第10阶段研究版保持，研究提交不作为产品版本发布。目标仍是可验证的跨场景风格迁移改进，不调整为仅交付已有程序或整理文档。

## 保留成果与停止证据

| 路线 | 当前实际证据 | 决策 |
| --- | --- | --- |
| 扩大真实配对覆盖 | 相对当前版平均误差改善约19.28%，但相对原C10的参考响应改善18/32，未达到20 | 保留研究候选和全部反例，不改门槛、数据量、轮数或种子追分 |
| 全局＋人物／背景残差及场监督 | 前者开发改善约0.27%，后者选零轮；未通过匹配控制 | 停止原头追加监督与调参 |
| 冻结局部对应小头及显式基线颜色条件 | 两轮均选零轮，无开发收益 | 停止该结构的块、损失、温度和种子追加 |
| GradeStudio直接区域颜色迁移 | 默认开发误差比现有高25.44%，严重退化20例 | 停止固定默认方案，不调整参数救回 |
| PETAL等已运行现成模型 | 已有开发与自然对照失败记录 | 不重复运行已排除配置 |
| ICTone／SAGE联合模型 | 有不同的信息利用方式；本机尚未运行，当前底模访问与标准资源前提未满足 | 先解决具体访问／资源，不把论文展示当本项目画质证据 |

背景干预和条件重放支持参考背景色度会影响目标人物；它们没有证明所有背景变化都应忽略。GT辅助拟合支持存在较好映射，不能证明两张正常输入足以预测它。停止低效路线不能改写成已解决这两个问题。

## 两项可供用户参与的具体事项

1. **用真实判断帮助确定新假设。**已提供两份各32组匿名诊断，覆盖全部旧开发案例，可只评几组或反馈组号与问题。这是路线诊断，不分配新独立数据，不把未通过候选改为上线。材料与核验见[人类诊断说明](2026-11-17-human-diagnostic.md)。
2. **确认是否有现成的更大资源。**如果有学校工作站或另一台机器，提供显卡、显存和内存即可先核查。当前机器不能直接照作者标准流程运行ICTone；需要用户本机底模访问以及经过验证的执行方案。具体容量、401访问结果及未测范围见[资源核查](2026-11-17-joint-model-resources.md)。不自动租用服务器，不要求发送凭据。

用户没有选择上述事项，不代表同意追加费用、素材上传、降低标准或暂停目标。当前没有运行中的训练或大模型下载需要等待；后续若没有新输入或新能力证据，不能以继续记录文档、重复扫描背景或更换旧参数充当算法进展。

## 后续验收保持

新路线先固定主要假设、同预算控制和停止条件，开发全部门槛通过后才进入新的独立自然／人类评估，再验证视频、完整处理耗时和候选交付。任何反馈或资源许可都只解除相应前提，不自动证明完整目标完成。成功后才形成产品PR，未经明确授权不合并main。
