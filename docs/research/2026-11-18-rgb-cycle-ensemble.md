# RGB 通道轮换未能同时保留风格与减轻偏色

固定用同一目标和参考，保留未换通道的 13 号 80% 成片。另将两张输入一起换成 GBR 和 BRG，沿用同一权重和强度，输出换回 RGB 后与原成片等权平均。算法没有读取人工蒙版、目标成片或参考的调色前图。这个方案想检验模型对特定颜色通道的不对称响应是否放大了偏色。见[事前协议](../../experimental/adaptive-reference-20261113/rgb-cycle-ensemble-protocol.md)。

| 开发检查 | 轮换合成 | 门槛 |
| --- | ---: | ---: |
| 参考背景换色后，人物减干扰且保留整图响应 | 0/8 | 至少 6/8 |
| 近中性色平均干扰下降 | 3.42% | 至少 15% |
| 近中性色最差干扰增幅 | +3.23 码值 | 至多 +1 |
| 对比度与去饱和响应 | 0/12 | 12/12 |
| 人物局部调色 | 0/4 | 至少 3/4 |
| 整图冷色 | 4/6 | 6/6 |
| 无人局部负例 | 2/2 | 2/2 |
| 台阶人与铁塔两方向 | 0/2 | 2/2 |

白球服局部版的近中性色误差从 5.47 降至 5.32 个码值，背景冷色方向投影也从 0.709 降至 0.684。台阶人像的近中性色误差由 16.77 降至 16.39，保留原图为 7.60。铁塔整图误差由 15.03 降至 12.44，仍高于保留原图的 11.39。实际成片中，台阶仍发青，铁塔天空比目标对照更灰。平均处理削弱了有效响应，未能让人物和背景的颜色同时接近目标。结束此固定方案，保留失败成片及 13 号现有入口。

两次运行的报告和 62 张 PNG 逐字节一致。同图恒等检查通过。独立从图片复算两幅实拍的 12 项误差和白球服人物近中性色误差。见[小型证据](2026-11-18-rgb-cycle-ensemble-evidence.json)。本机三组图片对照位于 `outputs/adaptive-reference-20261113/rgb-cycle-ensemble-v1/comparison.jpg`，仅保留本机。

复现时用既有 13 号研究环境，从仓库根目录设 `PYTHONPATH` 为仓库路径，再执行[实验脚本](../../experimental/adaptive-reference-20261113/probe_rgb_cycle_ensemble.py)，传入新输出目录。需要既有背景干预、局部开关和 PSBench 105 素材。本轮未进入独立画质或视频验收。
