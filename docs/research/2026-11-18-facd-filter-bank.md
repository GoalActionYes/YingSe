# 三款滤镜识别降低了平均误差，换款响应仍不足

用去黑边后同款可比较的七组 FACD 场景，以参考成片中暗部、中间调和亮部的相对色度学习滤镜类别，再渲染目标。每折排除该目标和两张候选参考的整组照片，四组训练前后图用于建立三张固定颜色表。正常两图推理只读取目标原图和一张调色参考。另用已知滤镜类别渲染，定位识别错误与映射限制。见 [运行前协议](../../experimental/adaptive-reference-20261113/facd-filter-bank-protocol.md)及[此前基线](2026-11-18-facd-two-image-baseline.md)。

| 方法 | 平均整图误差 | 平均近中性色误差 | 稳定、换款与画质联合通过 |
| --- | ---: | ---: | ---: |
| 保留原图 | 19.97 | 21.59 | — |
| 13 号 | 18.88 | 19.99 | 0/7 |
| 从参考成片自动推断类别 | 12.80 | 11.83 | 1/7 |
| 给定正确类别的颜色表 | 8.94 | 6.60 | 2/7 |

误差为相对作者 80% 效果的 RGB8 码值，按目标／参考组合等权平均。自动判定认对 28/42 次，低于预设的 34 次。判对次数按 Amaro、Hudson、XProII 分别为 9/14、11/14、8/14。查询照片跨折复用，42 次是判定次数，不能当作 42 张独立新照片。即便给定正确类别，七组的误差要求都通过，但只有两组达到换款响应门槛，说明目前的固定颜色表也压弱了一些实际风格区别。

婚纱例以湖景 XProII 作参考时，自动选成 Amaro。婚纱的明显青偏减轻，但实际没有跟到作者的 XProII 方向。给定 XProII 后能接近作者的黄色婚纱，衣服的这类染色不等同于自然中性色保护。火焰组 379484 是唯一完整通过的自动组；仍可见作者的 XProII 火焰偏红更明显。最小换款响应投影在自动组为 −0.537，给定正确类别仍有 0.168 的弱响应。所有场景保留。见 [数值与哈希](2026-11-18-facd-filter-bank-evidence.json)。

两个运行的 63 张 PNG 和结果 JSON 哈希一致。重新计算亮度档特征，使用对偶形式核对 42 个分类决定及各项得分，另从输出复算 588 项误差与方向。查看婚纱和火焰两组实图。这次对照不能区分颜色覆盖不足、全图映射对暗角等空间效果的限制，以及其他近似误差各自的贡献。

该方法限三款候选滤镜，没有未知类别拒绝能力，未进入软件。两个层面都有剩余误差，因此不通过继续调整分类阈值或仅减弱调色来追分。若推进这类方法，下一次需要单独求证固定映射丢失的参考效果里有多少来自空间处理，再决定是否值得扩充可识别的风格表示。原有独立画质目标和课程演示版本保持。

运行目录为 `outputs/adaptive-reference-20261113/facd-filter-bank-v1` 与 `facd-filter-bank-repeat-v1`。两张对照图分别位于前一目录的 `64573/comparison.jpg` 与 `379484/comparison.jpg`。在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path` 后，用研究 Python 运行 `experimental/adaptive-reference-20261113/probe_facd_filter_bank.py <去黑边目录> <两图基线证据> <去黑边证据> <新输出目录>`。媒体仅保留在本机。
