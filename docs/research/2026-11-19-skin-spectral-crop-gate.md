# 半幅裁切找回了部分小脸，也扩大了投影幕误改

对上一轮 18 张冻结输入增加九个半幅重叠裁切。沿用 0.70 的脸部皮肤阈值，各裁切只取有效内部，贴回原图后与全图定位取并集。只在新入选像素补上同一个已知光源的肤色修正，原有入选像素和矩阵基底沿用已检验结果。[事前协议](../../experimental/adaptive-reference-20261113/skin-spectral-crop-gate-protocol.md) · [全图定位基线](2026-11-19-skin-spectral-scene-gate.md)

| 区域 | 原图全图定位 → 加裁切 | 程序暖色全图定位 → 加裁切 |
| --- | ---: | ---: |
| 785 小脸 | 95% → 100% | 45% → 100% |
| 9483 前额 | 100% → 100% | 100% → 100% |
| 872 远处脸颊 | 0% → 82.14% | 0% → 82.14% |
| 8021 投影幕中的脸 | 100% → 100% | 5.45% → 100% |

三处雪地、浅墙和白衣的测量框在两态都逐像素保持矩阵基底，五组 DAST 历史核心仍全部覆盖。直接拍摄的小脸证明提高相对尺寸可以找回部分漏检，远处脸颊在两态仍低于 95% 门槛。旧检查由 19/22 升至 20/22。暖色投影幕的误改则由 0.17 增至 3.56 RGB8 码值，超过新增的不得退化要求。裁切对可见脸部纹理更敏感，仍缺少区分真实皮肤和画中人所需的场景判断。停止把固定半幅并集直接接入软件。真实暖灯、两图自动决策及独立画质和视频仍待验证。

两遍的 19 项掩膜产物和 19 项渲染产物分别逐件同哈希。另从 18 张掩膜和成片复核并集保持旧掩膜，所有新增像素变化均位于新增范围内。报告 SHA256 `21806a6f58f0ab59a7f1f0f472e9d6c719b516426f88515274578501ce585486`。本机对照位于 `outputs/adaptive-reference-20261113/skin-spectral-crop-gate-v1`。复现使用[上一轮环境](2026-11-19-skin-spectral-scene-gate.md)，便携皮肤定位 Python 用 `runpy` 执行 `probe_skin_spectral_crop_gate.py locate <研究输出根> <新掩膜目录>`，视觉研究 Python 执行 `render <研究输出根> <新掩膜目录> <新输出目录>`。原片、掩膜及成片保留本机。
