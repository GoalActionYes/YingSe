# 给定编辑范围后，16×16 网格能重现背景冷色

上一轮白球服对照表明，扩展研究版依赖的整图颜色统计同时传递了背景冷色和人物偏色。本轮把参考分析和渲染分开。先给出已知的目标编辑范围，再用与现有渲染器相同的空间采样坐标，将范围拟合成 16×16 双线性网格。这个网格给各深度层相同的颜色偏移，只测简单编辑所需的渲染能力。见[参考支路对照](2026-11-18-reference-path-response.md)和[预先固定的协议](../../experimental/adaptive-reference-20261113/local-grid-capacity-protocol.md)。

六组沿用局部冷色开关的已消费照片、作者基础调色、编辑偏移和 80% 强度。准确范围重放逐像素匹配 18 张作者结果。网格只改变局部冷色的空间分配，整图冷色仍用已知的常数偏移。因此整图列用来检查重放一致性，无法衡量自动参考迁移的提升。

| 输出 | 局部背景响应与人物保护 | 全图冷色 | 无人负例 |
| --- | ---: | ---: | ---: |
| 13 号已保存结果 | 0/4 | 4/6 | 2/2 |
| 已知范围精确重放 | 4/4 | 6/6 | 2/2 |
| 已知范围拟合为 16×16 网格 | 4/4 | 6/6 | 2/2 |

白球服组中，人物近中性色的局部增量误差由 13 号的 **5.47** 降至网格重放的 **0.22** 个 RGB8 码值，背景主编辑区的方向投影由 **0.709** 到 **0.994**，准确重放为 1。四组的过渡区平均误差介于 0.79 和 0.84 码值。网格产生了越过编辑范围的偏移，原本保护区的最大偏移约为编辑全幅度的 52%，因此区域平均通过不代表逐像素贴边。完整色彩引导、复杂局部调色和原尺寸边缘尚未由这一探针验证。白球服对照图保存在本机输出目录。

两次运行用时 3.83、3.86 秒，各 36 张输出哈希一致。从实际 PNG 独立复算六项整图与四项人物误差，并逐像素复查作者重放。见[数值及输出身份](2026-11-18-local-grid-capacity-evidence.json)。

这一结果支持现有网格的简单偏移表达能力。下轮的验证重点是从正常两张输入中找出足以预测有效背景调色的证据，并在运行前和背景物体换色控制成对固定。已知范围、作者基础调色和固定偏移只在本轮离线对照中使用。没有软件升级，也未使用独立保留素材。

复现时设 `$env:PYTHONPATH = (Get-Location).Path` 和 `$env:OPENBLAS_NUM_THREADS = '2'`，使用项目已有研究 Python 运行 `experimental/adaptive-reference-20261113/probe_local_grid_capacity.py <新输出目录>`。所需前置材料见[局部冷色开关](2026-11-18-local-edit-toggle.md)。两遍完整输出保存在本机 `outputs/adaptive-reference-20261113/local-grid-capacity-v1` 及 `local-grid-capacity-repeat-v1`。
