# 连续颜色过渡减轻跳色，铁塔仍有方格

沿用台阶人像与铁塔、两组 32×32 留块和 80% 强度。把 RGB 网格中没有可靠数据的节点设为零位移，再用三线性权重直接相加。颜色支持越少，输出越接近原色。用上轮的固定支持蒙版与新增覆盖蒙版评分，保持比较范围一致。见 [事前协议](../../experimental/adaptive-reference-20261113/psbench-action-rgb-continuity-protocol.md)及[硬切换对照](2026-11-18-psbench-action-rgb-interpolation.md)。

| 目标 | 整图误差，13 号／硬切换／连续过渡 | 近中性色误差，13 号／硬切换／连续过渡 | 旧启停边界的跳变第 95 百分位，作者／硬切换／连续过渡 |
| --- | ---: | ---: | ---: |
| 台阶人像 | 15.46／7.00／6.72 | 16.77／4.27／4.08 | 5／20／4 |
| 铁塔 | 15.03／5.98／5.32 | 15.91／6.10／6.28 | 4／25／9 |

单位为 RGB8 码值。两图通过事先设定的误差和方向要求。人像近中性色误差由 4.27 降到 4.08，铁塔由 6.10 升到 6.28，升幅在预设 0.50 码值以内。铁塔边界仍超过作者 4 码值加 2 的上限，连续性整体未通过。

查看相同 80% 强度四列对照，人像白台阶比 13 号少了青色，紫裙仍未达到作者结果。铁塔的大块青蓝交界变软，天空仍有可辨方格。为定位剩余跳变，追加按旧支持蒙版的边界是否跨越 32×32 留块分组来统计。铁塔同组边界为 13,002 对，第 95 百分位 4 码值；跨组边界为 6,821 对，第 95 百分位 11 码值。人像对应 3 和 8 码值。这支持检查两份颜色表切换的影响，尚未直接验证整张图共用一份参考表后的表现。

两次运行的四张 PNG 和结果 JSON 哈希一致。独立复算 80 项误差与投影，核查固定边界及零位移回退的数值。追加分析在固定边界上按相邻像素的 `(y // 32 + x // 32) % 2` 是否相同分组，沿用同一跳变定义。见 [结果与哈希](2026-11-18-psbench-action-rgb-continuity-evidence.json)。

保留为离线对照，不接软件，不通过更改阈值消除失败记录。进一步验证时可固定整张目标共用一份仅从对侧参考前后图拟合的颜色表，区分留块实验造成的方格和颜色映射自身残差。这仍需要额外参考原图。自动两图估计、自然度、肤色专门指标及视频未验证。
