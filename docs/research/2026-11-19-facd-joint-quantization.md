# 扩大 SDR 参考对照后，多数组跟随参考颜色

同档两张参考只在亮度差超限的像素联合取整，仍使用原来的亮度和色度门槛。21 个原配对共有 431 处超限位置，全部在各通道向上或向下的相邻码值中找到合法解。由此有 **20／21** 个配对通过并可评分。剩下的 XProII 配对只有 23.10% 的共同暗档支持，仍低于 25%。原先唯一通过的 Hudson 配对保持原参考和输出。[事前协议](../../experimental/adaptive-reference-20261113/facd-joint-quantization-protocol.md)

使用相同 13 号权重、80% 强度和原固定指派，保存 80 张目标成片。目标近中性色的变化沿 80% 作者滤镜的方向投影。正值表示同向，1 表示相当于作者方向的完整幅度。区域用于离线评分，映色仍只读取原目标和一张参考。

| 检查 | 结果 |
| --- | ---: |
| 色度投影高于亮度投影 | 18／20 |
| 色度投影为正 | 19／20 |
| 色度／亮度投影中位数 | 0.431／0.050 |
| 亮度投影 ≥0.5 且高于色度投影 | 0／20 |
| 参考选亮档作者色度时，输出比目标原图更接近作者色度 | 10／20 |

在婚纱 Hudson 案例，湖景参考颜色变化的投影为 −0.181，参考亮度变化投影为 0.228。亮档作者色度的输出距作者从目标原图的 0.01027 升至 0.01310。可见参考色度通常能传递有效信息，但也可以沿错误方向影响人物和浅色衣物。现有结果支持保留色度传递能力并检查方向；继续单纯增加响应或固定压低色度，都缺少升级依据。[婚纱四组对照](../../outputs/adaptive-reference-20261113/facd-reference-factorial-joint-v1/64573/Hudson/comparison.png) · [全部分数](2026-11-19-facd-joint-quantization-evidence.json)

采用联合取整后，所有参考位置最大匹配亮度差仍小于 0.005。两次运行的 181 份产物逐字节一致。对落盘图独立复算了 20 个配对的亮度匹配、未超限像素的保持和目标效应，并核对此前通过的 Hudson 全部九份图保持。此实验用于开发诊断，未修改软件或开放独立保留集。
