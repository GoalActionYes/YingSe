# 迁移幅度与参考条件结构：单一占比不够，下一步检验多特征条件

本轮完成两个诊断，没有训练或接入新调色模型。第一，使用 GT 逐图选择当前 13 号与 C10 的占比，仍只能在 25／64 例上比 C10 改善超过 0.1 码值，达不到既有 36 例门槛。因此不继续训练这种固定 101 档凸混合策略。第二，源码与实际运行都确认：当前 13 号的注意力参考条件只有一个 token，该模块不能根据不同查询位置选择不同参考 token。

第二点不是整个映射恒定的证明，也不是已找出画质失败的唯一原因。当前模型仍根据目标图的特征生成空间网格，并通过目标依赖的 guide 应用变换。本轮研究的是我们使用的公开作者模型，不是剪映原生算法的反编译结论。

## 为什么先检查一个占比能不能纠错

[上一轮配对约束](2026-11-14-paired-style-contrast-study.md)仍未消除三张目标上的四个严重退化。先问一个容量问题：如果已知理想结果，是否只需在现有两个输出之间选一个合适的占比，就能达到本阶段要求？如果连这种 GT 辅助的选择都不够，就不投入训练一个同范围的占比预测器。

按[预设协议](../../experimental/adaptive-reference-20261113/blend-capacity-protocol.md)，两个端点固定为当前 13 号和 C10 第 7 轮的已保存 8 位输出，不换用最新的配对损失候选。只读已经使用过的 64 张开发结果和 GT；枚举候选占比 0–100，使用精确整数分子和最近偶数舍入。此占比是在两个调色结果之间选择，不是 App 中原图到结果的强度控件，也不是原始网格／浮点输出混合。

同时保留两种程序：每张图看 GT 各选一个 RGB 误差最低占比；所有图看 GT 共选一个平均 RGB 最优占比。并列取最早值。两者都依赖开发 GT，不是可用算法，不具有独立评估或产品升级资格。

| 64 张已用开发图 | RGB MAE | 参考 delta MAE | 相对 C10 改善超过 0.1 的例数 | 相对当前严重退化 |
|---|---:|---:|---:|---:|
| 当前 13 号 | 12.41128 | 15.12363 | — | — |
| C10 | 10.94288 | 13.44712 | — | 4 |
| GT 辅助统一占比 99 | 10.94286 | 13.44712 | 0 | 4 |
| GT 辅助逐图占比 | 10.21068 | 12.43326 | 25 | 0 |

逐图选择虽然使平均 RGB 相对 C10 改善 6.69%，但改善数量只有 25<36；参考 delta 改善组数为 17<20，暗亮部 Cb／Cr 关系误差相对 C10 反而增加 7.18%，两种程序的描述性完整门槛都未通过。即使描述性门槛通过，也不能把有 GT 的程序升级成用户算法。

逐图 RGB 最优同时给出了这 101 档选择中每例最低 RGB 误差，因此任何限定在同样端点、同样 101 档字节混合中的预测器，都不可能在本组取得更多超过 0.1 码值的改善例。这个必要条件足以停止本次单占比预测器方向。它不是连续占比、原始网格混合或所有调色算法的上界，也不是参考 delta／色度关系的联合最优：不能用后两项失败证明所有其他占比选择都失败。

占比中位数为 96，最小 0、最大 99；4 例选择 0。8 位量化会产生平坦最小值，所记占比只是最早最小值，不能解释为模型的可信度或真实风格强度。统一占比 99 与 C10 的平均差异极小，也不能当成有意义的产品改善。

## 当前注意力实际上如何读取参考条件

随后按[结构探针协议](../../experimental/adaptive-reference-20261113/attention-topology-protocol.md)，对真实冻结的当前 13 号权重及作者源码执行合成渐变输入。没有读取照片、更新权重或改 App。

实际张量为：目标编码特征 `[1,128,16,16]`，直方图编码条件 `[1,128,1]`，注意力输出 `[1,128,16,16]`。原始 128 档直方图经连续降采样和最后卷积，形成一个条件 token。softmax 只有一个候选时为 1，该注意力模块的值输出会在查询位置间广播。

| 运行检查 | 最大差或最大梯度 |
|---|---:|
| 注意力输出在查询位置间的差 | 0 |
| 固定条件、把查询取负后的输出差 | 0 |
| 查询输入梯度 | 0 |
| q 权重梯度 | 0 |
| key 权重梯度 | 0 |
| value 权重梯度 | 2030.11340 |

value 梯度非零，说明此检查不是整个分支都没有参与计算。结果与 singleton softmax 的结构推导一致，完整来源与形状见[结构探针数值](2026-11-14-attention-topology-evidence.json)。

单向量可以编码某些关系，后面的融合网络也可以根据目标特征非线性地使用它；因此不能把此结构叫作软件 bug、所有输出都是全局滤镜、八种预设混合，或参考关系不可能迁移。这里唯一确认的是：这个注意力模块没有多个参考 token 可供逐查询选择。它也没有证明这就是前面所有退化的原因。

## 下一步已固定，尚未实施

下一次按[参考特征集合对照协议](../../experimental/adaptive-reference-20261113/reference-patch-protocol.md)实施：在当前 13 号上增加零输出初始化的小型参考注意力分支。候选保留 4×4 共 16 个参考特征 token；匹配控制把同样 token 压成均值再重复 16 次。两组完整初始化、参数、样本和更新预算相同，分别新训练，不把 C10 冒充同架构控制。

这是局部特征集合条件，不是几何位置对应。没有位置编码时，交换 token 顺序不会改变注意力输出；它也不是人物／背景分割或预训练语义对应。两组有效机制和可用梯度不同，不能声称有效容量完全匹配。结果可能仍受物体本色干扰，必须实测。

候选必须同时通过对新均值控制和外部较强 C10 的两套既有完整门槛，不放松 RGB、参考响应、关系或严重退化要求；通过后才冻结新的独立素材，并继续验证原尺寸、视频稳定、速度与实际操作。当前没有这次训练的结果，不能提前称为效果提升。

本轮仅整理本地研究检查点，后续与该受控训练作为同一批次发布。现有 13 号、阶段 6、简单的参考图＋目标输入均保持不变，完整目标仍未完成。
