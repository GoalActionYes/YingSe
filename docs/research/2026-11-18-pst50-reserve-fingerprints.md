# PST50 保留输入没有触及预设近重复警戒线

固定 PST50 发布版本及第 16–50 组，下载目标原图和配对参考共 70 张，合计 222,508,285 字节。逐项匹配发布清单的 LFS SHA256 和字节数。此轮只计算身份指纹，没有查看画面、运行调色或读取保留段专家目标及视频。见[运行前协议](../../experimental/adaptive-reference-20261113/pst50-reserve-fingerprint-protocol.md)、[发布来源与许可](https://huggingface.co/datasets/zrgong/PST50)及[先前的精确字节核查](2026-11-18-pst50-reserve-audit.md)。

| 比较范围 | 对照数量 | 最小指纹距离 | 预警结果 |
| --- | ---: | ---: | --- |
| 保留段不同编号之间，两个输入角色交叉 | 35 组 | 14 | 无 |
| 已消费的本机图片 | 207 张 | 12 | 无 |
| 两版 TST 扩展训练登记的图像 | 9,553 份唯一原件哈希记录 | 12 | 无 |

本机对照覆盖 PST50 第 1–15 组的三个图片角色 45 张、自然开发输入 64 张、COCO 输入 60 张、FACD 32 张及 PSBench 6 张。对保留图及本机对照检查整图、水平翻转、中心 90% 裁切及其翻转，对 TST 复用整图指纹。海明距离不超过 6 位才触发既定预警。另检查原始和准备后像素身份，没有发现交集。35 个编号仍各自列为待核对的单组，没有因本轮发现而隔离的编号。见[结果摘要](2026-11-18-pst50-reserve-fingerprint-evidence.json)。

独立重读全部 70 份文件，重算 280 个 DCT 指纹，再以不同的位计数实现核对三个范围的最小距离。输入文件不带 EXIF 拍摄字段；13 份参考只有 DPI 记录。作者论文说明配对素材出自影视飓风专业素材库，但所查发布资料缺少逐编号的拍摄组和原镜头映射。以不同时间截帧、强裁切、拼接或其他未覆盖库重用素材仍可能漏检。见[作者的数据来源说明](https://arxiv.org/html/2506.13465#S4.SS1)。

此轮降低了可检测近重复的风险，35 组暂列保留资格待定，未参与模型、门槛或效果选择。正式验收前还需核实实际镜头分组和其他已消费来源；原有自然度、肤色与中性色、视频及真实人类判断要求保持。视频 40 和 40b 仍按同一编号计。未取得新的算法或产品画质结论。

本机目录为 `outputs/adaptive-reference-20261113/pst50-reserve-fingerprint-v1`。原输入和完整指纹不随 Git 发布。复现时在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path`，用研究 Python 运行 `experimental/adaptive-reference-20261113/probe_pst50_reserve_fingerprints.py <新目录> [--proxy <本机代理>]`，保留原已完成目录。
