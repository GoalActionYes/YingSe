# 按编辑器关闭态颜色匹配，未修复真实混光局部编辑

已知真人作者操作的直接重放在另一张照片上接近预期，但原混光照片仍超线，而且编辑器在关闭该操作时也改变了输入。为验证使用哪套颜色作为匹配坐标，本轮用已经归档的作者参数导出 32³ 色卡。由同一组开关色度差构成两套查询：一套在输入 RGB 中找近邻，一套在编辑器关闭后的 RGB 中找近邻。两臂均使用已知区域、80% 强度、相同近邻权重和色域处理。[原直接重放](2026-11-20-playraw-rendered-input-operator.md) · [事前协议](../../experimental/adaptive-reference-20261113/playraw-editor-chart-bridge-protocol.md)

| 混光原片高权重区，折 0 | 3.199 | 3.274 |

| 《Cuckoo》脸颊 | 0.507 | 0.507 |

误差单位为 RGB8。两套《Cuckoo》缓存分数相同。在两臂中，混光原片高权重区的两折误差都超出 3，虽风格投影仍在门槛内。所有实际输出在登记范围外逐像素保持，最大明暗量化差为 0.4854。该保护来自离线已知区域。关闭态颜色并未一一对应原色卡的 32,768 种输入，中央取样只有 31,290 种输出颜色。以关闭态匹配时，近邻距离超过 8 RGB8 的像素占混光编辑范围约 1.50%，占《Cuckoo》编辑范围约 1.81%。[混光反例](../../outputs/adaptive-reference-20261113/playraw-editor-chart-bridge-v2/mixed/comparison.png) · [《Cuckoo》成片](../../outputs/adaptive-reference-20261113/playraw-editor-chart-bridge-v2/cuckoo-0/comparison.png)

首次导出后，倒序对照在比较前没有恢复块内坐标，误读为同点差异。恢复整个栅格坐标后，两种布局相同位置的值最多相差 1。独立检查还发现，同一输入色块内部的最大通道范围在关态为 84、开态为 74。旋转对照只验证了重新对齐后的稳定性，这个色块内部差异仍使当前导出链不适合当作纯逐像素映射。现有数据未定位到造成差异的具体模块。结束这套固定近邻桥接；若再提取逐颜色算子，需要先验证取样不受邻域、像素位置或导出处理干扰。普通两图仍需推断应施加的编辑及范围。产品与独立验收未改变。

## 复现

按[原编辑器实验的盘符映射及现有 CPU 环境](2026-11-20-playraw-rendered-input-operator.md)，把脚本换为 `experimental/adaptive-reference-20261113/probe_playraw_editor_chart_bridge.py`。将原项目和 `.tools/DeepWB-audit/vendor` 加入 Python 模块搜索路径，传入研究输出根目录与新结果目录的绝对 ASCII 路径。两遍各六张成片、三张图板逐文件一致，24 项区域误差独立复算一致。四张色卡导出的 RGB 中，三张逐像素一致，一张仅 599 个通道相差 1，报告因此保留两种输入身份。两轮候选数值一致。已知作者参数、蒙版、照片和完整导出保留本机。[完整数值、差异和哈希](2026-11-21-playraw-editor-chart-bridge-evidence.json)
