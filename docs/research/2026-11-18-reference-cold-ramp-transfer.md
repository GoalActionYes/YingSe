# 背景过渡判别未能迁移到不同局部边缘

此前在同一种羽化方式下认出了四张局部冷色参考。将特征和阈值冻结后，用从未参与该特征校准的六张原目标照片制作背景硬边及宽过渡版，同时保留原基础调色和整图冷色控制。照片已经用于项目开发。见[运行前协议](../../experimental/adaptive-reference-20261113/reference-cold-ramp-transfer-protocol.md)和[首轮结果](2026-11-18-reference-cold-ramp.md)。

固定阈值约 5.845。硬边版命中 0/4，宽过渡版命中 2/4，均低于各自至少 3/4 的门槛。16 张负例零误触发，其中两张无人图的八个版本均无判定。四组有人物的场景中，宽过渡分数均高于同图硬边和整图版本。硬边成片有已知的局部冷色，但背景内部的冷色增量已经均匀。这与本特征依赖背景近远色差的计算方式相符。首轮收益限定在固定羽化对照，停止把当前过渡特征作为自动保护的触发条件。

首次启动在核对阈值时退出，四舍五入的书写值与上轮保存值相差约 5×10⁻¹⁵。改用原报告完整精度 5.844976007785105，之前尚未生成图片或结果。之后两遍各约 3.8 和 3.7 秒，含生成参考、分割、计算与保存。24 张 PNG 和 24 份自动概率数组均在两遍逐张哈希一致，独立复算生成像素、特征值和判定。见[数值及哈希](2026-11-18-reference-cold-ramp-transfer-evidence.json)。

在已知开关的离线对照中，分配冷色仍能减轻白球服偏色。自动调色若继续处理类似局部风格，需要能跨过渡方式辨认的参考信息，并同时满足背景冷色保留和人物保持门槛。当前没有更换算法或验证独立自然样张。见[冷色重分配](2026-11-18-local-chroma-redistribution.md)。

复现时运行 `python experimental/adaptive-reference-20261113/probe_reference_cold_ramp_transfer.py <新输出目录>`，需要冻结开关对照及本机 DeepLabV3 权重。本机两遍目录为 `outputs/adaptive-reference-20261113/reference-cold-ramp-transfer-v1` 和 `reference-cold-ramp-transfer-repeat-v1`。
