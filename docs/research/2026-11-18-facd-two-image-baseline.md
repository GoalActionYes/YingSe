# 13 号对同滤镜换照片的响应大于对换滤镜的响应

使用去黑边后通过原结构门槛的七组。每张目标使用固定前后两组参考，每组各有 Amaro、Hudson、XProII 三种作者成片。预测只读目标原图和一张参考成片。先保存 42 张原尺寸 80% 输出，再用目标作者成片评分。婴儿近照 488102 因 Amaro 预先未通过结构核查未进入本轮，原结果仍保留。见[预先固定的协议](../../experimental/adaptive-reference-20261113/facd-two-image-baseline-protocol.md)与[去黑边记录](2026-11-18-facd-border-registration.md)。

| 检查 | 实测结果 |
| --- | ---: |
| 同滤镜换参考照片，平均整图输出差 | 16.50 码值 |
| 固定参考照片换滤镜，平均整图输出差 | 15.20 码值 |
| 相对作者成片的平均整图误差，保留原图／13 号 | 19.97／18.88 码值 |
| 同款稳定、不同款响应及目标误差三项联合通过 | 0/7 |

七组各自在三项检查中都至少有一例失败。固定参考照片换滤镜的 42 个方向投影均为正，有部分真实风格响应。最弱投影为 0.082，低于预设 0.50。最大的同款换参考差为 26.66，是倒挂马蹄莲 261132 的 Hudson 对照。用玻璃顶棚作为参考时，其暗背景明显转蓝，在同一轮用婚纱人像作参考时偏暗紫。

婚纱人像 64573 用的是湖景 244905 与马蹄莲 261132 的成片。两份参考同为 XProII 时，目标输出的整图差 22.94 码值，近中性色差 20.70 码值。湖景参考的婚纱偏青，马蹄莲参考的婚纱较白。作者同款成片本身给婚纱加了黄色，不能把它当作自然白色的唯一目标。其余目标与三种滤镜均保留。见[数值与文件哈希](2026-11-18-facd-two-image-baseline-evidence.json)。

两个运行的 42 张 PNG 和结果 JSON 哈希一致。另从已保存像素复算 378 项误差及方向判断，生成每组并列对照。已查看预先关注的婚纱和最大同款差反例。结果表明现有输入特征仍会把参考照片自己的颜色带入目标。这里只验证七组中三个固定滤镜的相对响应，不用来推断任何系统级风格辨别率。合法的强滤镜也能改变肤色、白衣与暗角，完整独立画质评估仍需另行验证。

七组可以在新的两图方法中同时检查同款稳定与换款响应，避免仅通过减弱强度追分。本轮未训练或更换模型，课程演示保持现有版本。运行目录为 `outputs/adaptive-reference-20261113/facd-two-image-baseline-v1`，各目标子目录的 `comparison.jpg` 含目标原图、两张参考、两张对应输出和作者结果。
