# 加入三组同款实拍，白球服的换款幅度反而下降

上一轮只改变了参考取样。这一轮增加扑克、实体色卡和焊工的照片内容。三组都使用各自同一原图生成两款已知调色，沿用既有配对。每次将这三组与当前参考一起拟合，四个来源在各通道内等权。对照使用当前参考单独拟合。所有成片使用同一三次色表表示和 80% 强度，目标成片仅用于评分。[事前协议](../../experimental/adaptive-reference-20261113/paired-added-sources-protocol.md) · [仅 Film B 的既有三来源对照](2026-11-19-pooled-paired-film-b.md)

| 留出区域 | 换款投影，单来源 → 四来源 | 响应 MAE，单来源 → 四来源（RGB8） |
| --- | ---: | ---: |
| 白球服，C1 背景 | 0.537 → 0.427 | 1.598 → 2.169 |
| 白球服，F1 背景 | 0.606 → 0.430 | 1.546 → 2.205 |
| 前景手臂，C1 背景 | 0.762 → 0.644 | 0.882 → 0.980 |
| 浅墙，C1 背景 | 0.866 → 1.002 | 0.503 → 0.607 |
| 投影幕中的脸，C1 背景 | 1.149 → 1.529 | 1.480 → 1.901 |
| 投影幕中的脸，F1 背景 | 0.951 → 0.436 | 1.111 → 1.503 |

两项白球服都低于预设 0.75，手臂、投影幕和雪地场景还出现超线退化。浅墙仍通过。投影幕场景的 C1 近中性色，落入参考已出现颜色箱的像素从 103／306 增为 306／306，响应误差也下降了，但同一画面的脸并未随之改善。白衣 83 个留出像素在两种背景下本就都有同箱样本，新增来源未改变这一粗分箱覆盖。覆盖只表示有参考样本落在同一颜色箱，无法说明同箱样本够不够近，或新增信息是否传递给这个区域。[本机白球服图板](../../outputs/adaptive-reference-20261113/paired-added-sources-v1/872-1268/comparison.png) · [本机投影幕图板](../../outputs/adaptive-reference-20261113/paired-added-sources-v1/8021-8690/comparison.png)

到此结束固定四来源等权拟合。均匀已知色样曾改善白衣，三组真实同款照片在本轮无法复现这一收益。后续若检验颜色监督，理由应来自实际关键颜色的细粒度覆盖或已知编辑操作提供的新信号，仅增加来源数量已不足以支持继续。普通参考输入仍只有调色后的图像，四组测试均为已消费开发素材，结果不进入独立验收。

## 复现

在原视觉环境将仓库根目录加入 `PYTHONPATH`，设置 `OPENBLAS_NUM_THREADS=4`，执行 `python experimental/adaptive-reference-20261113/probe_paired_added_sources.py <新的输出目录>`。复制局部配对四份得到的色表与原表误差不超过 `1e-7`，渲染逐像素相同。两遍各 16 张新成片、四张图板及报告逐件同哈希，从落盘成片独立复算 26 项区域评分。原取样与原加权入口各复跑 21 件文件，同各自正式报告完全一致。本轮报告 SHA256 为 `819513eae61dd0aa966231cf5db1488f946ed06d232f60f53ff5f23815a28224`。[脚本](../../experimental/adaptive-reference-20261113/probe_paired_added_sources.py)
