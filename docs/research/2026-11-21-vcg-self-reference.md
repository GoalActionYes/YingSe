# 扣除 VCG 的共同自调色偏移，未恢复参考风格

VCG 跳过预处理后，首个跨人物对照的目标仍有明显关闭态偏色。本轮固定已生成的四个普通两图色表。把每一张参考也作为模型的目标，另生成一个自参考色表，再从普通两图色表扣除它相对恒等表的改色量。这样可直接检验基础偏移能否解释失败。候选只读取当前两张 RGB，调色前参考附件、目标正确成片和区域均未参与生成。[事前协议](../../experimental/adaptive-reference-20261113/vcg-self-reference-protocol.md) · [冻结的完整两图结果](2026-11-21-vcg-first-grade.md)

| 范围 | 关闭态误差，冷灯，原 → 校正 | 关闭态误差，暖灯，原 → 校正 | 风格投影，冷／暖，校正后 | 开启态换灯差，校正后 |
| --- | ---: | ---: | ---: | ---: |

| 左脸颊 | 16.25 → 9.07 | 24.49 → 16.19 | 0.307／0.493 | 6.78 |
| 右脸颊 | 18.74 → 8.29 | 28.82 → 19.66 | 1.287／1.850 | 9.12 |
| 左白幕 | 16.15 → 5.38 | 15.65 → 8.67 | −0.152／0.460 | 6.56 |
| 右白幕 | 16.11 → 5.37 | 15.49 → 8.56 | −0.160／0.451 | 6.40 |

误差单位为 RGB8。同一参考拍摄的冷暖和开关四状态生成完全相同的自参考色表，距恒等表平均约 16.03 RGB8。固定配置的特征差在同图输入时归零，与四次产生同一张表相符。扣除共同色表降低了五个区域的关闭态误差，但同一固定偏移在线性差分中会抵消，只有限幅和量化等环节能改变实际风格增量。本轮四张校正表有 5.13%–6.75% 的分量需要限幅，整图风格投影几乎不变，五个区域联合仍为 0／5。相同输入的两份自参考表相减后经 PNG 路径逐像素保持原图。该同图控制不等同于跨场景有效。

停止这一固定偏移校正，不扩大到其他方向。结果说明 VCG 首组偏差的一部分可归到共同改色，但消除它无法替代学会响应有意的风格变化和抑制拍摄灯色。只覆盖一个已消费的跨人物方向和同一混合精度权重配置，未获得软件、自然度或视频验收。

两遍新实验约 93 秒和 33 秒，4 张 PNG、8 个 NPY 及报告逐文件一致。另从保存结果复算四张差分表及五个区域的原门槛数值。原入口重新执行后，其 8 张 PNG 和 8 个色表逐文件复现。沿用 [完整 VCG 运行环境](2026-11-21-vcg-first-grade.md)，将脚本换为 `probe_vcg_self_reference.py`，参数仍为来源目录、作者源码、完整权重和新的输出目录。成片留在本机 `outputs/adaptive-reference-20261113/vcg-self-reference-v1`。[数值与文件身份](2026-11-21-vcg-self-reference-evidence.json)
