# 同图参考零漂移修复

2026年11月5日。正式修复范围：目标图片或视频分析帧与参考图，解码为完全相同的RGB字节时，返回恒等映射，各强度不额外改色。不同文件名、PNG/BMP无损副本和从视频解码保存的帧均按像素判断，不按文件名判断。

## 原因与正式策略

原重建特征对目标mode0和参考mode1采用不同的直方图区间、均值与端点规则；同图也可能得到非零阴影、高光和对比度参数。样例2008_007676的源亮度均值约20.28/93.55/185.25，参考约9.22/29.39/164.06，生成的S=-0.45、H=-0.30、white=235、contrast=1.1。同图100%输出全图RGB MAE约16.30。精确浮点恒等网格和零强度均无漂移，指向生成映射的非中性响应。

这些差异来自现有重建实现，不能据此断言剪映原生也如此。保留features、参数求解和shader恢复公式；在产品管线中增加精确像素相等时的恒等策略。原参数诊断保留，并增加neutral_calibration标记，明确recovered_native_policy=false。缓存算法指纹包含新模块，旧映射不会静默复用。

曾试验全面差分校准：identity+raw(source,reference)-raw(source,source)。12份图片×六类输入共72组，同图误差归零，部分颜色测试改善，但12组对比度有7组恶化，近似图也有退步，因此未作为默认算法。该研究结果完整保留。正式管线只对像素完全一致的输入校准；其他输入继续使用原有映射，逐值回归测试确认。
