# 同机位补光差分比值未通过双光源实拍对照

在目前的白球服对照中，参考人物保持不变，换背景仍会改变目标球服的颜色。分出人物范围之后，软件还需要判断看到的颜色来自物体、光照，还是有意调色。灰球测点插值未能提供足够可靠的稠密光色信息。本轮用同一场景多拍一张带补光的图，检查这种额外观测能否减轻表面颜色对双光源混合估计的影响。见[事前协议](../../experimental/adaptive-reference-20261113/flash-ratio-protocol.md)。

使用 Hui 等的 `book` 和 `conference_room` 两组公开线性 RGB 示例，每场景两张 493×738 图。把加补光图减去环境光图，随后用环境光 RGB 逐通道除以该差分。与直接使用环境光 RGB 相比，两种方法都在相同像素上拟合色度直线，按 4×4 网格整格留出后测正交距离。作者蒙版用于离线选取有效像素。见[作者论文与数据入口](https://huizhuo1987.github.io/illuminationEdit.html)和[示例目录](https://github.com/huizhuo1987/illuminant_separation/tree/master/data/images/two_lights)。

| 场景 | 共同有效像素 | 中位距离，环境光 → 差分比值 | 90 分位距离，环境光 → 差分比值 | 预设门槛 |
| --- | ---: | ---: | ---: | --- |
| 书本 | 18,891 / 22,940（82.35%） | 0.01083 → 0.00897 | 0.02356 → 0.01604 | 未通过 |
| 会议室 | 5,911 / 22,940（25.77%） | 0.00518 → 0.00522 | 0.01216 → 0.01531 | 未通过 |

合成可分离对照的差分比值 90 分位距离为 5.98×10⁻¹⁶。书本实拍的中位距离下降 17.15%，绝对下降 0.00186，低于事前设定的 25% 和 0.005。会议室中位距离略升，90 分位距离上升约 25.92%。两场都达到样本覆盖门槛。整格留出衡量的是颜色落在同一条线附近的程度，两个 MAT 示例没有独立的光源颜色标签，无法据此判断混合轴方向或白平衡是否正确。

结束固定 RGB 通道相除的诊断。保留补光配对作物理研究素材。对软件最直接的未决问题仍是，普通参考图里能否只从观察到的色彩区分物体本色、光照与有意调色。若再研究额外拍摄信息，应先找到带独立光色标注或可隔离光源的配对，检验实际光色误差。本轮没有生成调色成片或接入软件。论文中的光谱模型未纳入本轮比较。

复现用 Python 3.12、NumPy 2.5.4、SciPy 1.16.3。将作者目录的两个 MAT 保存到本机输入目录，用 `python experimental/adaptive-reference-20261113/probe_flash_ratio.py <输入目录> <新结果.json>` 运行。脚本按 Git blob 校验输入，两次输出字节一致。另用逐像素筛选、奇异值分解及叉积复算，两组有效像素数与各分位数一致。源图和环境留本机。见[数值与输入校验值](2026-11-19-flash-ratio-evidence.json)。
