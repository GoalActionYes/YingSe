# 用灰度图做参考肤色定位，无法减少换背景偏色

上一轮给同一个参考人物换背景后，借用原背景下的肤色选区能让两个目标人物的偏色减轻。软件平时只有当前参考图，所以这轮尝试让定位器只读灰度，看看能否减少背景颜色的干扰。实际取色仍读原参考图，目标定位和 13 号基线也保持原有输入。四组固定开发配对各包括两个参考背景及编辑开关两态。[事前协议](../../experimental/adaptive-reference-20261113/reference-skin-gray-locator-protocol.md) · [上一轮诊断](2026-11-20-reference-skin-chroma-attribution.md)

| 编辑打开时的目标区域 | 原彩色定位 | 灰度定位 |
| --- | ---: | ---: |
| 785 脸部 | 6.75 | 10.65 |
| 9483 前额 | 6.67 | 20.15 |
| 9483 手背 | 7.07 | 23.20 |
| 白球服场景的人物手臂 | 1.16 | 1.09 |
| 8021 投影幕中的脸 | 3.37 | 10.11 |

数值为同参考人物换背景前后，目标局部的 RGB8 色度差。在这组受控输入中，值越大，背景改变对该区域的影响越大。六项重点肤色读数全部上升，达到改善门槛的为 0/6。投影幕关、开状态分别多出 2.51、6.74 RGB8，超过预定退化限。雪地、浅墙、白球服在两种编辑状态下读数均保持原值。白球服场景手臂在编辑关闭时由 0.96 升至 0.99，打开时小幅下降。[本机 9483 原定位成片](../../outputs/adaptive-reference-20261113/reference-skin-chroma-isolation-v1/background/9483-19432/F1-on.png) · [本机 9483 灰度定位成片](../../outputs/adaptive-reference-20261113/reference-skin-gray-locator-v1/9483-19432/F1-on.png)

八项配对中有六项的权重差变小，却没有带来重点肤色收益。9483 两张 F1 参考的灰度定位都未检测到肤色，触发回退。由此关闭这个定位输入方案。下一步有必要先核对定位器训练任务是否区分实拍人物与画面里的脸、是否能保住非脸部肤色，再决定有没有理由替换定位器。换背景差缩小只能说明一致性，选区保留和成片都要另测。
