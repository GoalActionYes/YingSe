# 现有色温与色调可减轻局部肤色偏移，但全图应用会牵连环境

本轮从三组已使用的开发成片中选用原先登记的五块直接肤色与一块浅墙。C1 与 F1 使用同一个目标和同款编辑，参考背景不同。把 C1 当作同风格测量锚点，只在每个小框的一半交错像素上用现有色温与色调估计参数，在另一半上评分。两种输出的参数完全相同，区别是全图应用，或仅在该位置内应用并使用八像素软边。人工选区与 C1 只供离线实验，软件原有控制没有改动。[事前协议](../../experimental/adaptive-reference-20261113/local-manual-color-scope-protocol.md) · [原区域与成片](2026-11-18-bg-real-skin-regions.md)

| 位置 | 留出像素数 | 原色度差 → 调整后 | 全图应用对区域外的额外改动 |
| --- | ---: | ---: | ---: |
| 滑雪者面部 | 10 | 2.571 → 0.788 | 4.818 |
| 人像前额 | 12 | 1.566 → 0.715 | 1.147 |
| 人像手背 | 14 | 1.515 → 0.642 | 2.402 |
| 人像旁浅墙 | 157 | 0.633 → 0.558 | 0.497 |
| 球场前景人物手臂 | 18 | 2.109 → 0.731 | 1.174 |
| 球场后方人物脸颊 | 14 | 2.263 → 0.932 | 1.445 |

单位为 RGB8 MAE。所测核心区域内，两种方式的结果相同，五块肤色均达到至少 15% 改善且色度差不超过 1.5 的开发门槛。浅墙只改善约 11.9%，因此整组预定门槛没有通过。手背的亮度误差从 0.971 增到 2.370，说明已有色温与色调会改变明暗。肤色测的是小块内部，不代表整张脸的颜色或边界表现。

六张局部成片在软边以外均逐像素保持，软边内平均改动为 0.420–0.996。全图处理在滑雪照的无关雪地另改 5.333，在两块球场肤色修正中令白球服另改 2.109 和 2.609。局部面积与位置是实验指定的，区域外保持属于实现约束，不能当成模型会准确识别人物或墙面。[留出误差、参数与成片身份](2026-11-20-local-manual-color-scope-evidence.json)

## 决定

位置控制能避免同一组手动颜色参数牵连其他材质，对局部肤色小块有可见作用。下一轮如继续，先在更完整的人脸或墙面范围检验边缘与明暗控制，并保留用户原有局部风格。两张封存的真实墙面此次未读取，仍作独立验收保留。本轮无自动定位、无界面改动，完整自动画质、独立自然评价与视频要求继续保留。
