# 同款滤镜仍需要改变近中性色的色相

在 FACD 的七组照片和三款已知滤镜中，即使直接使用作者成片的明暗，并为每个像素选最有利的饱和度，固定目标原色相仍无法复现多数近中性色变化。婚纱 XProII 的近中性色连续误差下界为 **10.40** 个 RGB8 码值，作者给婚纱的黄色未能重现。见[婚纱三款并列图](../../outputs/adaptive-reference-20261113/facd-fixed-hue-limit/wedding.jpg)及[同款换参考基线](2026-11-18-facd-two-image-baseline.md)。

沿用七组结构检查通过的照片、同坐标裁切和 80% 作者成片。把每个目标像素限制在原色向与作者 Y′ 相交的 RGB 色度射线上，并使其与作者成片的三通道绝对误差最小。每个像素可独立选择幅度。另保留只用作者亮度、尽可能保持原色度幅度的参照，以及两张同款参考各自的 13 号输出。前两个对照读取目标作者成片，属于表达能力检查。逐像素独立选幅度会在部分皮肤或衣料处放大颜色细节，空间平滑和自然度均无保证。见[事前协议](../../experimental/adaptive-reference-20261113/facd-fixed-hue-limit-protocol.md)。

| 滤镜 | 整图连续下界均值 | 近中性色连续下界均值 | 近中性色下界 >2 码值 |
| --- | ---: | ---: | ---: |
| Amaro | 6.11 | 4.77 | 6/7 |
| Hudson | 2.74 | 3.64 | 7/7 |
| XProII | 7.99 | 6.94 | 7/7 |

三个滤镜均达到事前规定的至少四组条件。全部 21 项的近中性色范围都有至少 256 像素。保守扣除每通道最多 0.5 码值的舍入影响，超过 2 码值的计数仍是 6／7／7。婚纱 Amaro 的近中性连续下界只有 1.72，保留为反例。近中性色代理包含衣料等目标原有低色度区域，未标成专门的白墙或肤色区域。

这批已消费照片可用于检查候选是否保留有意加色。后续应与[白球服背景串色负例](2026-11-18-target-hue-retention.md)一起使用，要求同一方法能在负例抑制偏色、在已知滤镜正例保留有意色向。本轮只验证固定色相的表达限制，尚无算法推理、自然画质或软件验收成绩。

两遍各 42 张 PNG、婚纱面板和报告哈希一致。用整数 Rec.709 系数和加权中位数独立核对连续最优误差，再从落盘像素复算区域结果。开始时错误地要求带补充字段的证据 JSON 与原报告全等，随后改用证据中保存的原报告哈希核验，输入、公式与门槛均未变。见[精确数值和哈希](2026-11-18-facd-fixed-hue-limit-evidence.json)。

在既有自适应研究环境运行 `probe_facd_fixed_hue_limit.py <FACD 对齐目录> <对齐证据 JSON> <13 号基线目录> <13 号证据 JSON> <新输出目录>`。原图和成片留本机。
