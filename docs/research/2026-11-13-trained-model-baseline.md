# 已训练模型基线：跨场景与速度验证

## 实际运行与来源

不是自训练成果，也不是剪映引擎。使用 [CanonCGT 作者代码](https://github.com/Jinwon-Ko/CanonCGT) 的 E2E 阶段权重，固定源码提交 `229a7d3ec24af19ea5d97bb136f0317762bb9261`，保留 Apache-2.0 授权，检查作者源码未被修改。使用 torch.load(weights_only=True)，所有推理参数必须完整匹配，只排除推理类没有使用的 57 个训练风格中心键。未使用 strict=False 掩盖缺失参数。

权重 SHA256 `916f7ad5028d3fef51cf915bb51febc9508e7a378c0babe9ff3d3992b8c594f7`。仓库 SSL.pth 为 2 字节，不能加载，故报告不声称使用最终 SSL 模型。MobileNet 构造时取消重复的 ImageNet 下载，然后由完整作者权重覆盖全部推理参数；检查缺失键与形状，不保留随机骨干权重。

独立 `.tools/adaptive-env` 从 PyTorch 官方 cu124 源安装 torch 2.6.0+cu124、torchvision 0.21.0+cu124，NumPy 2.5.4、Pillow 13.0.0。pip check 通过。依赖不写入主版 requirements，不更改稳定版运行时。源码、原始照片、模型和约 2.5GB 的 GPU 依赖均保留在忽略目录，不作为轻量便携版已交付。

## 同条件跨场景控制比较

直接复用已冻结的 150 组输入与数值对照；模型只接收目标 A 与调色参考 B，目标真值在推理后才读取用于评价，没有训练或调参。它们是历史照片合成风格开发对照，不是独立自然照片审美评估，150 组也不是 150 个独立场景。

| 方法 | 较主版改善 | 较主版恶化 | RGB MAE 中位数 |
| --- | ---: | ---: | ---: |
| 当前全局主版 | — | — | 12.179 |
| 区域均值／方差残差 | 21 | 125 | 14.524 |
| 作者 E2E 学习式模型 | 102 | 45 | 8.866 |

改善／恶化阈值 0.1 码值，不代表人眼可见门槛。模型另有 3 组变化不大。不能把 102/150 转为真实用户成功率或盲评偏好率。

| 类型 | 改善／恶化 | 主版中位数 | 模型中位数 |
| --- | --- | ---: | ---: |
| 恒等附加风格的不同参考 | 23／6 | 11.900 | 7.877 |
| 暖色 | 23／6 | 12.245 | 8.227 |
| 冷色 | 21／9 | 12.134 | 9.214 |
| 对比度 | 19／11 | 12.674 | 10.793 |
| 去饱和 | 16／13 | 11.496 | 10.055 |

模型表征比区域直接对齐更值得继续评估，但 45 组恶化不能忽略，不能默认替换当前全部路径。

## 自然示例观察

运行作者仓库固定的全部八对输入／参考，包含食品、建筑、风景、人物、花园与帆船。输出和整张总览已生成并目视检查。存在可见的不同风格处理，也有亮度、饱和度与偏色的取舍；没有人工目标效果或多人盲评，未捏造画质分数。这些是作者挑选的示例，不当作独立留出集。

## 同图漂移与已准备映射复用

另以十张 A→A 测试原模型，RGB MAE 中位数约 2.129。模型自身不能保持同图恒等。未来产品应复用主版已验证的解码 RGB 相等分支，绕过模型，不宣称模型天然具备该能力。本轮尚未接入产品选择器。

新增 GPU 两阶段固定 LUT 处理器 `gpu_mapping.py`。对十次实际模型输出，复用预先生成的两张 LUT 与直接推理输出相比，最大误差均不超过 1 码值。零强度逐像素返回原图；独立测试检查 RGB 通道顺序、两阶段执行次序与无效强度拒绝。

1920×1080 RGB8 单帧十次实测：中位数 0.01489 秒，95 分位 0.01872 秒，包含 CPU→GPU 输入和 GPU→CPU RGB8 输出。它只证明固定颜色映射处理有实时潜力；不含解码、播放器显示、编码或逐帧模型估计，不证明完整视频 30fps、时间稳定性或跨镜头适配。

完整模型在 480 边长控制输入上的前向推理中位数约 0.1204 秒，95 分位 0.1412 秒，不含输入上传与输出下载。第一个冷进程加载约 95.8 秒，后一次约 3.16 秒，冷启动差异不可隐去。

源码中模型生成并执行两张全局 LUT：内容可影响生成规则，但相同输入 RGB 在固定映射中仍得到相同输出。因此该模型基线没有直接完成用户要求的按内容区域分别处理全部关系。后续需要验证学习式风格表征与区域条件如何结合，不能靠“用了模型”宣布完成目标。

## 复现入口

实验目录 `experimental/adaptive-reference-20261113`：

1. 用 Python 3.12 创建 `.tools/adaptive-env`，从上述官方源安装 requirements-model.txt。
2. 克隆作者仓库到 `.tools/CanonCGT`，切到固定提交；保留 LICENSE 与完整权重。适配器会拒绝不匹配的源码版本、修改过的跟踪文件或不同哈希的权重。
3. 先完成 cross_scene_protocol.md 中的固定输入生成，再用该环境运行 `check_canonical_model.py`（不带 --limit 才是全部 150 组）。
4. 运行 `review_author_samples.py`、`summarize_canonical.py` 查看全部八对示例和汇总。
5. 运行 `check_prepared_model.py` 核验同图漂移、映射复用与 CPU↔GPU 耗时；运行所有 test_*.py 检查基础约束。

脚本运行时将本实验目录加入 sys.path。GPU、模型、素材路径和运行环境均独立于稳定版。
