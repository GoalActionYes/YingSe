# 真实样张对应试验与原始分析输入修复

本轮交付一项已验证的研究版修复：公开模型现在从原始解码图片／分析帧估计调色，预览独立缩小。新试验的语义颜色锚点、局部残差和自动全局选择没有达到稳定改善要求，均未接入默认算法。完整自适应协调目标仍未完成。

[机器可读证据](2026-11-13-dense-anchors-and-native-input-evidence.json)保留分辨率诊断、各轮全部结果、固定分组、预测冻结记录、模型版本及HTTP验证。原照片、模型、独立环境仍不入库。

## 已修复：分析输入不应随预览尺寸变化

复核新旧公开模型结果时发现：研究工作台在分析前把原图额外缩至最长640。相同权重、源码、环境下，五对1080p原图推断均完全复现历史输出；先缩640再推断，结果与原图推断平均每通道相差8.956–19.604码值。改变输入分辨率确实影响模型估计，不能当作仅减少计算量的等价操作。

`LearnedStore.analyze_engine`移除额外缩放，将解码后的目标与参考原样传给模型；同图保持、模型锁、64³映射编译及预览缩小均沿用原流程。缓存身份包含修改后的源文件，因此旧模型映射需要重新分析，原素材／工程记录保留。修改前先验证并停止自有服务，修改后重启，没有按进程名关闭程序。

回归检查先因目标实际收到360×640而失败，再验证目标720×1280、参考810×1080的尺寸与RGB像素原样传递。真实HTTP补验使用独立服务／数据目录，不替换用户最近工程：

| 检查 | 记录 |
|---|---|
| 自然图分析尺寸 | 1920×1080 |
| 首次分析／再次分析 | 约0.584秒／命中缓存 |
| 带不同强度的交互预览 | 约0.242–0.345秒 |
| 原尺寸PNG与作者直接RGB8输出 | MAE0.089，最大差1码值 |
| PNG与同一64³映射CPU输出 | 完全一致 |
| 图片／CUBE／工程恢复／同图／零强度 | 原有真实接口检查重跑通过 |
| 合成短视频 | 8秒960×540、24fps，输入／输出整片均192帧 |

完整预览有独立1440边长限制，不能直接与1920原图逐像素相减。按相同预览输入像素比较，64³合并与作者双阶段插值MAE0.460、p95为1、最大差10，超过5码值的通道约0.0168%。先前小样本最大8不是全色域误差界。验证中两次错误比较条件及失败目录保留；原尺寸PNG另行对照，不隐去预览的合并近似误差。速度与精度都只覆盖所测样张，不代表全部用户素材、超大照片或实时视频。

## 试验方法与限制

参考[Deep Image Analogy](https://www.microsoft.com/en-us/research/publication/visual-attribute-transfer-deep-image-analogy/)和[Progressive Color Transfer](https://arxiv.org/abs/1710.00756)中以深层对应辅助颜色迁移的方向，测试能否用相近内容提供颜色证据。不是这些论文的完整复现，也不是剪映算法。

使用固定版本DINOv2-small最后层patch特征，目标与参考做余弦匹配；4个相似参考patch的RGB均值形成颜色锚点。最大相似度及反向匹配一致性给出权重。该权重仅表示描述子一致，不能证明材质、颜色本色或照明条件相同。[特征模型卡](https://huggingface.co/facebook/dinov2-small)

固定比较三种新分支：在现有全局结果上拟合受限全图仿射残差；再加入RGB引导上采样的局部颜色残差；仅用锚点误差选择现有／Canon全局输出的混合比例。均只改变颜色，不移动像素，不生成纹理。全局／局部残差限幅和权重在查看新样张前固定。

第一轮仅用已使用1–5对，发现局部处理总体未优于全局。原图Canon比较修复前／后两轮分别保留，不能跨轮挑选分数。原始同图锚点仍有约0.8码值误调，暴露了软对应平均和采样差异，不称为同图通过；产品接入前必须单独解决或明确保持策略。

## 新10组开发对照

第6–15对在读取实际图片前确定为第二轮开发素材。先下载目标与参考，完成全部10组预测并保存文件哈希与完成记录，之后才下载专家目标评分。10组无推断失败，未逐例改参数或借助专家结果选择输出。

第6–15对已经使用，不能再称为未见测试；第16–50对未下载用于本轮，原300图的最后30张也仍未用于候选推断。

| 方法 | 平均RGB MAE | 相对现有版改善／退化 | 严重退化 |
|---|---:|---:|---:|
| 原始输入 | 13.195 | 8／2 | 1 |
| 现有全局 | 18.435 | 基线 | 0 |
| 原图Canon | 15.622 | 5／4 | 2 |
| 锚点全局残差 | 18.293 | 2／4 | 0 |
| 锚点局部残差 | 18.514 | 2／4 | 1 |
| 锚点选择现有／Canon混合 | 17.030 | 3／0 | 0 |

改善／退化使用0.1码值容差；严重退化指同时多于5码值且增加25%以上，未达到容差的列为保持。分数只是与配对专家结果的颜色距离，不是主观审美。原图均值更低也不能推导为用户不需要调色，它说明全强度迁移在这些场景经常过度。

实际查看北极光、雪地加油站、暮色山间建筑等对照：局部场可以改变画面，却会把参考中的不同明暗条件误当成应该转移的颜色。加油站例子中，参考大面积天空的色彩关系与目标主体附近的照明不同，简单对应不能得到专家结果。没有用全图分数声称人物关系已正确，也没有通过平滑掩盖错误匹配方向。

## 自动强度／方法选择扩展

第二轮发现原图往往比全强度结果更接近专家目标，因此另立协议：将原色加入两个动态估计映射作为第三种全局假设，最小化同一锚点的加权颜色误差，权重非负且和为1。精确检查二维凸问题内部及三条边界；仍不使用专家结果、预设滤镜库或人工逐例强度。

只在已用1–15对开发。全部15组输出先保存，再统一评分：

| 方法 | 平均MAE | 中位数 | 改善／退化 | 严重退化 |
|---|---:|---:|---:|---:|
| 原始输入 | 16.594 | 13.547 | 9／6 | 3 |
| 现有全局 | 17.867 | 18.088 | 基线 | 0 |
| 原图Canon | 16.950 | 14.045 | 8／6 | 4 |
| 自动全局选择 | 16.215 | 14.194 | 6／2 | 2 |

自动选择减少了一些过调，但仍有两例严重退化，不满足稳定协调的要求。它也只能选择全局变换，不能使同RGB在不同区域得到不同结果；不能用这个扩展替代最终局部关系目标。此次不接入产品、不消耗剩余35对测试素材。

## 验证和下一步

研究基础检查现为102项，新增原始输入传递、颜色对应、低置信回退、同RGB不同区域、RGB引导上采样、通道置换不变性、凸全局权重恢复等检查。白色软匹配凸组合曾因float32舍入超过1，回归先失败，再在验证输入后恢复数学范围。独立代码审查覆盖输入修复、对应与引导索引、预测／专家目标隔离；基础检查不代替自然图验收。

本轮确认：提前缩图是可复现且已修复的输入一致性问题；语义patch接近不等于颜色／照明可对应。后续需要联合考虑对应关系与明暗层级，或以完整的语义颜色迁移方法作为对照，先减少错误对应，再谈图片实验版。不能只继续增加混合比例、调高匹配阈值或把某个开发平均数降低称为完成。
