# 新候选准备：真实参考原图的辅助分布监督

前一周期已完成真实参考迁移、共享RGB下界和固定guide表达对照。结论是参考前后信息有用，但参考参数不应直接当成目标参数标签。本轮据此固定不同任务：训练时从调色后参考的共享图像特征恢复其原图颜色分布；最终目标调色仍读取真实配对GT，不要求两场景共享变换。

它不同于已停止的局部输出修正头、冻结特征参数回归、GT拟合场监督及合成参考增强：原图只作为参考分布标签，不输入正常推理、不替换真实参考、不生成目标参数标签。外置512→128→384辅助头只训练使用，候选实际推理仍为原`appearance_forward`，本轮没有接入产品。

## 实际完成的准备

- 核对865条训练记录、829不同前后对、438原图；原图均属于训练content，不读取验证原图或新独立素材。
- 在原vision-advisor环境准备1267个输入的作者YCbCr三路128-bin分布，共1267×3×128 float32，逐项检查父文件、RGB256像素、形状、有限值、非负与归一化。每条记录绑定原图教师和当前参考教师。
- 在真实expanded-v2所选epoch4结构上，辅助损失得到非零共享img_projection梯度（梯度绝对值之和约23.20065）；未执行优化器，主模型完整state前后哈希相同。
- 标准推理未传辅助头或教师原图，64开发PNG与原epoch4逐像素一致。没有将旧未通过候选改成已通过，起点仍是研究权重。
- 两项单元测试验证归一化、共享编码器和辅助头梯度、Hellinger公式、冻结教师与非法分布拒绝，均通过。没有声称独立重训或新的画质验收。

`audit_reference_normalization.py`核查全部标签来源、缓存文件／分布、训练限定、64项桥接登记和源码身份；没有独立重新提取全部GPU分布或重复GPU推理。[证据摘要](2026-11-17-reference-normalization-evidence.json)保留范围与哈希，原图和分布数组仅留本机。
