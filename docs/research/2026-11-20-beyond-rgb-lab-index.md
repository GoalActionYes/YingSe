# Beyond RGB 可按成员读取，先筛选实拍光照配对

这轮寻找能区分现场光色与有意调色的真实拍摄。FaceOLAT 数据仅限学术用途，原片按作者途径申请；CMU PIE 的正式页面描述了多光照采集，本轮未取得有明确同灯位换色记录、可小批直取的样本；DeepFlash 的第三方目录指向的作者补充入口返回 404。均未取得可用真人配对。[FaceOLAT 作者说明](https://github.com/prraoo/FaceOLAT) · [CMU PIE](https://www.ri.cmu.edu/project/pie-database/) · [DeepFlash 机构存档](https://openportal.isti.cnr.it/doc?id=people______::8f53cd29f040e9c540362541456e5590)

Beyond RGB 的实验室档案包含色卡、Oppo 原始 RGB 数据、拍摄标签和光谱仪测量。Zenodo 记录的许可为 CC BY 4.0，发布体量约 160.3 GB。作者仓库的公开小样每个实验室场景只有一种灯光，现场照片中的人脸做了模糊处理。它可用于真实静物光照对照，无法提供本项目所需的真人肤色配对。[作者资料](https://github.com/shirawerman/Beyond-RGB/tree/0a3ed93e37f9f1b67fb23781c5e6ab34631020af) · [数据发布](https://zenodo.org/records/16848482)

从第 5 分卷只读取 65,536 字节的 ZIP64 尾部和 4,654,010 字节中央目录，核对 HTTP 206、字节边界与完整目录哈希。共 30,888 条目录记录。13 个实验室场景各有 93 条不同灯光编号的 CRI 记录。对作者公开示例对应的 MIXED_organic 和 WHITE_rich，固定其中灯光编号 1 和 12，找到 16 个关联成员，分布于第 2、3 分卷，共 63,151,153 字节压缩数据。像素文件本轮没有下载。

四份 CRI 各自以 2 KiB 范围请求读取，校验本地 ZIP 成员名、解压长度及 CRC32。这四个状态的照度和色度同时变化，下一步优先在相同场景下用仪器记录筛选照度更接近、色度确有差异的组合，再取颜色配对。若缺少类似照度的状态，保留光色与强弱同时变化的事实，不将差异归因到单一因素。对肤色仍需真人照片，白墙和真实自然评价另行验收。[范围、成员和实测证据](2026-11-20-beyond-rgb-lab-index-evidence.json)

中央目录两遍解析一致。复算使用现有 Python 运行 `audit_beyond_rgb_lab_index.py <本机 central.bin> <新报告>`，目录来自第 5 分卷相对字节 897798755–902452764。每个选中成员的分卷与偏移随证据记录。未运行调色或修改软件。
