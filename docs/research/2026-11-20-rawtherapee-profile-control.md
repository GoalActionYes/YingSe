# 统一显影配置后，局部过调消失，整图仍迁移不足

固定上轮的三组显影训练对、原片、编辑器、ColorToning 参数和逐像素预测。只将留出的 Cuckoo 从作者全量配置换成三组训练样本使用的精简配置。用两份相同配置生成真值开、关图。冻结近邻距离、回退和渲染条件，原测区和真值只用于评分。另核对两份精简配置的文件哈希与三组已有样本逐字节一致。[事前协议](../../experimental/adaptive-reference-20261113/rawtherapee-profile-control-protocol.md)

| Cuckoo 测区 | 邻色覆盖，原 → 统一 | 色度误差，原 → 统一 | 响应投影，原 → 统一 | 统一配置区域通过 |
| --- | ---: | ---: | ---: | --- |
| 整图 | 79.4% → 89.3% | 2.827 → 1.415 | 0.766 → 0.384 | 否 |
| 近中性色 | 99.6% → 99.8% | 1.321 → 0.308 | 1.314 → 0.939 | 是 |
| 脸颊 | 98.7% → 100% | 1.972 → 0.314 | 1.557 → 1.031 | 是 |
| 浅色树皮 | 99.8% → 100% | 2.601 → 0.266 | 1.538 → 1.004 | 是 |
| 草地 | 0% → 100% | 6.761 → 0.394 | 0.354 → 0.932 | 是 |

误差为 8 位色度单位，投影 1 对应同一显影条件下的真实编辑幅度。脸颊和树皮均满足事先固定的局部过调改善门槛。整图仍低于 0.75 的响应下限。整图真实开关色度均值也随显影改变，统一后为 3.340 RGB8，两列分别对本条件的实际编辑评分。不能把表中误差变化直接当作同一张用户图的算法升级。近中性色是分别按每套显影的前后成片筛出的区域。

两套显影均为 900×599，局部边缘配准通过事前门槛。脸颊、浅树皮、草地测框分别移了 (-1,+2)、(+8,-4)、(-9,-1) 像素。区域对应是局部平移近似，完整配置还可能涉及镜头校正等几何差异。局部改善来自这组显影设置整体变化，无法归因给某个具体设置，也无法据此认定物体标签是否有帮助。结果记录已知同款操作下的一个实拍诊断。当前普通输入是成片，无法假定用户的图有共同 RAW 显影历史。[全部测量和哈希](2026-11-20-rawtherapee-profile-control-evidence.json)

复现时在原研究环境把仓库根目录加入 `PYTHONPATH`，运行 `probe_rawtherapee_profile_control.py <研究输出根目录> <RawTherapee CLI> <shared-response-v1 目录> <前轮像素响应证据 JSON> <前轮邻色证据 JSON> <新输出目录>`。配准另用确定的模拟平移、纯色及尺寸变化核对。两次完整报告和成片哈希一致，本机出图在 `rawtherapee-profile-control-v1`。本轮不引入产品候选。
