# 按亮暗分别统计参考色度，分区冷暖有改善，换背景保护仍失败

将参考的暗区和亮区色度分别送入冻结的 13 号模型。保持完整参考亮度统计、目标输入和原亮度出图，只改变色度来源。按目标亮度混合两个输出，并保持浮点整图平均色度。对照把暗部和亮部的色度来源交换，计算量和颜色样本相同。输入为实拍照片及已知分区冷暖操作，目标的预期结果和人物范围仅用于评分。[事前协议](../../experimental/adaptive-reference-20261113/tone-conditioned-reference-histogram-protocol.md)

| 检查 | 匹配亮暗 | 配反亮暗 |
| --- | ---: | ---: |
| 八个参考背景的换款误差门槛 | 6/8 | 0/8 |
| 原样换背景与统一冷调联合保护 | 未通过 | 未通过 |

人物近中性色的换款误差在匹配臂八项全部下降。其中白球服原背景由 14.58 降至 8.18 RGB8，换背景后由 15.15 降至 9.02。两项均达到本轮降幅。另有两个背景降幅不足 20%。原样参考换背景时，9483 组目标人物的偏色差从 2.77 增至 4.11 RGB8，超过允许增加 1 码值。统一冷调的八个对照均在退化限额内。[本机白球服两种冷暖成片](../../outputs/adaptive-reference-20261113/tone-conditioned-reference-histogram-white-jersey.png)

反向对照使每一项换款误差高于匹配臂，这说明亮暗配对确实对这类分区风格有用。固定分档同时会把参考物体颜色的亮暗关系带到目标。当前证据不能支持把这项做法接入产品。结束固定分档，保留「亮暗条件色度有可测贡献」和「无分区调色时仍有背景串色」两个事实。

在已有视觉研究 Python 下设置仓库根目录为 `PYTHONPATH`，`OPENBLAS_NUM_THREADS=2`、`OMP_NUM_THREADS=2`，执行 `probe_tone_conditioned_reference_histogram.py <新输出目录>`。原 32 张基线逐像素复现，同图和纯色回退通过。两遍 64 张候选图及报告逐件同哈希，重新读取成片核对全部换款、换背景和统一冷调分数，额外亮度变化最高为 0.499 RGB8。报告 SHA256 为 `ccdd992b14ee63ac8d0e52f03269364866471c237ddc65ebd5e54eee2b30d2d3`。这是已消费开发对照中的受控编辑试验，软件升级、正式独立画质和视频验收均待完成。
