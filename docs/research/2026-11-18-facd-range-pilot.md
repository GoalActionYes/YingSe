# FACD 同款滤镜小样可取得，原始前后图未通过结构筛查

FACD 作者为 1,280 张照片分别生成 22 个 GIMP 滤镜版本。发布是同一原始照片下的成组结果，限学术研究。这里检查它是否适合做映色的跨内容同款调色对照。Deep Preset 同样有明确预设研究，但公开作者仓库只提供示例内容及参考、基准预设和模型下载入口，作者说明其约 500 GB 训练成片未整套上传。本轮选择可直接取原图与滤镜结果的 FACD。见 [FACD 作者说明](https://wtwilsonsun.github.io/FACD/)和 [Deep Preset 固定说明](https://github.com/minhmanho/deep_preset/blob/04eb47352e2f4cd643d466c7c6835f17d9513c92/README.md)。

公开的 2,968,999,768 字节图片包返回 HTTP 206。ZIP 尾部及中央目录共 3,312,941 字节，包含 29,464 条记录。四个指定目录 `Origin`、`Amaro`、`Hudson`、`XProII` 各有完全相同的 1,280 个照片标识。按标识 SHA256 排序，在读取图片前固定前八组，再请求 3,273,431 字节媒体区间。前置探测另读取了一次同一尾部和中央目录。未取整包、权重或偏好元数据。见[预先固定的协议](../../experimental/adaptive-reference-20261113/facd-range-pilot-protocol.md)。

32 张 JPEG 的长度、ZIP CRC32、SHA256 和解码尺寸均匹配。独立解析中央目录复算选择及所取条目，八张原图精确哈希均不同，预设差值哈希最小距离为 44／128 位。该范围只检查这八个组之间的精确与近重复，并未排除与历史素材库的重叠。

| 核查项 | 结果 |
| --- | ---: |
| 解码尺寸一致的原图与成片 | 24/24 |
| 粗结构检查通过的原图与成片 | 9/24 |
| 三种滤镜均通过的原照片 | 3/8，低于至少 6/8 |

三个滤镜各通过三组，另五组的最低全图梯度相关分别为 0.185、0.689、0.728、0.442 和 0.782。24 对整图的最佳整数位置都是零位，但部分象限差异和零位相关未达到门槛。查看全部八行四列图，滤镜版本包含黑边，部分有暗角、高光溢出或较强反差。边框是已观察到的混杂因素，尚未分离每种变化对结构分数的贡献。保持失败判定，五组也保留，未从通过的三组挑小集当作成功。见[全部数值与文件身份](2026-11-18-facd-range-pilot-evidence.json)。

此来源填补了明确滤镜操作标签和跨内容分组，但当前原始配对不进入训练、独立验收或软件。若再使用现有小样，先核查黑边是否只覆盖边缘、内部是否有缩放，再重新固定去边框配准验证。只预测黑边就能认出的滤镜不能计作风格识别证据。样例被明显染色的白婚纱也不能当作应保护其白色的监督标签。

本机目录为 `outputs/adaptive-reference-20261113/facd-range-media-v1`，含 32 张图和 `overview.jpg`。复现时在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path`，使用研究 Python 运行 `experimental/adaptive-reference-20261113/probe_facd_range.py <新输出目录>`，网络有需要时附加 `--proxy <本机代理地址>`。JPEG、预览和 ZIP 片段只保留本机。
