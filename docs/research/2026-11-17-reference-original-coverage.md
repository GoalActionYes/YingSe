# 参考前后监督：扩展本机数据有新的可核查范围

本轮不等待用户填写表格，也不更换模型。核对了现有训练数据中可解析、已在本机的参考原图，发现此前75条额外原图诊断没有覆盖扩展数据中的全部可用范围。该新范围允许进一步验证监督来源；不是画质改进，也不是重新尝试已停止的小头。

原图身份按固定作者索引中的content stem与reference_family唯一解析，并额外要求原图属于本轮训练content且存在于已验收准备清单。没有通过文件后缀猜风格，没有下载新图，也没有读取目标GT、开发或保留图像。全部所需文件SHA256、准备清单、cohort身份及像素差异已核对。[数值证据](2026-11-17-reference-original-coverage-evidence.json)绑定本机逐对记录哈希。

两种清单的参考前后RGB256差异均值约20.75／20.29码值，说明这些配对不是同像素重复。**尺寸一致和路径解析不证明逐像素配准或共享同一个严格全局变换**，不能据此直接生成可信训练标签。下一项必须验证参考内部跨块拟合，以及估计的变换能否迁移至另一内容。

## 与旧失败方案的区别

旧一致参考增强从目标原图／目标GT拟合函数，再把函数施加到另一训练图，构造新的参考；这一路线已失败，保持停止。旧残差场监督也从目标GT得到修正场，不恢复该头。

本次待核查的是作者真实参考图与其可解析原图之间的变换，在估计时不读取目标GT。只有训练阶段和诊断可使用额外原图，最终产品仍只能输入目标与参考两张图。额外原图诊断成功也只支持监督任务有可达信息，不能冒充两图推理成功。

此前75条训练诊断已显示额外原图可带来收益，但样本少且共享47原图；直接扩大训练或换头没有依据。下一轮先从新增可用记录中固定64个不同目标，复用旧固定guide的两折变换诊断，不重做旧75条、不添加模型或超参。细则见`reference-original-extension-protocol.md`。如果新增范围也不能提供可靠变换，则停止该监督来源的推进，不直接训练。
