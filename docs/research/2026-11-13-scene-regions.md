# 场景类别与相对颜色试验

本轮在隔离环境运行轻量场景分割，并测试同类别区域相对颜色修正。分割可以提供区域证据，但该固定修正没有稳定改善照片效果，不进入产品。

来源为 [NVIDIA SegFormer-B0 ADE20K模型](https://huggingface.co/nvidia/segformer-b0-finetuned-ade-512-512)，固定revision `489d5cd81a0b59fab9b7ea758d3548ebe99677da`。Safetensors约15MB，SHA256 `6ae39addd01de6b1b8bde2cf677d43a5cd733424b8d186de3f95d1c51fee23f9`，权重加载信息无缺失、额外或形状错误。作者许可保存在本地研究资产中；本轮只作学术研究，不是产品模型依赖。模型没有学习调色或材质／照明对应。

## 固定候选

目标和参考整幅缩到长边640，processor再按512×512标准输入处理。先将输出logits上采样到工作图，再softmax，得到150类后验。每类只有双方置信度>=0.7、面积均>=1.5%时参与。

比较参考与现有调色结果同类像素的RGB中位数，形成类别偏移；减去所有支持类别偏移的逐通道中位数，去除共同分量。各通道限幅±0.12，强度固定0.5；按目标后验概率混合，不用硬边界或手工蒙版。共同支持类别不足2个时保留现有结果。

去除类别共同分量不保证全图平均颜色不变。原冻结协议将logits上采样误写为后验概率上采样，审查后已更正文档；执行代码始终是先上采样logits再softmax，原冻结证据保留，不掩盖文字错误。

## 结果与观察

只用已参与开发的PST第1–15组，全部预测冻结后再读专家目标，未使用第16–50组。

| 项目 | 实测 |
|---|---:|
| 总样例／应用区域修正 | 15／10 |
| 现有版平均RGB MAE | 17.867 |
| 候选平均RGB MAE | 18.098 |
| 改善／退化 | 4／6 |
| 严重退化 | 0 |

其余5组未修正。阈值沿用0.1码值，严重退化同时要求超过原版5码值及25%。零严重退化不能替代多数改善；总体均值和改善数量不足以支持接入。

分割每图约0.022–0.449秒，包含处理、推断、上采样和取回标签／置信度，首图包含初始化影响；不含原版调色分析、读写文件或视频。不能称为整套产品的实时速度。

查看第12、14组效果图，修改较轻，未充分恢复所需整体明暗；查看第14组真实分割叠图，人物主要轮廓可识别，但还存在前景误分类。同一person类别把衣服和皮肤合在一起，山体类别也不能区分不同照明和材质。同类别中位数不是可靠风格真值，不能据此强行对齐。

## 下一步

保留分割标签、置信度和类别支持作为诊断，不继续围绕这15组调节强度。后续应验证能否分离衣物本色、照明和风格，或获得可信的局部调色监督，再让区域信息决定如何处理。当前不能宣称已理解人物与场景关系，也没有验证视频时序或CUBE表达能力。软件和用户操作保持原状。
