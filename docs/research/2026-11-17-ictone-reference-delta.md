# 白墙案例：参考固有外观与对比度增量

## 运行前协议

单一问题：9483白墙案例的大幅曝光偏移，是否已经在使用未调色参考19432时出现，还是主要在参考加入已知对比度控制后出现？前轮最终误差15.13333→35.79732，裁切通道0.52%→15.52%，但参考本身是高反差日照网球场；受控GT只定义额外1.12对比度，不包含跨场景固有外观迁移。

固定目标9483、参考主体19432、全部模型／权重／Q3精度、4步／guidance50／seed666、预处理和默认33格LUT。唯一输入改动是将参考由已有global_contrast版本换回对应原始COCO参考。只新增一次生成，复用前轮已完成的加对比度输出，不调参、不更换样例、不追加训练，不作为新画质候选。只作离线非商业研究，许可／训练重叠限制不变。

预算：一张图片子进程660秒、内部600秒；之后一次默认LUT重建及current13两次前向不超过120秒，不新增下载或依赖。模型仍只收到两份RGB及哈希，不读取GT、蒙版或样式标签。LUT拟合只使用目标原图与该次生成，GT仅用于后续离线差值测量。

分别保存：参考变化幅度、已知目标控制幅度、未调色参考输出相对内容的变化、前轮输出相对GT的误差、两次输出的增量及其与GT增量的差、亮度均值和裁切比例；current13同时给出对应结果。新current13加对比度参考结果必须逐像素复现前轮保存图，再解释原参考对照。

若未调色参考也产生相近的大偏移，支持该例并非单由新增对比度操作造成；若偏移主要在增加对比度后出现，则支持增量响应异常。结果混合时如实保留，不强分二选一。MAE不具可加归因，禁止用两个MAE之比宣称根因百分比；单例不能证明泛化、过拟合、自然审美或量化是否为因。没有软件验收通过结论，也不修改前轮失败成绩。

## 实际结果

新增生成14088已确认退出0，默认LUT重建及current13对照完成；加对比度参考的current13重新前向与前轮保存PNG逐像素一致。四步生成范围76.5秒，重建／基线前向／测量2.406秒，不含初始下载、最初分组准备、T5缓存或全部组件加载，不能当作完整视频速度。

参考输入变化MAE4.94362，已知目标控制变化MAE6.71432。目标亮度均值99.02037，已知控制后95.69076；ICTone未调色参考输出117.86779，加对比度参考后119.28913。亮度均值不能代替局部白墙区域或自然审美成绩。

未调色参考本身已触发很大的曝光／颜色变化，支持这个案例的异常并非只在增加对比度后出现。ICTone对增量有一定正相关响应，但幅度／空间分布仍偏离已知控制，不能说它完全忽略参考变化。方向余弦和线性投影系数只描述本例向量关系，不是根因比例、学习能力得分或完整验收。

未调色参考的原始生成裁切相对内容MAE37.69869、裁切通道10.8907%；与LUT重建37.21087相近。因此大偏移也已存在于原始生成，不是仅由LUT重建产生。此检查仍不能分离量化误差、训练来源、参考固有外观和期望定义，不能把“跟随参考外观”直接当作所有自然任务中的错误。
