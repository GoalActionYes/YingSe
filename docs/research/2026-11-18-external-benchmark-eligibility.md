# 外部调色评估来源核查

本次核查的问题是能否找到有参考图、同款调色目标和可核验素材身份的外部评估来源，用于检查跨场景偏色改善是否牺牲参考风格。此前的 PPR 人物分区与专家身份探测已结束，现有研发素材仍按已消费处理。

## AceTone 发布数据存在可验证的配对，也存在重复目标

论文给出 1,024 组迁移测试，并提供图像与 LUT 真值。读取 Hugging Face 的仓库元数据后，核对了固定版本 `b504dfc28882281b1e77511227153294a6782360` 的全部成员。目标原图、参考图、调色真值和 LUT 四类均恰好覆盖 000000–001023。LFS 标识可用于后续验证成员身份，四类文件共约 3.68 GB。本轮读取范围为仓库元数据。见 [论文](https://openaccess.thecvf.com/content/CVPR2026/papers/Ma_AceTone_Bridging_Words_and_Colors_for_Conditional_Image_Grading_CVPR_2026_paper.pdf) 和 [发布版本](https://huggingface.co/datasets/Vivre/AceTone-Bench-Transfer/tree/b504dfc28882281b1e77511227153294a6782360)。

- 1,024 条记录只有 **927 份字节不同的目标原图**。839 份出现一次，80 份出现两次，7 份出现三次，1 份出现四次。抽样及统计须先按原图分组。
- 1,024 份 LUT 的文件哈希各异。哈希只判定字节一致，无法判断两份 LUT 的效果相近程度。重复目标可用于看换参考后的输出变化，但须逐项验证配对与参考差分后才可计入。
- 参考和真值之间有一组精确字节相同的成员，评估时须先核查具体配对角色。三类图像的远端哈希与一个现有 TST 准备清单的 18,706 个文件哈希均无精确交集。该结论限于字节和这份清单，改编码、缩放、裁剪、连拍及其他已消费来源均未得到排查。

固定版本没有数据 README 或许可标签。作者代码仓库标有 Apache 2.0，对单独托管的图像与 LUT 的使用条款仍缺乏证据。现阶段将此来源登记为待核验。其 LUT 真值适合检查整体色调与换参考响应，最终仍需要能判断肤色、白墙和中性色自然度的真实案例与评价。见 [作者代码仓库](https://github.com/martian422/AceTone)。

## 其他来源的使用边界

RTD 将多个摄影调色预设应用到 MIT FiveK 图像，提供固定参考关系。数据标注 CC BY-NC-SA 4.0，数据文件需登录接受访问条件。作者的测试划分只针对其训练过程，映色仍须核对既有 FiveK／TST 来源。论文方法通过参考的调色前后图推断编辑，对照时应将额外输入条件单列。见 [作者仓库](https://github.com/omarAlezaby/InRetouch) 和 [数据卡](https://huggingface.co/datasets/omaralezaby/Retouch_Transfer_Dataset)。

本机证据位于 `outputs/adaptive-reference-20261113/acetone-benchmark-metadata-v1`。元数据响应 SHA256 为 `d72b72246082ad3d07cb186ff629041b8d4506926ead1849569ffa29e00d8a54`，本机清单 SHA256 为 `da0b2162eea340fb75c2a1cfb62066658865a72873bbf951a01202add692603f`。复核时按文件角色和六位编号检查四组完整覆盖，再按 `lfs.sha256` 统计组大小、跨角色交集和本机精确交集。候选仍须经过原有画质、功能和视频验收。本次结果更新的是评估来源与抽样依据，软件画质目标尚待达成。
