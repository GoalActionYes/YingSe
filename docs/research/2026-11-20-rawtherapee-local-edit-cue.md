# 局部亮暗色度关系能感知同款编辑，单图仍易误判

固定两张已用人像，再在两张已用天空 RAW 上重放《Cuckoo》的同一个 RawTherapee 色彩平衡开关。新生成的四份显影图在各自场景内只切换 Enabled。两个新增场景的实际色度变化为 2.89 与 2.37 RGB8，两张人像为 6.14 与 1.08。每次留出整个场景，模型拟合只看另外三组。测试只读单张成片。[事前协议](../../experimental/adaptive-reference-20261113/rawtherapee-local-edit-cue-protocol.md) · [人像前后成片](2026-11-20-rawtherapee-portrait-cross.md)

| 特征 | 正确关闭 | 正确开启 | 共计 |
| --- | ---: | ---: | ---: |
| 全图亮度、色度分位数 | 3／4 | 1／4 | 4／8 |
| 局部高低亮度的相对色度 | 2／4 | 2／4 | 4／8 |

两种特征在四个场景里都给开启态更高分。绝对分数仍受场景改变影响，局部特征有两个场景的开、关都低于阈值，另外两个都高于阈值。对照也出现此类错误。场景内顺序一致不能代替普通单参考的判别。失败发生在决定要不要应用编辑的阶段，本轮不将该触发器接入调色。两张天空素材提供了新的同款显影配对，可继续测量同一编辑在不同物体上的实际变化。素材仍为已用开发内容，开放风格和真实换灯继续需要各自的证据。[所有分数及 RGB 哈希](2026-11-20-rawtherapee-local-edit-cue-evidence.json)

复现时使用既有研究环境，把仓库根目录加入 `PYTHONPATH`，运行 `experimental/adaptive-reference-20261113/probe_rawtherapee_local_edit_cue.py <研究输出根目录> <原双人像结果目录> <RawTherapee CLI 路径> <新输出目录>`。程序核验旧人像的 RGB、两个 RAW、编辑器及原配置。两遍的数值报告和四份新增显影的规范化 RGB 哈希一致。图像和显影设置副本保留本机。[两套 RAW 的来源说明](2026-11-20-rawtherapee-sky-pair.md)
