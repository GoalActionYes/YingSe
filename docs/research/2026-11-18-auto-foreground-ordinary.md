# 自动前景旁证在普通开发照片上没有提供修正

冻结 MLS 的平整背景定位、前景区域提取及两处旁证条件，应用于 42 张背景物体色／整图变体、18 张局部冷色开关及两张 PSBench 真实出图。比较原方法证据不足回原图，以及只修正有证据的近中性色、其余保留 13 号。图像均与 MLS 拍摄组分离，仍是已消费开发资料。见[事前协议](../../experimental/adaptive-reference-20261113/auto-foreground-ordinary-protocol.md)和[实验室基线](2026-11-18-mls-auto-foreground.md)。

| 门槛 | 回原图 | 回 13 号 |
| --- | ---: | ---: |
| 人物抗背景干扰并保留整图色向 | 0 / 8 | 0 / 8 |
| 对比度与去饱和响应 | 0 / 12 | 12 / 12 |
| 局部冷色与人物保持 | 0 / 4 | 0 / 4 |
| 整图冷色 | 0 / 6 | 4 / 6 |
| 无人局部空操作 | 2 / 2 | 2 / 2 |
| PSBench 实图通过 | 0 / 2 | 0 / 2 |

62 组输入仅七组取得可用背景候选。这七组各只得到一对前景匹配，且仅一组实图的一对满足同向条件。没有两对得到支持的输入，修正未启动。回原图的近中性色抗背景干扰表面改善 100%，同时有效变化消失。回 13 号的整图响应全部继承基线，白球服人物近中性色误差维持 5.47 个码值，台阶人像近中性色误差维持 16.77。两种都没有使照片同时达到预设抗干扰和风格要求。

两遍报告及 124 张输出哈希一致。另逐像素核对全部输出，分别等于该对原图或冻结 13 号结果。两种同图检查通过。见[数值与身份](2026-11-18-auto-foreground-ordinary-evidence.json)。

结束把当前重复材质旁证接入普通参考。实验室的正向结果依赖不同场景恰有可比较的表面，普通照片覆盖不足是本轮已观测的直接限制。后续若有新的线索，应优先能在没有重复对象的参考中仍定位有效调色，并用局部风格开关及物体换色成对验证。当前无软件升级、独立自然评价或视频验收。

复现时设 `PYTHONPATH` 为仓库根目录，运行[脚本](../../experimental/adaptive-reference-20261113/probe_auto_foreground_ordinary.py)并提供一个新输出目录。需要既有三组本机开发对照；本机结果在 `outputs/adaptive-reference-20261113/auto-foreground-ordinary` 与相应重复目录。
