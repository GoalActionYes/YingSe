# 正确分开人和背景，仍不能直接匹配各自的颜色

固定四组 Film B 实拍人像，每组两种参考背景、两个开关状态。两臂用同一协方差匹配、相同分辨率和 80% 强度。全图臂求一份颜色映射；分区臂用旧的参考主体标注和目标人物标注，在人物和背景内部分别求映射，再在目标边界羽化合成。作者成片仅用于评分。它直接拟合颜色映射，与此前把分区统计送入整图训练模型的办法不同；输入人工标注，因此属于离线诊断。[事前协议](../../experimental/adaptive-reference-20261113/film-b-regional-distribution-protocol.md)

| 检查 | 全图匹配 | 分区匹配 |
| --- | ---: | ---: |
| 四组风格与稳定联合通过 | 0/4 | 0/4 |
| 最差保护区换背景差，RGB8 | 41.23 | 33.17 |
| 白球服开态的人物区换背景差，RGB8 | 7.31 | 0.53 |
| 白球服开态的全图近中性色换背景差，RGB8 | 9.52 | 10.18 |
| 白球服人物核心相对预期误差，四状态平均 RGB8 | 16.26 | 107.74 |
| 白球服边界相对预期误差，四状态平均 RGB8 | 15.70 | 50.31 |

白球服两背景下人物区更一致，但与正确结果的偏差明显增大；人物区已经几乎稳定时，全图近中性色仍不稳定。白球服两背景的明暗投影从 0.590／0.436 下降到 0.339／0.254，色度投影也都下降。保留一项真实收益：785–3553 的人物核心平均误差由 34.94 降到 14.73，但有意色度仍双向反向、背景核心误差增大，未能通过。以上区域包含衣服和人物整体，不能当作专门的肤色或白墙测量。

首次运行在读取参考标注时停止：目标是 256×256，而参考本来就有自己的 768 或 576 边长。核对三份参考资源的尺寸一致后，分别使用各自原尺寸与蒙版，重新运行，无更改阈值。两次完整运行各有 32 张成片、四张对照板和一份报告，37 件逐项同哈希，另从落盘图复查 96 项区域误差。

结论：分区能减少背景对目标人物的干扰，但把参考人物的颜色分布直接作为目标人物的期望，仍会把原有人物、服装和照明差异当成风格。本轮停止固定分区分布匹配，未接入软件。后续有价值的证据是分区内的真实编辑前后变化，单张参考中人物和背景的颜色分布不足以替代它。
