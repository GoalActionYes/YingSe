# 真实局部调色可由固定色度变化近似

同一原片通过几何匹配可以恢复局部调色。要验证不同照片之间的迁移，需要先确定编辑是否必须随输入颜色变化。本轮用作者开关图和真实蒙版比较固定色度偏移与按原 RGB 拟合的色度增量。每折只在一个棋盘半区的高权重像素拟合，并在另一半评分。两法都保留原亮度、80% 强度及零权重像素。[事前协议](../../experimental/adaptive-reference-20261113/playraw-mixed-light-operator-protocol.md) · [实拍开关与作者蒙版](2026-11-20-playraw-mixed-light-skin.md)

| 留出折 | 高权重区投影，固定 → RGB 条件 | 高权重区 MAE，固定 → RGB 条件（RGB8） | 过渡区 MAE，固定 → RGB 条件（RGB8） |
| --- | ---: | ---: | ---: |
| 训练半区 0 | 1.012 → 0.989 | 1.582 → 1.469 | 0.554 → 0.523 |
| 训练半区 1 | 1.013 → 0.996 | 1.623 → 1.477 | 0.548 → 0.523 |

两种表示都满足高权重区投影和误差门槛，零权重区均逐像素保持。RGB 条件臂的两折 MAE 下降 0.113／0.147 RGB8，小于预定 0.25，因此不增加该颜色条件。保留固定色度偏移作为这份实拍编辑的简明离线正控。高权重区共用一张原片，位置来自作者蒙版，不能用这些结果证明其它场景的同类素材适合相同色度变化。后续若测跨场景，需另行定义不同照片中的有效编辑区域与保留区域，且目标答案应独立于待测方法。
