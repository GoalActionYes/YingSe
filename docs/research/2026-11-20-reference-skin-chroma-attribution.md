# 换背景后的参考皮肤权重变化，解释了两组肤色退化的一部分

上一轮将参考背景灰化，白球服案例的手臂和脸颊偏色减轻，但另两组实拍人物偏色加重。灰化取色仍使用全图亮度，自动分割也可能受新背景影响。这轮固定目标、普通 13 号成片、目标皮肤权重和 F1 原色度。灰化支路分别借用同主体 C1 参考的皮肤权重、亮度或两者，逐项测量相对原 C1 成片的色度差。先逐像素复现上轮两背景下的成片，再做三项干预。[事前协议](../../experimental/adaptive-reference-20261113/reference-skin-chroma-attribution-protocol.md) · [上轮两图结果](2026-11-20-reference-skin-chroma-isolation.md)

单位为 RGB8 色度码值。核心组为上轮退化的 785 与 9483，在开、关两态各测三个皮肤框，共六项。按预先规定的降幅至少 25% 与至少 0.25 RGB8，固定权重有 6/6 改善，固定亮度为 1/6，两者一起为 3/6。核心组两参考在全图权重上的平均绝对差为 7.34–9.76 个百分点，白球服组小于 0.10 个百分点，但后者仍对亮度替换敏感。投影幕的额外偏差是保留反例。不同案例主要变化不同，就算知道另一背景下的权重，仍不能保证所有场景的肤色和风格。

两组退化优先检查皮肤定位随背景变化的稳定性。应保留脸颊、手背、远处真人和投影幕等已有条件，并用普通输入验证。此轮借用了同主体的额外参考，不是产品推理，也无法证明任意灰化方案保得住风格。雪地、浅墙和白球服在本次三项干预下与原灰化支路的读数相同。现有软件没有替换，正式画质和视频验收仍待完成。[本机 785 干预成片](../../outputs/adaptive-reference-20261113/reference-skin-chroma-attribution-v1/785-3553/on-mask.png) · [投影幕反例](../../outputs/adaptive-reference-20261113/reference-skin-chroma-attribution-v1/8021-8690/on-mask.png)
