# 位置相关的颜色矩阵仍未还原跨灯强的实拍颜色

真实蓝光和后期蓝调都能让白色物体偏蓝。自动参考调色需要判断哪些偏蓝应迁移。已有控制发现，同一档灯强下用全图颜色矩阵拟合，数字加蓝可以复现，真实换灯仍有误差。为了判断简单的空间变化能否补足差距，这次让颜色矩阵随横纵坐标线性变化。用同一构图一档灯强的白灯与蓝灯配对拟合，再从另一档灯强的白灯照片生成蓝灯预测。两种矩阵在相同像素上评分，两个场景均双向交换灯强。[事前协议](../../experimental/adaptive-reference-20261113/physical-blue-spatial-cross-protocol.md) · [同档全图矩阵实验](2026-11-19-physical-blue-global-fit.md)

| 场景与灯强标签 | 全图矩阵 MAE／P95 | 空间矩阵 MAE／P95 | 实拍 MAE 降幅 |
| --- | ---: | ---: | ---: |
| 场景 1，213 → 241 | 9.91／14.67 | 9.40／13.33 | 5.1% |
| 场景 1，241 → 213 | 8.87／13.67 | 8.54／12.67 | 3.8% |
| 场景 2，213 → 241 | 10.31／15.33 | 9.49／13.67 | 7.9% |
| 场景 2，241 → 213 | 8.66／14.00 | 8.33／12.67 | 3.8% |

误差单位是 RGB8 码值，P95 由逐像素三通道平均绝对误差得到。实拍需同时满足 MAE ≤ 3、P95 ≤ 8 和 MAE 降幅至少 15%，结果为 0/4。数字控制在每个方向的两档白灯成片上采用同一已记录的增益，区分空间模型本身是否会破坏全图统一改色。所有数字成片 MAE 不高于 0.022，P95 不高于 0.334，两臂均通过。

空间矩阵在四个方向均略微减少实拍误差，仍有明显差距。结束用横纵坐标一次项补足跨灯强变化。这组场景共享拍摄来源且没有人物，结果无法区分光照分布、材质和相机响应各占多少，也无法说明肤色保护的收益。后续若研究换光，应优先寻找能分别控制这些因素的独立拍摄证据；调整坐标项或拟合参数没有现成依据。源档的真实两态只供离线拟合，留出档蓝灯只用于评分与统一的有效像素选择。没有新增软件候选。
