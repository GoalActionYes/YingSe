# 光谱肤色先验仍不能从普通照片给出换光方向

此前在明确光源时，肤色误差可以降低。这轮用 ISSA 实测光谱构造 D65 与标准光源 A 的两个肤色库，从源 RGB 的通道比选择更受支持的光源。支持距离按 ISSA 整采集来源留出的第八近邻距离预先确定。最近类优势、最少像素与同向覆盖同时满足后才赋值。普通图只用冻结自动皮肤掩膜，光谱人像的人工脸颊提供已知条件下的对照。见[事前协议](../../experimental/adaptive-reference-20261113/spectral-light-choice-protocol.md)与[已知方向的成片验证](2026-11-19-skin-spectral-donors.md)。

| 对照 | 结果 |
| --- | --- |
| 已知光源的六张人像切片 | 正确 4/6，弃权 2/6，无反向判断 |
| 普通有人照片的局部或整图有意编辑 | 8/8 比较至少一端弃权 |
| 普通无人照片的局部或整图有意编辑 | 六张图均未赋值，4/4 比较弃权 |
| 只换背景 | 4/4 比较至少一端弃权 |

282 的两张图分别有 2,359/4,608 与 2,091/4,566 个有效皮肤像素支持已知方向，约为 51.19% 与 45.80%，均低于 80%。普通照片共 26 张，仅一张局部编辑图单独被判为 D65，两端可判的普通对照为零。普通素材没有实际标准光源标签，所以把零反转报告为无法形成可比判断，而不是良好的误触率。没有执行自动调色出图。

结束从固定肤色颜色库直接判断这两种光源的规则。现有测量支持给定方向后的局部渲染，但单张 RGB 的肤色颜色无法为这套规则提供足够判断依据。继续自动方向研究需引入与拍摄光源、已知色样或参考编辑操作有关的独立信息，并用相同背景与有意风格对照验证。普通两图调色目标仍未通过。

两遍报告逐字节一致。用直接距离排序复核六张已知光源人像的像素计数，并复核 16 个普通对照的弃权判定。可用现有研究环境运行 `probe_spectral_light_choice.py <新结果 JSON>`。见[全部分类、弃权与哈希](2026-11-19-spectral-light-choice-evidence.json)。
