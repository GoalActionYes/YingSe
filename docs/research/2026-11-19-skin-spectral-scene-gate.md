# 近景肤色修正保持覆盖，远处脸颊仍会漏检

从既有开发素材取四组自然照片与五组 DAST 标称曝光。固定同一自动定位器，在原图及程序暖色图上各运行一次。对两态分别生成已知反向矩阵的基底，再在模型选出的脸部像素叠加已知光源的 ISSA＋供体修正。对照衡量叠加修正的范围。程序暖色渲染在与原图混合前有 0.76%–28.59% 的通道限幅，因此这是强色偏压力测试，不能把漏检归因于真实灯光。[事前协议](../../experimental/adaptive-reference-20261113/skin-spectral-scene-gate-protocol.md) · [此前的打码预览检查](2026-11-19-skin-spectral-preview-gate.md)

| 原有测量区域 | 原图／程序暖色图入选 | 叠加修正的结果 |
| --- | ---: | --- |
| 785，面部小块 | 95%／45% | 暖色时漏掉过半，未通过 |
| 9483，前额 | 100%／100% | 两态均有修正，区域均值改变量 1.31／2.44 RGB8 |
| 872，后方脸颊 | 0%／0% | 两态都没有修正 |
| 雪地、浅墙、白球服 | 各 0%／0% | 相对各自矩阵基底逐像素保持 |
| DAST 五组历史脸部核心 | 各 100%／100% | 两态整图定位交并比为 0.984–0.994 |
| 8021，投影幕中的脸 | 100%／5.45% | 原图修正平均改变 2.93 RGB8，分类不稳定 |

事前 22 项联合检查通过 19 项。3 个直接拍摄脸部框有 3/6 状态通过，已登记的三处浅色表面有 6/6 状态保持。手背和手臂不在脸部模型范围，两态均未修正。DAST 的历史核心来源仍是同一定位器，数值衡量对旧定位的稳定性。投影幕被当作真人脸选中，是本轮额外保留的反例。两态的所有实际修正都位于各自模型所选像素内。以上结果支持在已有近景中继续使用自动定位作研究工具，同时结束将这套固定脸部定位直接接入全场景修正。真实暖灯、人类自然度和两图的参考风格仍未验收。

两遍输入、掩膜、出图目录分别有 19、19、37 个文件逐件同哈希。独立读取 PNG 复核 36 张成片、28 项测量区域和各图定位交并比。报告 SHA256 为 `869c73766ef0f94d513959beada4c4ba31f2edb574ec1a9ad293e813e6e7d5c4`。

本机结果为 `outputs/adaptive-reference-20261113/skin-spectral-scene-gate-v1`，有 18 组矩阵／修正 PNG。复现同上轮用视觉研究 Python 执行 `probe_skin_spectral_scene_gate.py inputs <研究输出根> <输入目录>`。用已有便携 Python 和 `runpy` 执行 `locate <输入目录> <掩膜目录>`，再切回视觉研究 Python 执行 `render <研究输出根> <输入目录> <掩膜目录> <skin-spectra-input> <hyperspectral-faces-input> <新输出目录>`。各运行环境保持原样。原片、成片及预测掩膜仅留本机。
