# 径向补偿改善 Amaro 的暗角，仍未恢复稳定换款

固定上一轮的七个照片留出折、三款滤镜和 42 个类别判定。本轮在已验证的全图颜色表之上增加径向补偿，用只依赖亮度的四参数补偿作同预算对照。两个臂都只从每折四张训练照片的前后图拟合，渲染目标时不读取目标效果。见 [事前协议](../../experimental/adaptive-reference-20261113/facd-radial-renderer-protocol.md)与[固定表试验](2026-11-18-facd-filter-bank.md)。

| 渲染 | 已知类别整图／近中性色误差 | 自动类别整图／近中性色误差 | 已知类别联合通过 | 自动类别联合通过 |
| --- | ---: | ---: | ---: | ---: |
| 固定颜色表 | 8.94／6.60 | 12.80／11.83 | 2/7 | 1/7 |
| 亮度补偿 | 8.59／6.39 | 12.58／11.84 | 3/7 | 1/7 |
| 径向补偿 | 7.90／5.58 | 12.14／11.33 | 3/7 | 0/7 |

单位为相对作者 80% 效果的 RGB8 码值。已知类别时，两臂都通过了七组的稳定和误差项，各只有三组通过换款项。自动类别沿用 28/42 的识别结果。径向臂虽然降低了平均误差，自动换款项没有一组通过，相比固定表失去唯一通过的组。

| 已知类别时的外侧区域 | 固定颜色表 | 亮度补偿 | 径向补偿 |
| --- | ---: | ---: | ---: |
| Amaro | 19.70 | 19.30 | 13.91 |
| Hudson | 7.27 | 6.89 | 8.61 |
| XProII | 5.20 | 4.96 | 5.26 |

相对同预算亮度补偿，达到外侧误差至少降低 1 码值要求的只有 Amaro，少于预定两款。湖景 Amaro 的天空角落出现和作者同方向的压暗，但作者的暗角仍更强。湖景 XProII 的天空仍没有接近作者成片的青绿色，婚纱 Hudson 的暖色仍比作者成片强。说明至少 Amaro 有实际可迁移的画幅位置变化，现有径向项不足以解释其他滤镜的色调差异。径向与固定表的最大整图误差增幅为 0.043 码值。所有场景和滤镜均保留。见[分组结果与哈希](2026-11-18-facd-radial-renderer-evidence.json)。

21 张先前颜色表输出逐像素重现。两次运行的 42 张新 PNG 和结果 JSON 哈希一致，从落盘图像复算 756 项，包括内外区域及两个识别条件下的误差与方向。两臂都未越过原有画质和换款门槛，结束固定径向配置，保留其 Amaro 结果。没有更改分类器、软件或课程版本，未验证独立画质、自然肤色、开放参考或视频。

在仓库根目录设置 `$env:PYTHONPATH = (Get-Location).Path`，用研究 Python 运行 `experimental/adaptive-reference-20261113/probe_facd_radial_renderer.py <去黑边目录> <固定表输出目录> <去黑边证据> <固定表证据> <新输出目录>`。本机结果为 `outputs/adaptive-reference-20261113/facd-radial-renderer-v1` 和 `facd-radial-renderer-repeat-v1`。湖景、婚纱、火焰的对照图位于前一目录下的 `244905`、`64573`、`379484` 子目录。媒体不随 Git 发布。
