# 双颊对齐后，已知局部编辑仍难跨人物重放

前一轮已证明现有网格可以在同一目标表达这组局部编辑。这次让供样者额外提供参考开关两态，分别在参考照片的第一折拟合前后网格。把两态网格应用到同一目标，取两次渲染差加回目标原色。比较直接沿原画幅重放，以及按供样者与目标的双颊中心和间距平移、缩放网格。两臂的颜色引导、拟合方法和 80% 强度保持。每个目标的期望结果只用于评分。参考前图和已登记双颊框均为离线诊断所用信息。[事前协议](../../experimental/adaptive-reference-20261113/gros-local-grid-transfer-protocol.md) · [网格表达验证](2026-11-22-gros-local-grid-capacity.md)

| 检查 | 画幅原位置 | 双颊对齐 |
| --- | ---: | ---: |
| 参考自己照片留块通过 | 6／6 | 6／6 |
| 跨人物整图、双颊、双白幕及编辑范围外通过 | 19／36 区 | 19／36 区 |
| 跨人物同时满足风格和白幕保护 | 1／6 个完整方向 | 1／6 个完整方向 |

两臂完整通过的都是第 2 包目标向第 4 包取参考。第 2 包目标向第 3 包取参考时，双颊对齐让暖灯整图偏差从 **3.40 降到 2.46 RGB8**，对齐后全组由 3 区通过增到 5 区。同一张成片的右颊暖灯误差却从 **3.34 升至 4.75 RGB8**，风格投影从 0.90 降到 0.71，因而仍未完整通过。第 3 包目标向第 4 包取参考是严重反例。对齐后暖灯左白幕仍偏 11.32 RGB8，编辑范围外相差 21.77 RGB8，画面可见黄蓝斑。对齐确实改变了局部位置，但跨内容时可能把已拟合的颜色关系用在不合适的皮肤或环境上。本轮没有单独证明是哪一种颜色值或网格节点导致外推失败。[整图改善与右颊退化](../../outputs/adaptive-reference-20261113/gros-local-grid-transfer-v1/2-from-3-comparison.png) · [白幕色斑反例](../../outputs/adaptive-reference-20261113/gros-local-grid-transfer-v1/3-from-4-comparison.png)

现有渲染器在同图有已知离线表达见证。即使先知道参考实际编辑，直接复用其网格和仅对齐双颊的位置都不足以保障另一张照片。结束这套固定重放。下一次设计参考分析时，还需要明确如何约束目标上不受支持的色域和编辑范围，继续独立核对肤色幅度及浅色环境。该结果未提供普通两图自动画质收益，也未接入产品、训练或进行独立图片／视频验收。
