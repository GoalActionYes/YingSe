# 逐像素选择仍不足，部分真人颜色只在逐通道放宽时达到门槛

## 为什么做这个对照

过去让脸颊和白幕各用一组固定混合权重，六个真人方向都没有通过。上一轮共同色度方向还带来局部改善，所以要确认一个更具体的问题。现有成片的颜色是否已经足够，只差一个能按像素挑选的方法？若把可选范围放得比普通 RGB 混合还宽，仍达不到预期，就有依据为这些位置寻求新的颜色变化。[分区混合](2026-11-21-gros-regional-blend-bound.md) · [共同方向](2026-11-21-shared-chroma-direction.md)

## 怎么限定选择范围

沿用同一批真人的冷、暖实拍灯和 Film B。两档灯光各自开关预设，成片均按 80% 强度生成。七份可选图对应稳定 1.3、13 号、两套回归预测、共同方向、等幅减弱及目标原片。每个像素分别取三通道的最小值和最大值，容纳这些图的任意非负加权及其整数取整。放宽后的 RGB 范围还包含普通混合够不到的颜色，因为普通混合同一个像素的三个通道共用权重。

生成两类离线对照，关态均逐像素保持目标原色。第一类开态在七份图中选与预期最接近的像素，选择时每个 RGB 像素作为整体。第二类让三个通道分别贴近预期，但不能越出各自的最小和最大值。两类都使用已知正确成片选值，属于离线见证。另允许关态在区域平均误差 3 RGB8 的预算内调整，由区间和误差预算计算风格误差下界、方向投影区间与冷暖差下界。这些下界是各自独立的必要条件，不能证明存在一个同时达到所有要求的输出。[事前协议](../../experimental/adaptive-reference-20261113/gros-channel-envelope-protocol.md) · [原真人材料与门槛](2026-11-21-gros-film-b-cross.md)

## 结果

| 目标 ← 参考 | 整个 RGB 像素选用某一份成片 | 三通道可独立取值 | 放宽条件中可排除区域 |
| --- | ---: | ---: | ---: |
| 01 ← 02 | 1／5 | 3／5 | 0 |
| 01 ← 03 | 0／5 | 1／5 | 0 |
| 02 ← 01 | 1／5 | 5／5 | 0 |
| 02 ← 03 | 0／5 | 4／5 | 0 |
| 03 ← 01 | 1／5 | 5／5 | 0 |
| 03 ← 02 | 2／5 | 5／5 | 0 |

表中前两列的分母是整图、双颊和两处白幕。第一类按单像素误差挑选，六个方向均未完整通过。这个结果限于该选法，有时其他选择可改善综合评分。第二类完整通过 3／6，其余方向保留未通过和未排除状态。

目标 02 从人物 03 取参考时，最接近预期的整像素选择在右脸颊得到冷／暖风格投影 0.78／0.72，暖灯仍偏弱。允许逐通道取值后为 0.97／0.93，响应误差 0.16／0.27 RGB8，过线。同一成片的左脸颊即使放宽后，沿原色保持关态的开态风格投影仍只有 0.28／0.34。改变关态后，放宽的必要条件未能排除达标。这两个脸颊都要保留，避免用一处改善掩盖另一处明显欠量。[本机对照](../../outputs/adaptive-reference-20261113/gros-channel-envelope-v1/02-from-03-comparison.png)

## 路线决定

先区分逐通道放宽提供的颜色和普通 RGB 混合实际能生成的颜色。下一步将三通道重新绑定到同一套逐像素的非负权重，用相同预期和门槛复测这个范围。只有真实可生成的组合在关键区域保住风格和原色，才值得研究从正常两图决定权重。当前的三组放宽通过只说明哪里可再核查。开发素材、稳定版 1.3 和 13 号演示继续按原交接使用，画质目标仍待达成。
