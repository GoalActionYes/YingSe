# 本机十二个室内原片不足以覆盖剩余黄绿像素

餐区和走廊补色后，《Cuckoo》剩余 20,478 个无邻色像素。这轮用本机十二个已经用于开发的 SyncLight 房间，每个房间取一个环境光原片。只显影关闭态，然后用既有的 RGB8 欧氏距离 6 计算新增覆盖。选择只读取目标关闭态和各素材关闭态。原片和上一轮保存成片均先校验身份。[事前协议](../../experimental/adaptive-reference-20261113/rawtherapee-room-coverage-protocol.md)

| 匹配到的房间 | 单场覆盖像素 | 选择结果 |
| --- | ---: | --- |
| 21 | 188 | 第一 |
| 22 | 130 | 与第一名重叠较多 |
| 23 | 72 | 第二 |
| 其余九个 | 0 | 无匹配 |

前两组并集覆盖 228 个像素，只占缺口的 1.11%，低于 15% 的预定出图条件。停止本机室内场景补样，本轮只有供体关闭态显影，没有新调色输出。剩余颜色 R、G、B 的第 10／50／90 分位分别为 114／151／183、156／190／206、95／122／147，亮度中位约 177。逐通道中位数对应偏黄绿，下一批素材若继续查覆盖，应优先考虑有此色域的真实室外场景。找素材仍需按支持范围核验，不能假定同为植被就能补足。

首遍曾因登记场景 2 的哈希漏录一位而中止，部分输出保留在旧目录。核查原始证据与本地文件后修正登记值，将全部验证提前到显影前。用现有 Python 环境和仓库根目录 `PYTHONPATH`，运行 `probe_rawtherapee_room_coverage.py <研究输出根目录> <RawTherapee CLI> <响应证据 JSON> <显影证据 JSON> <上轮补样证据 JSON> <新输出目录>` 可以复现。两次有效运行都返回相同覆盖、选择和成片哈希。[全部数值与身份](2026-11-20-rawtherapee-room-coverage-evidence.json)

这组颜色覆盖调查属于已知同款编辑的开发证据。软件验收的独立白墙、肤色、自然风格和视频，以及普通两图如何识别意图，仍待验证。
