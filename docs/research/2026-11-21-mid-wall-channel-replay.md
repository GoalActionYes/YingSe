# 参考亮度传出了主要明暗干扰，墙面与双颊仍有串色

复印室实拍换灯与匹配数字染色的左墙色度接近，两种当前软件仍有墙面和肤色失败。本轮在冻结 13 号的 3×128 参考直方图里交换两者的 Y′ 一列通道，保持各自的 Cb、Cr。目标图、目标条件、模型、渲染和 80% 强度保持。原三态在两个目标上逐像素复现。数字编辑的亮度来自离线对照，生产推理中无法假定有这份信息。[事前协议](../../experimental/adaptive-reference-20261113/mid-wall-channel-replay-protocol.md) · [原成片](2026-11-21-mid-matched-wall-cast.md)

| 目标区域 | 换光综合色差原值 → 固定数字编辑亮度 | 仅交换亮度时的 Y′ 差 | 仅交换亮度时的去亮度 RGB 差 |
| --- | ---: | ---: | ---: |
| 客厅左墙 | 15.14 → 6.99 | 18.71 | 0.34 |
| 客厅右墙 | 15.73 → 6.94 | 20.03 | 0.55 |
| 人像左颊 | 12.38 → 7.69 | 12.85 | 0.41 |
| 人像右颊 | 9.58 → 9.05 | 11.48 | 0.39 |

单位为 RGB8 MAE，单独分量的 MAE 不直接相加。后两列固定实拍色度。反向固定数字编辑色度再换亮度，同样主要改变墙面与双颊明暗，去亮度差最多 0.69。共用亮度后，全部受保护测区仍高于 3 RGB8。数字编辑的原成片不变，双颊仍有有效风格，客厅两墙仍偏弱。两份目标都没有通过联合门槛。[客厅成片](../../outputs/adaptive-reference-20261113/mid-wall-channel-replay-v1/living-comparison.png) · [人物成片](../../outputs/adaptive-reference-20261113/mid-wall-channel-replay-v1/portrait-comparison.png)
