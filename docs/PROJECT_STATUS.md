# 当前可交接状态

功能基线：`feature/aligned-reference-20261105`，提交 `cb79e4a`。`main` 还包含后续交接文档与源码启动辅助脚本；功能基线和文档提交分别记录。

## 做到了什么

| 内容 | 当前行为 |
| --- | --- |
| 主版 | 参考图＋目标图片／视频，强度与原图对照，PNG／MP4／CUBE 导出 |
| 精确同图 | 解码后 RGB 完全相同，返回恒等映射 |
| 同画面、不同颜色 | 结构与拟合验证通过后，用 RGB 仿射变换构建 LUT；拒绝时走原统计路径 |
| 一般参考 | 恢复的特征、矩阵与 LUT 渲染链，加自主产品策略；不是剪映原生引擎 |
| 肤色实验 | 可选蒙版回补目标原色度，默认关闭；与学习参考人物肤色不同 |

视频支持 8／10 位 SDR 导入，进入当前算法前转为 8 位 RGB。HDR、BT.2020 或未确定的色彩配置不能视为已支持。单次输入上限 512 MB。这里是参考调色原型，没有完整剪辑时间线。

## 还没解决什么

- 不同场景的物体颜色、占比和明暗仍会干扰风格匹配。不是只要两张图就能可靠分离内容与风格。
- 同画面拟合不覆盖所有缩放、压缩、裁切和局部编辑。现有 JPEG 92 接受 10/12，半尺寸接受 4/12，是有限测试覆盖。
- 人物与背景分区协调仍是研究。扩展肤色试验存在恶化和很小的收益，未接入默认主版。
- 完整原生算法的全部逻辑没有恢复，不能宣称完全复刻剪映或保证输出一致。
- 便携包目前在负责人本地，GitHub 没有发布可下载 ZIP。源码可按指南安装依赖运行。

已有检查与误差仅支持相应素材和条件。[最新功能证据](research/2026-11-05-aligned-reference/README.md) 与 [肤色研究审计](research/content-balance-20261105/skin-effect-audit/README.md) 中同时保留反例和边界。

## 下一步适合怎样分工

| 优先级 | 任务 | 验收方式 |
| --- | --- | --- |
| 优先 | UI 易用性与导出提示 | 新同学无需作者指导完成一次图片和视频导出 |
| 优先 | 建立独立自然素材对照集 | 记录不同内容、冷暖、人物／无人、压缩等条件，报告改善和恶化 |
| 优先 | 形成可分发便携发布流程 | 独立目录验证，发布源码标签、完整包、依赖说明与校验值 |
| 后续 | 减少不同内容参考的误迁移 | 对照当前基线；不能牺牲同图与简单颜色变换 |
| 研究 | 人物与背景协调 | 先证明画面统一和稳定收益，再决定产品控件 |

这些是建议接手任务，不代表已实现承诺。选择一项后按 [协作指南](../CONTRIBUTING.md) 建分支、写验收条件。
