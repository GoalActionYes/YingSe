# 映色目前用什么算法

本文区分项目目标、剪映调查、已经运行的软件和离线实验，供汇报与交接使用。不同入口的能力不能合并成同一个已完成版本。

## 从最初方案到现在，发生了什么变化

最初希望调查剪映的参考图调色，再实现类似功能。调查取得部分资源、特征节点、映射生成入口和最终渲染链的证据，但**没有完整恢复剪映从两张图生成颜色映射的全部内部逻辑**。不能据此声称映色核心算法等同于剪映，也不能把剪映判定为八个预设滤镜的混合器。

后续为了改善跨内容风格迁移，项目扩展到公开模型与自有训练实验。这是技术路线的扩展，不是通过反编译得到的新证据。研究版使用训练权重，并不证明稳定版、全部历史版本都使用同一种模型。

原始立项书本来包含ResNet18预测八个基础LUT权重及合成数据训练。后续增加的是不同于该方案的空间模型和条件预测研究，不能把所有训练一概称为后来才提出。具体变更理由与停止条件见[路线决策](ROUTE_DECISIONS.md)；原计划书保留原样。

| 部分 | 实际用途 | 应怎样介绍 |
| --- | --- | --- |
| 早期预设滤镜混合方案 | 在已有滤镜表示范围内寻找组合 | 项目早期方案，不能等同于当前全部实现 |
| 稳定1.3版 | 全局颜色映射与手动调整 | 可用产品基线；具体流程以该版源码和记录为准 |
| 13号自适应实验版 | 公开Hist2Style路线的研究实现，使用已经训练的权重、参考色彩统计及目标内容条件来产生空间颜色变换 | 自有模型研究原型，不能称剪映原算法或已理解人物背景 |
| PETAL等候选 | 离线评估其他已训练模型及其组成部分 | 实验，不是新产品版本；失败候选不接入 |

当前13号使用的权重仍是 `multiref-control-v1/epoch-6.pth`，SHA256为 `d8d8e6727a44100e6fedb11b605a17e33afc675de7448d4ebcf6d24d492ad4c9`。后续性能优化没有修改这个权重。启动入口是仓库根目录下 `00-从这里开始/13-打开自适应调色新版.cmd`，本机环境与权重不随Git分发。

## 为什么会研究模型

普通全局颜色映射让相同输入RGB得到相同输出RGB。如果两个区域原本颜色相同，却希望它们分别呈现不同颜色，仅调整一张普通CUBE无法表达全部要求。这是表示能力的限制，不是增加几个滑块就能消除的问题。

希望提高的具体能力是：参考图换成不同内容后，仍较好地迁移颜色、明暗与饱和度关系，减少场景本色干扰、偏色以及风格被平均的问题。人物与环境协调是其中一种困难情形，当前没有通过充分验收。

空间条件模型可以让颜色变换随位置或图像内容变化，但**有空间变化不等于识别人、有神经网络不等于理解审美关系**。是否更好必须看实际图像和负例。普通CUBE也不能完整保存这种局部效果；13号实验版不能被介绍成可导出完整空间效果的普通CUBE版本。

## 「使用模型」「训练模型」「验证模型」不是同一件事

- 使用模型：加载已有权重计算结果，不更新权重。
- 训练模型：用样本和监督更新权重。项目历史做过这类实验，其中只有满足当时门槛的权重进入对应实验版本。
- 验证模型：固定权重和测试规则，比较结果。此前PETAL完整模型筛查与风格编码器诊断属于此类，那两次没有启动新训练。

之后实际做过新增条件头训练：固定原映射主干，只学习预测修正参数的小网络；对应候选没有通过完整画质门槛，未接入软件。也做过线性回归、高斯核回归和风险判断器拟合，它们同样从训练样本学习参数，不能笼统介绍成「没有训练」。最近高斯核试验的训练参数误差下降，但开发画质相对线性控制只改善0.0831%，完整门槛失败。[完整结果](research/2026-11-15-condition-kernel.md)保留收益与退化案例。

当前研究增加学习方法，是为了提高跨内容迁移的适应性；这不是从反编译中确认了剪映使用同样方法。现有导入、参考调色、手动调整和导出功能不依赖这些新候选成功。研究候选失败时保留已有软件，不以模型更复杂作为升级理由。

之后还测试了让冻结编码器指导亮度等五项自动微调。这是每对图片求参数，没有更新模型权重；实际77组画质门槛失败，未接入。详见[实际输出及失败范围](research/2026-11-15-petal-retouch.md)。

编码器可理解为把图片概括成一组数字的模块。它如果能把同一种调色风格的不同画面放得更接近，可能适合进一步研究；但这种配对成绩不能直接证明最终调色会更漂亮。

## 已做到与仍然缺少的证据

当前已运行参考图驱动的图片／视频调色研究原型，已有强度调整、预览及导出流程。第10阶段改进了整帧GPU渲染，在所测尺寸和强度上保持结果逐像素一致。它解决的是部分速度开销，没有改变风格提取或迁移算法。

还不能承诺完整复刻剪映、自动理解人物背景、所有自然照片都更好，或完整1080p视频链达到30fps。自然审美评价仍缺实际人类匿名评价；所测渲染耗时也不能替代解码、模型分析、调整、显示与编码的完整耗时。

下一项模型是否进入产品，必须同时有画质收益、负例不明显恶化、可接受速度与明确导出边界。配对准确率、单张好看的图、测试通过或模型规模，都不足以单独证明升级成功。
