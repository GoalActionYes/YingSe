## 发现并修复的交接问题

1. Git 的自动换行转换使曲线表校验失败。为两份 `curve_tables.json` 设置 `-text`，按字节保存；未修改曲线值或算法公式。
2. Windows 虚拟环境的启动器 PID 与实际解释器 PID 可能不同。测试改为对比解释器报告的 PID 与服务就绪文件，仍检查真实服务、认证停止与进程退出。
3. 仅安装依赖不会填充应用查找的 FFmpeg 目录。新增准备脚本，指南不再假设本机已有运行时。
