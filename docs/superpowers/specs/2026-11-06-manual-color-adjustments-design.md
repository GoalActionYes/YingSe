# 映色手动调色面板设计

日期：2026 年 11 月 6 日。状态：用户已授权自行实施和测试；第一批主版实现完成，后续批次仍为规划。

## 目标与依据

暂停人物与背景分区协调研发。保留当前参考图匹配，增加用户可理解、可重置、能一致导出的手动调色能力。用户提供的七张剪映面板截图用于布局、分组与操作参考，不作为其内部算法证据。

采用自主实现，优先使用确定性的全局颜色变换。不为这些常见控件启动新的逐项反编译工作，不复制剪映 DLL、模型、素材或标识，也不宣称同名数值与剪映像素一致。

本次属于现有软件的调色管线与项目状态扩展，需要同时覆盖前端、预览、导出、持久化和旧项目兼容，不能只增加外观控件。

## 交付范围

### 第一批：基础、HSL、RGB 曲线

先交付能共同作用于图片与视频、能导出 CUBE 的全局颜色工具。

| 面板 | 控件与操作 |
| --- | --- |
| 基础／色彩克隆 | 保留参考图缩略图、开关与强度，不改变已恢复的匹配公式 |
| 基础／色彩 | 色温、色调、饱和度、自然饱和度 |
| 基础／明暗 | 亮度、对比度、高光、阴影、白色、黑色、光感 |
| HSL | 红、橙、黄、绿、青、蓝、紫、洋红八个颜色段；每段独立色相、饱和度、亮度 |
| 曲线 | 总 RGB 与 R/G/B 四条曲线；添加、移动、删除控制点，单通道与整组重置 |

基础滑块用 -100 至 100、默认 0 的产品量程。数字输入、滑块与键盘同步，越界值限制，拒绝非有限数值。量程只属于映色，不能称为剪映数值标定。曲线端点初始为 (0,0)、(1,1)，默认对角线；控制点按横坐标排序，禁止重复横坐标，首版用有界分段线性插值保证操作可解释。

HSL 使用连续重叠的色相权重，红色跨色相环首尾连续，降低灰色像素的色相不稳定影响。自然饱和度优先影响低饱和颜色，不冒称人物识别或肤色保护。光感定义为温和的中间调曲线，与亮度的全局移动不同；文案明确其自主实现性质。

### 后续批次：不作为第一批已实现功能

- 色轮：阴影、中间调、高光和全局偏移，待第一批交付后再实现与验证；首批不放无效页签。
- 色相／亮度／饱和度之间的六类高级曲线、吸管取样、自定义 LUT 导入：后续独立设计。
- 锐化、清晰、颗粒、暗角：属于空间或纹理处理，需要另建图片／视频一致的像素处理路径；不承诺能导出到 CUBE。褪色可做全局曲线，但不混入未交付控件。
- 蒙版、关键帧、自动色彩校正、付费入口和完整剪辑时间线不在本次范围；不显示空按钮。

## 界面与使用方式

保持左素材、中大预览、右调整面板。右侧采用深灰背景、青色选中态，顶部使用“基础／HSL／曲线”页签，面板内部滚动；截图中的“色轮／蒙版”待实际可用才出现。

分组有折叠、启用开关和重置；每项有滑块、数字与单项重置。关闭一组不删除数值。提供“重置手动调整”，不清空素材、不重新分析，也不改参考图强度。色彩克隆开关只控制克隆，关闭后手动调整仍可生效；“原始画面”始终查看所有调整前的源画面，避免与关闭克隆混淆。

拖动参数更新分析帧预览，不每次重新分析参考图。最新设置覆盖旧预览请求，迟到响应不能覆盖新结果。预览缩放与全尺寸导出允许显示差异，但颜色计算使用同一份组合 LUT。视频维持现有分析帧预览，不把单帧预览表述为整片实时播放。

## 处理与导出契约

固定顺序：目标 RGB → 现有克隆映射及强度 → 基础调整 → HSL → 总 RGB 曲线 → 各通道曲线 → 合法色域输出。

把克隆强度后的结果与手动变换合成一个 64³ LUT。预览、PNG 与视频 FFmpeg 路径都使用该组合 LUT 的三线性插值；CUBE 导出写入相同采样表。合成过程中保持浮点精度，最终图像按当前 8 位工作精度输出，不逐个控件做 8 位取整。

全部手动参数中性、关闭或为空时，严格走原路径，避免 LUT 再采样引入旧功能变化。组合 LUT 是有限分辨率的近似，不能承诺任意极端曲线和 HSL 设置都与逐像素解析计算完全相同；用密集色卡测量误差，并对极端设置造成的断层给出测试记录。

图片与视频使用同一静态颜色映射，无逐帧识别或蒙版。本次维持源时间戳与现有音轨策略，不因手动调色强制 30 fps。10 位 SDR 仍转 8 位工作，HDR／Log 不因新增控件而获得支持。

## 参数、缓存与兼容

新增独立、带版本号的 adjustments 状态，包含基础值、八段 HSL、曲线点与各组开关。后端校验字段、类型、有限值、范围、曲线点数及次序；禁止字符串或布尔被静默当数值。旧请求缺少此字段时等同中性设置，旧项目仍可打开。

预览、导出和项目保存使用相同规范化状态。导出开始冻结当时设置，后续拖动不改变正在执行的任务；旧下载链接在参数改变后失效提示沿用现有行为。导出记录保存组合参数、计算版本与映射指纹。手动设置不改变原始参考匹配缓存，只影响组合 LUT 缓存，参数变化不能误用旧组合结果。

第一批以根目录主开发版为正式入口。肤色实验副本保留原样，不让同学误以为两份界面都已更新；版本说明明确差异。后续如需同步，单独验收其空间保护与新调色的处理顺序。

## 验收

1. 中性设置对旧 PNG、CUBE、预览保持原行为，原源码检查通过；关闭克隆与原始比较语义正确。
2. 每个基础控件有方向性、有限范围、端点、重置与分组关闭检查；自然饱和度和普通饱和度行为可区分。
3. HSL 覆盖八段、相邻段过渡、红色环绕、灰阶与极端参数；曲线检查默认恒等、通道独立、点编辑与非法输入。
4. 组合 CUBE 重读后与应用同表采样一致；图片预览与导出的同位置颜色对应；视频编码前后误差分开报告。
5. 使用生成色卡与有授权的真实画面演示。检查多项叠加、肤色、阴影、高光和灰阶，记录剪切与断层；主观效果不伪装成像素等价证据。
6. 实际短视频保留时长、帧时间和音轨，导出、取消、失败提示、项目重启恢复均验证。
7. 浏览器检查拖动、数字输入、切换页签、曲线点编辑、滚动和快速连续修改，不出现迟到预览覆盖。

通过一批完整功能与验证后统一提交并上传 Git，不为零散样式变动发布版本。
