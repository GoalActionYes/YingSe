# Supervised Style Probe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for inline execution. Steps use checkbox syntax for tracking.

**Goal:** 验证监督学习能否在未参与训练的图像内容上识别受限的全局／局部色彩风格，为完整自适应迁移提供证据；不把阶段通过当成总体完成。

**Design:** `experimental/adaptive-reference-20261113/supervised-style-probe.md`。沿用用户已授权的自主研究、测试和阶段性 Git 记录，不修改产品。

**Stack:** 当前独立 PyTorch 2.6 CUDA 环境、官方冻结 DeepLabV3-MobileNetV3-Large、NumPy／Pillow；不安装新运行时，不下载额外大模型。

## Task 1: 新数据与分组

- [ ] `test_style_dataset.py` 验证确定性、240/30/30 数量、原图隔离和重复身份拒绝；先观察失败。
- [ ] `style_dataset.py` 实现选择和下载，排除旧 60 张及相同原图哈希，保存授权／来源／图像／蒙版哈希。
- [ ] 准备300张素材，每类80/10/10分组，保存完整清单，不运行最终测试。

## Task 2: 受限风格控制与 RGB 特征

- [ ] `test_style_probe.py` 验证恒等、不同区域有不同映射、同风格标签跨内容一致、范围和尺寸不变；先失败再实现。
- [ ] `style_probe.py` 实现两区域六维风格及有界控制生成，人工标注仅用于控制生成和监督损失。
- [ ] `style_features.py` 使用冻结官方分割模型从 RGB 提取区域统计及深层特征；记录224方形推断分支、源权重哈希和冻结状态。
- [ ] 训练两个预测器：仅区域颜色统计、加深层特征；前向接口不接收人工蒙版。

## Task 3: 训练与验证

- [ ] `train_style_probe.py` 固定1800步、batch8（四种风格各两张不同训练图）、AdamW；每150步固定验证。
- [ ] 采用归一化参数监督和跨内容一致性损失，缺失人物角色不评分；记录零参数基线。
- [ ] 两模型使用同一训练流，只依据验证损失选择检查点。保留源文件／数据清单哈希、完整指标与安全状态权重。
- [ ] 验证参数MSE至少比零参数基线降低20%才认为有继续测试的信号；否则保留失败并调整研究路线，不接入。

## Task 4: 冻结后的独立测试

- [ ] 先写入选择结果与源文件哈希，再生成最终测试增强；图像身份从未进入训练或验证。
- [ ] 参数测试：与零参数基线比较。调色作用测试：从参考图预测风格，再应用到另一张原始目标图，与已知风格目标和恒等输出比较。
- [ ] 预先要求参数MSE降低20%、调色图像MAE相对恒等降低15%；结果只支持受限合成风格识别，不支持自然审美或视频交付。
- [ ] 完成独立代码／数据隔离审查，记录成功与失败，决定是否进入目标图风格估计及结构保持变换。

阶段后仍需自然参考图、未知照明、风格组合、强度／恒等、快速预览和完整视频一致性验证。Git 在完整研究阶段记录，不推送零散变动。
