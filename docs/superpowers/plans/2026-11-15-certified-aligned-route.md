# 同画面对齐分支实施计划

**目标：** 在独立13号复用既有固定门槛的同画面对齐拟合，避免统一风格负例退步，保持普通不同内容参考的模型路径。

**依据：** `docs/research/2026-11-15-product-style-diagnostic.md`。本方案为代理依据已有自主开发授权作出的实现选择，不表示用户逐项审阅过方案。

**架构：** 分析时只在multiref配置检查既有 `fit_aligned`；通过则持久化其LUT和诊断，否则保持原路径。已准备映射对象统一服务图片与视频，不逐帧切换路线。保留原图／满强度混合后再手动调整的顺序。无需新训练、依赖或界面开关。

- [x] 写失败测试：真实结构图的已知色彩变换应被13号接受并正确渲染；不同画面和App8不启用；重启、半强度及手动调整一致。
- [x] 新增 `aligned_spatial.py` 映射适配对象；接入 `spatial_store.py` 分析、缓存、准备和图片渲染；模型权重不改。
- [x] 接入 `spatial_jobs.py` 固定视频映射，明确导出记录，不将固定LUT记成逐帧模型平滑。
- [x] 更新构建／缓存依赖；跑回归、真实HTTP、受控66图和3组视频、普通参考不变性与浏览器检查。
- [x] 独立审查、整理前后证据；阶段发布以远端标记核对为准。详见 `docs/research/2026-11-15-certified-aligned.md`，视频独立无损审计与普遍自然质量不在通过声明内。

**审查重点：** 同长宽不同内容误接收、近似恒等、视频非零分析时间、旧缓存与损坏缓存、强度与手动调整顺序。门槛固定，不为通过检查放宽。
