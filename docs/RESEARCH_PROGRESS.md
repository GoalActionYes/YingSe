# 自适应调色研究：版本与交接

主程序仍为1.3手动调色版本。以下是独立研究进展，不表示已经替换稳定程序或完整复刻剪映。模型、训练数据、环境和本机项目不随Git发布。

汇报先看[阶段成果与方法](MILESTONES.md)：分别列出自适应模型、视频稳定、独立软件、强度连续预览、切镜重置和手动微调线程预览，每阶段保留问题、方法、效果、验证及版本。

## 先看当前状态

自参考偏差诊断：[固定扣除模型自身误差](research/2026-11-15-self-bias.md)未通过门槛，自然32组12改善、20恶化；受控局部均值虽降，仍有控制案例明显退化。不训练、不接入、不搜索扣除比例。全部62组原始公式与186张输出经审计，当前产品保持第9阶段。

直接分区统计诊断：[人物／背景加权直方图](research/2026-11-15-region-histogram.md)未通过门槛，30例6改善、12恶化、6明显退化；不训练、不接入、不调阈值重试。概率缓存、受控素材及当前基线已重新核验。它不等于已实现人物与场景关系迁移，当前产品仍保持第9阶段。

独立尝试：[近中性亮部锚点](research/2026-11-15-neutral-anchor.md)仅有很小的描述性收益，且无法区分材质与风格，不接入、不继续调阈值；当前产品保持第9阶段。报告同时保留小幅损害、协议偏离和未做视频／人类验收的范围。

自然参考诊断：[32组匿名对照及评价材料](research/2026-11-15-natural-review.md)。已更正比较对象：此前把 `before` 误标为旧全局，实际为App8模型。原始图片／选择／票数不改，不得将该AI统计解释为相对旧全局的收益。人类评价为0。默认80及相近改变量对照另行补验，产品保持第9阶段。

默认强度补验：[实际0／50／80／100与相近改变量控制](research/2026-11-15-default-strength.md)完成；同数字不等于同幅度，32例仅26例可在0.5码值内匹配。属于计算和非匿名诊断，不是新增人类偏好或软件升级。

最新性能改进：[第9阶段RGB8回传](research/2026-11-15-byte-render.md)，大图渲染加快、12／13号所测输出逐像素一致，实际导出哈希保持不变。未达到1080p完整视频30fps，不代表调色理解能力提高。

最新功能：[第8阶段同画面匹配](research/2026-11-15-certified-aligned.md)已实现并完成有范围的图片／视频／浏览器验收，受控60例50改善、0退步；不同内容参考保留原模型。未再训练，不代表语义对应或完整效果目标完成。[原缺口诊断](research/2026-11-15-product-style-diagnostic.md)保留。

## 如何接手

普通UI／控件修改从[协作指南](../CONTRIBUTING.md)进入主程序。算法研究从[实验README](../experimental/adaptive-reference-20261113/README.md)进入，每项结果先读对应协议和范围。研究权重与本机`.tools`没有上传，不能只克隆仓库便宣称研究入口已经可运行；稳定版源码按启动指南准备依赖。

本机Git已完成登录，研究阶段按里程碑推送至`codex/adaptive-reference-research-20261113`。此前连接器写入返回403，现由本机Git保留原始历史发布。最新提交是否已上传以远端分支为准。只上传代码、文档及可公开摘要，不上传测试照片／视频、模型或会话记录。稳定`main`不由失败候选覆盖。

本机已安装Git Credential Manager时，可以在仓库终端执行`git credential-manager github login --username GoalActionYes --browser`完成浏览器登录；密码和Token不要发到聊天里。登录后由本地Git推送研究分支，保留原始提交历史：

```powershell
git push -u origin codex/adaptive-reference-research-20261113
```

如果使用增量Git bundle，接收方先克隆GitHub仓库以取得基础提交，再在该仓库执行：

```powershell
git fetch "提交包路径.bundle" codex/adaptive-reference-research-20261113:codex/adaptive-reference-research-20261113
git switch codex/adaptive-reference-research-20261113
```

bundle保存已提交历史，不包含未跟踪素材、运行环境或模型。它是离线交接文件，不等于GitHub已收到推送。
