# 人物／背景自动分区匹配：图片与视频可行性试验

这是可撤回的研究试验，不是已集成的新App。稳定版和肤色保护实验版、旧分发ZIP均未更改。20项稳定版冻结文件SHA256全部保持一致。没有要求用户圈选区域，没有下载新的模型或依赖。

## 这次做到什么

参考图和目标画面分别自动识别人物（头发、脸部皮肤、身体皮肤、衣物）与背景。从对应区域提取统计特征，为人物和背景分别生成固定颜色映射，再用逐帧人物蒙版融合两种结果。背景在本次试验中包括人物以外的内容；没有进一步区分天空、建筑、树林，也不支持任意物体主体。

分割沿用已有离线SelfieMulticlass模型，人物类别1/2/3/4，分析最大边512。只使用可信区域估计特征，人物或背景不足时明确回到整体匹配。视频根据首帧生成映射，每帧重新识别人物并作少量光流对齐平滑；发生切镜时清理蒙版历史，但没有重新分析各镜头的颜色映射。

试验复制并修改了特征提取和视频管道至 work/region-match-probe，正式模块未改。特征直方图使用被选区域，区域色彩统计至多采样512点，因此它是新研究适配，不是剪映原生区域算法。模型负责识别，颜色映射及融合由数值算法执行。

## 运行结果与限制

| 检查 | 实际结果 |
| --- | --- |
| 自动区域识别 | 样例人物面积约37%，参考图和目标均成功识别 |
| 视频 | 3秒640×360、原25fps → 30fps，共90帧，完整解码90帧，输出3秒 |
| 视频处理时间 | 约23.94秒CPU；单样本，不是实时/4K性能承诺 |
| 逐帧模型 | 90帧均识别到人物，末帧采用运动对齐；不是仅铺首帧蒙版 |
| 无人物参考 | 显式回到整体匹配；没有假装完成分区 |
| 关闭/零强度基础行为 | 原映射0强度逐像素返回输入；尚未新增产品开关 |
| 统计隔离 | 改变未选区域像素，不改变受测区域的特征数据（本次输入未触发680缩放） |
| 子进程与视频文件 | 正常结束后登记子进程全部退出，整片解码验证成功 |

图片比较强度均为80%。控制参考由同一目标画面生成：人物变暖、背景变冷。区域边界也来自模型预测，因此只能作受控机械对照，不是人工标注真值或独立分割准确率评估。

| 对控制参考的RGB平均绝对误差（0–255） | 当前整体匹配 | 同采样政策的整体对照 | 分区匹配 |
| --- | ---: | ---: | ---: |
| 可信人物区域 | 10.31 | 10.04 | 9.32 |
| 可信背景区域 | 4.21 | 4.44 | 5.89 |

人物指标改善，背景指标变差，不能声称总体优于整体调色。两种结果都只以80%强度处理，而参考是100%已修改图，因此这些数值用于同条件比较，不能把它们视为应当为0的正确性指标，也不能替代审美评价。同采样整体对照用来提醒：新分区提取与旧全局提取的采样政策有差别，收益不能全部归因于分区。

恒等诊断（参考就是目标、强度80%）也出现颜色漂移：整体平均误差5.56，分区5.97。现有映射链有参考侧处理及曲线偏置，不能把同图输入当成恒等保证。未来新算法应明确设计并验证这种行为。

不同内容的参考图（多人、树林和马）下，目标人物的脸和白衣更偏紫，仅从结果还不能确定偏色来自衣物占比、参考肤色、统计提取还是原有映射偏置，需进一步消融比较。人物组内衣物本色是候选干扰因素。头发、衣物与皮肤合为人物一类，不能完全解决材质颜色与风格混淆。背景也没有变成与参考树林相同的视觉风格。这是继续研究的主要问题，不能靠改名字或增加开关掩盖。

已查看图片与视频0/1/2.5秒抽帧。尚未完成人工逐帧质量审阅、快速遮挡/多人交叉/自然背景/不同肤色/长片与跨镜头验收。本次视频无音轨，没有新增验证该实验分支的音频同步。此试验没有与肤色保护同时叠加，避免两种目标相互抵消。

## 下一步建议

视频应继续保留在目标范围，当前证据已证明管道可行。产品化前先研究：人物内皮肤与衣物统计如何分开；区域映射怎样在证据不足时向全局映射收敛；如何保证人物与环境协调；切镜后是否重新分析。再比较结果，决定是否接入默认关闭的“人物／背景分区匹配”开关。

这一步值得继续，但当前不足以发布一个“开启就更接近参考”的功能。先看本文件列出的成功与失败样例，讨论可接受的目标，再做正式设计。
