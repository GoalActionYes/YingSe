# 可用阶段：同画面参考的颜色匹配更稳定

1号基础版和2号肤色实验版已接入新路径。用同一画面的调色参考，软件在确认空间对应且拟合误差足够小时学习颜色变换；无法确认时自动沿用原算法。

这里主要改善“同镜头、同构图”的参考，不代表不同人物或不同场景之间的风格迁移已解决。压缩和缩放也只是部分样例通过，拒绝时保持旧结果。

材料：

- 人像对照.png、多人对照.png：左到右为目标、已知参考、上一版、新版；展示近似同图、暖色、冷色和对比度。
- 结果视频.mp4与视频参考图.png：学习首帧的已知暖色变换后应用整段，3秒75帧，带440Hz测试声。
- 源码与证据见docs/research/2026-11-05-aligned-reference。

12张图片的冷暖、去饱和、对比度测试全部通过，平均RGB误差中位数降到约0.02至0.20码值。JPEG质量92通过10/12，半尺寸通过4/12。264组不同内容负例和12组局部改变均未误触发；数据量有限，不保证真实使用永不误判。77项基础版、97项肤色版测试通过。

数学拟合是标准方法，属于自主增加的可靠性路径，不是新恢复的剪映算法。旧肤色协调研究仍未作为默认功能接入。
