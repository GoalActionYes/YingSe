# 阶段演示：参考肤色协调

这是本轮研究原型，尚未接入默认软件。作用是在整体参考调色之后，让皮肤颜色适度靠近参考人物，并限制局部色差，保留整体亮度与背景调色。

建议按顺序查看：

1. 肤色局部放大.png：左到右为目标、控制参考、现有管线、新原型。
2. 完整图片对照.png：包含六组已知调色控制和三对不同内容的自然参考。自然参考没有客观正确答案。
3. 目标视频.mp4、参考图.png、结果视频.mp4：三秒演示，结果为30fps、90帧，带测试用440Hz声音。

六组受控肤色色度误差下降约35%至49%，蒙版外背景不变，额外亮度变化小于半个8位码值。视频90帧整片解码通过。33项代码测试通过。

限制：不是完整复刻剪映；参考肤色不正确时也可能被学习；多人共用偏移，不能逐人对应；背影或遮脸可能回退；尚未验证长片、复杂光照和镜头切换。图片局部效果不能导出成普通全局CUBE。视频有损编码可能改变背景像素，逐值背景保证指编码前。
