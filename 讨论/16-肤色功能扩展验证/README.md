# 补测后的判断：还不足以作为正式功能

这轮扩大到60组控制测试和10对自然参考。排除一份旧照片的不同裁切后，55组新内容控制中，28组RGB逐像素误差改善、7组退步、20组变化很小；误差下降的中位数约0.12个8位码值。指标不是人眼画质评分，不能据此宣传成功率。

另有5组总体改善，但部分皮肤区域退步。原先35%至49%的结果只适用于那六组特定色度控制，不能代表一般照片。

建议先不接入参考肤色协调。当前更值得解决的是基础管线的同图参考漂移和亮度、对比度偏差：某一同图样例的皮肤RGB MAE约32.6，局部修正后仍约32.3，远大于新功能的典型改善。

材料：

- 反例对照.png：七组新内容控制中的退步样例。
- 控制对照：全部12份照片、每份五种参考，按左到右为目标、参考、实际原管线、局部修正。
- 自然参考对照.png：10对真实不同内容参考，没有客观风格真值，不能用肤色均值接近程度证明美感。
- 人物切猫再返回.mp4：修复后的3秒、30fps、90帧安全回退探针，带440Hz测试声。

视频旧探针只检查首帧，后续无人猫狗图仍可能被局部改色，已加每帧适用条件和历史清空。修复后30帧猫画面不受额外局部改色，人物返回时重新开始。只能保证此短序列，不能宣称复杂视频或无闪烁已验收。
