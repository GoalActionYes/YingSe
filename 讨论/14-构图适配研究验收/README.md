# 最新研究结果在哪里看

双击本文件夹的 **构图适配研究展示.html**，或使用 **00-从这里开始/9-查看最新研究对照.cmd**。页面包含流程、图片对照、已知失败和后续条件。

本文件夹的 **构图适配视频.mp4** 是本轮3秒视频验证输出，可直接播放。

本轮新增“只适配参考贡献”的研究方法，修复恒定色统计残差造成的矩阵异常。18项测试通过，三组新增受控占比漂移减少约47%、66%、55%，3秒视频75帧导出解码通过。

这些是限定条件下的结果，不代表普遍更好看。旧对照仍有只改善5%的样例，猫图有人物误识别，多人参考误差仍有轻微增加。因此本文件夹是研究展示，不是第三个已发布软件，默认App尚未改变。

本机展示页嵌入公开测试图像，不依赖联网；原图及许可按各来源规定。Git不上传嵌入图像的HTML和截图，只保存生成脚本、本文和小体积证据。另一台电脑只克隆源码后不会自动出现展示页。
