# 实际内容与视频补充验证

日期：2026年11月5日。结论：暂停当前贡献平衡候选的产品接入，保留代码和研究方向，不宣布算法有效。

## 实际执行

从Google MediaPipe官方资产下载portrait.jpg与pose.jpg，出处由官方face_landmarker_test.py和pose_landmarker_test.py的测试资源名称核对；记录URL、大小和SHA256于sources.json。另使用前轮三人骑马样本。两张是本轮新增，第三张不是新留出素材，不能算三组独立盲测。

所有图片缩到最大边640，在原图和参考上分别进行人物分割，比较同一个全像素统计估计器的0档和0.5档。参考由同图的人物轻微暖调、背景冷调构造；区域来源是模型预测，不是人工真值，也不是自然调色参考的数据集。参数没有根据本次结果重新挑选。

## 结果

| 样本 | 0档相对控制参考的RGB平均绝对差 | 0.5档 | 判断 |
| --- | ---: | ---: | --- |
| 正装人像 | 13.65 | 13.65 | 几乎无变化 |
| 海边人物 | 8.05 | 8.55 | 增大 |
| 多人骑马 | 10.69 | 11.29 | 增大 |

输出强度80%，控制参考为100%修改图，数值不是应该为0的正确性标准；这里只比较同条件候选。海边样例任一通道位于0或255边界的像素比例从24.44%到29.94%；边界本身可能来自原画面白沙等内容，不能单凭此指标断言所有这些像素都丢失细节。

另外循环使用三个不同内容参考进行了三对对照并查看拼图。部分输入有明显颜色和亮度迁移，但没有可靠证据表明加权版本整体比0档更协调。没有组织盲评，也不能将作者单次观察当用户调查。

## 视频工程验证

使用既有官方人物动作片3秒，分析帧与新portrait参考生成一套组合全局LUT，FFmpeg应用整段。保留原25fps，输出75帧，整片解码75帧，容器时长3秒。该路径不需要逐帧分割，因为本候选只改变分析统计，渲染仍是一套固定全局映射。

该样片无音轨，没有新增验证音频同步、取消、长片或切镜自动重算；没有把它说成新的完整App验收。视频输出文件位于outputs/content-balance-20261105/natural-check/global-balanced-video.mp4。

## 决定与下一步

当前候选未通过自然内容验收，不加入正式界面，不替换现有稳定映射，不提供一个可能让效果变差的默认开关。占比漂移减少不能替代整图协调。保留研究代码供组员复核；暂不继续用同一批样例反复调参数。

如继续该算法方向，先明确可验证的失败原因、建立独立风格参考和人工对照，再提出下一种方法。当前稳定版和肤色保护实验版仍是可体验的软件；研发脚本不是第三份可运行App。
