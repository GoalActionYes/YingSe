# 统计贡献平衡研究版

状态：研究中，不接入正式App。仅保留一套全画面映射，尝试在特征采样时平衡人物与背景贡献。每组相对原占比的权重限制为0.5至2倍，候选量为0、0.25、0.5。可信区域不足时回退全图采样。

同采样政策的0档是研究对照，不等于稳定版的原始稀疏提取路径。稳定版关闭功能时的逐值回退尚未进行产品接入；此处不能冒称已经实现。

## 代码

- balance.py：有上限的贡献比例与确定性采样。
- test_balance.py：零档、权重上限、重复性、输入保护、不可靠区域回退、参数验证。
- evaluate.py：受控占比与实际图片示意，使用已有离线分割依赖。
- repeat_controls.py：更换三个像素池采样种子，检查结果是否稳定。

使用上一级skin-protection-20261019/runtime/python.exe运行。研究依赖现有模型与work/region-match-probe/run_probe.py，尚未整理为可独立分发的产品模块。源码仓库不携带运行时和模型。

## 本轮结果

7项针对性测试通过。首轮单组受控试验，0.5档的占比漂移中位数较同采样0档下降21.6%。相同像素池换三个随机种子，0.5档分别下降36.2%、增大10.8%、下降21.2%。随机种子不是独立照片，不能据此称自然场景留出验证通过。

两张官方图片的实际内容对照已保存。0档采样路径本身也会改变旧版输出，同图参考仍有漂移。因此不能把全部差异归因于语义加权，更不能把漂移下降等同于画面更好看。

## 决定

不接入界面、不默认启用、不重新打稳定包。优先分离有限采样误差与占比效应；若同采样重复对照仍不稳定，则停止该候选。后续自然图片、独立留出、盲评和新方法视频验证均未通过，不能跳过这些条件。

结果入口：outputs/content-balance-20261105/candidate/。历史稳定版、肤色保护版保持原样。
