# 统计贡献平衡研究版

状态：研究中，不接入正式App。仅保留一套全画面映射，尝试在特征采样时平衡人物与背景贡献。每组相对原占比的权重限制为0.5至2倍，候选量为0、0.25、0.5。可信区域不足时回退全图采样。

同采样政策的0档是研究对照，不等于稳定版的原始稀疏提取路径。稳定版关闭功能时的逐值回退尚未进行产品接入；此处不能冒称已经实现。

## 代码

- balance.py：有上限的贡献比例与确定性采样。
- test_balance.py：零档、权重上限、重复性、输入保护、不可靠区域回退、参数验证。
- evaluate.py：受控占比与实际图片示意，使用已有离线分割依赖。
- repeat_controls.py：更换三个像素池采样种子，检查结果是否稳定。

使用上一级skin-protection-20261019/runtime/python.exe运行。研究依赖现有模型与work/region-match-probe/run_probe.py，尚未整理为可独立分发的产品模块。源码仓库不携带运行时和模型。

## 本轮结果

7项针对性测试通过。首轮单组受控试验，0.5档的占比漂移中位数较同采样0档下降21.6%。相同像素池换三个随机种子，0.5档分别下降36.2%、增大10.8%、下降21.2%。随机种子不是独立照片，不能据此称自然场景留出验证通过。

两张官方图片的实际内容对照已保存。0档采样路径本身也会改变旧版输出，同图参考仍有漂移。因此不能把全部差异归因于语义加权，更不能把漂移下降等同于画面更好看。

## 决定

不接入界面、不默认启用、不重新打稳定包。优先分离有限采样误差与占比效应；若同采样重复对照仍不稳定，则停止该候选。后续自然图片、独立留出、盲评和新方法视频验证均未通过，不能跳过这些条件。

结果入口：outputs/content-balance-20261105/candidate/。历史稳定版、肤色保护版保持原样。

## v3：只适配参考贡献

新增 composition.py：目标保持未加权统计；仅将参考图的可信人物占比向目标拉近一半，仍限制每组相对贡献0.5至2倍。相同占比、关闭或任一可靠区域不足时，逐值返回全像素未加权对照。此对照仍不是稳定版稀疏提取。

修复了全像素估计器在恒定颜色上生成微小虚假方差的问题：改用相对观测颜色的差值计算矩，不修改恢复的矩阵公式。测试增至18项通过。v2已有结果保留，新统计版本标记为 dense-weighted-packet-v3-stable-moments。

三组新增图像使用严格相同区域内像素分布，仅改变占比，输出漂移分别减少47.1%、66.0%、55.4%。旧像素池的一个重复对照仅减少5.4%，不能只报告新增组。猫图暴露人物误识别；不同内容风格、盲评和可靠非人物回退仍待验证。尚不接入默认App。

运行 check_holdout_v3.py 重现固定协议，evaluate_composition.py 重现旧对照及3秒视频；make_review.py 生成本地展示源文件，再按视觉说明技能渲染。素材和离线运行依赖不随Git上传。详细证据见 docs/research/content-balance-20261105/reference-composition-v3。

## v4：人物适用条件

已新增person_gate.py，要求连续的高置信可见面部证据，否则将人物蒙版归零，回退未加权全像素对照。只修复是否允许适配，不改变通过后的蒙版或颜色公式。不是独立人物检测器，背影、遮脸和极小面部可能回退。

固定协议后新增六份素材，连同七份已观察回归，九张人物保留、四张非人物回退；八个目标或参考方向的回退结果逐值一致，九张通过蒙版逐值不变。25项代码测试通过，3秒视频75帧整片解码通过。没有据此认定通用检测可靠或画质变好，尚不接入默认App。
