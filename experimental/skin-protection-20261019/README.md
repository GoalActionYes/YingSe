# 映色 · 人物肤色保护实验版（2026-10-19）

本版独立于原有稳定版。右侧新增默认关闭的“人物肤色保护”：开启后以调色前的目标画面识别脸部和身体皮肤，生成局部蒙版，回补75%的原色度，尽量保留整体调色亮度。关闭保护沿用原有处理。这是新增实验功能，不是恢复出的剪映肤色算法。

保护图片可导出PNG；保护视频逐帧识别并统一导出30fps H.264/AAC，可能较慢。视频预览仍为所选分析帧。CUBE不能包含区域蒙版，需关闭保护后导出。无可靠皮肤时保留整体调色并显示提示；模型错误会报告，不会假装成功。模型随包离线运行，无须联网或上传图片。

细小人物、遮挡、逆光、快速运动和相近肤色背景仍可能识别错误，本版用于比较与讨论，不保证所有肤色和视频场景。模型来源和许可证见 THIRD-PARTY-NOTICES/skin-model，固定依赖见 dependencies-lock.json。

完整解压至可写目录，双击「映色肤色保护实验版.exe」（或 ReferenceColor.exe）。无需安装 Python。首次启动会打开本机窗口；仅处理本机素材。支持8位图片及8/10位SDR视频：10位视频在分析和着色前转为RGB8，MP4输出为8位，界面显示转换提示。HDR/BT.2020、未知位深及其他高位深暂不支持。当前不承诺与剪映逐像素一致；视频使用选定帧生成的固定映射，MP4为H.264/AAC有损编码。单个导入文件仍限制512MB。

界面采用深灰、青色的剪辑软件面板布局：左侧导入目标图片或视频，中间查看画面，右侧“调整 → 基础 → 色彩克隆”选择参考图片。两份素材就绪后自动分析；滑块或数字输入调整0–100强度。“色彩克隆”开关关闭时显示和导出原色，保留强度，再次启用恢复应用；“恢复原画”明确把强度设为0。

视频在播放器底部选择分析帧时间，点击“应用此帧”后重新自动分析。顶部“导出”定位右侧导出区。图片可导出PNG或.cube；视频可导出MP4或.cube，导入视频后自动选中MP4。导出完成后点击“下载完成文件”。也可使用图像/视频示例。关闭浏览器窗口后后台仍保留，重新启动将恢复已有服务和最近项目、强度及开关状态。

本版按剪映色彩克隆面板的风格与已支持操作改版，未实现完整剪辑时间线或剪映其他调整工具。核心是依据逆向证据的独立实现，不是剪映原生引擎；输入纹理、GPU精度及完整运行调用链仍待核实，界面相似不代表算法完全一致。

命令行 `ReferenceColor.exe --check` 隐藏启动/验证后台，不打开窗口；`ReferenceColor.exe --stop` 安全关闭本包后台（导出期间先完成或取消）。不结束其他程序。所有项目、导入副本、导出、日志、窗口配置均在本包 `data` 内；请保留完整目录并预留空间。移到新位置前先关闭后台。不要从ZIP内直接运行。

启动失败查看 `data/launcher-error.txt`、`data/native-launcher-error.txt`、`data/server.log`。必须保留 runtime 和 .deps；缺少FFmpeg时拒绝启动并记录原因。只使用本包依赖，不借用全局Python或剪映组件。Edge存在时使用本包独立配置，否则打开系统默认浏览器。

`package-manifest.json` 记录发布文件SHA256；ZIP和旁边.sha256为运行前干净分发件，不含data和个人素材。THIRD-PARTY-NOTICES及运行时元数据保留授权与源码地址。
