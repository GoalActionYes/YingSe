# 固定整图颜色表的方格归因

上一轮连续插值保留了台阶改善，但铁塔在跨越 32×32 留块分组时仍有方格。本轮检验这些方格是否由两张颜色表交替使用引起。保持两张参考表的训练像素、网格参数、零位移回退、原尺寸裁切和 80% 强度，逐一对整个目标应用每一张表。唯一变量是是否随画面位置切换表。不合并表、不增加配对像素，也不从两个结果中选最好的一张。

- 每个方向各渲染两张图。每张表只从对侧参考前后图的一折计算。按旧分组将两张输出拼回去时，须逐像素重现以前的连续插值。模型不读取目标作者结果，读该结果只用于评分。比较原图、13 号、交替表以及两个固定表。
- 仍在上个协议的固定像素区域测量整图、完整近中性色和新增覆盖的近中性色。两个固定表都须比原图和 13 号误差降低至少 1 码值且有正向响应。整图和完整近中性色相对交替表允许的最大退化仍为 0.5 码值。
- 在旧启停交界上保留作者第 95 百分位加 2 码值的门槛，另比较跨旧 32×32 分组与分组内部的相邻跳变。两张固定表在两个方向都须通过门槛，且铁塔天空的原方格在两张成片中都不再明显，才支持分块切换是主要原因。保留天空、台阶和裙子的剩余差异。两个重复运行，预算两分钟。
- 此轮结束后保留可复现的离线对照与失败记录。额外参考原图仍是必要输入，任何结果都不能证明正常自动两图入口达标。若方格未消失，结束这项固定表归因；若消失，则将其用于验证未来正常两图方法的渲染，当前不接软件。
