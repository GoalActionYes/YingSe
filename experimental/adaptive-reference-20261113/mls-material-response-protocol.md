# 已知同材质身份能否传递实拍换灯变化

固定已通过资格的 MLS 02↔03 两个方向、原四张线性编码输入与蓝纸棱柱和绿纸方块。用另一场景的换灯前后图，在其两个实测材质区域内计算线性 RGB 的平均对数色度变化。三种重放使用相同目标掩膜、逐像素亮度保持及 80% 强度：按同名材质选相应变化、交换两种材质的变化、用供体两个材质共同有效像素的整体均值。只在两个材质区域输出，一律保持其他位置。目标换灯实拍仅用于评分。此处使用参考前后实拍和人工区域，是离线能力诊断，不能作为正常两图产品成绩。

沿用上轮输入身份、曝光资格、80% 实拍答案及原方向和误差门槛。每个方向每个材质均须通过，且同材质的色度误差在四项中都应比共同均值与配错材质各低至少 15%。任何一项不满足就不把材质名称直接当作跨场景调色参数。另用相同参考前后图做零变化校验。两遍 CPU，无新素材、训练、阈值搜索或软件集成。保留所有重复对照。
