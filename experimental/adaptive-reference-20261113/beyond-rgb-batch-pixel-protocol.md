# 核对曝光筛选后的原片

冻结筛选结果 WHITE_green 与 BLUE_red 的灯号 1／8、Oppo、带色卡版本。只运行原片检查，不替换场景、不运行模型。沿用原片核对的画幅、机型、焦距、曝光差 ≤0.10 EV、24 个色卡中心最大偏移 ≤画面对角线 1%。每场景至少三个对应灰阶中央的归一化 RGB 距离达 0.015 且两端发布 RGB 上界像素比例均低于 1%。真实传感器原始裁切在三通道 HDF5 上保持未知。

另在固定相机 D65 矩阵下估计线性 sRGB 超出 [0,1] 的像素比例，沿用旧实验的公式和抽样，不作逐片白平衡。越界比例只与旧极端灯比较，用于给下一轮制定显示限制，不在本轮事后增加准入门槛。若几何、色卡、原片可读性不达标，保留原因及实拍，不冒充可直接用于调色分析。若可用，保留范围、色卡、标签哈希和拼图，用于后续预先固定成片比较。
