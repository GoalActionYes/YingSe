# 先按实测照度和色度筛选静物光照配对

冻结上一轮的两个静物场景 MIXED_organic 与 WHITE_rich。这轮唯一改变是用仪器记录选择灯光，不按图像或算法输出来挑。本批固定每场景按拍摄顺序取目录前缀 1–12，复用已核验读取。目录前缀和灯号各自独立，例如第 2 次拍摄使用灯号 12。灯号 10、11 在两场景缺失，因此在读取新增仪器数据前按拍摄顺序消除编号歧义。跨场景对齐时使用实际灯号。只取 CRI 文件所在 2 KiB 范围，24 项合计 48 KiB。核对 HTTP 206、字节边界、目录成员名、原始长度与 CRC32。若访问失败，保留成功片段，恢复时只补未取得的文件。无训练、调色或下载整库。

同一场景照度比不超过 1.15 且 CIE xy 欧氏距离至少 0.025 即通过筛选。若两个场景有相同灯光编号对，优先选两场景中较小的色度距离最大的一对，距离相同以编号先后决定。若无共同编号，各场景分别保留色度差最大一对。保留所有读数和合格配对，输出选中拍摄的 Oppo 相机带色卡原始成员、拍摄标签与色卡坐标定位。照度接近只在探头所测位置成立，尚需核实原片曝光、几何、实际颜色与高光。选中成员供下一阶段正式取图和出图，不能当作独立白墙或真人肤色验收。
