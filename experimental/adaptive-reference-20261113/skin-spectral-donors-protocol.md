# 新增独立人像测量能否补足肤色覆盖并改善成片

原 ISSA 校准在已知换光方向时能改善两位人像的肤色，但 253 的同一侧双向未通过。第八邻距离诊断显示该侧颜色覆盖不足，不能靠关闭修正规避。此轮唯一改动是加入独立人像光谱作为近邻候选。CQS 矩阵、八邻居算法、两个光源、曝光、80% 强度、软边和所有成片门槛沿用原实验。旧 253 和 282 不提供校准样本。

从 UMINHO-HSFD 的剩余参与者按光谱原件大小排序。最小的 226、222 为新供体，下一位 235 整人留出。合计原件约 249 MB，只取这三位和对应的作者遮盖预览。依据预览先登记左右脸颊各一个矩形。原四处测试矩形不动。每个供体矩形按原有规则重采样为 64×64，再从行列 4、12、20、28、36、44、52、60 固定取样。两位最多提供 256 个点。仅保留两光源共同色域内的有效样本，以档案编号和矩形顺序稳定排列。测试和供体的用途在读取任何成片前固定，不按结果增减供体或改变供体点位。

比较原 ISSA 校准与加入两位供体的校准，在 253、282 和新留出的 235 上分别生成 D65 → A、A → D65 独立成片对照。全部修正仅应用于人工登记脸颊，非肤色灰块与有色材料保持原矩阵。原门槛仍为核心覆盖 ≥95%，两个核心中位数 ≤1.50，90 分位 ≤3，且中位数不得较原校准增加超过 0.50，过渡带 90 分位不得较原校准升高超过 1，灰块最大误差 ≤1，非肤色与原矩阵逐像素相同。另报告第八邻原阈值下的覆盖变化及新供体被选中的比例。供体光谱用于学习已知换光的残差，不读取任一测试目标作为候选推理输入。

只有六组全部过关，才继续该固定供体补充方案的定位验证。若覆盖扩大但成片仍退化，保留反例，区分“邻居更近”和“变换更对”。新留出个体与两供体使用同一测量设备，结果仍属于已知光源的人像光谱开发验证，不代表一般人像、自动选区或两图调色通过。只生成局部纹理拼图，完整面部原片与衍生图保留在本机忽略目录。
