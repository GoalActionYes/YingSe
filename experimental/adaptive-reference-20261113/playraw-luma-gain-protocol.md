# 用目标原始亮度预测同方向调色的力度

已知《Cuckoo》的编辑器答案时，适度减弱固定色差可让两处肤色通过，但同一倍数使混合光原片两个留出折退化。检验显影输出亮度能否解释力度差异。只允许变化固定色差的倍数，原图亮度、颜色方向和空间范围继续固定。

用混合光原片的一个棋盘折的高权重像素，计算编辑器变化在原固定色差方向上的投影，再除以作者蒙版权重。以目标关态 RGB8 的亮度为自变量，拟合一个带截距的一元最小二乘直线。仅在训练亮度百分位 1–99 的范围内使用该直线，截到非负值，范围外沿用 1 倍。保留对折作为同照片回归。将两个拟合所得倍数均值应用于《Cuckoo》，参考的色差向量仍用上一轮定值。预测只使用关态图与既定位置，编辑器答案在出图后参与评分。两张图均已用于开发，该实验只测试已有颜色方向及范围下的力度预测。

《Cuckoo》两处至少各有 95% 像素处于两个拟合共同亮度范围，才有资格支持亮度解释。两轮均须达到投影 0.75–1.25、MAE 至多 3 RGB8、区外逐像素保持。原片留出折两项高权重指标继续过线，过渡区 MAE 增量至多 0.25 RGB8。若范围不足或任一门槛失败，结束这条仅用亮度估计恢复力度的固定方案。本轮复用落盘成片，无需重导 RAW 或训练模型。
