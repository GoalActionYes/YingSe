# GIER 局部调色标注能否组成跨场景开发对照

PSBench 两个中央对比度成片大面积触及 RGB 边界。GIER 的发布者提供真实修图前后图的索引以及局部操作标注。此次只读取公开任务索引，不读取原图、成片、掩膜或外部原帖。下载上限为 5,000,000 字节，事前已确认公开索引长度为 4,996,658 字节。

枚举所有任务和发布的操作结构。筛选条件预先固定为恰有一个操作，属于亮度、明度、曝光、对比度、饱和度、色相、色偏或黑白，并有明确的局部掩膜引用。按最初请求判断有无人物／肤色、中性色表面或背景区域和变化方向，人工复核仅基于文本线索。重复原图 URL 保守归为同组，来源组的其他重复关系保持未知。报告近似语义共性以及无法核实的字段，Git 只保存计数和索引哈希，不上传文本、URL 或原始标注。

进入出图的前置条件为至少两组能独立追溯摄影内容、区域和同一操作，且核实图像使用范围与可取样的前后状态。只有同名操作或文案相似时，保留作候选和失败记录，不扩大取样、不启动训练。
