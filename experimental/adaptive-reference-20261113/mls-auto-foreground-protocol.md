# 自动对应区域能否复现已知材质的前景旁证

原前景旁证依赖作者标注的蓝纸与绿纸。本轮冻结两图背景估计和同灯、换灯、暖／蓝物体色四类条件，只替换取得旁证区域的方法。在每张 256×208 分析图上使用原 16×16 网格。只考虑自动背景外、超过一半像素在 16–239、对数色度各通道标准差不超过 0.12 且均值距自动背景至少 0.20 的小块。四连通里相邻均值距离不超过 0.12 的块组成区域，大小至少两块。候选区域之间的匹配只用正交于背景色差的平均对数色度和对数面积，距离为正交差的绝对值加 0.1 倍对数面积差。取互为最近且距离不超过 0.25 的对应，背景点色度变化的同方向分量不参与对应选择。

对应区域沿用上轮支持门槛。至少两个不同区域通过才应用原自动输出，否则保留原图。作者掩膜在全部输出保存后才用于评分，并审计接受的两组实拍是否至少有两个不同的正确材质对应；每端至少一半像素需落入同一个已测材质。真实换灯误差仍须比 13 号至少降低 15%，保留原方向要求；两种背景物体色和未干预同灯均不超过 0.05。任何门槛失败不调网格、阈值、匹配权重或样本。两遍 CPU，无下载、模型或产品部署。
