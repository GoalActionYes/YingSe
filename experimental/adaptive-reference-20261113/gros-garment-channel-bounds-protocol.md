# 单个通道接近上下限时，衣物能否仍提供判断证据

上轮中黑衣暖灯和两项全图编辑缺少 256 个三通道都有效的衣物像素。检查可用通道能否形成保守结论。固定两侧衣物框、同一参考前后图、原脸部和白幕统计。只在衣物三通道支持不足的状态尝试新区间，既有合格衣物的步骤和门槛保持。

每个通道以 RGB8 的半码量化范围转换成线性 RGB。0–7 只提供上界，248–255 只提供下界；另一端视作未知。分别在衣物区域计算 log(R/G)、log(B/G) 的中位区间，端点用中间次序统计量，不能按通道是否到边丢弃整像素。前后区间作差，再减白幕差。每个框至少 256 个测量位置。输出两通道有限支持比例、区间和最小范数。只有整个区间都满足原范数和余弦门槛，才认作共同拍摄变化；只有整个区间的最大范数小于 0.10，才使用原全局／局部判定。无界时也必须验证极端方向，未满足仍沿用白幕分量。

沿用前轮六个目标、80% 和全部成片门槛，至少五个完整通过，正常冷灯逐像素保持。复核不确定的参考不会偷偷升级为可信判定。真实作者仍用上轮严格资格和位置，保持衣物区域污染的失败。保存所有实际成片、读数并复跑两遍；范围不足则停止在同一批裁切颜色上改阈值。区间成立也只支持已知同一衣物的编辑前后图，普通两图输入另行验证。
