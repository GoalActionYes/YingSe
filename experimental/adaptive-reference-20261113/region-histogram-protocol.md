# Frozen regional histogram inference diagnostic

Question: can existing current13 weights exploit separate automatic person/background color marginals without cropping target context? This is an inference-domain-shift probe, not training, Jianying recovery, semantic style understanding, or product integration. Prior CanonCGT crop/shared-normalization experiments failed; this differs in model, weighted histogram conditioning and preserved full-target context, and must not inherit their scores.

Use only the previously consumed independent-coco/development jobs: six target/reference pairs (two single-person, two multiple-person, two no-person), five existing profiles each, exactly 30 cases. Do not read evaluation jobs/assets. Existing original/licensing manifest and automatic DeepLabV3 MobileNetV3 probability caches must match their original provenance and dimensions. Record all input/cache hashes before predictions; no new download, segmentation execution or checkpoint updates. Freeze current13 epoch6 SHA d8d8e6727a44100e6fedb11b605a17e33afc675de7448d4ebcf6d24d492ad4c9. Cached segmentation was previously evaluated against human masks, so this is consumed development, not independent acceptance.

Baseline: SpatialEngine(multiref-v1).prepare(target,reference).apply(target,1), native prepared COCO dimensions, no stage8 aligned route, strength100, no manual controls. Isolates model inference; not a comparison against stable global LUT or whole product including certified-aligned routing.

Candidate: keep same complete target analysis256 and low64 context. Resize soft automatic person masks to256 with PIL float bilinear; background=1-person. For each region compute exact author's YCbCr128 bin coordinates, scatter probability weights and normalize each channel by regional support. Both target and reference must have mean person probability and mean background probability >=.02; otherwise return exact baseline. Require each native target/reference hard person mask (p>.5) to occupy >=.02 and <=.98, to avoid low-confidence dust falsely supplying a class. No mask threshold tuning. Predict one grid for each of the two regional histogram pairs using the unchanged model and lowpass. Render both complete target images as float; blend with native automatic target person probability, clamp/round once. No crop, black fill, fitted residual, anchor or original-identity special case. Regions with similar colors may remain ambiguous; person is not skin, background is not one material. No unsupported same-image identity promise.

Write all 30 baseline/candidate predictions and hashes before loading truth or human masks for scoring. Truth/human masks used only in subsequent scoring. Report full RGB MAE, person/background RGB MAE (null for absent class), foreground-minus-background mean RGB relation error, boundary RGB MAE (3px dilation of hard annotation transitions), endpoint fraction, mean absolute change from baseline, application/bypass counts, wall time incl both grids/render but excluding cached segmentation. Inspect all six complete 5-case comparison sheets, not score-selected examples. No natural-style preference, video, live UI or end-to-end speed acceptance.

Fixed decision gate before results: among the 8 person-present regional-profile cases, >=6 improve full RGB MAE by >.5 codes and their mean MAE improves >=10%; among the other22 negative/control cases, <=2 worsen by >.5; across all30, zero severe regression (>5 codes AND >25% baseline MAE). Also report regional relation/boundary errors rather than letting aggregate MAE hide local harm. Passing only justifies a separately designed wider/natural/video evaluation, never automatic integration. Failure stops this recipe, with no threshold/strength retrial on these cases. No claim that failure makes the objective impossible.

Unit tests: all-one histogram equals author-equivalent bin counts, weighted single-pixel mass, mask permutation invariance with jointly permuted pixels, missing/uncertain class bypass, exact blend endpoints, invalid/nonfinite probability rejection and no input mutation. Record source/checkpoint hashes before and after. Keep assets/weights/caches out of Git; publish only code, protocol, aggregate/numerical evidence and limitations.
