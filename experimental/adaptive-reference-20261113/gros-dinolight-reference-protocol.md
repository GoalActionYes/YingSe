# DINOLight 实拍照明校正能否改善两图调色

现有局部颜色估计会把混合光和调色一起迁移。DINOLight 的作者权重直接用同场彩色灯与环境光对照训练，单图推理使用多层 DINOv2 图块特征。这项监督与已结束的全局白平衡、人工眼周取样和分量拼接不同。先核验物理照明正对照，再检查预处理是否也消除了参考中有意保留的 Film B。

固定作者 Lighting-Restoration 提交 2d705f46cd887eaee702dbfee85c9ed926bc0af0 的 DINOLight CL3AN 权重，以及 Meta DINOv2 ViT-B/14 register 原版权重和提交 7764ea0f912e53c92e82eb78a2a1631e92725fc8。两个权重 HEAD 对应 38,351,150 和 346,393,545 字节。只允许两份源码与两份正式权重，下载预算 400 MB，不训练。外部实现不作为项目发行资产。先做严格张量检查，通过才渲染小批图。

以 CL3AN 已用场景 1、2 的第 1 张色灯和环境光照片做正对照。RGB 图长边 672，尺寸 672×448，按原比例 LANCZOS。DINOv2 与作者同样的 ImageNet 归一化，使用最后层归一化 token 与第 2、7 层未作末层 LayerNorm 的 token，分别 L2 归一后沿通道拼接。整张缩小图推理，不用作者的大图滑窗，不对模型置信度调参。正对照要求两个场景 RGB8 MAE 都下降至少 20%。即使未过也记录真人诊断，但不得认定模型适配成功。

真人固定 01 ← 02 使用冷／暖灯、Film B 开／关的四张参考，按同样尺寸缩放。对比直接用缩小参考与先运行 DINOLight 的参考，在同一个冻结 13 号权重、目标原尺度和 80% 强度上出图。两臂只差参考的单图照明恢复，预设标签、目标期望图和人工区域均不传入模型。用五区原门槛联合评价，关闭误差、换灯差和风格误差 ≤3 RGB8，投影 0.75–1.25。记录参考的原始和恢复后风格开关差，防止把风格削弱看作收益。通过两场正对照及全部五区才扩展其他人物，任一不通过则结束这套固定预处理。所有输入来自已用开发素材，未来独立验收集保持封存。

## 运行兼容修订

首次整张推理在任何画质结果落盘前失败。作者模型在第三级下采样后依然需要按 8 切块，672／8＝84 不可按 8 切分。保持 672×448 图像及所有预设门槛，每次推理改为作者使用的 448×448 方块，横向取首尾两块，224 像素重叠使用线性互补权重在浮点 RGB 中合成，最后统一量化。没有调整权重或读取结果再选分块。
