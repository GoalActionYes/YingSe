# 分别关闭作者局部工具，定位前景变暗

P1005231 的作者开态将天空压暗约 38 RGB8，也将石墙压暗约 3.86，未过保护门槛。已有单线程成片及关态登记区域。固定 RawTherapee 5.13、两张归档成片、原 RAW、原 PP3 和所有原参数。分别从作者开态只翻转 `Expcolor_0` 或 `Expreti_0`，用两个单工具状态与归档全开／全关构成四态。源码用于核对字段语义，实际成片用于归因。

每个新状态单线程导出两遍。要求逐像素一致、配置仅一字段改变、尺寸和 ICC 与归档一致。沿用原天空及前景门槛，额外要求保留作者主天空至少一半的压暗幅度才视为有效的作者操作子集。对各预登记区域报告开关效果和两工具的非加和部分。若无合格子集，停止修改这份作者设置并寻找另一独立内容；不调原滑块或重选区域。
