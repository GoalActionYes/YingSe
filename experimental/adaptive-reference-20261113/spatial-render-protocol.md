# 原尺寸局部网格渲染验证

模型仍固定第8轮，不训练、不调颜色参数。分析继续整幅256×256，参考／目标直方图规则与首次训练一致；生成作者16×16×8、13通道局部网格。原尺寸渲染以全图归一化坐标和RGB引导采样，分行块只限制GPU暂存，不改变空间坐标；不能把每块当独立图片重置坐标。

先验证分块浮点输出与同网格作者完整采样/着色公式的误差：预设最大绝对差2e-5（0–1）。256工作图另比较作者完整forward，确认分析/网格构建一致。8位输出允许量化边界出现1码值差，不称位级相同；保存实际最大差。测试0/0.5/1强度、原图不变和不同块高，不按观察结果改门槛。

然后测一张已使用照片扩到1920×1080及3840×2160的分析、原尺寸输出时间和GPU峰值，保存输出。该扩图是速度与接缝诊断，不是真4K细节或高分辨率画质验收。对照只证明网格渲染一致，不证明颜色本身正确、视频稳定、CUBE表达或整套App实时。目标图片已在输入层准备为RGB8 sRGB；本模块不自行猜测ICC或处理高位深。

局部网格不能完全表示为普通全局CUBE。保留稳定版，尚不接App、不宣称完整目标完成。后续必须单独检查视频运动、照明变化及真实交互。
