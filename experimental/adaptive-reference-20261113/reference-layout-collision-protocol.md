# 同颜色统计、不同参考位置的对照

用户在意的情况是，同样一份冷暖关系只出现在参考的一部分时，软件能否保留位置差异。13 号的空间网格使用目标缩图，参考端只有全图逐通道直方图。本轮只问参考空间布局能否改变输出。上一项校光改变的是颜色值，本轮锁定全部 RGB 像素的计数，仅改变位置。既有目标镜像平均试验改的是目标端。

用已有两处 MLS 标准灯实拍互作目标和供体。把供体缩成 128×256，左右拼成对称的 256×256 参考。分别在左边或右边使用同一已知 Film A 数字编辑。参考两张互为精确水平镜像，且原始 RGB 多重集完全相同。目标和 80% 强度固定。离线预期是在目标相应的半幅应用既有 Film A；该人工任务验证位置表达，不能作自然风格或人物语义验收。

预算四次 13 号推理、无训练、无新增素材。核对参考 RGB、多通道直方图、网格、成片和两个位置答案。只有两方向均出现参考统计、网格和成片逐值相同，才记为复现此输入限制。同时报告两个答案的差、两臂实际误差和共同输出的最坏 MAE 下界。只有下界大于本开发对照沿用的 3 RGB8 诊断线，才将该范围记为不能同时达到误差线。达成时停止在现有直方图接口上寻找位置信号；未达成时只记录预处理或覆盖差异，不调整尺寸或场景追分。区分精确构造的能力边界与自然两图输入。
