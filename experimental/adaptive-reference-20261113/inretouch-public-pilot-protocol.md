# INRetouch 已发布示例的两图调色小样

问题是现有 13 号能否在不同参考内容表达同款调色时，提高与作者提供目标调色的一致性，并让两个参考产生近似输出。局部编辑许可及分组仍按来源核查处理。本轮只使用作者公开仓库固定提交 `cbf0db19487222c21d63116c320357764438360d` 中多示例配置列出的两对参考和两个对应命名的目标前后图，限本机非商业课程研究，不读取授权限制内的 RTD 图像，生成／原始媒体不随 Git 发布。

下载固定八个 JPEG，预算 2 MiB，逐文件验证 Git blob 标识与大小。目标原图与作者调色结果须同尺寸，两对参考各自同尺寸。使用四种固定组合，当前 13 号原生尺寸、RGB8、80% 强度、无微调，GPU 计算及写盘预算 90 秒。预测仅使用目标原图和调色后的参考图。先冻结四份预测，再解码作者的目标效果和参考原图作离线核验。作者配置将两组参考一起用于同款优化，不能仅凭这一事实确认具体涉及人物保护或局部蒙版。

用产品的 80% RGB8 混合将作者目标效果拉到同一强度。对照原图，记录整图和目标原图近中性色的 RGB MAE，以及固定目标更换两个参考后的输出差异。若两种参考在两个目标上均好于原图，且换参考差异低于作者调色的变化幅度，则支持进一步核对该样本类型的可用性。否则保留结果用于定位迁移失败。仅两个内容组，不改变现有验收门槛，不作独立自然评价或新模型资格认定。
