# 同类区域的相对明暗能否帮助跨照片迁移

绝对亮度分段在两张人像上覆盖不足。已有 FACD 和作者曲线试验也不支持整图亮度排名。本轮增加同类区域身份，检查从供样脸颊或近中性色自身分出的暗、中、亮，能否比各自只用一个偏移更接近目标的同款编辑。两张 RawTherapee 人像沿用同款开关，各轮互作供样与目标。供样的两态可见，目标只提供原图。生成候选成片之后才读取目标期望图评分。

《Cuckoo》保留既有脸颊框，混合光照片在原图成人脸颊固定像素框 x=184–200、y=263–280，坐标为左闭右开。近中性色沿用原图的既有代理判据，排除脸颊框。供样两个状态均要求每通道在 8–247 内。预测臂各自只改这两个区域，共用 Rec.601 亮度锁定与色域回缩。固定臂在每个区域应用其供样像素色度差中位数。分段臂将同一批供样按区域内亮度经验中秩分三等频带，在各带秩中位数处锚定色度差中位数，以目标原图区内的经验中秩插值。每带不足 32 像素或中心不递增则回退固定偏移并记为不通过。保留区域的整图秩中位数、区域内三带实际亮度及色度差，帮助解释同一相对明暗的可比性。

最终评分使用整块脸颊与开关两态都满足近中性标准的区域，沿用至少 128 像素、期望色度信号至少 1 RGB8、投影 0.75–1.25 且响应误差不超过 3 RGB8。四项均须通过，且相对固定臂至少两项误差下降 10%，任何一项误差增幅不得超过 0.25 RGB8。检查区域外逐像素保持及最大亮度漂移 ≤0.5001 RGB8。预算四张成片和两张对照图，跑两遍，无训练。真实收益不足就结束这种区内排序方法。通过仅说明在已知区域位置和供样开关的条件下值得继续，没有自动定位或双图推理的成绩。
