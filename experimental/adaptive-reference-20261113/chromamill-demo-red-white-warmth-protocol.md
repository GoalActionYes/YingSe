# 核对作者演示中单独拍摄的红灯和白灯

CHROMA-MILL 完整发行的红灯入口超时，原项目此前只使用了白、蓝等灯档。作者演示的公开 Git 树提供 Test13、Test15、Test17 的 600 × 400 单档 PNG。脚本直接取每只灯每个整数档的底层素材。演示页面的颜色混合、亮度插值和画布截图均排除。这里验证另一色轴和完整档位能否产生与固定局部暖色接近的实拍变化。[作者的拍摄说明](https://github.com/priubrogent/chroma-mill/blob/62fe4a3a33cd50ff39d94d20111146e3bf4d2d88/index.html) · [底层图像读取与混合的位置](https://github.com/priubrogent/chroma-mill/blob/62fe4a3a33cd50ff39d94d20111146e3bf4d2d88/static/js/mixer.js#L98-L148)

固定 Git 提交 62fe4a3a33cd50ff39d94d20111146e3bf4d2d88。两个灯色、三个布景、每色 11 档，66 个发布文件共 14,770,698 字节。逐项验证 Git blob 哈希，读取内嵌 PNG 字节，不执行远端 JavaScript。仅用白灯 11 档的显影确定每场景一个浅色材料测区和远处保护区。不可识别浅色材料或无可保护的区域时记录，该布景不强行配对。三场和全部可用档位按原始场景归组，已阅后作开发材料。估计总用时 15–30 分钟，PNG 导出两遍共最多 8 分钟，素材和成片保留本机。原档案数据卡曾标 MIT，公开演示素材暂无独立再分发声明，此轮仅本机验证。

沿用发布的线性 RGB 和同一 sRGB 曲线，所有帧采用固定尺寸和准备路径。复用旧全图梯度注册和暖色输入准入。固定 RawTherapee 暖色 1600、2800、力度 30，对每档各出一开一关。保证共同有效覆盖至少 80%、两个颜色信号均至少 3 RGB8、方向余弦至少 0.90、幅度比 0.75–1.25，比较不同灯色的全部有序方向，并区分同档和跨档。记录无效或平局。首个符合的方向仍是演示尺寸的待核命中，进入工作台之前需要补查局部对应、相机和同场原图的出处。无命中则结束这套端点灯色的取样，不混灯或改强度追分。既有跨来源、产品、独立画质和视频要求继续适用。[既有暖色准入](shared-local-warmth-protocol.md)
