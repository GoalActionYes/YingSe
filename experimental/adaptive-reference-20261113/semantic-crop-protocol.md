# 学习式区域候选：开发试验前冻结

不再用区域均值／方差直接拟合颜色。使用现有CanonCGT E2E分别估计全图、人物裁切、背景裁切的颜色映射；人物概率来自官方DeepLabV3-MobileNetV3，不读取COCO人工蒙版。只作为独立研究候选，不接入默认入口。

人物区域取概率>0.6的包围框，外扩图像宽高的5%；可靠面积必须占原图至少3%。背景候选为固定3×3位置、宽高各60%及40%的窗口，优先较大窗口，再选平均人物概率最低且低于0.1者。两区域裁切均要求最短边48、亮度标准差至少8码值。源和参考任一区域不满足，整体回退全图模型；不生成空区域控制。40%窗口在首轮实现的几何单元检查阶段加入，以覆盖居中人物遮挡所有60%窗口的情况，尚未查看候选调色结果。

全图和两个裁切各调用一次同一冻结模型；裁切模型的两张LUT应用到完整目标RGB。自动人物概率经半径1.5的模糊作为区域权重，置信权重为clip((abs(p-0.5)-0.1)/0.4,0,1)。局部残差先按置信权重去除每通道均值，避免重复施加全图色偏，再限制±24码值，以固定0.5强度与全图融合。边缘不可靠时减弱残差。没有逐帧视频或空间CUBE导出。

先运行COCO新内容中的6对开发素材、五种控制，共30组，和主版／全图模型比较。记录全图、人物、背景及边缘误差，记录回退、裁切位置、耗时及残差强度；不能用已知真值选择模式。24对评估素材仍不运行，直到明确保留／修改候选及冻结理由。

若区域关系控制有收益但统一风格明显恶化，先找失败原因，不直接接入。若无收益或大幅恶化，保留失败并放弃本候选；不能改用最优输出拼成绩。此试验不是新模型训练，也不是自然审美偏好评估。
