# 在真实人物相互遮挡片段筛查固定视频候选

合成半幅遮挡已通过，但不能证明真实人物相互遮挡能够触发。用 SAM 2 作者仓库 `notebooks/videos/bedroom.mp4` 的原始 200 帧、960×540、30 fps 演示视频做一个新开发对照。从输入接触表固定活动区间，4–19 为进入遮挡前，40–103 为人物互相遮挡，120–135 为重新分开，160–175 为后续无互相遮挡的运动。它不是逐帧像素标注。固定右侧可见墙面两个矩形，坐标为原图 `(730,115,785,220)` 和 `(815,150,890,280)`，左上含右下不含。数据和派生成片仅留本机。[来源](https://github.com/facebookresearch/sam2/blob/2b90b9f5ceec907a1c18123530e92e794ad901a4/notebooks/videos/bedroom.mp4)

冻结 13 号模型、参考、80% 强度和独立导出环境。两遍均分别以普通模式和两基准候选实际 HTTP 导出。记录所有触发帧；将同帧编码前成片减原 RGB，得到各位置调色改变量，再测每个区间内相邻帧调色改变量的 MAE。只在同一对输入墙面平均 RGB 变化 ≤1 的相邻帧上评分。另从完整 MP4 解码计算对应读数，默认编码及帧数保持。需要在遮挡区间至少 32 对合格相邻帧，两块墙面都满足资格。

给定墙面两区的遮挡段最大改变量波动，普通模式最大值至少 1 才算观察到可改善的问题。候选须两区均至少降低 0.25 且相对降低至少 25%，无互相遮挡段不得触发额外暂缓，重新分开后的任一墙面最大波动不得增加 0.25。两轮结论须一致。普通模式不达信号门槛时记为无可判收益，实际触发与差值仍完整报告。仅验证一段自然素材，不能当作完整真实遮挡或开放调色验收。不根据本轮读数更新规则或窗格。
