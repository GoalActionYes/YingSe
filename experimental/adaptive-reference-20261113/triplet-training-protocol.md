# 直接三元组监督：首次训练对照

目的：判断直接目标监督能否改善已经测过的轻量局部双边网格模型，区别于继续猜测颜色对应。只作非商业课程学术实验，TST100K及Hist2Style许可均保留，不接正式产品、不发布研究权重或原始图片。

前置：固定cohort-v1的128训练、32验证，32保留只读元数据；下载完整manifest、原图哈希、模式／方向／配对尺寸和跨组精确像素重复检查通过。存在不支持色彩模式或方向、缺失文件、精确重复泄漏时先修分组／数据，不补零继续。ICC语义还需单独核实，不能把仅记录profile存在当成色彩空间验证。

首轮只微调作者Hist2Style固定公开检查点，网络结构、局部网格、颜色引导保持不变。它只用参考直方图，尚不包含参考的语义区域关系；不能因为验证改善就声称完成全部目标。以这一基线检验真实三元监督价值，再决定是否需要加入参考语义条件。未证明好处前，不叠加新模块。

拟固定配置：随机种子20261113，AdamW学习率3e-5，weight_decay1e-4，batch4，8个epoch。训练目标／GT及参考整幅统一256×256，不裁人物，不改颜色；图像像素L1加0.1倍水平／垂直一阶梯度L1。最多256次更新，保留每epoch权重和完整验证记录；以验证平均L1选checkpoint，不按案例选输出。具体执行前须将最终配置与脚本哈希冻结，偏离本草案的选择须明确记录。

先保存未微调模型在全部32验证图的原始输出、现有版对照和真值评分，再训练；验证用于开发选型，不称独立测试。训练拟合、验证效果与运行速度分别报告。固定候选只有在验证呈现实质且广泛改善、没有明显结构损失后，才使用保留32组作一次独立对照。PST16–50和TST2K保持不读取。训练损失下降、快速前向或简单案例通过均不是目标完成依据。
