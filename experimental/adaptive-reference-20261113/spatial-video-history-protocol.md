# 检查完整导出中切镜和局部遮挡后的颜色残留

复用既有 640×360 人物实拍、有声课程短片的画面和固定参考。将两段分别解码为 30 fps RGB，再用无损 RGB H.264 编码，不带音轨，读回核对逐像素一致。人物单片作为对照。硬切臂在同一人物片前接 30 帧课程片。遮挡臂只在人物第 24–35 帧（从 0 开始）将左侧一半盖上固定暗灰色，其余区域不动。这是有真实运动底片的受控遮挡，人工确定时间和位置。

三个输入均走 13 号普通 HTTP 导入、分析和视频导出，固定参考、80% 强度及时序设置。导出时保存指定编码前帧及平滑重置原因，再核对完整 MP4 的帧数和时间基。硬切的后五帧相对人物单片相同位置应满足既有 MAE 至多 1、P95 至多 3 的残差门槛，且边界应报告重置。遮挡期间对未遮侧的同坐标区域使用同一门槛，遮挡结束后检查首五帧全图。记录有无额外重置。比较的是同一目标运动内容在不同历史或遮挡下的模型偏差，干净单片仅是对照，不是专业作者真值。

两次分别导出三个输入，预先固定帧索引与统计，复核控制或反例。若遮挡影响未遮区域，先保留反例，再考虑区分全图网格变化和时间历史。本轮只筛查现有工作台，无训练或新的软件版本，不用于宣布自然度或新候选验收通过。

## 关闭平滑的归因补测

首遍观察到遮挡期间另一侧明显变化后，保留原三臂并另做实际 HTTP 导出。仅在验证所创建的工作台里关闭时序平滑，继续用原来的网格、参考、导出和同一遮挡。与同样关闭平滑的干净臂比较。若无遮区域仍逐帧超过旧的 1／3 门槛，则已有证据表明关闭平滑不足以消除变化。此时不把差异全部归于时间历史，也不从这项比较外推新的修复参数。切镜后与遮挡结束后得分从新对照输出复算。
