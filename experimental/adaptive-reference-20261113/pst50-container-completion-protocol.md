# 补齐 PST50 两个未核验的视频封装

固定发布中 39/41 条视频已有封装核查。仅补查 in42 的长 MOV 元数据及 in46 的 MXF 头，两条均属于保留编号。沿用原清单的文件大小与 Xet 身份。只允许 206 精确范围响应，每条预算 512 KiB。MOV 按盒头跳过媒体，只读取 `moov`。MXF 只读经识别的 Header Partition Pack 和该封装声明的 Header Metadata，检查 KLV 键及长度，遇到视频或音频负载即停止。无需下载整条、读取视频帧、查看图片或运行调色模型。

从 MOV 时间码描述与 MXF 源包名称核对已有标签。UMID 用于记录封装包身份，除非有可信的上游对应表，不能当作物理拍摄场景身份。若发现同一来源标识跨开发／保留，先保守归组；缺失标签、只有成片名或相比源库无法核对时继续保留，不据此放行。比较全部 41 条的核查覆盖，其他旧结果不重跑或重定门槛。
