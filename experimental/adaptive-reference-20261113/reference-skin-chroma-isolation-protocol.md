# 去掉参考非皮肤色度后，目标肤色能否减少串色并保留编辑

《Cuckoo》已知变化重放说明自动皮肤范围可承载修色，但尚未从普通参考预测变化。本轮只检验参考背景色度是否是可移除的干扰。在普通参考成片上用冻结肤色模型生成软权重，将非皮肤色度按权重压到同亮度灰色，再运行同一 13 号和 80% 强度。只把该支路色度按目标皮肤权重混回基线，明暗沿用基线，零权重像素逐值保持。任一图没有可靠皮肤时返回基线，同图返回原样。模型推理只读目标与参考，效果和人工 ROI 只参与评分。

复用原四套开发检查及各自门槛，16 张背景实拍、42 张 FACD、12 张 Film B、2 张色卡。沿用已登记直接皮肤框，另报告其 C1／F1 色度差，但沿用原四套联合结论。无新训练，只增加一次 13 号分析与渲染给被定位器放行的照片。若任一套出现已有门槛之外的弱迁移或明显退化，不接入产品。若候选无法同时改善人物偏色并保留有意风格，结束固定灰化背景的方向。两遍执行，独立复核同图、无皮肤回退、非皮肤像素保持与冻结基线身份。
