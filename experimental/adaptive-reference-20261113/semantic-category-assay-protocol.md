# 局部对应是否保留人物类别：固定缓存诊断

问题：已经失败的DINO局部颜色修正方案，其余弦×10 softmax对应，是否至少比均匀参考更能把人物对应到人物、背景对应到背景？之前熵与颜色空间变化检查不能回答这一点。

仅用既有regional-correction-inputs-v1的自动人物概率与semantic-token-inputs-v1的1365项缓存，固定原1024训练／64开发行；无下载、神经推理、训练、GT或独立素材。自动标签不是语义真值、更不是肤色真值，本轮只测两个自动机制之间的类别一致性。

概率图按原DINO工作图对齐：Pillow浮点BILINEAR由256缩至252，再14×14平均得到18×18，最后按原adaptive average pooling至8×8。参考标签与查询标签均不进入对应计算，只用于离线测量。对应保持原单位特征、余弦×10和softmax，不调温度、top-k或类别门控。

沿用原输入准备的支持条件：两图soft_person_fraction和hard_person_fraction均在[.02,.98]。全部1088行保留；主要描述有支持行，其他行只作完整记录，不把新阈值用于选例。

定义：m_i=sum_j W_ij p_ref,j。人物一致性=sum_i p_content,i m_i / sum_i p_content,i；背景一致性=sum_i (1-p_content,i)(1-m_i) / sum_i(1-p_content,i)。两者平均为平衡一致性。均匀对应在两类都非空时恰为0.5，因此不受参考人物占比单独抬分。保存两项、平衡值、相对0.5增量、top1的同口径描述和全部支持度。零类质量则记null，不强造数值。

事前解释规则：训练和开发的支持行均值相对0.5增量≥0.1，且各自至少75%行增量>0，才支持“该固定对应具有可用的粗类别选择信号”；否则不得再把它当作已验证语义对应。该规则只作研究必要信号检查，不是画质或人物分割准确率门槛。即使满足也不重启旧修正头，仍缺本色／光照／风格辨识证据。

预算CPU最多120秒、约500MB内存；缓存逐文件核验，原记录顺序／身份必须一致。独立NumPy重建softmax、池化与统计核对，误差≤1e-6；固定首四个有支持开发行生成类别质量图，展示查询人物概率、匹配参考人物概率和参考人物概率，不能当调色前后图或人类评价。
