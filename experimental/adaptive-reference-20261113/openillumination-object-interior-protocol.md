# 固定主体外像素，检验主体受光是否随参考风格传到目标

## 问题与事前判断

纸球从蛋形物体取参考时，完整换灯使目标球内部相差 49.86 RGB8，换回入镜灯芯后仍差 39.12 RGB8。灯周、背景、物体受光都可能参与。若把参考主体内区混入另一档受光就使目标明显变化，准确找出主体仍不足以区分现场光和创作风格。

三组实拍沿用同机位 001、013。四个条件分别是原 001、在 001 内区换入 013、在 013 内区换回 001、原 013。使用已冻结的主体内区做离线交换。距内区边界 4 像素内按距离过渡，四像素及更深完全采用另一档实拍值，内区以外逐像素不变。对每个参考条件先后使用同一 Film B 的关态与开态，两个控制仍为冻结成片。产品推理仅访问目标和当前一张参考。目标主体评分区及实际预期仅用于离线测量。预算为每遍新增 24 张目标成片、12 张参考、6 张对照和 3 张权重示意，无训练与新素材。

## 决策门槛

沿用整图和目标主体原门槛。换灯差、关态与原片偏差、风格响应误差均须不超过 3 RGB8，风格投影须在 0.75 至 1.25。报告开关两态、整图和主体、全部正反方向。只交换内区后任一开态主体差大于 3 即记录为该方向上足以产生可测偏差。六方向中至少四方向的开态主体有符号贡献达到完整换灯变化的 0.5，才记为本组主体内区主导。沿用前轮四条件平均归因，交互项单列，保留偏移的原始方向和绝对差。

如果以内区换回原照明仍无法达到原门槛，结束把主体分离或统一扣除主体受光当作单独修复的路线。如果达到原门槛，先核对归因与素材边界，再判断正常双图推理能否获得这一信息。拼接边缘、保留的物体轮廓带和背景溢光限制解释范围。只使用已用开发数据，不能以这次诊断决定发布。
