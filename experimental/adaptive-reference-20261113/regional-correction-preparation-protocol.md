# 区域条件修正：输入准备与数据可用性核查

在参考色度传播定位之后冻结。准备一个新的匹配训练候选所需输入，不训练、选模型或读取开发 GT。它不重复已失败的「把区域直方图直接输入整图训练模型」配方。

拟定候选保持当前13号主干冻结，以新训练的小头预测人物／背景两组有界 RGB 仿射残差，按自动目标人物概率融合。控制头使用同维数、同结构、同目标概率及训练预算，但输入中的区域颜色描述用全图描述替代；隔离区域颜色信息是否有帮助。残差头必须零输出初始化，关闭时严格恢复基线。详细训练配置、损失与完整门槛在准备结果核验后、训练之前另行冻结，不凭缓存生成宣布候选有效。

本阶段只使用当前 `petal-condition-features-v1/results.json` 的输入注册表及行角色映射，它来自 `cohort-multiref-v1` 的 train1024／validation64 的 content/reference。仅复用来源注册，不读取PETAL特征或GT特征；逐项核对像素、父文件及行索引，禁止新增独立评估图。

采用已存在的 DeepLabV3 MobileNetV3 人物分割权重 fc3c493d68e89cc31ef488c803d5d7dd2f3190fb570598faa49fef69be8e5e70。运行前检查本地文件存在及哈希，禁止自动下载。以统一RGB256为输入，沿用既有 PersonSegmenter 的预处理，模型 eval、不更新权重。关闭 CUDA matmul 和 cuDNN TF32；模型状态前后摘要一致。记录全部概率图、耗时与来源哈希。人物概率不是肤色、材质或光照真值，不读取人工蒙版生成特征。

固定每张输入的特征：原作者 YCbCr128 边缘箱定义下的全图／人物概率加权／背景概率加权直方图（各384维），另加人物软占比和硬占比。每通道按区域权重和归一化；区域零支持输出全零并显式记录，不伪造均匀直方图。空间概率图单独保存，供目标区域融合。全部缓存仅来自产品推理时可见RGB。

数据核查按 split 和配对统计：目标／参考同时满足软人物与背景均≥0.02，且两张硬人物占比均在[0.02,0.98]的配对比例；只统计不挑选最优阈值，不删除失败输入。该条件沿用历史区域直方图配方的可靠支持定义，不证明分割正确。无可靠人物区域的配对暂计划精确回退，不根据GT选是否应用。完整训练与开发组均保留，不把支持充足子集成绩冒充全体。

额外记录训练／开发相同RGB像素的交集及目标与参考角色，不将已有开发集称新留出。核查现有真实风格配对是否足以提供全局监督；对局部操作监督尚无证据时，不擅自把背景颜色变化标为完全应忽略的噪声。只有数据可用性、输入隔离及零初始化桥接成立后，才允许运行另行冻结的匹配训练。

测试须覆盖单像素概率加权、全一权重退化为全图、零支持显式表示、无输入修改、非法概率拒绝和描述器形状。文件审计核对所有父文件／概率／描述器哈希、概率范围与归一化、行映射及权重状态一致性，抽样重新执行固定首尾输入推理，不按结果挑样。代码、协议、数值摘要上传，图片、概率图、描述器数组、模型与运行环境留本机。
