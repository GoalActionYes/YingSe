# 现有13号受控风格响应验收

2026-11-14，第7阶段浏览器验收完成后冻结。只测当前已接入模型及旧全局流程，不训练、不挑模型、不调参数。目标是核查软件是否正确响应参考的色彩、明暗和饱和度变化，以及视频逐帧处理是否抵消或放大这些变化。

## 图片

固定读取 `reserved-multiref-v1/results.json` 清单原顺序的前6张输入，逐项核对既有SHA。输入为先前已消费的256×256公开研究图，不称独立新测试。使用已有 `reference_feature_assay.OPERATIONS` 的11种固定变换，生成66个同内容参考，参考本身就是受控目标真值。覆盖恒等、冷暖、饱和度、对比度、亮暗及暗亮部分的相反冷暖。

通过 `SpatialStore.analyze/render` 执行真实产品图片策略，保留其恒等分支；不能用裸模型恒等误差冒充产品缺陷。旧全局流程使用当前 `pipeline.analyze/apply_mapping`，保留其同图／对齐拟合策略。统一满强度、无手动微调。保存每例全部输出、RGB MAE、已测试的参考响应指标、明暗分层误差、梯度误差、端点裁切比例、耗时及每个文件哈希。全局流程与13号各自的特殊策略明确记录，不删除使某方法有利的例子。

每张输入生成一张全操作对照表；先查看全部，不只选择好例。这里的同内容参考比任意自然参考容易，尤其有利于现有全局对齐拟合；不得把均值解释为整个产品或全部自然调色的排名。

## 视频

固定已有公开3秒人物运动片，按产品导出策略重采样30fps、640×360。以首帧构造暖色、冷色、低饱和3种参考，期望输出为对每个输入帧应用对应的同一已知变换。使用实际 `grade_video_frame` 及当前 `TemporalGrid(relative_cut=True)`。旧全局从首帧分析一次后固定映射。记录全部帧误差、模型／渲染耗时、相对受控真值的时间差分误差、裁切比例与重置原因。输出全部对照短片用于目视检查；该诊断片无音轨，音轨保留已有产品导出验收单独证明。

这里将统一全局操作作为无需局部变化的负例，不据此认定真实视频应消除光照变化。不包含自然切镜、遮挡真值或语义区域真值。固定设置，失败也完成并报告，不通过改阈值、挑例或另训模型追求通过。

## 交付与后续

交付完整公开数值摘要和本机对照图／片，不上传素材、模型或会话。结果只用于界定现有版的适用范围、定位具体问题，并与已有自然32图结果一起判断；不把完成诊断称为完成调色效果目标。必要的产品修复须有可复现问题与回归验证，不能在本检查中临时加入新算法。
