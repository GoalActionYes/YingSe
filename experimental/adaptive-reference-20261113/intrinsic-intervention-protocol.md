# 光照先验：背景物体色干扰与整图色偏响应

固定问题：Marigold IID Lighting给出的人物区域光照色度，能否相对不受参考背景物体换色干扰，同时响应已知整图色偏？这是约定的辅助信号必要条件，不是恢复唯一真实光照或完整调色验收。

保持首例全部权重、代码和配置：FP16、DDIM4步、ensemble1、768、batch1、seed20261117。先用首例9483输入桥接三层raw数组逐值一致，再复用背景干预v2六参考×12变体，共73次推理，无下载、训练、调参数或产品修改。模型仅读RGB，人工人物标注只在推理后离线测量，包含衣物而非肤色真值。

主要测量区域固定为参考identity人工人物区域中三个RGB通道均在[32,223]的像素。它只由原始输入选取，避开黑白端点，不随候选结果、方向或变体变化；少于32像素记不支持并不通过，不删例。全人物与全图结果作为次要描述；无人例只报告全图，不计入人物通过率。

光照S是线性RGB、整体尺度未知。采用(log(max(R,1e-4)/max(G,1e-4)), log(max(B,1e-4)/max(G,1e-4)))，抵消共享标量尺度。先逐像素计算再对区域求均值，记录S相对identity的向量变化、范数、floor比例；albedo A同口径变化作为描述，不用于挑选预测。已知输入色偏向量为变体与identity sRGB分段转线性后，区域平均log色度差。该干预在gamma RGB中构造，不冒充物理光源真值。

运行前固定必要条件：

1. 首例桥接和每参考identity/repeat的三层原始float逐值一致；失败即停止执行判断。
2. 四个人物参考、两个颜色方向均须有整图响应：S变化与已知输入色偏向量余弦≥0.5，变化范数≥已知色偏范数的25%。零分母不通过。
3. 同一参考、同一方向，背景100%干预的S变化范数≤对应整图变化的50%。
4. 主要区域identity及该方向整图／满背景S通道被floor比例均≤1%；否则相关检查记不可靠、不通过。

全部八个方向都满足才支持下一步参考调色信息使用实验。中间覆盖率、对比度、去饱和、全人物与无人例全量保留；不按有利分区重解释失败。它与DeepWB的校正映射指标不同，不能把两者数值直接当统一准确率排名。

预算：现有单GPU，执行总600秒、单次60秒；输出约180MB，本机保存全三层数组。不关闭用户应用，OOM／非有限结果停。独立离线审计重读输入／73数组、区域、log统计与八方向判定，不重跑GPU。失败不改ε、区域界限、强度、步数或seed追加搜索；成功也不接产品，仍须设计真实参考迁移并过原完整门槛。
