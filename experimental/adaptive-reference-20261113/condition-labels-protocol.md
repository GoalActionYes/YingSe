# 训练集条件监督生成

前提：64开发配对的已知GT拟合表明接口存在可达改善；固定输入缓存64图桥接已完成，画面精确一致、梯度按rtol1e-5/atol1e-8数值验证。缓存不保证逐位相同优化轨迹。

本次仅生成cohort-multiref-v1的train1024行（256目标×4风格），不读取开发GT、开发拟合参数或新保留素材。目标/参考/GT仅从训练行加载，逐项核验原prepared文件哈希、cohort及manifest关联。

保持epoch6主干冻结eval；每批4条件向量零初始化，Adam lr0.03，128步，整体梯度裁剪1，分量限制±3。损失RGB L1+0.1横纵梯度L1。批内裁剪耦合明确保留。0及每16步按单图缓存计算RGB8 MAE，以训练GT选最佳，含零步。学习率、边界、步数及样本顺序不搜索。

每例保存baseline与GT-fit PNG、9个条件参数/误差快照、所选条件及步数；每批保存进度。初始缓存画面/网格须与原B4路径相同，单图缓存零参数须与原B1输出相同，主干状态前后相同。缓存固定输入与原主干在本次计算期间不可修改。

这是使用训练GT构造监督标签，并非正常推理效果，不是已训练好的通用预测器。输出不能用于产品画质演示。全部1024行必须完成并审计后才能作为下一项学习输入，开发64行不能混入。后续预测器对照另行冻结，不能因标签拟合分数高就接入产品。图片、条件缓存和权重不上传Git。
