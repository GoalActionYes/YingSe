# 已知实测光色监督能否改善两图风格迁移

上一轮四场景拟合改变了常规参考的明暗和色度。新增的能力是作者基于实测照明训练的 CTI-Retinexformer，可独立输出 CIE xy 估计及白平衡／曝光校正图。本轮用作者明确公开的本地自有图像测试方式，固定提交 `bf607cec57739932ad2800501b1aa1601bfe4fe5`，只取 11,106 字节模型源码和 6,780,177 字节手机权重，按 Git blob 哈希验证。作者 README 说明可在自有图像上运行，未核实再分发权利；仅本机研究运行，不随 Git 保存原代码和权重。使用本机现有 einops wheel 与 Torch，无新安装，权重只用安全的张量加载。

沿用 CHROMA-MILL Scene1_a／Scene2_a 现有全部 16 张参考输入（每场两灯色两强度与 Film A 开关），及已有三种普通实拍各原图与 Film B 共六张负例。作者手机模型训练覆盖 CHROMA-MILL 训练分区，现有场景只能算开发测试。输入最长边沿用 512，按作者方式转线性 RGB，补齐到四的倍数，输出裁回原尺寸。每张保存作者校正输出、估计的平均白点与灯强。比较作者原输出及仅用其色度、保留原参考亮度的对照，各用 13 号 80% 新生成 16 张目标成片。另一分支没有新模型或权重。用真实灯色检查估计到已知白／蓝点的最近类别，并比较同一拍摄状态开关 Film A 是否改变类别。真实标签及目标真值不参与推理。

沿用上轮风格门槛（整图与近中性色投影 0.75–1.25、响应 MAE ≤3）、八项近中性色换灯差减半且 ≤3、白灯目标相对 13 号退化 ≤2 及六张普通参考预处理变化 ≤1.5 RGB8。两臂都报告门槛，另记录近中性色中的色度误差及最坏退化。只有一个组合通过全部门槛，才有依据继续验证其他拍摄组和风格。作者估计准确也不能代替成片成绩；任何结果都不改变现有软件。预算每遍 22 次 CTI 推理及 32 次 13 号出图，复跑哈希，未使用产品独立保留集。
