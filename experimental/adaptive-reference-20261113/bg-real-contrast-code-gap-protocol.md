# 对比度编辑留下的码值空档能否跨导出保留

五种两图成片的明暗与色度组合无法补足两组有意对比度。这里检查与画面内容统计不同的一条线索：对已经离散为 RGB8 的图提高对比度后，通道直方图可能出现被跳过的码值。先验证线索能否在常见的 JPEG 编码或缩放后保留，并且不会把 DAST 的实际换曝光当作编辑。若只在当前程序的无损输出存在，停止利用该线索。

同一 12 组 BG-REAL 用于确定阈值，四组开发对照用于检查。使用现有四种编辑及两种背景，无编辑、冷调与暖调均作为对比度负例。对 RGB 各通道计数，在码值 8–247 内找空档。候选号两侧相邻码值均须至少占图像像素数的 0.05%。各通道以空档数除以候选号数，候选号为零时记零，取三通道平均。阈值只取 12 组无损负例的最高分，严格大于该值才识别为有意对比度。算法只读一张参考 RGB，不读取本图未编辑原图、目标答案或操作身份。测试条件固定为无损、JPEG 95、JPEG 85、0.8 倍双线性缩放后 JPEG 95。JPEG 用 Pillow 的 4:2:0。每种条件均在解码后计算。

任一发布型处理条件下，须至少识别八个对比度参考中的六个，同时 24 项其他编辑最多误判两项。DAST 30 张实拍输入是额外曝光负例，四种处理条件下各自最多误判三张。另记录 PSBench 516、530 原作者照片未编辑与编辑后 JPEG 的得分，作为真实重度对比度的描述性对照，不参与阈值或正式通过。若未同时满足所有条件，则不把该量化信号送入模型。通过才可进入同一轮 32 张两图成片比较，原联合门槛仍有效。
