# 参考镜像：运行前协议

问题：同款参考换照片会让目标人物和近中性色跟着偏。测试扩展版会不会因为参考左右布局变化，把整图风格解释成不同颜色。只研究当前开发成片，不改产品。

固定扩展第 4 轮、80% 及四套冻结开发输入。保持原始目标和参考统计不变；唯一干预是把送入参考外观分支的图左右镜像。保留原向与镜像分支的成片差，再对两份 RGB8 成片逐通道取均值，作为固定的镜像对称对照。因为测试的是整图风格，左右翻转未改风格定义。这里不是目标镜像后翻回，也不替换参考颜色或取消外观分支。相同输入像素走原有同图保护。最多每份输出两次前向、四套 72 份输出，不训练、不下载。人工区域和作者成片只用于评分。

运行原四套开发门槛，另记逐图镜像差及对冻结扩展版的差；各套分别保留原失败与改善。若未同时通过四套，就不接入、不扫权重；若通过，再查局部作者编辑与其它负例，因为左右位置可能具有实际调色语义。
