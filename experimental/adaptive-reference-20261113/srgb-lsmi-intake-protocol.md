# sRGB 混合光校准素材准入核查

白球服开发案例中，固定扣除背景色度会加重人物偏色。需要与背景换物体负例配套的实拍正例，检验算法是否仍能迁移有效的空间色彩变化。本轮只问 sRGB-LSMI 能否提供可追溯且能小批读取的场景对，用于判断局部白平衡的作用，分开记录它能否覆盖真正的肤色或作者风格。

从作者数据页和官方源码读取公开文本、发布索引和存档响应头。不提交表单、不登录、不下载媒体、不运行作者代码。文本与头总预算 1 MiB。仅在确认许可、源场景键、实际 sRGB 输入和目标配对规则、文件体积或可按成员提取以后，才考虑另立协议取样。论文只有构建说明或链接无法给出上述证据时，记录具体缺口，停止这一来源的取样。与 FAU 同机位杯子区分，此来源用不同实景、相机和近似亮度匹配的校正目标；不将白平衡目标当作局部艺术风格真值。
