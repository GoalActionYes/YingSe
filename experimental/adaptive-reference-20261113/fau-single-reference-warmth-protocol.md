# 用真实改灯颜色压力测试单张参考的暖色读数

此前给定编辑位置后，估计同一表面的色度坡度让两组实际成片通过。继续自动定位之前，冻结做法，换成未用于拟合方案的 FAU 布景。这里用真实两盏灯中的一盏从白换红、另一盏保持蓝，检验算法会不会把现场照明变化当成有意暖色。固定 `lion` 与 `bmug` 的 `w_b`、`r_b` 四种拍摄加开关状态。原始公开预览没有逐档曝光、白平衡或亮斑真值，只将这个比较当作真实混光的开发压力。取件已经在本机，无下载、无训练。

在仅查看各自 `w_b-off` 的几何之后，冻结 452×260 图中看起来连贯的表面。坐标按原像素。

- `lion` 的木板上表面两部分。左边 (95,134)、(105,124)、(151,119)、(157,127)、(147,146)、(145,155)、(128,159)、(112,154)、(104,147)。右边 (289,118)、(359,118)、(388,126)、(395,137)、(387,146)、(353,151)、(312,155)、(297,147)。两块纹理支持是同一可见木板的假设，中间被遮挡。保留原先已经登记的编辑核心和实际暖色范围。
- `bmug` 的外侧浅色杯底环，避开印字、杯底边缘与深色带。取 (216,224)、(246,225)、(275,223)、(303,217)、(322,209)、(321,224)、(315,236)、(300,244)、(272,252)、(248,255)、(218,249)。曲面局部反光属于保留的真实扰动。

各组用固定 PP3 和既有灰片校准入口显影，保存 128、192 灰和既定浅暖片的诊断。各场景在同一固定掩膜估计，不根据另三张图更改位置。常数、平面与原模板均冻结。保留每四像素格点、RGB 4–251、弱强模板各至少 24 点、残余模板 RMS ≥0.10 的门槛。单图按匿名编号处理，目标读入上一轮已固定的 MIT 客厅与 Beyond RGB 白绿场及对应目标权重。两个 FAU 参考场景分别重放到两个目标，无选择性减弱或调阈值。另报告木板各可见块和杯带各自的强、弱支持。主输出锁定后，在四图共有的有效格点拟合实际两灯间变化和同灯的两个编辑响应。保留关态真实换灯的模板色度偏移及它在两个编辑向量上的带符号投影。一次有意义的混光压力至少应在任一组、任一档编辑方向上有一项绝对投影达到同期编辑的 50%。该线只判断测试压力，成片各项门槛沿用原值。

沿用之前的 80% 强度与核心投影 75%–125%、各误差 ≤3 RGB8、保护区和全图新增端点 ≤2%。归档彩灯关态的实际输出相对目标原图的差，报告关态漏偏、实际换灯差和有意暖色响应。有任一状态因几何不足就保留缺测。全部主输出和哈希锁定后才按角色读取目标开态。另用同档两个 FAU 参考开关估色，固定 L* 变化为 0，作为与单图臂通道相同的离线重放控制。配对控制的关态为原图恒等，单独保留单图臂的实测关态结果。

只有四个参考与目标组合全部可计分、都通过且达到事前混光压力线，才考虑投入自动定位。若联合失败且配对参考控制过线，结束把静态色度坡度直接当暖色开关的方案，可保留它作为局部编辑量估计的候选特征。若采样资格失败，记录支持样本缺口，缺测表示这张图无法按冻结条件计分。预计准备和核验 30–45 分钟，实际机器阶段两遍总上限 5 分钟。
