# 同机位补光比值的留格诊断

用户可见问题是换参考背景会带偏目标的肤色和白色。一次受控实验只检查材质影响能否借助额外同机位补光观测减轻。双光源场景中，如果补光差分能部分抵消表面颜色，无补光 RGB 除以补光增量之后，两个光源的混合色度应更接近一条线。相机光谱与表面反射的耦合、阴影、环境反弹和饱和都可能破坏这个关系。

固定使用 Hui 等公开示例 `two_lights` 目录按名字排序的前两项 `book`、`conference_room`，为两个不同室内场景。只下载两个 MAT 文件，总量约 33 MB。按作者接口，`im_nf` 为环境光，`im_f` 为环境光加补光。作者有效蒙版仅用于离线测量。以作者线性 RGB 预处理文件为输入，不解码或生成产品成片。

两种表示在共同像素比较。无补光全通道在 [0.01, 0.98]，加补光全通道在 [0.01, 0.98]，各通道原始差分至少 0.02。比较无补光 RGB 与 `im_nf / (im_f - im_nf)`；两者各自除以三通道和。用固定隔四采样和 4×4 矩形整格留出，以其余格拟合最小平方正交距离直线，测量留出像素到直线的欧氏色度距离。

每场合格像素至少占全部隔四采样的 10%，至少八格各有 100 个有效像素。两场均须达到中位距离下降至少 25% 且绝对下降 0.005，90 分位至多增加 0.005。先用含两盏已知灯光及三通道随机材质的可分离合成样本验证计算，差分比值的距离 90 分位应低于 1e-10。所有留出有效像素均计入距离。任何场景不满足门槛即结束固定通道相除的该项验证；达到门槛也仅支持继续诊断，需要独立的光源颜色标签才能验证真实光色估计。
