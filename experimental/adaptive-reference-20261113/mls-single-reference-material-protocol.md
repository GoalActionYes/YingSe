# 单张参考在已知材质时能否区分换灯与换场景

沿用 MLS 02↔03 两个方向、蓝纸和绿纸、已通过资格的编码输入。每次输出只用目标原图和一张另一场景的参考。材质对应仍由作者离线提供，参考原图和目标换灯图不参与当前出图。比较另一场景同灯、另一场景加蓝灯两种参考条件。每张输入在每种材质的有效像素内分别计算平均 log(R/G) 和 log(B/G)，参考减目标作为变化并用原逐像素亮度和 80% 强度重放。同一对输入上的对照使用两个材质色差均值，同样只给两个范围变色。各材质有效像素至少 256，统一沿用原 RGB 通道有效区。

在所有输出保存后按旧门槛评分。两个方向的两个材质均须满足同时保留有效换灯响应、同灯相对原图色度变化不超过 0.05，并且换灯误差相对共同均值至少改善 15%。同一照片与区域须恒等。任一失败则不以这个单参考色度相减直接驱动软件，不调门槛或扩大样本追分。用两遍本机 CPU；无下载、训练、自动材质识别或产品接入。
