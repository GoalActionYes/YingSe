# 训练条件标签的初始化稳定性诊断

目的：检验已知标准图拟合得到的128维条件是否存在实际近似多解，避免把训练条件MSE误当成最终画质。仅取原训练清单前32行，保持原顺序和每批4行；开发集不参与。该范围不是随机代表性抽样，不用于泛化结论。

三组初值：零、固定NumPy种子20261128的32×128标准正态乘0.5、该扰动的负值。原模型冻结，图像256、128次Adam、lr0.03、梯度裁剪1、条件±3、RGB L1加0.1梯度L1与原标签生成相同。每16步保存参数和得分，各组独立按自身GT RGB MAE选最好快照；不得按与零组相似程度挑结果。

零组32张基线/选中输出与已有训练标签逐PNG哈希一致，选中参数逐元素一致，否则停止，保留失败，不改容差继续。保存全部初值、9次参数快照、初始/零基线/最好图。检查冻结权重、来源及输入哈希。

预先记录两个不同诊断：A近输出多解：相对零组，参数RMS距离≥0.25且最好输出的RGB MAE距离≤1，且对GT误差不比零组多1以上；B近目标值不同解：参数RMS距离≥0.25且对GT误差差的绝对值≤0.25，但不要求输出相同。分别按两种扰动报告全部计数；A任一扰动至少8/32才支持此小样本上具有实际多解证据，B不能替代A。不达门槛不反称唯一解，也不调初值幅度、步数或阈值。

这是依赖GT的训练标签诊断，不是可部署推理、独立画质验收或数学唯一性证明。不更新主干，不修改产品，不把多解直接解释为此前预测失败的唯一原因。
