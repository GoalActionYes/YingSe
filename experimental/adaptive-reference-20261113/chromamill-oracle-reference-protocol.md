# 校正外推及理想参考还原能否解释留出失败

上一轮固定连续回归在 Scene3_a 尼康白灯参考上产生 4 倍蓝增益和 48.52% 裁切。冻结原折分和权重求解，展开回归的等价训练标签系数，记录符号、训练目标区间、限幅前通道值并核对原输出增益。若超出训练标签的通道区间，即有外推。此项用于归因，不调整模型、门槛或增益。

另给冻结渲染器准确的参考身份。实拍绿灯参考更换为同机位白灯实拍，白灯与有意染色保持原图，分别从正常渲染入口复跑。理想身份、实际白灯图仅用于离线确定这一对照输入。只有两个实际来源能够完美区分时才可达到这套参考校正，不能冒充产品能力。冻结同一组六个条件、80% 强度、整图和灰阶门槛。最多重放 18 张结果；同时保存原回归与理想校正成片对照。若准确校正仍普遍失败，结束仅从参考前处理寻找该问题的主要解决方案，后续需直接改进目标侧风格响应。若理想对照普遍通过，再考虑安全获取更多参考证据。
