# 弱响应来自蒙版未覆盖，还是编辑力度不足

冻结同一 ARW、darktable 3.8.1、作者 XMP、上一轮关态和四个登记框。本轮只改变 RGB 色彩平衡步骤的混合蒙版。通过 TIFF 附加页导出作者真实蒙版；另把同一步的混合模式由参数蒙版设为均匀全量作用，保留 100% 不透明度、色相参数及其它 XMP 字段。两个对照均用原先的 ASCII 路径、长边 1024、sRGB8、CPU 双线程及隔离配置，重复导出。只比较与原登记位置对齐的输出。TIFF 图像页与原 PNG 开态的平均绝对差须不超过 0.1 RGB8。附加页须核对名称、尺寸、位深及三个通道一致性。未知结构、错误页或无法复现则不推断蒙版覆盖。

胸口蒙版权重中位数小于 0.10 且全量作用色度变化中位数至少 2 RGB8，支持原蒙版限制响应。若全量作用也低于 2，原轮的弱响应不能只归给蒙版。继续用登记区域和既有色度计算，报告胸口、脸颊、树皮、草地及整图蒙版中位数、权重至少 0.5 的比例和开关变化。另用既有环境保护阈值 1.5 检查全量作用的环境代价。不同输出文件的元数据差异单独记录，核对像素和主要判定。数据、编辑参数和蒙版仅用于离线归因，无软件升级及独立验收。
