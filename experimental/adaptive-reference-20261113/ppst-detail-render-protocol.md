# 把生成结果的颜色变化应用到目标原片能否保住细节

PPST 首次出图保住了整图风格幅度，双颊、白幕以及结构仍未过线。若失败主要来自生成结果改变原图细节，用原片引导的空间变化可保住细节且减轻偏色。若基础颜色偏移仍在，则保留细节只能解开其中一部分问题。固定 01 ← 02 已用开发方向的四份 PPST 成片与一份同图重建，保持已施加的 80% 强度，复用既有准确参考风格和原评分。

唯一变项是最终图像的合成方法。原 PPST 成片作为基线；直接按作者备用路径的数值，引导滤波成片作为对照；候选改为对 PPST 成片减去原片的 RGB 差值做相同滤波，再加回原片。不重新生成 PPST，不从额外参考或目标答案估计色彩。两种引导使用目标的 RGB8 值，半径 30，epsilon 为 (0.02×255)²，边界与舍入均固定。记录裁切比例，并核对零差时逐像素恒等。全部实际成片保留。

沿用整图和两颊两白幕门槛。同图重建还须 RGB8 MAE ≤3、结构相关至少 0.95。整组五个颜色范围和同图结构门槛须同时通过才考虑扩展。只改善结构时分开记录，停止以此作为独立画质修复。两遍 CPU 每遍 ≤60 秒，不安装新依赖，不接入产品。
