# 从单张参考估计受支持的编辑，直接作用于目标原色

目标 13 号工作基底导致正确染色仍偏离预期。当前研究候选从正常参考 RGB 估计全局线性编辑，在目标原图上应用。对 CHROMA-MILL 绿灯和白灯标零编辑，匹配数字染色标离线已知编辑增益，真实成因只用于训练。复用冻结外观和全图特征。不同于上一轮线性外推，估计为训练标签的非负归一加权，增益受训练范围约束。只用训练折计算标准差、跨场景最近距离的中位数作为核宽度，以及其最大值作为支持边界。参考超界则回到零编辑。每张推理仅见目标和单个参考，同图精确保持。固定强度 0.8，不换特征或重训模型。

三个 CHROMA-MILL 家族整组留出，两台相机一起，复用冻结目标和各方真值。另用全部三个家族拟合后，测试原有两个 Beyond RGB 参考场景、四个固定目标的跨数据来源迁移。两处合计 30 张输出。记录整图、五块灰阶以及所有回退。整图须同时满足：白参考输出相对原图 ≤1.5 RGB8，实拍换灯相对白参考 ≤3 RGB8，数字编辑投影 0.75–1.25、响应误差及最终成片误差均 ≤3 RGB8。本轮入下一步的门槛为 CHROMA-MILL ≥4／6 且每机 ≥2／3、Beyond RGB ≥3／4。此前目标、基线、相机文件均固定。若不通过，停止以相同数据和特征改变权重、带宽或阈值。仅为有限的全局编辑研究，不替代已有手动、预览、导出、空间或最终独立画质要求。
