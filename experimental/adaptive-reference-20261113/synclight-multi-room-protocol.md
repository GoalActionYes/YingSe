# 用更多房间验证受光监督是否能迁移

上一轮从一间房训练后，在另一间房把整类强区或弱区判断错。此轮唯一学习改动是扩大监督房间数，沿用六个亮度、色度与平滑特征、岭回归和原阈值。按发布包大小排序，排除已有 scene35 与 scene25，从含至少四份 RAW 的 real/train 中固定前四个归档。只取视角 1 的环境光 0 和可见灯 1。若缺成员或不是 DNG，则按固定规则排除而不替换。源许可沿用固定发布 CC BY 4.0，TAR 元数据最多 1 MiB、原片最多 160 MiB，无新模型或解码器。

复用同机位亮度梯度门槛、白平衡与解码。对每个训练场景按单灯比例第五百分位向上取整环境光倍数，固定把至少约 5% 像素置于弱受光区，再以原曝光规则渲染。仅当强弱区各至少 5% 且配准合格时用于训练，至少三个房间才继续。场景比例只用于离线训练素材构造。留出 scene35 与 scene25，两组原 RGB 和原真值均不参与拟合，保持各自原环境光系数 11；这两组已用于开发，不能称最终独立评估。

沿用前轮固定判据：每个留出场景强弱平衡正确率至少 0.75，超过暖色排序至少 0.05，比例 MAE 比训练集常数至少低 15%。独立复算训练分组与留出成绩。两场都满足才进入参考响应和调色出图验证，失败则结束这一固定特征组合。预处理两遍、训练验证各两遍，每遍 120 秒预算。
