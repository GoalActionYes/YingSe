# 固定修正场辅助监督对照

动机：原预测头收益不足，而旧训练64图的GT辅助拟合存在明显可达空间。下一假设是直接图像损失未能充分传递可表达的修正场信号。该假设不能由oracle成绩直接证明。

原1024训练配对全量生成固定GT辅助8基区域拟合系数，方法与affine-fit-diagnostic-protocol完全相同（0.1幅度、±0.99潜在目标、ridge1e-5）。不生成开发拟合标签，不读取独立图像。所有标签明确是GT辅助训练监督，绝不进入开发或产品推理。

两臂都使用原RegionalCorrection结构、真实区域1154描述及原主干浮点输出、自动目标概率；同seed20261127、同初始化、同grouped_batches，8轮2048更新、AdamW lr1e-4/wd1e-4、batch4、梯度裁剪1。控制使用原RGB L1加0.1梯度损失；候选额外增加0.1倍潜在修正场smooth_l1(beta=1)。场为8基X乘拟合24系数；头的三仿射分支按真实p混合后、tanh之前的场与之比较。只监督实际像素场，不对冗余36参数逐项MSE。辅助目标截断与拟合误差全部保留。

推理只使用原head，不需要教师、GT或标签；候选不增加推理参数或步骤。开发全部预测先保存后读取GT；选轮仍按64图RGB均值，包含零轮，平局选早。先验证潜在场与原修正函数等价、辅助loss零点及梯度，关闭辅助损失不改变前向。

控制第0轮和两臂初始化应完全相同；控制完整训练应与原regional训练相同，若数值差异先记录和调查，不用差异伪称方法收益。全部1024原始缓存的像素／概率／描述器／源码哈希须核对，教师系数有限、幅度有效；训练／开发前向没有GT参数。

完整门槛不变：相对当前版RGB均值改善≥5%、≥40/64改善>0.1、明显退化≤2；新增参考32均值不退步、≥17改善。相对匹配控制RGB均值改善≥3%、≥36/64改善、明显退化≤2；32组delta均值改善≥5%、≥20组改善>0.1。明显退化为增加>5且>25%。失败不调整辅助权重、beta或拟合ridge，不改seed追分；通过后仍须独立画质、人类评价、视频与完整性能验证。

本轮是同一修复形式的第二个有新监督依据的假设；若仍无足够收益，停止围绕该残差头追加监督，整理路线选择材料。代码与数值公开，媒体、教师系数及权重留本机，不接稳定版。
