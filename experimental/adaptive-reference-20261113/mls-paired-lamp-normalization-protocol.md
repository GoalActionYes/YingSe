# 已知原片配对时，全局校光能否解除参考换灯干扰

沿用两处 MLS 实拍、Film A 和上一轮的两个方向，冻结标准灯臂和所有评分门槛。用同一参考场景的两张未调色照片估计固定全局增益。共同有效像素的六个 RGB8 通道都在 [16,239]，在 sRGB 解码后的值上取逐通道标准灯／蓝灯比例的中位数，再乘回蓝灯原片。报告输入补偿后的限域比例和误差。校光后的参考分别以原色和同一 Film A 出图。先校拍摄光，再施加数字风格，以免同一个增益改掉风格定义。

标准灯原有四张基线保持，新增四张目标图。目标灯及 80% 强度不变。已知原片只用于离线标定。用复用标准灯输出与校光蓝灯输出比较同款换灯差，并按既有整图／近中性色投影、MAE 和 3 码值换灯门槛评价。无新训练、下载、产品接入或独立评价。全局校光即使降低两灯差，也须保住有效风格才满足该受控任务。
