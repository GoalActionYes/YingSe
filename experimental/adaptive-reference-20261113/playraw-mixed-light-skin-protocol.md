# 核验混合光人像的作者局部调色开关

目标是取得一份有作者操作、明确蒙版和准确调色方向的实拍开发监督。固定使用 Joris Mak 发布的混合光原片和 Carlos 在第 2 楼发布的 darktable 4.0.1 设置。作者说明用 RGB 色彩平衡处理脸和手，另用蒙版改曝光。仅关闭当前生效的 RGB 色彩平衡历史第 28 项，曝光和其它步骤保持。此前的同实例历史保留，验证最终配置仅更改一字节。

- 使用官方 4.0.1 Windows 发布包和既有命令路径，隔离配置，CPU 双线程，长边 1024，导出 sRGB8 TIFF。开态另导出真实蒙版。只测导出的最后生效调色蒙版，权重 ≥80% 为重点，权重为零作保护对照。两处各至少 128 像素，重点色度差中位数 ≥2 RGB8 且保护区色度差 P95 ≤1.5，才纳入下一轮开发监督。色度为去除同像素 Rec.709 亮度后的 R、B 平均绝对变化。
- 两次独立开关导出。逐项核对画幅、蒙版、有效位置和主要数值。若工具不能导出原样设置或测量不够，保留具体失败，不使用默认直出替代关态。单一公开照片仅限本机非商业开发，不纳入独立验收。
