# 同款显影能否按原像素颜色迁移

普通单参考在跨场景时会把环境颜色和编辑方向混在一起。本轮先给出已知开关，检验另一项必要能力：从其他照片学到的同款色彩平衡能否作用到一张未见目标，重现脸颊、浅色材料和近中性色的合理变化。

使用上一轮已核验的四组开关成片。每次整组留出一个原始场景。其余三组各等权贡献 8192 个按像素索引等距抽取的训练样本。训练标签是在既有 80% 强度下的色度变化。固定整图色度平移为对照，实验只调整每个像素预测的色度向量。用暗、中、亮三个线性亮度分量和原色度的一阶交互项做岭回归，正则系数固定为样本数的千分之一。两组共享原图亮度和色域处理，关态直接使用原图。单次 CPU 预算两分钟，无需训练神经网络。

沿用每区至少 128 像素、开关色度变化均值至少 1 RGB8 的资格条件，以及投影 0.75–1.25、色度响应平均绝对误差不超过 3 RGB8 的门槛。要求两张人像的整图和所有有资格的已登记区域过门槛，至少一张天空的整图有资格且过门槛。还要求所有有资格区域中相对固定平移的响应误差增幅不超过 0.25 RGB8。若未过门槛，保留全部区域结果并结束本次像素模型。近中性色代理使用目标和关开真值共同判断，只在离线评分时生成。亮度保留为实验约束，本轮不评价亮度风格和真实换灯，也不作为独立验收。
