# 用同代 darktable 复核《Cuckoo》的作者蒙版开关

上一轮 5.4.1 能导出默认 ARW，但加载完整 2022 年作者 XMP 时崩溃。该 XMP 的 `colorbalancergb` 参数是第 4 版，darktable 3.8.1 同期发布，固定源码模块版本也是 4。本轮只更换隔离的重放运行时，保留已核验的原片和逐字节开关。用官方 Windows x64 包，118,978,495 字节，按官方 SHA256 校验。使用已有 7-Zip 解包，不跑安装器。只取这一个运行时，新建配置与缓存，使用 ASCII 路径、CPU 双线程、禁用 OpenCL 和用户配置影响，尝试 sRGB8 PNG，长边 1024。先导出原样作者设置，成功再处理关闭态及重复导出。失败时只补无侧车对照并记录能力边界。

源 XMP 保留原样。若两态成功，先只看关态登记胸口、脸颊、浅灰树皮和草地内框，重复导出后核对像素与色彩配置。沿用上轮胸口色度变化至少 2、环境两处各不超过 1.5 的开发门槛，脸颊仅记录。通过则成为单图局部编辑对照，仍需独立内容才可做跨场景迁移。若皮肤变化不足或环境超限，则保留为失败对照。无法出图时不以默认成片或模拟编辑代替作者开关。所有样片、侧车、日志和运行时留在本机。
