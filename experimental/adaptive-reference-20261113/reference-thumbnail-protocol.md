# 导出 JPEG 的缩略图是否保留调色前像素

原 XMP 审计无法可靠区分发布风格。EXIF IFD1 小预览是不同的信息源，如果仍保留调色前像素，有机会为跨场景参考提供同文件的前后信息。固定复用八个 FACD 原片和滤镜组、四个 PSBench 前后对，共 40 张 JPEG。记录每份文件的 IFD1 JPEG 是否存在、是否解码、尺寸和合格状态，不公开内嵌图、原 EXIF 或个人信息。

缩略图只读取标准 JPEG 偏移与长度，检查边界。用 Pillow 解码并调整方向，有嵌入 ICC 时转换到 sRGB。无 ICC 以 sRGB 解释。三张图的长宽比差异须在 5% 内，缩略图短边至少 48 像素，按缩略图尺寸比较 RGB8。发布前后图差至少 6，缩略图匹配前图的误差最多 6，且相比匹配成片至少好 3，才归为确有未调色预览。匹配成片使用对称条件，剩余标作无法判断。目标场景和其他图像不进入本轮。

合成控制覆盖无预览、明确旧预览和明确当前预览。真实文件要求至少两个原始来源组各有合格编辑预览，才进入另一期真实迁移比较。没有达到则结束本来源，不为保留此路径伪造真实 EXIF 或直接出图。两遍 CPU，每遍 60 秒，无下载。此轮只验证输入是否真实存在。
