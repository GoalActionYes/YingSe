# 实拍暖光的局部编辑浮点导出验证

上一轮两组暖灯脸部的蓝通道已在 8 位编辑器导出时变为零。先核查相同操作在浮点线性 Rec.709／Rec.2020 中能否保留通道变化。如果第 2 包暖灯的关态无法还原原 RGB8，或先前蓝通道变零的脸部像素在两种浮点输出都无有意义的通道差异，停止验证并保留旧失败。

- 继续绑定上一轮的六份原始输入 TIFF、作者两个仅差启用位的 XMP、darktable 4.0.1 及同人共用羽化区域。不调整色彩平衡参数。复用本机 OpenCV 解码 EXR，验证浮点数、尺寸和色度坐标约定。关闭态按标准 sRGB 关系量化回 RGB8，须逐像素与原图相同。短试仅取第 2 包暖灯一对，不决定门槛。
- 有浮点空间时，预定主比较使用线性 Rec.709 两态编辑差，只替换编辑差从编辑器到 8 位成片的色域处理。先依原羽化范围把编辑差施于输入线性值，再压缩高饱和色。保住线性 Rec.709 亮度和相对中性轴的颜色方向。色度超过同亮度同方向可用范围的 80% 时才进入连续曲线，渐近 99% 的可用色度。不统一调低强度。已经超出可表示亮度、关态改变或有非有限值时该控制不合格。
- 对照保留上轮实际 8 位结果与浮点差直接截断的结果。沿用双颊色度中位至少 2 RGB8、白幕与范围外原样以及新端点不超过整图 2%。另要求双颊相对旧 SDR 编辑差投影 0.75–1.25，用于避免仅靠降幅通过。比较两种导出同样过线的冷光区域，记录端点与开态误差。至少两组冷暖联合过线才运行既有 1.3 和 13 号对照，其光照、肤色与白幕门槛照原协议。
- 实验限既有 CPU 环境，无获取新资产、模型训练、产品修改。预检约 5–10 分钟，若通过，预计浮点成片、重放和既有推理合计 20–35 分钟。保留所有失败。完整重复，仅作开发诊断。
