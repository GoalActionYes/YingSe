# 同款参考开发组的近中性色空间信号

问题是固定的 24 组已有结果能否支持下一代两图候选学习局部调色。上一轮两种直方图训练的作者结果是整图监督。本试验每组比较两份作者结果的 RGB 差。在同一目标中，相同源 RGB 的像素若需要不同变化，则仅依赖 RGB 的统一查表存在可计算误差。进一步检查这种差异是否集中在可定位的画面区域。只读已有开发文件，不训练、不推理、不接触独立素材。CPU 预算 180 秒。

先核对本机 RGB8 副本哈希和尺寸。在 256×256 缩图上检查两份作者结果相对原图的亮度梯度，大于等于 0.90、最大整数相关在零位且四块的偏移提升小于等于 0.01，沿用既有 INRetouch 结构门槛。全部案例保留数值，只有两份结果都满足门槛才进入计数。该检查不能排除亚像素偏移或全部几何差异。

只量化目标近中性色代理区域。对同一 RGB，用逐通道中位数求两份作者效果差的 L1 下界。比较全图共享 RGB 表、允许四象限分别查表、同一源 RGB 内固定随机打散象限后分别查表。打散保持每个颜色键在各象限的样本计数，以控制容量。在原尺寸原像素和双线性 256 缩图上重复。原尺寸计数要求全局误差至少 2 码值，真实象限相对全局和打散都改善至少 0.25 码值且至少 5%。达到至少 6 个目标家族才支持为下一候选继续核验区域监督。没有人工局部标注，不能把任一信号直接说成作者有意保护肤色或墙面。
