# 自动脸部范围能否限制肤色修正外溢

使用已登记的 BG-REAL 四张普通原图、九个测量框。比较旧语义肤色权重与增加人脸框约束的同一权重。使用本机已有的 OpenCV 正面人脸级联，按灰度输入、倍率 1.1、至少 5 邻框、最小 16×16，框外权重置零。两个方法均只读取原图。测量框仅用于评分。脸部范围方案只验证脸部，手背和手臂覆盖单列，保留投影幕脸作为不应触发的对照。

每个直接脸部测量框需至少 80% 像素权重高于 0.5。白球服、浅墙、雪地与投影幕各框至多 1% 像素权重高于 0.05。必须全部通过才考虑接入下一项候选诊断。从原图用两个掩膜分别混入相同的固定小幅 RGB 偏移 `[-8,0,+12]` 并出图，只用来显示外溢和未覆盖部位，不计为光谱换光或自然质量结果。沿用原标注、固定模型和既有环境，不调阈值。失败时保留逐框证据，不凭平均数接入。
