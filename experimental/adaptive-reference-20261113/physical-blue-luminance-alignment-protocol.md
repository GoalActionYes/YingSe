# 给定正确亮度后，实拍换灯预测还剩多少色偏

上一轮跨灯强的空间变换在四个方向都未达标，RGB8 误差混合了亮度和色度。固定上一轮所有成片。对每像素在线性 RGB 中用同一非负倍率把预测亮度对齐到实拍蓝灯亮度，保持限域前的 RGB 比。采用 Rec.709 线性亮度权重作为现有显示 RGB 的测量约定。沿用上一轮的有效像素和整图评分。实拍目标的亮度参与构造，仅用于离线诊断。固定数字增益的成片执行相同流程作控制。

保留实拍 MAE ≤ 3、P95 ≤ 8 及数字 MAE ≤ 1、P95 ≤ 3 的原门槛。若空间臂四个实拍方向均达标，则先追查跨灯强亮度误差；若仍有方向未达标，记录未达标方向及限域行为。对于有裁切的像素，另报未裁切区误差，只作为归因证据。两遍各 16 张出图及一次从落盘图复算。预算不含训练或新素材。
