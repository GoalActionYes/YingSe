# 换背景与同一编辑交叉监督的同预算探测

目的在于检验交叉监督是否提供 learnable 的编辑方向信息。固定 12 组 BG-REAL 拟合素材，每组以 C1、F1 两个背景分别合成四个编辑条件。无编辑、冷调、暖调和对比度增加。每个参考的目标来自不同演员：按拟合 ID 数值字符串排序，使用下一个 ID 的 C1 作目标，首尾相接。已登记的四组 BG-REAL 开发目标及其两背景参考整组留出。合成前均将 RGB8 映射至 [18,237]，冷色用旧 `COOL` 向量，暖色为反向，对比度为绕 127.5 的 1.16 倍。目标效果由同样操作按 80% 混合。无人工蒙版进入训练特征或预测。

两个臂都使用 96 项、同一特征和岭回归。输入特征为 RGB、Rec.709 Y′、B−R 的 10／30／50／70／90 分位，拼接参考统计及参考减目标统计。训练行特征独立求均值和标准差，常量尺度取 1，拟合双参数（有符号冷暖幅度、对比度幅度），标准化后岭罚系数 1，截距不惩罚。对照臂仅用每个参考 C1 四个编辑版本各重复一次，交叉臂 C1、F1 各出现一次。推理幅度固定限至冷暖 [-1,1]、对比度 [0,1]，两臂按同一公式与 80% 强度渲染。

在四份冻结开发目标分别用两个背景、四个操作预测。每组要求同款换背景人物及人物近中性色 MAE ≤1.50；覆盖至少 256 像素的区域才计分。三种有意编辑相对无编辑的整图响应投影须在 [0.75,1.25] 且误差 ≤3.0。交叉臂应有至少三组联合通过、优于对照，任何一张输出整图误差不得较对照增加超过 2.0。另报告全部输出与合成答案的误差。不扩模型或素材搜结果。通过才有依据扩大训练，数据均为既有开发或训练来源。已知编辑只用于监督和测量，不是自然人像、视频或产品验收。
