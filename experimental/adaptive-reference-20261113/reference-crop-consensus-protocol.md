# 参考轻微裁边时，平均成片能否保留有效风格

扩展第 4 块存在白墙受背景物体色牵引和两个不由内部越界造成的严重退化。检验减少参考边缘局部内容的影响是否改善画质，以及轻微取景变化的输出敏感度是否能暴露已知退化。旧参考直方图加权没有改输入取景。INRetouch 的裁切检查动的是目标坐标，并需要参考原图。本轮只对正常参考成片作小幅取景变动。

固定扩展第 4 块、目标、分析和输出尺寸。对已准备的 256×256 参考先算原出图，再分别取 232×232 的四个角和正中央，左上角坐标固定为 (0,0)、(24,0)、(0,24)、(24,24)、(12,12)。每张裁片按现有双线性预处理回到 256×256。候选将原图出图权重固定为 0.5，五个裁片各 0.1，在 RGB8 端点上平均后按最近偶数取整。匹配控制用同样原输出权重 0.5，另一半来源为未裁边、只先缩到 232 再升回 256 的参考输出。记录各裁片输出相对原出图的整图绝对 RGB 差。作者图、蒙版、预期标签都不用于生成。风险部分只描述已知两例严重退化在 64 张裁边敏感度中的排名，不据排序生成新选择器。

固定六组旧背景干预的 42 张及原 64 张已用开发配对。背景方向沿用原 80% 混合与完整门槛。64 张须先逐像素复现冻结端点，候选整图均值须优于扩展版及缩放控制，并通过两套原开发门槛。所有预测保存后才评估。裁边可剔除有意义的局部风格，不能仅以更稳定为质量依据。记录严重退化与白球服表现。若失败，停止取景平均，不改裁片位置、占比或强度。两遍各≤120秒，不训练、下载、使用新素材或改软件。
