# 已知白色背景能否减少单参考的中性色串色

固定 MLS 02↔03 的标准灯、最弱蓝灯及四张已核对 RGB 输入。蓝纸与绿纸先前结果只覆盖有色物体。本轮新问题是作者标注为 background_white 的同一材质能否在正常两张图下给出可用的中性色调色线索。用整张已标注白背景有效像素估计参考减目标的平均对数色度，沿用 80% 亮度保持渲染，只改变目标白背景。当前推理只读取两幅 RGB 和离线提供的两张白背景掩膜。另一个目标的换灯结果用于另一对输入；每次出图不访问该目标自己的换灯照片。

固定同灯换场景、换灯换场景两个条件，并与本机冻结 13 号对应成片逐区域对比。评价整个白背景及白背景内目标原有近中性色，沿用有效像素、配准、投影和强度门槛。合格范围均须同灯变化不超过 0.05、换灯通过，且换灯相对 13 号误差下降至少 15%；要求两个场景至少有整块白背景可评，否则只作描述。已有形状和材质仍不能作为自动结果。两遍 CPU，保留所有失败及覆盖不足，不更改区域或门槛。
