# 参考肤色在取分类第一名时是否丢失有效信息

同人物换背景，两组目标肤色偏差曾在借原参考选区后减轻。灰度输入让部分权重差缩小，却有真实皮肤漏检和成片退化。现有 SelfieMulticlass 分别输出身体和脸部皮肤分数，代码相加后又要求单类第一名属于皮肤。检验这一额外判断是否丢失有助于调色的信息。固定彩色参考、原目标肤色权重、亮度、13 号及 80% 强度，仅移除参考端单类第一名限制，原置信度曲线、最小覆盖要求、平滑和无肤色回退仍采用原值。它不增加屏幕识别能力，屏幕脸作为退化检查。

对四组 × 两背景 × 两编辑状态出 16 张图，独立重复。先逐值重建原选区。另在四张原目标上，用固定九区域报告分类首选和身体、脸部皮肤置信度，说明手背与投影幕的输出差别。区域不参与预测。保持同图和纯色无人回退。旧彩色定位支路为对照，核心六项须至少五项达到 25% 与 0.25 RGB8 同时改善，其余登记区域不得退化超过 0.25 RGB8。达到门槛才扩展开发集，否则关闭此更改。禁止调阈值；如原权重差仍在，区分它来自模型分数还是后处理。
