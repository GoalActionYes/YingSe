# 复用预训练调色特征的参数识别对照

前面的分割语义特征、小型像素编码器和视觉模型直接建议均未形成候选。本轮检验一个不同假设：用于识别物体的特征不一定适合估计调色风格，已有 CanonCGT 风格编码器是否比冻结分割特征更有效？不能把换用预训练模型本身当成效果收益。

复用已核对的 CanonCGT E2E 固定权重，只取其 Embedding_Net 内的 MobileNetV2 特征图与原投影头。全图、自动人物、自动其他区域分别池化同一特征图，再经原投影和归一化，得到三个 64 维向量。区域池化是本实验新行为，并非作者方法或与作者区域算法等同。全图向量必须与作者原始嵌入数值一致；所有网络冻结，仅拟合原 StyleRegressor 回归头。真值蒙版仍仅用于合成与损失，不进入特征接口。

沿用已有 240 训练／30 验证／30 保留图片、固定训练和验证种子、六参数尺度、两个头与相同数据流、1800步参数监督、学习率和一致性权重；只改变深层特征来源。配套纯统计头同时重跑，不把早期已有数字拼成不同时流的对照。预先门槛沿用参数MSE降低至少20%；参数结果与150例画面组合诊断分别报告，不互相替代。两种特征头容量不同，不能把任何差异归因到纯粹的语义作用。

参数检查点只按固定验证MSE选取；随后在原150例画面组合控制上检查整图、人物／背景关系、同风格误调和严重退化。记录全部结果，仍不读取最后30张图。只有既定效果门槛成立，才考虑自然图和未见素材；暂不接入产品、不宣称视频或实时性成立。
