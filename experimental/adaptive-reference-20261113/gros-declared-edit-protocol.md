# 已知调色意图时，能否在成片保留暖调并避免串色

上一轮中，同人脸颈色差识别了局部合成暖调，却误判了冷灯与有意全局暖调。这一轮检验含额外输入的可用上限：用户提供同一参考的编辑前后两图，并指定处理范围。检验这项信息是否足以在无手工区域输入下同时减轻参考换灯串色和保留编辑。只比较这一条附加输入流程整体的成片有效性；不能把结果归因于单个内部部件。保留原 13 号普通两图成片与上一轮已知衣物证据作对照。

固定三个真人开发内容的六个跨人物方向，原成片强度、目标、四态参考和评分不变。额外信息来自已有对照的设定：冷灯是空操作，实拍暖灯指定保留目标光色，数字暖调指定整图，合成只暖脸指定人脸。仅评估这四种明确选择，不把它们当作程序自行识别的类别。用于估计编辑的供样前后图为已知同原片的合成两态，真实换灯不估计或施加偏移。整图估计有效像素对的线性对数色比差中位数。人脸使用现有 OpenCV 自带 frontalface_default，检测需恰好一张脸，且脸框估计有足够有效像素；从固定比例估计双眼，再重用既有平滑权重生成。只用原片定位。沿用原样本有效范围、人脸取两个眼点中间的权重至少 0.9 部分，最少 384 个成对像素。无人或多脸时拒绝人脸模式并回退 13 号。目标作者答案、人工双眼与区域只用于评分，输入新流程的函数不读取这些结果。

保留原冻结的分区风格投影、误差／串色、局部区外与原图保持门槛。六个方向至少五个联合通过，无人以及多脸拒绝要实际检查、恒等像素必须严格一致。保留每个输出和失败，运行两遍，不改人脸框比例或阈值追分。若通过，可用真实作者不同内容检查这种交互是否有用，普通两图、真实作者局部、白墙和视频仍需原有门槛。若失败，保留明确选择这项信息能解释的收益，结束此固定定位与重放组合。只使用已有本机依赖与素材，不打开保留集。
