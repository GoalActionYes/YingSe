# 检查局部肤色色偏是否需要随现有明暗变化

上轮锁明暗在六范围外逐像素保持，脸部仅 1／5 色度过线。本轮固定同一脸部和浅墙、同一旧成片、软边、16 像素交错块。拟合用原锚点与现有成片的色度差。唯一比较项是每范围使用一个固定色度偏移，还是允许在现有明暗的三个等频带估计不同色度偏移，再按各带亮度中位数连续插值。两臂都用中位数估计、同一亮度约束与越界回缩。每带至少 64 拟合点，亮度中位数须严格递增，否则以固定色度退回并留档。拟合及评分均离线，软件没有锚点或自动定位。

整图范围外逐像素保留，最大亮度漂移 ≤0.5001 RGB8；留出区域色度误差须至少降低 15%、并 ≤1.5。继续要求脸部不少于 4／5 且浅墙合格，另外按明暗的臂须相对固定偏移至少改善三个脸部 ≥10%，才认为目标明暗这一输入支持改进。记录全部亮度带、每张的拟合采样量、暗部及亮部误差、是否进行色域回缩。预算每臂六张成片，无训练和独立验证。即使通过也只说明该区域颜色模型有潜力，不能理解为普通两图可以预测这些偏移。
