# 暖色训练损失的方向核验

已停止的两臂在它们见过的原片上改善了底色和换灯差，仍漏掉有意加暖。要决定是否有依据设计新的训练目标，先问旧损失在固定末轮状态下是否抵消了恢复暖色的方向。检查两组训练家族和两臂，不读取正式独立数据。只复用原四头、清单、128 像素前向和原损失，机器预算两分钟，整体 15–25 分钟。不更新权重、不选择新超参、不接产品。

在未镜像的实际四态输入上复算全图、编辑区、编辑响应和换灯四个损失项，含原来的 0.5 权重。与原 `regional_loss()` 核对总值。固定关态与保护区，只让开态编辑区沿「现有输出到具备正确开关差的输出」移动。分别记录起点和补全时的四项、暖色投影、超出 [0,1] 的通道数，以及沿裁切后输出线段的右导数。这个正对照直接改变最终 RGB，使用目标答案，只有离线意义。

同一末轮权重下，从落地前向分别取四项对参考头参数的梯度。将负的加权编辑响应梯度作为固定方向，记录各项沿方向的点积、总方向及每项梯度范数。响应方向小或零明示。额外用无更新的正向试算与中心差分或单边差分核对符号，试算采用参数 RMS 变化 0.0001，仅用于核验局部趋势，恢复原参数。梯度因 ReLU、绝对值和裁切在折点可能与有限差分不同，差异也记录。

若直接补暖在两家族都降低原损失，现有四项并未普遍拒绝正确响应。若到头部参数上仍出现抵消，说明本点存在局部目标或表示耦合，不能凭局部梯度宣称是整段训练的唯一原因。若补暖反而抬高原损失，则报告具体拮抗项。四例都保留。不以结果重开原位置条件路线；如要提出下一版，只允许使用事前可核查的新输入或新目标依据。最终画质门槛不变。

EGM 复核后补记范围。试验直接补暖使用 `[0,1]`，80% 强度的前向逐通道区间更窄，为 `[0.2 × source, 0.2 × source + 0.8]`。另核对补全输出是否超出该区间，并检验四态输出等于答案时旧损失是否为零。以上都不能证明参考头能生成这些图。参数侧同时留存起点导数、正步与中心差分。后两项不同号时，只报告所测正步及不确定的局部趋势。
