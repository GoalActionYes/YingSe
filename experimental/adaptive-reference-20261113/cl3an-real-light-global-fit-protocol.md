# CL3AN 实拍色灯的整图校正上界

上一轮已能保住原片细节，人像局部颜色依然失败。本轮询问实际色灯照片能否用同一个 RGB 通道增益在整张图内校正，哪怕估计时已知道同机位环境光照片。CL3AN 提供同场固定机位的环境光、直接白灯和直接色灯实拍，与此前通过 RAW 分量合成冷灯不同。直接灯还可能改变亮度和阴影。白灯同样对环境光目标拟合，用于排查这些共同因素，所有结果均按诊断解释。

采用公开测试目录的前两个编号作为项目开发素材，每场取第 1 张色灯、第 1 张白灯及对应环境光图。文件名索引仅用于固定样本，白灯和色灯的灯位一致性未由索引保证。预算六个 PNG，各文件最多 80 MB，推理和训练预算为零。作者权重入口返回登录页，当前验证不加载网络。

使用等比例缩小至长边 1200 的三态照片。比较输入和环境光图的同位置像素，保留三态各通道均在 8–247 的像素。数据以 32 像素块的棋盘格分成参数拟合与测量两份。对每种灯只拟合一个全图三通道增益，在标准 sRGB 对应的线性 RGB 中最小化有效拟合像素到环境光的平方误差。测量侧的高、低色灯影响区域取色灯相对环境光的去亮度 RGB 差的最高、最低四分位，白灯复用同一区域。测量报告全图、高影响区和低影响区相对环境光的 RGB8 平均绝对误差，并保留原始失真。以项目已有每范围不超过 3 RGB8 为达标线，保留全部六个范围和白灯比较。有效覆盖不足 50% 或图像尺寸不同则该场不出结论。

若色灯在两场中任一场未同时满足三个范围，本轮只结束这一固定整图增益形式。若白灯同范围也失败，不把该部分误差单独归给色灯。发布图为相机处理后的 PNG，以标准 sRGB 作为近似，不将增益解释为 RAW 相机白平衡或物理照明参数。环境光答案只用于拟合和离线评分。该对照没有人物，也不验证风格迁移。禁止将这些场景留作本项目独立验收。

## 后续测量：原始码值相同时，逐像素色表的误差下界

覆盖筛查发现前两场的色灯图有大量通道接近边界，原拟合保持 50% 门槛和未判定结论。用同一批六张原图做后续诊断，不增加下载、训练和推理。每隔五行五列取原生 RGB8 码值，以免缩图把实际相同的输入值插值成不同值。任何逐像素色表对相同三通道输入只能给出相同输出。对每场每种灯分别聚合至少两个通道等于 0 或 255 的像素，按三个完全相同的输入码值分组。组内至少两个像素才贡献误差。从正确环境光图取对应像素，对每个通道求组内中位数，计算 RGB8 绝对误差。逐位置计算允许误差为零作为参照，其他未计入像素一律按零误差，得到整张采样图的保守下界。仍用 3 RGB8 为原有解释门槛，报告边界像素比例、重复码值比例、分区和全图下界。单场低于门槛时仅表示这个下界不足以判断，不据此认定色表可用。它也不评估人像、普通强度的偏色或参考风格迁移。
