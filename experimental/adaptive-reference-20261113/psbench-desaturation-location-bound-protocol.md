# 局部去色的全图色表表达边界：运行前协议

已有 PSBench 人像 145 与鸟照 248 的同帧前后图。问题是固定 RGB 查表能否同时重现作者的高支持去色区和保色区。固定原 512 长边、先做 80% 混合，再沿用原区域判据。按精确 RGB8 分组，只分析在两个区域同时出现的颜色，记录区域各自覆盖和样本数。每组要求两区各至少 256 个共有像素才能作整组判断。

对任何不按位置变化的映射，同一输入 RGB 的输出色度相同。把两个区域共享颜色上的目标色度以组内逐通道中位数代替，得到对共同区域像素加权的 L1 连续下界。为避免一类像素支配，也把两区域等权：每区每像素权重为该区共享像素数的倒数。两项区域平均色度误差若同时不超过 1.5，则等权均值也不超过 1.5；下界大于 1.5 时可排除这一要求。此为独立表达诊断，不能替代原来去色投影、响应误差和保色变化的联合门槛。

保存等权最优色度经色域约束并量化后的实际图，以及仅按已知区域重放作者色度的离线对照。两图共享像素之外都保留原图，使用相同原亮度。两幅原图共四张重放。人工意图区只用于离线；不能以这项诊断宣称自动空间调色已经通过。没有新训练、下载或打开独立素材。
