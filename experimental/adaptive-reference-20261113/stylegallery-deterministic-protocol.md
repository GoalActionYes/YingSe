# 完整尺寸确定性单步验证

前一步原执行A/B的完整64×64 latent梯度不逐值一致，旧整图检查点桥接仍失败。唯一问题：固定PyTorch2.6官方确定性条件后，相同单步A/B/C的损失与输入梯度能否精确一致？不重新定义旧桥接通过，不运行新图片优化或GT评分。

在CUDA初始化前设置CUBLAS_WORKSPACE_CONFIG=:4096:8；torch.use_deterministic_algorithms(True,warn_only=False)，cudnn.benchmark=False、cudnn.deterministic=True，保持TF32关闭。不得用warn_only跳过不支持的算子，也不更换精度、步数或种子。

复用前一次单步对照的同一22927可信自有缓存、同一固定模型、空文本嵌入、相同排序构造区域配对、缩放1及首个t。该构造配对不是历史候选匹配，缩放1不代表原150步动态GradScaler轨迹。

预算一次加载、原执行A／原执行B／检查点C三个单步反向。记录软件身份、设置、梯度哈希及差值、显存与耗时；损失与梯度两组比较均逐值一致才通过。任何不支持的算子、非有限或数值差异都停止并记录，不调整容差。通过也只能支持此单步，不等于整图等价或画质改善。

只有本项通过后，才另行固定新确定性上下文下的完整图对照。旧逐像素桥接失败事实不变，不合并旧两例、不把确定性开关作为调色参数追分；既有画质门槛保持。
