# 调色网格的局部权重是否压弱了有效风格

固定参考内容后，13 号仍能漏掉近中性色变化。上次直接跳过扩展版的 XY 平滑未改善联合画质。本轮保留 13 号和原 XY 平滑，检查接着发生的另一项操作：原渲染按网格节点的 alpha 加权插值，再除以插值 alpha；试验先在每个平滑节点除以本节点 alpha，设 alpha 为 1 后再插值。该操作只改变相邻节点的混合权重，不改变网格节点各自代表的矩阵与偏移、颜色引导、强度、内部裁切或输出流程。这里的 alpha 是网格权重。

固定背景与编辑开关、FACD、Film B、实体色卡四份开发对照，以及最近七目标的同参考内容换款测试。所有候选均只读目标和参考 RGB。控制须逐像素复现现有 13 号归档，同图返回目标。完整四套原门槛照旧。额外要求固定参考检查至少有两个目标新增联合通过，单图新增 RGB MAE ≤2。只有联合满足才考虑更大开发与正式独立验证；这不代替自然评价或视频验收。以常权重节点和权重不均的两节点数值检查确认干预有效，两遍各最多 92 张候选成片，固定方法、不训练或调权重。
