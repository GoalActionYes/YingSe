# 固定输入缓存桥接v2

缓存仅用于固定主干/固定目标参考的条件参数拟合，不接入产品，不改变128步等拟合设置。缓存目标图编码、直方图条件、采样坐标、固定像素预引导值；参数相关的attention、fusion、grid、采样与输出引导按作者公式保留。

v1在严格梯度逐位断言退出1，首次差异为output=0、grid=0、gradient=4.656612873e-10。旧源码和失败配置保留，不宣称全部通过。

v2在重新执行前固定：全部64开发图、batch4，条件三档0/.2/-.35；画面和网格继续要求逐项完全相等。每档另计算一次原流程自己的梯度，报告原流程重复差异；缓存梯度与第一次原流程按rtol1e-5、atol1e-8逐元素比较，必须注明不是逐位一致。记录最大绝对差、对应原梯度绝对值。这个容差只用于数值桥接，不是画质门槛，不能据此保证优化轨迹相同。若任意项超限则停止后续标签生成。

每批缓存准备单独计时；warmup比较后，原/缓存各6次交替测量一次forward+参数梯度，不计文件读取、模型加载或优化器。相同硬件、相同素材，不声称新图片画质、产品或视频速度已提升。主干始终冻结，状态前后相同，无优化器更新。
