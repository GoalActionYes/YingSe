# 同部位近色样本能否改善已有编辑方向

上一轮用目标颜色筛参考供样估力度，冷灯右颊恢复却丢失暖灯及其他区。本轮只改变聚合方向，从该轮已归档成片起步。使用同一参考开关图和近邻规则，核心像素覆盖至少 75%。在有支持像素求参考编辑中位向量和目标成片开关中位向量。保留后者长度，方向改用前者，再把二者之差按原余弦权重加到开态。向量不足 1 RGB8 或覆盖不足时保持归档成片。仅在量化前保持聚合幅度，记录裁切。关闭态与作用域外保持。目标预期仅用于出图后的计分。

沿用四区、整图、两灯、六个方向与原 80% 成片，比较原近色倍率结果。要求新增完整通过方向，且原通过区域不掉项、不多 1 RGB8 的误差。额外核查此前证实 0–4 倍固定方向不可达的脸颊项目是否恢复。不能挑冠军样例或改变覆盖阈值。失败则结束基于相同近色支持的固定通道方向替换。双跑，旧环境。
