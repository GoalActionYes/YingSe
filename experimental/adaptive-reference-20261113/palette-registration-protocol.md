# 颜色簇一致变换试验

本轮独立研究实现：量化RGB16档并对非空箱取真实均值，超256箱时固定最远点采样。两张调色板双向最近邻，保留误差最低80%的对应，以Cauchy权重加单位变换正则拟合4×3仿射矩阵，迭代最多20次。奇异值限制0.5–2，偏置限制±0.2。全部常量在本轮真实照片推断之前固定，不逐例调整。

方法借鉴点集配准的一致变换思想，不是论文的完整CPD或颜色同态复现，也不是剪映算法。近似颜色未必属于同一材质；只得到全局仿射候选，尚不能完成依赖画面上下文的协调调色。它作为识别可靠风格证据的试验，不用全局结果替代完整目标。

先做调色板打乱顺序恒等、小幅已知颜色偏移、无效输入测试；再使用已有8个内容占比控制。真实测试只用已用PST1–15，每组输出保存并哈希，全部冻结后才读专家图，不读取16–50。统计明确失败数和条件平均，保留所有失败，不按专家图选择输出。未接入产品，不承诺实时视频或语义理解。
