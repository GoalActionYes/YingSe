Motivation: reference-original training75 diagnosis showed frozen-guide transfer MAE5.83522 versus current13.37911, but with extra unavailable information, 47 shared original references, trained guides, and failures. This is not proof of a deployable algorithm. No filename suffix will be a style label; authoritative pairings remain unchanged.

Hypothesis: some conditioning ambiguity can be reduced by showing the model different training content rendered through the target/GT-derived color function. Test reference supervision rather than adding output capacity or retuning relation losses. Only this fixed augmentation recipe is tested; failure will be retained, no post-result mixture/weight tuning.
