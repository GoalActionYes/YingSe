# 用相同作者提亮寻找第二套匹配拍摄来源

这轮只检查固定两处 MIT Multi-Illumination 室内场景的实拍灯位中，是否存在与 Gros 可比的局部提亮开关。已有户外对照用了不同的压暗操作，不能让模型区分编辑与来源。这里复用 Gros 已验证的 Martin Werner 提亮参数，再到另一采集来源的浅墙上重放，固定位置及几何规则。只验证配对材料，暂不训练或新跑映色。[已定准入条件](../../docs/research/2026-11-24-spatial-condition-design.md) · [作者提亮](../../docs/research/2026-11-24-gros-author-tone-switch.md) · [室内实拍配对](../../docs/research/2026-11-21-mid-gray-anchor-lights.md)

- 只用冻结室内复印室与客厅，各用已下载的八张灯位：0、4、8、12、14、16、20、24。编辑区为两处房间先前登记的左墙，右墙与灰球保留作保护取样。各房间按左墙中心放同一份 Martin 局部点，保持作者的左右及上下半径比例，最大半径固定为左墙框宽的 1.5 倍、高的 2 倍。只改变三个几何字段，然后只翻转局部组启用产生关态。远处检查区为两倍最大半径之外。
- 各光照图须有左墙至少 80% 像素的 RGB 每通道在 [4, 251]，关闭图和原准备图的最大偏差 ≤2 且 MAE ≤0.25。编辑区压暗或提亮的统计仍用中位 Y′，需至少 +3 RGB8。右墙、灰球和远处的每像素平均绝对 RGB 差 P95 ≤1.5，整图新增触及 0 或 255 的像素 ≤2%。开关输出尺寸与 ICC 一致。如果单张失败，仍留片和数据，不调整编辑范围。使用相同来源、两处预先登记右颊和六套开关作 Gros 比较。
- 室内和人像分别枚举档位两两有序比较。两种差值分别为第二档关态减第一档关态、第一档开启减第一档关态。先找三图共同处在 [4, 251] 的有效区域。共同像素至少 80%。在已登记的同一测区独立求各图的逐通道中位数后相减，轻微表情位移较逐像素差更稳。两个向量的三个通道平均绝对变化均 ≥3、余弦 ≥0.90，编辑／换灯的欧氏幅度比为 0.75–1.25，采用原 EGM 准入线。两档各自的编辑质量也必须通过。所有方向完整列出，记录开关是否可比和失败原因。Gros 出片复用同一批原成片，不重复导出。
- 此轮机器预算 4 分钟，分析和复核约 35–60 分钟，不新增下载。如果室内至少一组和 Gros 至少一组全过，可固定为两来源的共享局部编辑开发对照。已有素材已用于开发，无论结果如何都不能据此开始新训练或开放独立验收。若任一来源无合格灯对，保留具体失败，停止在这套参数和灯位上重复筛找。
