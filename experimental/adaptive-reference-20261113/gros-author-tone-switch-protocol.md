# 将有出处的右颊提亮操作施加在三档实际灯光上

同原片开关可以确定编辑影响到哪些像素，未取得作者在两档实拍上分别编辑的原始独立项目。此轮只问：把已重放的 Martin Werner 局部提亮设置用到两位已有三档实拍的人像上，能否取得清楚的编辑开关，同时保住白幕和未编辑区域。此前同三档使用线性 RGB 半档人工增益，另一份作者的 darktable 暖色操作还出现了暖灯端点截断。本轮沿用真实拍摄，只换用可追溯的 RawTherapee「Color & Light」局部工具。结果是本项目在作者参数基础上重放的开发对照，编辑位置不是由原作者在这两位人物照片上选定的。[作者局部提亮](../../docs/research/2026-11-24-playraw-flash-room.md) · [旧半档对照](../../docs/research/2026-11-24-gros-mixed-light-exposure-toggle.md) · [旧暖色端点反例](../../docs/research/2026-11-22-gros-local-editor-cross.md)

- 只读原作者 `[Locallab]` 段和版本头。其余曝光、渐变、白平衡及镜头配置不复制。固定嵌入的 sRGB 输入配置、ProPhoto 工作空间、`RTv4_sRGB` 输出和相对色度意图。选取原来登记的人像右颊框中心作 RT-spot 中心。保留作者四向半径的同行和同列比例，按原脸椭圆 x／y 半径的一半限制各轴最大半径。位置仅取已备案的坐标，某人全部灯档和开关用同一几何。关闭只翻转该工具组的启用位。
- 保留原三档准备图及既有冷灯目标，共八张输入。输入补同一个嵌入的 sRGB 配置，写成无损 PNG。逐一导出每张的关、开并保存。关态与准备图比较用统一色彩解码，整图每通道最大偏差不超过 2，MAE 不超过 0.25。开、关尺寸及 ICC 均相同。右颊亮度的中位数至少增加 3 个 RGB8 码值，两片白幕及登记脸部椭圆外的 RGB 平均通道差 P95 不超过 1.5。整图新增 0 或 255 端点最多 2%。左颊作为旁及影响记录，保持所有未达标结果。
- 两人的三个参考灯档及冷灯目标都合格，才在正常 13 号工作台交叉人物出图。实际工作台收到普通目标和单张参考 PNG，固定 80% 及默认手动项，使用两个原人物、三档各两个编辑状态，共 12 张输出。作者重放目标的开态只用于离线评分。右颊沿用编辑投影 0.75–1.25、响应与开启误差各不超过 3 RGB8，白幕与椭圆外沿用关、开及响应各不超过 3，三个光档的分区响应差不超过 3。左右脸同时记录，另对已有的真实三档关态判断保留原开发限制。
- 本机两遍预算 35–60 分钟，机器预算 8 分钟，不做训练或下载。资格失败则保存编辑器的实际输出，停止此参数在该组上的跨人工作台比较。素材及工作台均通过，才将结果用作进一步候选的开发信号。资料来自同一套已用拍摄库；无论过线与否，都不能直接升为独立验收或证明摄影者为两种灯各手动制作。
