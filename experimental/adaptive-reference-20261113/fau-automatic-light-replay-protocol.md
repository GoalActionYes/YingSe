# 普通两图输入能否启动正确的实验室换灯

固定已验证的灯设置识别和目标照明响应，检验同设置换物体能否保持原图、真正换灯能否保留局部色度。使用此前未参与拟合或测试的三个杯类前缀 bymug、pmug、ymug 的 b_r 图作目标。五个此前用于验证识别的非杯类前缀全部作参考，每个参考都用 b_r 和 r_b，合计 30 对。它们是同一档案的开发对照，非独立产品验收。固定目标方向为 b_r，未校准反向操作。

候选从两图已冻结的 RGB 照明估计，经已保存的左右半幅分类中心判断设置；同设置输出原图，判断 b_r→r_b 时用两个已校准线性系数的算术平均在目标位置重放，沿用 80% 色度渲染。其他预测方向输出原图并记为错判。校准只取旧摘要，候选不能读取文件名中的实际灯设置、目标换灯图、评价蒙版或标签。对照为冻结 13 号的正常 80% 两图输出。输出全部落盘后才读取目标换灯图和评价标签。沿用此前输入编码，对新增的三个目标各做一次冻结估计，每个运行复现一遍。

同设置须逐像素恒等。换灯沿用两区原有资格、方向和误差门槛，至少两组目标同时有整图和近中性色评价资格；所有有资格的换灯输出均须通过，对每个有资格的近中性色评价还须相对同一对输入的 13 号至少降低 15% 误差。包括所有覆盖不足和错判。任一判定错误也使联合失败。通过仅支持继续检验跨实验室、不同光源及一般参考的能力；失败则不接软件、不调门槛，按识别与渲染拆分原因。预算为两次本机运行，不下载、不训练。
