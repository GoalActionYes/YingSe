# 显示区域外缘与屏幕前的人脸

沿用逐像素试验的原图、模型、屏幕类别和 0.70 置信度。唯一新规则是对至少 64 个像素的八连通显示分量取各自凸包，包内关闭肤色修正。64 像素剔除面积不足 8×8 的碎片，不按结果调节。不连接各分量、不更改模型及固定 RGB 诊断偏移。保留逐像素结果作对照。

原框沿用既有门槛。实际拍摄的三个脸部范围高权重覆盖至少 80%，投影幕脸、白球服、浅墙、雪地的低权重触及至多 1%。另用 9483 实拍人物 RGB 和项目存档人体裁切掩膜，固定将矩形 `[25,24,73,105]` 按平移 `(83,36)` 贴进 8021 原投影幕脸部位置。确知这块合成前景属于实拍人物。沿用前额登记框，若其完整落在被贴入的人体且原语义方法覆盖至少 80%，才有资格测量新规则，约束后也须至少 80%。合成生成使用标注，测试算法只读合成后的 RGB。屏幕原图与合成对照单独计分。

组齐才进入新场景验证。若能遮住显示人物但同时丢失前景，说明该几何范围不能代表物体前后关系。若凸包未覆盖屏幕人物，说明这批高置信屏幕像素不足以推断其外缘。测试仍只验证局部定位，不衡量参考意图、自然度或视频质量。
