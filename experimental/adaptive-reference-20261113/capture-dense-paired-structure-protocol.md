# 成对监督的视觉空间特征区分实拍换光与数字染色

固定旧四来源三态。更改表示方法，使用现有冻结 DINOv2 图块特征。逐块 L2 标准化，计算相邻图块的逐分量绝对差，横向、纵向分别均值后取平均，作为单图空间描述。拟合时先计算每组实拍向量减去同组原片与数字编辑向量的平均。按来源平均，再以跨来源平均差作为判别方向。将训练来源在该方向上的实拍和其余两态投影按来源等权求中心，中点作固定阈值。留出来源所有场景和相机不参与拟合或选择，分类只读一张参考图。对两个中心方向一致性不符、输入或描述无效必须明确拒绝。

沿用原四来源门槛：各至少识别 75% 实拍、原图与数字编辑零误触。复用 MIT 房间和人像真实成片做诊断，识别拍摄状态时回退原图，其他沿用 13 号。仍需全部原墙面、肤色、风格与底色门槛。禁止试其他层、阈值或合并旧线索。两遍复核，不启动主模型训练。本轮无法代替跨场景正式评估。
