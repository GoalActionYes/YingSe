# 验证全图参考编辑能否补足局部范围外

前轮恢复原底色后，12 项整图风格仍超线，局部完全正确也无法消除范围外误差。本轮保持目标原图作为关闭态、同一参考开关对及 80% 强度，使用原三次整图配对拟合，仅改变范围外编辑表达。冷灯读同一原参考开关，暖灯读同一限域参考开关。全图颜色表从参考配对拟合，目标原图应用颜色表。输出整图重放及合成两臂。合成以原区域羽化权重保留上轮目标底色重放结果，外部用全图重放。固定四个原核心逐像素保持局部结果。目标答案只在成片后评分。参考拟合资格一并记录，不用目标结果选颜色表；已核对实际配对允许离线出图，不构成自动准入。

仍用六方向、两灯、60 项风格、原投影 0.75–1.25、MAE ≤3 RGB8 及关态和换灯差 ≤3。要求新增完整方向且无既有局部掉项或超过 1 RGB8 误差增幅。额外比较全图臂与合成臂，以区分整图函数和局部保留的贡献。双跑，本机环境。候选即使通过也依赖额外参考原图和人工部位，当前阶段不能进入最终独立验收。
