# 按目标亮度分布汇总参考色度

雪地和白墙可能从亮度不相近的参考背景中继承颜色。旧版独立参考直方图丢弃亮度与色度的对应。上一轮按参考颜色的空间覆盖加权失败。本轮使用目标亮度分布和参考亮度与颜色的联合关系，验证该信息是否能降低偏色干扰。

固定八个等宽 Y 档。统计两个图的每档像素比例。对参考图每档赋予原参考质量与目标对应档质量的平均值。目标在参考空档的质量先按原参考分布回填。按该档质量汇总原参考的 128 桶 Cb／Cr，同时保留分档前的参考 Y 条件。若亮度档分布相同，恢复原色度统计。目标亮度与参考亮度均取模型的 Y，不涉及真值、人物蒙版或空间位置。该推断假定可迁移色度在相近亮度范围较相关，真实照片可能违反这一假定。

复用上一轮六组、42 个输入、固定权重、强度 80% 与 84 次前向预算。所有基线逐像素匹配存档，人物、近中性及整图响应阈值原样继承。保留每种正负对照，报告不改参考时的输出变化。失败停止这套配方，结果仅用于开发筛查。完整独立画质与视频要求继续适用。见[比较与门槛](reference-chroma-spread-protocol.md)。
