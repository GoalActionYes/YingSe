# 真实蓝灯的空间差异能否由单一全图颜色变换解释

两组实拍的蓝灯与数字蓝调已匹配全图线性均值，但按白点触发的校正仍误伤八张数字蓝调。本轮检验真实蓝灯的像素差异是否只剩能由全图变换解释的相机通道耦合。继续使用 CHROMA-MILL 的两个场景、两档灯强，以及先前固定的数字加蓝图。Film A 关闭与开启单列，避免把后期曲线引入的非线性归因给现场灯光。

- 拟合输入固定为对应白灯参考图。对真实蓝灯和数字蓝调分别用同结构的线性 RGB 3×3 矩阵。用 32×32 像素块按坐标 `(x // 32 + 2 * (y // 32)) % 4` 分四折，三折拟合、一折出图。拟合和计分均采用双方每通道在 4–251 的像素，每折至少 512 个且拟合秩为 3。保留所有输出和全画面误差，合格区评分与全画面分开。均值匹配原结果为附加对照。
- 四组 Film A 关闭的数字控制须在合格区达到 RGB8 MAE ≤1 且像素平均通道误差 P95 ≤3。只有同四组实拍均出现 MAE >3、P95 >8，且相对同组数字控制的 MAE 差 ≥2，才支持保留局部差异作下一轮诊断线索；否则不据此设计自动开关。不以 Film A 开启态决定主结论。
- 本轮预算为 16 个四折变换及一次重复。使用配准的白灯和结果图做离线诊断，无目标图真值进入产品、无新数据、无训练或发布。
