# 相同的手动色温与色调，是否需要限定画面位置

用户能看到的是换参考背景后脸、手、浅墙的颜色漂移。旧肤色保护能减少部分串色，但也误改无人场景并削弱有意冷调。本轮不改自动或产品功能，验证位置控制这一具体能力。固定三组实拍中事前登记的五块直接肤色和一块浅墙。基准为 C1 彩色参考的 13 号成片，需修正的是同目标、同预设的 F1 换背景结果。C1 只是同风格开发锚点，不是自然肤色真值。

先在每个旧框的交错像素中，用现有手动色温和色调从 −20 至 20 每 5 单位固定搜索，对 C1 锚点最小化色度 MAE。若同分选绝对改动和最小。参数只用于该框，未参与拟合的另半框单独评分。比较同一参数作用全图和仅作用在指定位置。局部范围为框内全值，框外按距离引入八像素软边。记录框外、软边和其余已登记区域，以及修改前后色度、亮度、最大变化。至少需有四块肤色与一块浅墙的留出色度差降 ≥15% 至 ≤1.5 RGB8，区域之外须逐像素保留 F1，以支持位置控制的开发价值。两版各六张成片，不调其他参数、不加 UI、无学习模型。人工范围与 C1 均只用于离线诊断，即使过线也不足以证明自动调整或自然画质。
