# 冻结的屏幕排除规则在真实电视与显示器照片上的验证

上一轮只在投影幕上测得失利。用已登记的 479248、340894、342367 三张真实屏幕人脸，检验问题是否泛化。另用 463618 原图 `[389,105,414,121]`、345252 原图 `[409,123,425,143]` 的直接脸部作为同框而互不遮挡的控制。先按原图固定框，再按宽高将 RGB 同样缩放到 256×256，框左上向下取整、右下向上取整。已知框只用于评分。

运行原语义肤色权重、冻结的逐像素屏幕规则及已存档的连通分量凸包规则。模型、置信度 0.70、类别、至少 64 像素、固定诊断色差均保持。不拟合、不更改方法。屏幕脸各框触及率至多 1%（权重 >0.05），直接脸部各框覆盖至少 80%（权重 >0.5）。归档每个方法的诊断成片、区域触及和最高概率标签。若三个屏幕脸中原语义权重均不触及，则只能描述本次无误触，不能证明屏幕规则有效。真实前景与屏幕重叠仍无本轮样本。
