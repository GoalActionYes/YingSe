# 参考背景灰化后的肤色串色来自哪里

上一轮的参考背景灰化在白球服手臂上有收益，却加重 785 和 9483 的实拍肤色换背景差。原方法仍从参考全图读取亮度，并可能因换背景而预测不同的皮肤权重。用现有 C1／F1 同主体配对，固定目标、已选权重、原生 13 号、基线明暗及 80% 强度。先逐值复现 C1 和 F1。然后在 F1 的灰化支路里，分别借用 C1 的自动皮肤权重、亮度、两者。三臂均保留 F1 的原色度，固定 F1 的普通基线，用 C1 成片作颜色差锚点。四组各两态，不使用作者目标或人工框作预测。

核心检查是 785 和 9483 上轮退化的直接皮肤框，另报告白球服、墙面、雪地、投影幕和全例。每项先报连续值；若某单因素在核心框六项中的至少五项都减少残余串色至少 25% 且至少 0.25 RGB8，且另一因素不满足同一门槛，才把该因素列为优先改进证据；否则保留交互或未解释因素。比较借两者后是否还有差，不能将双因素借值视为常规推理。采用锁定配对和旧成片，四组均为开发案例。两遍复现四组 × 两种编辑状态 × 三项干预的 24 张 PNG，原灰化对照仍须逐像素一致。此轮不上调度模型或改变产品。
