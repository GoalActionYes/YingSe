# 两张不同内容的同款参考能否抵消成片偏差

TST 的五组真实作者配对中，近中性色随参考风格切换保／改。目前 13 号用两张已知同款参考出图，换参考会产生可测色差；固定保护或加重监督未能兼顾风格。这里检验同款成片偏差能否互补。区别于同参考裁切平均和不同模型输出混合，本轮使用两个真实内容的同款参考，由原标注分组确认。

固定五组、三张 13 号成片、作者 80% 效果和旧切换区域。只改变两张同款成片的组合，异款成片不变。自动候选缺席，因为同款身份和额外参考为离线条件。比较基线、同款两输出平均、逐像素允许同款两色度任意凸组合。最后一臂以作者结果求最小色度 L1，统一沿平均成片亮度渲染到 RGB8。另存凸组合最小误差的未量化数值，区分区间表达与出图限域。保留每组两个原输出在应保／改范围上的同方向误差、三种重放及最差单区。只在给定的旧测量区域做组合，其余保持同款第一张成片；实用候选仍需逐图自动选择所有区域。

保持旧保色误差 ≤1.5、风格投影 0.75–1.25、换款增量误差 ≤3。组合后两张同款槽位共享成片，不能用必然的零换参考差宣称抗干扰通过。若至少三组等权成片达到三项，且每组两同款状态相对平均基线在整图 RGB8 MAE 增量不超过 2，作为测试学习多参考一致性的依据；否则若参考成片的最优插值也不足三组，结束该输出组合的修复方向。若仅最优插值有机会，保留其与均值的差距，需先取得能预测参考可靠性的证据。两遍 CPU，只读归档，不更换模型或开启独立验收。
