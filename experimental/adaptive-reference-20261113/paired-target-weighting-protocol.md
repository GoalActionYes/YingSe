# 用目标原图的颜色分布给配对样本加权

白球服场景中，两张参考背景的旧配对拟合分别只重现 0.537 和 0.606 的换款投影。用已知调色变换生成均匀色样后，同一种三次色表达到 0.914，手臂和整图仍未通过。要判断已有真实配对的颜色能否用得更好，本轮只问一个问题。按目标原图的颜色分布重排参考样本的拟合权重，能否让白球服恢复预期风格，同时保住其余区域？

- 使用已经开发过的四组原始场景。每组保留两种参考背景、两款已知调色、旧配对输出和 80% 强度。旧配对的系数须由全一权重逐项复现，渲染须与归档成片逐像素一致。
- 将参考原图拟合像素和未经调色的目标原图分别划分为均匀的 8×8×8 RGB8 箱。对两张归一化直方图的每个箱加 1/512，计算目标对参考的概率比，并限制在 0.25–4。参考样本权重随所属箱变化。拟合沿用原输入缩图、8 像素棋盘、通道裁切筛选、三次基函数和正则，按各通道可用样本权重之和缩放正则。没有参考像素的箱只记录缺口。目标成片和手工区域均仅用于离线评分，不参与拟合。
- 沿用上一轮 16 像素棋盘留出、同一近中性色定义、手工区域、至少 8 个像素和至少 1 RGB8 信号的条件。白衣另需至少 40 像素。主要结果要求两种背景的白衣投影均在 0.75–1.25，响应 MAE 均不超过 3 RGB8。其余符合条件的区域不得丢失原通过项，响应 MAE 不得增加超过 0.25 RGB8。保留缺测和全部反例。
- 两次确定性运行，每次 16 个配对拟合，保留报告、16 张成片和四张对照图。比较全套哈希。联合条件全部通过才考虑更多来源的配对验证。没有通过就收尾固定配对加权路线，不在这批素材上换分箱、权重范围或重新选区域。普通用户仍只有一张已调色参考，本实验需要参考原图和调色成片，因此结果只用于开发诊断。
