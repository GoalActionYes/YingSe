# 检查显示裁切是否改变换光与编辑响应判断

上一轮的作者目标四个登记区域全有 RGB8 通道到端点，冷光羽毛编辑色度方向甚至翻转。这轮只改变显示转换。沿用原 EXR 与 PQ 作者成片、两个时点和区域、缩放顺序、四种参考以及 13 号 80% 强度。使用同一套固定转换处理四张输入，并先核对登记区域再决定能否运行。预算四张准备图、最多八张模型成片及一次复跑，不再查找曝光参数或下载。

新转换仅用于测量。线性 Rec.709 先计算 Y，用同一单调函数 `0.003 + 0.82 × (max(Y, 0) / (100 + max(Y, 0)))^0.55` 映射亮度；分数次幂抬起极暗原片，保留亮度上限。Y 为正时先按比例提升线性 RGB，保持有效 RGB 的色度；如通道将越出 [0.001, 0.95]，在该亮度下沿中性轴压缩色度，低于零亮度绘制中性底。编码为 sRGB8。统一映射与上下界不按脸颊、白羽毛、原片或成片调整。该转换不用于产品，作者输出亮度和原片曝光仍无共同物理锚点。

计算各登记区域原片、作者成片的 RGB8 端点比例和 CIE 1976 u′v′；报告色度被压缩的像素比例及压缩量。作者目标端点比例须 ≤10%，且原片到作者成片的色度变化在转换前后余弦 ≥0.7，显示内变化幅度须 ≥0.005。四区域全过才运行原八项对照；任一失败即保留数值和图，停止此显示修正，不更换映射或选区域。通过只表明可按前轮定义测量方向，档案两个时点仍可能有不同的调色意图。

复用前轮参考开关与原有灯光差异门槛，不调整参数。若脸颊反转或白羽毛消失的失败随转换移动，说明原案例不能单独支撑由模型引起的特定严重退化；若同一参考在新显示下仍不达门槛，保留为对比候选的必要回归。无论结果，旧转图和新转图的表格均保留，不用较好的一次代替旧结果。该轮不修改推理链、不进入最终独立评估。
