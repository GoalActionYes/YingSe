# 真实屏幕遮挡照片准入

复用本机已校验的 COCO 2017 val 标注，筛选同时有 `person` 和 `tv` 非拥挤实例的照片。只考虑 COCO 元数据标为 CC BY、CC BY-SA、无已知版权限制或美国政府作品的图片，最短边至少 240 像素，两类候选框各占图面至少 3%。从有重叠的候选按交叠面积除以电视框面积降序排序，平局按图编号，取前八张。再取范围内所有合资格组合均无交叠的两个最低编号作控制。最多查看十张，单张最多 3 MB，完整图片和裁切留本机。

在任何模型推理前逐张查看。记录框交叠是否真的来自实拍人物挡住显示平面、是否有能登记的直接皮肤、屏幕上是否也有可见的人物面部。仅第一和第二项明确成立的图能进入前景保护诊断。同图同时有可登记屏幕人脸，才能用于两类脸并存的联合测试。遮挡、背景共现、反射或屏幕里的人须分开记。不能从 COCO 框推断前后关系。保留全部入选图、未通过说明和所用来源。此轮不设新模型门槛、不运行调色，不称为最终独立验收数据。
