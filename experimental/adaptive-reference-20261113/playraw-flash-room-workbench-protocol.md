# 真实局部提亮在映色两个工作台中的响应

上一轮已由 RawTherapee 重放作者开关。同一份 RAW 的右颊只因编辑而提亮，预选墙面和杯身不变。三档灯光的程序半档提亮已经证实现有基线往往漏调。本轮只查此前没进过工作台的真实局部编辑，验证完整参考能够重现多少提亮，以及改变参考取景后是否仍保留这项效果。固定完整关闭图为目标，分别用完整参照及裁切参照。每种参照都使用同一照片的开关配对。完整关闭图也用作已有同图保持检查。[作者素材的开关确证](../../docs/research/2026-11-24-playraw-flash-room.md) · [此前程序提亮的成片](../../docs/research/2026-11-24-gros-mixed-light-exposure-toggle.md)

从原 PNG 用固定半开矩形 `[170,70,1400,1140]` 裁切两张参考，保留 ICC、原像素尺度与三个评分框，只改变参考构图并去掉部分背景。右颊中心从原宽 56% 附近移至裁切宽 72% 附近。先用现有图片解码器验证裁切后原像素保持，验证三处登记框均完整落在裁切内。两版工作台固定默认手动项和 80% 强度，用真实导入、分析、PNG 导出各走两遍，一遍产生 8 张工作台成片。原照片级答案为相同的作者开关与现有 80% 混合，只交给分区评分函数，工作台接收普通两图。无新增素材下载或训练，预算 20–40 分钟，最多两次计划运行。

沿用右颊编辑响应投影 0.75–1.25、响应和实际成片误差均不超过 3 RGB8 的联合判定。关闭态在三个框里相对原色均不超过 3 RGB8。墙面与杯身的实际开启偏色和开关响应也均不超过 3 RGB8。关闭、开启各自相对目标的整图新增截断分别最多 2%。报告各项误差、整图误差、重复性和两张参考构图各自门槛。完整关闭参照的两版本各自应逐像素保持。输出尺寸、身份与对照检查失败时停在核验层，保留产物。不得改变裁切框、强度、模型或数值门槛复试。

两版若在完整场景都漏掉真实提亮，把这组开关加入后续候选最低开发回归，并继续优先解决参考端如何识别局部编辑。完整通过而裁切退化时，后续候选要先证明同一编辑在构图变化下的响应保持。两类都通过时，保留该作者编辑作为成功回归，将候选训练决策交给独立的跨内容和真实多灯档证据。本轮一张原片始终计作一个用过的开发内容。
