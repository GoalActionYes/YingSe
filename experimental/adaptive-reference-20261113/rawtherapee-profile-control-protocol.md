# 用统一显影配置核查近邻过调

四组同款编辑中，Cuckoo 使用完整作者配置，另外三组只加载 Version、ColorToning 和 Resize。上一轮用后三组预测 Cuckoo 时脸颊、浅色树皮均过调，草地无相近颜色。本轮仅把留出的 Cuckoo 切换到后三组的显影配置。保持同一原片、CLI、色彩平衡参数、处理开关和长边，冻结其他三组、原逐像素模型的训练和近邻规则。不以人工蒙版或 Cuckoo 开态拟合模型。重复两次，各渲染两份显影和两份估计，预算每遍三分钟。

检查新旧成片尺寸。脸颊、树皮和草地使用在旧图框周围扩展 16 像素的亮度梯度模板，新图只在原坐标 ±16 像素内搜索。最大归一化相关至少 0.65，且比距最佳位置超过两像素的次佳匹配至少高 0.05，方可移动原测框。尺寸不同或匹配不足则保留该区缺测。整图和各态近中性色仍按原规则评分。

脸颊和浅树皮均有资格、邻色支持至少 80%、投影 0.75–1.25、响应误差不超过 3，并且两区各较原完整配置邻色臂降低至少 0.25 RGB8，才认为统一显影消除了本例的两处过调。整图、草地和中性色同时报告门槛与覆盖，若关键区继续失败则不晋升候选。改变显影包含多项设置，结论限于整组设置的相互影响，不能分配给白平衡、色调或物体识别，不改变产品的普通两图输入。
