# 分离关闭态底色与局部支持范围限制

上轮局部方向与力度通过 34／60，六方向所有整图关态和风格仍超线。固定六方向、参考两灯和已有 RGB8 编辑差。第一对照仅把目标关态换成目标原图，把原开态减关态逐通道加到原图，按 RGB8 色域裁切。第二对照在第一对照的原有非零支持范围内直接换成已知正确成片，范围外完全保持第一对照。支持范围沿用半框宽羽化，硬替换仅用于下界诊断，不判断自然边界。由范围外误差对整图的贡献取得任何只改支持范围内像素的整图 MAE 下界。第一臂不读目标预期，第二臂明确使用答案。原两态换灯、风格投影 0.75–1.25、误差 ≤3 以及关态门槛照旧。

若重放编辑后仍无整图通过，且范围外下界超过 3，下一候选须改整图编辑表达或作用域，不继续在原框内累计成绩。记录底色、完整方向、实际开态误差及外域下界。两次复跑，本机现有环境。
