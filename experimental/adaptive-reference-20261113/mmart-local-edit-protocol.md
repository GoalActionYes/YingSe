# 核对 MMArt 的公开材料是否记录同款局部调色

发布方的论文包含真实照片修图、参考参数及人像区域评价。公开 MMArt-PPR10k 顶层只有 global 目录，另有 MMArt-Bench 单个 ZIP。本轮固定两份已核实发布版本，检查样本身份、原图和成片字段、局部编辑记录、蒙版的用途和跨照片的同款关联。数据卡的许可标识与上游照片许可分开记录。

只从 MMArt-Bench ZIP 读取尾部和中央目录，限 512 KiB，拒绝服务器返回未请求的部分。用原 ZIP 记录统计角色，只有发布中有可识别的文本操作文件时才考虑读取少量非媒体信息，累计元数据 1 MiB。没有编辑开关或参数一致性的分组时，不把同类描述当同款。人物评价蒙版不能当作实际编辑范围。缺少任一核心信息则结束素材准入，原图、成片和蒙版不下载。没有新训练、软件接入和独立验收。
