# 逐像素色度力度的离线可行性

统一力度已无法同时满足两张人像的整图和近中性色。固定相同两版、两方向和原测量区域。这次允许每个像素分别缩放模型的编辑开减关色度向量，方向固定，力度不限且非负。关态理想地设为原图。使用已知目标色度求取逐像素两分量的 L1 最小误差，并按既有色域算法实际出图。连续色度误差用于检验方向本身的限制，实际成片沿用投影 0.75–1.25 和误差至多 3 的要求。读取原目标编辑成片与开关参考，两者只用于离线数值诊断。

逐点误差为分段线性凸函数，最小值可在 0 或两条通道残差各自归零的位置取得。保存实际成片，并按整图、共同近中性色、已登记的脸颊、浅色树皮和草地报告。主要求沿用前轮整图及共同近中性色联合。若方向下界仍超线，则局部力度无法补足所需的方向。实际成片在这组最小误差选择下未过投影，也不推出所有满足投影约束的其它选择都失败。两遍运行均保存四张成片。原脚本默认入口保持，并复跑校验。
