# 边缘引导能否减少局部去色串到保色范围

PSBench 145 与 248 的固定粗网格对应未通过。给对目标范围后，固定力度能准确重放局部去色。此次检验一个独立问题：在不重新匹配区域的前提下，自动去色图的像素边界能否沿目标原图的明暗边缘收紧，减少本该保留的颜色被改掉。

复用冻结的两图候选、12 个空操作对照和已记录的四张 JPEG。自动臂只接受目标原图与参考成片。唯一变动是在旧方法的目标权重图之后加入灰度引导滤波，以目标 RGB8 的 Rec.709 亮度为引导，方框半径 7 像素、亮度正则 64 码值平方，范围约束到 [0, 1]。固定原强度、模型、匹配和原图明暗。另给出只用于定位问题的对照：将由作者前后图得到的目标区域汇总到相同视觉网格，在相同插值和引导中比较。像素级正确范围是先前上界，此处不将离线目标区域当作自动输入。

沿用完整作者成片与区域判据。两个自动方向都要达到去色投影 0.75–1.25、去色响应误差 ≤3、保色变化 ≤1.5；12 个空操作逐像素保持。旧自动成片须逐像素重放，候选最大明暗变化不超过半码。离线网格只辅助判断，区域未标注部分不计入网格取均值，空格设为零。若自动臂不达标，保留真实成片并结束固定去色区域的边缘后处理支路。两次重放，复用本机 GPU／OpenCV 环境，不下载、不训练。
