# 真实配对样张第二轮开发检查

此协议在读取新样张前写入。原五对中的颜色锚点全局分支平均MAE由16.731降至15.476，约7.5%；只有两对改善、三对退化，尚不足以接入产品，但支持对“减少部分全局过调”做一次更广的开发检查。局部分支总体没有超过全局分支，不视作已成功的区域算法。

固定使用PST50第6–15对作为新一轮开发素材，原第1–5对继续只作旧开发结果；第16–50对保留，不下载图片。第6–15对用过后不得再称未见测试。不同原照片相同合成控制的结果仍保留，但本轮使用真实配对专家结果作为颜色迁移距离依据。

在新图片下载前保存分组与源文件哈希。推断只下载原内容和参考图；所有10组候选完成并保存预测文件与哈希后，才下载对应专家目标评分。保存失败组，不从平均数中悄悄删除；不得以专家目标选择混合系数、强度、模型或图片。

候选与参数全部沿用dense-anchor-protocol.md：当前全局、原尺寸Canon、锚点全局残差、锚点局部残差、锚点无监督混合。当前算法和Canon都从原始解码图分析，再将结果缩至长边640评分；DINO取工作图特征。第二轮不修改算法参数、不按例调节、不增加语言建议。白色凸组合的float32边界修复另有先失败后通过的测试；不借此改变颜色方法。

记录每组RGB MAE与相对当前版的改善／退化，汇总平均、中位数、严重退化（多于5码值且超过25%）。另外查看人物、色偏、明暗结构和局部边缘；没有人工区域标注，不能从全图分数声称人物关系正确。10组数据是开发验证，不能证明跨来源泛化，也不能代替更广的照片／视频检查。

如果结果仍然不稳定，保留全部记录，不继续逐例调整阈值，不接入默认版；需要新的对应可靠性或风格证据，而不是将任意匹配余弦称为语义理解。原图相同的原始锚点输出有约0.8码值误调，产品接入前还必须有明确的同图保持策略，本轮不将其隐藏或称为通过。
