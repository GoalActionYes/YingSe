# 白幕颜色能否抑制真人换灯串色而保留有意暖调

真人基线显示，暖灯实拍的脸颊变化与全图数字染色相近，但白幕变化明显更小。本轮检验已知白幕位置时，是否能用可比较的中性材料估计参考的全局色度。使用前轮已冻结的三人六个方向，目标、参考与强度不变。新增的只暖脸参考由相同染色量和据原图双眼位置确定的椭圆羽化区域制作，背景保持；它是合成的局部编辑对照。评估所需的同款目标图用相同方法制作，运行拟合不读取这些期望成片。

基线为冻结 13 号，针对只暖脸参考补出其正常图像路径成片。试验臂分别使用当前目标原图与当前参考图中登记的两块白幕，取各自有效像素的线性 RGB 对数色比中位数，再求差作为全图色度参数。使用已有亮度保持操作，固定强度 80%，其余像素内容来自目标原图。白幕框只作离线已知材料，不是自动定位。只暖脸控制的椭圆中心以双眼中点向下 0.42 倍眼距，横、纵半径分别为 1.25、1.10 倍眼距，归一半径 0.82 内全权、到 1 线性衰减。混合在线性 RGB 进行。

保留原脸颊、两处白幕和整图的换灯变化 ≤3 RGB8、全图数字染色投影 0.75–1.25 且响应误差 ≤3，新增关闭参考相对目标原色各区 ≤3。只暖脸对照要求两颊同样达到投影与误差门槛，羽化区外变化 ≤1.5，且每个方向造景时两颊羽化权重中位数 ≥0.90。两个操作都通过才支持将此线索作为完整编辑估计。保留未通过的任一路径；若只通过全图暖调，则仅能继续将白幕用于估计全局分量。两遍复现成片及报告；无模型训练、软件接入、独立白墙或人评。
