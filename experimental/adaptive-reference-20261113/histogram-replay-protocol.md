# 固定输入的参考亮度／色度条件重放

在背景干预 v2 完成后冻结。本轮只定位当前模型的条件传播，不训练、不做区域直方图候选，也不再扩大背景干预素材。

读取已保存 v2 六对的 identity 和六种背景干预 RGB，验证结果文件、父文件、源码与模型哈希。当前 multiref-v1、同 256 输入、默认强度 0.8。六对的同画面认证均未触发，允许直接重放神经路径；若检查不成立则停止。

通过产品实际 `srgb_to_ycbcr` 和 `batch_histogram_1D` 得到参考 H0／H1。目标低分辨率图、目标直方图、权重、渲染和强度公式固定。每个干预分别使用三种条件：完整 H1；只将 H1 的 Y 通道换入 H0；只将 H1 的 Cb／Cr 通道换入 H0。另对每对原始 H0 生成一个基线。共 6＋36×3＝114 份输出。

完整条件输出必须与 v2 保存的产品输出逐像素相同，H0 基线也必须完全相同。先原尺寸网格渲染到 RGB8，再用产品 `finish_spatial` 混合至 0.8，不用浮点满强度结果直接混合冒充产品。如果重放失败，保留结果且停止机制结论。

保存条件数组、输出 PNG、网格哈希；描述各通道直方图 L1 差、投影条件变化、网格平均绝对变化及目标人物／背景／中性色代理／全图 RGB MAE，沿用 v2 的区域定义。记录完整响应与仅色度、仅亮度响应的差，不能假设非线性模型可简单相加。>1 码值仍只是可测敏感性，非质量门槛。

检查全部六对满覆盖正反条件的完整／Y／CbCr 对照。独立从保存数组重算条件来源及区域统计，验证 PNG 哈希。参考直方图来自 RGB，不让人工蒙版进入神经推理；区域标注仅作离线测量。保持全部结果，不读取 GT 或独立评估，不按分数选例。

若仅色度路径仍产生主要人物响应，确认应在参考颜色条件及其使用方式上设计下一项修复；如 Y 路径贡献大，优先处理直方图量化与亮度耦合。历史直接分区直方图固定配方已失败，不把本轮确认敏感性当作允许重跑该配方的证据。修复仍须区分合理全局风格与内容误迁移，不能简单屏蔽色度或固定回退。
