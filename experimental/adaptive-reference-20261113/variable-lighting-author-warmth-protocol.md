# P1020943 作者日照区域暖色的取件与核验

现有暖色开关多由项目复现同一编辑，普通参考的意图仍难判断。先前《Variable Lighting Workflow》只发现一份原片；本轮只问 Todd Prior 描述的日照建筑加暖，能否得到独立于现有自制编辑的单原片正例。对照 kofa 公开的两实例局部白平衡侧车，仅用于核对同一发布有不同作者的操作。两份来源侧车合计预算 ≤80 KiB，先不取照片，预计 10–15 分钟。

固定原帖原片 `P1020943.RW2` 与第 5 楼的 Todd 侧车、第 7 楼的 kofa 侧车。只读论坛发布内容和 XML。核对来源链接、文件体、哈希、可解码模块及各色彩实例的启用、名称、顺序、混合模式及蒙版。只有作者说明能关联到特定导出版本，且该版本有可唯一定位、启用且可重放的对应实例，才把操作归给 Todd 所述的局部加暖。蒙版引用、作用区域和变化方向均须能够核实。若侧车不足以隔离这项操作，暂停取 RAW，继续补查下文的 JPEG 元数据。kofa 的局部白平衡仅用于核对 kofa 本人的编辑与蒙版解析。

若通过，原帖所标 CC BY-SA 4.0 的原件约 14.7 MB，最多取 20 MiB，使用已核验本机 darktable，保留原片与完整侧车。只改变唯一操作的启用位。先核对开关均正常出图、尺寸和 ICC 一致。以关态和作者说明登记建筑测区和未编辑保护区，再查看开态。沿用暖色有效覆盖 ≥80%、红减蓝变化 ≥3 RGB8、亮度变化绝对值 ≤3 RGB8、保护区 P95 ≤1.5 RGB8、全图新增通道端点 ≤2%。保持编辑强度、色域和测区。正式出两遍对照约需 20–40 分钟，无新训练。通过后可新增一条外部作者单原片局部加暖与保护区回归。跨灯档监督、普通两图候选和独立验收仍须各自验证。

附件中若不能定位作者叙述的一项局部加暖，补查 Todd 同楼发布的两份 JPEG，先取各自文件头前 64 KiB。验证 HTTP 范围和 JPEG 段，仅读取元数据。两份历史均可解码、比较，相关蒙版能解析且无未取得的扩展依赖时，才可逐实例确认局部颜色差。预算内无法核实则记录范围并停止该案。
