# 用固定机位的真实近景行人遮挡验证视频候选

从 Xiph 发布的 `pedestrian_area_1080p25.y4m` 取原始第 258–329 帧，保持画面内容，变为 640×360、30 fps 无损 RGB MP4，共 86 帧。原素材由 Taurus Media Technik 拍摄，固定机位，近景行人从右向中央穿过。复用前一轮的工作台、参考、权重与两基准候选，不改变候选阈值。[原始发布目录](https://media.xiph.org/video/derf/) · [文件来源与 CC0 声明](https://commons.wikimedia.org/wiki/File:Video_Codec_Test_pedestrian_area_1080p25.y4m.webm)

只看输入时固定三个区间。CFR 帧 0–11 为目标近景遮挡前，19–64 为近景进入与经过，66–78 为右侧背景重新可见的阶段。原人物此时在画面中左部，这不是整个人离开画面的区间。测量采用两个左上建筑矩形 `(20,12,66,42)` 与 `(80,18,122,52)`。沿用前一轮同坐标相邻帧差、输入稳定线 1.00、至少 32 个可评分相邻帧、原漂移至少 1.00 的资格条件。候选需两区至少降低 0.25 且相对降低 25%，恢复帧不得增加超过 0.25，事前区间不得新增暂缓。完整 MP4 另行复算，保留原编码设置。各模式两遍，候选未显著改善时不调阈值，也不将该片当作独立画质验收。
