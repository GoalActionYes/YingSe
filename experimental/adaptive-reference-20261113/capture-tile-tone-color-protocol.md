# 平滑区域的明暗与色度关系能否减少换灯串色

冻结四个拍摄来源：CHROMA-MILL、Beyond RGB、MIT 复印室及 Gros 人像。每组用未改图、实拍换灯、同向数字染色。对单张 RGB 缩至 256×256，取 8×8 个区域，保留有效像素至少 80% 的区域。按局部线性亮度标准差排序，选较平滑的一半。按区域中位亮度排序，以四等份的对数色比中位数计算最亮减最暗，以及中间两档平均减两端平均，共四维。至少 16 个合格区域。每次把一个完整来源留出，所有相机和同场景变体同组，其他来源拟合标准化最近中心。参考没有原图对照，使用单张判定。无有效特征回退。

核心资格要求各来源至少识别其实际换灯的 75%，原图与数字染色无误触。额外保留 MIT 房间和人像两目标的离线成片。检测为换灯时保留目标原图，否则沿用实际冻结 13 号成片。待测作用仅为验证该触发能否工作。任何数字编辑被清空计为退化；仍使用原综合色差、风格投影和原稿偏差门槛。两遍复核，不调阈值救分。即使通过也仅进入新内容开发验证。
