# 参考外观只读取明暗的双人像试验

交叉实验证明外观支路会减轻关态偏差，也会抵消反方向的有意改色。检验把参考外观编码的输入固定为相同画面的标准亮度三通道副本，是否还能提供有用的场景信息，而减少重复传递颜色造成的抵消。目标、参考颜色统计、模型、空间渲染及 80% 混合保持固定。候选只需普通目标和参考图。灰阶外观输入与原训练分布有差异。

锁定双人像编辑开关的四个模型输入、原扩展第 4 轮、原分区及门槛。两方向的整图和共同近中性色均需通过。另报脸颊、浅树皮及背景。当前完整模型逐像素复现，同图保持精确。保存候选输出后才读取评分答案，每遍四张候选成片，重复一遍。若任一方向失败，结束该固定灰阶转换。若全过，再复核四套已有开发反例后考虑独立测试。
