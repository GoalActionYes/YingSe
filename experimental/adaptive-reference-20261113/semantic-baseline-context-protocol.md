# 显式基线颜色条件的固定对照

上轮局部／池化均未改善，停止原配方。注意力统计排除完全平均化，但不能证明对应正确。源码发现原修正系数预测没有显式读取原主干已调颜色；本轮仅检验补充这一条件，不改温度、描述器、限幅或损失，不追加旧区域头监督。

两臂沿用冻结DINO64×387输入和相同局部匹配。原774维token拼接额外3维，均为目标空间8×8局部RGB均值：候选使用固定原主干浮点输出clamp至[0,1]后adaptive_avg_pool2d；控制使用目标原始归一化RGB作相同池化。输入维777→128→12，GELU、末层全零，空间系数插值及0.1*tanh与原候选相同。仅预测输入条件不同，基线本身在两臂完全一致，实际颜色来自推理可计算输出，不含GT。

先检验条件对照的来源、零输出／关闭恢复、非零权重时对基线改变的敏感性、梯度及非法值；两臂同初始权重、64开发零轮精确恢复原主干。随后同seed20261129、AdamW lr1e-4/wd1e-4、batch4、8轮2048更新、grouped_batches、RGB L1＋0.1梯度L1、裁剪1。train1024／development64全部保留，描述器不训练。开发预测先全部保存后读GT。全64开发均值选择包含零轮、平局取早。

全部旧强制门槛不变：候选对原版均值≥5%收益、≥40/64改善>0.1、严重退化≤2，第二参考32均值不退步且≥17改善；对同预算控制均值≥3%收益、≥36/64改善、严重退化≤2；32组delta均值收益≥5%、≥20组改善>0.1，并保留关系与明暗／反差／饱和度非退化。严重退化为增加>5且>25%。通过开发后才冻结新独立自然、人类评价及视频／完整性能验收，不能据均值一项宣布成功。

这是局部颜色修正结构的第二个有明确条件差别的假设；若仍无收益，不围绕该结构增加新块、损失或seed，整理停止证据与下一路线。GT、权重、特征和媒体不上传，代码与小型数值上传。任何图像不移动结构，普通CUBE不能容纳完整空间效果。原版继续可回退，未通过不接产品。
