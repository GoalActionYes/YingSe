# 参考色度的空间覆盖权重

雪地、白墙和球服会跟随跨场景参考背景的色度变化。已消费的六组受控对照确认了这种传播。本轮检验新假设：集中于少数位置的颜色对参考统计贡献过大，按颜色的空间覆盖调权可以保留分布更广的整体色调。人物分区和中性亮部回补的既有配方保持停止。

冻结背景干预 v2 的六组目标与参考。每组复用 PNG 原参考、满背景正反换色、整图正反换色、整体对比度、整体去饱和，共 42 个输入。分析 256×256，强度 80%，使用旧权重和字节混合。比较现有参考直方图与一个候选。修改只限参考 Cb 和 Cr：参考分成 4×4 个等面积格，各自在原 128 桶计数。对每桶乘 0.5 + 0.5 × (总计数平方 / 各格计数平方和 / 16)，空桶保持零，各通道归一。保留原 Y、目标统计、网格和渲染。蒙版仅用于衡量结果。

先要求全部基线重放逐像素匹配存档。以各自原参考输出为起点，四人像 × 两方向中至少 6/8 项背景干扰的人物绝对 RGB 差比基线低 20% 且至少 0.25 码值，同时整图同方向干预的人物响应以对基线 RGB 变化向量的投影计，至少保留 90%。六组近中性色度背景干扰均值需改善 15%，且不能有单项增加超过 1 码值。全六组对比度和去饱和的整图变化向量投影系数均需在 0.90–1.10。报告各自原参考输出差，以识别静态换色带来的风险。

通过仅支持进入下一轮开发画质比较。失败保留所有输出和指标，停止本固定参数配方。已有独立画质、负例、自然评价和视频门槛继续适用。预算 84 次网格前向、180 秒计算，使用本机已有权重，零下载。
