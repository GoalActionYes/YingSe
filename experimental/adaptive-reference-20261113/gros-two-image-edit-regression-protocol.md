# 从目标和参考直接回归颜色编辑系数

旧预设分数的连续混合未保住原片。本轮直接拟合有符号 RGB 编辑系数，不输出预设类别或混合权重。训练仍来自已核验的 DAST、MLS、Middlebury、ARRI 四来源，Gros 三人整组留出。每个参考状态与不同原始内容的训练目标配对。用目标原图及同款已知编辑估计二次 RGB 增量系数，无风格为零系数。所有训练目标采用相同下采样、二次特征及最小二乘。比较同一训练样本的参考描述回归和增加目标相关描述差的回归。特征为既有整图色调统计及局部相关读数，按训练均值和方差标准化，正则固定 0.05。推理不读原参考、实际灯位、作者编辑与区域。

用 Gros 上原片、Film A、Film B 的两灯六个跨人物方向比较。权重预测完成后从目标原图以固定 80% 渲染。另用目标自己直接拟合已知编辑验证二次表示容量，仅作离线参照。同图强制保持。检查原片偏差 ≤3、旧整图与区域风格门槛以及跨灯差。新增完整方向且原片不退化才可推进。若直接回归无收益，不调正则或再跑闭集分数。双跑，旧环境。
