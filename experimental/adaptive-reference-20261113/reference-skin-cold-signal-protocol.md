# 参考皮肤能否提供整图冷调的独立线索

旧皮肤回混保护了实拍皮肤，却削弱了有意冷调。仅调保护强度也未通过。此前的边界色差检查以人物轮廓为依据，主要辨别局部冷色。本轮改用参考皮肤内部的蓝红差中位数，辨别是否有支持保留整图冷调的证据。只输入当前参考成片，用既有固定皮肤识别器。整图蓝红差中位数作为比较。该信号不能区分所有冷色光照和艺术编辑。

对六组既有冷色开关参考运行。四组有人照片中分别用整图冷调为正，基础与局部为负。每次留一整组，剩余三组中用严格高于最大负例的规则定阈值，皮肤版仅使用至少 16 个权重 ≥0.8 的像素。若某一折训练中没有有效负例则该折不触发。保留两组无人场景为负，另将四组 BG-REAL C1/F1 作为无新增全图冷调负对照。四组范围本身无经核验的历史调色标签，因此 BG-REAL 只检查 C1 → F1 是否制造误触发，不按单张判历史操作。为了比较，整图版使用全图像素并沿用相同训练与门槛。两组无人参考分别采用全部四组有人负例定阈值。

通过条件为四个有人的全图冷调至少命中三个，八个有人的其他参考和六个无人参考零触发，且对四对 BG-REAL 使用四折阈值时没有 C1 不触发而 F1 触发的翻转。若失败则停止该固定单值信号，保留原因。全部通过才考虑接入现有隔离候选验证出图，仍须更广的有意调色与背景负例。两遍 CPU，每遍不超过 60 秒，无新下载。
