# 两个小范围暖色目标的网格表达核验

两组训练素材在见过的输入上也漏暖。给定正确编辑后，13 号原生网格可以表达此前的人脸编辑。但本轮 MIT 客厅墙面登记区只有 42 像素宽，可能明显受固定 16 × 16 网格影响。Beyond RGB 用另一套相机和不同墙面范围。只核对原生网格能否表达这两个已登记的目标编辑，同时保住周围材料。结果决定下一步是否需要改目标端的空间表达。

固定原暖色清单中的 MIT 客厅灯 0 与 Beyond RGB 白绿场灯 1，使用实际目标关态和暖色开态。沿用上次 Gros 的固定 SciPy 求解器、棋盘留块、样本步长及全局共享与原生网格两个表示。沿用原渲染、80% 强度和 JPEG 以外的原 PNG。只变输入场景。拟合以同一目标的开态作为离线答案，评分只用该像素未参与拟合的结果。两套灯光对照的目标答案相同。关态以恒等作为能力对照，开态用此离线成片。仍按原登记的 3 RGB8、暖色投影 0.75–1.25 和保护区规则核查。另记录编辑范围之外一格网格宽的最近保护带平均误差，仅补充观察，不更改原联合门槛。检查稀疏数值实现与原生渲染、零强度恒等。两遍比对报告和原尺寸 PNG，机器预算 5 分钟，整体 15–25 分钟。

原生网格优于共享，并在两组均过线，提供给定答案时的表达见证。若有人出图失败，保留失败材料，旧求解器不是数学最优，不能只凭这次试验否定整个空间表示。原生网格和共享都过则只确认两者在指定阈值可表达。真值只用于离线容量，不能作为普通两图推理结果或产品画质。无新模型训练，不重开停止的位置条件路线。

EGM 复核后补记。留块拼图来自两张固定网格的互补预测，单独保留为留块测量。已见拼图结果，补存两套已固定折的单网格完整成片，包含参与拟合的方块。不变更场景、求解、阈值或挑选过程，报告所有单格结果。每个来源至少一个原生固定网格全帧通过，才作为该场景的单网格可达见证。保护带按横向图宽／16、纵向图高／16 扩张，裁到画面内，剔除登记编辑范围。零换灯误差由两档共用答案与成片构造。
