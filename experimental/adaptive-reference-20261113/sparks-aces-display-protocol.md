# 用标准显示转换复查《Sparks》跨镜头调色基线

上轮焊工近景偏色，远景近中性色更接近同帧 GAM，但远景 GAM 有 13.28% 的通道样本超出诊断显示上界。原因假设为原亮度压缩及逐通道裁切可能改变两向误差和视觉差异。本轮唯一改动为显示转换。沿用四份 EXR、512×270 的线性区域缩图、方向、13 号权重和 80% 强度。用 OpenColorIO 2.5.2 内置 ACES 2.0 CG 配置从 ACES2065-1 到 `sRGB - Display` 的 `ACES 2.0 - SDR 100 nits (Rec.709)` 视图。各输入同一处理，不逐镜头改曝光。保留原转换和全部结果。

同一显示空间内计算原图和模型相对同帧 GAM 的误差，录入前后差及范围外样本率。整图与各显示原定义的中性色代理均沿用旧分数。另固定在两种显示的中性色代理交集上复算，至少 256 像素；不足则标记不可用。用旧面板选定近景脸部小块 `x=183:205, y=72:86` 和远景天空小块 `x=390:470, y=20:64`，在两种显示中记录模型减作者的平均有符号 RGB 偏差，仅为开发诊断。人工选区及同帧 GAM 不进入推理；两个镜头的色调和编辑可不同。

分别判定两方向：若 ACES 后模型整图误差仍大于原图，则该方向基线退化复现。远景中性色须在原定义和共有像素上均保持误差下降才视为具有跨显示证据。局部颜色只比较有符号差，记录任何反向和退化。若结论随显示改变，只能报告显示敏感性；若整图退化在两方向均复现，后续优先核对两镜头有无可转移的实际调色响应。此轮没有产品候选和独立画质得分。

不再取媒体。单独解包一个不到 4 MiB 的已校验官方 Windows wheel，预算为两遍四份 EXR 的缩图和两遍双向推理，每遍各阶段 120 秒。保留所有对照与不适用项。
