# 根据当前参考分别组合两个模型的亮度与色度

离线分析表明，扩展第 4 块与 C10 等已有成片存在互补。固定训练参考估计的共同偏移会在换参考时抵消。此前研究过单一图像占比、固定风险判断，以及中点差分的离线选择。本轮让两个可观察系数分别决定亮度和色度的组合，系数可以随当前参考变化，并直接监督组合后的整图及换参考差。

使用已审计原训练清单的首批 64 个完整目标组、每组四张参考，及同一 64 对已用开发配对。组按数字内容编号升序、组内按 style_index 固定排列。训练组里的目标与参考拍摄家族和开发组不交叉。候选和 C10 主干权重不改。这些训练配对曾供被冻结模型使用，训练表现不能判为泛化。

亮度采用 BT.601。两条输出端点逐像素拆为 RGB 共享亮度与 RGB 去亮度残差。用两个 sigmoid 权重把 C10 分量混入扩展版，从 0.1 初始化。候选的两个线性预测器各取八项输入：参考减目标的 Y、B−Y、R−Y 均值差及标准差差，共六项；扩展与 C10 出图的平均绝对亮度差、平均绝对去亮度残差差，两项。只用训练集均值和标准差归一化，标准差下限 1e−6。常数对照采用同一目标、训练行、初始化及优化，只保留两个截距。候选与它的唯一结构差别是权重读取当前两图和已有出图。

两臂端点和作者结果等比例划分为 8×8 方块求平均，得到 32×32 监督。使用训练整图 RGB L1、0.5 倍同目标另外三张相对第一张的变化 L1、斜率平方和乘 0.002。Adam lr=0.04、180 个全批次 CPU 更新、保存最后一步，没有开发选轮或超参搜索。单张开发成片完全独立渲染。结果在全尺寸 RGB8 诊断入库尺寸上混合并按最近偶数取整，裁切前另记录超出色域比例。同图直接保持。开发成片均保存及核对哈希后再读取作者结果。

候选须满足未降低的两套开发画质门槛，并比扩展版和常数组合的平均整图误差低，保留相应换参考收益。失败停止固定配置，不更换权重、特征、种子或同一数据的门槛。只有通过才另行验证已有背景干扰、自然图和视频。GPU 仅计算 640 次固定网络推理，CPU 拟合不超过 180 秒，每遍总预算 180 秒。两遍同配置，不下载、接软件或读取独立预留素材。
