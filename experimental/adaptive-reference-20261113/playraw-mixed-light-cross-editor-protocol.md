# 用独立编辑器检验一次跨照片局部调色

此前用混合光原片的两个互斥区域估计固定色度偏移，均能重放同一张照片上的局部调色。本轮检查肤色换成另一个场景时，固定偏移还能否近似同一项编辑。目标采用已有《Cuckoo》原片和事前登记的脸颊、胸口、浅色材质及绿色背景区域。

在 darktable 4.0.1 中将目标 XMP 的原有第 10 步换成参考 XMP 第 28 步的颜色参数。保留目标自身的曝光、白平衡、裁切和其他步骤。参考的手绘蒙版随原图几何定义，改为均匀覆盖后导出开关两态。离线将开态按 80% 强度混合，只把脸颊和胸口矩形内的结果作为局部对照。这样得到的是编辑器对同一操作的响应，矩形是实验设计中的已知作用范围。

待测方法只读取目标关态，在相同范围内应用上一轮两个固定向量的算术均值，并保留目标亮度。拟合使用混合光素材，目标开态只用于评分。本轮无需训练，预算为两次独立渲染，每次两次导出。

导出需保持已登记的 1024×683 几何，新旧关态的亮度梯度相关性至少 0.97，原位置的相关性需为 ±2 像素内最高。脸颊和胸口分别要求至少 128 像素，编辑器本身的色度变化中位数至少 2 RGB8，重放投影在 0.75–1.25，色度响应 MAE 至多 3 RGB8。两个保护区域的色度误差 P95 均至多 1.5 RGB8，零变化由固定范围直接约束。两次导出的通道差异至多 1 RGB8，判定须一致。若几何或编辑幅度不合格，停止解释重放成绩。若重放失败，保留反例并停止外推此固定向量。

## 关态导出超时后的独立显影对照

带目标完整历史的关态在 180 秒内未完成导出。用同一 4.0.1 工具无 XMP 导出，确认原片可读。默认显影与旧关态的梯度相关为 0.9620，低于原协议的 0.97，故保存原试验为未取得可评分结果。查看默认显影并确认同样的四个矩形仍落在原登记物体上。固定该无 XMP 成片的像素身份，才开始独立对照。只在默认显影中加入该操作一项，XMP 关态必须与固定的无 XMP 成片最多差一个码值。在这个基线中继续用同一色度向量、区域门槛和重复性要求。两种显影的结果各自记录。

直接验证完整历史关态通过原几何门槛后，回到主协议。引入的唯一运行环境调整是在编辑器子进程移除研究辅助模块设置的 `OMP_NUM_THREADS`，以完成原计划的四次导出。最小侧车实验单列，因未达到自身的默认关态要求而未读取开态。
