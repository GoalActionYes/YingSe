# 独立人像光谱上的局部肤色修正

上一轮在 ISSA 点测脸颊样本中，通过整采集来源留出的肤色门槛，但把修正直接用于全图会带偏灰块。本轮只问：同一修正能否在独立测量的连续脸颊区域重现收益，同时保住相邻的非肤色对照？沿用 D65、标准光源 A、同一光谱采样、80% 强度、冻结的 CQS 矩阵及最近八个肤色残差算法。ISSA 所有合格来源样本用于预测，临时输入和答案只由 UMINHO-HSFD 生成。

固定使用 UMINHO-HSFD 光谱原件中最小的两份 `253`、`282`，合计约 155 MB，以及对应两张已遮盖面部识别特征的作者预览。根据预览图在任一输出生成前确认双脸颊矩形范围。每个矩形抽样为 64×64，不导出完整重建人脸。原件 400–720 nm 系列只取 400–700 nm。数值需为 [0,1] 反射率，两种光源均入共同色域的像素不少于 95%。两块脸颊原始纹理与人造灰色、两块近中性有色材料拼接成同一张图。灰色反射率与非肤色色样在协议中固定，对应已知光源目标由同一积分得到。

以矩阵成片为基线，比较不带区域限制的残差与仅在脸颊区域应用同一残差。区域限制由人工离线提供，任何非肤色区域改动按错误处理。为检查边界，指定脸颊蒙版最内侧八像素之外计为核心，候选在到矩形边缘的前八个像素从 0 线性过渡至全强度。限制臂核心脸颊 RGB8 误差中位数 ≤1.5，90 分位 ≤3，任一矩形同方向不得比矩阵增加超过 0.5 码值的中位误差。接缝内边一圈的 90 分位不得高于矩阵超过 1 码值。非肤色保持矩阵成片像素完全相同，灰块最大误差 ≤1。四张受控成片的两个脸颊都须通过。严禁以这个蒙版结果表述自动皮肤定位或自然人像验收。若达标，下一步才测试自动定位及真实衣物、白墙。

合成控制使用平坦光谱灰度 0.08、0.18、0.32、0.48，两个非灰控制使用 CQS VS1、VS9 的反射率各 25% 与 0.32 平坦反射率 75% 混合。所有输入及控制持续写在本机忽略目录，Git 只保存程序、协议和聚合数值。两位的裁切坐标作为生成前登记附表。

附带保存 13 号出图，参考为另一位的同一目标光源下拼图。13 号按原双 RGB 接口运行，报告用同一脸颊与非肤色范围。该臂提供现有软件的受控比较，不改变候选门槛。

坐标在读取作者遮盖预览后、任何输出生成前写入 [`skin-spectral-portraits-regions.json`](skin-spectral-portraits-regions.json)。按原文件宽高使用左上包含、右下不包含的像素坐标，避开遮盖区域、嘴唇、鼻部和脸部外缘。
