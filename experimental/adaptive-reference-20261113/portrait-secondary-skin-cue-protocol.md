# 使用同一人物的脸颊与颈部色差区分换灯和编辑

跨场景调色时，参考人物在暖灯下变橙，直接迁移容易让目标人物的脸也变橙。只看脸颊会丢掉身体其他部位是否有同向变化的信息。用原有三人四态对照，验证加入颈部后，判别能否保留有意调整并避开真实换灯。只增加颈部这一处测量。用同一留出划分和分类器，比较脸颊对数色比中位数与脸颊减颈部的中位数差。

颈部框从原始预览登记，使用左闭右开的 PNG 坐标。01 冷／暖分别为 [453,364,464,385]／[454,368,465,389]，取画面右侧胡须和衣领之间的外露皮肤。02 为 [367,431,407,446]／[367,432,407,447]，取胡须下方。03 为 [356,404,410,436]／[356,416,410,448]，取颈部中间。两种合成图复用冷灯坐标。每张脸颊至少需要 384 个、颈部至少需要 128 个原有亮度范围内的像素。只暖脸图的颈部必须和冷灯逐像素相同。作者案例检查儿童颈部 [762,555,789,568]，必须目视属于同一人物、蒙版权重全为零、开关前后逐像素相同才能作为独立测量。蒙版及原图对照只用于核验资格。

按人物逐一留出，其余两人拟合原有标准化最近中心分类器。暖灯实拍为正类，冷灯原图、同向整图数字染色和只暖脸为负类。结果必须识别 3／3 暖灯且 9／9 对照无误报或缺测，还须在可测的真实作者开态判为编辑，才考虑出图。缺测与错判逐项保留。这一轮限两次 CPU 复跑，禁止移动框或调阈值追分。未过门槛即结束这项线索，不改产品。即使通过，也还需验证自动区域定位和真实成片。
