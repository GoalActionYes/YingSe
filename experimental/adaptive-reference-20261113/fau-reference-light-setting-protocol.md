# 不同物体的参考图能否区分两种双光源设置

系统若把参考物体变化当成换灯，就会错误启动局部调色。此前在给定操作时，目标图自己的照明估计可以决定部分变色位置。本轮只检验参考端的必要条件：能否从单张参考区分实验室的 b_r 与 r_b，并据此正确判断两图是否同设置。

固定原两组 bmug、bpmug 作为校准，使用另五个同时具有这两种设置且名称不含 mug 的档案前缀作开发检验。按前缀保留全部变体，不拆分同一前缀。相近名称的场景可能相关，不将五组作为独立来源。沿用统一增亮两档及冻结照明模型。每张图计算左右半幅 log(R/G)、log(B/G) 的均值差，以校准组每个灯设置的两条特征均值作为中心，分配到距离最近的中心。对照完全相同，但用线性化后的输入 RGB 计算特征。使用全部像素与固定下限 1e-4，禁止根据标签或预测筛选区域。此法只比较粗略左右差，既不配准物体，也不搬运光照位置。校准标签来自档案命名，检验标签只用于评分。先生成全部特征与预测，再按档案命名评分，不读取光照真值图或蒙版。

比较十张单图判定，以及每对不同前缀的四种两图组合，共 20 同设置、20 换设置。候选必须十张全对且同设置与换设置均零错误，才值得将此信号接到已知操作的出图诊断。若直接 RGB 同样全部通过，则这组实验不足以支持额外照明模型。任一候选错判即停止固定分类器接入，不调分区、中心或阈值。两次本地冻结推理，不下载、不训练、不动软件；本轮不将两类实验室灯设置等同于普通图片中的调色风格。
