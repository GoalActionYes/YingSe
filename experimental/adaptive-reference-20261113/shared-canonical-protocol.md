# 共享中性域消融（开发结果之后、该消融运行之前冻结）

首轮人物／背景裁切候选在30组开发控制中10改善、8恶化、其余回退或小变化，整体MAE中位数10.93→10.98，尚不足以接入。区域颜色／明暗关系有改善，区域饱和度／对比度关系及多人场景没有稳定改善。

一个待验证原因是：原候选分别用目标人物裁切与背景裁切重新估计中性化，可能把目标本色与裁切上下文差异当成需要额外纠正的色调。消融只改变这一点：完整目标仅中性化一次；参考人物／背景裁切分别产生风格向量，再对共享中性目标生成两张区域restyler LUT。裁切选择、概率、残差去均值、±24限制及0.5强度全部保持。

使用同一6对开发素材，不读取24对冻结评估。新结果保存在不同目录，不覆盖首轮失败。该方法是自定义区域应用，复用作者冻结权重，不是作者原始全局模型，也不是新模型训练。
