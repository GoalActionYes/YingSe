# 用实际工作台检查可见变化相近的室内换灯和局部提亮

前一轮在两处已用室内拍摄中取得合格的局部提亮与光线近似对照。这里只回答现有软件面对这两种参考时，是否把有意的左墙提亮传给目标，同时避免误传实际换灯。两款工作台走真实 API 导入、分析、PNG 导出，强度 80%，默认手动项。保持版本和评分线，不生产新候选。[前置配对](../../docs/research/2026-11-24-shared-authored-tone-admission.md) · [原联合门槛](../../docs/research/2026-11-24-spatial-condition-design.md)

- 固定两处场景互作目标。目标取对方房间灯位 0 的关闭成片，同一张目标在三个参考条件中保持不变。验证所有 12 个合格的有序方向。每方向依次给基准灯关态、另一实拍灯关态、基准灯开启有意提亮。共享文件允许按工作台媒体身份去重，按相同请求导出并保留各条件来源。额外在两个工作台各用两个房间的同一张目标作为参考，要求逐像素保持。同款编辑使用目标自身灯位 0 的开启成片与原图做 80% 混合，目标答案只用于离线评分。
- 在目标左墙、右墙、灰球以及远离目标编辑点的范围分别读数。保持已定门槛。原参考与目标原图平均差 ≤3 RGB8，单换参考灯光相对基准成片差 ≤3，编辑开启的成片相对答案误差 ≤3。开关响应误差 ≤3，左墙响应投影 0.75–1.25，各保护区也核对开关响应。原图自身的四张基准如有错误单独报告，全部方向和成片保留。各款逐区域及全方向给完备计数。
- 两遍机器预算 6 分钟，报告和人工核验估计 40–60 分钟，不新增下载或训练。若两个基线都无法处理这套近似参考，将其冻结作下一候选的开发筛查。若至少一款通过，说明该室内组超出上一轮人像失败的覆盖范围，保持数值与其他反例。此套源自同一采集库及已有开发场景，独立训练准入及正式验收条件仍未完成。
