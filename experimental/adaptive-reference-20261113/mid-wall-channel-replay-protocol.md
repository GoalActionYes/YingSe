# 近等亮墙对照的参考明暗色度交叉

对新复印室实拍换光与匹配数字染色，墙面颜色接近但参考整图明暗不同。冻结两张目标、两款成片与原评分。这轮只在 13 号交换参考亮度直方图，其余色度直方图、目标全部条件和原渲染不变。生成「实拍色度＋数字编辑亮度」与「数字编辑色度＋实拍亮度」。原三态须逐像素复现。真值与区域只用于离线归因，不将混合参考当普通两图输入。

先测相同色度仅改亮度时的输出 Y′、去亮度 RGB 与综合色差，再以数字编辑亮度固定的两端同原整套评分比较。若去掉实拍参考亮度后所有保护区域达 3 RGB8，且数字编辑仍达标，才认为此单独参考分量可覆盖当前反例；否则逐区记录剩余误差。两遍固定出图，只涉及同一个参考房间和两个开发目标。结果只为拆分路径，不是采用已结束的固定通道替换做升级。
