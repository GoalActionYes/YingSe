# 使用目标颜色筛选同部位的参考编辑差

固定 Gros 六方向、冷暖灯、参考开关、部位对应、限域校正、80% 强度、0–4 倍与原范围。本轮唯一变化是估计力度前先按目标原图的 RGB8 颜色选供样。每个目标核心像素查询参考同部位至少八种不同的原始 RGB，要求第八近不超过 12 个 RGB8 欧氏距离单位。相同 RGB 的供样编辑差先求均值。对满足条件的目标像素，取八近邻的平均参考编辑差，再在该目标部位求中位数。目标已有方向在同一批像素测中位差。部位覆盖至少 75% 且原方向/幅度检查合格才改变该部位倍率，否则复用上轮倍率。范围外逐像素保持。目标答案只计分。

用原中位差估计作主对照，额外保留原部位对应结果及原门槛。要求新增完整通过方向且保住原参考中的肤色和白幕，不能只看覆盖或通过数。若按同色查询仍几乎没有足够覆盖，或有覆盖但风格不稳，结束当前固定同色选择。在报告中单独记录范围外保持和覆盖。双跑，CPU，不训练。
