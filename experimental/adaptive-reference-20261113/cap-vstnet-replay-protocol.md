# CAP-VSTNet 背景串色的分区与颜色重放

CAP-VSTNet 与 B0 的固定候选已停止。剩余问题是雪地染绿主要依赖自动标签变化，还是参考换色即使沿用原标签也会进入颜色计算。结论用于判断后续是否值得优先改进分割，不能作为重启旧候选依据。

固定六组已用目标，各取原参考、满背景绿色、满背景品红。目标输入固定。对每种换色用原参考 RGB 编码及标签作为控制，然后交叉重放两组参考编码和两组自动标签，形成完整换色、只换编码、只换标签与未改输入四种。各分支都沿用原重映射、解码和 80% 混合。它们是受控反事实，会读取通常用户无从提供的未换色参考。冻结上一轮 18 张已保存输出作桥接，桥接整图 MAE 须不超过 0.05，否则停止解释。无新数据或训练，推理及保存预算 90 秒。

按既有近中性色区域测量。若固定标签的串色在至少 9/12 个方向上仍大于等于完整变化的 80%，且最差雪地至少有 80% 的变化保留，则优先调查颜色如何在分区内传播。若至少 9/12 个方向的串色降低至少 20% 且至少 0.25 码值，并包含雪地，则自动分区变化是值得优先调查的因素。其余结论为混合。完整差分不可按两个单因素结果直接相加，保留交互残差和所有反例。
