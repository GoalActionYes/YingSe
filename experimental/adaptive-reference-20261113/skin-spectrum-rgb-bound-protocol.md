# 检查已知换光下的 RGB 映射余量与同码冲突

上一轮保白矩阵在多个来源降低了脸颊误差，十组仍未双向通过。本轮固定两个光源、80% 强度与原共同色域，问同一个问题：在已知光源方向的情况下，仅用输入 sRGB8，是否有证据表明原矩阵误差主要来自信息已经丢失，还是仍有可学习的规律？

对两个方向分别按完全相同的输入三通道码值分组。离线用组内答案的逐通道中位数算任何逐像素固定映射的样本平均绝对误差下界。每组取目标差最大的两项，二者目标 RGB 平均绝对差的一半是至少一项的误差下界。分别统计超过 1.5 与 3 码值的冲突组。保留每方向最大冲突的两片无人物纹理色块，将源画面、共同参考和不同换光答案排在一起。查表只用于诊断，不能当作模型结果或完整图像模型的上限。

只有一个新预测臂：以固定 CQS 矩阵为基线，从其余采集来源中按源线性 RGB 欧氏距离取最近 8 个脸颊样本，预测相对该矩阵的线性残差均值。待测来源整组排除，两个方向分别计算。相同距离按冻结的来源和工作簿记录顺序排列。测同一输入及强度，保留原样、已知白色增益和矩阵数值。用现有数据，最多四张诊断图，不访问新素材。

肤色门槛仍为每个合格来源双向中位数 ≤1.5、90 分位 ≤3、共同覆盖 ≥95%，并且 90 分位不得较矩阵增加超过 0.5、不得增加线性输出剪裁。另对第一来源的两张色块图保留灰色外推，预设灰块最大逐像素 RGB 平均误差 ≤1。若肤色达标，说明测量数据的可迁移信息值得用真实人像检验，灰块外推也过关后才支持进一步研究全图映射。矩阵在普通输入的策略、肤色区域判断、一般非肤色保护和风格迁移仍待验证。若存在超过 3 的同码下界，保留反例。若新映射失利且同码下界只覆盖少量样本，不把其他失利全归于 RGB 信息丢失，也不继续调邻居数量。
