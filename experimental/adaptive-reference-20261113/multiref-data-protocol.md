# 同目标多参考数据准备

目的：检查同一目标只有一个GT的监督限制。该限制使忽略参考图也可能拟合训练样例，但尚未证明它就是前轮失败的原因。新准备只建立开发数据，不分配或读取新的独立测试。

在固定TST索引及cohort-v2 family规则内，依旧512训练目标的原顺序，选首256个拥有至少4个不同GT路径及参考路径的目标组。每组保留原配对作style0，再按固定hash顺序选3个不同GT及参考配对，共1024训练三元组。目标源图可重复，必须全部位于训练分区；参考与目标为不同family，未知参考family排除。

依旧64开发目标顺序，选首32个有至少2个合格配对的组，保留原配对及一个不同GT／参考，形成64开发三元组。保存为先32个原配对、后32个新增配对，支持同一目标更换参考后的响应评估。它们是开发图，不能声称新独立样本。两批已消费保留family不得进入训练或开发。

全部选择仅用配对元数据，不读取GT评分，不按画面挑选。不同文件路径不保证视觉风格不同，下载后保留全部组并记录GT差异，不按结果换样例。所有原图／准备图仍须核字节、ICC、尺寸、跨组精确重复；组内同内容重复是设计，不是跨组泄漏。无足够完整组时停止，不缩小分母。

下载前仍核大小与固定远程身份，上限2GiB／20MiB单文件／并发4；优先重用已核验字节，保留原图，另存RGB8 ICC副本。训练及关系损失配置在实际评分前另行冻结，本阶段不把新数据定义视为效果已改善。模型、数据和许可边界不变。
