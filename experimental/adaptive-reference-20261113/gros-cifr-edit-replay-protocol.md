# 由单张参考推断未调色版本，检验能否重放编辑

已有参考前后图时，跨人物可以重放 Film B。通用修光会同时消除灯光和有效风格，不能直接当作参考。CIFR 作者针对相片滤镜还原训练，与修光的监督不同。本轮考察模型输出能否近似保持拍摄条件的未调色参考，随后从估计的前后图中重放变化。这里的未调色图由模型预测，实际参考原片与灯态不进入该臂。

使用固定作者 CIFR Git 提交 6b0a9b28cb2a724db869c02f376f123d05137e46，权重来自其公开演示，VGG16 使用模型卡明确来源于 torchvision 的同版特征权重。只取 CIFR 91,520,207 字节、VGG16 卷积特征和最小源码，下载上限 160 MB。权重和源码保留在本机作研究，加载前核对版本和哈希。固定方向 01 ← 02，冷暖灯和 Film B 开关四张参考。沿用作者演示的 256 方形及 RGB 归一化规则，每张单独估计原片。

在同尺度参考上，对估计原片和当前输入的逐像素配对拟合原有固定三次 RGB 映射，用同样预定格点与目标像素重放，混合强度 80%。另外运行同规模已知真实参考前后图的离线正对照。真实原参考和目标正确成片不进入候选的恢复或拟合，先落盘再测与真实原片的偏差及现有五区门槛。预算 4 次估计、8 张目标成片、原图恒等对照。必须在全部五区满足关闭态、抗换灯和风格误差均≤3 RGB8，投影 0.75–1.25，才扩大。未达到即结束固定模型及回放方式。旧图库与独立保留集角色保持不变。
