# 左右区域分别读取参考色彩

参考两张图的颜色计数相同、编辑位置不同，13 号成片不变，旧扩展外观分支也未传出正确幅度。本轮只新增两块对应位置的参考统计。冻结 13 号对目标全图分别读取参考左、右半幅，保留普通全图输出的亮度；在目标相同方向按预定 45%–55% 宽度平滑过渡色度。无手工蒙版或目标答案输入，坐标只表示半幅，不能当作人物语义。短边不足两像素、同图均沿用原输出或原图。

比较固定的两组布局对照，沿用原完整区域误差、响应投影和近中性色门槛。另同时执行背景与 FACD 两套旧完整开发检查，保留整套反例。空间改动的亮度误差必须不超过 0.5 RGB8。两次出图复核；任一联合门槛未达到就结束固定左右对应，不调接缝或位置。即使通过也仅允许跨构图的开发验证。
