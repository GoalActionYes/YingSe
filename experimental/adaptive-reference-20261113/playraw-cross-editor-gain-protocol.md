# 检查跨照片色差能否只靠减弱修复

固定色差在《Cuckoo》的脸颊和胸口均超过 3 RGB8。已有成片的投影大于 1，可能是变化太强，也可能是两个色度分量不该等比例变化。给定两轮原关态、编辑器局部对照及同一个参考色差，改变的只有该色差的倍数。保留目标亮度、已登记区域与 80% 对照强度，无需重导 RAW 或训练。

两处肤色共同拟合一个 0 到 1 的倍数，以未量化色度 MAE 最小为准。两个分量各自的目标变化与固定变化之比是待选倍数，按固定分量绝对值取加权中位数并限制在 0 到 1。将这个倍数通过原渲染器出图，分别检查两处投影和误差。再计算每个像素独立选择任意非负倍数所能达到的未量化误差下限，用来分辨颜色方向的残余误差。所有拟合都使用目标答案，仅为离线诊断。

共同减弱后，两处都须满足投影 0.75–1.25、色度响应 MAE 至多 3 RGB8，区外原像素精确保持。两遍区域结论一致才用于判断方向。本轮继续保留父实验全图不复现的记录。若共同力度带来的有利结果只成立于这个已知目标答案，后续仍需在其他场景验证可预测性。若逐像素下限也不达标，结束在固定颜色方向上调力度的解释。若共同力度失败而逐像素下限达标，当前结果只能排除共同力度，不能判断可预测的局部力度会否有效。

## 已通过场景的回归检查

在《Cuckoo》两份结果给出相同倍数后，将这个倍数冻结。回到混合光原片的两个旧留出折，各用原折固定向量、原蒙版权重和原 80% 答案重放。唯一变化是同时乘以冻结倍数。两个留出折分别沿用 0.75–1.25 投影、MAE 至多 3 RGB8 和区外逐像素保持要求。过渡区同步记录，保留此前 0.25 RGB8 最大额外误差要求。若任一折失败，停止将该倍数作为统一自动减弱值。源照片已用于估计原向量，回归结果仅能否定统一设置，不能用于独立验收。
