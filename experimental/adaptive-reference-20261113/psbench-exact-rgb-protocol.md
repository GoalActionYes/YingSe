# 有操作记录的跨照片调色能否作为统一颜色监督

S24 同款成片的精确同色对照出现明显跨照片差异。这里检验另一项本机材料：PSBench 105 的教程视频显示台阶人像和铁塔均使用同一个 Photoshop 动作，但无法确认发布成片中全部参数一致。本轮判断这对成片在共有 RGB 上是否足够接近，供后续判断能否当作统一颜色映射的监督。

仅用已核验哈希的 105 前后图，按历史实测切出的 704×1080 两侧图，比较 80% 强度。沿用 S24 精确 RGB 与 16×16 棋盘半区，每个颜色在四半区各至少出现 8 次。报告两个方向覆盖率、跨照片差、两项图内差，并单列近中性色代理。同时用同两张原图加确定的固定 RGB 映射作为技术对照，共享输入颜色应逐值给出相同输出。

整图至少 128 个共有颜色且两张照片各至少覆盖 10%。满足覆盖后，跨照片差比两项图内差最大值高至少 2 码值即确认存在明显差异；否则只记未达到差异门槛。近中性色沿用同样数值条件，单独判定。覆盖不足的区域不作一致性结论。若整图或近中性色存在明显差异，不可把该对所有像素作为统一映射监督；若整图覆盖足够且未达到差异门槛，允许将这对保留为有限的颜色映射开发对照，仍须扩大来源。

上限两次 CPU 统计，无新素材或模型、无新训练。使用已有跨场景成片与颜色表结果作背景，不重跑那两套方法。结果不用于软件画质验收。
