# 已调色参考能否携带跨内容编辑身份：固定小型诊断

问题：三位专家的同图结果不同，但只看已调色参考图，能否跨照片识别其专家身份？这是参考条件的信息检查，与已停止的“真值人物分区有空间拟合收益”假设不同，不恢复该支路。专家身份仅是本数据中真实监督标签，不等于任意风格或固定滤镜。

固定四组4_2、7_4、15_3、19_1各三专家，共12张已取得的专家图。输入只允许这些已调色图，经既有ICC到sRGB及BILINEAR 256处理；不能读取参考原图、人物蒙版、源／目标真值或XMP作特征。官方专家标签仅用于监督和统计。全部已消费训练来源，仅是开发诊断，不是独立产品评估。

唯一主要特征为RGB三通道各32箱归一化直方图＋RGB均值／标准差，共102维；次要描述基线仅均值／标准差6维，不根据二者优劣选型。固定多类ridge回归one-hot，lambda=1，无参数搜索。每折完整留出一张原照片的三个专家版本，只在其余九张图上拟合标准化与分类器；四折各一次，每图预测一次。训练集零方差特征的标准差置1，不读测试统计。

主检验精确枚举组内标签置换：各照片的三个标签独立置换，固定首照片标签不动以消除全局重命名等价，共6³=216配置（含真实标签）。每个配置重新按相同四折拟合／评分，p值为不少于真实命中数的配置比例。主特征预设至少9/12正确且p≤0.05，才认为本固定小样本支持继续最小参考条件研究。次要基线不用于挽救主检验或改门槛。

保存全部预测、每照片／专家表现和完整置换分布。该信号既非审美分数、调色误差，也不证明能迁移任意风格；四照片很小，阴性不能证明专家身份不可学习，阳性也不能批准479项或产品训练。若主检验失败，停止本固定特征探测，不调lambda、箱数、种子或增加原图／真值蒙版追分。

CPU60秒、BLAS两线程，无GPU、网络、安装、新下载或产品候选训练。不做三个预设的软件，不将类别ID作为正常调色接口的额外输入；正常产品目标仍是参考图＋目标图／视频。
