# 学习像素特征的风格分支

固定特征的画面监督及稳定微调均未通过验证门槛。降低学习率避免了参数饱和，但没有取得整体收益。所有失败保留，最终30张测试图仍未用于推断或选择。

验证诊断进一步区分表示和推断：已知风格参数时，自动224人物概率的组合平均MAE约0.607码值、局部关系误差约4.916，相对输入的8.465／16.001明显下降；人工蒙版控制约0.093／0.231。此项是明确标记的真值风格诊断，不是可部署效果。它说明当前着色表示和自动区域信息有表达空间，主要缺口仍是从RGB推断风格。

新试验复制官方MobileNet分割模型的特征主干作为可训练风格分支，原分割模型继续完全冻结。风格分支学习识别与调色相关的像素特征，并使用RGB推断的固定人物概率池化；不接收真值蒙版。BN运行统计固定，卷积和BN仿射参数可学习。风格头从参数预训练的深层特征模型初始化。

保持原240／30／30图像分组、S/T生成与组合、150例验证、四项验收门槛不变。不放宽数据或标准来获得通过。固定6000步，4对图/batch，AdamW；风格主干学习率0.00001、风格头0.0001，余弦降至各自10%。画面、参数、同风格监督权重分别为10／0.2／0.01。BN固定以及矩标准差零边界的有限梯度先测试。

另用训练集中的30张图生成固定训练监测控制，明确标为训练诊断，不参与最终选择，以区分模型无法拟合与拟合后不能泛化。只依据原30张验证图保存最优与符合门槛的检查点。最终测试仍需验证门槛全部通过、先冻结选择再执行。成功也仅能支持受限合成风格，需要自然参考图、全分辨率、速度和视频等进一步验证。
