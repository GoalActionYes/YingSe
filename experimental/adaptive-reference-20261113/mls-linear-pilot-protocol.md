# 检查线性原片能否提供有效的换灯色度

上一轮最强蓝灯预览与参考基线的共同有效区域不足。固定最先已登记的场景 02、03，取标准灯 2HAL_DESK 和最弱蓝灯 2HAL_DESK_LED-B025 的线性 PNG。读取作者原始 ZIP 目录和这四个成员，下载上限 32 MiB。不更换场景或灯位以追求过线。作者发布为 CC BY-SA 4.0，档案和图片留本机。

原片保持相机 RGB，不声称提供标准色域。按两对共同使用固定线性增益 4 并应用 sRGB 编码曲线，同时保存无增益的覆盖对照及源高码值。原始 16 位通道上限参与核查。先检查两图共同有效面积、换灯的色度 RMS、两种纸块及近中性色支持，沿用预览实验的门槛。共同增益不得成为跨灯逐图校正。若至少两个范围合格才值得运行完整输出比较；否则结束这组线性对照，不降低门槛。无论结果均保留覆盖缺失与原始尺寸记录。
