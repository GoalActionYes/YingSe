# CL3AN 白光方向对照协议

映色已知会漏掉浅墙局部暖色，遇到灯光引起的暖色时又可能影响目标肤色。现有配对多用彩灯端点，变化过大。CL3AN 作者使用固定机位和相机参数，在固定布景分别拍白色软箱漫射光与白色直射光。两套白光标称均为 6400 K，作者用实体色卡校准。待检验的是默认白光下布光及表面反射是否仍可能发生类似局部暖色的小变化。本轮不使用 RGB 彩灯，也不重复原来以色灯为输入的 CUBE 下界。两套不同灯具、光位、阴影和亮度均可能变化，无法归因到单个变量。

只用已冻结的两个场景的漫射光 GT 与第一档白色直射光 SH_IN，四张源 PNG 逐一与旧证据比对。使用已用过的 BOX 缩小方式，固定 1200 × 800，不另行白平衡或改相对曝光。作者发布源图可用于本机学术诊断，许可未扩展为产品训练或媒体分发。先只看漫射光，选择一处实际浅色漫反射区域和至少一处不相交的保护区，登记两处可辨别的固定地标以及源图身份。之后核对两档的局部材质及无遮挡。整图仍过现有预检的零位配准条件，若不满足则记录为未确认，不放宽阈值或改用不同场景。

复用暖白灯预检生成四组开关图，判定沿用既有暖色全套门槛。三态共同有效覆盖至少 0.80，方向余弦至少 0.90，幅度比 0.75–1.25，两个变化平均绝对通道幅度各至少 3 RGB8。每场保留两个方向，出图复跑并独立复算。若出现暂定匹配，需核对独立来源、局部对应与材料类别后，才讨论跨来源工作台验证。若无命中，保留有意开关和失败原因，停止这两场取样。用途限现有开发诊断，无新下载和训练，预算 15–25 分钟。
