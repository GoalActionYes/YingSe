# 按表面方向积分的实测环境光能否改进自然光校正

上轮用整球平均 RGB 校正真实自然光，降低了部分换时段差，但未保住目标绝对原色及风格。本轮只改变从同一环境图取光的角度权重，检验同一光场中水平铺地与垂直墙面是否需要不同读数。

固定原 WildRelight 两个时段与墙面、铺地登记。用图像上缘为天顶的等经纬坐标，观察环境图上下半球是否与肉眼所见符合。铺地按正向水平表面取上半球余弦权重；墙面方位角未校准，按所有竖直朝向等权，入射角余弦的方位均值为 sin(纬极角)/π。两者都计入球面积权重。由每种方向的首／末 RGB 比得到增益。方向臂与球面平均对照均把各自倍率作用于整个末时段参考，以相同 SDR 显影和 Film B 开关渲染到另一处目标。该设置只用已知表面类型估计一种颜色增益，不提供参考逐像素照明。另用登记参考的 16 像素棋盘半区拟合首末线性 RGB 的固定逐通道比值，在另一半只评参考误差，用作离线能力对照，不进入任何目标渲染。首末照片的相关性和 RGB 假设沿用当前资料。

报告登记浅色表面和整图的参考首末差、目标同一风格的换时段差、关闭态对目标原图偏差及开关风格响应。方向臂须在两个浅色参考上都比整球 RGB 改善至少 0.5 RGB8 与 20%，且实际成片通过商定的 3 RGB8 / 风格投影 0.75–1.25 完整门槛，才支持进一步采用。增强方向保留的同时继续核对色度与曝光，候选不得使用目标答案或区域出图。方向、增益和假设固定，失败不补调角度。预算四张新参考、四张新成片和四张对照图，每遍只用本机开发资产。环境光和已知朝向只用于诊断。
