# 参考换光与提亮的冻结特征诊断

位置候选压低误传，也压低了有意提亮与脸颊暖色。直接延长训练不能区分输入信息、特征压缩和训练目标。固定上一轮 18 个匹配方向和两折采集来源，检查有意提亮与真实换光在参考编码和渲染网格中是否有可迁移的方向。上轮所有成片继续保留。此次为开发诊断，不拟合新的调色权重。[上轮成片](../../docs/research/2026-11-24-positional-lightness.md)

- 逐方向固定 A 关态、B 实拍换光关态、A 有意提亮开态。分别读 4×4 下采样 RGB、13 号的参考 YCbCr 直方图和 4×4 投影特征，以及给同来源另一场景 0 档关态目标时的 13 号与局部候选空间网格。局部候选读取上轮同一折训练权重。上述两种网格包含普通目标图，前三种只读取参考图。均不读取目标真值或蒙版。
- 同一比较有两种离线输入。单参考模式使用当前参考特征；知道原参考的诊断模式计算当前特征减 A 关态，并按 L2 长度归一化，避免只按差值能量分类。单参考结果不使用 A 关态。两模式分别在 MIT 拟合、WildRelight 测试并反转。训练对重复的实际输入去重，每个场景和标签等权，参考尺度只从训练数据计算。测试保留全部已登记方向、平局和误判。
- 使用相同的线性岭读出，训练居中，按加权总体特征能量缩放，权重之和为一，正则 0.1，无调参。每折需要至少三分之二配对方向把有意编辑排在真实换光前，且独立去重后的两类平均符号准确率至少三分之二，才认定该表示有足够信号支持下一项开发。两个折同时满足才视为复现。比较和决策均仅适用于这批材料，出现低分不能证明其他模型或非线性读出一定无信息。
- 预算 30–45 分钟，包含两次特征提取和从落盘特征复算。若单参考过线，优先查清在哪一步保留或丢失；若只有知道原参考的模式过线，保留其作为额外信息的离线上界，后续以证据选择能估计原色的输入或方法，同时维持原两图工作流验收；两种都失败则先检查代表性和已知样本歧义。保留成人肤色、暖色和全部产品验收门槛。
