# 自动微调候选空间：仅离线诊断

这是主实验之外另加的离线诊断，不属于主实验的事前预注册，不更改主实验冻结源码、选图规则或画质门槛。最初文本在读取本次工具返回的分数和对照表前写入，但不能确认早于后台评分完成，因此不据此声称事前冻结。所有已有素材和历史基线成绩已消耗，仍不是盲测。

在主实验所有输出保存及评分后，对每例已保存的原基线及三个联合候选计算同一RGB MAE。另报告每例真值误差最小选项组成的理想上界，及其按同一门槛的结果。这个选择使用正确答案，只是判断候选空间够不够，不能作为可运行方法、产品成绩或无真值可达效果。

报告实际选择中：有改善空间却选差、没有任何候选优于基线、实际选择优于/等于/劣于基线的数量。距离差和误差差仅用于诊断，不改变阈值、参数或输出，不追加候选。

若连真值选项的理想结果都不够，下一步不能只改选项排序就声称能达到本轮目标；需重新设计颜色变换表示或候选生成。若理想结果足够而实际不够，则排序/风格目标是明确待解决环节。这两者都不证明局部语义理解。
