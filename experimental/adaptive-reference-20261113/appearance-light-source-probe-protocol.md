# 单张参考的冻结外观特征能否辨别真实换灯与有意染色

固定扩展第 4 轮已学习的参考图像编码器。本轮唯一变项是判别器读取全图颜色统计，还是额外读取已冻结编码器在整张参考图上的 128 个均值特征。源数据使用 CHROMA-MILL 已核验的四个训练场景、两档灯强，逐档由白／蓝实测线性通道均值比合成匹配的数字蓝调。匹配最大通道均值差 ≤0.02，裁切 ≤5%。每组正类为真实蓝灯，负类为匹配的数字染色。白灯仅作额外负控。两场景共四个 CHROMA-MILL 已有回归条件不进入拟合，Beyond RGB 两组匹配实拍同样不进入拟合。两来源均是项目已消费的开发素材，不称独立验收。

两臂均用相同标准化和线性岭回归，按特征维度归一的核、固定正则 0.1，分数零为固定决策线。只拟合训练来源，不调特征权重、阈值和正则。每份推理只读一张参考 RGB，不读取拍摄标签、配对图、目标图或标注。训练至少六个合格配对且来自至少三个场景。额外加入外观特征须在 CHROMA-MILL 留出组至少 3／4、Beyond RGB 2／2 分对真实与数字各方，且六份白灯／原图 0 次误触，并严格优于仅颜色统计的合格配对总数，才有依据下一轮试调色控制。所有拒绝和误判保留。此次不预处理软件参考，不更换或训练编码器，不以判别率替代画质。
