# PPST 作者权重首组真人照片验证

现有 13 号与生成全局色表在首组真人的脸颊和白幕无法同时保住原色与风格。PPST 的对应矩阵依赖源与参考的局部特征，生成器可按区域产生不同输出。固定作者源码 7d13291368e166442cfba50312faa41311c45391 及其公开 411,443,360 字节权重。只在本机研究，不用素材训练模型。不将生成式重建当作已经保持原片结构的调色。

固定 Gros 开发方向 01 ← 02，冷暖、风格关开四状态，附加同图重建作为负例。普通两图进入作者结构编码、外观编码、特征对应与解码顺序，风格插值为作者默认 1。对照冻结 13 号。作者训练默认 512 方图且对应函数固定 64×64，输入保比例缩放并以边缘值补成方形，输出裁掉补边再恢复原尺寸，保持所有原画面参与评分。两图均使用种子 48，PNG 结果用 80% 与目标混合。Windows 禁用编译算子，运行作者代码中的 PyTorch 实现。训练专用的损失、判别器和分布式入口不进入本地复现。推理网络权重按组件严格匹配，禁止随机填缺。

沿用已有整图、两颊及两白幕误差与风格门槛。同图关闭状态整图 MAE ≤3，并且成片灰度梯度相关至少 0.95，作为保持结构的必要检查。同样报告仅缩放补边再还原的对照与实际成片的相关。未全部通过则不扩大筛查、不改参数。两遍每遍 ≤120 秒。下载源代码、作者权重仅限此前核验的上界，不改现有依赖、代码和软件。
