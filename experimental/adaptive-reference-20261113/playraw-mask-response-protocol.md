# 用编辑器全覆盖输出核对局部蒙版的色度比例假设

现有固定色差从混合光照片的局部开关成片提取。拟合时按作者蒙版除以权重，隐含显示色度变化与蒙版权重近似成比例。本轮检验这条假设。新导出使用同一原片、作者 XMP 和 darktable 4.0.1，只把有效 RGB 色彩平衡步骤的混合模式从手绘蒙版改为均匀覆盖。原作者开态、关态和真实蒙版是已校验的本机输入。两次独立导出，不训练也不使用新数据。

用原有 80% 强度比较作者局部开态的实际色度增量，与均匀覆盖增量乘原权重后的预测。分区固定为权重 255、204–254、64–203 和 1–63。每区至少 128 像素才解释；权重 255 区 MAE 至多 1，零权重区 P95 至多 1.5，和均匀成片的量化重复差至多 1 作为控制。极小蒙版权重不做除法外推。

另用两个既有棋盘折的高权重像素计算均匀覆盖色差中位数，和原拟合向量比较。两折色度分量的平均绝对差都至少 1 RGB8，才将该比例近似视为下一轮值得校正的高权重监督误差。若只有过渡区超线或两折不一致，保留原方法的范围限制，不因此重启固定色差迁移。读数用于当前实拍编辑和处理顺序，不能外推到其他编辑或自动定位。
