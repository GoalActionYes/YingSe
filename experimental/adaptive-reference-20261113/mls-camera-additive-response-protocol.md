# 线性相机 RGB 的换灯增量能否改善跨场景重放

上轮按已知材质迁移固定对数色度增益，绿色塑料棒 04 原始取样稳定，仍只达到约 65% 的目标变化。06 的统计和出图均未达标。新假设是线性传感器上新增灯的响应更接近通道加法，因此可结合目标原片的已有亮度估算该灯对颜色比例的影响。本轮只替换供样估计，从供体的固定色度比改为供体双灯的线性相机 RGB 中位数差，结合目标原片的通道中位数换算为色度比。同一 80% 渲染器、原输入、内缩 8 像素掩膜、输出量尺及留出方式均沿用。供体的两灯分开统计，不配对像素。

固定原实验六个场景和供体归属。除留出场景外，同材质两场景平均，不同材质三场景平均，保留等权混合、零编辑及上一轮同材质固定色度对照。原图掩膜和有效曝光沿用原流程，每图分别计算未缩放、未编码的三维中位数。候选用目标原图中位数加供体增量，在值为正且不超原码值上限时换成 R/G、B/G 的对数变化。禁止符号钳制或逐例调参。渲染外部严格保持目标原图，记录裁切和出图曝光。保持对目标实拍响应的 80% 量尺。预先登记四个合格的评分场景 02、03、04、09。仍按原六场景报告，05、06 保留为位移稳定性不合格，禁止据其升级结论。本轮不是原中位增益的复跑，旧方案成片只作成对对照。

继续的条件是 04 同材质误差较旧同材质至少降低 15%，投影 0.75–1.25，且较新混合、异材质及零编辑均降低至少 15%。02、03、09 必须继续满足旧通过条件，旧同材质中位误差增加不得超过 0.015，两端分位误差各不得增加超过 0.02。所有皮肤、白墙和风格产品验证门槛均继续适用，但本轮的实验室材质不能给出这些成绩。运行两次 CPU 检查，保留所有成片和反例。若条件不满足，停止用供体固定 RGB 增量解释已观察到的场景差异。
