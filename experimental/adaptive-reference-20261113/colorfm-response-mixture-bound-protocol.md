# 现有三套输出能否用同一空间权重修正局部偏色

白球服目标的局部冷色响应不足，保留 ColorFM-L 空间特征也未解决。要判断已有模式是否有互补性，比较 13 号、ColorFM-L 全局和 4×4 空间版各自在基础与局部冷色之间的 RGB 增量。不同于旧 C10 实验的单一整图占比，这里允许每个位置有不同权重，但同一位置权重在基础、局部与整图参考三种输入中相同。这样才能检验固定的空间分配能否纠正响应，而不是在看到不同参考后临时更换输出定义。

固定六组原局部开关、三个已保存模型、80% 强度。每像素求三个 RGB 增量的凸包内到作者局部增量的最小 L1。非负权重和为 1。枚举三角形顶点、各边与任一通道误差为零的交点，以及内部两个通道误差同时为零的交点。每像素取最早的最低误差解，留浮点下界。三种参考共用解重新生成 18 张 RGB8 成片，再沿用原局部、整图冷色、无人检查；同时保留量化前下界和各原模型。每像素独立且使用目标答案，这个解不能用于实际推理。保留的固定权重下界无法覆盖随参考而变的空间权重、非凸变换或新模型。

如果背景核心的理论误差仍大于 3，或人物近中性色误差仍大于 1.5，则该例三个端点的固定空间混合不可能同时达到原门槛。解在量化后还须通过局部至少 3/4、整图 6/6、无人 2/2 才值得考虑建模；达到也只说明端点有潜力。由于只最小化局部误差，整图列仅检验该组解，整图不通过不能排除所有同局部误差的解。预算两遍 CPU、仅本机已消费开发图，验证哈希，不训练、不读取保留素材。
