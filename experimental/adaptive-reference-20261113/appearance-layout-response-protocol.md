# 现有参考外观能否传递局部编辑位置

上一轮的两组实拍镜像控制只交换参考里的 Film A 编辑位置，13 号四张成片显示每组两态完全相同。既有扩展第 4 轮检查点提供不同于全图颜色统计的参考外观编码。本轮只问这条现成路径能否把差异转成正确的局部编辑，或只是产生与答案无关的小变化。这是检查已停止候选可复用的能力，不追加训练、重新选权重、改人物掩膜或重启候选。

冻结上轮全部目标、参考和 80% 预期。用同一第 4 轮检查点和原尺寸渲染。比较完整路径及同检查点关闭外观的控制，后者仍保留原全图独立与联合颜色统计。两臂各四张成片。核对全图统计和输出。图像推理只读取原目标与一张参考，读回成片后再载入预期结果。评分区取此前定义的共同近中性色，另报整图。

事前门槛为：关闭外观时两个位置的输出逐像素相同，完整臂在两组的整图及近中性色换位置响应投影均在 0.75–1.25、换位置响应 RGB8 MAE ≤3，且每态的整图及近中性色预期误差各 ≤3。若只出现输出变化而未过画质线，保留全部例子，不把变化算为有效位置迁移。失败时结束这条冻结外观的候选资格；通过也只说明具备受控位置响应，再检查真实人物换背景与有意风格。预算每遍八次推理、两遍复核，保留素材不读取。
