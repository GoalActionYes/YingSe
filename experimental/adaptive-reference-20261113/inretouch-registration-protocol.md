# INRetouch 示例前后图的布局核查

前后图全局映射的拟合误差偏大。先确认原协议用的四对前后图是否有可检测的位移，或带不同色彩描述。本轮只读取已保存且哈希相符的八张 JPEG，无新下载、调色或训练。

记录原始尺寸、EXIF 方向和 ICC profile 哈希。按现有 RGB8 解码规则得到亮度梯度。参考项目已有对齐检查，使用签名梯度的归一化相关系数。原尺寸上以固定有效重叠区比较横纵各 −3 到 +3 像素的整体平移，同时按固定四象限复核。全图零位相关至少 0.90、零位为全图最高、且每象限非零位最多只比零位提高 0.01，才记为未检出整数平移。用一张已保存的参考原图构造横 2 像素、纵 −1 像素的控制，要求恢复对应位移。

若出现明显位移或 ICC 信息不一致，先限制此前逐像素结果的解释。若未发现，保留原先的诊断，同时注明检查不排除亚像素、畸变、裁切或偶然漏检。预算 CPU 90 秒，范围限四组公开开发样例。
