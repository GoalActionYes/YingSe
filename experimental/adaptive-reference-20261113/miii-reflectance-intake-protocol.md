# 核验实拍反射率与照明能否提供调色新线索

Film A 的两种单图识别方法会把参考背景或物体本色混进调色决定。考察 MIII 低分辨率实拍发布。它与只有逐像素照明的 FAU 双色档案不同，作者按原色和喷灰重拍推导了逐像素反射率与着色分量。本轮只回答一个问题：同一场景在白光和有色双光下，发布分量是否在实际像素上支持保留物体本色、单独测量照明变化。

使用作者官方非商业发布，先确认响应长度和磁盘容量，下载只限低分辨率 ZIP，最多 16 MiB。不下载深度或高分辨率组。按作者图 5 的白光 W1W2、有色 OB 及发布场景号检查配对。先核 ZIP 结构、全部成员名及内容摘要，再检查固定场景和光照格式。不取任何封存图，不训练或运行映色，实际原图和标注留本机。

对于发布中同时存在的 W1W2 与 OB，比较同一场景的实拍变化及对应反射率色度变化。可用区域须排除无信号的像素，按发布的线性编码检查相同尺寸、光照变更，以及该两态反射率的色度是否更稳定。固定至少两场景、各至少 1,024 个共同有效像素。以归一化 RGB 色度的平均差衡量，彩色光与白光原图差 ≥0.02，反射率差须不超过该差的一半。达到这些输入门槛才进入后续用普通 RGB 分离照明与编辑的诊断。该检查并不提供皮肤实测或作者的调色意图。

## MIII 档案未取得后的替代来源

DAST 作者公开样例含相机照片和色度仪记录。其变化是曝光与相机处理，不是 MIII 的换光。先核对官方 Git 固定提交的样例 ZIP 对象、成员和配对元数据，最多 10 MiB，只在本机检查，不访问需申请的全量。若样例存在至少两个不同参与者的同相机名义曝光与非名义曝光照片，并有可关联的脸部测量记录，则登记为后续肤色稳定性开发小样。先核对部位、相机编码、曝光标记和图像格式，无脸部像素配准或测点坐标时不做逐像素误差。只公开聚合计数和档案摘要，不公开图片、人物标识或单人测量值。该样例没有编辑意图，结果不用于独立画质或推断人口属性。
