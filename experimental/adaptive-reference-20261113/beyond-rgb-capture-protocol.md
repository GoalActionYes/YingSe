# 核对同一静物换灯原片的可比性

映色在跨场景参考中会让浅色墙面、灰白物体出现偏色。要诊断环境光相关的误差，需要同一组物体在不同光色下的实拍。上一轮基于测光记录，在 MIXED_organic 与 WHITE_rich 都固定选中灯号 6 和 13，照度差约 6%。这轮只比较这四份 Oppo 带色卡原片。不换灯号，不训练，不运行候选算法。

按已固定分卷索引按范围读取四份原片和随附标签及坐标，压缩传输上限 72,000,000 字节。校验 HTTP 206、范围、成员路径、解压长度及 CRC32，本地保留图像与原始标签。源数据许可为 CC BY 4.0，仓库只记录数值、方法与哈希。

先核对色卡中心、原片尺寸及相机标签。色卡几何允许偏移至多图像对角线的 1%。曝光以能够确认的快门、ISO、光圈检验，差值容许 0.1 EV，缺失就记未知。曝光不符时，可以记录变化及可用像素，但照度近似不能直接解释原片明度。对最后一排从浅至深的灰阶色卡，比较同一块的相机 RGB 中位数和归一化通道比例，成对保留白色和中间灰的裁切比例。要求至少三个对应灰阶色块在两图里都低于 1% 高光裁切，且有至少三块的归一化 RGB 欧氏距离达到 0.015，才认为这些原片适合观察真实换灯下的中性色响应。发布的 HDF5 已重建为三通道相机 RGB。固定记录色块中央区域任一通道达到归一化上界的比例，该比例仅用于三通道图像的可测性筛查。若只有重建数据，传感器原始裁切保持未知，不能通过原始裁切检查。曝光差按快门、ISO 与光圈的标签测算，不能替代对场景发光强度或传感器线性的标定。保留全部反例。此对照供开发诊断，真人肤色、真实白墙及视频另行验证。
