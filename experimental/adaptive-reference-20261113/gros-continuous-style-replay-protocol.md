# 从普通参考的风格分数连续重放颜色操作

已知双灯开关的正对照 6／6，旧单图模型留出 Gros 原样时全部回退。本轮保持同一历史训练资料、局部描述、配对惩罚和原分数，以原 0.65 硬选择为对照。新方式只把三个分数正值化后归一，按权重逐像素混合目标原图及目标上的两款固定 80% 颜色操作。目标图和当前单张参考为预测输入，调色标签、实际参考前图和正确成片不进入渲染选择。同图强制保持。此测试的固定操作只覆盖两款已知预设，用来检验不确定时连续迁移能否得到净收益。

固定已用三人、两种实际参考灯、原片和两款编辑，另测 JPEG 85。沿用 60 项每款风格投影、RGB8 MAE、关态及换灯门槛。候选至少应有新增完整方向，且旧原片保持和通过风格不能因持续染色失守。原片误差上限仍为 3，逐像素差也记录。两次复跑，现有环境，不将结果当普通开放风格验收。
