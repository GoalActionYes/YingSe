# 用灰度预测基准判断参考皮肤的整体冷调

固定同一批皮肤自动取样和留出照片规则，比较原始 D65 Lab b* 与相同像素的灰度颜色预测残差。原参考皮肤蓝红差无法控制人物本色。此轮新增的信息是只读明度的颜色先验，它不直接读取被检验的色度，也不直接预测编辑标签。原灰度对照检验背景与人物差，本轮只检验应保留的整图冷调是否作用到皮肤。

使用原 18 张冷色开关和八张 BG-REAL 参考。只对 BG-REAL 新算固定 ECCV16 灰度预测，沿产品参考分析用双线性缩到 256×256。冷色开关复用既有预测。自动皮肤范围从对应 256×256 RGB 独立取得，权重 ≥0.8 且至少 16 像素。记录中位数，取负 b* 为冷方向。沿用先前逐整组留出最大负例阈值，要求至少 3/4 整图冷调命中、0/8 有人负例、0/6 无人负例和 0/16 BG-REAL 不触发到触发的翻转。并比较和复核同图增量与跨图基线跨度。仅全部通过才进入出图实验。无任何阈值、颜色模型或尺寸搜索。两遍运行，每遍 CPU/GPU 总预算 90 秒，无网络。
