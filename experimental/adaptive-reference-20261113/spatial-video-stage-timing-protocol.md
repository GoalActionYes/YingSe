# 通过 13 号正常导出测量视频环节耗时

冻结 13 号 multiref 权重、选用已经验证过的人物运动短片和课程有声短片，复用已登记参考。每片以实际 HTTP 路径分别导出正常和计时两臂，强度 80%，开启现有时序平滑并沿用编码参数。无新画质算法。每臂使用新的本机工作台数据目录，避免分析缓存造成假收益。两臂必须保持 30 fps、相同帧数与尺寸、相同音轨存在状态，解码后的所有视频及音频帧哈希必须相同。未通过时不把测量视为正常流程的基线。

记录上传后分析请求、导出提交到完成和工作线程的总体耗时。只在验证脚本临时包装即有入口来记录工作线程内初始素材解码、每帧读取、分析输入缩放、空间网格准备（包含统计和推理）及逐帧变换。模型网格 GPU 调用另用 CUDA 事件记录。记录写入编码管道、关闭管道与等待子进程、最后媒体探测的耗时。管道读写耗时是父进程可见的等待，编解码可与计算交叠，不能当作纯编解码 CPU 时间。完整导出包含实际编解码；最终独立解码校验单列。任何耗时对照均为基线，不能当作新的画质、运动遮挡和切镜验收成绩。
