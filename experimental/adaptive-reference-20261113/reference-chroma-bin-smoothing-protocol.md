# 参考色度相邻档平滑是否减轻串色并保住风格

白球服换参考背景时，目标近中性色明显偏移。已有通道回放说明参考色度能传播这类变化，原尺寸统计仍未改善。本轮检验固定模型是否对邻近色度档之间的计数分配过于敏感。只改变参考 Cb、Cr 的 128 档直方图，按相邻档分配 1/4、1/2、1/4，边界溢出份额保留在原端点。Y、目标直方图、目标空间特征、权重、采样及 80% 强度保持。与原 13 号逐像素复现控制比较。

冻结四组实拍换背景 HSL／曲线开关及三个场景间的六向 Film B 开关，产生 28 张候选成片。既有开发图用于评分；推理只读目标原图及参考图。换背景保留原响应 0.75–1.25、保护区差 ≤1.5 的组内门槛，要求至少 3/4，且全部保护区最大差 ≤3。Film B 沿用整图及共同近中性色投影 0.75–1.25、响应误差 ≤3。至少须修复焊工两方向而不让任一开关响应误差增加超过 1.5 RGB8。另检查未编辑参考成片相对原 13 号的整图改变量，各方向 ≤1.5 RGB8。

重复一次并比对文件哈希。未同时通过时结束固定平滑作为候选，不换核追分，不触碰独立保留集。即使达到筛选条件，仍需其它画质和功能验证。
