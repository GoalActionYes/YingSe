# 显存失败后的激活重算验证

有效v3已完成22927／88391，第三例39532在第121次latent优化的反向阶段显存不足；外层已停止。GPU峰值约6.07GB，但不能从峰值分配断定驱动／碎片／其他进程占用的具体贡献。当前瞬时可用CPU物理内存曾低至约315MB，不优先将大量激活卸载CPU，不关用户程序。

本项仅检查作者已公开enable_gradient_checkpoint选项的执行等价与内存收益，不改变150步、模型、参考、损失或种子。先以同一已固定UNet、作者Controller及AttnDataCache测试：固定生成的1×4×16×16 latent、1×77×768文本嵌入、固定参考latent，模型F16冻结，前向自动混合精度与作者优化阶段一致。调用作者content_loss与style_loss，比较无检查点／有检查点两次的损失、缓存形状、输入梯度、模型参数不变及本进程增量CUDA分配峰值。

要求损失、输入梯度逐值一致，缓存形状一致，且有检查点的增量峰值严格更小。失败则停止该执行适配，保留差异，不降低数值条件。此测试不是完整512推理、自然评价或质量收益，不把小尺寸输入用于候选评分。

小测试通过后，在独立目录按原512流程重复已完成22927一次，仅开启该作者检查点选项。原512及256 PNG都必须与v3逐像素一致，才复用v3两例并继续未完成39532等记录；不覆盖v3、不重算已有质量分数选赢家。桥接若不一致，保留结果并先查差异，不作为新的调参候选。计算预算为测试一次加一个≤600秒桥接，不追加模型／步数／随机种子。
