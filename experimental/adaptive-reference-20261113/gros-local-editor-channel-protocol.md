# 暖灯局部调色的通道层次与跨人物出图

上一轮保亮度与颜色方向的统一色度压缩让暖灯双颊的编辑投影只剩 0.398–0.519。最近边界的离线控制投影足够，却把此前变零的蓝通道全部压成码值 1。浮点文件仍保存不同的蓝值。本轮只改变从浮点编辑差生成 SDR 样本的方式，验证逐通道的单调边界能否同时保住层次与幅度。停止此前色度压缩路线的参数调试。

- 固定六张原片、已落盘的 12 份 32 位 EXR、旧输出、作者操作、区域和强度。沿用相同线性编辑差和羽化范围。对每个通道应用带符号的 sRGB 编码，围绕码值 1 与 254 用一个事前固定的双端软边界，尺度为 8 码值。以该曲线在原片处的值作参照，确保零编辑保持。最终按 8 位量化。曲线统一应用于照明、人物和颜色通道。允许小幅亮度或色相变化。对照为原 8 位操作、浮点直接截断和上一轮色度压缩。
- 沿用关闭态及区域外逐像素保持、左右白幕不变、双颊色度变化中位至少 2 RGB8、相对原 SDR 编辑投影 0.75–1.25、全图新增端点不超过 2%。补足层次检查。三组暖灯原先蓝通道新变零的对应像素上，新的蓝通道 P95−P5 至少 2 码值，且至少有 3 个码值类别。两颊与直接截断对照的亮度 MAE 各不超过 3 RGB8，避免靠改变明暗让颜色脱离边界。每处保留原成片、数值和失败原因。
- 若至少两组冷暖同时合格，立即运行稳定 1.3 和 13 号全部合格跨人物互换。目标固定冷灯图，参考仅更换另一人的冷暖灯或开关。每次读取目标及一张参考。使用旧有 80% 强度、3 RGB8 端点／换灯／编辑响应门槛和 0.75–1.25 投影，实际保存所有成片和白幕保护结果。运行同图控制。开关答案、图像区域仅离线生成或计分，保留真实失败。无两组合格则止于素材，禁止改门槛。
- 本机 CPU，预计 20–35 分钟，无额外素材、下载、费用或模型训练。完整两遍复跑。本次是开发对照的充分性和既有两版本的实图诊断，无独立作者逐图编辑证据，不作为正式独立验收。达到开发准入后才据实际失败位置决定下一候选改哪里。
