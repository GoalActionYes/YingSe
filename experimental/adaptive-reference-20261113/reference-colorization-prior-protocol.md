# 灰度上色先验能否减去场景固有色差

白球服的离线冷色重分配已经说明空间分配有意义，但人物边界、固定过渡和单图视觉描述均不能判别自然参考的编辑意图。本轮用仅从明度输入预测色度的已发布 ECCV16 网络，为参考中可见物体提供与当前色度无关的颜色先验。此前 CanonCGT 底图使用已调色 RGB 做域归一化并拟合完整照片。本轮仅用 L* 得到每像素预期 b*，比较色度残差能否帮助判断局部冷色，不拟合参考原图或重渲染目标。

固定作者 PyTorch 源码提交 4f6009ed1495b1300231ebeb41cc4015557ddef7 和官方权重 colorization_release_v2-9b330a0b.pth，128,976,165 字节。只下载该权重、两个网络定义文件及 BSD-2-Clause 许可。已有 Python、Pillow、NumPy、Torch 与 CUDA 足够，不安装环境。用原 256×256 明度输入与作者网络，D65 Lab 转换按作者 scikit-image 的矩阵和白点实现，去掉 ECCV 定义未用的 IPython 调试导入。权重先核字节数和作者哈希前缀，加载用 weights_only。输入与资源保持本机。

使用原固定羽化 18 张及压力测试 24 张的冻结成片和单图自动人物概率。不读原图、目标、人工蒙版或同图其他版本生成特征。按 L* 每 10 单位分箱，在每个明度区间相匹配的人物概率 ≥.8、背景概率 ≤.2。两类各至少 64 像素才启用该箱。在各箱计算人物残差中位数减背景残差中位数，以两类像素数的较小值加权平均。要求总支持至少 256 像素配对，否则无判定。残差为实际 b* 减模型预测 b*。同一算式直接用实际 b* 作无先验对照。

原六组成片用既定整张原参考留一阈值规则。硬边与宽羽化的六张不同原始照片仅使用全体首批有人照片算出的单个冻结阈值。继续采用首批至少 3/4 命中、14 个负例零误触发、三组同图局部排序第一。第二批每种边缘方式至少 3/4 命中、16 个负例零误触发。无先验并行结果用于解释新增信息的作用。若失败，不使用本批素材交换先验、统计量或阈值追分。分析须区分原物体的实际本色与模型预测的合理颜色，原始内容均属开发素材。两遍各≤90秒，保存原分数、分割来源、先验哈希及全部判定。不接软件、不训练、不读取最终独立照片。
