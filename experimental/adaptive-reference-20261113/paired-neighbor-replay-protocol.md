# 从参考相近颜色读取变化，能否补回白球服的风格

加入三组同款实拍能扩大粗 RGB 覆盖，但全局三次拟合下白球服更弱，投影幕中的脸也出现过度与不足。若这些局部有足够细的参考色样，直接按 RGB 邻居读取变化可能比整张色表共享系数更合适。原近邻方法在两组 Film A 实拍对照上测得过收益，本轮检验它是否适用于两款、两背景及四组人物素材。

- 唯一改动是把四来源三次色表替换为已有 RGB 近邻重放。保持前轮四个配对来源、双线性缩图和 8 像素采样棋盘。按原近邻脚本把相同 RGB 的前后差逐通道取中位，再按八个相近 RGB 的距离加权。沿用该脚本的全范围估计，不加硬半径、来源权重或新控制项。三次拟合按来源归一化且逐通道过滤裁切，近邻按相同颜色合并自然样本且保留其原有裁切处理，比较的是现成映射方法整体。渲染保留 80%。评估时同时对照同输入的四来源三次色表和原单参考色表。
- 保留原有开发门槛。白球服两个背景的换款投影须为 0.75–1.25，响应 MAE 均须 ≤3 RGB8。其余合格区域相对原单参考不得丢失已有通过项，误差不得增加超过 0.25 RGB8。保留缺测及失败。该门槛用于决定是否继续该已知编辑的表示路线。
- 两遍固定运行，每遍 16 张成片、四张对照图及报告。联合通过后才考虑用它作为更可靠的已知编辑对照，检查如何从普通参考自动判断编辑。若失败，收尾固定四来源 RGB 近邻重放，不在这些样例上搜索邻居数、半径或权重。参考调色前后图属于离线输入，目标成片和手工区域仅用于评分。
