# 用近邻明暗检验 RAW 与 sRGB 暖调响应的差值

同一位作者、同一暖色操作和同一蒙版下，混光原片仍在 RAW 与关闭锐化的 sRGB 两条流程间出现色度差。这轮只检验普通 RGB 能观测到的近邻明暗是否能解释这一差值。上一轮数字色卡带有导入锐化，已有直接关闭锐化的 sRGB 对照能逐像素复原关态，沿用这份对照。

在实际混光照片的冻结全覆盖 RAW 和 sRGB 成片上，用每像素两种开减关的色度差作监督。以 8×8 棋盘块分两折，输入用同一关态 RGB。两臂都先拟合常数、RGB、六个二次项。主臂唯一增加原像素亮度减去 sigma=2 的高斯邻域亮度。固定 OpenCV 镜像边界、最小二乘相对秩截断 1e-5。训练用原图所有通道介于 8 和 247 的有效像素，每折只读一个棋盘半区的响应，另一半用于候选。已知作者蒙版只用于离线合成，同时评分。另将两折系数均值对第二张真实照片《Cuckoo》的两个已有缓存原样重放，目标成片和区域未用于拟合。

输出保留 80% 强度、规定色域处理及原亮度。高权重/脸颊/胸口 MAE ≤3 RGB8、投影 0.75–1.25，过渡区不超过旧固定色差误差加 0.25，保护区 P95 ≤1.5，范围外逐像素保持，Y′ 最大偏差 ≤0.5。主臂同时通过所有门槛且在两折各比同 RGB 对照至少少 0.25 RGB8，才支持近邻特征。两个已有《Cuckoo》区域误差的增量不得超过 0.5。保留未修正的原 sRGB 对照。每遍至多 9 张实际结果、三张对照，无重新显影、无新照片下载。此项针对已知作者操作，未验证普通两图能识别操作与范围。
