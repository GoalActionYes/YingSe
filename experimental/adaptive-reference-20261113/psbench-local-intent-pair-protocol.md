# PSBench 全任务局部调色配对核查

已有 600 任务的人像冷暖核查和 61 任务的局部调色抽查。此轮固定同一发布的 600 份本机任务说明，补查背景／天空局部去色、人物与非人物区域的局部颜色和明暗调整。目标是找到同一方向、作用于同类区域、且可从工作流核实为同一明确操作的两份不同拍摄内容。灯塔 230 是既有真实局部编辑单例，也是背景去色的定位对照。

先按固定照明／颜色词与区域词筛出说明，逐条复核。候选需核对几何、物体、纹理和其他色彩操作。仅文案相近时登记为线索，不能升级为同款配对。无下载整包、训练或使用独立集。

文本检查后、取得图像前锁定 516／530。它们都明确在中央约半宽半高的矩形内增加对比度，并保持外部不变。发布树合计四张 JPEG 3,022,046 字节，每张依 LFS SHA256 验证。双侧原尺寸需一致，像素诊断长边统一缩到 512。全图亮度梯度零位相关需 ≥0.95，且在上下左右 3 像素内无更优位移。中央 30%–70% 的保护边界内 RGB 增量均绝对值需 ≥3，距中央选区至少 5% 的外围需 ≤1.5 且小于中央增量的 35%。确认两源内容可区分。通过后可以做固定位置的跨内容编辑对照，作者操作参数是否相同需另有依据。

若前置检查通过，从供体中央区内的共同中间调拟合 Rec.709 码值亮度线性斜率与截距，把同一亮度偏移重放到目标 25%–75% 中央矩形。以 100% 强度直接对标作者成片。对照用全图相同偏移，不应用矩形。双向各两张，落盘后使用目标作者成片评分。联合门槛为两个方向分别在中央区误差相对原图至少下降 25%，预期明暗方向上的投影 0.75–1.25，外围误差 ≤1.5，并报告矩形附近的误差。若源图不符合必要条件，只记录图像诊断，保存原有范围且不强行拟合。
