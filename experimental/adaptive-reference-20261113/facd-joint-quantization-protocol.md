# 联合取整验证 FACD 参考亮度和色度对照

上轮 21 个 FACD 配对因独立 RGB8 取整只通过一组。固定所有指派、共同亮度计算、支持条件、目标评分、权重和 80% 强度。唯一变化是同档两张参考在量化后 Y 差超过 0.005 时联合取整。每个像素每通道只允许连续 sRGB 码值的向上或向下相邻整数；从两张图的有限组合中选择满足原亮度限制且六通道量化平方误差最小者。原本通过位置必须逐像素保持。无解时保持原量化并记录，绝不降低门槛。比较上一轮的覆盖率和通过结果。

若至少四种不同内容具备可评分输出，沿用从两种亮度和两种颜色条件计算的目标作者色度投影。只有同一滤镜在至少四个目标组的亮度主效应均 ≥0.5 且大于色度主效应，才记为该滤镜的跨内容亮度主导。其余有益、反向、交互和方向很小的现象一并保留。预先通过的 Hudson 组须保持原参考和成片。无新增采集、训练或软件改动。渲染上限 84 张，单次 GPU 预算五分钟。若仍不足四组，不继续修改本轮量化配方。
