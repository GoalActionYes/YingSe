# DaVinci Resolve 教程调色对照的来源核查

查第 7 课车库片段是否有可以按帧比对的原片与作者调色。冻结官方 Resolve 20 调色教材和第 3 部分练习包，先确认教材是否明确哪些镜头使用共同创意节点，能否保留输入输出色彩转换并单独关闭创意处理。只获取官方发布元数据和 ZIP 中央目录，档案响应体最多 256 KiB。核对精确的 HTTP 206 范围、总大小和对象标识；无有效分段响应就停止。检查目录是否有原始素材、教学工程、已渲染成片或可辨认的静帧。核对本机是否有可用 Resolve；不安装软件、不下载整包、不取档案成员。

若只有已完成工程，需验证同帧导出路径与练习条件之后才能取样。若同组的调色只以教学示范出现，记录其适用范围。未核实授权前，资产仅考虑本机执行官方练习，不纳入训练、再分发或独立验收。PST50 保留集保持封存。
