# WildRelight 浅色表面自然光交叉对照

要验证的缺口是，已有室内灯和背景换色对照在真实户外的光色、阴影变化下是否仍成立。固定作者发布 90ab579145da9f3ea998d706c8defd0d4b87641f、small-aligned、wall 与 pillar 场景，分别使用 time0 和 time5。四张照片、四张环境光图和两份采集清单，总上限 76 MiB。核对发布许可、大小及 LFS SHA-256，元数据核对 Git blob。仅限开发诊断，按整场景记为已用。相机位置、时间和环境光用于核查，环境光图不进入产品推理。真实拍摄可能包含阴影移动、环境移动和配准残差；不把它归因为单一均匀色偏。

统一以各自 time0 的线性亮度 P95 决定曝光，使其压缩到线性 0.8，time5 不重新曝光；应用 x/(1+x) 和 sRGB 编码。照片先核对有限值、动态范围和时序共同有效区域。沿用 13 号 80% 强度，用另一场景的首末实拍分别关闭或开启同一 Film B 作为单张参考。目标固定首时段。用 13 号的四态实际成片比较参考换时段和参考同一时段开关。目标预期由同一 Film B 和同一 80% 强度生成，人工登记的浅色表面矩形在渲染前固定。评估整图、浅色表面，沿用冷暖灯交叉的换时段偏差、关态偏差、风格误差 ≤3 RGB8、投影 0.75–1.25。两场景无皮肤评估，不代替独立验收。目标只读目标原图与单张参考，人工区域只评分。

每遍最多八张目标结果、两张对照，另保留四张基础显影与全部输入身份。渲染前检查浅色样本及相邻内容对齐，若出现不可用时段或区域可见遮挡，记录缺测，不事后换时段。这轮是预先固定的新来源基线，不用失败样本训练。
