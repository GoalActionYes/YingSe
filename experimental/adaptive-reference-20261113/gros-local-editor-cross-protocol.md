# 用真实换灯与有记录局部操作验证两图参考

上轮取得三组新的冷暖灯照片，两组同快门。旧跨灯 Film B 对照是全图预设，不能说明仅改肤色、不碰白幕时会发生什么。本轮在已知两个实际灯位的原 JPEG 上，首次交叉一项真实作者的局部调色操作。只测试能否取得可解释的四格对照，以及稳定 1.3 和 13 号会不会把局部有意改色与拍摄光一起搬到目标白幕。不改模型和现有产品。

1. 冻结六张原件和坐标。使用上一轮签名的作者原 XMP 第 28 项 RGB 色彩平衡和同版 darktable 4.0.1。测试以已呈现 JPEG 为输入，统一为 1024×683 sRGB8 TIFF。关闭自动锐化，在全覆盖条件下导出开关两态，两 XMP 内容只差一个启用位。关闭态须逐像素等于输入。外部用同一组内共用的羽化椭圆合成，从原图预先登记，白幕不参与确定参数。完成的六对仅为作者操作离线重放，由本项目确定新位置；原作者未对新照片逐张修图，旧 RAW 效果不得当作这里的答案。
2. 资格检查沿用已有局部作者编辑开发要求与区域筛选。两颊色度改变量中位均至少 2 RGB8，至少 128 个样本，白幕及蒙版外逐像素保持。两种灯下全图新到端点的像素均不超过 2%，并报告区域 P95。记录预先圈定的两颊与左右白幕；人工标注和开关真值仅用于本机生成对照与评分。任一条件失败则保留该组实测但排除出主比较。少于两组合格时停止基线出图，不调门槛或改作者参数。
3. 对合格人物间全部互换方向，保持目标冷灯图不变，参考分别来自另一人的两种实拍灯位与两种开关状态。两版仅输入目标和单张参考，强度 80%，无手动微调；目标的开态按相同合成操作取得，再以软件固定的 80% 混合。原 3 RGB8 关态、换灯与编辑响应误差上限和 0.75–1.25 方向投影继续适用于有效编辑区。白幕预期零改色，两态都直接对原片，沿用 ≤3 RGB8；不计算零信号投影。保留整图的方向及开态实测，不能据此覆盖任一局部退化。两版检查同图保持、逐方向保存成片及对照。全部组合复跑，重复结果按实际报告。CPU 专用，预算 45 分钟，无新增下载、付费或训练。
4. 通过说明形成一个固定操作的交叉开发对照。原件和所有重放只作本机开发。该受控小样无独立作者逐图编辑证据，不据此解除联合训练准入，也不进入正式独立评估或产品发布。如果基线两类误差可以分离，作为后续候选的实图指标，若不可解释，保留限制和反例。
