# 目标受光能否提供跨内容的换灯位置线索

跨内容按坐标传递参考光照时，同灯设置也会改变目标杯子颜色。只计算一个全图比值则无法复现局部红蓝换灯。本轮问一个必要条件：已知灯光操作时，目标图的估计照明色度能否预测各位置应改变的方向与幅度。

固定两次留一场景验证，分别以 bmug 和 bpmug 的 b_r 到 r_b 照明标签做离线校准，在另一组评分。候选用截距及该图自身估计照明的 log(R/G)、log(B/G)，线性预测照明对数比变化。对照只用截距，即校准组有效区的平均变化。仅校准组使用两张真实灯光标签和既有有效范围。测试组推理只使用 b_r RGB、该图的冻结估计照明和另一组已拟合参数，无参考位置、测试标签或蒙版。渲染沿用整图 80% 色度重放，同图的恒等渲染另外检查。保存两组共四张预测，再做测试组离线评分。不做调参或训练新模型。

使用之前固定的换灯有效区、近中性色范围和原换灯门槛。必要条件为四项均合格，且两个近中性色误差各比只用截距降低至少 15%。全部通过也只支持探索如何从参考推断操作，尚无参考意图识别及同灯抗干扰成绩。任一失败，停止用该照明表示和固定线性校准直接决定空间换灯，保留跨场景误差供后续判断。预算为本机 CPU 两遍，不新增数据、下载或 GPU 推理。
