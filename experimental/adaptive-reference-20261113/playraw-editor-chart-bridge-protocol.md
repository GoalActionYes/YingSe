# 真实局部编辑：按编辑器的关闭输出匹配调色增量

作者参数直接用于 sRGB 导出图时，《Cuckoo》肤色改善，但原混光照片高权重区仍超线，关态也改变像素。待验证问题是，目标 RGB 应该在进入编辑器前匹配，还是在关闭编辑器模块后的颜色空间匹配。

固定原 darktable CPU、作者参数和 sRGB 输出。按 R、G、B 各 32 档生成色卡，每种颜色占 4×4 像素。导出同一色卡开关状态，再把色卡的颜色顺序倒置作为位置无关控制，两种布局对齐后的样本逐通道差最大须 ≤1 RGB8。对照以输入色卡 RGB 寻找近邻，主臂以关闭输出 RGB 寻找近邻。两臂固定同一开减关的色度差、四近邻与反距离权重。近邻只在 RGB8 空间寻找，使用固定单线程查询，反距离权重的距离下限为 0.001。记录距离超过 8 RGB8 的查询比例，同时保留所有查询参与评分。用项目已有色域处理与 80% 强度合成，目标原亮度保持。两张真实照片、蒙版及预期使用原冻结归档。涉及目标作者结果的读取仅用于离线评分，登记区域用于本轮已知边界的重放。

沿用原混光两折高权重区、过渡区和《Cuckoo》两套缓存的脸颊、胸口、保护区。高权重和肤色区误差 ≤3 RGB8 且投影 0.75–1.25，保护区 P95 ≤1.5，区域外逐像素保持，亮度差 ≤0.5。过渡区误差不超过此前固定色差的结果加 0.25。仅凭真实图满足全部门槛才支持更换匹配坐标；固定色卡不用于打开产品入口或改变既有验收。两臂未通过则结束固定色卡近邻桥接。每遍四次色卡导出、六张真人结果、三张图板，无训练、无新照片下载。
