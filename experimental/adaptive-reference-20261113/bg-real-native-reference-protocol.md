# 检查参考缩图是否吞掉曲线与颜色编辑

白球服对照中，参考图有可测的明暗变化，而 13 号只传了约四分之一。本轮检验 256 × 256 双线性采样是否在生成参考直方图之前丢失了这项信号。现有资料确认目标路径和参考路径均有缩图，但以前的原尺寸渲染不等同于用参考原尺寸统计。

仅替换参考直方图的采样尺寸。比较 256 缩图与同一参考原尺寸，分箱、转换、权重、目标输入、80% 混合和目标区域保持不变。冻结上一轮四组开关和背景实图，所有 16 张缩图对照须逐像素复现。每臂 16 张成片，仅使用已有 GPU 环境。记录参考直方图的开关总变差，以及沿用前轮的目标 Y′、Cb／Cr 投影与人物和近中性色跨背景差。原尺寸条件只读取这两张测试所需图像，没有读真值蒙版来预测。

沿用原风格门槛 0.75–1.25、保护差 1.5 RGB8 码值、至少三组联合通过且保护区最大差不超过 3。即使整体未达标，若八项明暗投影中至少六项向 1 靠近不少于 0.20、且保护差相对缩图没有增加 1.0 码值以上，才保留缩图损失为值得下一轮验证的线索。若逐像素对照失败，不解释候选。若两项条件都不满足，停止将参考尺寸作为主要修正方向，不改变产品路径。
