# FAU 双光源实拍与标注入库检查

S24 蒙版给出了次光源区域，但缺少对应的颜色真值。本轮只检查 FAU 公共档案是否提供可直接关联的实验室混合光原图、逐像素照明及光源影响图。它可以隔离实际光照线索，不能单独评定自然参考风格。

从作者发布的唯一低分辨率档案获取 42,311,680 字节，上限 43 MiB。保留原档案与 SHA256。先读完整成员索引，只处理普通文件，以脚本读取成员字节，不直接解压整档。只取按文件名可配对的实验室子集，选按原始场景名排序的前两个不同场景、每景按名称最早的完整组合。若无法凭目录和格式确认两个场景，保留纸面及索引结果，不以外景近似标签充数。

核验尺寸、编码、数值范围、非空的双光源空间变化及标签语义。成片或标签缺失、尺寸不一致或整图光色恒定均不得作为本轮可用场景。若满足条件，登记可测空间范围，为后续根据光照真值验证算法预备开发小样。本轮不训练、不打开独立保留样张，也不把素材的有效性当作软件画质收益。按作者要求引用，媒体留在本机。
