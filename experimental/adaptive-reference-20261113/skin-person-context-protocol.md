# 整图人物及躯干线索能否阻止画中人误改

半幅裁切恢复了一些小脸，也使投影幕脸完全入选。之前屏幕类别和外缘均有真实反例。本轮检验独立全图人物定位能否给脸部范围提供额外上下文，复用已核验的 DeepLabV3 MobileNetV3 Large。保持 18 张场景／程序暖色输入和裁切掩膜，再加已登记的三张屏幕人脸和两张同框真人。额外五张沿用原实验的源尺寸与皮肤高低阈值。人工范围只用于事后评分。

全图人物概率 ≥0.50 后，比较直接人物交集与带躯干判断的交集。后者对八连通的原脸部区域找重叠最多的八连通人物区域；在脸框下方最多两个脸框高度内、向两边各扩一个脸框宽度的矩形中，若同一人物区域像素不少于当前脸部区域的像素数，则保留交集，否则回退该脸部区域。条件对所有图一样，不额外补裁切未选中的像素。分辨率、矩阵基底与已有修正保持。主18张从裁切成片回退被过滤像素，新增五张沿用已登记的固定 RGB 偏移重放，仅作范围对照。

门槛：18 张设置继续报告原 22 项，其中两个已经漏检的远处脸颊状态须原样记录，不作为本轮可新增覆盖的对象；不得令其余既有达标真人、保护区或 DAST 核心失去资格。投影幕两态及额外三张屏幕脸的触及 ≤1%；额外两处真人高权重覆盖 ≥80%。主比较用同一裁切基线，区分整图人物交集及躯干约束的作用。若任何屏幕或真人要求失利，结束两种固定上下文开关。仅做本机两遍离线 CPU 重放，不新取模型或照片，不计入独立或产品验收。
