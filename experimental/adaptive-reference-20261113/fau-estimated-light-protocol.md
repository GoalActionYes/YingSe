# 只用 RGB 的空间光照估计能否复现实拍变化

FAU 逐像素照明真值重放通过四项色度检查。本轮检验新的实测条件：一个现有普通 RGB 光照估计器能否在无需标签时复现其中的相对空间变化。Marigold 的旧背景合成干预已经失败，不改旧结论或再跑旧对照。已发布的五预设融合模型需要同图五种 WB 渲染，不能冒充普通两图入口。

固定增亮后的 FAU 两场景，一张目标和同机位换灯参考。分别用本机固定版 Marigold IID Lighting 估计 RGB 光照，沿用原桥接参数和随机种子。取估计光照通道比的变化，使用上一轮保持目标线性亮度和 80% 强度的重放。估计值下限 1e-4。空间比值与整图几何平均共用同一重放，覆盖全图。两者都不读取真值、暗区蒙版或目标效果。全量输出落盘后才做离线有效区域评分。比较既有 13 号、测量标签重放和普通两图估计。该同机位实验只考察信号与画面响应，不能推出不同场景可逐像素配对。

四项有效区域须通过原方向投影至少 0.50、误差相对原图降低至少 10%，两组中性色须比全图估计误差各低至少 15%。同步记录照明比值方向与测量标签的余弦、下限触发、裁切以及同图恒等。两次本机运行，保留所有结果。未达标时结束该估计器作为当前路线的输入，不搜索种子、步数或强度。
