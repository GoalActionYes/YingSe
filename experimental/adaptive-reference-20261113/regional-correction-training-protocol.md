# 全局加区域残差修正：匹配训练前冻结

原因证据：参考色度条件传播已通过固定输入重放确认；直接把区域直方图输入旧主干的历史试验失败。新候选显式学习修正，而非复用整图模型解释陌生区域输入。输入准备发现精确回退仅覆盖开发28例，原方案不启动。本设计必须覆盖全部64例，不降低40例改善的要求。

输入为已审计1365项区域缓存，使用既有train1024／development64全部配对。GT仅供训练监督及预测保存后的评价，不作为推理输入。当前13号主干冻结，缓存原始浮点满强度输出，准备时逐个验证实际RGB8基线。基线、颜色权重、分割状态及输入哈希固定。

两臂同初始化、同参数量：1154维目标描述、参考描述与差值拼接为3462维，经Linear3462→128、GELU、Linear128→36，末层权重和偏置全零。候选使用真实区域描述；控制只把人物／背景384维块替换为同图全局384维块，保留相同支持度。两臂均使用相同自动目标人物概率，不使用人工标注；无可靠支持的区域信息显式保留零值和支持度，不删除样本。

36个输出解释为全局、人物、背景三组3×4仿射残差。输入像素采用归一化RGB及常数1，先计算global(x)+p*person(x)+(1-p)*background(x)，再乘0.1*tanh限制总残差，叠加原主干浮点输出。全部配对均可学习全局修正；没有人物时p接近0但不强制整个输出回退。先验证零初始化与关闭时输出完全恢复原版、概率端点、界限、梯度、缓存及状态身份，再开始训练。没有证据时不增加局部合成监督。

配置固定seed20261127、AdamW lr1e-4、wd1e-4、batch4、8轮各256更新、裁梯度1；沿用grouped_batches，两臂同一随机流和预算。损失为RGB L1加0.1横纵梯度L1。只按全部64开发图的平均RGB误差选轮，包含零轮，平局取早。保存全部轮和失败，不改seed、幅度、层宽或支持阈值追分。

沿用完整开发门槛：候选对当前版均值改善≥5%、≥40/64改善>0.1、明显退化≤2；新增参考32图均值不退步且≥17改善。对匹配控制均值改善≥3%、≥36/64改善、明显退化≤2；32组delta均值改善≥5%、≥20组改善>0.1。明显退化仍指增加>5且>25%。额外报告全局色度、人物／背景及无支持组的输出，不能只看支持子集。全部预测先保存再读开发GT评分，不将分割支持率作为质量门槛替代项。

通过才冻结新的独立画质与完整产品验收；失败保留该固定配方并停止，不做自动逐图回退。不代表语义理解、剪映恢复或实时视频。部署时须计入在线分割与描述器耗时，普通CUBE不能保存空间效果。代码、测试、协议和小型数值公开；图片、概率、数组、权重和环境留本机。
