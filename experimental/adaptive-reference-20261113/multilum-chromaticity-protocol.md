# 实拍换灯位的色度诊断

判断两个实拍换灯位对照是否提供可用的偏色信号。全局 RGB 误差同时含曝光、阴影及色度变化。这里检验去除等比例线性 RGB 增益后，已观测的软件反应是否仍与实拍色度同向。

复用两房间共四张实拍 JPG 及上轮 13 号输出四张 PNG，核对公布哈希。不生成新图片，也不读取更多素材。区域为整图和上轮定义的目标近中性色。只在实拍两张图均三通道处于 16–239 的像素上测量，并报告其占各区域的比例。候选输出中的低值或高值保留在评分中，另报告比例，避免输出退化使像素从测量中消失。

按 sRGB 曲线转线性值，用同一个 8 位码值对应的最低线性值截断对数输入。色度以 log(R/G) 与 log(B/G) 表示。线性 RGB 同比变化时这两个分量保持不变。分别记录实拍变化向量与软件输出变化向量的 RMS、向量误差和朝实拍方向的投影，另外记录线性 RGB 加权亮度的 log 比值 RMS。保持图像不变的色度误差等于实拍变化 RMS。60 秒 CPU 上限。

诊断资格事先固定：近中性色两组各有至少 50% 像素保留，且实拍色度 RMS 均达到 0.05，才将这一对照继续用作色度开发诊断。若有一组不满足，停止扩展此灯位组合用于偏色判断。即使有色度信号，实拍是光照与相机成像记录，不能给出自然画质或肤色真值；全部原验收门槛不变。
