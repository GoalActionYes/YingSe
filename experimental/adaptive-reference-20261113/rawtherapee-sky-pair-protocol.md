# 取得两个可开关的真实天空局部编辑

一张参考只给出颜色结果，缺少「局部编辑开关」会让背景物体色与编辑混淆。既有 Windows darktable 路径未输出冻结 XMP，本轮使用另一种编辑器原生记录。固定两个公开主题中独立拍摄的 RAW：Tamas Papp 的 P1005231 与 Karl 的 R6_06283。只取 Sunhillow 第 16 楼、Martin Werner 第 2 楼直接公开的 RawTherapee PP3。核对原件的措辞、授权及有效局部字段。两份 RAW 为 CC BY-SA，本机研究保留归属；不上传照片、设置、运行时或重新发布成片。

PP3 两份共不超过 64 KiB；复用已核验的 P1005231，额外 RAW 上限 16 MiB。若两个设置均确有局部编辑，且可获得官方 Windows x64 5.13、大小不超过 128 MiB 且 SHA256 匹配，使用隔离解包运行命令行，不安装或替换已有应用。先确认原作者设置可导出。对每份设置，仅翻转 `[Locallab]` 的启用位，两份其余字节须一致。记录具体局部参数，若它启用了多个工具，称为关闭局部操作组。两组共享的是压暗天空的意图，不能凭参数名称认为编辑量完全相同。

固定边界：关、开都须落盘为同构图 sRGB 图，重复导出像素一致。对关态预先记录天空和前景位置，再测开关亮度差；不以输出差反选位置。天空中位亮度下降至少 2 RGB8，前景亮度绝对变化中位数小于 1，并保留蓝天、树边或建筑边反例。若某组不满足，仍记录两组成片，不把该组作为同款局部监督，不进入映色推理或独立验收。输入和软件获取不足时停在可核实步骤并记录实际阻塞。

从关闭态登记分析矩形。坐标是图像左、上、右、下的归一化位置，按四舍五入取像素边界。天空门槛用中心清晰区域 `sky`，前景门槛要求两个登记区域均通过。侧向天空和树／建筑边均保留读数，不参与改选主区域。原作者文件字节就是开态；先导出关态以便盲标区域，再启用原作者开态。
