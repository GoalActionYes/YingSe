# 同一组 HSL 与 RGB 曲线能否跨参考背景保留

白球服在旧的固定分位数实验里能恢复冷调，对比度仍会丢失。旧真值是互相分开的色度偏移和线性对比度。本轮唯一变化是用软件现有手动调色器定义一个同时包含色相选择和非线性曲线的可重复编辑，检查 13 号是否能从成片中同时继承两种变化。源照片为已消费实拍开发图，真值为可控后期出图。

沿用四组 BG-REAL 开发对象、对应的 C1 和 F1 背景、13 号原模型及 80% 强度。编辑开启使用蓝色 HSL `[-35, 35, -12]`、青色 `[-20, 20, -6]`、绿色 `[15, -15, 0]`，RGB 曲线 `[[0,0],[.25,.20],[.5,.5],[.75,.80],[1,1]]`。关闭为默认参数。不调参。目标与参考不重设留白和伽马，保留已有准备流程。每组四个模型输出，最多 16 张，CPU 四线程，禁止训练、下载和独立验收集使用。

参考只送开关后的 RGB 与目标原图，不给模型原参考、区域标注、参考开关标志或目标成片。对比是同参考的开关输出差，与目标直接执行同一编辑的 80% 差。按 Y′、Cb、Cr 分别量化方向和幅度，Cb、Cr 由蓝、红通道扣除 Y′ 后缩放得到。两种背景下整图的 Y′ 和合并 Cb／Cr 预期变化绝对均值均至少 1 码值才给方向结论，合格方向投影须在 0.75–1.25。对每种输出开关状态，目标人物和近中性色代理的跨背景 RGB 平均差须不超过 1.5 码值，区域至少 256 像素。人物是全身范围，近中性色另外报告全图与人物内，不能当作独立肤色真值。

案例须在两个背景满足有效风格响应及背景稳定全部条件才通过。至少三组全项通过且没有超过 3 码值的合格保护区变化，才将这组复合编辑作为本轮联合通过。弱信号按缺证据保留，不能判通过。若失败，保留全部成片，区分模型丢的是明暗、颜色或背景稳定，不据此调参或训练。若通过，再补明确的皮肤与墙面区域及独立内容，当前开发结果不能作为产品验收。
