# 固定高斯核条件预测对照

目的：检查目标/参考输入到条件参数的非线性是否有用，不继续调上轮失败判断器阈值。两组均使用同一H128目标/参考/差值＋128颜色上下文，训练RMS与训练标签保持。控制为既有线性HC回归；候选预先指定为高斯核回归。

固定训练1024和已消费开发64。构造原设计X，距离为平方欧氏距离；σ²取1024训练设计两两距离严格上三角的中位数（不按开发或GT选）。K=exp(-d²/(2σ²))，训练K按行/列/总均值中心化；开发核只减自己的训练列均值与训练K列均值、加训练总均值。Y只减训练均值。λ=0.1trace(Kc)/1024，固定解dual=(Kc+λI)^(-1)Yc。预测截±3，不搜索核宽/λ或新增特征。

保存核宽、中心统计、dual和条件预测。全部64图基线/线性控制/候选输出先保存，再读取开发GT像素评分。基线与线性控制须和既有对应PNG哈希相同。新预测器训练使用训练GT条件，不使用开发GT条件。原映射主干冻结。

沿用完整门槛，并以同输入线性HC为更严格匹配控制：候选比当前13号均值降低≥5%、≥40/64改善>0.1、明显退化≤2；新增参考style1均值不退步且≥17/32改善。比匹配线性HC均值降低≥3%、≥36/64改善、明显退化≤2；32组delta均值降低≥5%、≥20组降低>0.1。明显退化为同时增加>5且>25%。全部通过才另设计独立质量和速度评价；失败不更换核宽或从多个核结果中挑选。

当前开发数据已消费，不是独立泛化验收，不证明语义理解。推理与核拟合时间单独记录不能代替完整App或视频性能。普通CUBE仍不保存完整空间效果，不修改产品。
