# 近场实拍人脸是否具备可隔离的灯色配对

当前要测的是只改变参考的人脸照明颜色时，目标肤色和浅色表面是否稳定，且真实的创作染色仍能迁移。核对作者 near_ps 仓库中两组真人、八盏独立 LED 的拍摄资料。只读取固定提交的树、研究用途说明与 `light.mat`，不下载照片或运行作者重建程序。

校准文件匹配树中的 Git blob 和大小。分别计算 28 对灯的线性 RGB 强度向量夹角和 XYZ 位置距离。若至少一对有可测色差（RGB 角度 ≥3°）且位置距离 ≤5 mm，记为近同位置候选，仍需按原拍摄家族核对相机与姿态、源图以及照明模式。阈值仅用于优先挑样片，不是产品门槛。若不满足，按近场换方向资料处理；同场景多灯数据不得标作只换色。保留静态脸部方向光用途与限制。报告使用已有 SciPy，在固定仓库清单上重复两遍，不增加训练或软件功能。
