# 真实局部调色是否需要随输入颜色变化

同一原片的几何重放可以恢复作者局部颜色。不同照片没有像素对应，需要先知道真实编辑是否可由跨像素共用的变化描述。比较固定色度偏移与由原 RGB 条件决定的仿射色度增量。

- 沿用已核验的开关图与作者蒙版，目标为原关态，已知效果为 80% 作者成片。用原尺寸 8×8 棋盘两半做双向留出，每次只用其中一半的 ≥80% 蒙版像素学习。两臂均先以蒙版权重归一化训练变化，再按目标位置权重重放。固定臂取训练色度变化逐通道中位数。候选用常数与标准化 RGB 拟合两个色度分量，非截距岭系数 0.01。保留原始目标亮度与零权重区。作者蒙版只用于离线拟合与重放边界，属于正控诊断。
- 两个留出折的高权重区投影须为 0.75–1.25、响应 MAE ≤3 RGB8，且候选较固定偏移每折 MAE 至少降 0.25。过渡区单独报告，候选不得增加超过 0.25 RGB8。零权重区必须逐像素相同。通过仅支持开放内容开发时用输入颜色条件描述编辑。失败则保留两种表示的误差，不调岭权重或更换分区。两遍各四张真实原片成片及报告。
