# 作者局部去色的空间与幅度分离：运行前协议

此前自动分割和局部特征对应都弄错保色范围。同一 RGB 的全图查表也已有反例。这里不再改变范围预测，改问：如果区域完全正确，两份编辑之间共享的「去色幅度」能否迁移？

固定 PSBench 145 和 248、长边 512、相同 RGB8 输入及 80% 用于目标与参考效果。使用原实验的高支持去色／保色区域。对照：在目标已知去色区使用固定 0.8 色度减量。试验：只在另一张参考的已知去色区，用作者 80% 成片拟合一种共享的色度保留率；在目标去色区使用该值。两臂都保留目标明暗、保色区及未测区域。另报告本地作者拟合的最小平方解作离线上界，不作候选。比较另两个原模型输出仅作为区域分数对照。四张重放另存。

沿用去色投影 0.75–1.25、响应误差 ≤3、保色区开关变化 ≤1.5；为区别抵消原错误，另记录去色区实际与作者绝对色度误差。两个方向都满足这些门槛且相较固定力度有至少 0.5 码值的去色误差收益才支持继续拟合幅度。若两臂都满足但拟合增益不足，优先恢复位置估计。所有已知区域及参考前后都是离线信息；没有正常双输入或独立验收成绩。
