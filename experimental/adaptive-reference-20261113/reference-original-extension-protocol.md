# 新增真实参考原图的有界变换诊断

问题：扩展4096训练中新增可用的参考原图是否也能给出可迁移的颜色变换，还是旧75条的结果仅限于很小的配对范围？这不是新模型训练，也不是重启旧增强或残差头。

绑定`reference-original-coverage-v1`的两份清单及报告哈希。按扩展cohort原train顺序，排除旧75条已测index，要求原图在扩展训练content中且已准备。取前64条目标content互不相同的合格记录；不按GT、文件风格后缀或误差选择，数量不足则停止，不补保留图。详细选择在运行前固化，所有64条保留。

唯一方法复用旧`run_reference_transfer.py`的guided_global特征、32像素棋盘块两折、ridge1e-5、原multiref-v1冻结guide、两折系数均值。参考原图／调色参考用于估计；同一系数应用目标原图。目标GT只在全部预测保存后用于评分。只读严格核查参考原图与参考尺寸，尺寸不一致报错，不做配准变形；相同尺寸仍不等于证明几何配准。

保留参考两折重建、目标迁移、当前基线的RGB8、系数与哈希，不比较多项新特征、不调正则或阈值。原脚本仍保留不修改其已冻结历史实现，使用独立扩展入口。先用一条旧诊断记录校验桥接与旧存档逐像素一致，只作迁移实现验证，不混入新64条统计。

诊断报告参考跨折误差、目标迁移相对当前基线的逐例误差与退化、全部失败及覆盖范围。继续研究监督任务的必要条件：迁移均值至少改善5%、至少40/64改善>0.1、严重退化（增加>5且>25%）最多2例。该条件沿用已有最低画质筛查尺度，不是产品通过资格；未过则不训练该来源的预测器。通过也先解释为什么这些额外信息能作为训练监督、正常两图推理如何获得对应表示，不能凭oracle成绩启动原失败头或宣布升级。

总预算64个新增训练目标加一项历史桥接，不读新独立像素、不下载资产、不训练、不修改软件。数据、额外原图、系数和媒体不上传；源码、协议及小型数字按一个完整诊断阶段提交。人工反馈可辅助，缺少填写不阻止本项执行。
