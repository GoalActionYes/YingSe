# 明暗与色度边缘方向能否提供换灯线索

整图分位校准无法区分有意染色和实拍灯色。已有边缘幅度、平滑区域色比和冻结视觉空间特征均未跨来源可靠触发。这里唯一改变的是单参考描述。对缩至长边 256 的 RGB，分别在两种差分距离计算线性亮度和两个对数色比的局部空间梯度。给强明暗、强色度边缘分别统计两种色比梯度与明暗梯度的绝对方向一致度中位数。依据是部分受光边界会同时改变颜色和明暗。材质边界也会同向，检验方向和尺度能否提供足够信号。只使用未裁切、梯度有信号的像素。描述只读各自单张图，无区域标签。

复用四来源固定归档，按来源留出，用原最近中心规则拟合另外三源。每个来源需实拍识别 ≥75%，原参考与数字编辑零误触且无缺测。再沿用 MIT 两张独立目标上的同一诊断回退比较，所有区域按原门槛通过才进入幅度估计。数字编辑与原参考应保住风格。停止条件是任一来源不合格或发生静物、人像输出退化。运行两遍，CPU，不训练渲染器。
