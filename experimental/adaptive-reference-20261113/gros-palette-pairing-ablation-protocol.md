# 去掉逐像素对应后，联合 RGB 颜色分布能否重放风格

原配对试验有正确的原片与成片对应，且六个跨人物方向能通过。历史单通道分位迁移没有保住联合颜色。当前只验证：在仍知参考原色分布的有利情况下，能否省掉逐像素对应。固定原三个 Gros 人物、冷暖实拍、Film B 开关和六个开发方向。

对各参考分别选 1024 个等质量 RGB 样本。先按联合 RGB 编码排序，再在各分位区间中点抽样。对照让原片采样点直接取得成片相同坐标的颜色。主臂独立抽样成片像素，使用 RGB8 平方距离做匈牙利最小代价配对。两臂在同一批源样本上拟合残差，对原色重复的样本取均值。渲染时用现有近色样本思路，固定最近八种 RGB、距离下限 1 的反距离加权，然后裁切并用 80% 强度出图。记录目标颜色到供体的距离。在关闭状态也运行配对与渲染，验证恒等。已通过的完整密集正对照只作外部基准。唯一待解释变项为采样点之间的像素对应是否已知。

沿用整图、双颊、双白幕的风格投影 0.75–1.25、风格响应误差、关闭状态误差与冷暖换灯误差 ≤3 RGB8。全部六个方向与两个灯均保留。只要配对样本臂本身失格，不能仅凭主臂失败断言联合分布不可用。若配对臂完整通过而独立分布失格，支持逐像素对应或更强先验有实际价值。两臂都通过才进一步检验用户普通两图是否能给出足够准确的参考原色分布。本轮不增加数据和依赖，两个 CPU 复跑各最多 60 秒。
