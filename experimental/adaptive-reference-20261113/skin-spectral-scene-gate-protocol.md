# 普通人像和暖色输入上的自动肤色修正范围

已知光源的校正方案在打码近景中保住了脸颊收益。当前检验同一个自动定位器，在包含浅墙、白衣和远处面孔的已有自然照片上能否启用脸部修正，同时限制误改。采用既有 BG-REAL 三个直接人物组及一个投影幕组，沿用登记的九个区域和输入文件身份，不重新选框。另复用 DAST 五组标称曝光，检查同一定位器标称曝光的既有核心能否覆盖。该核心为历史模型定位，不是独立真值。手背、手臂和投影幕分别报告，不计入脸部覆盖门槛。

原图及其用既有 D65→A CQS 矩阵、80% 强度得到的程序暖色图分别定位，固定 `face_skin` 概率 ≥0.70。程序暖色图用于改变输入色相，不代表暖光实拍。再在两态使用已知的 A→D65 矩阵作为普通底图，自动脸部像素上叠加既有 ISSA＋两个光谱供体修正。比较有／无脸部修正的 RGB8 变动。已知光源方向用于离线渲染，不从目标或参考推断。标注、历史定位和原图暖色生成信息不进入自动预测。

最低筛查条件：三块直接拍摄脸部框在两态各有 ≥95% 像素入选；雪地、浅墙、白球服三个框在两态无入选、成片相对该态基底逐像素一致；DAST 五组的既有脸部核心保持 ≥95% 覆盖。报告各图掩膜面积、两态交并比、区域变化，单独保留没通过的脸和实际成片。两个状态共 18 张局部修正，两次 CPU 重放。不评价未测的自然肤色或把这些已用开发图算作独立验收。若脸部不通过，暂止直接接入此固定定位器；若即使覆盖足够也改变受保护表面，保留可复核的反例。
