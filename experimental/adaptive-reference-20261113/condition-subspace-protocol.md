# 输出敏感方向的固定16维容量诊断

上一轮前32训练行均为style0，只有该范围内多初值近似多解证据；不是四种风格的全面结论。本轮不用参数PCA，改从实际渲染对条件的敏感度找方向。

固定训练清单位置0,16,...1008，共64行，四种style各16；只读取目标/参考，不读取这些行GT。零条件渲染256图，area下采样到16×16；每图16个固定seed20261129的Rademacher输出探针，除以sqrt(768)。对每个探针求128维条件梯度，保存1024×128梯度，CPU float64求G.T@G/1024的特征分解。按特征值降序，最大绝对分量规范正号；固定前16方向，不按效果搜索rank或探针数量。该能量是局部、低分辨率、随机探针估计，不是完整非线性空间的保证。

容量样本取训练位置8,40,...1000，共32行、8个目标组×4种style。验证两批目标group_id不交叉；主干此前见过整个训练集，不能当整个系统独立留出。开发数据不使用。先保存基与来源，再读取容量组GT。

两组均零初值，在同一特征向量基坐标优化：full128用全部128方向，rank16用前16方向。Adam lr0.03/128步/每批4/梯度裁剪1/RGB L1+0.1梯度L1；每步将坐标整体缩放以保证映射后delta的最大绝对值≤3，不逐分量截断破坏子空间。两组相同径向边界、步数和坐标方向，预算相同不代表FLOPs相同。各组按自身GT RGB MAE从0及每16步快照选最好。记录完整坐标/条件、选步、输出。所有零基线PNG须与历史对应B1输出SHA相同。旋转坐标和径向边界不同于旧标签的逐分量截断，因此不能要求与历史优化轨迹相同；以本轮full128为匹配容量控制。

固定诊断门槛：full128平均GT误差相对零基线至少降低50%，否则控制不足；rank16保留至少90%的full128平均降误差幅度；至少28/32例rank16误差≤full128+0.5；相对full128明显退化（同时增加>2码值且>25%）≤2；四style全部6种配对×8组的响应delta误差均值≤full128的1.1倍。全部通过只支持继续研究低维表示，不支持上线。失败不换rank。

原映射主干冻结，GT只用于容量拟合与选步，不能作为正常推理成绩。不训练从两张输入预测的新模型，不修改软件，不宣称语义理解、普通CUBE可保存空间效果、视频或整体速度完成。
