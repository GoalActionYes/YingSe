# 预测经过同款 JPEG 编码后，验证误差是否减少

上轮八个无损成功正例中，只压缩参考时旧拟合放行两个，两端都压缩时放行三个。后级扩大比较尺度最多恢复一个。沿用那 47 个重拍和 14 个同原片对，固定原八个无损正例为主要计分组，分别只压缩参考及压缩两端。本轮检验旧拟合的失败是否来自预测与参考的 JPEG 路径不一致。所有压缩使用原实验的 JPEG 85、4:2:0，属于可复现的开发条件。

保留旧配准和仿射优先规则，按原缩图、训练棋盘、三次函数和正则拟合一次，共用同一张色表。三臂只改变验证读取的预测。旧臂在缩图上应用映射；原尺寸对照先在完整目标上应用映射再按旧方法缩小；候选在原尺寸映射之后经 JPEG 再缩小。三臂评分使用同一张参考缩图、同一留出块和 1.5 MAE、4 P95、6 最坏块门槛。将原尺寸对照与候选的差作为编码影响；只与旧臂比较会混入缩图次序的影响。

前置过线后，各臂共用上轮原尺寸预测上的 8×8 细节判断；模拟编码后的预测只用于拟合验证。实际输出沿用未再次压缩的目标映射 80% 强度，否则走常规 13 号，原仿射及同图路径照旧。每个编码条件至少六个固定正例须最终过整图及可测近中性色门槛，47 个重拍方向零新增三次误触，完整复现两遍。若过线数仍不足，或新方法也放行重拍而后级没有排除，结束固定 JPEG 前向校验方案，不修改通过线。若误差变化很小或不一致，保留前置瓶颈但不归因于 JPEG 次序。此轮没有真实 JPEG 文件的编码器匹配或跨场景结论。
