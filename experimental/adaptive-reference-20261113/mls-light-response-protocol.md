# MLS 重复材质的换场景与换灯基线

固定场景 02↔03 的蓝纸棱柱、绿纸方块，以及 13↔22 的深、浅色木板。选择共同的 2HAL_DESK 与加入最强蓝 LED 的 2HAL_DESK_LED-B100。每场景仅取这两张 JPEG，按已核对的 ZIP 中央目录验证成员和 CRC，限制下载数据不超过 4 MiB。保持发布的预览 RGB 编码，读取 578×475，不根据成片重配准。

每一方向固定三种参考：另一场景同灯、另一场景换灯、本场景换灯。13 号均为正常两图、80% 强度。为避免本场景变成对照分支，这里三种都直接调用相同空间引擎。先落盘所有输出，再读取作者掩膜只用于评价。验算两张实拍明度梯度的方向相关度，至少 0.50 作为配准代理。对两种材质、整图和目标近中性色分别记录色度；使用原图和换灯实拍 RGB 全通道落在 [16,239] 的共同像素，至少 256 像素且覆盖 20%。换灯实拍以 80% 混合后若色度变化 RMS 至少 0.05，要求输出方向投影至少 0.50，误差比保持原图低至少 10%。同灯参考以相对目标原图色度变化 RMS 不超过 0.05 为色差控制。不同场景同灯仍可能有不同反射；这些门槛用于开发诊断，不是摄影真值或自然效果验收。

首次解码在生成任何输出前发现 JPEG 是 600×493，发布的小样掩膜才是 578×475。保留 JPEG 原尺寸推理，用最近邻将掩膜缩放到同尺寸用于离线评分。两者宽高比差异小于 0.02%，仍须查看掩膜位置，不做逐图搜索或平移。其余条件保持。

报告全部覆盖不足或反向结果，两次复跑，未经授权不公开图像。若相同材质在两个场景仍不能提供稳定的颜色响应，后续需先检查照明与几何差异，不能只按材质身份驱动调色。
