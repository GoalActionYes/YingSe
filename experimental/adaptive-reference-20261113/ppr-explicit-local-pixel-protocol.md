# 显式启用局部记录：第二轮固定像素诊断

目的：前三专家四例没有人物分区信号，但其A元数据也没有显式局部修正。仅对479暂余候选中全部三项启用、非零颜色调整与非空笔刷记录244_4、1369_1、1645_1，检查官方专家A像素是否提供新的空间拟合信息。选择依据为元数据，与输出误差无关；不是重选第一轮好图或调参救回。

固定只取三项源TIFF／A TIFF／人物PNG，共九成员。沿用原作者非商业研究范围及同三份公开Drive ZIP身份，总大小12079675100／4639852620／36915637字节，前后复核大小与修改时间。范围读取上限16MiB、单次4MiB、64请求、600秒，必须206和精确Content-Range，成员≤4MiB、CRC与SHA核对；身份或预算失败即停，不取整包。

旧训练原件按原manifest SHA定位，先要求与官方源文件完整字节相同；若不符停止该对应，不通过重新对齐或拟合颜色追求一致。原始位深／尺寸方向保留，ICC到sRGB与BILINEAR 256准备不变，蒙版作软权重。它们仍是旧训练来源，即使编号属于作者val也不能当新独立集。

原样沿用ppr-spatial-information-protocol：20项全局三次、56项全局五次、40项人物／水平位置／固定打散控制；8×8块两折、ridge=1e-6、种子20261118＋照片顺序、RGB8裁切四舍五入。这里只对A，不虚构B／C标签。沿用至少3组的必要信号要求，因只有3组故须3/3均相对三种控制各改善≥5%且≥0.25码值，人物和背景不得比全局五次恶化>0.1。不得改阈值、阶数或采样救回。

CPU180秒、BLAS两线程，无GPU、安装或产品训练。真值和人工蒙版只用于离线拟合，不冒充自动推理或独立照片泛化。保存全部失败／退化和局部结构的证据边界；不能只凭非零元数据确认实际笔刷因果效果，因没有去除局部修正后的作者同管线重渲染。

这是同一空间监督信号假设的第二轮；若仍未满足规则，停止当前“这批PPR＋人物分区即可支持扩大训练”的路线，不重启旧区域头或换名继续。即使满足，也须另定参考条件和完整开发门槛后才能讨论最小候选训练。
