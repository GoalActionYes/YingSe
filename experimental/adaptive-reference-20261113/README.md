## 实施顺序

1. 固定区域残差接口并先验证同图、缺失区域、零强度和蒙版边界等不变量。
2. 实现多区域软蒙版颜色残差：对主版全局结果与参考图的同类区域比较均值与方差，受限估计颜色偏移和对比度；缺失或不可靠区域回退。该统计只能表示候选，不能证明理解了风格。
3. 复用已有离线分割模型提供自动蒙版，单独记录分割失败，不将人工真值蒙版混入自动评估。
4. 固定自然素材来源、开发／评估分组与参考配对，保存所有对照与失败。
5. 图片效果成立后才接入视频和主版开关。视频须逐帧区域识别与时间稳定性验证，不能把首帧蒙版固定到整片。

训练模型不是第一步。若现有区域识别与统计不能提供收益，应记录失败原因，再决定是否需要区域对应学习、参考风格表征或调色监督数据。

2026-11-13 增加经过空间留出验证的局部画面对应分支 `spatial.py`，支持平滑局部明暗、对比度、饱和度与颜色变换。它不解决不同场景匹配，不替代上述目标。开发检查与速度范围见 `docs/research/2026-11-13-spatial-correspondence.md`。与区域残差共 11 项基础检查通过，完整目标仍未完成。

跨场景 150 组反证后，区域统计残差为 21 改善／125 恶化，不接入默认版。作者 CanonCGT E2E 模型在同条件下为 102 改善／45 恶化，作为后续基线；是复用已训练模型，不是自训练或剪映复刻。详见 `docs/research/2026-11-13-cross-scene-countertest.md` 与 `2026-11-13-trained-model-baseline.md`。GPU 固定双 LUT 已验证有快速应用潜力，完整视频和区域关系仍未完成。

## 约束

- 输入：目标原图、全局结果、参考图，各自的区域概率；输出不生成新内容。
- 第一候选以 RGB 区域均值／方差为起点，明确不是审美真值；颜色占比、衣服本色和照明仍会混淆。
- 同图保持、零强度保持、缺失区域保持、有限数值输出为必要条件，不代替画质评估。
- 参考图区域与目标区域布局不要求相同，但类别必须对应；低置信区不额外调整。
- 输出 PNG 可包含局部效果；普通 CUBE 无法表达该完整处理。
