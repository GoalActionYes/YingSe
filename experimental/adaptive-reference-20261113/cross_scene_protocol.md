# 跨场景已知变换开发反证协议

运行前固定。使用历史开发集的十张照片，不将其称为独立评估集。按索引偏移 1、3、5 选择三十个有向配对，不挑选结果。两人合照中可能出现相同人物，不等于内容独立。

每对使用 B 图经恒等、暖色、冷色、对比度、去饱和五种全局变换作为参考，A 原图为目标；同一已知变换应用 A 为数值对照。共 150 组。两张原始照片本身的白平衡与曝光未被统一，故这个对照只检测给定合成变换的重建趋势，不是自然风格审美真值，更不能要求模型准确恢复不可辨识的变换。

冻结当前区域残差候选参数，不在本批结果上优化。比较主版全局映射与区域残差，自动分割参考使用实际调色后参考，不从目标真值取得蒙版；目标分割只用未调整 A。目标真值只用于评估。

记录全图 RGB MAE、皮肤／非皮肤误差（语义为模型估计，不是人工真值）、裁切比例与回退。改善／恶化阈值 0.1 码值，仅用于计数，不代表可见差异；按原图、变换分别汇总。恒等参考不是 A 同图，要单独观察其不必要改动。失败样例全部保留。

若恶化广泛或收益只集中在部分配对，停止把区域统计当作可交付效果，转向能区分原场景内容与调色风格的模型基线或监督数据。本轮不通过不断降低局部强度来凑通过。
