# 双向排名检查同材质匹配

上一轮视觉近邻的主要错误是把绿纸立方体匹配到未登记区域。单纯拒绝无法提高原总体召回。固定候选为正反两个余弦排名之和最小的参考块，同分选原正向排名较高者。分数矩阵与原单向法完全相同，不取材质标签、不限制参考位置、不调参数。另报告严格互为第一的诊断覆盖和正确数，但对拒绝的查询不另设通过门槛。

复用两处实拍、四种参考状态、原有两材质标签、整图检索范围与有效块。重算每个方向的单向基线，必须与冻结报告一致。新方法仍需八项各至少 75%，且平均比原 RGB 至少高十个百分点才可用来出图。两遍逐件复核。若仍不过线，结束本轮固定视觉近邻方案，保留同灯、变光、真实材质的开发反例。
