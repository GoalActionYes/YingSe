# 换光已正确区分时，两套渲染器的编辑响应上限

固定复印室的真实换光和同向数字编辑、客厅与人像目标、稳定版与 13 号落盘成片。为测理想换光判别后的目标侧上限，原参考和实拍换光均保留目标原图。两款模型的数字编辑减原参考输出作为增量，分别从同一目标原图重放。第三臂逐像素允许在两款模型的 RGB 增量之间选择一个共享通道的凸组合比例。离线从正确目标获得 L1 最小的比例，计算量化前误差与实际量化成片。此上限使用正确标签和图像答案，所以不能作为自动模式。

沿用原区域门槛。分别报告整图、墙面、灰球、双颊与白幕，不按有利区域改门槛。若逐像素最优混合仍失败，计算量化可能改变误差的上限，并说明是否还能仅凭连续混合解决。若通过，说明表示有机会，不证明存在自动比例。分别保留两种原增量和最优混合三类成片，两遍逐件复核。不重开两轮固定换光判别。
