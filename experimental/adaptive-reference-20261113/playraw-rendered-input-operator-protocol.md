# 从作者编辑参数重放已导出的照片

同一局部暖调在两张实际照片中需要不同的像素变化。此前提供准确范围后，固定色差和固定通道比例仍有不合格区域。本轮检验已有作者操作参数是否能直接用于普通的已导出目标图。唯一实验变量为编辑所在管线：基准在各照片的 RAW 显影历史中运行作者模块，候选把冻结的 sRGB 关态写为带标准 sRGB ICC 的 RGB TIFF，再让相同编辑器执行同一色彩平衡模块。作者蒙版不带入候选编辑器，在离线合成时应用原有范围和强度；目标作者成片只做评分。此结果需要额外作者参数，不能算普通参考成片的两图推理。

保留混合光作者原片与《Cuckoo》两份冻结缓存。候选先验证已导出输入的编辑器关闭态，最高 RGB 通道误差不得超过 1，几何与尺寸须一致。开启和关闭成片相减取得有符号色度变化，使用现有 Y′ 渲染器、固定 80% 与原范围施回 sRGB 关态。混合光用登记的作者蒙版权重和高权重区，过渡区另报；《Cuckoo》沿用两个肤色框，原本的树皮和绿色背景为保护区。主肤色区域投影需 0.75–1.25、MAE ≤3 RGB8，过渡区相对原两折固定色差误差不得增加超过 0.25，区外逐像素保持，区内 Y′ 偏差不超过 0.5 RGB8。若关态不合格，仍记录输出用于查明管线差异，该结果不可计作通过。

两次运行，每次三组开关，限用已安装的 CPU 编辑器和冻结素材。逐件核对结果。成功只说明已知作者参数在有限已导出样例上的可迁移性，后续才检验没有参数时能否自动识别该操作；失败则保留对应成片，停止将此 RAW 操作直接放到 sRGB 端点上。未达到本轮门槛不得更换工作色域或编辑历史追分。
