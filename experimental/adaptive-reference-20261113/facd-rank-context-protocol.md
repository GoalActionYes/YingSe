# 同 RGB 的滤镜响应能否由照片内的明暗排名解释

用七组通过裁切配准的 FACD 原图和三款同滤镜成片，整张目标照片留出。只比较在目标与至少两张其他照片中具有完全相同 RGB8 值的像素，每张供体需至少观察该值四次。两种预测共用相同支持。基线对各供体的同色成片均值等权平均；实验臂只取源明暗排名最接近目标的供体（平局按照片编号）。排名采用原图取整 Rec.709 Y′ 的经验中秩，未使用目标成片。两臂都按固定 80% 混合，未支持像素保持原图，仅用于展示位置，不计分。不同于旧色表和径向补偿，这里完全固定 RGB，只增加原图内部相对明暗信息。

每个目标至少支持全图 10% 且至少 256 个近中性色像素。近中性色定义为 RGB 最大与最小差 ≤18 且 Y′ 在 [24,231]。比较同一批支持像素的相对作者 80% 成片 RGB MAE。每款里至少五张图的整图支持像素误差须下降至少 20% 且 1 码值，同图近中性色不能增加超过 0.5。至少两款达到要求才保留此线索用于模型设计。未知支持范围、失败和回退全部保留。该轮读供体作者前后照片，不会自动从仅有两张普通图识别滤镜。数据是已消费开发素材，不作产品验收。
