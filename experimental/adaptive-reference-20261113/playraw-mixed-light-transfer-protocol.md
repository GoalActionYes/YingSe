# 用真实局部改色检查正常两图入口

已复现真人混合光的开／关成片与手绘蒙版。这轮用现有 13 号的正常入口出图，问它能否跟随同一个作者改色，同时避免区外串色。

- 目标用关态原画幅，参考用原画幅、水平镜像及中心裁切三个构图，每种均有作者开／关态。中心裁切固定保留中央横纵各 7/8。预设只在裁切保留 ≥95% 高权重像素时计入同画面联合检查，否则记缺测。所有参考变换均对两态一致，导入为标准 sRGB8，使用 80%。独立的跨场景检查固定白球服原目标，用原画幅开／关参考，只测原来登记的白衣区域，不为异场景肤色指定作者目标。
- 以作者原画幅开关成片按 80% 渲染作为离线真值。人像高权重区要求颜色方向投影 0.75–1.25，响应平均误差 ≤3 RGB8；零权重区及其中近中性色的开关色度差 P95 ≤1.5，白衣跨场景开关色度差 P95 ≤1.5。按 Rec.709 去亮度后 R、B 两维测色度。记录同图保护、预览匹配、实际分析路径和每个失败。
- 两次正常路径各八张输出和报告。局部和全部保护条件同时通过才支持现有路径能处理该例；失败则保留为带真实作者标签的开发反例。人像及其三个构图共用一个原片，跨场景只验证白衣保护，均不进入独立验收。
