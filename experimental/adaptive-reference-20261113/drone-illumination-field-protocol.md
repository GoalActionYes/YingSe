# 灰球稀疏光色能否支持独立位置的空间校正

上一轮两个场景通过位置核验，固定窗口灰世界失败。本轮不更换或调节该估计器。检验已知真实光色在图像平面内是否足够连续，能否从邻近测点推断未测位置。只有在留出位置预测有收益，才有依据将稀疏测量扩成局部光色监督。用餐区的真值变化小，保留作近全局照明对照。

沿用走廊与用餐区 154 个固定标签和原生坐标。按 4×4 网格留出整格，预测时不得使用该格任一标签。以四个最近训练点的反平方距离权重平均 L1 归一化光色，欧氏距离用图像短边归一化。第四近点距离超过 0.25 则该点无支持，记为回退。全图对照使用同一折可用测点的归一化光色均值。仅在相同支持点比较局部与全局的角度误差，另计含回退的全部测点误差。

每场须有至少 80% 测点受支持，支持位置的中位误差相对下降至少 20% 且绝对下降至少 0.5°，90 分位不得比全局高 1°。全部满足后才为该场生成实测标签引导的局部白平衡示意。示意采用同一插值、范围外回退，无实拍成片真值，不能取代留格指标。未通过时保留逐点错误和坐标支持图，禁止按结果改网格、窗口、测点或阈值。标注仅用于离线诊断和监督可行性，不进入产品推理或独立验收。
