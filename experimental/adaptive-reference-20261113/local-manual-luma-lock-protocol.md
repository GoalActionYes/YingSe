# 扩大选区并锁定明暗，验证局部颜色调整

用已有 DAST 五个标称曝光暖调场景和已用于开发的 9483 浅墙。DAST 取原暖调流程已登记的目标脸部范围、13 号 nominal-on 及已知暖调成片。浅墙仅据目标原图固定 L 形范围，将 [0,0,232,15) 上方浅墙与 [0,0,28,66) 左墙合并，避免将脸和窗框纳入，沿用 F1 与 C1 锚点。范围为离线手工／既有定位输入，不算自动推理。所有本机目标和锚点由原清单哈希检查。封存墙面不使用。

保持现有色温／色调和 −20 至 +20 每五单位的固定格点。在范围内部用 16 像素交错块拟合最低色度误差，在留出块评分。两臂共用参数，使用到范围外的距离做八像素内羽化。对照直接应用手动结果，候选只保留手动结果的色度并锁住 13 号现有亮度，超色域沿等亮度方向缩回。核心留出色度需较基线改善 ≥15% 且 ≤1.5 RGB8。亮度锁定误差最大 ≤0.5001，范围外逐像素等于入图。记录软边改动、核心亮度相对锚点误差、有意编辑方向及裁切。五个脸部至少四组通过且浅墙通过才值得扩大位置控制。任何通过只代表本次实际选区、离线参数和已用场景，不代替正式自动画质或产品交付。
