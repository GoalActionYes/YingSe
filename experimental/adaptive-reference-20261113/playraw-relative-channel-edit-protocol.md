# 按线性通道比例重放真实作者局部色彩

固定色差用到另一张照片《Cuckoo》时，两处肤色 MAE 为 3.094／4.502 RGB8。用目标答案找出的统一减弱倍数可以救该图，却使供样同图两折超线。此前还验证了亮度分档与近色覆盖。本轮不用目标答案定值，只比较色差的表示。对作者开关图的两个冻结棋盘半区，在原高权重区中额外剔除开关后任一通道不在 [16,239] 的像素，计算 80% 期望成片相对关态的两个线性对数色比差，除以作者覆盖率后取中位。各折至少需要 128 个像素。折内拟合后只在另一折评分，跨照片以两折向量平均后渲染。固定色差对照复用旧成片。保持本轮与上轮相同的原图亮度 Y′、有效范围和保护区。通道比例渲染先用已有线性 RGB 比例函数生成目标色度，再按旧渲染器恢复原 Y′。同一局部权重用于各臂。不能读取目标真值来选比例、方向或范围。目标的登记区域模拟已知编辑范围，只用于离线开发，不能当作自动位置。

复用预先核验的两份《Cuckoo》开关缓存，不重跑旧编辑器。四个目标肤色读数（两次旧编辑器结果各两区）都须达到旧投影 0.75–1.25、误差不超过 3 RGB8，保护区误差 P95 不超过 1.5。供样两折高权重区须守住同一门槛，过渡区误差较旧控制不得增大超过 0.25。目标原 Y′ 的量化差在有效范围内不超过 0.5 RGB8，范围外逐像素保持。两次 CPU 运行保存所有结果和失败。未通过即结束固定通道比例，不用试后倍数给本轮追分。通过只说明在固定范围与单一作者操作下有效，仍需新真实作者和普通两图对照。
