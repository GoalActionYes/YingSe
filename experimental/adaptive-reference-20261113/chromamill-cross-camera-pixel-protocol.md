# 双相机白光与绿光的像素和编辑资格

固定上一阶段选出的 Scene3_a、Scene9_b、Scene10_a，手机和尼康，241 档，白光 0.3127／0.3290 与绿色照明 0.2821／0.4727。仅从冻结来源清单读取 12 张，复用缓存的三张手机白光照片，新增 139,294,691 字节，下载上限 192 MB。保持官方 val 与 test 像素未打开。所有照片按发布长度与 SHA256 完整核对。本阶段不拟合模型。

沿用 CHROMA-MILL 固定线性到 sRGB 的显影，每张长边 512，无逐图曝光或白平衡。相机内比较同一布景的白／绿图，要求同尺寸、全图零位梯度相关至少 0.60、最优位移相对零位的相关增益至多 0.02。使用真实白／绿通道均值比将白光图染色，作为已知数字编辑。沿用最大线性通道均值差 ≤0.02、数字图裁切 ≤5%，另要求实拍白／绿的线性均值对数色度变化范数 ≥0.08。两机在同一布景分别测量，不假设位置严格相同。至少两座布景的两机都满足条件，才能称该批支持跨相机小型开发对照。保留全部六组图、资格与失败原因。结果不能当作跨相机独立验证、肤色或画质成绩。
