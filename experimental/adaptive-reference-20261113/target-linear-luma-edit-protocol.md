# 只应染色时，目标线性亮度约束能否保住风格

前轮两套输出共享比例的凸混合在静物 24 项中 11 项可证不能通过。待检验原因是，原模型编辑增量混入了亮度变化，妨碍本应保亮度的颜色操作。此次使用既有 MIT、Gros 和 Beyond RGB 六个目标，共四个构图。所有样本已用于开发。事先声明数字编辑为保线性亮度的色度操作。原参考及实拍换灯臂在共享的诊断基线上保持原图，数字臂继续从参考前后对得到变化。未使用目标成片答案计算新像素。

只改变重放端的线性亮度约束。将同一个编辑候选转到线性 RGB，按 Rec.709 亮度比例恢复目标原亮度。若超色域，沿该亮度的中性轴压缩色度。比较两套各自的原重放和锁亮度成片。保持 80% 及原评分区域，MAE 不超过 3 RGB8、风格投影在 0.75 至 1.25。同一规则在四个构图全通过、且该规则在相应端点原已通过的区域无失败或超过 1 RGB8 的误差回退，才继续判断能否自动识别编辑类型。失败则不进入产品，按剩余亮度和颜色误差决定是否值得延续。每张记录量化前亮度误差、色域压缩比例、零编辑恒等。仅本地 CPU，无训练，双跑校验。
