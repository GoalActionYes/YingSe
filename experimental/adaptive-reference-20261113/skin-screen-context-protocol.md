# 场景屏幕标签能否排除投影幕上的脸

沿用四张已登记照片、九个测量框和旧语义肤色权重。唯一变化是将冻结 ADE20K SegFormer 识别出的显示区域权重置零。按模型原预处理对整张照片推断，双线性上采样 logits 后计算类别与置信度。只屏蔽最大概率类别为 `screen`、`television receiver`、`crt screen` 或 `monitor` 且置信度不低于 0.70 的像素。类别依模型字典，既有场景试验的置信度门槛沿用。不扩边、不调门槛。

沿用上一轮门槛和同一固定诊断偏移 `[-8,0,+12]`。三个直接脸部的高权重覆盖各须至少 80%，投影幕、浅墙、白球服、雪地低权重触及各须不超过 1%。手背、手臂单列。保留投影幕区域的模型首选类别分布和四种屏幕后验之和，只作解释。候选须全过才进入额外数据验证。测试只验证小范围定位与外溢，固定偏移不是参考调色或换光验证。
