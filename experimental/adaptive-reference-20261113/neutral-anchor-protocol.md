# 近中性亮部锚点：独立、固定参数检查

只作独立诊断，不改产品、不训练。目标是在参考和目标都包含可靠近中性亮部时，限制模型额外引入的亮部色偏；不是肤色或语义保护，不把目标原色一律当作正确颜色。

固定方案：从RGB8中提取亮度>0.65、通道差<0.12、最大通道<0.98的样本；目标与参考各至少64像素且占比≥0.5%，不足则完全保持原结果。以样本RGB减亮度的通道中位数估计参考色偏，并与目标对应位置的调色结果比较；修正向量投影到零亮度平面，每通道限幅0.04、乘0.5。目标的亮度和低色度连续权重限定作用范围，不调整明显彩色像素。先修正满强度RGB8，再按产品方式混合到80。

先测同图恒等、已知额外绿色偏色、彩色像素不变、参考没有可靠锚点时绕过、带明确冷色风格时不强行变中性。再在已经消费的自然32目标上保存全部输出，核对旁路／作用范围和参考风格，计算既有GT的描述性误差，不作新留出验收。

优先暴露损害，不按GT挑样例或改阈值；收益不稳定或破坏风格则不接入。预期视频须固定分析参数并保持时序，但本次未实现，不用图片结果声称视频支持。任何部署仍需图片／视频一致性和独立评价。
