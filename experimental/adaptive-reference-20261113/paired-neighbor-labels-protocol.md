# 固定参考颜色，区分配对差值与近邻重放的影响

上一轮近邻重放让白球服 F1 达标，C1 仍不足，雪地及投影幕 F1 失去原通过项。对于已有的颜色邻居，本轮检验由参考照片测得的前后差值是否限制结果。

- 唯一改动是固定同一 RGB 调色前样本，将照片测得的差值换成同款已知颜色变换直接作用于这些 RGB 得到的差值。两臂使用相同的背景、四个来源、8 像素棋盘、八邻居及插值权重、取整与 80% 渲染强度。旧臂必须逐像素匹配归档，并复用上轮的正式门槛。验证用原始目标的已知调色成片只用于评分。
- 固定四组已消费的开发内容，两款和两种参考背景。重点解释上一轮失败的白衣 C1、雪地 F1 和投影幕脸 F1。若已知差值臂将同区域恢复到投影 0.75–1.25、误差 ≤3，且误差至少下降 0.25 RGB8，判定准确的参考差值在现有颜色位置上有明确帮助。仍不通过时，记录已知差值逐区域结果及最近样本距离，区分两臂都弱与其他退化。保留其余保护区和缺测。
- 两遍固定运行，每遍 16 张成片、四张对照图和报告。若替换差值仍不足，结束在固定样本位置修正参考配对读数的解释。结果仅为已知编辑的归因，不扩大为产品画质、独立验收或普通两图识别结论。
