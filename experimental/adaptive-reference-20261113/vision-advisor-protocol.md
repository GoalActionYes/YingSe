# 预训练视觉模型调色建议对照

小规模参数、画面监督与可训练像素特征试验均未通过验证；最终30张测试图继续保留。需要检验更丰富的视觉先验能否帮助区分场景本色与调色风格，而不是假定再训练一个小网络就能解决。

本试验使用官方 Qwen3-VL-2B-Instruct，只输入参考／目标 RGB 图片，输出受限的人物和其他区域六个相对调整量，不生成或重绘像素。现有自动区域概率与解析着色负责实际结果。相同图片和零强度应由确定性规则保持；解析失败不能当成有效建议或静默通过。

首先在独立环境验证运行、JSON接口、时延和已使用开发／验证样张；不读取保留的30张测试图片。所有模型输出及无效建议都保留，不根据目标效果手工修改每例输出。只有开发验证显示收益才冻结提示、模型版本与参数转换，再进入保留测试与自然照片／视频检查。

使用官方固定模型版本 `89644892e4d85e24eaac8bacfd4f463576704203`，只下载配置／分词器／Safetensors和许可，不执行模型仓库Python代码。推理设置 `trust_remote_code=False`，只加载已核对哈希的安全权重。模型约4.26GB，独立运行环境复用已有本机Torch，其他包单独安装，不更改稳定版和前面训练环境。

这是新的视觉分析研究路线，不等于获得剪映算法，不证明视觉模型天然能精确测量颜色，也不保证2B模型或本机显存足以达到最终速度和效果要求。若无收益保留失败；不以这项准备工作认定总体目标完成。

## 首次运行前固定的接口与对照

只接受 person/background 两个键，各六个 -100 至 100 的有限数字；拒绝重复键、布尔值、多余字段、说明文字、越界和非有限值。不以截断或替换零值掩盖解析失败。

相对调整依次为红增益、蓝增益、全通道曝光增益、亮度偏移、饱和度、中间调抬升。物理尺度分别为 0.30、0.30、0.35、0.08、0.50、0.25，除偏移外作用于自然对数参数；顺序为饱和度、增益与偏移、限幅、gamma。软人物概率混合参数，强度最后混合原色和结果。初版没有独立高光／阴影或复杂曲线，不能代表全部调色能力。

官方模型 bfloat16、SDPA、确定性贪心、最多 180 新 token；两张输入各保留比例缩至最长 448。固定提示写在 vision_advisor.py，逐次记录提示哈希、原回复、时间、显存峰值。不在样张之间改变提示或尺度。不使用图中可见文字作为指令。

第一轮仅用已使用的 PST50 1–5 对，工作长边 640，原有算法和专家目标同比例评分；先推断后读取专家目标。实际目标 RGB 经官方分割预处理获取软蒙版。若自动人物概率平均值小于 0.02，实际应用背景参数覆盖人物参数并记录。额外将第一张原图同时作为参考与目标，检查不加产品恒等短路的原始模型建议。记录所有案例包括无效 JSON。MAE 是配对目标距离，不是美学评分；五对不足以准入产品。
