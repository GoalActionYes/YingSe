# PSBench 两组冷暖调色的操作核查

102 与 105 的前后图均已消费。原尺寸下 13 号双向迁移一升一降，但任务文字相近不足以认定属于同一调色流程。本轮只检查这两组的发布附件能否确认主体与背景的实际调色步骤。

- 固定数据版本 `929d0710eb7c86a988f8a69a74619052b60ac293`，只读任务 102 和 105 发布树中的 MP4，总预算 26 MiB。按发布字节数及 LFS SHA256 校验，本机使用已有 FFmpeg 解码，不运行外部程序、安装依赖或上传媒体。
- 先检查每个视频全段的定间隔关键画面，记录是否包含界面、具体调色控件、蒙版与参数。遇到可读性不足或状态切换，允许对对应片段另取帧核对。不从单帧没看到蒙版推断全程没有蒙版。
- 只有两段均能看到相同的区域选择机制、相同主调色操作及足以复现的设置，才将这两组作为可核对的同流程开发对照。不同、无法辨认或视频与前后图对应关系不足，各自记录证据与时间点并结案。无新模型、训练或独立验收。
