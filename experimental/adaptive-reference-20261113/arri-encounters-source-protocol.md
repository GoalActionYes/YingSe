# ARRI Encounters 的镜头身份与访问核查

PST50 保留样本缺少完整上游拍摄分组。本轮只核对 ARRI 为调色工作流公开的 Encounters 指南与两个共享入口。看它能否提供可追溯镜头源、不同光照下肤色与浅色物体，以及明确的输入调色域。没有授权的媒体发布不纳入本阶段。

固定 2023-06-16 版指南。逐条提取发布编号和原镜头代码，核对原镜头复用，按同一拍摄日期代码保守归组。日期只是隔离键；不同日期仍可能属于同一段场景或同一人物。分别核对代理和 TIFF 共享入口的响应、能否取得公开资产目录、资产与镜头标识的对应关系、以及有无作者发布的创意成片。仅获取文本元数据和指南，合计不超过 3 MiB。不读取整段视频、图像像素、训练或评分。

若有权获取且能一一关联素材和镜头，才进入小范围像素校验。仅有已知技术输入域时，保留作有来源的工作流对照候选。拍摄日期、同项目来源或人脸题材不代替自然度评价。PST50 保留集的资格不因本轮改变。

指南中若有逐镜头链接，补查两个固定案例的公开网页元数据。06 有室内外亮度差和肤色标签，08 有灰色建筑标签，拍摄日期代码不同。对照 PDF 的可见行与链接位置，检查网页标题是否对应这些镜头。仍计入 3 MiB 元数据总预算。
