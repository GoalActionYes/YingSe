# 室内外跨来源局部提亮迁移工作台验证

已有的室内工作台对照中，两版会漏掉有意提亮，同时把参考灯光变化带到目标墙面。户外浅墙和柱旁铺地现在有与室内相同的编辑操作和已匹配的实际换光。只回答在跨这两个采集来源时，两版能否保住有意提亮并维持目标未编辑区域。此前测试在同一采集来源内完成，未知失败表现在另一类取景上有多大，也未知有无二者兼顾的方向。[室内工作台结果](../../docs/research/2026-11-24-matched-wall-lightening-workbench.md) · [户外配对](../../docs/research/2026-11-24-wildrelight-shared-tone.md)

## 预先固定的输入

| 参考场景 | 冻结目标关态 | 使用的合格有序方向，A 至 B |
| --- | --- | --- |
| WildRelight 浅墙 | MIT 复印室，灯位 0 | time5 至 time1、time5 至 time2、time2 至 time0 |
| WildRelight 铺地 | MIT 客厅，灯位 0 | time5 至 time0、time5 至 time1、time1 至 time2 |
| MIT 复印室 | WildRelight 浅墙，time0 | 4 至 20、12 至 8、14 至 20、16 至 20 |
| MIT 客厅 | WildRelight 铺地，time0 | 4 至 8、8 至 0、12 至 0、14 至 8、16 至 4、16 至 14、20 至 4、20 至 14 |

按固定一一互配使用每个来源的所有已匹配方向。室内外配对只用于把同款提亮带到不同来源。它们的材料与构图不同，且没有人像。每个方向固定目标关态，分别以 A 的原参考、B 的实拍换光关态和 A 的有意局部提亮参考执行。共 18 个方向和四个同图控制设定。两版输入相同媒体，通过已有 API 导入、分析并导出完整尺寸 PNG，默认手动项，强度 80%。同一目标与参考文件组合只导出一次。核对冻结清单、输入像素及 ICC。目标开启成片只在线下与原图按 80% 混合来比较，从未传进工作台。报告保留全部方向、角色及哈希。

## 判定与投入

沿用原室内对照的联合门槛。每个方向都测目标编辑区、邻近保护区和原编辑作用范围外，另测已有的室内灰球。各区关态对目标原图差、实拍参考换光差、开启态对答案差及开关响应误差均不超过 3 RGB8，编辑区投影在 0.75–1.25，且同图控制逐像素保持。该读数测目标对一项已知编辑的反应，全图外观与其他风格仍需另验。

两遍本地运行合计预算 10 分钟，准备、人工查看和独立复算预计 45–75 分钟。复用现有环境和素材，无需下载、训练和付费。若读取身份、同图控制或出图尺寸失败，保留当次失败及调试证据。比较全部方向，若有完整达标的方向，固定为后续候选不得丢失的基线。若两版均未达标，则将全部方向加入白墙和其他浅色材料开发回归，下一候选必须同时减少参考照明误传和恢复有意编辑。两套素材已经用于开发，不用于正式独立验收。本轮结果只决定后续基线，跨来源素材扩展和训练的准入独立检查。
