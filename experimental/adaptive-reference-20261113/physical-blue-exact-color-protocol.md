# 白灯同色像素在实拍蓝灯下是否仍同色

上一轮的 3×3 矩阵有实拍残差，可能只是矩阵不能表示非线性。沿用相同的两场景、两灯强、白灯原片、实拍蓝灯、数字加蓝和 Film A 开关。如果白灯原片中的同 RGB8 像素在离线答案里需要不同输出，则任意只按 RGB8 查表的函数都有误差下界。

- 真实与数字两臂在同一套位置评分。主域限定三图每通道在 4–251，且各图 3×3 邻域任一通道的最大最小差均不超 8 码值，排除外圈一像素。白灯同色组至少含四像素并分布于两个 32×32 图块。另对全画面算下界，报告整个图的覆盖边界。
- 对同色组每通道取对应输出中位数，计算最小平均绝对误差。整数中位数取中间两个中较低者。全画面拟合的结果用于离线成片，主域另行求最优值，图板标出主域。查表使用对应输出作离线拟合，不读作独立验证成绩。
- 四组关闭态主域各覆盖全图至少 10%，数字最小误差均为 0，且实拍最小误差每组 ≥1 RGB8，才保留「在平坦区域仅依赖 RGB 仍会留下可测误差」作为后续依据。未通过时只报告实际覆盖及上下文，不把上一轮矩阵残差都归因于空间。开启态仅作附加核查。不启动自动开关、训练或产品改动。
- 预算 16 张全图最优查表成片、四张图板与一次复跑。素材为已使用的实拍静物与程序控制。
