# 在原生 SDR 滤镜上拆分参考亮度和色度

用已配准的 FACD 七组和 Amaro、Hudson、XProII，检查同帧滤镜的亮度变化能否独立驱动跨内容目标的近中性色，并比较这种变化跟已知作者色调是否同方向。相对上一轮的 Showgirl，唯一主要变更为来源，不重新挑滤镜。参考和目标沿用原 FACD 固定表中每个目标的第一参考。用每张参考的原图和滤镜成片构造四张共同色域参考。输入条件沿用上一轮全部门槛，不为本数据调整。未达门槛的组合记录并跳过。

在通过参考输入检查的组合上，用 13 号和 80% 渲染四张实际输出。目标真值沿用 80% 作者滤镜成片，只用于离线测量。沿用 FACD 近中性色定义，并排除原图或作者目标色度不具备的端点，至少 256 像素。若作者目标相对原图的色度变化均方根低于 0.005，仍保留输出，但不报告归一化投影。分别以两个颜色条件的平均值测亮度主效应、以两个亮度条件的平均值测色度主效应，同时记录交互。主效应都投影到已知目标滤镜方向。记录亮度单独改变是否导致同向色度变化，以及四张成片的作者色度距离。

至少四个不同目标组有可评价结果，且其中同一个滤镜的亮度投影在这些组均 ≥0.5 并大于色度投影，才登记为跨内容的明确亮度驱动。意思只限本开发集和这些滤镜。无新下载和训练，最多 84 张目标成片，推理预算五分钟。不改变软件或独立验收，所有排除及反例保留。
