# Frozen controlled-transform feature assay

Question: on already-consumed training originals, can fixed reference representations distinguish known applied color operations across different original photographs? This is representation diagnosis, not a transfer model, independent acceptance, semantic understanding, or a product upgrade.

Use exactly the 256 distinct content originals in cohort-multiref-v1/train, current13 epoch6 encoder d8d8e6727a44100e6fedb11b605a17e33afc675de7448d4ebcf6d24d492ad4c9, prepared sRGB256. Do not read real references, GT, validation or reserved pixels, download assets, modify checkpoints, or train the encoder. All photos were seen by the frozen encoder; held-out below means only probe-fitting exclusion, not independent model evaluation. Distinct dataset paths do not establish distinct scene identity; near-duplicate scenes may remain.

Apply fixed 11 operations to each original RGB: identity; warm/cool additive (+/-.06,0,-/+.06); saturation1.4/.6 about BT709 luma; contrast1.3/.7 about .5; brightness +/-.08; cool-shadows/warm-highlights and its inverse, shift=(2*Y-1)*(.08,0,-.08). Work in gamma-encoded RGB, clamp and round once to uint8. This is not physical exposure or a complete style taxonomy. Original grades differ, endpoint clipping and content affect observations; equal applied operation does not guarantee identical final photographic style.

Features, all from the single resulting image, not original-minus-result: M=marginal YCbCr128 hist384; J=M+three sqrt pairwise16 hist768 (1152); A=J+frozen64px img_projection spatial means128 (1280); S=J+means128+populationstd128+uppertriangle uncentered Gram8256 (9664). No target/ref adapter, GT, original image or operation name enters feature extraction. Standard Gram/moments are descriptive, not claimed novel or equivalent to VGG/AdaIN. https://arxiv.org/abs/1508.06576 ; https://openaccess.thecvf.com/content_iccv_2017/html/Huang_Arbitrary_Style_Transfer_ICCV_2017_paper.html

Sorted original paths are shuffled once using numpy default_rng(20261114), halves are two probe folds. Every operation on an original stays in its original's fold. For each feature family and fold, fit fixed ridge multiclass regression to 11 one-hot applied-operation labels on the other128 originals (1408 rows), then predict this128 originals. Standardization mean/populationstd is fitted on training rows only, minimum std1e-6, scale standardized features by sqrt(feature_dimension). Dual ridge solves (Ztrain@Ztrain.T + I) alpha=onehot without additional bias; fixed lambda1, no tuning or feature-family promotion by this result. Log count/accuracy/per-operation confusion, per-row predictions and feature dimensions for all four families. Chance1/11 is only a reference for balanced labels, not a significance test. No labels based on filenames.

Retain all 2816 rows including failures, generated pixels local, feature arrays and source hashes local. Verify parent/cohort/prepared/checkpoint/source hashes before and after, unique prepared hashes across256 originals and fold disjointness; archive source before extraction. Model encoder weights never update. Local npz for feature/numerical recomputation, aggregate confusion and row predictions in numerical evidence. Unit checks cover identity, transform directions, no mutation/invalid inputs, pooled statistics, pixel permutation invariance, grouped folds and ridge no-test-statistics dependency. Report all outcomes, not just best family; never lower existing full development gate or allocate fresh evaluation based on classifier accuracy alone.

Decision: use this only to assess whether pooled appearance is visibly missing discriminative information under controlled operations. Even a strong S result needs a separate predeclared same-budget real-reference training comparison before any new independent-image, original-size/video/latency/UI evaluation. A weak result does not prove the general goal impossible. Current13/stage6 remain usable throughout; academic noncommercial context, no photos/GT/weights/environments/sessions to Git.
