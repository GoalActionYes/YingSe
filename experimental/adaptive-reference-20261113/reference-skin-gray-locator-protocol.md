# 灰度定位能否减少换背景导致的肤色偏色

上一轮在 785 和 9483 发现，固定参考人物、改换背景后，借回原背景下预测的皮肤权重能改善全部六个重点测量值。但日常使用只有当前参考图。此次检验定位器是否可通过灰度输入减轻背景色的干扰。

唯一变动是参考肤色权重从 `round(reference @ LUMA)` 的三通道灰度图预测。目标仍用原 RGB 定位，参考的亮度和色度仍来自原图。候选使用原有同图保持、无肤色回退和 13 号基线。先运行四个固定配对，每对两个参考背景、两种编辑状态，共 16 次自动推理，并重复执行一次。同图及纯色无人的回退须逐像素正确。人工区域仅用于离线测量。

用同轮 C1 输出作为 F1 锚点。785 和 9483 共六项直接肤色测量须至少五项同时降低 25% 和 0.25 RGB8。其余已有区域、包括白球服和投影幕，任何一项增加超过 0.25 RGB8 即停止。每张参考须保留原 RGB 权重大于 0.5 的像素中至少 50%，且四个配对的八项中至少六项的 C1／F1 权重平均绝对差下降。权重重叠衡量对原选区的保留，不能证明像素语义正确。上述条件全满足才扩大到其他开发集。用固定阈值做一次比较，不做参数搜索。
