# 将有出处的局部压暗施加于两处室外实拍换光场景

已有真人开关覆盖脸部局部提亮，无法说明对非人物浅色表面的有意压暗应该如何处理。这轮只问同一项局部压暗能否在两处实际光照变化下产生清楚的编辑开关，并保持无关区域。用 WildRelight 已核验的 wall、pillar 两处固定场景，分别用 time0 和 time5，同一场景两张都使用完全一致的选区及编辑参数。重放来自 Martin Werner 为 R6_06283 实际使用的局部编辑工具组。仅复制分离后的 Locallab 和版本头，保留编辑参数，用本项目已登记的墙面或铺地区域重定位。两位原作者没有参与新位置的编辑。[原作者编辑](../../docs/research/2026-11-20-rawtherapee-sky-pair.md) · [架设与来源校验](../../docs/research/2026-11-21-wildrelight-wall-cross.md) · [已有面部提亮](../../docs/research/2026-11-24-gros-author-tone-switch.md)

- 使用冻结准备图的完整尺寸，将已登记矩形中心作为局部点中心。保留作者左右、上下半径各自的比例。把 x 方向的最大半径设为登记矩形宽的 1.5 倍，y 方向设为其高的 2 倍。完整记录三个修改字段。另登记同一墙带左段 x200–350、y435–469 及钢柱 x420–540、y375–430 为保护取样。以最大方向半径的两倍作为排除框，之外像素用于察看远处变化。仅翻转 Locallab 的启用位对每图导出前后。
- 四张都须通过素材门槛。统一色彩配置下，关闭图与输入整图最大通道误差不超过 2、MAE 不超过 0.25。预定墙面或铺地的开启 Y′ 变化中位数不高于 −3 RGB8。保护取样与排除框外的 RGB8 每像素通道平均绝对差 P95 均不超过 1.5，整图新增触及 0 或 255 的像素不超过 2%。图像尺寸与 ICC 在开关状态相同。如有任何失败，保存全部成片与反例，不更改位置或参数。
- 四个开关全通过后，同一来源的两处场景才互作参考验证 13 号。目标使用 time0 关态，参考使用另一场景两时段各两种编辑状态。原工作台只读一张目标和一张参考 RGB8，强度 80%。以目标编辑器的开启状态制作 80% 离线答案，比较两个区域和框外的关态、开态、开关响应及跨灯差。被编辑区域的投影 0.75–1.25、误差和所有区域跨灯差均不大于 3 RGB8，保护区关、开、响应不大于 3。记录两个方向。它属于已消费的开发场景和独立于 Gros 的采集来源，独立验收集继续封存。
- 本机总预算 35–60 分钟，机器预算 5 分钟，两遍，零付费，不训练。若编辑器门槛过线而工作台失败，交给未来候选做开发回归。全部通过仍要补真人和独立来源。编辑器门槛未过时仅保留作为作者工具作用范围的反例，结束固定设置重放。
