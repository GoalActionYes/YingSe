# 检查 AceTone 公开颜色表编解码器的实际保色和风格误差

本轮检验新外部路线的必要条件。AceTone 将普通两图推断结果表达为 64 个全局 LUT 码。先给公开编解码器已知正确的 RGB 颜色映射，检查固定的标准编码过程是否保留原片、中性色和有意风格。无需下载完整 VLM 或运行普通两图预测。若固定编码失败，结束本机直接接入该标准编码配置，不能据此认定模型不可能生成其他更好 token。

固定 Gros 三位真人的两种实拍灯，共六张源图及五个区域。对照是未经量化的 32³ 三线性色表，候选为同一张表经作者编码器和码本解码后的 32³ 表。以作者评价器的 RGB 输入轴与末维翻转约定传入，先用身份表验证方向。表内有意 Film B 由原 OCIO 显影变换实际采样；关闭态为身份表。每组均以 80% 同流程出图，对照期望来自已固定的原实拍 Film B 输出。给定正确色表只验证编码重放，区域只用于评分。保持原分数线：关闭态 MAE 至多 3 RGB8，实际风格响应 MAE 至多 3 RGB8 且投影 0.75–1.25。若未压缩 32³ 表无一项不过线且自身开关误差都不超过 1，才用它判断压缩造成的额外误差。编码臂须保住全部原通过项才考虑权重路径。六张照片结果全部保留。

来源为作者 Apache-2.0 代码的固定提交 916393b3f26bdf89c3d939cc5f2a9a3c115ccbc5。只下载 vq.py 和 21,383,912 字节的公开 VQ 权重，本机总量上限 23 MiB。用 weights_only 和既有 PyTorch CPU 运行，没有环境安装、完整 VLM 和训练。保存两次运行的成片和数值、记录源码权重哈希。
