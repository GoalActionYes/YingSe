# 内容占比诊断与颜色箱均衡试验

保持8种RGB颜色不变，参考的各颜色面积按4种固定权重排列变化。目标始终等面积。测试恒等风格与固定暖色仿射两种已知变换；不提供区域标签给算法。检查内容占比变化是否改变输出，以及与已知目标的误差。该控制用例只定位统计混淆，不证明自然图语义理解。

修正候选：RGB每通道16档，按非空颜色箱计算真实像素均值，每箱等权，固定种子打散填充512×512分析代理。最多1024个箱等距取样，不按专家结果改变参数。只改变分析输入，保留现有映射生成与原图渲染。该方法对低饱和噪声、颜色箱数量不一致等可能敏感，不保证移除内容本色，也不是分区语义调色；不能因合成恒等测试恢复就接入产品。

先冻结控制用例和算法，再在已用PST1–15上保存全部预测，最后读取专家目标；不读取16–50。实图与合成结果全部保留，不逐例择优，不改稳定版。

首轮等权结果改善平均误差但仍有严重退化后，追加明确的开发诊断：箱权重改为count^0.5，以减轻稀有箱过度影响。不是新的独立验证，不能按案例选择幂值。追加脚本支持固定0、0.5、1三个值，后两者分别为温和均衡和面积权重对照；全部保留。分析代理不代表实际空间对应，因此追加轮禁用aligned-reference拟合，直接用特征和原映射；仅分析代理完全相同才作中性校准。首轮实际15组及暖色控制均未触发aligned拟合，旧证据保留。
