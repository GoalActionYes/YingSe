# 白平衡改变后，能否直接复用同一相机渲染风格的像素变化

映色在复合编辑中同时遇到对比度不足和背景带色。如果相机的白平衡与渲染风格可近似独立，离线监督可跨白平衡共用同一风格残差。此处用作者发布的真实拍摄衍生成片检验这个前提。区别于本机合成 HSL 与曲线，两个因素来自公开相机渲染数据。

固定 Deep White-Balance Editing 提交 `d70afa227c94152fd8421db75b3ee6ac06a417dc` 的 `dataset/8D5U5524_{C,D,F,S,T}_{AS,CS}.png` 十份。按文件标签分组，D 为固定供体，C、F、S、T 为留出的白平衡设定。十份属于同一原始照片，仅用于离线诊断。下载预算 6 MiB，按发布清单核对字节与 Git blob。仅本机非商业研究，无需作者模型和额外环境。

先确认同尺寸 RGB 与零位配准。用亮度梯度 Pearson 相关，整图缩到最大边 256 后检查 ±3 像素偏移。D 的 AS 对其余九张要求零位最优且相关不低于 0.5，有一张不满足即停止像素叠加。目标色彩空间若有不一致 ICC，则停止直接叠加。

对每个留出设定，用该设定的 AS 加上 D 中 `CS − AS` 的像素残差并裁切为 RGB8。对照为不复用任何残差，真值为各设定独立发布的 CS 成片。统计整图 RGB8 MAE 和 AS、CS 中同时为近中性的共同区域 MAE。近中性为通道极差 ≤20 且 Y′ 在 40–220，至少 256 像素。另记录残差夹角投影、限幅比例和独立的白卡／肤色资格。四个设定均须在有覆盖的近中性色和整图达到 1.5 码值以内、且相对不复用的对照均有改善，才保留固定残差为待跨拍摄组实测的监督假设。未通过则结束该假设，不进入训练。作者样片与全部结果留本机，Git 只保留源码、证据和复现说明。
