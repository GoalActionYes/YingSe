# 视频颜色网格平滑实验

新候选完整907帧人物片的背景动态均值步长0.18017、p95为0.45936，旧App8为0.10645／0.29588。指标受真实照明影响，不等于闪烁真值，但新候选额外波动值得修复。以下参数在新平滑视频运行前固定，不改模型或参考，不使用独立图片继续选型。

仅平滑每帧已经生成的13通道颜色网格：当前0.2、上一平滑网格0.8，约对应30fps时0.15秒时间常数。保留本帧像素和本帧颜色引导，不混合画面像素。首帧、显式reset、引擎改变、尺寸改变均直接使用当前网格；32×32缩略图平均绝对RGB变化超过0.16时视为大切镜，立即重置。阈值不保证检测所有切镜，也可能误判快速运动；这不是完整镜头检测。

沿用相同完整视频、参考、30fps、缩放、评价ROI及编码设置，输出独立motion-multiref-temporal-v1。记录所有重置帧、处理耗时、均值步长及p95，不能只展示改善的区间；本机诊断期望两项背景步长均低于未平滑候选，并不高于App8的1.25倍加0.02码值。任意一项失败则保留结果，不调参数重跑来宣称通过。

单测必须验证静止输入下系数递推、返回值与历史隔离、切镜立即重置、引擎／尺寸／显式reset和无效参数／非有限网格拒绝。另测原有已知运动与小幅亮度变化，检查平滑带来的滞后：平移平均对齐MAE相对未平滑候选增量不得超过0.5码值；黑至白硬切须触发重置、与当前帧直接渲染最大差不超过1；短片须75帧完整、重置后首帧重复差不超过1。不同诊断段之间reset，不能跨片污染状态。不凭一个背景ROI通过就接入产品。该模块目前仅供诊断，工作台默认及实际视频导出不改变。
