# 真实参考原图的辅助分布监督

上一周期完成64目标诊断：真实参考前后有信息，目标guide可达低误差，但直接共享参考变换有3项严重退化。停止直接参考参数标签；不启动该来源参数预测器。本轮是不同任务：原图只提供颜色分布标签，改善共享图像编码器，最终输出仍用真实目标GT监督并适应目标内容，不要求两场景共享参数。

在完整原C10结构与expanded-v2已选epoch4权重上继续训练。推理函数保持appearance_forward，不安装旧局部／残差／条件修正头。外置辅助头仅训练使用：共享img_projection对参考RGB64特征空间均值128维，拼参考当前YCbCr三路128-bin分布384维，经512→128 GELU→384，每通道softmax。两臂同一随机初始化；控制标签为当前参考分布，候选标签为可解析参考原图分布。头不进入推理输出，两臂实际推理开销与原结构一致。

仅对现有扩展训练中865条有原图的记录计算辅助损失（829不同前后对、438原图），不重采样、不替换参考、不增加原图推理分支。原图均属于训练content，教师分布由原vision-advisor环境／作者相同RGB256、YCbCr与hist函数生成并冻结。其他训练行只算原图像损失。原图标签不能进入验证、正常推理或候选分支选择。

辅助损失为各通道平方Hellinger距离之和的均值：mean_channels sum_bins (sqrt(p+1e-8)-sqrt(q+1e-8))²。总loss=RGB L1+0.1梯度L1+0.1辅助loss；不按开发结果调整权重。控制与候选同形状、同损失和同865条位置，只变教师分布来源。

两臂seed20261201，batch4，原4096配对全量grouped_batches，每轮1024更新，4轮4096更新；AdamW原参数lr1e-5，已有reference／pairwise adapter及辅助头lr1e-4，wd1e-4，梯度裁剪1，TF32关闭。均从完整epoch4权重和新优化器开始，辅助头同初始张量，训练数据顺序与主损失一致。按旧64开发图RGB均值最早最低选0–4轮，保留全部PNG／权重和项损失。不可依辅助标签误差、严重反例或delta改选。

训练前验证：辅助头形状、归一化、标签校验和Hellinger公式；非零随机头的辅助梯度确实到达共享img_projection；默认推理不调用辅助头／原图；64开发零轮恢复所选expanded-v2输出及全部评分。确认865标签逐项来自训练原图，控制标签来自原参考。原C10、当前13、共同expanded起点和同预算控制的完整门槛沿用现有函数，候选必须同时通过相对原始C10、expanded起点及同预算控制要求；零轮不构成新收益。

若无完整画质收益，停止这一固定辅助任务，不调辅助权重、分箱、seed或加旧输出头。若通过开发，也仅有资格冻结新的独立自然／人类／原尺寸／视频／性能评估。无权重与媒体上传、无产品替换，人工反馈不作为开始条件。
