# 通道内排序能否保住局部暖调线索

固定数值相减会放大脸部和周边的曝光差。本轮使用通道内排序。统一且严格单调的通道响应保持像素排序，落在脸部的加暖却可能使脸部像素在红通道越过周边像素，在蓝通道反向移动。真实相机处理未必在整个画面中保持此性质，剪裁又会制造平局。

复用五组、三档曝光、两种编辑状态与上轮冻结的脸部及环带位置。保留全部区域像素，防止曝光通过中间调筛选改变排名总体。逐区域至少 1024 像素，平局记半次。每张参考计算脸部随机像素比环带随机像素更高的概率，取红通道概率减蓝通道概率。相同区域上以红减蓝的脸部平均线性对数色度减去环带均值作为数值基线，像素下限 1；上轮中间调分数只用于背景对照。保留每组全部十二项通道概率、关态跨度、开关间隔、剪裁比例，以及每对参考编辑前后环带被修改的像素比例。

接续门槛在概率单位上事先固定：至少四组关态跨度 ≤0.05 且最低开态比最高关态至少高 0.05，且五组共用阈值有 ≥0.05 间隔。若达到才进入实际两图输出比较。以保序的整数升序编码检查排序实现，以真实曝光状态检验假设。只读 30 张参考和既有离线定位，两遍 CPU，保存完整结果。若不达标，结束固定环带作为单图曝光线索的这一路线，不再改半径、阈值或排序参数。当前是开发诊断，不作为正式画质验收。
