# 深层内容对应的颜色锚点试验

目标是让相近内容提供参考颜色证据，而不是用人物平均颜色或语言模型直接输出滑块。本轮是独立算法试验，不接入产品。

依据：[Deep Image Analogy](https://www.microsoft.com/en-us/research/publication/visual-attribute-transfer-deep-image-analogy/)与[Progressive Color Transfer with Dense Semantic Correspondences](https://arxiv.org/abs/1710.00756)支持以深层对应辅助颜色迁移的方向。此处用DINOv2小模型特征和受限解析残差，是新探针，不是这些论文的完整复现，也不是剪映算法。DINOv2特征用途见[模型卡](https://huggingface.co/facebook/dinov2-small)。

## 运行前固定

- 官方转换权重facebook/dinov2-small，固定版本ed25f3a31f01632728cabb09d1542f84ab7b0056；Safetensors SHA256 ae1e99fcefd534ed978cdeb8326f08030c96e28b7a81ffcbc98a857c84d14be1。在独立视觉环境离线加载，不执行远程Python代码；复用已有依赖。
- RGB保持比例缩至最长448，再将宽高取近似的14倍数（最少14）；不中心裁剪，明确少量比例误差。按模型配置的ImageNet均值／标准差归一化。取最后归一化的patch特征，移除CLS，逐patch单位归一化。
- 目标原图特征与参考图特征做余弦匹配。每个目标patch取4个相似参考patch，温度0.05归一化加权其RGB均值。置信度由最大余弦从0.65到0.85线性变化，再乘反向匹配目标特征一致度从0.85到1的线性变化；不假定不同构图有相同坐标。
- RGB局部均值是颜色锚点，不是原像素替换。基础输出沿用当前全局算法。可靠权重不足时保持基础输出。第一分支对锚点拟合全图受限仿射残差；第二分支在第一分支后增加平滑的patch残差。所有逐通道残差限制在±0.12，再以固定0.5强度使用；不按例调整强度。
- 全局残差以中心化RGB加常数拟合，置信权重按总质量归一化，岭系数为[0.02,0.02,0.02,0.002]。仿射系数限±0.5、常数限±0.12。平均置信度低于0.1时完全回退。
- 局部残差先在patch网格用归一化3×3均值平滑，再用目标RGB引导的低分辨率局部线性模型上采样，窗口5、epsilon0.001；只输出颜色残差，不移动像素或生成纹理。边缘保持只是待验证性质。
- 额外以同一对应和RGB均值误差比较当前算法与Canon候选的固定0、0.25、0.5、0.75、1混合权重，保存整条分数曲线；不能用配对专家目标选择混合系数。该分支用于检查对应证据能否帮助避免全局过调，与局部方法分别报告。

## 分组和验收范围

第一轮仅用已使用PST50 1–5对与相同图片控制。工作画面最长640；所有输出先完成，才读取专家目标。对比输入、现有算法、Canon、锚点全局、锚点局部、无监督全局混合，保存全部分数及图。不在五例之间改变提示、参数或算法。第一轮不得称为独立测试或产品验收，MAE降低也不能代替查看风格与自然程度。

若第一轮不能证明方向有用，不读取更多留出样张。若形成候选，先冻结源文件、参数和候选规则，再使用PST50 6–15作为新一轮开发验证；这10对一经使用就不再称为未见测试。16–50继续保留；原合成数据最后30张也继续保留。新轮分组须在读取6–15实际图片及专家结果前写入清单，不按人物或分数事后挑选。

必要基础检查：同图、零强度、无匹配回退、数值与形状检查、颜色锚点正确路由、同RGB不同语义可不同处理、全局与局部分支差异、软边界和引导上采样有限输出。自然图还需检查错误材质对应、背景缺失与明显风格差异，不能把余弦高当作语义正确。

图片结果成立后才考虑视频；DINO逐帧特征可能引起闪烁，不能由图片速度推断视频稳定。普通CUBE不包含局部颜色场。最终仍须证明真实素材整体比现有全局版协调，简单快速；本协议不修改总目标。
