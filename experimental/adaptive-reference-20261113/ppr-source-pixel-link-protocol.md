# 官方源图与旧训练输入：固定四例像素关联

问题：文档ID指向同一PPR照片的旧训练原件，是否与已取得的官方源TIFF具有真实像素关系？此前只有元数据关联与官方三元组粗几何核查，不能直接宣称旧输入已获得专家像素配对。

固定沿用像素取样计划的4_2、7_4、15_3、19_1，不增删或按结果重选。绑定v3排除结果、取样计划与完整coverage-v2准备manifest。对每个ID须在537文档候选中唯一对应旧训练路径，且未列为已知同组排除；先按manifest核验旧原件及已准备文件SHA，再比较官方源文件。

只回答身份与预处理兼容问题，不比较候选算法画质，不把四例当独立测试。顺序为：文件字节；原始位深／尺寸；固定RGB8解码；沿用triplet_color.to_srgb的ICC策略与已准备副本；最后双方分别固定BILINEAR到256×256的实际模型输入。保留全部不等项及误差，不拟合颜色、尝试不同缩放或自动平移旋转来追求一致。

CPU60秒，无网络、无GPU、无新下载／安装／训练。原件和旧准备副本只读，报告保留SHA、数值误差、尺寸及预处理策略；不输出私密元数据、源／目标像素。至少文件或像素关系明确后，才讨论后续专家条件任务；若不对应，停止将这些文档ID当作像素配对依据。

若只有8位解码一致，不推广为16位保真；若采用现有OpenCV另核原生16位，单列其用途。即使四例全部一致，也不能推广为479例全体配对、完整场景隔离或训练资格已通过。官方专家A像素与人物蒙版仍仅限离线监督／测量，不能作为自动产品推理的真值输入。
