# 在两种分辨率检查同编号作者成片的共享 RGB

同编号作者配对上，旧色表通过 9/10，近邻通过 6/10。缺少邻近颜色和相同输入颜色被不同处理都可造成失败。沿用这十个合格槽，用精确 RGB8 消除近邻半径及分箱的影响。检验原尺寸与先缩至 256×256 是否给出相同证据。

- 固定此前全部十个合格槽，保留其余 62 个原不合格槽的上游状态。按旧 S24 方法将参考和目标各拆成 16 像素棋盘两半。每个精确 RGB 在四份半图中均须有至少 8 个像素。按键等权比较 80% 作者成片的跨图差，并扣除参考或目标图内较大的半区差。原尺寸和标准缩图分别做同一测量。两种尺寸沿用同样的每格像素数，结果不视为只隔离了缩放核。
- 整图及近中性色分别报告共享颜色数和目标覆盖。有效范围沿用旧精确颜色规则，至少 128 种 RGB、至少 10% 目标覆盖才有资格解释。合格区跨图差超出图内差至少 2 RGB8，才记为同色冲突。范围不够保留为证据不足。两遍报告逐字节核对，并独立复查失败槽的颜色分组。
- 若第 23 组有有效冲突，后续不把同编号当统一颜色真值。若在两种尺寸仍缺有效范围，继续把覆盖不足和条件变化都列为待验证解释。无需运行新候选或启用独立素材。两种尺寸使用的作者成片都是离线测量输入。
