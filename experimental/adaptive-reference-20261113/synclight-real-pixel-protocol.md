# 实拍分光源小样与 13 号跨视角基线

固定 SyncLight 的 scene35、scene25，每场只读相机键 1、2 的环境光 0 和可见灯 1，共八份 DNG、106,973,902 字节。按已验证的覆盖区间取成员，检查响应范围、发布版本及归档身份，计算成员 SHA-256。原片和解码器只留本机。每场固定用视角 1 作参考、视角 2 作目标。

用相机 1 环境光白平衡作为同场四份原片的共同系数，统一线性 sRGB、16 位、无自动增亮、小图比例不变。检查同场传感器颜色矩阵、每视角原始尺寸及传感器参数。用缩图亮度梯度及 ±4 像素的平移搜索检查同机位组件，零位相关须 ≥0.50，最优位移两轴均不超过 1 像素。不对齐的场景保留原因，停止该场的基线渲染。独立的物理采集组件允许合成已知灯光系数，不能视为作者的自然调色答案。

基准为环境光 + 单灯，变化版为环境光 + 单灯乘线性 RGB 系数 (0.6, 1.0, 1.4)。每场用两个基准视角的 99 百分位亮度中的最大值统一定曝光，目标 0.70，再以同一曝光输出 sRGB8。基线用 13 号 80% 对同一目标分别输入参考基准和参考冷灯版。相对锚结果的增量与目标自身冷灯版的 80% 增量比较。目标原片生成的冷灯版只在出图后评分，不传给模型。

保留整图、近中性色及单灯贡献低／高的范围。近中性色要求基准 RGB 通道跨度 ≤20、亮度 40–220 及 ≥256 像素。单灯贡献按基准线性亮度份额 ≤10%／≥30%，各 ≥256 像素。记录方向投影、增量 MAE 和不迁移的误差。一个范围须满足投影 0.75–1.25 且误差至少优于不迁移 15%。近中性或受光范围不达资格如实报告。该轮建立开发基线，失败保留，不由两场结果声称独立验收。出图、解码与独立复核各两遍，单遍计算预算 120 秒。
