# 检查同一编辑跨照片时的原始 RGB 支持

亮度覆盖充足，但按亮度修正后《Cuckoo》胸口仍偏色。RGB 多一个观测维度，可以检查参考照片是否真的包含相近的原始肤色。两张照片此前已用于开发，颜色方向、80% 强度、位置和原开关全部来自既有对照。此实验只更换固定色差的取值来源，无需训练或重新导出 RAW。

在参考原片两个棋盘分区的高权重像素分别找最近原始颜色，距离取 RGB 三通道最大绝对差。为了避免只凭单一参考分区作判断，两个分区都须各自有距离不超过 2 RGB8 的像素，才算有近色支持。记录精确相同、距离至多 2 与至多 5 的覆盖率，后两档只按事先规则统计，评分仍使用 2。匹配存在平局时优先选原图中行优先顺序靠前的像素。两个参考像素的色度增量分别除以其作者蒙版权重后取均值，作为该处推荐变化。无支持处用原固定色差。只读取参考开关与目标关态出图，目标编辑器开态在落盘后用于评分。

脸颊和胸口各自至少有 128 像素且至少 80% 处于双分区支持，才有资格解释整区效果。按原协议要求整区投影 0.75–1.25、MAE 至多 3 RGB8、区外逐像素保持，并在两次原导出的成片上复核。另报告有支持像素的预测 MAE、匹配像素在两分区的增量差及固定对照误差，避免把缺样解释成颜色规律冲突。覆盖未达标时，停止从这张参考直接使用最近 RGB 重放，不据此排除有充分配对覆盖的局部颜色模型。父实验全图复现未通过的状态保留。
