# 同一输入颜色在四个场景里需要多少不同处理

上一轮已知编辑后两张人像仍迁移不足，Cuckoo 草地误差为 6.761 RGB8。固定四组同款 RawTherapee 成片与上一轮出图，核对失败是缺少相同输入颜色，还是相同颜色确实对应不同编辑。沿用上一轮 80% 编辑真值和原有区域。先验条件为输入 RGB8 三通道逐值相等，跨场景至少另一组存在相同值。无下载，不换模型，CPU 预算每遍两分钟。

唯一对比为每种 RGB 共用逐分量色度残差中位数，或每组场景分别取中位数。共用表在四场景的所有重合像素上给出不设色域限制时的最小总绝对误差；单场景表提供同图参考。区域均值只是同一张全图拟合表下的残差，不能称作该区域单独最小误差。两张表都读取编辑真值，仅用于离线诊断。生成固定亮度的两臂成片，缺少跨场景重合的像素共同使用同图中位数。不得用这些读取真值的成片评价自动推理。

对冻结测区报告精确重合覆盖率、重合与未重合的原候选残差、两臂分量中位数误差，以及两臂渲染误差。重合至少 128 像素且覆盖率至少 50% 才在该区判定趋势。当共用中位数误差比同图高至少 1 RGB8 时，记录场景差异证据；若两个既有失败人像整图或 Cuckoo 草地至少一处达到该条件，后续优先检查哪些场景信息有用。否则不以精确重合试验为依据引入场景模型；覆盖不足保留缺测，不等同于附近颜色也缺失。保留所有测区，本轮不申报产品门槛。
