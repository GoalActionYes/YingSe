# 固定明度后，输入底色能否解释跨素材的暖色幅度差

上一轮按七档明度校正，八张实际成片仍只有 61%–70% 的有意暖色。现问真实底色之间的差距能否解释这批偏弱。已有照片的 Lab 色度跨度远大于原有近邻量化控制，例如 FAU 杯带 b* 约 4，Beyond RGB 目标约 47。[上一轮明度实测](../../docs/research/2026-11-25-warmth-lightness-response.md)

先从冻结关态读取已核验的四个 FAU 灯档与两个目标的有效编辑核心，按上一轮规则取 D50 的 a*、b* 中位值。与固定 (3,9) 锚色合计七个底色。每个底色均设名义 L*=60。转到 sRGB，记录浮点 RGB，并先验证各通道处于 0–255 内，再舍入为 8 位。缺测时保留原因。分别在 FAU 狮子与 MIT 客厅已冻结的两个位置模板、尺寸、PP3 和核心中实际显影开关。测试因素只是在同一位置内替换底色。两块用于重复核验，保持位置与编辑参数。实际关态 L* 须距 60 不超过 0.30，另报全组实际极差。沿用原色度量化 ≤0.65、关闭逐像素保持、有效核心 ≥80%、编辑外逐像素保持和新增端点 ≤2%。记录两块实际颜色、支持、色度向量、预设 (1600,2800) 方向投影和向量方向偏差。相同 RGB8 保留各自原标签，共用一个实际响应。

幅度使用每块横跨七个有效底色的共同核心估计，仍须 ≥80%。以固定锚色归一化，两块差须 ≤0.10，等权平均取得各底色的响应。若任一样片超色域、同亮度或支持条件失败，对应结果登记缺测，不外推或替换底色。未纳入共同核心的差不用于推断色度响应。

以共同核心上的正 Lab 响应算目标除以参考的倍率，缩放既有配对 a*、b* 偏移，同时保持 L* 变化为零。非正响应视为缺测。固定八个方向，在两个目标上重放，关闭态仍为旧恒等控制。真实目标开态仅在八张新成片和哈希回执完整落盘后读取。两臂均与同一份冻结真实目标开态按 80% 混合所得图评分。实际重放对照用上次明度试验前的原 FAU 配对结果，不叠加该试验倍率。保持 RGB8 响应 75%–125%、原色差、保护区及新增端点 ≤2%。缺测、幅度失败和其他画质失败单独记录。

若四组完整成片全部达标且原通过区无退化，再在新场景验证。有效成片只要仍漏暖，就结束用 L*=60 的平场倍率单独修正这批幅度的方案，随后可把相同核心像素置于真实周围内容，验证局部混合。幅度达标但画质失败时保留幅度结果并记录失败项。若八图缺测则封存未得分回执，成因保持未定。输出不能界定实际明度与底色的交互。目标和参考位置来自冻结实验信息，本轮仅为有配对信息的开发诊断。准备与核验预计 20–35 分钟，两遍机器合计上限 5 分钟，无新拍摄、安装或训练。
