# 单张参考能否显示冷色集中于人物以外

白球服的离线重分配依赖已知局部编辑标识。这里用单张参考成片、自动人物概率，检验人物边界相邻且亮度接近的像素是否提供可用的局部冷色线索。旧的区域直方图替换和类别颜色校正直接改变了输出；本轮只检验参考端能否辨认局部／整图编辑意图。

沿用上一轮冻结的六组、每组基础／背景冷色／整图冷色三张参考 PNG。同一参考的三种版本完全同组。冻结现有 DeepLabV3 MobileNet 权重、预处理及 GPU FP32。每张图独立取自动人物概率，配对相隔 16 或 24 像素的横竖像素。只留一个端点概率 ≥0.80、另一端点 ≤0.20、两端 BT.601 亮度差 ≤12 的配对。计算其背景减人物色差沿冻结冷色单位轴的中位数。少于 128 对时无判定。对照分数使用整图平均颜色在同一轴上的投影。

以整张原参考留一。四个有人的场景各轮只用剩余三个场景定阈值，取局部类均值与基础／整图类均值的中点。少于两个完整训练场景时无判定。分数严格超过阈值才判为局部。对两个无人场景用全四组定出的阈值预测，预期全为非局部或无判定。无需读取待测参考的其他版本、原图、人工蒙版或目标结果，也不对自动概率使用人工标注校准。

预先固定推进门槛为四张局部至少三张命中、其余十四张零误触发，且至少三个有人的场景的局部分数同时高于同图基础与整图版本。最后一项只用于成组分析。只有通过才考虑另立正常两图的渲染协议。额外记录未判定、组内排序与相比整图对照的差距。失败保留原有离线对照，停止此固定特征和阈值，不在本组上搜索参数。成功也只针对受控冷色和已用素材，不能外推任意调色或自然参考。两遍各不超过 60 秒，不下载或训练分割权重。
