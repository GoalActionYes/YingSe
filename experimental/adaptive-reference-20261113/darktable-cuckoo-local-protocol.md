# 核验实拍人像里的蒙版去绿操作

固定《Cuckoo》的同一原片与 Todd Prior 第 11 楼公开 XMP。作者先用全局白平衡修正脸部，再在 RGB 色彩平衡中按胸口色相选取蒙版。这轮只关闭 XMP 中唯一一项已启用的 `colorbalancergb`，保留白平衡、曝光、蒙版参数和其他工具。沿用本机已核验过的 darktable 5.4.1 CLI 和 sRGB8 PNG 输出，长边 1024，禁用 OpenCL 与用户预设。若原样作者 XMP 无法出图，测试同一原片无侧车导出以定位范围。两次调用都保留现场日志，原样作者路径失败则停止此 CLI 路线，不把默认成片或模拟调色当关态。复用上一轮原片，仅取小于 64 KiB 的公开设置。

核对开关仅一字节并可逆。若两态都成功，重复导出，先从关态登记胸口、脸颊、浅灰树皮和草地的内框，使用原人像试验的 RGB8 色度测量方式。胸口至少 2 码值、树皮和草地各不超过 1.5 才能作为限定的局部修色实例。脸颊只作额外读数，因为这项蒙版操作主要用于胸口。若关态没有足够的区域、任一状态不复现或不达标，保留相应反例。只对单个编辑操作做离线测量，不计为跨场景成片或自然画质验收。
