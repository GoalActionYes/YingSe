# 参考前后图空间拟合的绝对坐标对照

红岩参考前后图的空间拟合改善了雕塑目标，但此前与全局二次拟合相比，同时改变了网络和可见信息。问题是相同网络能否在不读取绝对位置的情况下保留单例收益。保留 RGB 邻域、参考前后图、目标、模型结构、初始化种子、优化参数、窗口采样和 80% 输出。唯一干预是训练与渲染时将归一化 XY 都设为零。该对照只检验绝对坐标，卷积邻域、图像边界和相对空间信息仍存在。

使用已通过结构核查的同组红岩与雕塑素材。同次分别运行既有 XY 路径和固定零 XY 路径，各 1,000 步，单臂 GPU 循环预算 90 秒。分别保存频率固定的训练日志、参考重建、目标输出和哈希，生成后读取作者目标评分。既有 13 号和全局二次拟合仍为外部对照。无新权重、照片、训练集选择或软件接入。

控制臂须通过既有整图和近中性色门槛。若零 XY 臂也通过，整图和近中性色相对同次控制各至多退化 0.25，则在该样例上无需绝对 XY 即可保留已观察收益。若任一指标相差超过 0.50，则记录绝对坐标开关与该项误差的变化方向，再决定是否优先调查位置或其他信息。处于两界之间时保留为不确定。本轮无论结果如何都属于额外参考原图诊断，不能计入两图推理或独立验收。不搜索其他坐标值、种子和训练步数。
