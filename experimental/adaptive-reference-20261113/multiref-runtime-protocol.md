# 多参考候选的运行检查

候选已通过新32独立图完整数值门槛，但尚未接入App。运行检查显式使用`SpatialEngine('multiref-v1')`；无参数默认仍为App第8轮，不切换已有工作台。两种配置均为固定文件／SHA，不接受任意权重路径。候选角色为多参考普通监督第6轮。

原尺寸数值检查沿用已有空间渲染协议的全图／分块／边界／零与半强度阈值；同样的640×360人物短片、平移和细小亮度变化检查仅改模型配置，实际输出解码帧数及重复帧确定性照常核对。六张原尺寸开发图仅用于观察尺寸和适用边界，不称新的独立集。

速度另用同一进程、同一目标／参考、相同预热，交替运行App8和候选，各6次，以640×360和1920×1080的完整prepare+apply中位数比较。跨次历史运行的GPU／CPU状态不同，不能把旧日志耗时直接归因为权重变慢。此比较不含UI、解码或编码，也不保证30fps视频。

完整人物运动视频沿用`natural-video-protocol.md`的自有P1106511-8bit-SDR.mp4、参考67849、30.25秒完整区间、720×1280、固定30fps及上方背景评价ROI，只将权重显式换为候选，保存独立`motion-multiref-v1`目录。旧协议的“固定第8轮”描述是历史控制，新运行配置以本协议及输出checkpoint SHA为准。

该片逐帧生成网格，记录静态背景RGB均值、帧间变化及输出与输入残差，与旧motion-v2日志并列；不凭全帧运动差或单片无明显闪烁认定普遍时间一致性。诊断片不带音频，不冒充工作台音轨／导出一致性验收；4K原尺寸和HTTP导出另测。观察到不稳定时先记录，不改参数掩盖。研究图、诊断片和权重不入Git。
