# 真换灯与同向数字染色的墙面和肤色出图

固定复印室 0／16 和左墙资格。对 0 号参考施加保线性亮度的色比变化，该变化只由左墙共同有效像素的差估计。在实拍、数字参考、未动参考的共同有效像素中，墙面变化范数须至少 0.08，实拍和数字参考的估计色比差须不超过 0.025，共同覆盖至少 80%。保存整图裁切率，另报参考灰球及右墙的剩余差，不用它们定参数。

目标固定客厅 14 号与 Gros 01 冷灯。分别对稳定版、13 号用原参考、实拍换灯和数字染色出图，统一 80% 强度。墙壁用上轮登记的左右框，人物用原双颊与白幕框。目标期望是在目标施加与参考相同数字转换后混合 80%，只用来评分。沿用目标保持、换灯串色 RGB8 MAE ≤3、编辑响应投影 0.75–1.25 及误差 ≤3。检查全部测区与整图。两个目标均为开发素材。两遍固定出图，结果不能视为真正的墙面自然度或独立评估。
