# 实拍换灯的空间变化能否跨灯强复现

已有实拍蓝灯对照中，全图颜色矩阵留出空间图块后的误差高于预设门槛。空间变化可能来自局部受光、材质分布或成像。只允许矩阵随横纵坐标作一次变化，用同场景一档灯强的白灯与蓝灯拟合，在另一档灯强的白灯成片上出图，双向测试。全图矩阵使用相同拟合源和留出目标。沿用两场景、两档灯强、Film A 关闭态、线性 RGB、相同可用像素和编码。每个方向另用拟合档已登记的数字增益生成两档数字对照，确保真实跨档对照和数字正控没有混用，且数字正控的增益确实固定。拍摄源和构图共享，结果属于开发诊断。

沿用实拍 RGB8 MAE ≤ 3、像素平均通道误差 P95 ≤ 8，以及数字控制 MAE ≤ 1、P95 ≤ 3。要求两场景各自两方向都过线，且同一留出区域空间臂实拍 MAE 较全图臂至少降低 15%，数字 MAE 增加不超过 0.25；否则停止用一次坐标项解释并补足这组实拍换灯。若通过，再寻找普通单张参考中可估计该空间变化的输入证据。若其中一类失败，报告对应限制。整个检验只做 16 次最小二乘拟合和 16 张出图，重复两次。实拍留出蓝灯成片只参与评分和共同有效掩膜，离线源档配对参与拟合。
