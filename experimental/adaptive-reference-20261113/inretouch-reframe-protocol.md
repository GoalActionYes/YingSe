# 重新取景是否改变同一内容的空间调色

上一轮确认绝对 XY 参与雕塑单例收益。问题是同一目标的重叠内容改了归一化位置后，能否保住以参考前后图学习到的效果。

勘误。运行前文字误判 `CNNDWSplitSiren` 的执行路径仅有 1×1 卷积。运行后确认 `model_m` 调用 `CNN_DW`，含一层 3×3 深度卷积。原协议、哈希和勘误记录均保留。比较、预算和门槛沿用运行前版本。复核另记录去掉一圈边界后的差异。

沿用固定的一次 1,000 步拟合和默认参数，保持参考前后图不变。目标保留原图对照，分别裁去顶部和底部的八分之一行数。两张 RGB 裁切各渲染两次，一次沿用裁切在原画面中的 XY，另一次按裁后画幅从 −1 到 1 重新分配 XY。无插值、无重训、无参数搜索。原位置对照隔离张量尺寸和裁切本身。每组仍按 80% 混合，并在读取作者目标前保存输出与哈希。预算为固定一次 90 秒 GPU 拟合及四次追加渲染。

在同一裁切区域计算重新取景相对原位置的整图和近中性色 RGB MAE，以及两者各自相对裁切后的作者目标误差。原位置裁切与全图结果裁切须在两区域均相差不超过 0.25 码值，才认为尺寸对照有效。若两方向重新分配 XY 都使任一区域输出变化超过 0.50，则记录明显取景敏感性；若两方向两区域均不超过 0.25，则本轮未观察到明显变化；其余为不确定。按全部方向如实报告角色误差，无法由这张图判断另一种构图是否需要重新设计渐变。此试验仍含额外原参考，仅为离线诊断。
