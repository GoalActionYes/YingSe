# 同原片局部重放工作台验证

独立研究工作台验证已核验的同原片局部重放能否从真实上传、预览与导出使用。保持两个普通输入。完整参考和整数裁切参考仍须通过原有几何与共同细节门槛，开放八百万像素以内的静态图片。不重调阈值。一旦支持不足，沿用既有 13 号工作台。该能力的收益限定于同一原片，跨场景画质与既有产品验收要求保持。

- 使用独立项目目录、服务身份和 Git 分支。复用 13 号图片与视频导入、色彩解码、工作台、微调和导出。运行时用原尺寸核验两个解码 RGB，调色只重放已确认的重叠范围。目标边界外保持自身。图片原尺寸 PNG 与缩小预览共用已核实的像素基准，当前强度与微调仍在混合后应用。原件和映射仍由现有存储验证。关闭并重启后重新核验成片。
- 正例固定原研究的两位作者各完整参考与裁切参考。真实请求检查 80% 优势、关闭图逐像素保持、预览的强度端点和微调、恢复后导出、CUBE 拒绝。负例固定该研究的 12 张 Gros 间换灯、2 次固定机位重拍和 2 次白球服异图，要求实际 PNG 精确回退。JPEG 另记，只有原门槛允许重放时才计作开态。固定一段旧短视频比对默认 MP4，保留当前视频管线。两遍同报告、或解释并核验非画质的计时差。
- 机时预算 10 分钟，准备和核验约 60–90 分钟。任一重拍误触、图片不能复现、视频或微调回归时保留失败，独立入口留在研究状态。所有素材为开发用途，保持完整独立验收标准。[原始开关成片及边界](../../docs/research/2026-11-24-same-capture-detail-replay.md)
