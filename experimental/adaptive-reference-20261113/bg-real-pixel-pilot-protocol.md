# 换背景对照的主体像素与 13 号串色小样检查

从已经核验的 87 对中只取作者标作 Man 或 Woman 的前四对，按源主体 ID 排序，供体仍不重复。不因文件内容或成绩重选。每对下载 C1、F1 和共有的主体掩膜，固定发布版本，12 个成员共最多 12 MiB。每个图像按发布清单 SHA-256 核验。掩膜按固定发布的对象哈希或内容哈希核验并留全部署名本机。

先检查原尺寸及主体核心。以半径 5 像素的方形腐蚀分别取主体和背景内部。要求两个区域各至少 256 像素，C1／F1 主体核心 RGB MAE 不超过 1 码值，背景核心 RGB MAE 至少 8 码值。记录全主体、核心、边缘变化。失败仍保留，不替换素材。

如果至少两对合格，固定依次用既有目标 785、9483、872、8021 搭配这四对参考，80% 强度，以实际两图生成 C1 和 F1 对应成片。作者参考掩膜、目标人物标注只用于离线核查；不修改模型。报告相同目标被不同背景参考驱动的整图、人物、人物内近中性色及整图近中性色变化，并以超过 1 码值记可量化变化。用于开发负对照，不认定全部变化自然上都不允许，也不替代保留有意局部风格的正例。两遍 CPU 取样评分，必要时用现有设备完成推理。媒体不上传。
