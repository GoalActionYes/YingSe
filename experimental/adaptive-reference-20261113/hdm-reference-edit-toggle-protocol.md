# 实拍参考的原片、等亮度和作者调色对照

《Bistro》和扑克在采用《Showgirl 1》作者成片作参考时，目标近中性色均偏离各自作者成片。检验这个现象有多少在使用同一参考的原片时就存在。锁定两目标的 1 倍曝光、已有显示转换、13 号权重和 80% 强度。两目标各跑三个参考状态：同帧原片、把原片颜色调整到作者参考的逐像素线性亮度、同帧作者成片。最后一臂要求与已有成片逐像素一致。目标成片仅用于离线评分。

在两目标既有三档共有近中性色位置，测量原图和各输出到目标作者 PQ 裁切前色度的距离。再把原参考造成的目标色度变化、提亮参考带来的增量、以及等亮度下换参考颜色的增量，沿最终色度变化方向作逐像素向量投影。每组至少 256 个像素。若原参考已重现过半偏色增量且误差仍比原目标大至少 0.001，登记为存在与参考后期无关的传播证据。等亮度臂量化后逐像素 Y 最大误差须 ≤0.005，且为保持色域而缩减色度的位置不得超过参考的 10%，才允许用该臂解释两种参考变化；否则只报告区别与限制。

只回答上述来源问题。两目标共享同一参考，作者调色意图未核实相同。CPU/GPU 预算两分钟，无新权重、无下载、无推理接入或保留集读取。
