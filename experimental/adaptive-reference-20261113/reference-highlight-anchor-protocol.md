# 用多处亮部颜色线索检验参考编辑是否可辨认

参考物体与背景颜色会盖过真实编辑信号。本轮检查能否从参考中不同位置的亮部变化提取共同色度线索。原因假设是某些材质的反射高光会让局部色度朝同一个光色偏移，数字编辑也能改变这个交点。因此尝试联合不同位置的颜色方向，而非平均边缘色、按位置拷贝参考或把较亮像素当中性。任意实拍像素对不一定是反射高光，交点仅用作待验证的参考描述。

单张 RGB 按比例缩至长边 256，解码线性 sRGB。横纵各取间距 2 像素的亮暗对，线性亮部 Y 在 [0.30, 0.85]、亮暗 Y 差至少 0.05，两端 RGB8 通道在 [4,249]，归一化线性 RGB 的 (r,b) 色度变化长度在 [0.009,0.12]。以亮端划分 4×4 块，每块至少 16 对才参与，同块权重相等。对色度连线拟合共享交点。至少 128 对、4 块，正规矩阵较小特征值 ≥0.10，亮端前向支持率 ≥55%，加权中位垂距 ≤0.025，交点位于 RGB 色度三角内，才登记为可用。先用固定的线性混合色块和均匀负例核对方向、无裁切及拒绝路径。

测试一沿用 FACD 七组和原四组训练折。用原亮度分带岭分类作控制，候选只追加公共交点坐标（缩放到 255 量级）和可用标志。缺支持时坐标置零且明确登记。无调参，并要求原控制复现 28/42，候选至少 34/42 且至少五张查询照片的三个滤镜均有支持。闭集这里只检验能否提供新增可辨信息，不为三套固定表做产品选型。

测试二沿用四组 BG-REAL 两背景、复合编辑开关。每组四张参考的交点全部可用时，计算同画面开关改变量和同编辑换背景改变量。两背景的开关方向余弦 ≥0.5，且最小开关改变量至少比最大换背景改变量大 0.005，才称该组可区分。至少 3/4 组通过。两项联合通过才做成片验证；缺覆盖或失败则保存数值及定位，停止固定做法。预算两遍纯 CPU，无新媒体、调色推理或调色模型训练。作者成片只在原有分组里提供参考角色和评估标签，未接触最终验收。
