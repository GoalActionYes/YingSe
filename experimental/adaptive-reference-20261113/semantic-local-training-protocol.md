# 冻结内容对应的局部颜色学习：匹配对照

候选使用既有1365项DINO局部token缓存，不重训描述器；原13号主干固定，不训练原区域残差头。区别于旧解析DINO锚点是通过真实配对学习使用局部颜色；区别于旧自训练参考token分支是使用固定预训练内容对应，且不更新原网格主干。

每图64个8×8 token，384维单位内容特征及3维颜色。目标／参考特征余弦乘10、参考维softmax得到64×64权重；聚合参考384特征＋3颜色。每个目标token拼接自身387维和匹配参考387维，经774→128 GELU→12，末层全零。12值为3×4仿射系数，8×8系数字段双线性插值至目标尺寸，align_corners=False；应用到目标归一化RGB＋1，残差0.1*tanh后叠加固定原主干浮点输出。像素位置和结构不生成、不移动；普通CUBE不能表示全部效果。

控制计算同样的输入token和相同模块，但参考特征／颜色先均值化并重复64次。两臂初始化、参数量、样本流和预算相同，注意力有效选择能力不同，不宣称有效容量一致。目标保持局部信息，两臂均不输入人工或自动人物蒙版；只用RGB可计算特征。冻结余弦对应并不保证语义、材质或照明对应正确。

固定seed20261128、AdamW lr1e-4/wd1e-4、batch4、8轮各256更新、梯度裁剪1；同grouped_batches；损失RGB L1＋0.1横纵梯度L1，不加教师、额外增强或loss。全64开发RGB均值选轮，包含零轮、平局取早。相同全部train1024/development64，不选支持子集，不读取独立数据。

先测试零输出、池化控制不随目标query变化、局部对应可区分位置、同时置换参考特征与颜色的不变性、非法输入拒绝、梯度与残差界限。实际64图两臂零轮必须恢复原主干RGB8像素哈希，主干缓存每例核验浮点量化与字节渲染一致，任何失败停止训练。缓存父文件、token范围、模型／源码哈希核验。开发先保存全体预测再读GT。

沿用完整门槛：对当前版RGB均值改善≥5%、≥40/64改善>0.1、严重退化≤2，第二参考32均值不退步且≥17改善；对匹配控制均值改善≥3%、≥36/64改善、严重退化≤2；32组delta均值改善≥5%、≥20组改善>0.1。严重退化指增加>5且>25%。此外沿用关系／明暗／反差／饱和度非退化要求，不用均值单项替代。通过后才冻结独立自然、人类评价及视频／性能验证。

失败停止固定方案，不调温度、残差幅度、层宽或种子。每项学习都不证明剪映实现或可发布成果。需要在线DINO编码，后续计入首分析成本。数组、模型、媒体留本机，代码与数值摘要上传研究分支。
