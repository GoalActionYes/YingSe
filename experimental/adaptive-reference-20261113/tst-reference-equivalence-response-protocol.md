# 同结果一致性与不同结果响应的联合训练

上一轮直接拟合同结果一致性，在开发组降低同结果换图差，但联合通过从 7/24 降至 6/24。本轮只检验一项增量。保留该候选的逐图 RGB 监督和同结果损失，另外要求第三个输出相对前两个输出的 RGB 差，各自匹配作者的不同结果差。两项不同结果差的 L1 取平均，附加权重固定 0.25。相比旧版向量配对监督，本次变化只约束同一个目标的实际出图响应。

复用固定的 82／24 分组、13 号初始权重、样本顺序、直方图分支、AdamW 参数、每次 82 步共 3 轮及末轮比较。先逐像素复核基线，再只训练一臂，复用已完成的同预算控制及仅一致性候选。训练循环预算 240 秒。作者结果只用于训练和评分，推理仍用目标与单张参考。

保留完整上一轮门槛和全部反例。候选还须比仅一致性候选多至少 3 组联合通过，才将收益归因于新增响应约束。若达不到，结束使用固定直方图分支和这组同结果／不同结果损失的续训，不改权重、步数或门槛追分。通过才进入另外的背景换色和完整验收。独立保留素材不参与。
