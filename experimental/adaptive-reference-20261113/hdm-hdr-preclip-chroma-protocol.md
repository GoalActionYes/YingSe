# 扑克镜头作者成片在显示裁切前的色度

前轮等亮度对照中，1,397 个固定近中性色像素有 1,381 个在作者 SDR 转图里红通道到达 255，排除端点后仅剩 16 个。原图及 13 号成片在同一像素均没有端点。本轮只换测量参照，检验作者成片的显示裁切是否影响色度判断。使用前轮冻结的同一批原片、输出和坐标，从已经校验的作者 TIFF 按 PQ 解码、转为线性 RGB 和 XYZ，在显示压缩、裁切和量化之前取 u′v′。保留原 512 × 288 缩放顺序，防止改变像素对应。保留全部三档原片与输出，不主动排除端点或调整曝光。

在共同像素上，三档 13 号的平均色度距离若都比原图增加至少 0.001，才支持退步方向不依赖作者端 SDR 裁切。若各档方向不一致或门槛未达，记录影响和全部分数。若某像素 XYZ 色度未定义，报告数量并停止作强结论。预算为本机 CPU 解码一帧，无下载、训练或推理。作者 HDR 色度只作为相同位置的档案参照，不等同于 SDR 审美目标。作者论文确认该镜头白桌布由 HMI 照亮，测量区域仍按原图 RGB 阈值生成，未单独登记桌布或人体区域，不写成白桌布或肤色专项成绩。
