# 用另一张人像的编辑前后图估计分段色度

上一轮使用目标自己的参考答案拟合局部偏移，证实按明暗分段可表达多组脸部偏差。这轮检验偏移能否从另一张照片估计。复用《Cuckoo》和混合光人像，两张照片的原始显影不同，编辑开关与参数相同。两张已进入开发，双方互作参考，每个方向只用供样照片的原图及 80% 强度编辑图拟合。目标只提供未编辑原图。目标的期望图及既有评分区域在生成两臂之后才读入。

两臂均估计供样两图的 RGB 色度差。供样像素要求两态的三个通道均在 8–247。固定偏移臂使用整个有效像素集的各通道中位数。分段臂按供样原图的亮度分三等频带，记录各带亮度中位数与色度差中位数，并按目标像素的绝对亮度插值。超出中心范围时使用最近端值，报告该比例。带内不足 64 像素或中心不严格递增时，记录失败并退回固定臂。两臂均将偏移应用于目标原图全幅，复用上一轮 Rec.601 亮度锁定与色域回缩，量化后最大亮度偏差限 0.5001 码值。未编辑态逐像素保持。

13 号归档用来交代既有软件在同样素材上的表现。新方法多知道供样图的未编辑态，两个实验臂之间的比较用来判断分段的贡献。沿用既有 Rec.709 系数的色度评分，两个方向的整图和共同近中性色均要求投影 0.75–1.25、误差不超过 3 RGB8，并至少有两个区域相对固定臂降低误差 10%。《Cuckoo》固定脸颊、浅色树皮、绿色背景三个区域的误差各不得增加超过 0.25 RGB8。保留完整数据和成片。两方向各生成两张成片，复现一次，无训练或重新显影。本轮达到门槛，也只支持在已知供样前后图的条件下继续验证。
