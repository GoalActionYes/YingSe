# 往返调色残差能否纠正原成片的色度偏差

13 号普通两图调色会把部分背景颜色带到人物、白衣及其他中性色。有意风格也可能偏弱或反向。已知底色或照明的干预不足以解决这个问题。本轮测试只由当前两张 RGB 产生的额外线索：把正向成片以原目标为参考反向调色。如果两向误差各自贡献近似的共同色偏，往返回不到原目标的残差可能指出正向偏差。如果残差主要来自正常风格的不可逆性或反向模型误差，修正会伤及风格。

以既有 13 号 80% 输出为对照。候选基于该成片生成反向条件与 80% 结果，从正向成片的色度减去一半的「回程减原目标」色度，保留正向亮度，用现有渲染器处理限域。系数固定，不追加可调阈值或训练。参考与目标逐像素相同则返回目标，正向成片与目标逐像素相同时不修正。处理不读取任何真值、编辑开关或人工区域。

两遍各 72 张成片，沿用已有四套开发门槛。BG-REAL 的原登记六项重点肤色须至少五项同时改善 25% 与 0.25 RGB8；其余九处区域里的测量任何一项不得增加超过 0.25 RGB8。反向保存附加成片以便复算，并报告色度改变量和亮度量化误差。四套原门槛和局部限制同时满足才继续考虑候选；否则结束这一固定的对称补偿。控制在现有 GPU 与 CPU 上运行，不安装新依赖。
