# 已知答案的条件拟合诊断（不是产品算法）

前一条件头学习未过门槛。先固定诊断：当前epoch6主干冻结，每个已消费开发配对独立优化一个128维条件残差，检查该接口在有答案时能达到什么实际误差。GT直接参与优化和选择，绝不能称为无GT推理、独立测试或可交付效果。

使用全部64开发配对，原256RGB8与数据哈希不变，不读取新保留集。每批4图，残差初始化0，Adam lr0.03，固定128步；每步仅优化残差，梯度裁剪1，更新后分量限制[-3,3]。主干eval且参数不更新。损失仍为RGB L1加0.1横纵梯度L1；不使用风格余弦或PETAL编码器。固定seed20261126，不搜索步数、边界、学习率。

在0、16、32、48、64、80、96、112、128步保存各图RGB8误差、对应残差；每图仅在这些快照中按GT像素MAE选最佳，包含零步。保存所选原始float32输出、PNG和条件参数，便于核验取整与误差；全部64图保留。同批优化及GT选步均需披露。

零残差必须与原未启用路径原始输出逐项一致，与前一训练零轮PNG逐像素一致。主干完整状态前后相同，梯度均为空。报告原始/最佳误差、改善>0.1数量、每图残差边界、选步分布及32组参考响应。均值降低至少5%、至少40/64改善仅表示该接口在本次已知答案拟合下有进一步研究价值，不代表正常预测能达到。

若拟合明显成功，说明预测条件和学习方式值得继续检查；若弱，只能说明本次有限步数与约束下未找到好条件，不能证明接口数学上无法表示，也不能称为穷举最优上界。禁止将GT拟合PNG当作实际产品演示、覆盖前一学习失败或修改产品。
