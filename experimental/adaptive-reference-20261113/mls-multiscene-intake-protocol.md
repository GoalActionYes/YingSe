# MLS 新增同材质场景的线性原图资格检查

前一轮发现，蓝纸棱柱和绿色塑料棒是作者资料中唯一同时覆盖至少三个场景的两种前景材质。为了判断新增成像资料能否支持换灯诊断，固定补入 04、05、06、09，每场景只取 2HAL_DESK 和 2HAL_DESK_LED-B025 两张图。蓝纸同时复用 02、03。用原尺寸作者掩膜与预览掩膜互相核对。本轮不拟合模型，主要改动仅是补齐这四个场景。

作者按 CC BY-SA 4.0 发布。用已固定目录哈希的 FTP ZIP 分段读取，只下载八张 PNG 和小于 1 MiB 的原尺寸掩膜 ZIP，总量上限 48 MiB，不安装依赖。图像和掩膜保存在本机。[作者发布](https://github.com/Visillect/mls-dataset#license--citation)

文件须通过 ZIP CRC 和 SHA-256 身份记录。图像须为 1157×950 的三通道 16 位相机 RGB，灯组之间形状一致。沿用固定线性增益 4、省略逐图白平衡、随后应用 sRGB 编码的离线量尺，保留原始裁切像素数。灯组的全图亮度边缘相关至少 0.5。对应材质原尺寸与最近邻放大预览掩膜的交并比至少 0.90。内部像素用原尺寸掩膜向内缩两像素后测量，按既有共同有效像素检查，至少 256 像素且占内部半数。所有场景均列出灯组配准、掩膜尺寸与有效覆盖，任一场景资格失败则保留证据，不替换采样场景。若纸和塑料各三场景均合格，则有理由继续测试同材质换灯响应离开原拍摄场景后是否保留。资格检查不计入产品画质验收。
