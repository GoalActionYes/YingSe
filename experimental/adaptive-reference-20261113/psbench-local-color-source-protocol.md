# PSBench 局部颜色监督的来源资格核查

问题是可公开取得的作者素材能否提供可核对的局部颜色或明暗操作。固定 PSBench 数据版本 `929d0710eb7c86a988f8a69a74619052b60ac293`。从已公开示例 040 所在区间 `035–055` 和 201 所在区间 `201–240` 枚举任务 JSON。范围固定，不依据模型输出选任务。JSON 每份最多 4 KiB，总计最多 256 KiB。任务说明、编辑类型、源和结果角色可读，不重发指令原文或第三方图像。

手工阅读固定结果表。筛选同时满足可定位的区域、只改颜色／饱和度／明暗、可取公开前后图的任务。模糊、几何、物体增删、材质替换或只描述全图的工作流保留为排除记录。至少需要两个内容不同的案例拥有同一区域语义和同一意图，才考虑组建两图局部调色小样。文字相似只作线索，须审查图像注册、局部变化、可识别的背后意图和素材权利。可即时获得的图像限定最多两组、10 MiB，无付费、无安装 Photoshop、无执行工作流。

如果仅有独立的局部前后图，保留作编辑意图线索，不能取代跨场景同款参考和独立画质标准。本轮不改变软件或数据划分。

单例实图核查。任务 230 的人工说明包含整体蓝调和背景去色，固定先读这组前后图及评分规则。核对作者发布大小、SHA256 和准备后的尺寸。若图像可对应，检查同一原始 RGB 在不同位置的输出跨度，另以近中性色 RGB 表和象限表复算，无人工真值蒙版。这个单例的用途是确认文字意图在文件中是否有可量化的空间信号，不能独立组成两图参考迁移对照。
