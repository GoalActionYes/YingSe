# 共同 RGB 色卡对照同一编辑在两条显影曲线的响应

实拍参考与目标缺少共同肤色 RGB，无法判断近色的编辑响应是否一致。本轮以固定合成色卡建立有共同颜色的受控输入。每块颜色经两条流程处理。A 使用色卡本色，B 在编辑前将归一化 RGB8 按 0.55 次幂编码，在编辑器导出后应用相应逆曲线。除了这对互逆曲线，两条流程均使用相同的 darktable 4.0.1、同一项已校验的 RGB 色彩平衡参数及相同导出选项。曲线是可控实验变量，用于展示显影上下文，不能视为真实相机或 RAW 历史的模型。

预先固定肤色和中性灰色卡，各色块中心取 16×16 像素。只有关态的 A／B 中心逐通道最大差不超过 1、两态均未在中心触及 0 或 255 且 B 流程的 80% 色度变化中位数至少 2 的色块才可评分。沿用 80% 混合、原亮度渲染、色度投影和 MAE。将 A 的实际色度响应逐像素重放到 B 的关态色卡，B 开态在输出后用于评分。把 A 响应重放回 A 关态作为同流程检查。

两次独立重复均须有至少八个合格肤色块，同流程每个合格肤色块误差须至多 1。若至少四个合格肤色块跨流程色度 MAE 超过 3 且两遍判定一致，说明在这个构造中，接近的输出颜色也可对应不同的调色响应。中性块另报结果。若资格不足或没有跨流程差异，则不将此构造用于解释实拍失败。共两遍，每遍四次小尺寸 TIFF 导出，无训练或新外部素材。
