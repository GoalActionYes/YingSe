# 参考配对缩图是否影响白球服的颜色重建

对白球服来说，两种真实背景的旧配对只达到 0.537 和 0.606 的预期风格投影。粗 RGB 分箱中的邻近样本已经存在，加权仍未通过。本轮检查进入旧拟合的样本本身。参考原图和已调色参考都为 768×576，旧流程分别双线性缩到 256×192，混合可能发生在局部颜色变化的两端。

- 唯一变化是取样。旧臂保留双线性缩图。新臂取原尺寸每个 3×3 区块的中心像素，两张配对都取相同坐标，保留 256×192、8 像素棋盘、裁切筛选、正则和三次色表。保留原渲染和 80% 强度。先验证旧臂与归档逐像素一致。目标成片和区域仅用于离线评分。
- 固定前轮四组开发场景、两款风格、两种参考背景及 16 像素棋盘留出。白球服两种背景的投影均须为 0.75–1.25，响应 MAE 均不超过 3 RGB8。其余合格区域不得丢失原通过项，响应 MAE 不得增加超过 0.25 RGB8。沿用像素数和信号要求，保留缺测。
- 两遍固定运行，每遍 16 张新成片，另保存四张对照图及报告。结果通过说明可以进一步研究保留原尺寸颜色对训练的影响。失败则以本轮作为对预处理影响的一次排查，保留全部反例，不改采样相位或数量继续追分。由于使用了参考前后图，结果属于离线开发诊断。

## 首次运行中止后的尺寸勘误

首次运行的固定尺寸断言因参考原图包含 768×576、576×768 和 768×512 而中止。旧缩图分别为 256×192、192×256 和 256×171。正式运行在各自原缩图的宽高上按像素中心回取原图单点，整数比例时与原 3×3 中心规则相同。两版输入共享取样位置，样本数、留出和门槛不变。首轮未生成完整报告，成片不计入正式比较。
