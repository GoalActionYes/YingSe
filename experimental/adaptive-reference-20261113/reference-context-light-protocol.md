# 用编辑区外的亮度预测正常受光

同一面浅墙亮起来，可能是灯移了，也可能是照片编辑者只提亮这块墙。既有同墙三点和 4×4 全图 RGB 读数不能稳定区分。本轮只检验一个额外信号。墙面之外的场景同时记录了灯光变化，可否在没有看到待判断墙面时预测它在正常照明下应有的亮度。

## 输入和拟合

使用已有 MIT 两间室内和 WildRelight 两个户外场景的 18 个完整匹配方向。每次按方向把实拍灯档 a、b 同时排除。校准只读同一固定机位其他通过原素材线的真实未编辑照片。争议方向中的 a 关、b 关、a 开均作为留出输入。所有预测只接受当前参考像素，指定的场景校准先于预测，目标答案和其他两张同方向图不参与预测。场景位置、编辑范围和校准照片来自离线开发材料，所以这是响应上界筛查。

固定 8×8 全画幅分块。只有完全在编辑包围框和原评分框之外的块可读。每块以 8 位 Y′ 平均亮度表达，单值对照取同一批块的均值。两者分别用同一中心化岭回归预测墙面评分框中的有效像素亮度中位数。训练输入的归一尺度用本折行向量的平均平方范数，惩罚固定 0.1。截距取训练亮度均值。有效像素与原范围线保持一致。逐折核对编辑开关在可读像素范围是否逐像素一致，若不一致，该方向不计通过。

## 继续条件

真实留出 a、b 两档各自的亮度预测误差不得超过 3 Y′。编辑 a 开的亮度减预测值须至少为 3 Y′，并处于实测有意变化幅度的 0.75–1.25 倍且误差不超过 3 Y′。三个状态联合通过才计为一个方向。按两采集来源分别统计。空间分块须在室内至少通过 8／12、室外至少通过 4／6，并相对均值对照在每个来源至少新增一项且保住均值已通过方向。所有超线、无有效校准与实测异常保留记录。

若满足，才用新拍摄来源验证单参考如何自动获取位置与受光校准，后续先过原肤色、浅墙和暖色的成片门槛。若不足，停止依赖这批跨区域亮度作局部开关。保留各方向的真实亮度、预期亮度和输入图板。预算 20–35 分钟，两遍 CPU，无新下载、无 GPU 训练，独立评估素材不启用。
