# 主图像色彩目标：固定训练梯度核查

旧reference-patch确已测试多token查询交互，不能重启。PREEN新论文讨论RGB与CIELAB主图像目标的差异，但本轮未找到可直接用的作者权重／代码入口，不复刻其网络或自称采用作者模型。论文不是本项目改进的证据，只提供一个不同于辅助头的可检验线索。

本项目已试YCbCr色调统计辅助约束，但未比较主像素RGB误差与色度加权CIELAB误差。先固定4096训练清单原顺序前128行（无开发／独立图），使用未扩展新头的expanded-v2 epoch4，读取真实训练GT。每图计算原RGB L1、RGB MSE、候选D50 CIELAB主目标对预测RGB的梯度；候选为0.2 RGB MSE＋L*/100 MSE＋5(a*,b*)/128 MSE。白点、归一化和权重固定，不作开发调参。

报告RGB MSE与候选的逐图梯度余弦、冲突比例及RMS；原L1只作背景对照。用训练128行的聚合RMS比固定候选梯度缩放因子，使后续RGB MSE／候选目标在共同起点的像素梯度RMS匹配，避免仅将放大梯度解释成更好的色彩目标。边缘项不在本次校准内。若梯度几乎相同，则没有继续训练的依据；不同也只说明目标方向不同，不证明有画质收益。

Lab使用W3C公开公式的sRGB解码、D65 XYZ矩阵、Bradford至D50与CIELAB分段定义；安全计算未选中的立方根分支，黑色梯度不可NaN。先验证黑白／灰中性、边界有限梯度、双精度有限差分；本机固定小数组另查CPU／GPU值和梯度差。

仅读取原训练数据，无新下载、模型、辅助原图或优化器。保留全部128数值与输入哈希、原模型参数前后身份；不生成候选上线，不恢复已停止辅助归一化任务。之后若设计训练，对照为同预算RGB MSE主目标，候选为冻结缩放的Lab主目标，其余结构、主GT、边缘项与完整门槛一致；不以Lab评分替代原验收。
