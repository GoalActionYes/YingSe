# 跨内容同滤镜原图与成片的小样核查

需要能按原始照片隔离、并具有明确跨内容调色标识的配对。FACD 作者称用 GIMP 的 22 种滤镜处理每张原照。它能提供同操作标签，尚不能据此认定滤镜有针对皮肤或背景的空间调整。本轮只验证以少量字节取得、分组并核对真实前后图的可行性。结果用于选择后续两图实验，不替代自然画质和人工评价。

- 固定作者所链接的 `FACD_image.zip`，总大小 2,968,999,768 字节。只用 HTTP 206 字节区间，先取尾部和 ZIP 中央目录，元数据总预算 12 MiB。核对响应的 Content-Range 与长度，遇到整包响应、路径歧义或无可用条目时停止。
- 只取 `Origin`、`Amaro`、`Hudson`、`XProII` 中可用同文件标识的数据。以原图文件标识的 UTF-8 SHA256 字典序选前八组，先固定选择，再读图片。逐组不挑选替换；单成员压缩和原始大小均至多 2 MiB，媒体区间预算 16 MiB。只在服务器公开下载入口读取。数据仅用于本机学术研究，图片不进入 Git，不读取数据包中的 pickle。
- 校验 ZIP CRC32 和长度，记录 JPEG SHA256、解码尺寸以及原图与成片的粗结构。每组四份图不共享到其他分组。近重复以原图横、纵各 64 位差值哈希合计相距不超过 10 位为筛查线，含水平翻转。若至少六组的三种滤镜均通过既有结构门槛，且八张原照片无精确或近重复，建立一份固定开发小样。否则保留全部失败，不扩大下载。预先指定的三种滤镜是跨内容操作归因对照，艺术偏好投票和空间语义另行验证。
