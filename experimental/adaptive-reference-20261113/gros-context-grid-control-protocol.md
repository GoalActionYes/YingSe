# 同一提亮答案的直接网格对照

共享／按位置两种 128 维偏移都碰到固定幅度上限，右颊仍未达到 3 RGB8。检查同一目标编辑在相同原生前后处理下能否通过已验证的直接网格拟合。此前的直接拟合用的是另一种局部编辑，本轮只改变成上述两张目标和已冻结的半档局部提亮答案。沿用现有 16 像素棋盘留块、同一分区及原阈值，继续保留共享颜色矩阵对照。用既有 SciPy 1.18.1、每通道最多 240 步。预计 2–5 分钟，无下载或新训练。[主诊断](gros-context-capacity-protocol.md) · [既有网格拟合](gros-local-grid-capacity-protocol.md)

先复算未混合的编辑，并确认用 80% 强度生成的结果逐像素与已冻结答案一致。已知答案只用于离线拟合和留块评分。本对照直接拟合最终调色网格，主诊断则从既有冻结解码器的结果扣掉基线调色后衡量响应。两者用于确认同一最终答案的可达性，不将误差差异归为一项纯网络层效应。直接网格若通过则保留可达见证；未通过则在本轮不宣布获得渲染表达见证，不改阈值、步数或样本。
