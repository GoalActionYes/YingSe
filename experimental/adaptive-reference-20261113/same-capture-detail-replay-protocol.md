# 用共同细节像素核验同一原片的局部调整

目标是恢复已经看见的失败场景。用户把自己的照片和带局部调色的另一版用作两图输入。上一轮真实脸颊提亮在 13 号趋近于零，墙面和杯身反而发生变化。既有 SIFT 对齐在另一位作者的局部色度编辑上有效，但几何相同也可能来自固定机位重拍。本轮检验，在不训练的情况下，能否从两张输入里的相同纹理像素确认整数对齐，再重放局部 RGB 变化，同时拒绝把换灯照片直接贴回目标。[先前色度重放](../../docs/research/2026-11-20-playraw-mixed-light-geometric-replay.md) · [真实提亮失败](../../docs/research/2026-11-24-playraw-flash-room-workbench.md)

比较正常 13 号、只用同一整数几何判断的 RGB 重放、另要求共同细节的同款 RGB 重放。两个重放臂共用已实现的 SIFT、相似变换、55% 目标重叠与梯度相关门槛，只在确定精确整数对齐后使用相同的 RGB 混合。评分与其他实验一致维持 80% 强度、默认手动参数。保留目标的不重叠范围。拒绝时返回此前实际工作台的输出；新增负例使用实际 HTTP 图片导入、分析及 PNG 导出生成 13 号基线。编辑答案和评分区域只在离线测量使用。

共同细节核验把对齐重叠面覆盖到固定 4×4 目标画幅网格。对每个相邻 L 形三像素组，要求在重叠区，且横或竖相邻 RGB 码值至少一通道相差 2。有效组至少 128 个，且其中至少一半在两图的三个位置、全部 RGB 通道逐值相等，才记该格支持。至少 8 个格子支持才重放。该规则用于足量不受编辑影响的像素，颜色相同的平坦区不单独提供证据。重新压缩、缩放、非整数对齐和改色范围较大的照片可能没有足够证据。参数只运行一次预先指定的值。

- **正例。** 复用 Martin 的局部提亮及 Carlos 的局部改色。各用原先登记的完整、裁切参考及各自开关，一共四组。若裁切不覆盖前知测量区，应用原预设逻辑在完整范围保留该结果，且仍按原区域评分。Martin 沿用右颊、墙、杯的原门槛，Carlos 沿用掩膜高权重区及零权重近中性色门槛。两组另查全 RGB：有意区域开启后误差最多 3 RGB8，投影 0.75–1.25；关闭和非重叠范围保持原图。各态新增截断不超过 2%。
- **负例。** 两位 Gros 人像同机位低、中、高档互相作两图，共 12 个有序比较；CHROMA 两个此前误触全局三次拟合的固定机位重拍；白球服用陌生作者照片作关闭／开启参考；另对 Martin 的同原片两图都做 JPEG 85、4:2:0 重编码，记录可用证据及回退。实际重拍与白球服跨内容必须全部拒绝直接重放。JPEG 若放行，须按同一画质门槛检验，拒绝则匹配当前 13 号，不解释为 JPEG 支持通过。
- **停止条件。** 四组正例和指定负例任一失败，保留相应实际输出，不调阈值。若全部达到门槛，记录可复用的范围，并用更广内容、压缩、结构、工程和视频要求决定候选接入。若整数几何已全部拒绝重拍，则这一批只能确认新核验不妨碍正例，不能证明它带来额外拦截。两张照片的跨场景风格推断和最终画质目标另按原门槛继续判断。

在现有本机研究环境计划两遍，预计 30–50 分钟，机器出片预算 8 分钟，无需下载、GPU 训练或新增运行时依赖。代码仅放独立研究目录。
