# 自动定位能否保留已知光源的脸颊修正收益

在已有三位 UMINHO 人像的六个光谱成片中，已知光源及脸颊支持能达到肤色与灰块门槛。本轮只测定位覆盖。冻结作者的打码 JPEG、已有 MediaPipe 人像部位模型、登记的脸颊坐标与六张档案图板。定位模型只读打码的完整 JPEG，不读手工区域、光源真值或成片。把 `face_skin` ≥0.70 的结果以最近像素采样投回已登记脸颊的 64×64 评估块。将它乘到离线已存修正增量，比较已知矩阵和旧修正。此处落盘使用局部图板，原作者打码图及预测掩膜仅供本机诊断，不重建完整人像。

每个脸颊核心至少保留 95% 的自动覆盖，打码预览中 RGB8 三通道均 ≤3 的黑彩背景预测比例 ≤1%，两个标准光源方向的脸颊中位误差 ≤1.5、90 分位 ≤3，过渡带 90 分位相对原已知修正增加 ≤1。源光谱的共同色域与原实验一致，可从档案代码逐像素复查。只测自动定位对既有修正的漏检影响。现有灰块拼接未进定位模型，数值保留作为离线控制，不能解释为自然白墙或衣物保护。打码只在 D65 预览上，两个方向共用同一 RGB 检测，不能代表暖光人像上的重检测。六组合格后才值得在实际白墙、衣物、暖灯和遮挡中进一步查误报。两遍 CPU，保存全部合成成片与哈希。
