# 当前多参考模型：明暗／色彩响应诊断

固定当前第6轮、cohort-multiref-v1的32开发目标×2参考及已保存的64输出，不读任何reserved目录或新独立图。读取前记录脚本、模型结果、cohort及预处理清单SHA；准备图和预测逐个核验原SHA，不重选样例。该开发集已消费，不能称独立检验。

对每张图计算全图亮度均值、亮度标准差、RGB最大最小通道差的均值，以及Cb／Cr均值，均按0–255码值口径；另计算按当前图亮度中位数划分的亮部减暗部Cb／Cr均值差。分位区域只用于数值诊断，不是人物或语义识别。平坦图两区域条件均值差记0。

同一目标两参考分别有预测和GT，比较预测统计差与GT统计差的绝对误差，报告所有32组及均值。GT统计差绝对值至少2码值时报告方向是否正确；小于2记空，不人为算对。这个2码值阈值只筛方向有意义的变化，不删样本或改变平均误差。

全图统计不等于局部协调或审美真值。只用这份结果定位当前模型的响应弱点，不据此给已消费保留图调参数；新的候选仍需同预算训练控制、完整开发门槛及新的独立检验后才能接入App。当前产品权重保持不变。
