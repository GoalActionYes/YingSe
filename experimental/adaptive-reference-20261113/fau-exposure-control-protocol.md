# 用共同曝光控制复核双光源响应

上轮相机 RGB 编码整体偏暗，可能使 13 号拟合失败。此轮检测同一批实拍、同一风格强度在共同提高曝光后，色度响应的结论是否改变。

两场景的目标与参考均在 16 位线性相机 RGB 上固定乘 4，达到饱和则裁切，再沿用固定的 sRGB 曲线编码。记录裁切像素数。这是同一传递曲线下的曝光变化，保持相机 RGB 色轴，未做色域转换。不重新选择场景、方向、曝光或强度，不重跑原曝光推理。13 号读取两张新编码图，80% 强度，其他模型及处理沿用上轮。两份暗区和照明图在输出落盘后评分。

按上轮门槛计算增亮输入的整图和近中性色。另固定允许两种曝光中都满足有效条件的共同像素，近中性色范围由原曝光定义。在共同像素上分别用各自曝光的 80% 实拍对照评分，以区分像素换组和真实响应变化。增亮后两个场景的整图与近中性色须都满足原资格和响应门槛才支持原失败主要来自低曝光。仅能减轻一个场景的误差或改变方向，保留为限定条件下的发现。两遍本机运行，保留全部成片，不训练、不接入软件。
