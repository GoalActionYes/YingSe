# 用目标图的局部结构检查单参考调色判断

已知 Film A／B 能在局部色样充分时重放正确变化。此前从单参考的颜色可达范围、全图逆向先验和边缘统计辨认这两款，均未通过。目标图是普通用法中的另一个输入。检验目标和参考中结构相近的小块是否能提供可迁移的颜色线索。

- 固定原逆向查表，两款已知操作和未调色三个解释。对参考成片和目标原图按最长边 256 缩放，截取完整 8×8 块。结构描述用每块 16 个 2×2 亮度均值，减去整块均值。只取以结构距离互为最近且描述均方根差不超过 12、块均值差不超过 16 RGB8 的块对。对应在逆变换前固定，且至少需 16 对。任何目标区域和作者真值均不参与选择。
- 对三个解释分别计算匹配块红减绿、蓝减绿的平均差，最终取每个块对绝对差均值的中位数。最佳编辑解释必须比次名低至少 1 RGB8 且逆重放误差 ≤2 RGB8，否则选未调色。固定与旧方法相同的目标和 80% 成片。普通输入未包含参考调色前图。
- 四来源各自原 72 态，增加同一参考的 JPEG 85 压缩作为稳定对照。每种编码至少三来源通过原门槛：识别率 ≥80%，全部关闭态保持、至少 80% 视图通过整图及近中性色开关、换曝光或灯色的同款近中性色差 ≤3 RGB8。留两遍运行的 144 张成片及报告。若失败，结束以同像纹理的跨场景小块为两款风格判断依据，不在本批调纹理阈值。
