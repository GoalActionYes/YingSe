# 按光源实拍资料的开发对照准入核查

已有杯子换灯对照的色度结论难以外推到房间浅墙和中性物体。本轮核查 SyncLight 实拍按光源的组件，判断能否构造已知局部受光变化、同场景换视角的正例，与背景换物体负例互补。灯色变化从真实 RAW 的独立灯光响应合成，不能冒充任意风格或自然肤色标签。

只读取作者公开发布的元数据、场景目录和小型配置，不下载图像或运行作者代码，合计最多 1 MiB。核查版本、许可、实拍场景键、相机与灯位可配对性及精确成员大小。至少找到两个可独立分组的实拍场景，每场两台相机都含环境与同一非环境光源且原始成员总量不超过 128 MiB，方可进入固定小样渲染。若无法区分实际重采样、灯位编号或分组，保留缺口并停止该来源取样。无需登录、不提交资料。另记录人像实拍来源的公开访问与适用边界，若只能预览或需申请则不下载。

两个已查 test 场景的八份 RAW 超出体积门槛。补查范围固定为 real/train 中含至少四份 RAW 的两个最小归档，按发布字节数排序，同大小按场景键。保留原 test 索引与超限结论。train 目录含义属于上游划分，仅拟用于本项目开发对照。
