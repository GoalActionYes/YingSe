# 区分成片共同色调与换参考响应

扩展训练改善平均整图误差，换参考改善仅 18/32。逐张按往返误差选择又丢失 35 条原有收益。需要知道这批已有成片是否包含可分别利用的共同调色和有效的换参考响应。此前只混过每张成片的整体占比，也量化过单一模型的响应方向。本轮把两张同目标成片拆为它们的中点和差分，检验交叉重组的实际效果。

用同一 64 条已消费配对的 13 号、原 C10 和扩展第 4 块 RGB8 输出。每个目标有两个参考。在 32 个目标上固定生成九套分解组合。像素先用有符号整数算中点来源两图之和 M、差分来源第 1 张减第 0 张 D。两个输出分别为 round-even((M−D)/2) 和 round-even((M+D)/2)，再限制至 RGB8。对角线逐像素复现既有输出。按未经量化和裁切的数学表达，M 决定两张的共同色调，D 决定换参考差。记录裁切及量化后差分偏离，避免误解释。渲染所有组合后才使用作者效果。人工标注不进入计算。

报告两套预设交叉成片：扩展中点＋C10 响应、C10 中点＋扩展响应。报告九套全组整图和响应误差及既定双门槛。在每组中另外用作者效果取两幅平均 RGB MAE 最低的整组组合，顺序相同优先原扩展端点，保存全部 64 张离线最低误差成片。此结果是九组合里的最佳 RGB 误差，不是完整门槛联合最优。还逐组取所有九种实际 RGB8 差分中的最低响应误差，分别计算相对 C10 和旧续训最多改善组数。任一少于 20 即可停止当前九组合的选择方向，即使 RGB 平均值改善也不能通过。

这项诊断使用同一目标的两张不同参考，余项使用真值离线评分与取最优。不能作为普通产品推理。若离线上界有足够空间，才考虑另行验证正常两图是否能独立提供两种成分。CPU 两次各≤90秒，使用已审计 64 图及权重身份，不训练、下载或读独立集。
