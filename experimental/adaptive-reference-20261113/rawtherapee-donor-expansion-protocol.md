# 用额外原片补足已知同款显影的颜色覆盖

统一显影 Cuckoo 的 10.7% 像素无邻色，承载真实色度能量的 73.7%。上一轮用答案得到整图投影 0.991，本轮直接用额外照片验证能否补足。冻结本机四个此前已用开发来源的 RAW，包括走廊、餐区、DSCF0419 和 1Q8A5461。先仅用统一配置的关闭态筛选，在原无支持区以新增像素覆盖数为准，依次固定最多两张素材，新增像素为零即停。用路径顺序处理平局。筛选不看 Cuckoo 开态与标注，无下载。

只给选中的素材打开同一颜色平衡。取新增素材同色残差中位数，沿用 RGB8 距离 6、最多八邻居、倒数加权和固定原亮度。只替换旧无支持且新有支持的像素，其他颜色保持，三组原供体不变。两遍各最多六张显影与一张预测，CPU 每遍四分钟。原编辑答案仅用于输出完成后的评分与新增实际色度能量统计。

继续门槛为整图与原合格局部全部通过已冻结门槛，整图色度误差下降至少 0.25 RGB8。未通过时记录新像素和真实信号覆盖，区分新增数据根本没覆盖缺口，或有覆盖却无法准确迁移。通过也只证明已知同款操作和本组统一显影的开发收益。
