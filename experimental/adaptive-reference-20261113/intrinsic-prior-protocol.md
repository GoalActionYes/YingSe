# 彩色光照／反射颜色先验：首例运行协议

问题：与已失败的全局白平衡、人物分区和内容对应不同，固定预训练内在分解能否提供空间反射颜色与光照颜色的估计？本轮仅核对真实执行、输出身份、重复性和输入重建，不称参考调色候选或自然质量通过。

选取 Marigold IID Lighting v1.1，模型固定08c3930bb641abf786ba44ce92547507ebefbc16。它针对sRGB输入预测线性albedo、diffuse shading、non-diffuse residual，关系I=A*S+R；A不标为up-to-scale，S和R各有未知尺度。既有diffusers0.36.0包含MarigoldIntrinsicsPipeline，复用隔离依赖，不安装新环境。

许可：模型卡openrail++，作者仓库2bfbdeae5d10a50b71f1ba20c865d46e480f6010的LICENSE-MODEL.txt提供使用与分发授权，同时含占位文字，所链接上游SD2许可页当前401。只作本机无害图像研究；不能据此宣称许可链完整或可公开分发，后续产品使用前必须补齐。不是绕过账号或访问受限模型，所需完整微调检查点自身公开且非gated。

资产预算：仅三个FP16 safetensors，UNet1,732,019,968、CLIP680,820,392、VAE167,335,342字节，合计2,580,175,702字节，加必要小配置和分词文件；逐项核对API固定元数据的LFS SHA256或Git blob，不下载FP32、bin或底模。复用已有diffusers／transformers／torch，不重复下载其他已失败模型。8GB显存、16GB内存，本轮一次仅加载此pipeline，不关闭用户程序。

固定首例为已用COCO目标9483-input.png，canonical256 RGB BILINEAR。作者配置DDIM、4步、ensemble1、默认768处理尺度、batch1、seed20261117；两次独立重置同seed，保存三层原始float数组和可视化。不是用于生成新照片或补细节。单次600秒、首例总图片预算1200秒，OOM或非有限输出停止，不能降尺度／改步数冒充默认成功。

后处理只做离线诊断：按标准sRGB分段转线性，将A*S和R作为两列，以所有像素拟合非负两个共享标量，使其重建输入。用解析非负最小二乘枚举两项／单项／零项边界，不按GT调图；报告尺度、未截断误差、裁切比例、重新编码sRGB误差与原始三层范围。这个拟合读取原输入，不读目标效果或人工蒙版，也不能当作分解准确真值。

必要执行条件：三层尺寸与标签符合配置、全有限，两次原始float结果精确一致。重建误差仅描述，不自行设为自然质量验收。只有输出和身份可信，才另行预登记“已知照明变化下反射颜色是否稳定、物体改色是否仍保留”的小型控制；未通过不得直接拿反射颜色作白平衡或参考原图。旧白平衡／局部修正头不重启。
