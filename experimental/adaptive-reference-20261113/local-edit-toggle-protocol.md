# 单独打开局部冷色时，13 号能否只改变相应区域

白球服曾随参考背景物体换色而偏色。实际参考成片也可能有意把环境调冷、保留人物。本轮用同一处理环境分别导出关闭和开启局部调整的照片，建立已知局部变化的实图开发对照。旧背景干预测干扰抑制，旧人物风格训练测多参数合成监督，本轮直接比较完整两图渲染对同一局部操作开关的增量，并用同向全图操作排除只靠减弱响应。

沿用既有六组背景开发配对，人物及无人案例全部保留。目标和参考均从冻结原图生成三个版本。强度 100% 的全局基底为 `127.5 + .88 * (RGB - 127.5) + [6, 2, -5]`。在同一浮点底上追加冷色方向 `[-8, (8*.299-17*.114)/.587, 17]`。局部版只在存在人物时对人物以外区域生效，使用现有 11 像素膨胀滤镜和 8 像素羽化，人物内部权重为零。全图版对所有像素生效。三版各独立量化。无人图的局部版定义为原全局基底。

用固定 13 号及默认 80% 混合强度分别渲染参考全局基底、局部版及追加全图冷色版。推理仅接收 RGB8 目标原图和对应参考成片。源人工人物蒙版用于离线制作版本和评分。将各输出相对本组全局基线的变化，与预定目标效果相对其全局基线的变化比较。离线目标同样使用 80% 混合。先保存目标和参考前后对照，18 张模型输出落盘后再计算指标。运行两遍，单遍 120 秒，用现有 CPU 与 GPU，不训练、不下载。

拍摄主体和背景均存在、且目标与参考的完整权重背景各超过 256 像素的配对为正例，任何缺失角色的配对保留且说明。正例需同时满足完整权重背景方向投影介于 0.75–1.25、该区域相对预定增量的 RGB MAE ≤3、人物额外变化 MAE ≤1.5。人物近中性色 ≥64 像素时，该区 MAE 也须 ≤1.5。全图版用于检验保留冷色风格，所有配对的全图方向投影须在 0.75–1.25。无人且参考也无人时两份参考逐像素相同，要求输出逐像素一致。记录近中性色代理、非编辑区、饱和及亮度变化，记录所有不适用或失败。

若局部版失败而全图版响应充分，表明只分辨色向仍不够。若全图版也失败，本轮无法将失败限定在空间分配。阳性仅支持此局部编辑在冻结样本上的响应。把输出及局部开关对照保留作以后两图方法的开发控制，对结果不调强度或删除个例，也不据此判定真实自然度。
