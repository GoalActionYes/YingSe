# 视觉建议分类接口诊断

首轮数值接口在五对 PST50 全部输出零；后续诊断能描述明显的亮度和色偏差异，但另一数值提示产生变量名而非有效数值。说明本地图像输入有效，不能据此认定数值调色能力。旧结果保留。

本轮只检查较简单的相对类别判断能否产生有用结果：人物／背景各四项（亮度、冷暖、饱和度、对比度），每项三种固定选项。固定提示不含可直接复制的 JSON 示例或任意数值。模型仍只能看参考和目标，保持原图布局，不读取专家目标；工作尺寸与模型预处理沿用首次对照。先跑原五对、原图同图对照和已知蓝暗同内容对照，不接触新测试图。不按例改提示、调幅度或挑选输出。

类别到物理参数转换事先固定：亮度改变曝光参数 ±35、中间调 ±15；冷暖改变红参数 ±30、蓝参数 ∓30；饱和度参数 ±35；增加对比度以偏移 -12、曝光 +15、中间调 -25 实现，降低反向。先按类别相加，再应用已有物理 SCALE；这只是粗粒度着色近似，不宣称与剪映控件等同。没有人的自动回退沿用首次对照规则。只接受完整 JSON 及整个 JSON 围栏，未知类别／多余字段／说明文字／重复键拒绝并记录。

该分类探针可以说明模型能否识别变化方向，不能把少数正确类别等同于风格复现；是否有画面收益仍看全部对照和后续独立验证。若该有限诊断仍不能稳定输出有用结果，停止直接建议路线，不继续逐例调提示。
