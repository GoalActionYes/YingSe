# 已失败局部候选的对应统计

只读取已用train1024/development64的局部token缓存和既有训练日志，不训练、不改温度、不读GT或独立图片。完整保留1088行，分别统计训练与开发。

固定候选实际余弦×10 softmax：记录每query最大权重的均值、归一化熵、exp熵有效参考token数、实际匹配参考颜色与均匀参考颜色的RGB MAE、匹配颜色在目标空间的标准差及原参考token颜色标准差。单位颜色统一8位码值。熵和集中度是机制描述，不是语义准确率或审美门槛。

独立从q/k和softmax重建匹配向量，与产品候选match函数逐项比较，误差≤1e-6；核对所有输入索引及缓存哈希。全体数值保存，小型摘要与代码公开，特征不上传。固定首4对匹配色块图可以检查是否近常量，但不称自然效果评价。

引用既有各轮训练loss及开发误差，明确训练loss含梯度项、不能与RGB MAE直接比较。局部/池化有效机制不同，同预算不等于有效容量相同。若对应弱，只能说明本固定配置的选择行为，不能推导提高温度或top-k一定改善，更不能重启已失败配方。
