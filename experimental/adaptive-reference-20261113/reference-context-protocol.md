# 参考图外观条件实验

已有边缘统计和按亮度条件均值不能充分表达参考风格，本轮检查完整参考图经过现有图像编码器后的特征是否有帮助。该编码器不是独立语义分割模型，不把它称为已经理解人物、背景或区域对应。

复用当前作者Grid的img_projection：内容与参考均整幅准备为256，再缩64编码。将两个128维特征的空间均值及其差拼为384维，经过384→128→128 MLP，输出加到原128维直方图context；最后一层权重／bias全0，新增65,792参数。空间网格、alpha、lowpass、颜色引导、RGB仿射及后曲线公式保持。参考图只影响颜色变换，不产生新像素位置。零分支须在64开发图与未改造模型最大float差≤1e-5、RGB8差≤1，全部差异记录；不满足则不训练。

固定从512训练普通路径第16轮出发，SHA17be34dfff3e778761c92e1442e75e8ce3bc2b0bb033543171eae40bc8e0b795。建立同预算普通续训和参考条件两条路径，均只用cohort-v2的512训练／64开发，不读取已经消费的两批保留图、PST16–50或TST2K作选型。

seed20261116，batch4，再8轮／1024更新，epoch17–24每轮验证，最早最低均值选型。AdamW重置，base lr1e-5；新MLP lr1e-4（新参数与已有参数不同学习率是候选设计一部分，不声称只改输入且优化完全相同）；weight_decay1e-4，L1＋0.1梯度，clip1。原始grid和输出在限幅前检查finite，保存各轮、源码／配置／数据／控制SHA。

开发推进条件：相对起始第16轮均值改善≥5%、40/64图改善>0.1、严重退化≤2，新增32均值不退步且至少17改善；参考条件还须相对同预算普通续训均值改善≥3%、36/64图改善且严重退化≤2。另核对相对当前App第8轮的开发条件。只有全部达到，再做屏蔽参考分支及受控方向检查、实际图片／原尺寸／视频验证，最后使用新的未消费评估。禁止在已消费保留组上改标准冒充独立通过。

首次参考分支仅是全局外观context，不能把零初始化后可训练或反例输出不同当作有效风格迁移。失败保留，不替换App，不发布研究模型或数据；许可沿用非商业学术用途。
