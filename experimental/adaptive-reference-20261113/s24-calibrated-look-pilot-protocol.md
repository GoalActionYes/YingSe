# 用已知的相机实拍与 Lightroom 预设检查参考替换

S24 发布把照明记录与同一实拍照片的多个 Lightroom 版本关联，可测量固定拍摄内容下的预设响应。这个小样先核验发布配对，再实际出图。它不要求参考原图作推理输入，也不把白平衡标注当作任何特定风格的自然审美真值。

固定衍生版 `c233b3ab441d24b8fd57c33b0ab99a205fc8b84b`，仅 `train/data` 索引前 30 个不同标识，按标识 SHA256 排序取前六张。在读取媒体之前固定选中清单。每个标识仅取得 Lightroom 样式 1、2、3 三张 JPEG、次光源蒙版和非媒体 JSON。媒体总上限 32 MiB，单件最大 3 MiB；校验发布目录中的长度及 LFS 哈希或 Git blob。原始照片和派生版本不外发，遵守非商业研究许可与署名。照片以原比例和方向核对相同场景、遮罩以及配准，六张样式 1 的 128 位感知指纹两两距离须大于 10，全部 12 组前后图须过现有梯度结构检查。配准、重合或颜色内容失败按原样保留，不能替换选中样本。记录混合光区域和单色区域，仅用实际像素与对应掩膜评分，未提供的编辑蒙版仍标为未知。

先生成普通两图输出，再读取对应作者风格文件比较。每张目标使用样式 1，参考按固定循环取后两张场景的样式 2，以及第一张参考的样式 3。目标作者样式 2、3 也按同一 80% 强度混合。沿用同结果替换的联合筛查：作者换款的整图差至少一个码值，输出同款换参考小于两种换款差，换款方向投影至少 0.50。固定至少 5/6 组通过才把当前两图机制视为有可迁移信号，否则记录具体缺失。另分近中性色、次光源范围和整图，检查画质是否仅来自降低响应。结果仅是已消费的开发小样，无训练、产品升级或独立验收。
