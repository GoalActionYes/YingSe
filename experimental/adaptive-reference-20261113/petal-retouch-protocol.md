# 冻结PETAL编码器引导自动微调：固定77组开发对照

目标是实际画质收益，不以风格余弦距离下降作为成功。此实验承接编码器配对诊断，既不重新评价整套PETAL网络，也不启动训练或修改产品。

## 方法（生成候选前冻结）

1. 重用完整PETAL筛查中当前13号的77张基线PNG（强度100、微调归零，未走对齐认证分支），逐项核对原报告、目标、参考和输出哈希。使用同一工作尺寸：PST完整画面长边640，自然图既有256，COCO既有工作图。不重新挑样本或基线权重。
2. 使用相同严格加载的PETAL冻结编码器，RGB8经512双线性、归一化LAB到L2归一化z1024；保持原有精度、cuDNN及RoPE。每次两图编码。只访问目标、参考、基线和候选，不使用真值或人工蒙版求参数。
3. 基线颜色变换复用主版adjustments.transform，仅启用brightness、contrast、saturation、temperature、tint五项，顺序遵从原实现。参数u的每一单位相当于控件20，限制u∈[-1,1]，输出np.rint(clip(float32)*255) RGB8。u=0必须逐像素等于基线，无空间生成或改写结构。
4. 编码参考及基线。对五个轴分别计算u=+1和-1的编码，以中心差分构造1024×5 Jacobian J。对L2归一化向量，固定求解 `(JᵀJ + λI)u = Jᵀ(z_ref-z_base)`，λ=0.1·trace(JᵀJ)/5，然后分量裁到[-1,1]；若trace≤1e-12则u=0。不调ridge、幅度、维度或距离。
5. 分别生成u、u/2、u/4三个联合候选并编码。在新增0或255通道比例不超过基线0.005的候选中选余弦距离最小者，且距离必须比基线至少降低0.001，否则返回基线。比较严格阈值，边界等于0.001时不接受。并列按候选原顺序，不由真值选择。最多16次图像编码（参考/基线2、中心差分10、联合候选3加填充基线1）。
6. 保存所有77组基线/三个候选/选择输出、参数、特征缓存及哈希，之后才读取已有真值像素和人工蒙版评分。所用素材和历史成绩已经消耗，不称盲测或新独立验收。模型状态前后摘要必须一致。

## 门槛与检查

沿用完整77组筛查的画质门槛，不能因这是微调降低要求：自然32均值至少改善5%、≥22例改善、至多2例明显退化；PST15均值至少改善5%、≥10例改善、至多1例明显退化；受控人物局部8例均值至少改善10%、≥6例改善，其余22例至多2例恶化，全部COCO30不得明显退化。自然/PST改善阈值0.1，COCO0.5；明显退化为同时增加>5码值和>25%。均为RGB8平均绝对误差，不是人类偏好。

额外报告区域、人物背景关系、边缘梯度、输出端点、原图到输出变化、选择/回退数量、每图分析耗时和CUDA分配峰值。所有基线分数必须与原筛查一致。所有原图/参考/真值保留哈希。按原顺序固定生成19张全样本对照表，不按真值挑最好看案例。无人类匿名评价、原生大图/新视频或端到端实时验收，不接入产品。

若余弦分数变好而实际真值/视觉变差，结论必须记为风格特征目标与颜色优化效果不一致，不通过搜索步数、阈值或有利子集补救。这种结果否定本次固定微调配方，不证明该编码器不能用于其他经过独立设计的方法。
