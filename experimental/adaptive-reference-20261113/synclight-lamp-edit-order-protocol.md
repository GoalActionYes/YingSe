# 已知分灯差能否在显影之后安全扣除

前几轮仍无法从普通照片可靠估计拍摄光照。为先划清校光与调色的顺序，本轮使用既有 SyncLight 两个房间、两个视角及全部八份 RAW。严格复现已验证的环境光倍数、全场曝光、冷灯通道增益、校准白平衡及 sRGB 成片。场景各相机视角的环境和单灯组件来自同位实拍，冷色来自对单灯的数字通道调制。按原始分量得知每个像素的灯光变化。它只给诊断，不是产品推理可得输入。

以冷灯和标准灯分别组合，再套同一冻结 Film B。正确参考由先扣冷灯差、再加 Film B 生成。主要比较将同一已知差在已经调色的参考图中事后扣除。两个实现分别扣除 RGB8 码值差和扣除线性 sRGB 物理差；对照保留未校光输出。空风格下两种扣法须从冷灯复原至标准灯，在两种灯、全开关共四个状态均不过近黑或近白条件的像素内 MAE ≤0.5 RGB8。强弱区域沿用已知灯占比 0.30 和 0.10，须各超过 5% 及至少 256 像素。资格不满足原样报告，不复选图片；同时保留全部像素得分。

对照定义不随结果变化。扣光后的参考在强弱区相对正确 Film B 均须 MAE ≤3，且风格投影须为 0.75–1.25。将参考的标准灯、未校冷灯、两种事后校正各喂给原 13 号，以 80% 在匹配目标视角产生真实成片。各方式均计算原片偏移、Film B 响应和同风格换灯差，使用之前的上限 3 RGB8、风格投影 0.75–1.25。若正确参考仍无法达标，说明仅把灯光还原也不足以解决现有迁移算法。若事后扣光失败，停止「拿未调色光量差直接校已调图」的方案。CPU／GPU 既有环境，两次复算，不训练或下载资产。
