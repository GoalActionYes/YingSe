# 13 号正常入口的同画面配准对照

上轮绕过了同画面配准。本轮只恢复用户通常走的 13 号分析、预览与渲染路径，测同一批开发实拍中配准是否实际启用并保留风格，以及是否误认不同场景。按原素材来源保持分组。现有配准拟合和门槛保持。

四个背景目标和三个 Film B 目标各导入原片及同画面的已知调色版，执行目标／参考原片与目标／调色版，共 14 次分析。80% 输出必须与预览像素一致，同图须逐像素保持，走普通空间主干的编辑态必须复现上轮同画面成片。仅对已有跨内容对的 28 张参考检查配准是否会错误启用，不再跑已有成片。评分使用固定上轮的明暗、色度与同款响应门槛，另报告保护区域绝对误差和未通过配准的原因。

若同内容启用后通过原响应检查且无跨内容误触，保留为现有功能范围和以后分流时的对照。若配准不启用，按拒绝原因区分几何是否真的不同与当前颜色函数是否不能解释该编辑，不能用单一信号作完整因果解释。用户得到的仍是现有 13 号能力的核证。这些同画面参照含目标已知编辑，只作离线诊断，不能代替普通两图跨内容结果。
