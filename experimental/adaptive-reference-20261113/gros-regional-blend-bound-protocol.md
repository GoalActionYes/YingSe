# 同一批两图输出能否按区域组合保住人像与白幕

原全图共用权重六个跨人物方向都不可行。这次唯一改变是让两块脸颊、两处白幕和这些区域之外各自选择一组全图候选的非负凸权重，区域内四种输入条件仍共用权重。原人工范围互不重叠，验证其联合及补集逐像素恰覆盖全图。复用原素材、五个候选、目标真值、量化及线性求解。区域坐标和离线权重不能作为软件预测成绩。

每个命名局部范围用原来的规则独立求解，正的必要条件下界可排除该范围内的所有常数权重。补集也用同一规则求一个折衷，只用于评分和实际渲染，补集本身不增加产品门槛。各区域直接拼接成四张图，仍用已有整图、左右脸颊和左右白幕规则检查，门槛不变。不将硬边渲染当作用户可用界面或自然度结论。每个方向都保留所有局部证书与整图评分。
