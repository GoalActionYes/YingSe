# 核对 S24 实拍混合光区域是否可用

白球服和白墙偏色研究还缺少区分光照与物体本色的已标注区域。S24 首轮六组次光源蒙版全部为空，无法回答混合光问题。本轮只验证同一固定衍生发布的训练段能否单独取得非空次光源蒙版及可关联的次光源标签。

固定 `c233b3ab441d24b8fd57c33b0ab99a205fc8b84b` 的训练段蒙版和数据目录前 100 条，排除与先前测得的全零蒙版字节哈希相同的记录。按编号先后取最多六个其它蒙版，各并取同编号 JSON。单件最多 512 KiB，全部响应合计不超过 4 MiB。保存名单后才读取这些对象，校验发布长度和对象哈希。来源和非商业研究范围沿用已核验许可。仅本机读取，未列出此范围的原图、成片、保留素材和模型权重均不获取。

逐项确认 2000×1500 或 1500×2000 的蒙版有足够相邻的非零像素，占完整画面 2% 至 80%，且 JSON 同时含可识别的主次照明标注。至少两个不同编号满足条件才可进入后续图像诊断。无拍摄组证明即只用于开发条件检查。此轮没有图像推理或画质评价。
