# 同款编辑的邻近颜色支持与实际出图

上一轮发现 Cuckoo 草地没有精确同色，整图仅 15.6% 精确重合。用同款显影的四组既有配对验证较近的颜色能否补足。整场景留出，其他三组以同一输入 RGB 的两维色度变化中位数建立规则。任何目标编辑图只用于当前留出折评分。对照是上一轮已归档逐像素成片。

沿用已有 ARRI 近邻诊断的 RGB8 欧氏距离 6 和最多 8 个不同颜色的倒数加权，距离分母至少为 1。固定实现计算球内精确邻色，同距按 RGB 位移字典序取舍。候选唯一改动是用这个估计替换有支持像素的色度输出，仍使用原图亮度和原色域规则。半径内无邻色则逐像素保留原预测。公开每区的支持覆盖、支持区误差及完整成片评分。预算两次 CPU 运行，每次两分钟，不安装依赖或下载素材。

草地支持至少 80% 且完整区域误差比对照下降至少 1 RGB8，才认为增加邻域证据对该反例有效。新预测还须沿用上一轮两人像整图与合格区域、至少一张天空整图的响应门槛，并在所有合格区相对对照误差增加不超过 0.25 RGB8，方可继续推进该预测。若草地覆盖不足，优先补能覆盖这类输入颜色的已知编辑证据。覆盖足而无误差收益则结束固定邻色预测。已知同款编辑的出图属于开发诊断，不能用于单张参考识别宣称或独立验收。
