# 从两个 ARRI 镜头档案验证单帧可取性

冻结此前登记的 06 肤色和 08 灰色建筑两个镜头。通过 ARRI 链接的公开分享与正常下载入口取得临时文件地址，核对文件名、总长度及对象标识。先验证服务器能提供精确的 HTTP 206 范围，只读取 TAR 头、必要扩展和第一张可归属到已选镜头的 TIFF；若返回整包、范围与身份不一致或超过预算，停止。每档案最多 128 KiB 目录／探测字节及一张不超过 96 MiB 的 TIFF。临时链接、媒体和网页响应留本机。

通过后验证文件头、位深、尺寸、路径和 SHA256，保留源帧为 AWG4／LogC4 技术对照。使用 ARRI 官方技术转换和既有色彩工具验证可用于现有 SDR 处理；只有确认同帧的独立作者成片才可作创意真值。若仅取得代理或标签，记录其限制。PST50 保留区和完整验收条件保持。
