# 核对实拍白平衡与已知风格成片能否同时取得

现有两图规则无法稳健分辨大面积物体色、光照和后期风格。固定核查 S24 Raw-sRGB 原发布和公开衍生发布，及两种相邻来源 LSMI 派生白平衡集、Rendered WB。目标是找到能将实拍照明、固定跨内容操作和局部区域状态分开的已标注开发素材。

只读作者固定版本说明、许可、发布树、公开数据格式和访问响应。总元数据不超过 2 MiB，单请求不超过 512 KiB。若可能，只取可以单独读取或经授权分段读取的目录或索引。不会打开媒体；不使用任何需登录、填表或另行接受权限请求的路径，不取大归档，不执行第三方代码。两份未认证同源的发布不能合并当作同一个样本。

继续小样的必要条件是明确的数据使用范围、可取得的原始和风格结果关联、可按来源隔离的场景、能核实的照明或区域标注。仅满足照明诊断条件时记录为光照材料，不能当作人像和空间调色监督。真实局部润色必须有操作开关或可追溯区域才准入。所有判断只影响素材选择，保持原目标门槛、软件和独立保留集。
