# 同一人像编辑的统计与外观路径对照

用已锁定的两人像开关图和扩展第 4 轮。固定目标、80% 强度、权重和原渲染。分别使用开关图提供参考颜色统计或参考外观，两条路径交叉构成四组。两条同开或同关必须逐像素复现归档。两条交叉用于定位信号依赖，不具备普通两图输入条件。

保存成片后，沿用原整图、共同近中性色与登记区域。固定三种开态都减同一完整关态，比较响应误差、投影以及原关态偏差。将完整开态增量减两条独立开态增量，记录色度交互残差，不将两路解释为相加的独立贡献。报告所有区域，两遍运行，不训练或筛选新权重。只有某条路径在两个方向的整图、近中性色和登记关键区域均达到相同风格门槛，才有依据研究如何用普通参考图估计该路径独有的编辑信号。
