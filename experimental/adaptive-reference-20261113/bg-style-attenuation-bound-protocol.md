# 测量固定方向部分抑制的可行范围

完全去掉背景偏色方向会丢失白球服和浅墙的换款响应。检验从不抑制到完全抑制之间，是否存在同时抑制背景漂移、保留风格的力度。沿用上轮冻结的成片、区域、背景轴和资格门槛，任何区域均允许独立取系数。这比部署时使用同一个自动规则更宽松。

对背景漂移与正确换款两个已知差分中的轴向分量应用同一减弱比例 `a`，允许 0 至 1。量化前，风格投影随 `a` 线性下降，风格 MAE 随 `a` 线性增加。先用原投影下限 0.75 和 MAE 上限 3 固定允许的最大 `a`，再将各背景色度分量绝对残差的折点取加权中位数，限制在允许范围内。得到对风格约束下背景残差的全区间最小值。还记录单独满足 1.50 背景门槛所需的最小 `a`。以各自开态亮度，实际渲染被选系数的换款和换背景结果，再按原门槛量化评分。

只有原先取得资格的区域才作联合判定，其余读数保留缺测资格。连续空间存在可行范围而成片不通过时，单列量化或色域压缩的影响。连续空间无可行范围时，只排除既定轴与常系数在该连续表示中的解。若所有合格重点区域联合通过，才值得继续验证能否只凭普通两图预测该系数。本轮按原模型输出及已知编辑答案做离线诊断，无训练或新素材。
