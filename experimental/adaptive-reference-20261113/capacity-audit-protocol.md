# GT辅助表达能力审计：分开容量和风格推断

本轮只使用cohort-multiref-v1全部32开发目标×2参考对应的64个内容／GT及13号当前第6轮保存预测。数据已被开发使用；不读取reserved、不下载新图、不训练或升级App。GT直接参与拟合，因此所有拟合器都是诊断工具，不能包装成从参考图推断出的算法。

每组采用既有准备方式的256×256 RGB8。固定32×32棋盘块，两个fold分别用偶／奇块GT拟合、在另一半块验证，最后拼成每像素均来自未使用该位置GT的cross-fit输出。全部样例和两fold保留，不按结果选尺寸、正则或方法。它只是同图区域留出，不是新内容或独立图测试，也不能排除相邻块颜色相似带来的容易泛化。

固定四种拟合：RGB全局仿射4项、RGB全局二次多项式10项，以及使用当前模型固定pre/post guide、sampler guide和8层z插值的全局矩阵场32项与3×3粗空间矩阵场288项。后两者alpha固定1，3×3场双线性升到原生16×16后沿用作者lowpass；由实际原生采样器渲染，比较设计矩阵预测和原生输出，最大量化差≤1码值。全局场的颜色输出不依赖像素位置。

先用当前post guide的单调64点表把GT反解到矩阵输出域，低于可达最小值或超界部分夹到端点并完整记录。以岭回归最小化反解空间的均方误差，全局／多项式正则1e-5；粗空间正则除9，使复制同一全局函数到9节点时惩罚相同。设计与求解用float64，原生渲染保持当前float32。后guide和alpha等限制意味着失败拟合不能证明整个模型容量不足；该方法也不是RGB MAE的严格最优上限。

记录全部cross-fit图的RGB MAE、p95、各fold，当前模型相同像素的误差、guide z范围／有效层、post guide不可达GT比例、系数幅度、原生一致性及拟合耗时。不优化当前模型权重、guide或参考特征，不让heldout GT参与该fold的系数估计。GT反解按像素进行，heldout反解值不进入训练法方程。

另对同一RGB8输入键在全图GT中出现的输出做逐通道中位数，计算任意确定性RGB→RGB查表在这份解码像素上的最小L1误差，报告重复键／像素覆盖。此处使用全部GT，只是离散查表下界；唯一RGB键可被任意记忆，不能据低下界断言映射易学。JPEG、量化、ICC转换和缩放均可能造成重复RGB对应不同GT，不能单凭此项断言存在语义／局部调色。

预先描述性判断：统计各方法MAE≤3及≤5的样例数；若固定guide全局场有至少48/64达到≤3码值，说明这批目标中存在可表达的低误差颜色函数，应优先检查参考条件推断，而不是继续假定需要更多空间容量。比较粗空间相对同guide全局的逐图误差，改善至少1码值的数量完整报告；这只能说明该GT辅助拟合中位置变量是否有帮助，不证明真实参考映射能被推断。

先做恒等／仿射恢复、空间已知变化、颜色碰撞中位数及原生渲染对照的合成测试，再运行全64组。最后查看固定前2、全局误差最大和空间收益最大的未覆盖例，保留所有失败。不得据审计调当前App参数，也不据低误差宣布协调性或独立门槛通过。
