# GradeStudio 直接区域迁移固定筛查

旧局部系数头两轮无收益，已经停止。本轮检验不同机制：不学习修正系数，直接用冻结 DINO 对应构造区域 Lab 分布迁移，再按目标空间权重混合区域 LUT。它可能绕开系数预测失败，也可能把参考物体固有颜色误当风格；语义正确性不能由描述器名称保证。

作者代码固定在 LivDevGit/GradeStudio 的 5c10ccb685be7b58cdd88ec2f5e78a8975d4139e，仅本机只读来源副本，不转载第三方源码。当前树没有 LICENSE 文件，没有发布权重资产，不能据 README 宣称产品可分发。推理复用已核验本机 DINO-small，以注入同一模型实例的方式避免联网；作者 patch_features、默认 448 长边插值和其余公式保持原样。无安装、训练、权重下载和素材上传。

固定已消耗的 TST 开发 64 对，只用于开发筛查。三臂为原 multiref-v1、作者全局 transfer_lut 默认值、作者 semantic_match 默认值，均全强度输出到 RGB8；不将它们与默认 80 产品混合结果混称。保持六区域、温度、采样数、种子及全部默认参数，不搜索配置。作者默认使用六个 33³ LUT；本轮上限 64 对和首例一次精确重复。保存全部输出后才读取 GT 评分，GT 不进入迁移函数。

先检查身份 LUT、作者模型严格本地加载、有限值、形状、区域权重和为 1、区域覆盖与置信度；首例重复须 RGB8 逐像素一致。不通过则保留故障，不以修改作者公式继续追分。记录推理时间，仅是 256 图研究调用时间，不是完整视频速度。

筛查第一必要门槛沿用现有协议：相对原版均值 RGB 误差下降至少 5%，至少 40/64 改善超过 0.1，严重退化（增加超过 5 且超过 25%）最多两例。未过则停止固定方案，不调区域数、温度或强度。通过也只是进入其余开发控制、关系和独立自然／人类／视频门槛的资格，不能直接接产品。与作者全局臂比较以识别局部机制是否有效，保留原图误差防止弱化冒充收益。

研究仅使用课程研究数据；媒体、模型与第三方源码不随 Git 上传，只上传自有运行桥接、协议、报告与小型数值／哈希。
