# 目标颜色在网格取样阶段是否造成跨场景偏色

上一轮只去掉目标空间编码器的颜色，未改善画质。现有渲染器还会根据目标像素的 RGB 计算网格取样深度。本轮固定原空间网格及渲染的 RGB，仅把取样引导模块的输入换成三份相同的 BT.601 亮度，判断这条路径是否限制中性色与人物画质。灰度是冻结模型未专门训练的输入。

沿用 13 号固定权重、两张原图、直方图、网格预测、取样坐标、原 RGB 仿射、量化及 80% 强度。只在原生逐帧渲染调用内临时替换 `sampler.pre_guide` 的输入，立即解除，之后复查正常 RGB 路径仍逐像素复现。在同图时返回原图。记录网格取样深度的变化、RGB 出图变化与严重退化，人工标注和作者效果只评分。

两次各至多 100 秒，沿用全部 42 张背景换色、18 张局部开关和两张 PSBench 真实对照。原 RGB 路径须逐像素复现 62 张。候选须过原背景联合门槛，局部人物至少 3/4 组、整图冷色至少 4/6、同图及无人负例通过；两方向实图至少一向满足原门槛，另一向不恶化超过一个码值。失败则结束冻结模型直接去掉目标颜色的机制检查，不用改灰度比例或训练相同配方挽救。无新增数据、模型、产品修改或独立验收。
