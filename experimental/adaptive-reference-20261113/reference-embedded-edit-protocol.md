# 导出参考 JPEG 内有没有可用于调色的编辑字段

此前检查的是相机白平衡字段。这轮检查四个 PSBench 编辑前后对与八个 FACD 原图／三个滤镜对，共 40 个已锁定的发布文件。只用原始 JPEG，登记 EXIF、ICC、标准或扩展 XMP 的存在与否。从标准 XMP 中比较已知 Adobe Camera Raw 色彩与调子设置字段。作者软件、拍摄描述与色域不能作为编辑身份。扩展若存在，保留为未解析。

用带标准字段的合成 JPEG 验证读取。报告仅保存字段名与计数。FACD 至少 18/24、PSBench 至少 3/4 个编辑结果须含有与原图不同的明确色彩参数，才继续视觉核对。通过只表示字段可用，不能证明当下风格或迁移正确。两遍只读，不下载或改产品代码。
