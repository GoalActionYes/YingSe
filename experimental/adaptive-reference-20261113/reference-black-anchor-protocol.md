# 近黑区域能否提供可用的参考色偏线索

白桌布和人物偏色已有实拍反例，但直接减去共同色偏会压弱有意胶片色。检验一个明确先验：没有裁切的近黑区可能比整图受场景物体颜色影响更小，可以提供近黑染色的线索。彩色物体、彩灯或电影曲线也会改变近黑区，这正是要用实图检验的限制。

在普通目标、参考 RGB 内各取亮度 4–32 RGB8 且三通道均未裁切的暗像素，每图至少 256 个，否则逐像素回退到 13 号。参考在这一区域的两维色度中位数，减去 13 号成片在目标原图同一组选定像素的中位数，作为共同色度修正。两维分别限于 ±8 RGB8，保持原亮度及空间色度变化，越界由既有色域压缩处理。这个锚点和固定上限只用一个配置，无训练或搜索。同图保持以及亮度不足的平坦图回退单独检查。

运行既有四套开发对照，每轮 72 张成片，重复一次。成功条件为同时通过各套既有整图、保护区、有效编辑及退化门槛。原参考换背景下的九处区域作为额外读数，重点六项直接肤色至少五项同时改善 25% 与 0.25 RGB8，其余任何一项不得新增超过 0.25 RGB8 的换背景色度差。至少实际触发一个受控开关的两态，避免全回退被当作稳定。若未过，不通过扩大/缩小暗部阈值延续同一先验。成功才考虑独立候选和正式验收。真值、参考原片和人体区域只进入评分。
