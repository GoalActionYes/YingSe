# 可见四边形能否挡住显示画面的人脸误修

先前从场景类别像素扩出显示区域，没能覆盖投影幕和部分电视、显示器的人脸。此次测试原图本身的四条直边能否补全缺失范围。冻结八位 RGB 输入和原肤色权重。从亮度图用固定 Canny 边缘和近似多边形提取可见、闭合、凸的四边形。边长、面积和角度只筛几何可靠度；不使用场景标签、脸框、人工区域或案例身份。用固定诊断色偏出两臂成片，唯一差别是候选在几何覆盖范围内不做额外皮肤修正。同一个四边形即使来自窗户、球衣、相框也有误排除风险，须用原真实肤色框制约。

使用已有四张 BG-REAL 原图、三张实拍屏幕脸、两张真人和显示器分开的照片、原登记的合成挡屏控制，共十张。测量沿用旧定义。四个真实屏幕脸全部须降到权重大于 0.05 的触及率不超过 1%；每个原本高权重覆盖至少 80% 的真人框都须保住 80%。其他真人框高权重覆盖不得下降超过 5 个百分点。浅墙、雪地及白球服须维持无触及。合成挡屏只用于发现误杀，不能替代实拍。两遍生成同样的诊断成片与报告，预算 30 秒级 CPU，不下载模型。若未过门槛，关闭仅凭可见闭合边框的路线；若通过，再验证普通两图成片和真实遮挡。诊断偏移不作正式画质指标。
