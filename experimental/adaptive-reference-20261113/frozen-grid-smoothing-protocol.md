# 冻结网格的空间平滑对照

白球服两背景与 Film B 的风格幅度不足，前两轮排除了最终取整与内部曲线仅在越界处延展。当前检查原模型的 XY 网格平滑是否把本来存在的变化压掉。早期全局网格实验在平滑后对所有位置求均值，还包含重新训练，与本轮移除单个固定滤波步骤不同。

加载扩展第 4 轮。对每对输入预测一份未平滑网格。控制照原方式对该网格作平滑，候选直接使用同一未平滑网格，两者沿用原采样、曲线、RGB8 渲染和 80% 强度。只用普通两张 RGB 输入。同图保持逐像素相同。必须核对控制与归档成片逐像素相同。预算为四套已消费开发对照各一遍，合计 72 张候选，保留全部反例和原门槛。

重点看白球服两背景明暗、人物和近中性色换背景差、Film B 整图与近中性色响应、FACD Hudson 退化和实体色卡。只有四套全部按原门槛通过，才进入额外负例和空间过渡验证。若白球服两背景或 Film B 六方向仍不足，或任一保护区门槛加重失败，结束将当前固定平滑视作可单独移除即可修好的原因，不搜索尺寸或滤波强度。独立素材保持封存。
