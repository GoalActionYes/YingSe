# 核对原生 SDR 同款滤镜的近中性色测量覆盖

HDR 输入即使没有 RGB8 端点，仍可能改变真实编辑方向。此次只核对已登记的 FACD 原生 SDR 配对能否提供有明确滤镜标签且背景不同的近中性色开发对照。复用已配准通过的七张照片、三款滤镜、已有照片分组与每组两份参考。只读原片和作者成片，不重跑模型、不扩数据、不改既有评分。

沿用七组近中性色代理的阈值。对每张图和每种滤镜，报告原片与作者成片的近中性区域里所有通道严格在 0 与 255 之间的共同像素数及比例。每照片组再取三种滤镜的共同有效范围，保证下次同款与换款评分使用同一批像素；需至少 256 像素且保留至少一半近中性区域才可用于该组端点敏感性诊断。全部七组均记录，任何被裁切样本仍保留为反例。至少四组达到覆盖才采用该对照补充候选核验。

端点核对只检查落盘 SDR 像素的测量覆盖，作者滤镜本身可能有意压黑或裁切。保留原有颜色响应与自然度验收，不把此检查当作新增画质通过或独立评估。预算为两遍本机 CPU 数组统计。
