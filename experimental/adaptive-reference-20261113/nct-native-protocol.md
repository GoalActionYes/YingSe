# 作者完整渐进颜色迁移程序兼容性与首例

目标是检查完整的对应／局部颜色联合优化，而不是继续将一次DINO相似匹配视为充分证据。使用[作者Neural Color Transfer](https://github.com/hmmlillian/Neural-Color-Transfer)的公开Windows预编译程序，仅作独立研究基线，不接入产品、不修改Windows或GPU驱动。

源码固定commit eb86d9368608e6dbca55377593d66f161f13286f，用于理解参数与配置；预编译二进制来自该README的Google Drive链接，并非本机从该commit重编译的可验证同构建产物。下载exe.zip 231,146,920字节，本次SHA256 2bb04d957e8b31b9987306126ed1d0fcf965ac19f73e923a9a5051ec28a12321；提取到隔离.tools目录，跳过包内kernel32.dll与advapi32.dll，使用系统KnownDLL。其余依赖只在程序目录，不安装到系统。

按作者链接下载Oxford官方VGG19 Caffe权重（574,671,192字节），记录本次哈希。配置使用作者demo中的prototxt。原始二进制以CUDA8／cuDNN5／Caffe构建，是否支持当前RTX4060须实际验证，不能由命令行帮助可启动推断完整推理可用。

第一例固定已使用PST50第4对（有小人物与山景）。输入／参考保留构图缩至640，8位Rec.709，不读取新16–50。pairs.txt固定BDS2.0；显式传入源Config.h中的eps0.6、nonlocal2.0、local0.125、WLS0.024，避免README帮助文字与当前源码默认数值不一致。实际二进制参数与行为另记，不声称可验证地等于论文所有细节。

创建隐藏的自有子进程、记录PID与原始日志，最长180秒；超时只终止该子进程，不按名称关闭其他程序。失败／超时与具体停层都保留。没有输出时不评分，不把程序启动或资源下载视为方法有效。若原始GPU后端明确失败，可在单独变体中检查数学等价的CAFFE卷积后端；须保留原失败、不声称字节等同、不修改原二进制或原配置。
