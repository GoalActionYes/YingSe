# 光谱肤色先验能否从普通 RGB 判断换光方向

只检验两个已知标准光源 D65 和 A。以 ISSA 点测脸颊在两种光源下的结果组成两个颜色库。输入以量化后线性 RGB 的两个对数通道比表示，降低曝光差的影响。每一方向的支持距离上限按 ISSA 整来源留出的同类第八邻距离的 95 分位确定。两类距离的相对差 `(远−近)/远` 至少 0.25，查询与较近类的距离也须在支持上限内。每个图至少 16 个可用肤色像素、至少 80% 可用像素通过上述判据且同向才赋光源。比较本轮不拟合普通照片。

用三位独立光谱人像的六张换光拼图检查已知方向，人工脸颊核心只用于这个物理上限对照。另用冻结自动肤色掩膜检查此前六组普通照片的原图、局部编辑和整图有意编辑，以及四组换参考背景的原始／换背景对。普通对照没有标准光源标签。若两张均能分类且方向相反，定义为分类器建议换灯。只改变后期颜色或背景时，冻结规则不得给出换灯建议。另要求没有人物的三版输入不得赋予光源。弃权、支持不足和相同方向都保留，不按正确分类计分。需要物理六张全部正确、普通两类对照无反转、无人无赋值，才进入带自动估计的调色出图。协议不把这些诊断视作真实混合照明或产品验收。
