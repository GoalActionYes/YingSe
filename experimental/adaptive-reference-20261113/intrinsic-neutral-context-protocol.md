# 自动背景去色后的光照估计：第二轮固定修复

唯一问题：上一轮3553／19432品红背景干扰过大，是否能通过自动去除非人物背景色度、保留亮度结构，降低人物S误判，同时保留整图色偏响应？这是输入层干预，不是换seed、阈值或模型。旧分区直方图／RGB肤色回补没有采用本空间光照估计；不得把该区别当作成功证据。

输入RGB逐张送入已有DeepLabV3 MobileNetV3人物分割，固定原权重和预处理，输出软人物概率p。令Y=.2126R+.7152G+.0722B（gamma RGB），新RGB=round(p*RGB+(1-p)*Y)，三个通道同一灰度背景。p只来自当前RGB，每个变体独立估计；不使用人工蒙版、原始未换色参考或操作标签。不另设p门槛，不按支持度选择输出；无人例也执行同公式，因此可能损失合理背景风格，此限制不能隐去。

沿用原六组×12变体、四人物参考的同一主要测量区域、log(R/G),log(B/G)、floor1e-4、余弦≥.5、整图响应幅度≥.25、背景/整图≤.5、floor比例≤1%、全部八方向通过规则；完整主门槛不变。已知输入变化仍按原始用户RGB计算，不按去色后的输入重新降低要求。原73份分解作为匹配控制复用，无须重跑。

同一Marigold配置与权重，先用原9483做raw桥接，再推理72份去色参考。分割使用CPU，避免增加GPU驻留；必须确认已有权重且全SHA匹配，禁止下载。保存72概率图、新RGB和三层分解，重复参考的p、新RGB与raw均须逐值一致。人工人物标注仅在该参考全部预测保存后，用于离线测量及描述去色对真实人物区域的影响。

执行预算600秒，单次推理60秒，本机新输出≤250MB，无训练、新依赖或产品修改。独立审计从保存概率和原RGB重建去色图，复用上一轮独立log测量重算73分解及全部判定。通过仅允许另做完整两图输出比较，不称软件升级。该方案只针对人物条件，原开发双方区域支持仅28/64；即使通过，单独回退其他场景也无法满足完整改善覆盖要求，不能直接发布为完整候选。

这是一条光照先验路线的第二轮有明确因果干预的修复。若仍不通过，停止本路线的背景处理、分割阈值、温度、步数、seed和规模追加搜索，保留成果与反例，转向有实质新依据的决策；不以继续换先验模型维持研究。
