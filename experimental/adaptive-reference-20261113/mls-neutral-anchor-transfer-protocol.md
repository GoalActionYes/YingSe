# 白背景线索能否用于背景以外的近中性色

固定已验证的 MLS 02↔03 两方向与单参考白背景估计量。将该色度变化应用到目标白背景以外、原本接近中性的像素。此处白背景位置来自作者掩膜，目标中性色范围用原 RGB 固定规则，保证白背景像素未进入评分。需要判断白背景的实拍收益是否能推广到同一照片其他近中性颜色，尚不测试自动白色检测。出图仅用目标原图及该对参考的冻结白背景估计量，目标换灯图只供评分。

固定同灯换景和换灯换景，保持相同 80% 色度重放，范围外保留目标原图。比较相同区域的 13 号与保留目标原图。沿用 256 像素、20% 覆盖、0.05 真实色度变化、0.50 方向投影及误差改善门槛。两个目标均须有资格，同灯变化均不超过 0.05，换灯均通过且较 13 号至少降低 15%。任一失败则禁止把该固定白背景线索推广到任意近中性色。保留所有结果及两次哈希，成本为已有本机素材的小批量 CPU 渲染。
