# Filmic RGB 对真实作者局部暖调响应的影响

上一轮统一蒙版后，RAW 和 sRGB 的高权重两折各相差约 3.4 RGB8。XMP 顺序中 Filmic RGB 位于 RGB 色彩平衡之后。本轮只切换这项模块。复用原 RAW 全覆盖开关为已启用 Filmic 的对照；在两份新侧车中关闭 Filmic 的全部历史记录，保证此前状态不会重新生效。其余历史及参数保持。每组仍取色彩平衡开／关差，统一按原蒙版和 80% 强度加权。与冻结的 sRGB 同规则响应比较，目标本底变化和裁切另报。

两次各两个 CPU 导出。使用原双折和满权重区，若两个高权重区对 sRGB 的响应差均减少至少 1 RGB8，且开关四态中任一通道 ≤1 或 ≥254 的评分像素占比相对冻结 RAW 不新增超过五个百分点，才认为此单一后级改变给出有效解释。若仅达到距离要求但新增裁切，记为不合格。对齐、覆盖和记录完整性为必要条件。结果仅作用于已知作者操作和一张开发照片。
