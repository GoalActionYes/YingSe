# 用目标自身的色度响应检验保色修正

白球服和婚纱都出现参考颜色覆盖目标本来颜色的现象。目标镜像平均已经失败。本轮给目标施加已知、小幅、等亮度的颜色变化，用它测量 13 号对目标自有色度的响应。若模型压掉这部分目标信号，试补回损失。参考图固定，且没有新模型、人工区域或额外用户输入。

固定原图和参考、13 号 80% 成片。先把目标原图的色度降到 75%，保持 Y′ 后量化，只比原向多运行一次。分别取原目标和减色目标之间的色度差 `input_delta`、对应成片之间的色度差 `output_delta`。候选加回 `input_delta − output_delta`，保持原向 13 号的亮度并在中性轴收回超出色域的值。以真实量化输入实际差值计算，保留方向和符号。区别于沿同一色相减弱滤镜，也区别于把两方向成片取平均。若模型能原值传递这项已知变化，修正为零。同图按原样返回。

复用上一轮同一批 BG-REAL 16 张和 FACD 42 张基线、原生 SDR 共同近中性色支持。候选每对额外运行一次，两遍固定预算 116 次推理。冻结目标色度 75% 和单位补偿，不根据案例调强度、色相或蒙版。用合成恒等与仅保亮映射检查差分公式，留出素材不读。

保持原联合门槛。BG-REAL 至少 3/4，最大人物、近中性或人物近中性色换背景差 ≤3；FACD 同款稳定性、换款响应与误差联合至少 6/7，共同近中性色任一配对退化 ≤2。量化后最大 Y′ 差 ≤0.5 码值。保存实际成片、已知输入色度变化的模型响应和全部正负例。若失败，结束固定目标响应补偿，不用增大修正掩盖参考端问题。
