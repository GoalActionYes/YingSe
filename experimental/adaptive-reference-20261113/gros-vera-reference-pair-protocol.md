# VeraRetouch 两图与已知原片对照

CIFR 路线在真实参考前图可用时成功，但自动估计原片不可用。本轮用已按真实编辑关系训练的 VeraRetouch 做同权重输入消融。只检验已知全局 Film B，方便区分编辑推断与渲染本身。发布解码器的整图逐像素映射不能表达不同位置相同 RGB 的局部差，本轮通过也不等于支持该能力。

固定作者源码 fefe6c4408f00beae07e132fc404cae0efee0985、Encoder Renderer 公开权重 182,507,490 字节，以及 01 ← 02 已用人像。在作者默认 512 参考编码、原尺寸目标与原 mask 通道设置下比较：两图臂用目标同时作为待渲染图和参考前图，提供单张当前参考。三图诊断臂将前图换成参考在同一实拍灯下的真实未调色图。除此之外保留权重、输入编码、目标图、80% 项目混合和阈值。比对四种冷暖灯和预设开关状态，共 8 张渲染，加 1 张两图同图控制。不用人工真值掩膜参与推理，目标正确成片只作离线评分。

保留作者 CLI 的输入色道和归一化，并如实记录任何兼容调整。在 3 RGB8 关闭误差、换灯差和风格误差条件与 0.75–1.25 风格投影下，测整图、双颊和双白幕。需五区同过及同图保色才扩大，三图成绩仅诊断。无完整收益即结束该固定模型的本组试验，记录两臂差异。权重、外部源码与影像留本机，预算小于 190 MB，新安装、训练与独立保留集均不涉及。
