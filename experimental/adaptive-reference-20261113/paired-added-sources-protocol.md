# 增加同款编辑的参考内容能否补足白球服的变化

固定参考的加权与原图取样分别未通过。均匀已知色样曾让白球服局部达标，但手臂和整图未通过。本轮检验增加真实照片内容是否同样有用。已有扑克、实体色卡、焊工三组实拍，在同一处理链记录了两款全局编辑前后的图像。

- 唯一改动是在当前参考配对基础上加这三个不同内容的同款配对。按原有多来源拟合函数，各来源在每通道内权重相同。对照仍为只用当前配对；重复同一来源四次与单独拟合读数一致，另检查现有拟合与归档成片逐像素一致。两款使用同一组原图，所有输入校验哈希。沿用原缩图、棋盘留样、裁切筛选、正则、三次色表和 80% 强度。目标真值只用于评分。
- 使用已消费的四组人物场景、原来的两个参考背景、16 像素棋盘留出及固定区域。白球服在两种背景下的换款投影都须为 0.75–1.25，响应 MAE 都须 ≤3 RGB8。其他合格区不得丢失原通过项，响应 MAE 不得增加超过 0.25 RGB8。保留所有结果、退化及缺测。
- 两次固定运行，共比较每遍 16 张成片与四张图板。报告同时记录目标像素落在哪些已出现的粗 RGB 颜色箱，以检查新增来源是否真的增加覆盖。若联合通过，便有理由继续验证如何从普通参考成片辨认能可靠重放的编辑；若失败，保留实图反例，结束这一组固定多来源拟合，不在同批素材上增删来源或调权重。即使通过，也只是已知调色的离线对照。
