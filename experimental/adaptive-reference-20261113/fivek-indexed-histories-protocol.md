# 按图像索引核对 FiveK 相同修图操作

上一轮 SQLite 行号两端抽样只有一张照片得到连续历史。本轮用目录已发布的 `(image, dateCreated)` 索引读取完整单图序列。按索引头尾各选前四个不同图像键，在读取编辑内容前冻结。每图最多 64 步，超过则只记录超限和计数下界。查原文件键并按其归并虚拟副本，对同一原文件不计跨内容。目录文件不同仅视为不同源文件，拍摄家族另须核实。

复用完整字面量参数比较。仅对相邻、时间不同且均完整解析的状态判断。预设三种结果：仅改变单个已知曝光、对比度或其它颜色字段；只改变明确局部字段；多项或其它改动。一个配方候选须至少两个不同原文件出现相同字段和相同带符号变化量（十进制定点精确相等），并比较两边起止值及其余处理状态是否一致。重复变化量只作为查找可复现成片的依据，不宣称滤镜相同或画质改善。

新下载的数据库页总计不超过 384 KiB，复用前一轮本机缓存。页面预算不足时保留全部已审计组并显式标记未完成；不切换到下载目录或归档。作者许可沿用上轮。只读取目录元数据，公开证据仅含匿名分组、字段变化计数、结果哈希和版本身份。按固定抽样核对索引项和历史行的一致性，另用本机 SQLite 生成结构对照。后续成片须从原片和受支持的原处理模型恢复。渲染条件不满足时，保留真实编辑历史用于离线比较。

按图像键的预定抽样结束后，如果头部四个图像键全部指向同一原文件，另用已有 `Adobe_images(rootFile)` 索引按原文件建立对照。固定取该索引开头四个不同原文件，每文件前六个图像版本（最多包含原版本及五个虚拟版本），在打开其历史前全部冻结。重复文件仍不计跨内容。第二臂新读取最多 224 KiB，并继续遵守本轮累计不超过 384 KiB 的预算；两臂记录均保留。可用步骤门槛和跨文件操作配对条件不变。用已有照片页补报吻合的两条编辑记录是否在不同拍摄日期，不增加网络读取，不公开日期或时间值。
