# 现有拍摄白平衡字段能否提供独立的光色方向

检查四组已核验同机位 SyncLight DNG 的环境光和隔离补光。读取拍摄色彩平衡字段 `AsShotNeutral`，转成相对绿色的 `log(R/G), log(B/G)`。检查两份原片之间的字段变化能否跟随实际像素的光色变化。用绿色归一不是要将相机 RGB 换成标准色温。

实际像素对照用黑电平扣除后的 Bayer 2×2 四样本，两个绿色取均值，在可见区固定每隔 16 个 Bayer 格取样。以环境光的拍摄白平衡寻找近中性代理点，三个增益后通道最大比值 ≤1.15。两原片每通道归一到黑白电平后均须在 [0.025,0.85]。至少 128 个共同代理点、两维对数色度变化中位向量长度至少 0.05 才能用于评估。元数据差向量须长至少 0.015、与观测方向余弦至少 0.8。只读取既有四组、四组均需合格并通过，才继续研究其作可选提示的价值。

另只核查八组 FACD 的 32 张原图／有意滤镜 JPEG，以及九张已核验 COCO JPEG 是否保留数值中性色或白平衡模式标签。仅报告字段存在、数值向量、模式枚举，忽略位置、设备识别或其他私人字段。EXIF Auto/Manual 不计为可用光色方向。没有新素材、训练和产品改动。色度统计是已对齐实拍在同一材料上的相对观察，未给出标准场景光源标签。
