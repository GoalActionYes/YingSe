# 换灯和有意降低饱和度的交叉对照

映色会把参考的现场光色带入目标。要减少误带入，必须先有一个可核验的正例来判断有意风格是否仍被传递。本轮冻结两场景与两个灯号，复用有色域余量的四张图、两版调色流程和八组未编辑对照。唯一新增因素是给参考图施加已有的 global_desaturate 操作，色度缩至原值 60%。这是明确的统一编辑，并可在任一灯光下重复。目标始终是原目标图。直接对目标使用同款编辑、再以 0.8 强度混合，只作为离线已知结果。两版各新增八张成片。无训练和无手动参数。

固定目标与参考灯时，用编辑开关前后的成片差比较真实的同款编辑差。分别测整图及白至中灰的五块色卡。沿用研究已有的方向投影 0.75 至 1.25、成片差误差不高于 3 RGB8。固定目标和编辑状态后，再交换参考灯，沿用既有的 18 RGB8 可测差幅和 0.20 同向投影门槛。保留两个编辑状态下的原始幅度，并记录同一编辑的成片差随参考灯变化的误差。若未通过，保留反向、过调、迁移不足和饱和边界，禁止以任一均值认定有效。若编辑响应真实但仍随灯波动，可验证独立削弱参考光色的信息来源。若两版连统一编辑信号都无法稳定响应，则不以单改强度或色度抑制作为升级路线。
