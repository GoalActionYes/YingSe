# 人像换款是否只差一个全图色度力度

使用冻结 13 号、扩展第 4 轮和相同双人像开关归档。先让关态等于目标原图，给力度调节最有利的条件。保留开减关的逐像素色度变化，只改变非负的共同增益。用原色度投影区间 0.75–1.25 计算每个合格分区允许的连续增益区间。整图和共同近中性色是原必要栏位；登记的脸颊、浅树皮和草地作为附报区。交集为空只说明在量化和色域处理前，仅统一缩放不能恢复预期幅度。

固定选择整图色度误差最小的非负最小二乘增益，按已有色域处理实际生成每个方向、每种模型的成片，保留目标亮度。沿用投影、响应 MAE 3 及原资格标记评分，记录发生色域压缩的比例。已归档的完整模型分数须复算一致。另检查同一增益为何不能同时满足所选区域。两遍各四张实图。若连续必要条件或真实成片失败，就结束在本批上训练单一色度力度的想法。所有答案和原参考开关都只供离线诊断。
