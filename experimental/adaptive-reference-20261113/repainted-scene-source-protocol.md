# 实拍换材质与换灯对照的来源核查

问题是能否取得同机位、灯光设置可查、表面材料有实际变化的照片，用来辨别普通参考的偏色来源。核查官方发布中的拍摄分组、对照记录、数据许可、可读性和少量取样成本。优先检查 FAU 2011 重新喷灰的实拍与 Visillect MLS 实拍。ICTPolarReal 用于确认是否有可直接取用的多材质实例。此前 FAU 红蓝灯交换档案不包含这次的喷灰对照。

仅核查元数据。FAU 若支持字节范围，则最多读取 512 KiB ZIP 目录，通过明确的同场景后缀核对原色和灰色两类的实际配对。验证范围响应、对象大小、ETag 和索引文件名。不读照片成员、不绕过访问控制。满足条件后才能决定下一轮取样；未核实数据许可或配对身份时保留为候选来源。整个流程不训练、不调整此前失败方案、也不用于独立画质验收。
