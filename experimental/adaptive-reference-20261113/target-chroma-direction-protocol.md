# 锁住亮度后，现有色度方向是否足够

上轮恢复线性亮度使两套算法各多过 5 项，但浅灰卡和白幕仍失败。本轮只放开编辑幅度，检验固定方向本身是否足够。沿用六个开发状态和 33 个原区域。以原图为起点，从已归档锁亮度成片差值中扣除量化残留的线性亮度，得到恒亮度颜色方向。每像素允许任意非负力度，限于该方向的合法色域。以正确成片求使线性 RGB L1 最小的合规力度，并实际生成 8 位成片。已知前后参考、理想关态及目标成片均属离线诊断条件。

沿用 RGB8 MAE ≤3 和风格投影 0.75–1.25。将线性 L1 最低值乘 sRGB 的最小斜率，再减半码取整余量，作为 8 位 MAE 的下界。并报期望成片与目标线性亮度差单独能解释的最低误差约束。若颜色方向下界超过 3，而独立放开方向的恒亮度成片通过，则证明该区域需要改方向。失败成片而下界未超过 3 的区域保留未定。恒亮度方向不限的参照由目标正确成片恢复到目标亮度，仅用于可达性判断。输入与模型强度固定，CPU 无训练，双跑校验。
