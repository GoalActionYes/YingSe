# 已知编辑位置能否修复原模型的天空响应

从双向真实天空开关的冻结成片出发，固定各模型关态。以目标作者 80% 成片相对关态的亮度下降至少 1 为离线编辑支持，支持区外停止原模型开关变化，区内保留原亮度差。第二臂在同一支持下允许一个非负全局倍率，在预先登记的主天空内按作者亮度差最小化平方误差。两臂计算只向三个通道均加同一亮度差并量化，报告色域裁切。作者支持与倍率均参与离线诊断，不能计作普通两图推理。

沿用原天空投影、响应误差、前景保护和额外误差门槛；新增双向均通过才支持继续沿同一模型的亮度变化只改位置。报告倍率、前景和关态误差。若支持臂不够但倍率臂通过，位置和幅度都需估计；若倍率臂也未通过，保留亮度分布或已有基底误差。固定两场景两个冻结模型，不训模型或扫参数；两遍各八张开态图。
