# 量化全局 RGB 映射在局部冷色对照上的表达限制

ColorFM 两种公开入口用语义信息决定调色，但固定一对输入后由全局颜色函数渲染。待检验的是这一限制是否足以让白球服等既有局部冷色对照中的人物与背景误差门槛不可同时满足。允许任意精确 RGB8 查表，容量大于 ColorFM 固定形式及普通插值 CUBE。

固定已用六组、80% 强度和渲染尺寸，复用局部开关的目标原图、作者基础版、作者局部版和标注。所需增量为作者局部减基础。同一个目标输入 RGB 在全图只能获得同一局部增量。对四个有人的目标，在人物近中性色与背景编辑核心两区域内求最小的加权绝对误差。权重以像素数归一后分别除以原门槛 1.5 和 3。若最优归一化误差和大于 2，则这两个门槛无法同时通过；若不超过 2，只能说明此必要条件尚不足以排除，不代表完整门槛可达。记录两区域精确同色像素数量、两项误差与无人恒等。该诊断允许读取答案，得到的是表达下界，无新算法评分。

以 6 份相同输入与两个现实画面区域的生成开关为预算，两遍 CPU 比对。先核对 ColorFM 来源和量化条件，不下载其权重。只有渲染能区分区域的候选才值得直接做完整局部调色测试。若严格下界未压过门槛，再以实际两图误差区分，不把架构限制直接当作数值失败。
