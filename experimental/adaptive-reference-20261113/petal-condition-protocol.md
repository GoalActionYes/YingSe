# 冻结风格条件：下一对照的准备与边界

动机：PETAL配对信息较强，但直接优化其余弦距离的微调失败。下一问题是把该信息作为颜色映射的输入条件，并用实际标准结果监督，是否有帮助。不能继续用同一余弦分数作为画质成功标准。

本阶段只准备训练1024/开发64行的content和reference特征缓存，不启动训练、不生成候选画质分数、不使用新保留图片。输入统一历史256×256 RGB8。只复用上一编码器诊断中偶数索引的参考特征，逐个核验父文件、像素和次序；不复用其GT特征。剩余输入按像素SHA去重，PETAL仍用官方512/LAB/z1024和原精度，batch2，末个不足时用同图填充。前后完整模型状态摘要一致。缓存保留每行角色到像素及特征索引的映射。

后续拟定的配对对照：两臂从当前13号epoch6相同主干出发，冻结主干，只训练一个零输出初始化的条件头。控制为当前冻结H128（补零到1024），候选为冻结PETAL1024；两者均输入目标、参考和二者之差，经3072→128→128，残差加入原hist_projection的128维单token条件。保持原渲染链，不另加局部/语义模块。初始所有64开发图必须与原模型逐像素一致，禁用头必须恢复原输出。零初始化桥接通过后才允许启动两臂训练。

拟定训练固定seed20261125、AdamW头lr1e-4、wd1e-4、8轮2048更新、batch4、相同grouped_batches样本流，RGB L1+0.1横纵梯度L1、裁梯度1。仅按开发64图平均RGB误差选轮，包含零轮。不得更新PETAL或H128主干，不增加余弦损失、不按已消费77组挑参数。正式启动前必须另存完整配置、特征缓存及源码哈希，若发现数据或结构问题修改设计则保留版本记录。

拟定开发门槛：候选比当前13号平均改善至少5%、至少40/64改善>0.1、明显退化至多2；新增参考32图不退步且至少17改善。候选还须比同预算控制平均改善至少3%、至少36/64改善、明显退化至多2；32组delta MAE均值改善至少5%、至少20组改善>0.1。明显退化仍为增加>5且>25%。全部通过才设计新的独立评价；不以开发成绩代替自然人类偏好、原生分辨率、视频稳定或速度验收。

这条路线如实施条件头学习，就属于新增小模型训练，必须明确记录；本阶段特征缓存不更新权重。即使通过也不等于剪映原算法、不证明语义理解，普通CUBE不能完整保存空间结果。首分析要包含PETAL编码耗时，不能仅报告缓存后渲染速度。
