# PETAL 风格编码器诊断：预先冻结的范围

问题：整套 PETAL 迁移配方未通过后，其公开冻结编码器是否仍比当前 H128 更能识别跨内容的对应调色风格？这是独立诊断，不训练、不接入产品，不修改完整模型筛查结论。

- 仅使用既有 frozen-grade-correspondence-v1 的 1024 个已使用训练配对，共 256 组、每组同一目标内容的四种风格；参考图与标准结果共 2048 次输入。输入统一为该历史诊断实际使用的 256×256 RGB8，逐项核对父文件和像素哈希。不新增素材，不接触保留集。
- H128 直接复用历史特征缓存，先验证缓存与报告哈希及全部 2048 个输入顺序、像素哈希。它在这些训练样本上有训练优势。PETAL 预训练重叠未知。这不是独立泛化评估。
- PETAL 使用现有已校验公开源码、权重、隔离 Kornia wheel；官方严格加载，不更改权重、浮点精度或内部 RoPE 配置。RGB→512×512 双线性（align_corners=False）→官方归一化 LAB→原始 style_branch['z']→L2 归一化；保持 float32 与官方 cuDNN 配置。每次两张图，先参考后标准结果。
- 在提取前，用首个已使用配对运行一次官方 inference，forward hook 捕获编码器结果，与诊断包装结果比较；最大绝对差必须为 0。该步骤仅验证同一运行环境的桥接，不证明与发布者原始运行环境一致，也不评价该次生成图像。
- 提取前后全模型参数和缓冲区哈希必须相同；模型保持 eval、requires_grad=False。所有特征必须有限、非零，保存缓存及哈希后才计分。
- 对每组 4×4 特征计算 float64 L2 归一化后的余弦距离 clip(1-cos,0,2)，对角线为提供的配对。使用既有 correspondence 的并列分数规则（rtol=1e-10，atol=1e-12），保存全部成本矩阵，不删组、不换距离、不调参数。
- 研究价值门槛：PETAL row_top1 ≥50%，且比 H128 至少高 5 个百分点，assignment_fraction_correct 不低于 H128。必须三项同时通过；通过仅支持另外设计真实迁移实验，绝不代表产品升级、语义理解或允许直接启动训练。
- 报告编码器耗时与 CUDA 分配峰值；不声称端到端速度或 1080p/视频支持。2048 次输入包含标准结果，仅用于离线诊断，不是产品运行条件。
- 无人类盲评，无新视频、原生分辨率或独立质量验收。本实验不会证明更好的编码器必然带来更好的调色器。
