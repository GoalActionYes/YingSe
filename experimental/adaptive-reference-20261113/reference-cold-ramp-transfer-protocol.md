# 换照片与局部边缘方式后，背景过渡判别能否复现

固定的背景内过渡特征已识别原四张局部版。它可能主要看到了原程序的羽化边缘。这一轮冻结整组参考的 5.8449760077851 阈值和特征，用此前未作为参考的六张目标照片作开发压力测试。六张目标来源编号与定阈值的六张参考均不重合，仍属项目已用照片。

沿用此前全局基础版与整图冷色版，另做同一局部冷色的两个版本。硬边版给人物蒙版外全部像素等量冷色。宽过渡版按人物轮廓外的八邻接距离除以 32 并截断到一作为权重。两种形式均保持人物内权重为零。两张无人照的局部版本等同基础版。冷色向量与 100% 参考输入沿用原协议，使用同一浮点基底再分别量化。人工蒙版仅用于制备照片。每张成片独立计算原自动分割与冻结过渡分数。无支持则无判定，不从其他版本补参考。

两种局部方式各需至少 3/4 命中。基础／整图及无人变体共 16 张，须零误触发。保留分数、有效配对、遮罩哈希及各臂失判。若一种方式失败，原固定特征不得接入自动保护，禁止按这些照片修改阈值、边缘范围或保护程度。若均通过，也只是照片及边缘扰动检查，之后仍需普通自然参考的开发筛选与完整渲染验证。两遍，每遍最多 60 秒，使用现有 GPU 与资产。
