# 整体强度衰减的开发对照

问题是白球服与人物等区域的背景串色，能否仅靠降低现有 13 号调色强度解决，同时保住原有参考变化。固定背景干预 v2 的六组开发目标与 42 份 80% 输出。候选变化仅为把各输出继续向同一目标原图混合。给予每组目标独立的任意系数 `a ∈ [0, 1]`，但同组换参考时保持该系数。使用已有输出及已有区域蒙版，只做离线测量，CPU 预算 45 秒。

沿用已有门槛。人物方向串色至少下降 20% 且至少 0.25 码值，等色方向的整图着色在人物区域至少保留 90%。每组两项全图对比度／去饱和响应均需维持 90%–110%。近中性色平均串色至少下降 15%，最差上升不超过 1 码值。人物方向根据原判定至少 6/8。

同组未量化的任一干预差均为原差乘 `a`。允许每个输出最后四舍五入，两个输出相减后单通道误差放宽到 1 个码值。由此得出每个必要条件允许的系数区间，使用对衰减最有利的舍入误差方向。区间冲突可排除整类衰减，区间相交只表示必要条件未排除。报告每个方向和近中性色最乐观的平均改善，不输出调参候选，也不消耗独立样张。若 6/8 仍有数学可能，下一步才用对应区间验证实际舍入输出。否则保留为「仅降强度」对照，并继续寻找能选择性保留有效风格的方案。

实算阶段固定检查 101 档 `a = 0.00, 0.01, ..., 1.00`，用有理数混合后作最近偶数舍入。每组先要求两项全图响应合格，再分别求人物通过数最大值和两方向近中性色串色之和的最低值。各组允许独立选档，人物与中性色两个最优值也分别求解。若其中任一宽松上界仍不达标，排除该组允许范围内的联合通过。档位之间仍只使用前段数学界限，不能由离散实算宣称连续区间不可能。
