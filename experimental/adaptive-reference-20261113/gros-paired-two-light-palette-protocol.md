# 用同一参考人物的另一真实灯位补足颜色覆盖

上轮人物 01 暖灯供样在两处失败右颊上覆盖 0.16% 和 6.91%。本轮只向残差样本加入相同参考人物的冷灯开关对。保持原暖灯三次表、不同 RGB 去重、八近邻、距离 6、衰减、80% 与目标原图关闭态。整图使用同一规则，范围和原目标答案只在评分用。先复现旧暖灯残差图及评分，再生成补样输出，冷灯成片完全沿用。新增参考图已归档，不打开独立验收素材。

固定六方向、两灯、整图及四区。需新增完整方向且旧通过区没有掉项或超过 1 RGB8 误差回退。若覆盖显著增加仍过调，下一阶段应分离拟合误差，不继续放宽距离。若覆盖与结果同时增加，保留为参考开关与多光照已知时的开发证据。记录新增不同颜色数、右颊覆盖、风格和换灯差。双跑，旧 CPU 环境。
