# 单张参考中的局部色差能否辨认同一编辑

固定《Cuckoo》、混合光人像及已有两套 RAW 天空素材作为四个内容组。用同一 RawTherapee ColorToning 参数给后两张 RAW 生成编辑开关对照，其余默认显影固定。该组用来确认参考成片中是否有可观测的开关信息。与同旧风格识别不同，本轮使用相邻区域内按亮暗分组的相对色度特征，试图少受场景整体色偏影响。

每组有两张参考。逐整组留出，训练只用其它三组。对照用全图亮度和两个色度分量的 10%、50%、90% 分位数。候选只使用 4×4 个固定网格中高低亮度两组的平均色度差，再汇总三个分位数。各臂在训练分割内标准化，使用同一固定岭参数 1 的线性分类器。输出符号大于零为开启。读取待测参考的单张成片，配对仅供离线拟合及评价。仅在开态及关态各识别至少 3/4、且两种内容类型至少各识别一个开态和一个关态，同时整体超过对照 2 项时，才把信号纳入后续调色试验。固定运行两遍，保留误触和漏判。即使通过也只覆盖这一项已知编辑。
