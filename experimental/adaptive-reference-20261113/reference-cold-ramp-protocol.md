# 仅在背景内测量冷色过渡

上一轮跨越人物边界取样时，换照片产生的色差压过了局部冷色。检验只在自动人物边界以外比较近处与远处，能否避开人物和背景的材质差异。要求方向在多条向外的背景线上一致。

只用原 18 张参考成片与每张独立产生的冻结自动概率。基准仍是跨越人物边界的色差。唯一改动是新的背景内取样值。以概率 ≥0.50 为人物，计算截断的八邻接距离。近端距离为 2–10 像素，沿四条水平或垂直方向取 16 像素远端并检查中点。近端、中点、远端概率均须 ≤0.20，三点到人物的距离严格递增。两端的 BT.601 亮度差须 ≤12 码值。分数为远端减近端的既定冷色投影中位数，至少 128 对才判分。距离和选择条件与结果无关，不使用原图、目标、人工蒙版或同图其他成片生成特征。

沿用整张参考留一的阈值规则、至少两组可用训练场景、四张局部至少三张命中、十四张负例零误触发，且局部在同图版本中排序最高至少三组。本轮程序化调色有羽化，成功也仅说明能观察该受控过渡，之后需更换独立原始内容和多种羽化流程，不能直接接入产品。若不通过，结合上一轮结论停止仅用冷色边界／过渡及阈值判断编辑意图，不在此批照片继续调整带宽或阈值。

在合成阶跃图中检查纯整图等量冷色保持分数，背景冷色渐变使分数增加，缺少人物返回无证据。两遍 CPU 验证各≤30秒，保存全部分数、配对数量、失判和重复核对，无训练、下载或软件改动。
