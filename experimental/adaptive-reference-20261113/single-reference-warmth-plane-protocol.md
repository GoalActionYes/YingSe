# 单张参考的同表面色差能否提供局部暖色

给定已知编辑范围后，用参考前后图取得的暖色可重放到新场景。现只替换取色输入。MIT 复印室和 Beyond RGB 白蓝场的每张参考仅以自己的像素估计要传的暖色，仍用上轮冻结的参考与目标位置。相对于之前两个框之间的亮度差，此处对同一表面的两维色度和已知软编辑形状做空间拟合。场景内的局部灯色、投影阴影、材质或反射仍可仿造相同形状。

掩膜只按两张冻结基准关态查看可见连续表面，在读取其他灯态与编辑开态前登记。MIT 图为 1500 × 1000，墙面多边形顶点依次为 (144,335)、(485,317)、(498,411)、(472,460)、(447,519)、(441,655)、(416,777)、(141,803)、(137,575)。Beyond RGB 图为 1024 × 768，实验箱托盘下方浅色底面的多边形为 (757,670)、(829,687)、(913,705)、(1024,730)、(1024,768)、(818,768)、(785,741)、(768,710)。两者都只是离线的同表面假设。使用上一轮 128 灰的两份落盘校准 PNG 重建固定形状，不从当前照片的颜色或真值改写编辑位置。

以原图每四像素固定格点采样，单张使用该多边形中 RGB8 每个通道均处于 4–251 的格点。模板权重低于等于 0.15、高于等于 0.80 两组各至少有 24 点，二维平面拟合扣除背景后的模板标准差至少为 0.10。输入不足保留缺测，不为失效调区域。两臂读取同一批像素和 D50 Lab 色度。常数背景臂拟合 1 加模板，平面背景臂拟合 1、归一化 x、归一化 y 加模板。模板的 a、b 系数直接作为有符号偏移，L 设为零。各自对四张参考独立估计，不使用其他灯图、参考原片、编辑开关标签或目标的开态。保留所有原始符号和幅度，不做选择性归零或阈值优化。

沿用上轮目标空间权重、D50 回转、80% 强度和区域计分。准备步骤把参考先赋无状态名称。每张只用自己的 RGB、冻结多边形和两侧归一化模板独立出图。合并参考标签、比较像素对与读取目标开态都发生在无状态主输出及哈希锁定之后。对原本未编辑的参考也运行并评分。用相同有效格点额外测参考关态跨灯色差和每档编辑开关差沿模板的投影，方便区分整图误偏与编辑响应。判定依据仍是单张逐图出片。

完全通过要求墙面幅度 75%–125%，关闭、开启、编辑响应及同态跨灯差的误差各 ≤3 RGB8，原保护区门槛和新增通道端点 ≤2% 继续适用。一并报出保护带和无模型恒等对照。即使两家族都过线，也先用另一组固定位置的真实有色灯斑及有意调色验证，再进入自动定位。常数和空间平面都通过时保留常数为基线，额外复杂度需由困难对照决定。若仍有家族失败，记录前置支持、关态假暖、开减关幅度或跨灯差各自的意义。若两臂都失败，不以更复杂背景多项式或在这些样本上选阈值延续。沿用本机已安装依赖、媒体和评分。无训练，准备及核验 30–45 分钟，两遍出图与计分预算 5 分钟。
