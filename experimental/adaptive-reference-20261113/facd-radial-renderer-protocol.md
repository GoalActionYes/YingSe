# 固定颜色表的径向渲染对照

FACD 三款滤镜在给定正确类别时画质误差下降，但换款响应只通过 2/7。人像和湖景的 Amaro 等成片中可见暗角，固定颜色表无法把同一 RGB 按画面位置分别调整。本轮只验证添加可迁移的径向位移能否恢复换款差异，正式类别识别保持 28/42，不重训。

- 保持原七折，每折仍排除目标和两张查询参考照片，用四个训练场景拟合。先复现上一轮三款固定颜色表对目标的 21 张离线输出。训练场景原图与效果只用于建立相同的全图表并计算 80% 成片的残差。
- 候选以像素中心的规范化坐标计算 `r=(x²+y²)/2`。四个特征为 `r−1/3` 与 `r²−7/45` 分别乘 `1−Y` 和 `Y`，Y 为原图归一化亮度。匹配对照有同样四个亮度特征 `1,Y,Y²,Y³`，没有位置。两臂用每隔两像素的固定取样、四张训练图等权的最小二乘与归一化后岭系数 0.001，额外 RGB 位移各限 ±12 码值。
- 测量两个臂给定类别及原有自动判定的全图误差、近中性色与换款响应，沿用原分组门槛。按半径另外检查外侧 `r≥0.5` 和内侧 `r≤0.25` RGB8 MAE。若给定类别仍少于 6/7，或相对等预算亮度补偿的外侧平均改善至少 1 码值的滤镜少于两款，或任一全图相对固定表退化超过 1 码值，则不认为固定径向模型足以恢复风格。保留所有实图，查看婚纱、湖景与火焰。
- 两次运行，预算四分钟。仅已消费开发组，无额外下载。正确类别作为离线对照，正式自动结果沿用指定参考成片识别。径向暗角是画幅效果，没有自动主体蒙版，也不代表自然肤色与白衣保护。两轮后不以调整半径、增益或分类阈值继续追分。
