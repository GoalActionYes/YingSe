# 更换定位来源后，局部暖调能否保持

上一轮的六个跨人物方向中，整图暖调和保色均通过，局部暖调四次回退都涉及同一位漏检的人物。唯一实验变量是局部重放的人脸框来源。用本机肤色保护版的 SelfieMulticlass 预测，从面部类别 3 且该类分数大于等于 0.5 的像素取八连通块。忽略小于分析图面积 0.1% 的块。每块的紧包围框按原比例映射到全图。恰好一块才继续用上轮脸部权重函数和色比估计，其余回退到 13 号。读到的参考编辑意图、编辑前后图、范围、参数、权重公式与目标强度均沿用，人工区域只参与评分。肤色分割可受显色、姿态和遮挡影响，也可能把一张脸分成多块。只做一次固定比较，不调整阈值或膨胀框以追补结果。

重新渲染六个局部方向，锁定并读取前一轮其余三态成片。联合门槛至少五个方向通过原区域风格和串色要求。无人和两脸必须逐像素回退，原先两项局部通过均须保留。两次运行比较全部输出。成功仅允许进一步用真实作者跨照片案例验证，失败就结束以粗定位自动代替区域意图的固定组合。过去的真实作者对照已证明给定区域以后固定偏移仍会偏强。本轮不重跑它，也不从这批合成素材推断普通两图或真实作者通过。
