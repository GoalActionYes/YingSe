# 核对 PPR10K 与 MMArt 同照片能否作笔刷开关对照

已知 1645_1 的 PPR10K 专家 A 配置启用过一项笔刷，MMArt-PPR10k 公开 XMP 未检出该项。可以成为笔刷开关正对照的必要条件是两份参数仅有该笔刷及无关的文件描述差异。上轮其余两条已知笔刷记录的 MMArt 同名目录不可用，本轮固定只检查 1645_1。

逐文件校验既有上游源配置、专家 A、MMArt 三份 XMP。按命名空间解码最外层 Camera Raw Description 的参数，独立比较处理版本、白平衡、曝光、色彩、曲线、细节、裁切及其他设置。别名、字段表示差异或缺失默认值单独记录。把专有局部树和显式列出的非成像标记从全局比较中移除，数值统一十进制，嵌套数组保留顺序。只公开已知非隐私成像字段的名称及差异类别。

任一可见有效全局成像设置互相矛盾，就拒绝将其作为单独移除笔刷的配对，无需读取媒体。即使设置一致，也须另行核对原图身份、同渲染链、对应成片和位置对齐，才能用作离线正对照。本轮仅本机读取三份 XMP，预算 45 秒，无下载、拟合、软件改动或独立评估。
