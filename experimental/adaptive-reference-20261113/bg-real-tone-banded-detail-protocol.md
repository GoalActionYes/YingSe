# 分亮度测量邻域对比度能否补回有意对比度

已有局部统计改善过白球服的冷调方向，但两种背景下的对比度投影都不足。此前单个全图对数亮度差读数会混淆曝光、背景和编辑。本轮检验不同亮度位置的局部相对变化是否提供额外信息。在正常图像中取向右和向下四像素的近邻对，取线性亮度对数差的绝对值，按两端显示亮度均值的固定区间分组。每档取第 50、75 百分位，相对于全图相同分位归一。低于 64 个点对的档回退到全图读数，归一后为 1。对照和候选共享已有亮度排名特征、同一岭回归、12 个拟合组、更换背景的四个开发组，以及同一 80% 目标渲染。每次预测只用两张普通 RGB，作者效果和人物范围参与离线评分。

两臂各 96 行拟合，四组共 64 张成片，每种编辑与背景均保留。沿用至少 3/4 联合通过、人物与近中性人物换背景差 ≤ 1.5、有效风格投影 0.75–1.25、增量 MAE ≤ 3、整图相对对照的最坏退化 ≤ 2。另报告白球服两个背景的对比度分数及所有退化。同图返回原图，平坦图的分档特征应有限且回退有效。若联合过线，再执行既有其他开发套件；未过则结束此分档近邻统计。色彩参数与成片只用于这批固定闭集开发检查，不作为正式自然画质验收。
