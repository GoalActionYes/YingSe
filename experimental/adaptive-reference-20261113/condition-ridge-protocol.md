# 条件预测的固定线性回归对照

前提：全部1024训练GT条件目标已生成并审计。前一MLP训练未提供升级，不能仅根据GT拟合分数认为预测容易。本次用封闭式回归避免迭代优化/选轮影响，同时检查已有输入能否预测有用条件；这是新的预测器训练，GT只来自训练行。

冻结三种预测：训练标签均值常量、H128特征回归、PETAL1024特征回归。H128使用上一对照保存的补零1024维缓存，PETAL用既有缓存，索引与同一1365个目标/参考像素对应。每行X=[z_content,z_reference,z_reference-z_content]；各输入向量先float64单位化，X与128维Y仅减训练均值，不按开发统计缩放。令K=Xc Xcᵀ，λ=0.1·trace(K)/1024，固定解A=(K+λI)^(-1)Yc，预测Yhat=(Xtest-Xmean)XcᵀA+Ymean。预测分量截到±3，与教师边界一致。λ相对尺度固定，无超参数搜索、无开发集拟合或GT参数输入。

三组在全部64开发图上生成零条件基线与预测条件PNG，原主干冻结，原256工作尺寸，不接入产品。基线需与历史零轮PNG哈希一致。所有预测保存后才读取开发GT像素评分。既有素材/分数已经消耗，不能称新盲测。标签均值仅作常量诊断，不能用GT选成实际算法；每个结果都保留，不择最好子集。

PETAL回归需比当前13号均值下降≥5%、≥40/64改善>0.1、明显退化≤2；新增参考style1均值不退步且≥17/32改善。另需比匹配H128回归均值下降≥3%、≥36/64改善、明显退化≤2；32组delta均值下降≥5%、≥20组下降>0.1。明显退化同时增加>5与>25%。完整通过才考虑另设计独立评价，不能用标签MSE或训练拟合好坏代替实际画质。失败不搜索λ或改特征标准化以追分。
