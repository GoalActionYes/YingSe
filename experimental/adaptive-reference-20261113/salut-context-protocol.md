# SA-LUT 上下文贡献对照

本协议在运行此项对照前固定。只使用已经用于开发的 PST50 前五对，6–50 不使用。

问题：在相同的、由模型预测的 4D LUT 下，空间变化的上下文图，是否比固定为整图均值的上下文更接近配对目标？这是局部机制的贡献检查，不是产品验收，也不证明语义对应正确。

每对读取真实 Log 内容图和普通 RGB 参考图，按作者流程预测一次。保留模型 LUT，分别应用：原上下文、上下文整图均值、固定 0、固定 1。后三项不改变 LUT，不重新预测。所有输出完成后才读取配对目标图。记录 RGB MAE、PSNR、与原上下文输出的差异、上下文和输出图，保留所有结果。

不根据目标图挑选上下文、强度或 LUT，不做每例择优。即使局部机制有贡献，也不能据此认定普通图片接入、自然观感、视频稳定性、实时性或商业授权已经解决。
