# 扩大数据的同预算特征对照

固定512训练、64开发验证及32新保留组。沿用yingse-tst-v1源照片family哈希分组与原始配对索引，保持原128训练／32验证为前缀，不依据画面或效果挑选新增图。此前已读取的32保留组及其内容／参考family整体排除在新保留组之外；所有跨组family不相交。family不保证人物、连拍或语义场景完全独立，下载后另查精确文件／RGB像素重复。

先冻结cohort-v2元数据与本协议，再请求仅训练／开发素材的远程大小及LFS SHA256或Git blob身份，下载总量上限2GiB、单文件20MiB、并发4。复用原cohort-v1字节也须按远程固定revision身份重新核验。不会下载新保留图片。模式、方向、配对尺寸、原始／准备后跨组重复不合格时停止训练，保留失败，不默默删掉样例缩小分母。

保持原图不变，另存RGB8 sRGB副本，嵌入ICC使用LittleCMS转换，未标记图假定sRGB；高位深TIFF在PIL解码后再ICC转换，不能宣称保留16位。原始ICC不一致记录与准备后的检查分别保留。

训练两条固定路径：原三条边缘特征、增加亮度条件色度统计。均从固定第8轮权重出发，AdamW重新初始化，seed20261115、lr1e-5、weight_decay1e-4、batch4、8附加轮／1024步，L1＋0.1梯度、clip1。每轮9–16评估64开发图，按均值选最早最低轮；分别报告原32与新增32，均非独立测试。新增权重为0时先验证相对原模型的初始数值等价，全部原始输出先检查finite。训练代码、配置、数据、初始权重与同预算控制记录哈希冻结。

进入独立评估的开发门槛：相对原第8轮均值改善至少5%、40/64图改善超过0.1码值、严重退化≤2；新增32张验证图也须均值不恶化且至少17张改善，避免总均值被已反复使用的旧组掩盖。联合候选还须比同规模纯边缘控制均值好至少3%、36/64图改善、严重退化≤2。严重退化为超过5码值且25%。新增子组门槛在下载阶段、任何新验证评分和训练之前补充冻结。无收益不替换App；开发均值或可区分反例不能替代自然协调性、迁移方向及视频时间稳定性验证。仅在固定候选通过开发门槛并审查实际图后使用新保留组一次。
