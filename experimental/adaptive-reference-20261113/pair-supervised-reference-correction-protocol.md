# 保留数字风格的参考校正原型

新 CHROMA-MILL 对照在另一个场景的两档蓝灯参考下均出现 Film A 反向。此前固定相机／灯光校准和三态风格选择已停止。本轮增加可监督的信息：直接用同场景实拍白灯成片作为参考校正目标，并在白、蓝原片两端施加同一个已知 Film A，让模型学习保留编辑。输出是校正后的参考 RGB。正常测试只给单张参考和目标原图，不读参考的对应白灯照片。

固定手机训练分区中按数字场景顺序选出的前四个非 Scene1/2、且同视角具有完整四状态的场景 Scene3_a、Scene9_b、Scene10_a、Scene23_a。各取白／蓝灯与 B_213／B_241，共 16 张，先核公开清单、MIT 数据卡、大小和 LFS SHA-256，最多 48 MiB。测试保留上一轮 Scene1_a／Scene2_a 全部状态；同场景其它视角不得混入。采用与上一轮相同的线性缩图、sRGB 编码及 Film A。训练场景的资格为四图同尺寸、原始白蓝参考零位梯度相关至少 0.60，±3 像素搜索提高不超过 0.02。全部合格者入训练，至少三组才拟合，否则留样本和原因。

两臂以固定 8×8 像素步长在同图格取样。两端使用同灯强、同风格状态。白灯输入的目标就是白灯自身。以原图 RGB 的二次多项式拟合三通道校正残差，岭惩罚 0.001；候选唯一新增用图像整体 RGB 均值调制这些项，使同一像素颜色可按可能的拍摄条件获得不同修正。两臂使用相同 16 张物理图、相同切分、采样、目标和系数求解。拟合完后固定权重，不看测试结果调参。校正输出限域取整，再用 13 号在 80% 出图。预测与渲染均不读标注、真实白灯对照或已知目标成片。先保留所有预测，再按固定真值评分。

每臂在原两个留出场景上各保持两档灯和开关风格，生成 16 张目标成片。候选须在所有蓝灯参考的近中性色换灯差中至少减半且不超过 3 RGB8，整图和共同近中性色风格投影 0.75–1.25、响应误差 ≤3。对白灯及三个已有实拍来源各两种自然参考（原图、Film B）另查退化，白灯目标的绝对误差相对 13 号最多增加 2，六张自然参考校正前后差均不得超过 1.5 RGB8。只有候选通过且优于无全图条件的同预算臂，才讨论更广验证。不调样本、公式或门槛追分；失败保留全部白／蓝成片和自然参考负例。此轮为开发训练和原型，独立人类、完整视频和肤色成品验收仍适用。
