# 亮度—色度联合条件候选

目的：验证上一轮独立Y′／Cb／Cr边缘直方图丢失亮度—色彩依赖的问题，能否通过很小的特征扩展改善。不是人物分割或参考语义对应，不接入App，不新增用户控件。

对内容与参考各增加3×128维特征：按Y′所在bin累计2Cb、2Cr及sqrt(2)×sqrt(Cb²+Cr²)，除以bin内像素数＋32。无样本bin为0，少样本bin收缩，不用GT或人工区域；统计使用整幅256×256 RGB8的作者Y′CbCr转换。原6条边缘直方图顺序保持，新增6条条件统计接在后面。第一Conv1d从6扩到12输入，原权重和bias原样复制，新增480个权重初始化为0，其余结构不变。

训练前验证：条件统计能区分相反亮度—颜色关系；空bin有限；非法值在分箱前拒绝；零初始化投影等价。真实32张开发验证图再比较改造前后初始输出：最大float误差≤1e-5、最大RGB8差≤1，完整记录数值差而不宣称天然字节相同；不达标则不训练。

沿用cohort-v1的128训练／32开发验证、同一ICC准备副本及固定第8轮权重。配置与训练-v2对照相同：种子20261114，重新初始化AdamW，lr1e-5、weight_decay1e-4、batch4、24附加轮／768更新，L1＋0.1梯度损失、梯度裁剪1，原始grid及输出先校验finite。仅在12／16／20／24／28／32轮验证，按32组平均RGB8 MAE选最早最低轮。启动前冻结协议、代码、数据与初始权重哈希，不读取已用reserved图片或PST16–50、TST2K，不按失败样例调种子、参考和强度。

开发推进门槛保持：相对第8轮均值至少改善5%、至少20组改善0.1码值、严重退化≤1组；同时须优于同预算纯延长训练的最佳均值至少3%、至少18组改善、严重退化≤1组。严重退化为超过5码值且25%。输出不同只能证明可区分，不等于方向正确；后续必须检查反例方向、真实对照及去掉联合特征的反证。只有开发表现成立才申请新的独立评估，不能用开发结果替代自然协调性和视频验证。

失败如实保留，不放宽门槛或替换App。许可沿用非商业课程学术研究；原图、训练权重和环境不入Git。
