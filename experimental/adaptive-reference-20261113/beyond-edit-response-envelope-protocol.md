# 静物灰卡的现有编辑增量混合上限

问题来自固定目标亮度混合的反例。两套渲染器在静物的部分灰卡都出现响应不足，仍不知道是比例选择问题，还是两套输出混合的范围问题。本轮只把固定权重换成离线逐像素最优的共享 RGB 凸组合。保持同一目标底图、参考编辑前后对、两款渲染器与 80% 原强度。实拍换灯和原参考仍按受控条件保留目标原图。目标真值供离线求解和评分。

使用前一轮 Beyond RGB 两个已用构图及各两种拍摄状态。整图与五块灰卡均纳入，沿用 RGB8 MAE 上限 3 与风格投影 0.75 至 1.25。连续最佳误差减 0.5 仍大于 3，或投影可达区间含量化余量仍与门槛无交集，即证明该区域任何比例都不能通过。否则保留未证实区间。权重根据 MAE 拟合，其成片的投影失败本身不足以排除其他权重。四个状态各保留一张最佳成片和一张对照，两次同输入运行，CPU 无训练。

若存在无法通过的区域，结束把两套现有增量的凸组合作为完整修复的路线。根据误差或投影下界判断下一次需要的渲染自由度。若所有状态的离线成片通过，则可以继续评估可推理的权重信号。若仅得到未证实区间，则报告证据限度。
