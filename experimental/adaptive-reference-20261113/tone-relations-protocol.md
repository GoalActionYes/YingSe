# 固定目标明暗权重的关系监督

本轮仅为开发研究，不修改App。起点仍为13号当前第6轮SHA `d8d8e6727a44100e6fedb11b605a17e33afc675de7448d4ebcf6d24d492ad4c9`，不从已失败候选续训。数据仍为cohort-multiref-v1的256目标×4参考训练及32目标×2参考开发，不读任何已消费reserved或新独立图。

两臂都安装上一轮两两联合颜色条件，保留相同模型、额外参数及零初始化方式，仅改变损失。先检查全部64张初始浮点输出／网格和保存PNG与当前模型完全一致；候选与控制的初始完整参数必须逐张量一致，不能只比较零头输出。

对归一化RGB的固定目标计算Y=0.2126R+0.7152G+0.0722B，以0、0.5、1为三角中心、宽度0.5得到暗／中／亮三个软权重，每像素相加为1，另加全图权重1。权重只读目标、detach，不读输出或GT，不是人物／语义分割。每个区域的加权矩加入0.01倍全图均值先验，再除区域平均权重+0.01，防止稀疏／缺失区域不稳定。

每区域五项为Y均值、sqrt(max(E[Y²]−E[Y]²,0)+1e-4)、Cb均值、Cr均值及RGB最大减最小通道跨度均值，共4×5项。Cb／Cr继续采用作者矩阵[-0.1146,-0.3854,0.5]与[0.5,-0.4542,-0.0458]；五项权重[1,1,2,2,1]。扩散项有0.01下限，不称精确物理标准差；RGB跨度是饱和度代理，不是HSL饱和度。

保持原RGB L1+0.1倍横纵梯度L1损失。实验臂额外加0.25×描述子绝对SmoothL1及0.5×配对描述子差值SmoothL1，beta均固定1/255；控制臂额外权重为0。配对必须为batch4中的0/1和2/3，目标像素完全相同；使用同一套固定目标权重计算预测和GT。这个组合只验证整体关系约束，不据此归因两个子项各自贡献。

训练前合成numeric-v1发现，原始L1在理论应为零的色度／扩散差上受舍入影响，CPU／GPU标量损失仅差9.31e-8，梯度最大差却达0.000806。定位到约1e-9至1e-6的误差跨零导致L1符号导数反转。新增小于一个码值的SmoothL1过渡后重新执行检查；权重、数据、训练预算及推进门槛不改。这次修订发生在任何本轮开发评分／训练之前，失败原记录保留。

先用合成数值检查：GT预测损失为0；平坦灰图／缺失区域及梯度有限；同空间置换和配对反转不改损失；全局RGB均值相同但明暗颜色相反的构造仍能被检测；有限差分与CPU／GPU对照。合成结果只证明约束性质，不算真实调色效果。不用开发GT调整损失权重。

seed20261119、AdamW、base lr1e-5、额外头lr1e-4、wd1e-4、batch4、8轮／2048步、梯度裁剪1，二臂样本顺序及初始化相同。普通控制先完成并冻结结果／评分，才启动关系臂；保存配置、数据及共同源码SHA，每轮输出全部64图。控制完成校验沿用已修复的最终门槛／预算／检查点／源码一致性检查，不能只看finished标记。

选轮仍只按64图平均RGB MAE最低，包含0，不按训练关系误差或多个指标换轮。完整推进门槛保持pairwise_gate.response_development_gate不变：相对当前平均RGB至少改善5%、40图改善、严重退化至多2，新增参考32图均值不退且至少17图改善；delta响应至少改善5%；明暗关系误差改善至少5%，亮度／对比度／饱和度代理误差不退。关系臂另须胜同预算控制：RGB均值3%／36图／严重至多2，delta均值5%／20组，明暗关系误差3%。全部通过才分配新独立评估。

上述旧tone_response评分继续保留原已冻结601式口径（Y权重0.299/0.587/0.114，Cb=(B−Y)/1.772，Cr=(R−Y)/1.402），以便沿用门槛；训练约束采用作者709式矩阵。两个口径预先分别声明，不在结果后换矩阵或重选模型。可以另报告训练描述子分数作次要诊断，但不能单靠被训练的指标宣布成功。

结束核验两臂源码、预算、全部保存输出和选轮；至少查看固定前2及相对控制最好／最差未覆盖例。失败时不升级、不放宽门槛；通过后仍须新的独立图、原尺寸、视频时间稳定和速度验收。不会为训练增加用户操作开关，也不声称语义关系已解决。
