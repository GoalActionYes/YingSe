# 相同输入 RGB 的同款成片能否跨照片一致

白天样式 3 的反例在两图共有的颜色格里仍有明显误差。待检验问题是，固定颜色格是否把实际不同的颜色混在一起，或者即使输入的 RGB8 完全相同，同款成片也会随照片而变化。

固定上一轮四张照片和 12 个目标／参考／样式比较。读取样式 1 和对应样式 2、3，使用原有 80% 混合形成评分成片，不做缩放。按精确 24 位输入 RGB 分组。每张照片用 16×16 空间块棋盘拆为两半，每个精确 RGB 在两张图各自两半都至少出现 8 次才纳入。比较相同 RGB 的成片平均 RGB：参考对目标的两条交叉半区比较，以及各照片自己的两半比较。像素数和评分覆盖率一起报告。主统计按精确 RGB 等权，近中性色独立报告。

预先固定白天样式 3 为主例。整图共享颜色至少 128 色、覆盖目标至少 10%，且跨图成片平均差比两项图内差的较大者至少高 2 个码值，才视为同一输入颜色对应的结果随照片发生明显变化。其余情况分别保留为覆盖不足或未达到差异门槛。结果只针对该来源的渲染 RGB8 输入，无法排除前期处理、JPEG、局部调色和预设按图变化。

CPU 两遍，复用八份预设成片对，无下载、训练或产品变更。每个比较保留结果。若主例通过差异判定，结束将本来源直接用于跨图统一 RGB 映射的路线，并保留用于研究照片内调色的信息；若两图同色覆盖不足，本批不足以支持跨图统一映射结论。
