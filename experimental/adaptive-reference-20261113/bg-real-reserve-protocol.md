# 冻结未用的现实背景替换对照

最终评估需要区分素材是否真的未参与选择。PST50 的拍摄家族仍待确认。本轮先在 BG-REAL 的固定发布里核对背景稳定性负例的来源隔离。它补上的是实际换背景的受控回归；真实自然度、人物／白墙专项及视频仍按总目标评估。

复用已验真的四份发布 CSV、87 对资格清单及两份本机消费台账。把同一 Open Images 来源、同一 Flickr 原片号及相同成片摘要归为同源；沿发布匹配流程连接 C1／F1 的主体及供体，按连通分量处理，允许不同号因交叉角色或共享原片号归在一起。既有四组开发及十二组拟合的任一角色命中即排除整个分量。核查两输入目录的实际媒体哈希，不打开、解码或显示未用图。缺身份或照片号冲突时隔离。未知第三方近重复关系仍须另核对。

在冻结分量中选择六个 `Man`、六个 `Woman`，每个仅一对。同类按 `SHA256("yingse-bg-reserve-v1|" + 来源号)` 排序，先取 Woman 再取 Man，优先排除已占用的整个分量；选择只读发布标签。目标取名单里的下一组 C1，最后一组回到首组，同一场景的起始与替换背景只作为参考。12 对全满足元数据与消费隔离才冻结本机暂存清单，否则保留计数和阻碍，不换人群或降低条件。标签不能代替同意、肤色或材质标注。

公开摘要只写分组计数、保留清单摘要和发布身份。12 对只作候选冻结后的背景稳定性回归，不能参与训练或对照参数选择；本轮不下载新照片、不启动模型。取得正式资格前，还需检查跨来源近重复、实际主体像素保持与范围覆盖，并保留自然和有效风格的另行独立评估入口。

本机名单摘要冻结后，从已登记的 COCO 与监督风格两个来源清单读 `flickr_url`，核对同源照片号是否与保留项任一角色共用连通组。保守排除已取得的所有清单照片。发现精确冲突时登记受影响的名单序号并隔离，不替换条目。无法解析的 Flickr URL 单列，按不同图集的近重复仍属待验。只读已经存在的清单，不检查封存图。
