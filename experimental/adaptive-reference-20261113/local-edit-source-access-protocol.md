# 核对局部调色来源的公开入口

白球服在已知范围时可由现有网格重现，正常两张图的颜色统计还无法稳定确定编辑范围。本轮检查能补充监督的真实修图来源。只核查此前未通过代码与发布清单验证的 Adobe Artist-Retouched／PIH、NTIRE 2026 Photography Retouching Transfer、MirrorPPR，以及检索到的两图软件 GradeStudio。已有 RTD 与 PPR10K 记录继续作为参考。

规则固定为查找同一原始照片的原始和调色结果、能追溯的编辑区域或操作、跨拍摄内容的同调色标识及足以判断使用权限的素材条款。主体蒙版只能说明主体范围。评测所需的额外参考原图与人工蒙版不能成为映色推理输入。

只用官方论文、项目、发布树、开源代码清单与官方接口访客可见元数据。直接检查单请求至多 512 KiB，累计至多 2 MiB。禁止绕过登录或防自动访问页面，不下载媒体、权重、归档或环境，不使用个人账号。只有确认授权、资产可访问且已有跨内容和区域关联证据才进入另行固定的少量像素试验；未达条件保留具体缺口，避免扩大既有无信号训练。
