# 多参考基础上的两两联合颜色条件

先冻结协议，再运行新的训练或开发评分。只用既有cohort-multiref-v1的256训练目标×4参考及32开发目标×2参考。当前第6轮SHA为`d8d8e6727a44100e6fedb11b605a17e33afc675de7448d4ebcf6d24d492ad4c9`。不读三批已消费独立图，不分配新独立数据，不修改13号权重。

动机来自已冻结tone-response-v1：当前模型更换参考时，全图亮度方向25/28组正确，亮部减暗部Cb／Cr变化方向只有15/24与16/24。它是开发诊断，不是新增独立验收。此前亮度条件色度均值未胜过单参考同预算控制；本轮改用完整两两分布，并保留失败记录，不把方法换名当成已有效。

统计当前256×256分析图的Y–Cb、Y–Cr、Cb–Cr三个16×16硬直方图，各自计数除像素数后开平方，得到768维。Y按[0,1]分箱，Cb／Cr先加0.5按[0,1]分箱，极值放入末箱。只允许1e-6数值边界容差，明显超界／非有限值拒绝。它保留两两关联，不是完整三维分布，也不保留位置或人物／背景语义。

源与参考的768维及二者差拼为2304维，经2304→128→128、GELU的MLP，加入原直方图context；末层全零初始化。先逐张对照全部64张开发浮点输出与当前模型，必须最大差0再训练。保留原边缘直方图、内容编码、网格、引导、低通及图像位置。新增311,552参数，不称相同FLOPs。

两臂从同一个当前第6轮开始：普通续训control与额外pairwise条件。使用同样本流、seed20261118、AdamW、base lr1e-5、adapter lr1e-4、wd1e-4、batch4、8轮／2048步、梯度裁剪1。损失仍RGB L1＋0.1倍横纵梯度L1和；不同时改变监督损失。每组4参考按既有grouped_batches组织，同一轮所有1024样本各使用一次。安装额外头后重置Torch随机流，避免初始化消耗改变训练随机性。

只按64图平均RGB MAE选轮，包含起点0；每轮保存完整64输出、MAE、32组delta响应和tone诊断，不按多个指标事后换轮。控制结果冻结后才训练候选，结束复核控制结果／评分SHA不变。

沿用完整开发门槛，相对当前基线：平均RGB MAE至少改善5%、至少40图改善超过0.1、严重退化至多2，新增参考32图均值不退且至少17图改善。严重定义仍为误差增加超过5且超过基线1.25倍。两臂还需平均delta MAE改善至少5%。候选另需相对同预算控制：RGB均值改善至少3%、至少36图改善、严重退化至多2；delta均值改善至少5%、至少20组delta误差下降超过0.1。

针对本轮动机另设关系门槛：两臂的亮部减暗部Cb／Cr两项平均delta误差之均值比起点改善至少5%，饱和度、亮度和对比度delta误差均不高于起点；联合候选的该关系误差还须比控制改善至少3%。全部条件同时成立才考虑新的独立评估；失败不接入，不放宽、不挑图、不调轮重跑。

训练后对所选候选做屏蔽联合头的消融，以及只错配联合参考特征、保留正确原边缘直方图的消融，判断新增参考信息是否产生净收益。即使这些消融有差异，也不称语义识别成功。后续独立、原尺寸、视频时间稳定、性能及App接入仍分别验证；本轮仅为开发研究。
