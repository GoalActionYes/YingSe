# 实验室换灯规则在普通参考中会不会误调

受控杯子实验通过以后，检验同一个冻结两图链路遇到一般主题照片会不会误将参考背景变化当成已校准的红蓝灯互换。固定已有背景干预的六对目标与参考，包含四对有人和两对无人。各对使用原参考、原参考重复、满幅背景绿／品红、整图绿／品红，共 36 对。参考照明复用同版已落盘分解，六张目标用同版 RGB-only 推理。分类中心、两标定系数平均、渲染强度不变，先桥接已有实验室输入，核对自动出图与旧预测一致。

本轮所有普通参考都没有实施已校准的红蓝灯位互换。这个前置条件的检验要求不激活该操作；整图绿／品红用于检查另一种整体色偏会不会被误认作这个操作。它不规定普通参考应原样输出，也不计作整体风格迁移能力。主指标为错误换灯数、相对原参考的背景换色开关变化、及其相对原参考输出的 RGB MAE。报告每对的整图、目标人物和近中性色，区域标签只在全部出图后用于测量。还需原参考重复逐像素一致。

任一错误启动即停止冻结的实验室链路作为通用方法，不调整类别中心、距离阈值、方向或参考区域追分。即使零错误，仍需验证普通参考的有效迁移。两次本机运行，预算为每次六张目标照明估计和一次原权重桥接，不下载、不训练、不动软件。
