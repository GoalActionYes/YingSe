# 根据对应证据选择全局调色假设

第二轮10对中，输入原图对专家目标平均MAE13.195，现有全局18.435；全强度迁移常常过调。锚点全局18.293、局部18.514，没有稳定收益；仅在当前／Canon之间选择的锚点混合17.030，三对改善、无对明显退化，其余保持。不能据此发布，但说明“是否需要这么强的迁移”应成为自动估计的一部分。

本轮只在已使用1–15对上开发，不读取16–50。新增原始输入作为第三个颜色假设，另两个仍是由同一参考／目标实时估计的当前映射与Canon映射，不是预设滤镜库。用相同DINO对应颜色锚点，最小化三个输出patch均值的加权RGB平方差；非负权重和为1。二维凸二次问题检查内部最优及三条边界，不使用专家目标或逐例人工强度。平均对应置信度低于0.1时仍回退现有算法，保留现有跨内容迁移能力。

所有15组输出先保存，再统一与既有开发专家目标评分，记录全部权重与误差。此分支仅研究全局自动强度／方法选择，不解决同RGB在不同区域的独立变化，不以它替代最终自适应协调目标。先看是否确有整体收益、明显退化减少和视觉风格保持；若没有，保留失败，不继续逐例改权重规则。未通过独立素材、自然观感、完整图片／视频导出与交互验证前不接入产品。
