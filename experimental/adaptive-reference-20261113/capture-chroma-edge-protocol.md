# 相邻像素的色度差能否区分真实换灯和同色数字染色

上一轮在脸颊及近中性色内部对齐亮度排名，仍不能恢复改色幅度。已有全图和分块色偏统计也难以区分布景换灯与整体染色。本轮检验不同的拍摄线索：在线性 RGB 中取 log(R/G) 与 log(B/G)，再对相邻位置求差。整图乘以固定通道增益时，同一比值上的偏移为常数，沿空间求差会消去这个常数。实拍照明可能改变局部材料、反光和阴影的相对颜色。量化、裁切和选点变化可能破坏该性质，因此一并记录可用比例，并对数值进行配对检验。

复用已核验的 CHROMA-MILL 三布景两个相机及 Beyond RGB 两布景。每个布景使用基准、真实换灯、匹配数字染色三态，均属已使用的开发资料。使用水平及垂直相距四像素的边，只比较端点各通道在 8–247 内的边。每个通道取绝对差的中位数和 90 分位数，固定为四维描述。配对核查时，对每个三态用共同有效边，分别计算数字染色与真实换灯相对基准的绝对差分误差中位数。有效边不少于 1,024，实拍差分至少是数字差分的两倍，才认为该组支持所设机制。保留三态的并列成片和局部差分图。

单张识别只能用自身有效边。按布景整组留出 CHROMA-MILL 的两相机，在对应训练折用标准化后等权欧氏最近类别中心区分实拍换灯和其余两态。Beyond RGB 使用三布景训练，整体检查来源迁移。门槛为 CHROMA-MILL 至少 5／6 实拍正确、12 张基准／数字无误报及至少 5／6 配对机制过线；Beyond RGB 两张实拍正确、四张基准／数字无误报且两组配对机制过线。如未达标，停止将这四维描述用于调色分支。即使通过，也尚需测试参考误判和目标侧风格响应。本轮限八套已有三态及两遍复现，无新训练模型和目标软件改动。
