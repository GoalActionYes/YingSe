# 新摄影内容与人工区域标注协议（运行前冻结）

使用COCO2017 validation的官方实例标注与逐图来源／许可记录，仅用于本地研发，不把照片纳入Git。来源是COCO官方下载页；标注ZIP独立对照TensorFlow Datasets公开SHA256：113a836d90195ee1f884e704da6304dfaaecff1f023f49b6ca93c4aaae470268，252907541字节。

按图像ID升序、短边至少240，许可仅选ID4、5、7、8，并保留实际许可名称与链接。分别选择20张单人（一个非crowd人物，标注面积8%–70%）、20张多人（2–6个非crowd人物，总标注面积8%–70%）、20张无已标注人物的图片。有person crowd实例的图不入选。无已标注人物不保证绝对无人，须目视检查。

每类相邻两张组成目标／参考，不根据调色结果选配对，共30对、60份输入。每类前两对（共6对）为开发，其余每类8对（共24对）为冻结评估；新候选冻结前不得用评估集结果调参。都独立于本项目历史开发选择，但无法证明未出现在第三方模型的大规模训练数据中。

人物蒙版来自COCO人工polygon，不使用分割模型输出生成评估真值。非crowd polygon先在原尺寸栅格化，再缩放。蒙版只供控制参考生成和评估，不进入候选算法；候选只接收实际RGB输入，自动蒙版必须从这些输入重新推理。栅格化方法与COCO官方API存在边缘取整差异，不称为官方像素级评分。

开发阶段固定五种控制：恒等、全图对比度、全图去饱和、人物／环境不同颜色与明暗、人物／环境不同饱和度与对比度。无人图对应区域控制退化为背景变换。参考B及目标真值A各按人工区域应用相同规则；物体本色和原曝光不同导致风格仍不可完全辨识，不把合成重建误差当自然审美真值。

同时保留30对未经变换的自然输入用于后续匿名对照。开发6对先测，评估24对保持未运行。记录RGB MAE、人工人物／环境分区误差、区域关系误差、白黑裁切比例和蒙版边缘，不以被直接优化的均值距离单独作画质分数。所有失败保留。

当前全局主版与作者E2E模型参数冻结。结果若再次表明全局方案不能表达区域关系，下一候选须显式使用区域条件；不能仅增加全局强度或重选漂亮参考来宣布解决。
