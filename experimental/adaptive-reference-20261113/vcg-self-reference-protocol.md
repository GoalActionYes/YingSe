# 去除参考自调色偏移是否能救回 VCG 色表

VCG 首组默认预处理和跳过预处理均不通过。当前使用实际下载的同一权重检验新假设：模型对一张照片参考它自己时已经会改色。如果这部分变换也叠加到了普通两图色表中，扣除参考特有的自调色偏移，可能改善关闭态又保留跨图风格。本轮不复跑原默认预处理或重新挑种子参数。固定现有 ncc 色表、已用目标 01、参考 02 的四状态、512 方图、25 步和 80% 强度。

候选对每个当前参考图 R 额外调用一次 VCG(R,R)，使用作者跳过预处理的入口。对冻结的 VCG(T,R) 色表减去 VCG(R,R) 相对恒等色表的增量，截断合法范围后应用到同一目标。额外推理只读取当前输入 R，不读取未编辑参考附件或目标答案。分别保存自参考色表、差分色表、实际成片和裁切比例。用相同 R 的配对表与自参考表验证校正严格恒等。冻结 ncc 原成片复读评分，不重新生成。复核原探针的默认运行，色表与成片应逐字节一致。

原有整图、左右脸颊和左右白幕，风格投影 0.75–1.25，响应误差、关闭态偏差和换灯差均不超过 3 RGB8。只有五个区域全部通过且不增加任一原通过项的退化，才考虑扩展到下一个跨人物方向。若任一区域未过，保留实际反例并停止本固定校正。两遍运行，单遍 GPU 预算 120 秒。目前只用于开发诊断。
