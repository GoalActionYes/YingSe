# 复查 VeraRetouch 的参考颜色通道顺序

固定提交的参考入口通过 OpenCV 读参考，在转 Pillow 前没有 BGR→RGB，而目标明确转换成 RGB。作者同提交的其他推理数据入口也转换为 RGB。尚无证据确定训练时参考编码约定。上一轮遵循参考入口原行为，现只验证结果是否对正常 RGB 参考编码敏感。不能将颜色差异直接认定为作者错误。

冻结已用 01 ← 02 人像、VeraRetouch 权重、模型实现、512 尺寸、图像强度、分块、掩膜、期望图和评分。比较原已复现的 BGR 两图及参考前图离线诊断，与前后参考同时按 RGB 输入。目标均保持 RGB。预算 8 张新成片、1 张同图、2 张比较板。不更动已存基线。唯一变量为参考通道顺序，其他输入和所有评分保持。按原 3 RGB8 和 0.75–1.25 投影门槛，检查整图、双颊和白幕；同图仍要求保色。若 RGB 无法同时通过，则结束固定权重的通道顺序路线。若只改善离线三图，继续记录输入不足，不能当作普通两图成绩。无额外模型、训练、独立保留集或产品改动。
