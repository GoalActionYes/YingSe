# 现有 13 号局部网格能否表达已知暖调

普通两图的失败可能来自参考意图推断，也可能来自渲染器无法同时表达脸部编辑和白幕保护。旧 Film B 表达实验通过了全图预设。本轮固定新 Gros 三组冷暖灯、六张局部编辑开关和旧工作台对照，验证真实位置变化对现有表示是否可达。给拟合器该目标的开关成片，仅供离线诊断，软件推理和真实用户流程不读取这些答案。

- 两个拟合只改变是否保留 XY 位置变量。均用 13 号冻结的前后非线性映射与八层颜色引导。全图每层共用一个仿射矩阵，与 16 × 16 个空间节点各有一个矩阵比较。两臂 alpha 固定 1。固定 16 像素棋盘互换两折，每折仅用训练块里 x、y 均能被 3 整除的像素。在网络输出的反解域拟合。空间臂相对全图拟合固定用 SciPy LSMR 求残差，列按范数归一，damp 0.01，atol／btol 为 1e-6，最多 240 步。记录终止原因和残差。前后映射可达范围、离线估计及数值限制必须带到结论中。
- 使用已有原生渲染器生成 RGB 并施加 80%。先对共同的已知可表达颜色映射做坐标测试，再在每个真实拟合上比较稀疏设计与直接浮点渲染，最大差 ≤1e-5（0–1 浮点）。另用恒等输入的 0% 混合检查旧入口。输出由两折各自未参与拟合的块拼出保留留出结构。
- 沿用双颊及整图投影 0.75–1.25 和响应 MAE ≤3 RGB8，两个白幕对原图各 ≤3 RGB8。同时记录未编辑范围、误差 P95 和原样片。六张全保存。均能达标表示此编辑在既有固定表示中存在可达见证，优先查推断。局部失败则定位哪一处还不够，以失败范围限制下一轮，不以此近似求解证明全部网格不可达。
- 本机两遍，预计 30–50 分钟，既有模型上 GPU 仅用于冻结渲染，没有权重训练。本机研究目录固定 SciPy wheel，不改产品环境。无新媒体，所有媒体、成片及权重留在本机，只保存数值证据、代码和复现步骤。
