# 用灰球固定近等亮度灯位，再检查浅色墙面

固定上一轮已核验的复印室、客厅与其墙面、灰球坐标。复用 14、24 号，每个房间另取 0、4、8、12、16、20 六个固定灯位。每房间新增成员请求总上限 4 MiB，另加 ZIP 目录尾部。以灰球先筛选：共同 RGB8 范围 [16,239]，覆盖至少 80%，至少 128 像素，中位线性亮度比绝对对数不超过 0.25，且两维对数色比差范数至少 0.06。通过的配对中选灰球色差最大的一个，按灯号固定打破平局。只有选定后才复核原左右墙框，对墙面沿用同一门槛。墙面不参与挑灯，也不换框挽回失败。至少一个墙框通过才取得该场景的近等亮度浅色面开发配对。若失败，保留空间受光差和过曝反例；本轮不把资料写成两图画质验收。
