# 用均匀色样补齐已知调色的近邻支持

固定参考颜色校准已知调色差值后，白衣和雪地恢复，投影幕脸 F1 的换款投影仍为 0.623，第八近邻距离中位数为 42.37 RGB8。本轮检验剩余不足是否能通过增加接近目标颜色的已知样本解决。

- 唯一变化是在原参考 RGB 样本上加入以既有规则生成的 24×24×24 均匀色样，去重后在同两款已知调色上计算前后差值。基线只用原参考位置的已知差值，须逐像素复现归档。两臂共用八近邻、距离权重、舍入、80% 强度及全部开发素材。构建样本时不读取目标成片、区域或目标原图颜色。
- 投影幕脸 F1 须恢复到投影 0.75–1.25、响应 MAE ≤3 RGB8，且相对原位置已知差值至少改善 0.25 RGB8。记录最近和第八近邻的距离中位数。其他符合原条件的区域，相对已知差值不得丢失通过项，响应 MAE 不得增加超过 0.25 RGB8。保留原单参考保护门槛、两种背景下的白衣判断与全部缺测。
- 两遍固定运行，每遍 16 张新成片、四张图板和报告。若通过，较近的样本位置可以解释这个已知编辑下的剩余失配，保留作离线正对照。若失败，结束固定均匀补样路线，不在同批素材上换网格密度或针对投影幕加样。已知调色仅用于归因，普通两图的编辑判断仍须另行验证。
