# 用主干训练之外的已用照片校准亮度／色度组合

上一轮在两主干已见过的训练照片上拟合时，两套权重都趋近只选扩展版。现在使用两批各 32 张已经消费的早期评估素材，核对主干训练之外是否仍存在真正的模型互补，以及这种互补是否能在原 64 张开发配对上迁移。不会把这 64 张拟合照片重新登记为独立评估。

在运行前固定两份旧报告的完整哈希及已消费状态。目标与参考家族均须和两主干训练／当前开发家族隔离，核对已知别名和准备素材精确哈希。使用原分组审计的近重复筛查证据，不把家族号当作自然照片绝对独立。原 64 条开发集、扩展第 4 块与原 C10 的权重、RGB8 帧、八项输入统计、常数与自适应两个模型、优化器、初始混入率和 180 步保持上一轮。因每张校准目标只有一条已保存的参考，不构造假的第二参考，拟合只用整图 RGB L1 及原斜率正则。未经校准的换参考行为仍必须通过原开发门槛。

先保存所有校准端点，再读取校准作者图，记录每份端点误差、C10 改善超过 0.1 的例数和逐张从两端点选最低误差的离线对照。随后训练截距控制与自适应权重。冻结拟合和全部开发预测后才读开发作者图。不得择例、调整阈值或重新开启已停止的结构。通过要求沿用原双门槛，且亮度／色度自适应组合须优于常数控制和扩展版均值。否则停止本次固定校准；若校准逃离全选扩展而开发无益，记录真实域差及失效范围。

两遍总预算每遍 120 秒，固定 GPU 端点、CPU 拟合，不读取未消费独立集、不下载、不修改软件。核对校准来源、全部开发 PNG、权重、端点评分和敏感范围。
