# 单图视觉语义能否辨认人物与环境的冷色分离

白球服的离线重分配能保护人物，同时保留背景冷色。前两类手工色差和羽化特征无法稳定判别应启动重分配的参考图。已有 Qwen3-VL-2B 数值／类别建议未稳定改善画质并已停止。本轮使用同一冻结模型，改为从单张参考提取一个可直接核查的视觉描述选择。没有参数建议、自动分割特征或输出修改。

使用冻结的原六张参考的 18 个程序化成片，以及未参与原阈值校准的六张目标照片的 24 个新的硬边／宽过渡／基础／整图成片。各样本只给模型当前 RGB。不得给模型同图其他版本、原图、蒙版、文件名、调色参数或操作标签。用以下两个陈述的固定英文提示。顺序交换两次，比较答案的单 token A 和 B 的下一词 logit，每次对有局部冷色陈述取正，结果取均值。均值严格大于零才判局部，不根据成绩调整。另测一张均匀灰图，用于记录语言偏向，分数不用于校正。

- 局部陈述描述背景的大范围偏冷，而人物肤色及通常中性的衣物较少受冷色影响。
- 第二陈述包含两种情况。没有清晰的局部冷色分离，或看不到足以判断的人员。忽略物体天然颜色，证据不清时选该陈述。

留用原门槛。固定羽化的局部参考至少 3/4，14 张负例零误触发，至少三组同图局部排序第一。第二批硬边和宽过渡各至少 3/4，16 张负例零误触发。只有同时达到才进入另行预注册的渲染验证。只比较固定权重、固定提示，不复活旧直接参数建议，也不因失败在本批照片改写提示、换阈值或增加模型。保存全部成对 logit、排序和失判，注明模型描述外观不能识别真实编辑历史。预算两次各 180 秒，使用现有本地 BF16 权重及环境，无下载、外部请求、训练或软件改动。
