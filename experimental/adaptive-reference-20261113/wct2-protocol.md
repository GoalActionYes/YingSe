# 普通 RGB 特征变换基线

SA-LUT 输入适配后，30 例 COCO 开发控制的整图 MAE 中位数为 16.073，现有算法为 19.298，Canon 全局模型为 10.929；人物／背景关系误差中位数仅从现有算法的 11.088 变为 10.952。输入域适配有用，但不能说明局部风格对应已解决。

增加官方 WCT² 作为另一种技术路线的诊断基线：直接处理普通 RGB，在编码器、解码器和小波高频分支进行特征白化／着色，不依赖同一个全局 RGB LUT。固定 cat5 作者权重，三个位置全部开启，alpha=1，不按目标图挑选组合。

本轮先检查与源实现的接口兼容及前五对已使用 PST50 开发样张。为控制显存，目标和参考均等比例缩至最长边 640；右侧／底部复制边缘补齐到 16 的倍数，输出裁回工作尺寸。此处保留原图全部构图，但尺寸和边缘预处理与作者中心裁剪 CLI 有区别，必须说明。所有方法与目标图在同一工作尺寸评分，不把低分辨率结果当作完整 1080p 效果。

先不使用分割或人工标注，也不把模型直接解码结果称为严格只改变颜色；需要检查边缘、纹理和内容重建。数值、处理时间和完整对照全部保存。此基线还不是产品候选，不修改现有软件；若失败，保留失败原因。COCO 留出 24 对、PST50 的 6–50 不用于本轮开发。
