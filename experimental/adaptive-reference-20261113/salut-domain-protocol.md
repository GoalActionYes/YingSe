# 普通 RGB 输入适配诊断

固定问题：作者的 Standard.cube 反向近似，能否把普通 RGB 图构造为 SA-LUT 可用的模型域输入？此适配不声称恢复真实相机 Log、高光或原始色域信息。

已先检查前五对原始 Log→Standard.cube→RGB 与数据集 Rec.709 图的差异：五组每通道最大误差均为 1。这支持检查固定表的逆近似，不支持用任意 Log 曲线替代。

逆表只能根据固定 Standard.cube 生成，不读取照片、参考图、配对目标或对应原始 Log 图进行拟合。使用 33³ RGB 网格和有界最小二乘迭代，记录回环误差和无法准确表示的颜色。应用时同样计算用户 RGB→构造 Log→Standard 的回环误差，不能把不可逆颜色隐藏。

初始化修正：第一次试验发现中性轴初值会陷在裁剪平台，人工构造的可逆颜色也留下 0.25 的回环误差。已增加固定前向表全格点最近邻初值，并以人工控制通过作为修正依据；不依据风格目标图调整求解器。第一次结果保留在 `development-salut-inverse`，修正后写入 `development-salut-inverse-v2`。历史字段 `grid_unreachable_fraction_over_2_codes` 不能证明不可逆，后续改名为 `grid_residual_fraction_over_2_codes`：残差也可能来自网格近似或数值求解失败。

开发诊断仅使用已经检查过的 PST50 前五对。现有算法和 Canon 基线保持原普通 RGB 输入；SA-LUT 分别比较普通 RGB 直入、真实 Log、逆表构造 Log。模型、参考图、网络尺寸、插值和输出方式保持不变。所有模型预测先完成，再读取配对目标评分。记录所有结果，不按配对目标选择输入分支或强度。留出样张不用于构造逆表或开发选择。

首版逆表只用于本研究脚本；不接入产品，不增加用户要选择的色彩空间，不把真实 Log 结果当作普通图片能力。普通图片适配即使成功，局部对应、独立自然效果和视频稳定性仍需验证。

普通照片控制：固定逆表版本后，进一步使用已经检查过的六对 COCO 开发照片及五种已知变换，共 30 例。与保留的现有算法／Canon 输出对照，不改变逆表或模型，不按照片挑选算法，真值和人工蒙版只用于预测后的评分。该项在执行前确定，仍不使用 24 对留出素材，也不把合成目标评分称为自然审美结论。
