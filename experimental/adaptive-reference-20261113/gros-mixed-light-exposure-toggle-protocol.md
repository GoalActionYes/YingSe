# 三档实拍下的同款局部提亮开关

只换参考灯档已经让两版的白幕和肤色明显改变。本轮只问一个问题。同一局部提亮在不同实拍灯档下分别开启时，现有两图流程能否提取同方向、相近幅度的风格响应。此前冷暖对照使用了暖肤色操作，此处改用独立、事前确定的明暗操作，补同一混合灯配比下的开关证据。[冻结的两版关闭成片](../../docs/research/2026-11-24-gros-mixed-light-transfer.md)

- 使用此前同一人脸羽化椭圆，从各档原片的线性 sRGB 增加 0.5 EV，以相同权重混合有、无曝光的像素。关闭态读此前工作台实际读取的参考 PNG。白幕和椭圆范围外必须逐像素保持，整图新增端点不超过 2%，双颊的 Y′ 提亮中位数都至少为 3 RGB8；两人的三个参考档和各自冷灯目标都通过，才运行工作台。固定动作由本轮定义，用于开发控制，不归给照片作者。估计本机 15–25 分钟，无新素材或模型训练，跑两遍。
- 固定另一人的冷灯目标、默认手动项和 80% 强度，稳定 1.3 与 13 号各实际导出三个开启态。关闭态沿用上一轮哈希绑定的实际工作台成片。目标答案只由同一已知操作和现有强度合成生成，参与离线评分。两颊要求方向投影 0.75–1.25、响应误差不超过 3 RGB8；白幕与编辑区外检查相对原色及开关后多出的改变量。分别保留各档误差，以及不同灯档的开减关响应差，避免把整张带偏但开关相近解释为过关。
- 任何输入身份、尺寸、启闭数学控制或准入变化先停并记，不按效果重调加强。若两版在同款开关下仍不能稳定保留预期颜色，只将对照列入开发标准，暂停继续试局部强度；若有局部通过，先看是否跨人、跨灯档且白幕没有退化。两批均为旧开发人物，不构成独立评价或新训练素材的完整资格。
