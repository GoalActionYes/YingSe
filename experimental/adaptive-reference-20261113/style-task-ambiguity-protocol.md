# 新局部训练任务的输入歧义检查

只回答：是否能不附加先验，要求两张RGB输入唯一判定“参考背景物体换色应忽略”和“同样颜色来自全局风格应迁移”？这不是寻找真实数据错误，不训练、不改模型、不读GT或独立图片。

固定旧训练行顺序中双方都满足原人物／背景支持条件的前四个不同目标内容，保留原行身份。仅为可逆构造，将两份RGB截到[16,239]，明确为合成演示，不冒充原照片；参考人物区域用既有自动概率>0.5。

固定两个整数位移d=(-8,4,-8)、(8,-4,8)。给定目标T、参考潜在底图R和人物区域P：

- 解释A：背景物体变色，观察到O=R+(1-P)d；没有风格操作，答案为T。
- 解释B：潜在底图R'=O-d，整图风格为加d；观察仍为O，答案为T+d。

所有像素均在色域内，整数运算不裁切，R'+d必须逐像素精确等于O。两种解释对算法可见的(T,O)哈希必须完全相同，输出答案必须不同。人物分割、DINO特征等若仅由同一RGB确定，无法新增解释标签。

预先判定：出现任一精确双输入碰撞，则拒绝把这两种隐藏生成历史同时作为“唯一客观答案”混入新训练；先明确自然图先验、产品偏好或额外观测如何选取。不能把该构造外推为真实数据广泛冲突、所有两图方法无用或目标无法改善。
