# 核查真实修图历史能否提供独立编辑开关证据

现有实拍之前／之后多为最终成片，不能确定作者同时改过哪些参数。本轮核查 MIT–Adobe FiveK 官方 Lightroom 目录的历史状态。目标是确认能否从同一照片相邻两个状态辨认仅改变一个色彩参数或明确局部工具的真实操作，并关联到另一个拍摄家族。目录记录是离线证据，生产推理仍只接受两张图。

读取研究许可、官方公开 tar 的 HTTP 范围与元数据。只在范围请求返回正确的 206、偏移及文件身份时读取目录，不下载整包。元数据探测预算 2 MiB，最多 1,024 个 tar 头；目录下载预算 320 MiB，文件超限即只读其 SQLite 页目录和小型统计抽样，若不可达则停在准入。只在本机保存目录，不读取或上传照片、路径中的作者姓名或身份字段。

如可解析目录，只读表结构及聚合数量，确认照片、历史顺序和完整可解析的参数状态是否能连接。固定查三类：有前后完整状态、疑似局部工具、仅一项可用调色参数变化。只有两份可明确对齐的状态确实仅改变一个相关参数、可与另一拍摄家族的同操作关联且能恢复前后像素，才用于下一轮出图。工具名称、状态数、专家身份或不同照片的相同滑块数值单独都不足。未获得像素与真实开关前，只登记为素材准入调查，不新建画质成绩或训练集。

页结构可读后，固定抽历史表最左、最右各 10 行。由更新时间排序，仅比较时间不同、同一图像的相邻状态。使用字面量解析器全量比较顶层参数，包括嵌套取值；未知语法与时间并列不判。仅核对照片表所指的原文件标识是否一致，输出计数与关联结论，不输出标识、时间和路径。另一端及关联检查限再读 40 KiB HTTP 数据，原抽样从本机缓存复用。先按结构抽样，不能后选命中不同调色项目的照片。如果另一端是同一原文件、没有对应记录或仍无色彩开关，则保持现有单图证据。
