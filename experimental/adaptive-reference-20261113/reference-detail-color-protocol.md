# 用局部颜色细节解释参考的整图颜色

上轮小块色度截距由固定成像假设给出校正，未跨场景通过。同结果与不同结果训练也已两轮停止在旧直方图分支上追加约束。本轮固定 13 号及其输出，测试是否能使用额外的局部明暗与色度变化信息，从真实作者配对学出有用的输出残差。局部差分能提供整图均值中缺失的照片内容线索，不假设它能直接指出真实调色操作。

两个学习臂共享 82 组已固定训练照片、同一亮度带色度残差、同一回归方式与渲染。控制输入含目标和参考的亮度、去亮度颜色均值及标准差；候选额外使用 1 和 8 像素位移的横纵局部差分。每尺度取绝对明暗及三通道色度变化均值，以及明暗与色度差分协方差除以明暗差分方差。训练组统计标准化，标准差下限 1e-6，固定 ridge 1e-1 相对于平均训练平方损失。输出标签为目标原图八等宽亮度带内、作者调色减 13 号的平均色度残差。每带训练按有效像素占比加权，推理时在带中心线性插值，限定最大通道绝对偏移 8 个 RGB8 码值，去亮度后等比限幅。13 号输出亮度在裁切、量化前保持，不更改调色强度。两张原始产品输入和 13 号出图是推理所需的全部信息。

沿用跨角色隔离的 82 组训练和 24 组开发，不读取独立保留素材。先输出 72 份控制和 72 份候选，再读取开发作者结果。候选须通过参考替换已有完整门槛，包括至少 18/24 组，且比新控制多至少三组，以及无超过两码值的严重退化。固定候选在局部开关和背景物体色对照也实际输出，继续还须通过原背景门槛、至少三组局部联合、原 4/6 整图响应和同图／无人负例。若失败，不调整局部尺度或回归配置追开发分。两遍各不超过 150 秒，无下载、产品改动、独立评估或新增权重发布。
