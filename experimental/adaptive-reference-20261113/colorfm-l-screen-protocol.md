# ColorFM-L 的固定两图画质筛查

ColorFM-L 用语义交叉注意力预测颜色流参数，渲染每个像素时使用同一参数组。离线下界显示现有局部冷色照片里同色冲突较少，因此仍有必要实测该模型能否减轻已有调色失败。它是全局对照，不能按位置分配同一输入颜色。

固定作者源码 `64c84c228cb505425c18546b886d3c80906f5e27`、权重发布 `693df21de201df1df83e503ea5bc5709673f7c84` 的 `ColorFM_L.pth`，123,249,227 字节。代码 Apache 2.0；权重发布标注 CC BY-NC 4.0，限本机非商业课程研究。最大权重预算 124,000,000 字节，严格检查大小和哈希，使用 weights_only。启动器可隔离仅用于日志的可选依赖，模型的计算不改。优先已装 PyTorch，既有环境不增依赖。按作者原尺寸入口令输入为 RGB 0–1，使用 float32，完整推理再与原图按 80% 混合量化。固定模型只看目标和参考，禁用在线演示、人工蒙版和目标答案。两次合计最多 10 分钟。

固定复用 42 张背景对照、18 张局部开关和 PSBench 实拍两个方向。通过条件沿用上一轮：人物联合至少 6/8，近中性色平均抗干扰至少 15% 且最差不超过 +1，对比度与去饱和 12/12，局部人物至少 3/4、整图冷色 6/6、无人负例 2/2，实拍两方向整图和近中性色均优于保留原图与既定比较门槛。同图作为产品端恒等对照，原生输出也单独记录。同一设置重复验证并保留所有失败。任一门槛未过不接入，不调参数追分。
