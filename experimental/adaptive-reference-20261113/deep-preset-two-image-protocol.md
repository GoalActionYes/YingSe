# Deep Preset 两图原画面筛查

候选使用已调色参考与目标图，作者训练用 Lightroom 预设参数监督。核查的公开源码中，图像解码直接取联合参考／目标及独立目标编码特征，默认图像输出不读取预设线性头结果。它区别于已停的七组固定分类与径向渲染，但仍可能把参考布局误作目标风格。

- 固定作者提交 `04eb47352e2f4cd643d466c7c6835f17d9513c92`、公开 wPPL 权重、非商业研究。按发布树核对五个 Python 文件的 Git blob。下载前确认 1,071,225,835 字节旧序列化文件中，六段合计 47,482,012 字节属于图像前向所需张量。使用 206 区间及固定内容范围，预算 50 MiB，不下载预设预测头。解析时只构建元数据，拒绝未知全局、数据类型、视图与尺寸。严格核对本地模型键及形状。
- 固定 13 号 80% 强度。六组已消费背景干预每组七种参考；另用已消费 PSBench 105 的人像／铁塔做双向实图。按作者方法让参考匹配目标尺寸及双三次缩放。尺寸不足 16 倍数时右、下复制边缘补齐，输出裁回原尺寸。使用作者 RGB8 转换再按 80% 混合。相同输入按现有产品规则保持原图。
- 沿用人物 6/8、近中性色平均至少减少 15%、最差增幅不超 1、对比及去饱和 12/12 的原背景筛查。PSBench 两个方向的整图与近中性色均至少比 13 号好 1、也不得劣于原图，整图方向为正。另检查 256 输入的实际网络输出、人物与边缘变形，防止生成结构变化冒充颜色收益。
- 42 个受控与两张实图输出，做两次复现，使用本机已有 GPU 环境，无安装。仅开发，不上传权重、原图或产物。若失败保留全部结果，不追调尺寸、权重或强度。若显存不足，保留失败与已完成结果，不能把低分辨率替代当作同一条件。
