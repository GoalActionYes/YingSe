# 固定检查点的训练／开发拟合差距

只评价已选择的控制第8轮与区域第3轮，在原1024训练和64开发配对上比较原主干RGB8误差。不新增训练、选轮、阈值或保留集。每例生成候选后读取对应GT计分，保持全部样例。

先核验当前源码、输入注册、描述器、概率缓存、cohort与预处理manifest；逐行检查content/reference角色、index/group/style顺序；将content/reference/gt三路径与原作者triplet.json对应行核对。路径相符不证明风格真值完美，不根据文件后缀猜测配对错误。

按与已完成训练相同的RGB256、TF32关闭、SpatialEngine原始浮点满强度结果及两组残差头，重算每例原版／控制／区域RGB8 MAE与改变量。全部64开发输出必须逐像素复现各自已保存结果。训练组不需要发布照片或保存所有PNG，记录输出像素哈希。

分别报告训练与开发的均值、改善>0.1数量、明显退化、区域支持组与不足组结果。若训练和开发均无足够收益，不能称纯泛化失败；若训练收益强而开发弱，优先调查泛化与监督对应。该检查不会证明是哪一个模块导致失败，也不自动授权扩大模型或延长训练。保留原失败决定。
