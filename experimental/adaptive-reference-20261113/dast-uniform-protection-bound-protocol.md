# 统一肤色保护的取舍：运行前协议

问题：统一减弱肤色变化是否能同时解决真实换曝光串色和有意暖调偏弱。用五组冻结 13 号成片及曝光归一成片。仅研究同一目标所有参考状态共用一个全局系数 g，目标脸部每像素线性 RGB 对数色度围绕原图等比例缩放。按原报告冻结各比较的像素支持，则换曝光色度范数和暖调投影均乘 g。计算每组稳定要求 g < 0.03 / 最大曝光差，以及暖调要求 g ≥ 0.75 / 最小正投影。即使离线按组选择，若区间无交集，也不开发此统一保护。仅作连续值、固定区域下界，不外推到像素可变、参考自适应或其它色彩空间的修正。

从归档逐图验证输入身份并独立重算稳定及暖调投影。另在每组最弱暖调对应曝光制作一张采用稳定边界系数的 RGB8 对照，保留归档结果的线性 Rec.709 亮度，记录色域裁切；它只是可看示例，不代替连续数学结论。共十张。目标效果及肤色区域仅用于评分和选择离线展示，不进入产品。无需训练或推理。
