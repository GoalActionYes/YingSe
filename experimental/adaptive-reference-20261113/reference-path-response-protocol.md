# 分开参考统计和外观，检验局部色变化通过哪条路径传播

13 号此前已确认受控的背景偏色主要从颜色统计传播。扩展版另有参考外观分支。旧消融把外观替换成目标本身，测不出同一参考发生局部调色时两条路径各自的作用。本轮固定扩展第 4 块，在参考内容不变时只向一条路径送入参考变体，并检查该路径是否能在抵抗背景物体色变化的同时保留有意的局部冷色。

对每个固定目标和参考锚点，运行原锚点、完整变化、只换颜色统计、只换参考外观。颜色统计包含边缘与联合直方图，外观保持现有编码。两个隔离臂均使用现有 appearance_reference 接口，不禁用分支。两条路径的输入按固定锚点配对，不使用目标作者效果或人工蒙版推理。响应交互项为完整增量减去两个单路径增量，使用已量化 RGB8，记录带符号分量及绝对差。交互项和区域幅度不能被当作百分比因果归因。

固定六组旧背景干预的 42 个完整输出及同六组 18 张局部冷色开关。旧背景锚点为原参考，另含两种背景物体色及四种整图变体。新开关锚点为基础调色，另含背景额外冷色及全图额外冷色。两套输出均用原 80% 混合。旧正常完整输出和锚点必须逐像素复现。全部新输出落盘并核对身份后再读评分蒙版、作者目标。旧背景沿用相对 13 号的原门槛，新开关沿用局部响应、人物保护、整图可见效果和无人负例门槛。

固定下一步条件：同一隔离臂必须通过两套控制，才值得另行设计正常两图可用的条件。此离线探针需要已知参考锚点，不能作为普通产品输入。预计失败也应分别记录有意局部响应和背景干扰，保留同一分支对两者表现不同的可能。两遍各≤100秒，无训练、下载、独立评估或软件改动。失败不调阈值或再搜索相同路径的开关比例。
