# 独立实验入口设计与实施

范围：把已跑通的 CanonCGT E2E 模型接成可操作研究版，支持图片／视频分析帧、方法切换、原图对照、既有微调、PNG/MP4/CUBE 与工程保存。模型仍是全局映射，不伪称完整区域理解，不接入已经在反证中失败的区域统计。

稳定版 reference_color_app 与依赖不改。实验服务器继承原 HTTP 校验、上传、项目、预览和异步导出；实验 Store 单独持久化模型缓存与指纹。模型冷启动在后台进行，首次使用前显示准备状态。模型加载失败时显示失败，不静默换算法。

界面沿用原基础/HSL/曲线，仅在克隆区加入方法下拉框。切换时失效当前分析和导出链接，旧请求不能覆盖新选择；项目恢复显示真正对应的方法。页面标题与页脚明确实验版。

模型先按最长边640提取两阶段映射，再用浮点64³网格合并到主版 Mapping 合同，预览与导出同一路径。合并属于采样近似，需与原模型输出对照。强度沿用现有双层响应，不能叫线性0–100。同图精确恒等绕过模型。视频沿用分析帧固定颜色表，不新增逐帧语义或空间场。

实施顺序：
1. 先测试模型 Store 的同图绕过、缓存恢复、方法隔离、篡改拒绝、输入合同，再实现。
2. 检查模型浮点LUT组合的通道与采样误差。
3. 实现服务器与受控的静态页面适配，保留现有安全校验；接口测试字段、跨站请求、不同方法恢复、PNG/CUBE导出。
4. 实际模型HTTP上传、分析、预览、微调、导出、重启恢复及短视频MP4验证。基础测试可用伪模型验证流程，真实模型核验单独标注。
5. 运行并检查界面，收集已知失败与速度范围；仍未通过独立自然质量评估，不作为稳定版发布。
