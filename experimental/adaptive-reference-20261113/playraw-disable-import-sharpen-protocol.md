# 关态锐化归因与编辑参数重放

冻结上一轮三份已导出的 sRGB 输入 TIFF、作者模块开关、导出设置、调色范围与成片规则。编辑器关闭态日志中出现自动锐化；当前假设是这一步导致原本无编辑的 sRGB 回读出现较大边缘误差。本轮唯一改动是独立 CLI 配置中的 plugins/darkroom/sharpen/auto_apply=false，各状态同时设置，不影响映色或本机编辑器的正常偏好。沿用开关差分、原目标亮度、固定 80% 与原编辑范围。两个缓存仍来自同一个 Cuckoo 内容，不能当作两张独立照片。

比较父实验相同关闭状态下的 RGB8 偏差和像素管线日志。关态必须最大偏差不超过 1，肤色和保护区仍用上一轮的投影、误差、过渡区限制与像素恒等门槛。冻结作者 RAW 编辑答案，只用于离线核验。两次各运行六个 CPU 导出，逐件比较最终合成 PNG 及报告；中间 RGB 若有差异逐项记录。若只通过关闭态，保留锐化归因和合成反例，结束固定 sRGB 端点方案。若连全部肤色与退化门槛也通过，才进入新的真实照片检验；额外作者参数依然是输入条件，不能算两图画质验收。
