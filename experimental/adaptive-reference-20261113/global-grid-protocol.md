# 同条件的输出空间约束对照

容量审计capacity-audit-v1已完成：64开发例的GT辅助跨块拟合中，同一固定guide全局场均值2.19996，54例≤3码值；粗空间场1.67933，额外平均改善0.52062。它不是从参考图推断出的效果，也不证明所有自然／语义关系都可用全局函数表达。本轮仅以此为动机，检验约束预测输出的空间自由度是否减少开发误差。

不改App，不从失败候选续训。两臂都从13号当前第6轮SHA `d8d8e6727a44100e6fedb11b605a17e33afc675de7448d4ebcf6d24d492ad4c9`开始，安装相同的零初始化pairwise条件头，参数、输入特征、内容编码、引导及低通都相同。唯一差异：实验臂在lowpass之后对13×8×16×16网格的XY取均值，得到13×8×1×1，之后使用同一原生sampler和apply_coeffs。

13通道包含12个alpha预乘的矩阵／偏移分量及正alpha。因此先平均预乘分子和alpha，渲染时再相除，产生alpha加权的全局系数；不是先除alpha再平均。投影在训练、开发及后续诊断时始终一致。映射仍根据目标和参考预测，并由输入RGB的guide选择z层；不是固定预设滤镜混合。只对同一次分析后固定的映射而言，同RGB不随像素位置变化；重新分析不同内容仍可得到不同映射。

控制完整场启动前检查64张原始float／grid／PNG与当前模型完全一致；实验的未投影完整场也必须通过同样检查。二臂初始完整参数逐张量一致。实验投影后的起点输出允许改变，单独记录，不能宣称它与当前输出相同。

数据仍为cohort-multiref-v1，256目标×4参考训练、32目标×2参考开发。seed20261120，batch4，AdamW base lr1e-5／额外头lr1e-4、wd1e-4、8轮2048更新、梯度裁剪1；损失仅RGB L1＋0.1倍横纵梯度L1，无上一轮额外关系损失。样本顺序与初始化相同，不称相同FLOPs。

完整控制先成功完成，冻结源码、配置、检查点和评分后再训练投影臂。每臂另保存baseline-current完整场评分及64图，以同一当前12.41128基线执行完整门槛，不能用更弱的投影起点当提升基线。每臂选轮仍仅按本臂64图最低RGB MAE，包含其第0轮，不按目标关系指标换轮。

沿用response_development_gate，不因可能提速／导出CUBE而放宽质量门槛。两臂需相对当前RGB平均至少改善5%、40图改善、严重退化至多2，新增参考32图均值不退且17图改善；参考delta改善5%，明暗关系误差改善5%，亮度／对比度／饱和度代理均不退。投影臂另需相对同预算完整场RGB均值改善3%／36图／严重至多2，参考delta改善5%／20组，明暗关系误差改善3%。失败不升级，不按结果修改标准。
