# 允许逐像素逐通道后，现有真人结果能否达到既有肤色、白幕和风格门槛

整图和区域固定权重对照已经失败。上一轮用两套出片共同支持的方向重组色度，一处脸颊改善但风格过量和白幕退化仍在。未知的是，即便允许逐像素和逐状态选择，现有成片是否包含足够的颜色变化。该问题决定是否值得设计更复杂的自动混合器。

固定 Gros 六方向、冷暖灯、Film B 和 80% 强度。备选是 1.3、13 号、两种回归、上一轮的共同方向与等幅，以及原片。分开为每个输出像素、RGB 通道、冷暖与开关状态取最小最大值。这个盒子包含任意非负混合及其逐通道取整，也额外允许混合器做不到的选择。答案和区域只供离线核验。生成两种实际文件。第一种保持关态原色，开态逐像素选与预期最近的一份现有输出。第二种保持关态原色，开态将每个通道的答案限制在放宽后的范围内。后者用于解释边界，不能冒充模型或产品输出。

用原整图、双颊及双白幕门槛。每区域每灯的关闭态平均绝对误差不超过 3 时，复算开关响应的最小误差和投影上、下界。前者用同通道调整一单位关态误差最多减小一单位响应误差，以及开、关态区间之差，得到精确下界。后者按参考信号绝对值从大到小分配关态误差预算，计算放宽条件下的确切端点。冷暖成片差另用区间间距下界检查。范围本来就由整数端点组成，取整仍留在范围内。

若必要条件已经超线，就排除从这七份冻结成片单独选择或非负混合的完整修复路线。若未超线，只说明这组必要条件无法排除，继续保留完整反例。只有可达或实际通过的方向才值得追究无标签选择依据，不能把离线逐像素见证当作产品方向通过。预算 48 张诊断成片、6 张对照和报告；无新素材、训练、封存检查或接入。
