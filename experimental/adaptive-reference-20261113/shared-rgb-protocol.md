# 同一全局RGB映射的一致性下界

固定上一轮全部64个训练诊断配对，不增删，不拟合预测器，不读取独立图。已知参考原图／参考效果和目标原图／目标GT仅用于数学诊断。

把两幅输入图像中相同RGB8键的所有期望输出合并，每通道中位数给出任意确定性全局RGB函数的最小L1误差；允许每个RGB键独立取值，因此这是不要求平滑、LUT插值或可学习性的乐观下界，不是可部署算法。分别计算单幅图的下界，按像素数加权，再用联合下界减去该值，分离图内冲突与两场景共享函数额外代价。

同时报告精确共享RGB键数、两幅图落在共享键上的像素占比、共享键各自输出中位数的距离。不得对RGB量化分箱或搜索阈值放大冲突；中位数距离只作描述，不作额外下界。先通过常量矛盾、无共享键、图内矛盾及小数组暴力中位数核验。

全部64结果保留，并按上一轮预先固定的3个严重退化案例单列。若下界很低或共享覆盖少，只能说明该检验不足以证明共享函数矛盾，不能据此认定单一变换成立或需要更大的网络。若存在冲突，也不能排除量化、配准、局部变化或配对风格近似；不能判定标签错误、删样或改验收门槛。

本项只用CPU和现有准备图，输出数值与哈希，不训练、不生成新调色候选、不替换软件。下一决策根据边界证据确定，不能把数学检查通过当产品画质通过。
