# 复原两张原始实拍的局部压暗开关成片

问题是编辑者留下的曝光实例是否在真实出图中压暗了天空，同时大体保持前景。使用上一轮的 `sky-A.xmp` 与 `sky-B2.xmp`，每张只改最后有效的第二曝光实例启用位。A 最终保存关闭，B2 最终保存开启。保持全部历史、蒙版和参数。用固定 darktable 5.4.0、CPU 和 sRGB8 无损 PNG 渲染，长边 1024，最多两遍，每次只运行一张。编辑器独立展开到忽略目录，使用隔离临时库及配置。预期预算为两个约 23 MB 的原作者授权 RAW、官方 Windows 包约 126 MB、最多一个小型解包依赖。各输入核对来源、大小和哈希，媒体与安装包仅留本机。

用只看关态图登记各图明确的天空、远离天空边界的前景，以及一段山脊／树线附近的带状矩形，坐标单位为归一化图像位置。登记后再读开态。判据为两组天空内平均亮度至少降低 5 个 RGB8 码值，前景 RGB MAE 各不超过 2.0，图片尺寸相同、各有两遍一致的解码像素。亮度用 0.2126R + 0.7152G + 0.0722B。边缘带记录 RGB MAE 和蓝减绿的变化并保留实际裁切，解释已知色边，不将其隐去。只选这两张及指定编辑实例，不为追分重选附件、坐标或门槛。

两组通过才作为后续跨图开发材料。若一组失败，保留原因及能用的反例，先收尾该输入，不将相同意图当成相同强度或正式验收。这轮只建立已知编辑开关；映色推理仍只使用参考成片及目标原图。若无法取得或运行固定编辑器，保存实际阻碍，不用自编模拟替代原编辑器输出。
