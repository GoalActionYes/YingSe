# 用 FAU 的实际换灯补查同款局部暖色

此前合格的有意暖色只在 MIT 室内取得一个方向、幅度同时接近实际换光的来源。FAU 档案把红、白、蓝两盏灯的颜色组合登记在文件名，包含同一布景的重复实拍及排除过暗区域的掩膜。现在以相同的 RawTherapee 局部暖色打开或关闭，核查能否从另一个采集机构获得合格正例和真实换灯近似。档案旧工作只用灯组评估照明转移，本轮增加同款暖色交叉对照。

## 固定材料与预算

使用本机固定的低分辨率档案，仅取实验室十个布景全部 58 个灯色组合。沿用作者 sRGB8 预览编码及同名有效掩膜。每个布景只查看白蓝灯锚图，选择一个浅色表面、一个远处保护区并固定坐标，再读取其他灯档。杯底的浅色带、木台及不同材质道具单列，说明光谱反射未知。作者预览用于显示对照，非 RAW 色彩匹配或已知绝对反射。资料不提供逐张快门确认，弱化额外的因果解释，仅保留已有的同布景和灯色组合信息作为研究对照。预计 25–45 分钟，机器预算两遍共 8 分钟，无新下载或训练。[作者说明和档案](https://www5.cs.fau.de/research/data/two-illuminant-dataset-with-computed-ground-truth/) · [上次匹配边界](../../docs/research/2026-11-24-shared-local-warmth.md)

## 门槛与决定

每张保持原素材准入的关态、保护、色度、亮度和新增端点线。固定暖色参数 1600、2800、力度 30，沿用实际编辑器和原匹配函数。遍历全部有序方向。两档需过素材线，共同支持至少 80%，真实换灯和有意变化的三通道幅度各至少 3 RGB8，方向余弦至少 0.90，幅度比 0.75–1.25。可进入下一预审的方向还要求只改变一盏灯的颜色代码，并在两张照片的登记编辑区域内都达到至少 80% 的作者掩膜共同有效覆盖。保留双灯同时变动、过暗及所有幅度和方向反例。

任一布景在额外条件下通过，才有依据把这套已使用的 FAU 技术素材交给跨来源预审，并以真实工作台对照验证。没有合格方向时，仍可保留通过原素材门槛的有意编辑正例，结束对这套现成灯档的取样，不调现场标签、选择框或暖色力度。杯类实验提供浅色材质代号，不能当作真人或白墙独立验收。公开来源、原始照片、完整成片、权重和运行环境按既有边界处理。
