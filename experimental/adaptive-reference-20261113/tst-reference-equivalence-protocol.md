# 同一调色结果的跨内容参考核查

问题是现有训练素材能否提供作者明确认可的参考替换，而不用按预设文件名推断风格，也不用从目标真值拟造参考。核对固定 TST100K 索引和既有扩展训练资产清单。只用元数据，CPU 预算 30 秒，不读照片、不下载、不重新分组独立数据。

同一目标原图和同一作者结果必须在原始索引中对应至少两张来源内容不同的参考。排除同一目标／参考对应多个结果的歧义行、目标同源参考以及已知关联家族。另要求同一目标有至少一条明确对应另一个结果的参考，避免只有一致性约束。先统计已知家族允许的索引配对，再核对原图、参考和结果都在既有训练资产集合中且有已准备副本的配对。开发或保留资产不得进入可运行组。

至少找到八个不同的目标内容组才计划小样像素核验和同款参考换图实测。低于该数量则保留缺口，不下载新照片或启动训练。索引只提供图级配对，即使达到数量，也需要实图复核，不能解释为局部编辑或独立画质真值。
