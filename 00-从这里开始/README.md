# 从这里打开映色

**体验和课程交付先读：[统一入口与五分钟演示](0-体验与课程交付.md)。** 当前优先整理已有软件；新画质升级仍未完成。旧1号便携包路径本机缺失，稳定源码体验使用14号入口。

本机当前推荐研究入口：**13-打开自适应调色新版.cmd**。输入一张参考图及目标图片／视频，保留基础、HSL、曲线和撤销等已有操作；视频自动平滑色彩过渡。它是独立课程研究版，不是完整剪映复刻，也不替换稳定版。

## 选择版本

| 入口 | 用途 | 导出 |
|---|---|---|
| **13-打开自适应调色新版.cmd** | 当前自适应候选，独立工程目录 | 原尺寸PNG、30fps MP4；不支持普通CUBE |
| 14-打开稳定版源码.cmd | 稳定源码版；独立课程工程，手动打开打印的地址 | PNG、MP4、全局CUBE |
| 12-打开局部调色研究版.cmd | 上一版空间模型，保留作对照 | PNG、30fps MP4 |
| 11-打开自适应调色实验版.cmd | 现有全局算法与模型基线比较 | PNG、MP4、CUBE |
| 1-打开当前稳定版.cmd | 历史便携包入口，需要完整dist包 | 以实际包版本为准 |
| 2-打开肤色保护实验版.cmd | 独立旧实验包，需要完整dist包及模型 | 以该实验版说明为准 |

13号双击后会打开本次本地服务地址；再次双击会复用正确版本的服务。程序更新时，启动器会识别自己创建的旧服务；有导出进行时不会强行结束。不要按文件日期猜入口。

静帧预览与经过时间平滑的视频成片可能略有差异。图片导出保留原尺寸；视频保留首条可用音轨，以30fps输出，奇数边补齐偶数。4K视频导出仍较慢，不是实时编码。

13号使用`dev-data/spatial-multiref`，12号使用`dev-data/spatial-reference`，不会覆盖彼此工程。模型、素材、环境和这些本机工程目录不随Git上传。

## 我要修改什么

| 位置 | 内容 |
|---|---|
| `reference_color_app` | 稳定版源码，基础／HSL／曲线等通用控件 |
| `experimental/adaptive-reference-20261113/spatial_workbench.py` | 当前研究版HTTP服务及界面适配 |
| 同目录`spatial_render.py`／`temporal_grid.py` | 空间颜色变换与视频网格平滑 |
| `prototype` | 最早的八滤镜原型，历史比较用 |
| `docs/RESEARCH_PROGRESS.md` | 版本状态、证据与交接入口 |
| `outputs` | 本机测试输入、结果和模型，不需从这里寻找软件入口 |

9号、10号是历史研究展示；本机`.lnk`快捷方式不随Git同步，可能受迁移路径影响。以本表的源码路径及13号启动脚本为准。

## 同学从Git接手

研究分支为`codex/adaptive-reference-research-20261113`，不要把Git GUI的“变更列表”当成整个项目目录。版本进展先读[交接入口](../docs/RESEARCH_PROGRESS.md)，新版范围读[工作台说明](../docs/research/2026-11-13-multiref-workbench.md)。

准备给老师和同学汇报时，打开[阶段成果与方法](../docs/MILESTONES.md)：按阶段列出问题、方法、效果、验证和版本标记，避免只展示功能而说不清改进过程。

Git克隆不包含EXE、便携运行时、研究权重或测试照片。13号依赖已准备好的本机研究环境，不能只克隆便宣称可直接运行；其他电脑先按[源码启动指南](../docs/GETTING_STARTED.md)运行稳定开发版，再单独准备研究环境及权重。所有模型研究限课程／非商业用途。
