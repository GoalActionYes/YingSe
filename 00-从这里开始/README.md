# 映色项目从这里开始

## 我只是要打开软件

双击本文件夹的 **1-打开当前稳定版.cmd**。这是参考图调色软件，能够导入图片或视频、选择参考图、调整强度并导出。

需要试肤色保护时，双击 **2-打开肤色保护实验版.cmd**。这是另一份独立版本，保护默认关闭，视频保护输出30fps。

当前“参考构图适配＋人物适用条件v4”只是研究代码，没有新的可操作App。双击 **9-查看最新研究对照.cmd** 可以查看图片对照与验收结论；v3历史展示仍保留。

## 我要修改项目

- `3-当前稳定版源码`快捷方式 → 根目录 `reference_color_app`。
- `4-肤色保护版源码`快捷方式 → `experimental/skin-protection-20261019/reference_color_app`。
- `5-当前研究代码`快捷方式 → `experimental/content-balance-20261105`。
- `6-研发日志与计划`快捷方式 → `讨论/11-研发日志与调整策略`。
- `7-交给同学的安装包`快捷方式 → `讨论/09-肤色保护实验版`。
- `8-Git版本管理`快捷方式 → 在项目根目录打开Git GUI。
- `9-查看最新研究对照.cmd` → 打开本机生成的研究展示页。

快捷方式是本机生成的，不随Git上传。源代码与启动脚本路径仍按原结构保留。

## 原目录是什么

| 位置 | 用途 |
| --- | --- |
| reference_color_app | 当前稳定版的实际源码 |
| experimental | 独立实验与当前研究，不一定有界面 |
| prototype | 最早的八滤镜原型，保留作历史比较 |
| dist | 各次打包结果；稳定启动脚本已经指向正确版本，不必按日期猜 |
| 讨论 | 汇报、同学体验包、演示素材和日志 |
| docs | 技术证据与设计文档 |
| outputs | 测试素材与输出，通常不用手动打开 |
| work | 临时调查、脚本、验收副本，通常不用打开 |
| 归档/根目录旧说明 | 本次从根目录收起的7份早期说明 |

根目录旧的“映色.exe”和“启动演示.cmd”属于早期预设版，暂时保留以免破坏旧入口。日常请使用本文件夹的1号入口。

## 其他电脑与Git克隆

Git源码不包含dist、便携运行时和模型。若只克隆仓库，1号和2号入口会明确提示缺少完整包；请先完整解压相应体验包，或按源码说明安装开发依赖。这不是软件丢失。

本次只增加导航入口并归档散落说明，未移动程序、源码、模型、用户素材、数据库或Git仓库。
